# Day61 くみまえ

自分で入力したPCパーツの寸法・規格を、3Dの模式図と数字で確認するアプリ。
[公開URL](https://hundred-days.pages.dev/day-061-kumimae/)

## 使い方

1. 架空の作例で動きを試す。
2. 「寸法を入力する」から部品を選び、購入候補の値に置き換える。
3. 確認結果と未確認項目を読み、仕様リンク・メモ・画像を持ち帰る。

初期値は実製品の仕様ではない。実製品カタログや自動価格取得は提供しない。
価格の空欄は未入力、0は0円。入力値は端末に保存し、APIへは送らない。
仕様リンクに価格は含めず、メモと画像には入力価格を含める。

## 確認できる範囲

- ケースの対応基板、CPUソケット、メモリ規格・枚数。
- GPU長、空冷クーラー高、電源長と、入力した上限の比較。
- CPU/GPUの入力電力と補助機器の概算から、電源容量の目安を計算。

通常配置・空冷クーラー・GPU1枚・SSD1枚が対象。
水冷、特殊配置、BIOS、金具、ケーブル、冷却性能は別途確認が必要。
3Dの配置と一部の寸法は説明用の代表値。実製品の外観・動作・取付けを保証しない。

## ソースと公開物

`source/` にTypeScriptとテストを置き、`index.html`・`assets/`・`legal/` は生成する。
共通サイトのビルドでは `source/`・`tools/`・`tests/` を配信しない。

```sh
cd day-061-kumimae/source
npm ci
npm test
npm run release
cd ../..
npm run shared:sync
npm run index:sync
npm run precheck
npm run build
npx playwright test tests/e2e/day-061.spec.mjs
```

`release` は型検査、Viteビルド、OSS通知と配布物の照合を行う。
通知の許可リストにない依存、未知の素材、通知とビルドの不一致は検査を止める。
既存の第三者カタログや素材を追加するときは、公開前に利用条件を確認する。
