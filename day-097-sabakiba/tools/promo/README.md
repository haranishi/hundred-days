# Day097 宣伝動画の作り方

縦1080×1920・30秒・30fps。実アプリを動かして、1コマずつ撮る（作り物の画面は足さない）。
絵コンテの正本は `timeline.mjs`。映像（`render-promo.mjs`）と音（`promo-audio.mjs`）は、どちらもこの表を読む。
設計と狙いは `.kiro/specs/day-097-sabakiba/promo.md`。Day096（`day-096-ux-recipe/tools/promo/`）と同じ型。

## 作り方（4工程）
```sh
OUT=<作業フォルダ>                                  # リポジトリの外に置く。mp4/wav/pngはコミットしない
node day-097-sabakiba/tools/promo/render-promo.mjs --out-dir "$OUT/render" --no-encode        # 1. 撮影（約7分）→ frames/ ・ cues.json ・ capture-report.json
node day-097-sabakiba/tools/promo/promo-audio.mjs --variant a --out-dir "$OUT/audio" --cues "$OUT/render/cues.json"   # 2. 音（b も）
node day-097-sabakiba/tools/promo/verify-audio.mjs --out-dir "$OUT/audio" --cues "$OUT/render/cues.json"             # 3. 数値検査
node day-097-sabakiba/tools/promo/render-promo.mjs --out-dir "$OUT/render" --encode-only --audio-dir "$OUT/audio" --mux a,b   # 4. 書き出し（silent・a・b の mp4、first-frame.png、contact-sheet.jpg）
```
部分撮影：`--frames 0-200`（途中のコマだけ `preview-0-200/` へ。ただし時計は最初から回すので、読み込みと先送りの時間はかかる）。

## なぜこの作りか（コードに残らない理由）
- **時計を止めて1コマずつ**：`context.clock` で時計を止め、1/30秒ずつ進める。実時間の揺れが、練習の点数や動きに入らない。
- **描画は1コマにつき1回、見えている画面だけ**：3Dの描画（ソフトウェアGL）は1回約0.1〜0.15秒。時計の `requestAnimationFrame` に任せると、見えていない画面も毎刻み描いて、撮影が終わらない（11画面で1コマ約3秒、読み込み中は描画の待ち行列が詰まって最初の1枚が撮れなかった）。`requestAnimationFrame` を差し替え（`window.__flush` / `__hold`）、撮影側が見えている画面にだけ1回流す。読み込みも1画面ずつ。
- **画面は12枚を先に開いておく**：本体・透視・次へ・練習・魚8種の静止画。切り替えは「見せる画面を入れ替える」だけ。画面ごとに別ポートで配信し、保存領域が混ざらない。
- **魚を大きく**：アプリの3D領域は縦に短く、台所の視点では魚が幅の55%ほど。本体と魚8種の画面は、撮影前に3D表示へマウスホイール（`zoom`）を回して、幅の75〜85%にしてある（ユーザーと同じ入力。字幕や数字は変えない）。
- **指の入力の時刻も止めた時計**：`Event.prototype.timeStamp` を `performance.now()` に合わせる。練習の採点が撮影の速さで変わらない。
- **本番のアドレスは映さない**：アプリは本番と同じセキュリティ見出しで配信し、埋め込みに必要な `frame-ancestors` / `X-Frame-Options` だけ外す。

## 映像のために足した見た目の調整（アプリ本体は変えていない）
切り替えの途中のコマを作らない（CSSの遷移を止める）／タップの強調（端末が出す水色の四角）を消す／手順の説明欄の下端を30px、ぼかす（文が途中で切れて見えないように。練習の結果カードは切らない）。

## 字幕と画面の照合（字幕は画面に出ていることだけ）
| 秒 | 字幕 | 画面に出ていること |
|---|---|---|
| 0–2 | 丸ごとの魚、どこに包丁を入れる？ | アジの手順4。魚と赤い点線とこの手順の青い手の印。包丁が降りてくる |
| 2–4 | 刃の通り道が、赤い線で見える。 | 包丁が赤い線のところを通る |
| 4–6 | 台所と同じ向きから、回して確かめる。 | 視点の札を押す→台所の視点から真横・真上へ回る |
| 6–8 | 身を透かして、骨の位置まで見る。 | 手順2（真上の視点）に切り替え。「透視」を押すと皮が透けて骨と内臓が見える |
| 8–10 | もう一方の手の位置も、示す。 | 青い手の印と札（枠で囲む。印が動くと枠もついていく） |
| 10–12 | 左利きは、左右を反転。 | 「左利き」を押す→画面も札の文（左手→右手）も反転 |
| 12–18 | 魚は8種、さばき方は5つ。 | 8種を0.75秒ずつ。魚名・さばき方（帯の2行目）と点。さばき方はアプリの用語集の分類 |
| 18–22 | 手順は、「次へ」を押すだけ。 | 手順7から「次へ」を3回。手順の名前・番号・3Dが変わる |
| 22–26 | なぞって、練習もできる。 | 「練習」→始点から線をなぞる→アプリが出した一致度・ランクを大きな札で映す（アプリの結果カードの値そのまま） |
| 26–30 | （エンドカード） | 魚をさばきたい人へ／迷うなら、3Dで見てから。／さばき場／できること／登録なし・無料・ブラウザだけ／住所 |

数字は、アプリが出した値だけ（8種・5つ・一致度）。「上達する」「失敗しない」「プロ並み」は書かない。

## 権利
- 絵はすべて、このアプリが描いた3D（計算で描いた模式図）と、アプリの画面。外部の画像・動画・フォントは使わない。
- 音は、Node の計算だけで合成（発振器・ノイズ）。サンプル・既存曲の旋律は使わない。
- `tools/` は本番へ配信しない（ビルドが落とす）。
