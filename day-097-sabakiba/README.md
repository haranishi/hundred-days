# Day097 さばき場

魚のさばき方を、台所の手元と同じ向きの3Dで見ながら学べる。アジ・イワシ・サバ・サンマ・タイ・ヒラメ・キス・カツオの8種を、三枚おろし・手開き・背開き・五枚おろし・節取りの5つの方法で。刃を入れる線と向き、もう一方の手の位置、骨の中までを、手順ごとに回して・透かして確かめられる。画面の上で線をなぞる練習もできる。
登録もインストールも要らない。ブラウザで開くだけ。保存するのは、続きの手順・練習のベスト・設定だけで、このブラウザの中に残る。通信はしない。

## 使い方
1. 入口で魚を選ぶ（方法と「初心者向け」で絞れる）。前置きで、道具・所要時間の目安・安全のひとことを見て、「さばき始める」。
2. 手順ごとに、3Dの動き（包丁・切る線・外れる部品）と文章（魚の置き方・どうする・コツ・やりがち・できた目印）が出る。「次へ」「前へ」・再生・速さ（0.5×／1×）・動きの途中のスライダー・一覧から好きな手順へ。
3. 札で、視点（台所・真横・真上）・透視（皮を薄くして骨と内臓を見る）・部位の名前・**左利き**（画面も文章も左右を入れ替える）を切り替える。キー：←→ 手順・Space 再生・X 透視・1/2/3 視点・L 左利き。
4. 「なぞって練習」で、切る線を指かマウスで一筆でなぞる。「ガイドとの一致度」と「なめらかさ」を出す。**実際の歩留まりの採点ではない**。端末の中にベストを残す。
5. 台所向け：画面を消さない・手順の読み上げ（日本語・任意）。3Dが使えない端末では、文章だけの手順で最後まで読める。
6. 「さばく前に」（安全）と「部位の名前」は、入口から開ける。

## 内容の根拠と、言い切らないこと
- 手順は、複数の日本語の公開資料（農林水産省・水産庁・自治体・水産団体・料理の資料）を突き合わせた調査をもとに、自分の言葉で書き直した。**標準的な一例**で、地域や流派で順序は変わる。刃の角度の度数は資料に無いので、向きと寝かせ具合で書いている。所要時間の初心者／慣れた人の差は推測。
- 「さばく前に」の数字（アニサキス・クドア・ヒスタミンなど）は、厚生労働省・農林水産省・消費者庁・食品安全委員会・自治体の一次情報だけから。項目ごとに出典へのリンクと確度（確認済み／一部確認）を出している。「安全です」「必ず防げる」とは書かない。
- **フグなど毒のある魚の処理は載せない**（資格が要る）。釣ったフグはさばかず、持ち帰らない。
- 魚・包丁・まな板の3Dは、**コードで形を計算して描いた模式図**で、実物の写真や測定ではない。魚の寸法・色は、図鑑・FishBase・機関の資料の要約（多くが推定）を目安にした。
- 3Dで操作して学べる無料のWebアプリを、調べた範囲では見つけられなかった。ただし、ほかに無いとは言えない。

## 仕組み
- 魚は部品（頭・中骨・左右の身（背側・腹側）・腹骨の層・皮・小骨・内臓・背わた）に分かれ、**断面の連なり**から作る。どの魚も同じ部品で、方法ごとに動かし方だけが違う（手開き・背開きは左右を蝶番で本のように開く）。
- 手順は純データ（`lib/procedures/`）。時間は `stateAt(手順, 進み具合)` の純関数で、飛ばしても戻しても同じ状態になる。撮影・試験も同じ関数を使う。
- 魚の形・手順・画面の文章は、すべて契約（`lib/contract.js`）の検証を通す（部品・線・道具・字数・禁止語・HTMLを含まないこと）。
- 皮はシェーダーで描く（うろこ・濡れた艶・切り込み・透視）。画質は3段（高・標準・軽め）で、端末に合わせて自動で選び、遅ければ下げる。
- 外部の通信・画像・書体・3Dモデルは使っていない。three.js（MIT）だけを同梱している。

## 既知の限界
- 実機のスマホ（指の感触・画面の消灯・読み上げ・発熱）は、本人の実機確認が済んでいない。実ブラウザ（Chromium・WebKit）での指のイベントまでを確かめた。
- ヒラメのエンガワ・カツオの血合い取りは、線とラベルで示すだけで、部品としては分けていない。尾びれ・背ビレは中骨と一体。
- 魚の細部（ヒレのすじ・鰓蓋の盛り上がり・うろこの並び）は簡略化している。
- 左利きでも、画面のボタンの配置は変わらない（3Dと文章の左右だけを入れ替える）。

## まだないこと
魚の追加（ブリ・サケ・イカなど）・刺身の切り分け・小骨抜きの個別の操作・アカウント・クラウド保存・オフライン対応・音声での操作。
