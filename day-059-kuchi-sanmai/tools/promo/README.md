# 「口さんまい」プロモーション動画

縦型1080×1920・34秒・BGM付き。絵コンテは `timeline.mjs`、音は `promo-audio.mjs`、画は `render-promo.mjs` の3本で完結する。

```sh
PLAYWRIGHT=/path/to/playwright/index.js node day-059-kuchi-sanmai/tools/promo/render-promo.mjs
```

出力は `promo.mp4` と `promo-first-frame.png`（どちらも gitignore 済み）。`promo-audio.wav` が無ければ `--variant a` で自動生成する。

## このDayで気をつけること

- **見本は自作のロボットとテスト音だけを使う。** 有名キャラや人の声で試した画は、宣伝に使わない（権利の調べの2・3）
- **外への通信は断つ。** このアプリはもともと外と通信しないので、ログが「断った宛先: なし」になる
- **再生は「▶ 再生してみる」を画面を動かさずに押す。** 録画用のブラウザだけ自動再生の制限を外している。スクロールの位置は pan だけで決める
- **テスト音は録画に入らない。** 動画の音はBGMだけ

## 字幕は画面と突き合わせてある

`render-promo.mjs` が、書き出す前に画面の状態を確かめ、違っていたら止まる。

| 場面 | 字幕 | 照合する画面の状態 |
|---|---|---|
| S1 | 声の大きさで、口が開く | 口の状態の欄に「大」が出た |
| S2 | 閉じ・小・大の3枚を入れるだけ | 口の3つの枠が読み込み済み |
| S3 | 背景はグリーンも透明も選べる | 背景のグリーンが選ばれている |
| S4 | 縦・横・正方形で書き出せる | 正方形が選ばれている |
| S5 | 録画して、そのまま保存 | 録画した動画のプレビューが出た |
| S6 | 人の声や絵は、許可の範囲で | 音声の欄の注意書きに「許可なく使わないでください」がある |

口の状態の欄の文字は「口の状態大」のように見出しと値が続くので、値の末尾で比べる。

## BGM

Day 039〜042 と同じ生成器（F メジャー・92BPM）を中身を変えずに複製した。録音やサンプルは使わず、コードで合成した音だけでできている。字幕の書体は Zen Kaku Gothic New（SIL OFL 1.1）で、書体のファイルはリポジトリに入れない。
