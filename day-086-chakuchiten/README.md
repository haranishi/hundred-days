# Day086 ふたりの着地点

「なんでもいい」で行き先が決まらないとき、同行者と3問に答え、近くの候補を1軒ずつ見るアプリ。
ごはん・お茶・一杯・外でリフレッシュから気分を選び、徒歩約3分または10分の範囲で探す。

- 現在地の利用は操作後に確認する。許可しない場合も、駅名や場所から検索できる。
- 候補は最大3軒。Google マップで選んだ施設への徒歩案内を開く。
- 座標・回答・施設結果はアプリに保存しない。共有するのはアプリのURLだけ。

## データと目安の限界

[OpenPOI API](https://openpoiapi.com/attribution.html)を利用。
検索時は座標、場所指定時は入力した語を同APIへ送る。キーや登録は不要。
施設の写真・星評価・空席・店内の静かさ・営業中かどうかは取得しない。
空間の回答は施設種別の優先に使う。実際の雰囲気や営業状況は地図で確認する。
徒歩時間は直線距離×1.3を毎分80mで換算した目安。実際の経路・坂・信号を反映しない。
閉業した施設・位置のずれ・未収録の施設がある。イラストは施設写真・実際の地図ではない。

描画素材は独自SVGとシステム書体。APIデータの出典と通知は[NOTICE.txt](NOTICE.txt)を参照。
