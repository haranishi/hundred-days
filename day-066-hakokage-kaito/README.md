# Day66 箱影の怪盗

押せる箱で、見張りと警備員の光、レーザーをさえぎり、影を通って宝を盗み、出口へ逃げる1手ずつのパズル。全8面。登録なし。ブラウザに配信する部分は、依存ライブラリなしの素の JS・CSS・SVG。プレイ中にゲームの記録を自動で送ることはなく、通信は、ページの読み込みと、共有を押したときの共有リンク（X・LINE・端末の共有シート）だけ。端末に保存するのは、面ごとの星と最少手数、音の入り切り、文字キーの入り切りだけ。

## ねらい

頼れる道具を「押せる箱」だけにした。1つの箱が、光をさえぎる、巡回の警備員を引き返させる、押し間違えると逃げ道をふさぐ、の三役を持つ。難しさは頭の中の先読みから来るようにして、「見えていなかった光に当たった」という理不尽さは、仕組みで消した。

## 設計で決めたこと

- **見えている光＝判定。** 動いた直後と、警備員が動いた後の2回判定する。次の1歩で光るマスは、点線の枠で常に出す。点線は、箱を動かさずに待った場合の次の光。箱を押す手では遮光や巡回が変わるので、予告と結果が違うことがある（箱をどかすと光が戻る。箱を警備員の道へ落とすと、警備員が引き返す）。これは仕様。
- **巡回は一直線の道を往復し、端と箱の前では1歩使って向きを変える。** 止まって引き返す瞬間が目に見える。L字の道は、角でどちらを向くかが読めないので捨てた。
- **出口は宝を取るまで閉じた扉。** 宝なしで出口に乗る迷いをなくした。
- **詰みは、箱を押した直後だけ調べる。** 上限は1万状態で、全面の詰み状態の最大（9164）より多いので、取りこぼさない。
- **星は最少手数（par）以内で★3、par の1.5倍を切り上げた手数以内で★2。** お手本（同じ面で2回失敗すると最短解を再生）を見ても、星は減らさない。
- **「最初へ」は確認の窓を出さない。** ひとつ戻すで取り消せる。親指の誤タップのほうが、確認の1手より害が大きい。
- **盤のタップ・スワイプは入れない。** 縦スクロールとぶつかり、光の中へ踏み込む事故が起きる。
- **Space は「待つ」。ボタンに焦点があっても待つ。例外は、Tab で焦点を当てたボタンだけ（そのボタンを押す）。** マウスで押して焦点が残ったボタンと、アプリが動かした焦点（見つかった欄から「戻す」へ）では待つ。体験評価で、PC の「右へ」の後の Space がもう一度「右へ」になり、時期合わせの面で事故になった。
- **ヒントは「ルールは言うが、答えは言わない」。** 置く場所・待つこと・押す先は書かず、問いか、考える向きで終える。面4は「待つのも1手」と待つ方へ誘導し、実際に要る箱の使い方を隠していた。あそびかたには、順番の決まり（いま光っているマスへ入ると、光が動く前にその場で見つかる）と、自分の駒がどれかを書いた。
- **ヒントと一言は、盤の外の同じ行に出す。** tall・short・wide はヒントの行（常に出ているヒントを、一言の間だけ差し替える）、compact・tiny は状態の行と同じ場所に重ねる。行の高さはヒントの2〜3行で決まり、開閉や一言で変わらないので、盤も操作も動かない。手を動かす・やり直す・面を変える・Esc で閉じる。面1の初回（星がまだ1つも無い）だけ開いて始める。
- **全面クリアは、見出しを「全8面クリア！」にして「脱出成功！」と重ねず、星と手数を1行にし、星の合計を出す。** 320×568で主ボタンが最初の画面に収まる。
- **押せない見た目は `aria-disabled` に統一（Tab が止まる）し、色で表す。** 不透明度は焦点の輪まで薄くした（輪が基準の3を割った）。自分の駒には淡い輪、宝を持つと金の印を付ける。
- **お手本は1手700ms。「お手本」の札は盤の上に重ねず、状態の行に出す。** 400msでは追えず、面5で左上の札が出口を隠した。終わりの文は、読み上げに加えて見える一言としても数秒出す。
- **結果の欄（見つかった・詰み・成功）は操作の場所に差し替える。** 窓にすると盤が隠れる。共通の共有欄（アプリの紹介を送る）は、帯のボタンから開く窓の中だけに置き、結果の共有（Xで投稿・LINEで送る・リンクをコピー）は成功の欄の中に置く。

## 画面で決めたこと

- **ルールは `lib/sim.js` だけが決める。** 設計側の参照実装の写しで、4行目以降は一字一句同じ（単体テストが突き合わせる）。画面は光・影・判定・予告を計算し直さず、結果を描くだけ。
- **1手は、判定を同期で確定してから、見た目を150msで動かす。** 光・影・予告は動かさず、動きの終わりに一度で描き直す。途中の光が判定と食い違って見えるため。動きの終わりはタイマーで待つ（裏のタブでは rAF が止まる）。動きの途中で次の入力が来たら、今の動きを終わりの位置へ飛ばしてから進める。
- **画面の型5つ（tall・compact・tiny・short・wide）は `lib/layout.js` の1関数で決め、CSS は `html[data-layout]` を見る。** 境目を JS と CSS で二重に持たない。盤のマスは、帯・題字・面の帯・状態・操作の実測の高さから決める（文字だけ拡大しても、盤が操作の下にもぐらない）。
- **「盤を文で読む」は、画面の外に置き、キーボードで届いたときだけ見せる。** 場所を取らないので、盤と操作が最初の画面に収まる。
- **三角・星・矢印は、文字でなく SVG で描いた。** iPhone で一部の記号が絵文字に化けるのと、端末ごとの字形の差を避ける。星の絵には「星3つ中2つ」の名前を付ける。結果の共有文の星だけは、投稿の文なので文字のまま。
- **影のくさびは、箱の向こう側の最初のマスの両脇に出る、薄い三角にした。** 設計の「箱に接する辺に、影の向きへ伸びるくさび」の読み方が一通りに決まらなかったため。判定は光だけで行い、影の絵は判定に使わない。
- **tiny（高さ620px未満）では、題字を帯の左に出し、ホームのリンクは「066」だけにした。** 帯に、ホーム・題字・絵のボタン3つが入りきらず題字を隠したら、320×568の最初の画面で何のゲームか分からなかった（見た目の評価）。「100 DAYS /」は読み上げにだけ残す。
- **操作が画面の半分を超えるほど小さい画面（拡大の倍率が大きいとき）は、固定をやめる。** 固定すると盤が隠れる。
- **色・寸法・字・不透明度・動きは、`app.css` の `:root` のトークンだけに置く。** 単体テストが、`:root` の外の直書きを0件に保つ。

## 捨てた案

- ヒントを面の帯の下に押し広げる案：開くたびに盤が動く。盤に重ねる案（以前の compact・tiny）：駒と出口を隠した。いまは、状態の行と同じ場所に差し替える。
- 状態の行の「お手本」を、常に44pxの高さで確保する案：狭い画面で盤が小さくなる。ボタンが出るときだけ、盤の大きさを測り直す。
- 光をなめらかに動かす案：途中の光が判定と食い違って見える。

## 罠

- **CSS の `scale` や `transform` を、位置を持つ要素に掛けると、位置ごと飛ぶ。** 宝のきらめきは、位置を持つ外側でなく、内側の組に掛ける。
- **動かす直前に、いまの見た目を確定させる。** 確定前に transform を変えると、動かずに飛ぶ。連打で盤を描き直した直後の手がこれに当たる。
- **`left: 50%` と `translateX(-50%)` で中央に置いた吹き出しは、使える幅が半分になる。** 「進めな／い」と割れた。`width: max-content` にした。
- **共通の共有欄は最低幅と上の区切りを持つ。** 窓の中では打ち消さないと、右へはみ出して余白が出る。共通の共有欄は帯のボタンから開く窓の中だけに置く（結果の欄に置くと、共通の試験が落ちる）。結果の欄には、共通の共有欄でなく、結果専用のボタンを置いた。
- **本文は `word-break: keep-all` で、`auto-phrase` は使わない。** そのままだと「見つか／る」と語の途中で割れるので、ひらがなの並びが終わる所に折り返し候補を入れる。
- **窓を閉じたあとの焦点戻しを、閉じたあとの非同期のイベントでやらない。** そのあいだに別の場所へ移した焦点を奪い返す（試験を繰り返して見つかった）。標準の動作（同期）に任せ、自前の閉じる経路は閉じた直後に戻す。
- **`:focus-visible` で、マウスで押したボタンと Tab で当てたボタンは見分けられない。** Chromium は、最初のキー入力の keydown の中で、マウスで押したボタンにも `:focus-visible` を真にする（実測。Firefox は偽）。Tab の keydown の直後の focusin だけを覚える。
- **Space は keydown だけでなく keyup の既定の動作も止める。** Firefox は keyup でボタンを押す。押している間に結果の欄が出て焦点が移ると、離した Space が「ひとつ戻す」を押す。
- **共通の部品が出す長い文（`.share__note`）は、`word-break: keep-all` で折り返せず、窓の右で切れる。** `shared/` は直さず、折り返しを許す一覧に足す。
- **close イベントの時点では、閉じた窓の中のボタンが activeElement のまま残る（Chromium）。** 焦点が窓の中か body なら焦点が無いものとして、開いたボタンへ戻す（Safari はクリックでボタンに焦点を当てず、Esc で戻らない）。別の場所に焦点があれば奪わない。
- **wide（幅700以上）では、8列の盤（512px）が右の列を押しつぶす。** 幅700〜800で操作がはみ出し、面の帯の「次の面」が左下に落ちた。盤の列を縮められるようにし、右の列は操作の幅より狭くしない。右の列が狭いときは、面の帯を「名前／前・次」の2行にする（コンテナクエリ。しきい値は var() が使えず数で書いた）。
- **折り返しは、候補の入れ方（`lib/wrap.js`）が先で、`text-wrap: pretty`・`balance` が次。** 助詞で終わるひらがなの後ろ・読点・句点・開き括弧の手前だけで折り、保護語（引き返す・通り道・ひとつ戻す・座標…）は割らない。以前の「ひらがなが終わる所すべて」は「引き｜返す」「通り｜道」と割った。`text-wrap` を足すと、最後の行が4文字以下の段落が、390・320 で4件・6件から0件になった。
- **共通の部品（`shared/`）の説明文は、区切りが無いので、`overflow-wrap: anywhere` の非常用の折り返しだけになり、「直／接」「リ／ンク」と語の途中で割れた**（禁則を守らず「。」だけの行もできる）。部品は直さず、`app.js` が窓の中に部品が据え付いたあと（と合図の文が入れ替わるたび）に、同じ文字のまま `lib/wrap.js` の区切りを入れ直す（MutationObserver）。`anywhere` は最後の保険に残す。
- **Chromium は 1.5px の縁を 1px に丸める（画面の密度2・3でも）。** 縁の太さでは強弱を付けられず、「最初へ」は地を透明にして弱くした。
- **行の高さを増やす物は、行に重ねる。** 44px の閉じるボタンは absolute で右端に、一言も absolute・`inset: 0` で行いっぱいに。流れに入れると、開閉のたびに操作が動く。
- **保存の名前の定数は、末尾を KEY にしない。** gitleaks が誤検知する。
- **押すタイミングが関わる試験は、等速の「3回合格」を安定の証拠にしない。** 押す間隔を0〜200msで振り、ページの CPU を遅くした実行でも通す。
