# Day066「箱影の怪盗」プロモ動画の道具

縦1080×1920・30fps・32秒・BGM付きの動画（Xの投稿用）を、**実際のゲーム画面の録画**から作る。
画は、アプリを開いてキーで遊んだ画面そのまま。足すのは字幕・押した十字ボタンの輪・終了カードだけ。
音は外部の音源を使わず、コードだけで合成する（A案・B案の2種類）。

## 再生成

```sh
node day-066-hakokage-kaito/tools/promo/render-promo.mjs
```

約1〜2分（機械が忙しいと撮り直しで延びる）。必要なもの：リポジトリの Playwright、ffmpeg / ffprobe、Zen Kaku Gothic New Bold（既定は `~/Library/Fonts/ZenKakuGothicNew-Bold.ttf`。別の場所なら `PROMO_FONT`）、アプリの配信（既定は `http://127.0.0.1:4671/day-066-hakokage-kaito/`。`--base=<URL>` で変える）。

| 指定 | 内容 |
|---|---|
| `--variant=a\|b\|both` | 音の案（既定は両方） |
| `--reuse-video` | 録画をやり直さず、音だけ付け直す |
| `--hide-share` | 成功の欄の「Xで送る・LINEで送る」ボタンを、録画で見えなくする |
| `--video-only` / `--keep-work` | 音なしで書き出す／撮ったコマ（`output/_work`）を残す |

出力は `output/`（Git管理外）。`Day066_hakokage_kaito_promo.mp4`（A案）・`…_promo_b.mp4`（B案）・`bgm_a|b.wav|mp3`（効果音込み）・`spectrogram_a|b.png`・`frames/`（確認用のコマ）・`capture-checks.json`（検査の数値）。

## ファイル

| ファイル | 役目 |
|---|---|
| `timeline.mjs` | 絵コンテ。操作の時刻・字幕・音の合図。画も音もここを読む。効果音の合図は、操作の列をアプリのルール本体（`lib/sim.js`）で再生して作る |
| `render-promo.mjs` | 録画 → 30fps のコマ列 → H.264 → 音を付ける → 検査 |
| `overlay.mjs` | 録画のときだけ重ねる字幕・指の輪・終了カード |
| `promo-audio.mjs` | BGM と効果音の合成（純JS）。ラウドネス合わせ |
| `audit.mjs` | 書き出した動画の検査（ffmpeg だけ） |

## 絵コンテ

| 秒 | 実画面 | 字幕 |
|---|---|---|
| 0–4 | 面1。光の中へ踏み込み、見つかる → 「ひとつ戻す」→ 箱の上へ歩く | 見張りの光に、見つかった… |
| 4–6 | 箱を押す（4秒＝拍の頭）。影ができる | 箱を押すと、光が止まる |
| 6–10 | 影の中へ入り、宝 → 出口が開く → 成功（12手・星2つ） | 影を通って、宝を盗め |
| 10–16 | 面5。早送りで箱を運び、14秒に警備員が箱の前で引き返す。宝 | 警備員は、箱の前で引き返す |
| 16–24.5 | 面8。見本の解 29手を早送り（最少手数・星3つ） | 光とレーザーを、先読みで抜ける |
| 24.5–28 | 「面をえらぶ」で一覧（全8面） | 全8面。どこまで抜けられる？ |
| 28–32 | 終了カード。箱が光の中へ入り、後ろに影ができ、宝が光る | 箱影の怪盗／全8面・登録なし／URL／100日チャレンジ Day 66 |

1コマ目は、光の中へ踏み込む途中の絵（0.17秒後に赤く光る）。0秒と0.3秒のコマは別の絵で、`audit.mjs` が差を測る。

## 撮り方（決めたことと理由）

- **`Page.captureScreenshot` を連続で呼ぶ**（約25ms間隔・PNG）。`recordVideo` は 540×960・VP8 約1Mbps で字が荒れるので使わない。倍率は撮影用の CDP セッションで `Emulation.setDeviceMetricsOverride` して 2 に固定する（Playwright の context の倍率は別セッションの撮影に効かず、540×960 で返る）。1080×1920 のネイティブなので、字はにじまない。
- **コマの時刻から 30fps を作り直す**。各コマに撮った時刻を持たせ、動画の各時刻に直前のコマを当てる。
- **準備運動**：最初の1手だけ動き出しが約140ms止まる。本番の前に1手押して戻す。
- **箱を押す手は遅れる**：アプリは押すたびに詰みを探す（面8で約40〜100ms）。そのぶん画が遅れるので、**効果音は押した時刻でなく、書き出した動画から測った時刻に置く**（動き出し・結果の欄が出たコマ。`output/onsets.json`）。押す手以外の止まりと、撮影間隔の中央値が40msを超えたときは、撮り直す（最大3回）。
- **画面の値で照合**：キーを押すたび、`<main id="app">` の歩数・状態・宝が、ルール本体で再生した値と同じか見る。ずれたら止まる。
- 字幕は面の帯と盤のあいだ（ヒントの行を隠して）に置く。盤が高い面8でも、盤や十字ボタンに重ならない。字幕は画の動きより0.2秒先に入れ替える。
- 足のリンクとフォーカスの輪は隠す（タッチ操作に見せる）。重ね物は popover（最前面）なので、面の一覧の窓が開いても暗くならない。

## 音（効果音込み）

120BPM・1小節2秒。和音は Am｜G｜F｜E7 の下りを土台に、場面の頭（4・10・16・24・28秒）で主和音へ着地する。

- 0–4秒 フック：ドラム無し。持続音と時計の刻み。ライザーとスネアの連打で4秒へ引っ張る
- 4–10秒：キック・ハット・パルスのベース・鍵盤。4秒の頭で一発
- 10–24秒：主旋律が入る（14秒に和音の一撃）。16秒からは16分のハット・クラップ・副旋律
- 24–28秒 約束：ドラムを抜いて薄く。28秒の終止（E7→Am）へ
- 28–32秒：終止和音を鳴らし切り、フェード

A案はイ短調・FMエレピ・パルスのベース・リム/クラップ。B案はホ短調・マリンバ・ピチカート・ブラシ・ホイッスル風の主旋律。
効果音は、足音・箱を押す・影ができる・見つかる（警報）・宝（チャイム）・出口が開く・警備員が引き返す・成功（ファンファーレ）・ひとつ戻す・面の一覧・場面の切れ目・終了。
音量は BS.1770 の K 特性（`promo-audio.mjs` 内に実装）で測って -17 LUFS に合わせ、リミッタで -2.0 dBTP 以下に収める。BGM は固定シードで毎回同じ。

実測（2026-10-13・書き出した mp4 の音を ffmpeg で測定）

| 案 | 統合 | トゥルーピーク | クリップ | 120Hz未満 | 8kHz超 | フック−本編 |
|---|---|---|---|---|---|---|
| A | -17.1 LUFS | -2.3 dBTP | 0 | -6.9 dB | -24.5 dB | -1.3 dB |
| B | -17.0 LUFS | -2.5 dBTP | 0 | -7.2 dB | -24.6 dB | -1.9 dB |

帯域の値は全体の RMS との差。

## 守っていること

- 絵文字なし。実在の商標・他作品の名前なし。言い切れない主張なし。`checkTexts()` が、絵文字と許可リスト外の欧文を止める。
- 外部の音源・サンプル・取得した画像は使わない（映像はこのアプリの実画面、音はコードで合成）。字幕と終了カードの書体は、第三者の書体 Zen Kaku Gothic New（SIL OFL 1.1）を端末から読み込み、字を映像に焼き込む。書体ファイルはリポジトリに入れない。終了カードの絵は自前の図形。
- アプリのファイルは書き換えない。ページへ足すのは、字幕・輪・終了カードと、足のリンク・ヒントの行の非表示だけ。
- 成功の欄に、アプリ自身の「Xで送る」「LINEで送る」ボタンが約1.3秒×2回映る。字幕・終了カードには書いていない。映したくなければ `--hide-share`。
- パス・実名は書かない。

## 罠

- `lib/*.js` は package.json に type が無く、import すると Node が警告する。`timeline.mjs` は本文を data URL で読む。
- 時刻表は動画の頭からの秒。`render-promo.mjs` が場面の頭からの秒に直す（直し忘れると2場面目以降が空振りする）。
- キー入力の確認は、次の手の前に行う。歩数・状態はキーを押した瞬間に入り、結果の欄は約0.19秒後に出る。
