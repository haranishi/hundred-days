# Day 036「一画ずつ」要件定義

打った言葉が、筆順どおりに一画ずつ書かれていく。筆の入りと抜きで線の太さが変わり、書き終わったものは動画とPNGで保存できる。

## 背景と狙い

漢字の書き順を調べると、出てくるのは番号を振った静止画か、1字だけの動画だ。**名前のような2〜4字を続けて最後まで見る**手段がない。いちばん確かめたい対象の前に、字ごとにページを開き直す手間が立っている。

Day31〜40は外部API1個が解禁された区間だが、難易度設計のルールは「1日に伸ばす軸は1〜2個」で高難度を強制しない。Day032〜035が4日続けて外部APIだったので、今日は **UIの状態（アニメーションと演出）** に振り、外部依存はゼロにする。

- 改変点：1画ごとの種別（`kvg:type`）とパス（`d`）だけを取り出し、座標を小数1桁へ丸め、符号位置の上位バイトごとのJSONへ分割した。部首の入れ子・異体字（`-Kaisho` 等）・要素名は落とした
- 入力した言葉はどこにも送らない。通信は同梱データの取得だけ

## データ（同梱）

`tools/build-data.mjs` が KanjiVG の配布XMLから生成する。

- `data/kvg/<上位バイト>.json` … `{ "<符号位置16進>": [["<画の種別>", "<パス>"], ...] }`。配列の順がそのまま筆順
- 6,702字 / 79,907画 / 94ファイル / 計5.19MB（最大96KB）。1字の取得は1ファイルで済む
- シャード名は `codePoint >> 8` を16進2桁にしたもの。画面側も同じ式で求めるので索引ファイルはいらない
- 座標は小数1桁。相対座標（`c`）なので丸めの端数を次の座標へ繰り越し、生成時に元のパスと曲線を突き合わせて**ずれが 0.25 単位（109四方の0.23%）以内**であることを検査する。実測の最大は 0.188

## ユーザーストーリー

1. 名前の書き順に自信がない人として、名前を打って押すだけで1画目から順に書かれるところを見たい
2. 子どもに教える親として、速度を落として見せたい
3. 教わる側として、いま何画目か・全部で何画かを数字で知りたい
4. 順番を覚えたい人として、これから書く画が薄く見えていてほしい
5. 覚えたい人として、同じ言葉を何度でも書き直させたい
6. 見せたい人として、書いているところを動画で保存したい
7. 名前に難しい字が入っている人として、データが無いときは無いと言ってほしい
8. 繰り返し使う人として、前に書いた言葉をすぐ呼び戻したい

## UX5階層を通したことで決まった実装（10件）

| # | 決めたこと | どの層から |
|---|---|---|
| 1 | 読み・意味・部首を載せない | 戦略（主役は動きであって情報ではない） |
| 2 | 1字ずつでなく、言葉として続けて書く | 戦略（名前は2〜4字。開き直させない） |
| 3 | 保存は「書き終わり」でだけ出す | 構造（Day035で空から白紙PNGが落ちた再発防止） |
| 4 | 速度はスライダーでなく3段ボタン | 骨格（スマホでつまみを掴ませない） |
| 5 | 5字以上は2行に折る（縮めない） | 骨格（縮めると画の順番が見えない） |
| 6 | 音は既定オフ（デモ収録だけ音オン） | 表層（開いた瞬間に音を出さない） |
| 7 | データが無い字があっても、ほかの字は書く | 要件（全体を失敗にしない） |
| 8 | 上限8字 | 骨格（4字で1行、8字で2行に収まる） |
| 9 | 動画保存が使えない端末ではボタンを出さない | 非機能（押せるのに落ちる状態を作らない） |
| 10 | これから書く画の下書きを既定オン | 要件ストーリー4 |

## 機能要件

### 画面と状態

1画面・縦1列。入力 → 書き取り面 → 進捗 → 操作 → 保存 → 設定 → 最近の言葉 → 出典。

| 状態 | 画面 |
|---|---|
| `empty` | 空のマスだけ。進捗・保存は出さない |
| `loading` | 「筆順を読み込んでいます」 |
| `writing` | 面が動く。進捗が進む。保存は出さない |
| `done` | 全画が残る。保存が出る |
| `partial` | データが無い字のマスに印。ほかの字は書く |
| `error` | 「筆順データを読み込めませんでした」＋再試行 |

`[hidden]` は `!important` 付きで潰す。クラス側の `display` に負けて、空の状態で保存ボタンが押せた前例（Day035）があるため。

### 書き取り面（Canvas）

- 1マス = KanjiVG の 109 四方。薄い枠と十字の補助線
- 1〜4字は1行、5〜8字は2行。マスの大きさは行数と幅から決める
- 書き順は「1字目の全画 → 2字目の全画」の順
- これから書く画は薄いグレー（切り替え可）。書き始めに朱色の番号（切り替え可）

### 筆（`lib/brush.js`・純関数・DOMに触れない）

- 1画は、進み具合 `t` に応じて線の太さを変えながら描く
- 入りは細く、送りで太く、終わりは**画の種別**で変える
  - はらい（`㇒` `㇏` など）＝細く抜く
  - とめ（`㇐` `㇑` など）＝太いまま止める
  - はね（種別に `㇟` `㇆` `亅` などのかぎを含む）＝終端で細く跳ねる
- 種別が空のときは「とめ」として扱う

### 速度と進捗

- ゆっくり／ふつう／はやい の3段。1画あたりの基準時間を変える（書いている最中の変更も効く）
- 画と画の間に短い間を置く。字の変わり目はもう少し長く
- 進捗は「N画目 / 全M画」とバー

### 保存

- 動画：Canvas を `captureStream` で録り、`MediaRecorder` で書き出す。対応する形式を検出し、どれも使えない端末ではボタンを出さない
- PNG：書き終わった面をそのまま書き出す

### その他

- 入力は最大8字。それを超えたぶんは切り、切ったことを伝える
- 異体字選択符号・結合文字・空白は落とす。サロゲートペアは符号位置で数える
- 最近書いた言葉を5件まで `localStorage` に保存（`day-036-stroke-by-stroke` 名前空間）。押すとすぐ書き直す
- 音は Web Audio で合成（ノイズ＋バンドパス）。既定オフ

## 非機能・共通ルール

- 依存ライブラリなし。ビルドなしのESモジュール
- 通信は同梱データの取得のみ。CSP は `connect-src 'self'`
- 共有ブロック（`shared/share.css`・`shared/share.js`）を入れる。OGPと `canonical` は `meta.json` からビルドが入れる
- ダークモード対応。`prefers-reduced-motion` のときはアニメーションを飛ばして完成形を出す
- キーボードだけで主要な操作ができる。面には現在の状態を伝える `aria-live` を置く

## テスト

- ユニット（`node --test`）：入力の正規化／シャード名の計算／筆の太さプロファイルと画の種別の判定／マスの割りつけ／進捗の数え方／最近の言葉の保存／パスの最小化と丸めのずれ
- E2E（Playwright）：空では保存ボタンが見えない／書くと進捗が進み最後に保存が出る／データの無い字で印が出てほかの字は書かれる／速度を変えられる／最近の言葉から書き直せる

## デモ・スクショ・プロモ
