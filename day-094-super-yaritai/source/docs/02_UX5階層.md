# 02 UX5階層（②要件〜⑤表層）

①戦略は 01 にある。ここでは、そこから導いた画面の決め方を書く。

## ②要件：入れる機能と入れない機能

- 遊び方は2つ：**ひとりで**（CPUのライバル1人と勝負、強さ3段階）、**ネット対戦**（友だちと「あいことば」の部屋で2〜4人／知らない人と自動で2人、見つからなければCPU戦）
- 1試合2分（部屋の主は90秒・2分・3分から選べる）。荒らし度がいちばん高い人が勝ち
- やっちゃダメリストは10個、ほかに「ひみつ」が2個（03）。店員は目立つ人を追いかける
- 結果画面：順位・荒らし度・内訳・達成したやっちゃダメ・称号・店の被害率。シェアは4点セット（端末の共有・X・LINE・リンクのコピー）。OGPとcanonicalも入れる
- 操作：スマホは左スティックと右のボタン3つ。PCはキーボードとゲームパッド
- 音：効果音もBGMもブラウザの中で合成する（外部の音源ファイルや既存の曲は使わない）。消音は1か所で切り替える
- 通信先は自分のWorkerだけ。外部フォント・CDN・解析ツールは読み込まない
- 画質は低・中・高を自動で選ぶ。スマホで毎秒30コマを下回らない
- 入れないもの：01の「やらないこと」

## ③構造：画面のつながりと、迷ったときの戻り道

```
タイトル ─┬─ ひとりで ─ CPUの強さ ───────────────────────────────┐
          ├─ 友だちと対戦 ─ 名前 ─ 部屋を作る／あいことばで入る ─ 待合室 ─┤
          ├─ だれかと対戦 ─ さがす（20秒）─┬─ 見つかった ──────────┤
          │                                └─ 見つからない → CPU戦 ─┤
          └─ あそびかた                     ゲーム（2分）─ 結果 ─ もう一回／タイトル
```

- 迷う分岐は対戦の2択。ボタンの下に「リンクを送って友だちと」「知らない人と自動で」を1行で添える
- **リンクで来た人**（`?room=K7QM`）はタイトルを飛ばして名前の入力へ進む。入れなかったら理由（部屋が見つからない／満員／もう始まっている）を出して入力に戻す
- **接続が切れた**ら自動でつなぎ直す（待合室は60秒、ゲーム中は20秒）。部屋の主が抜けたら、その時点の点数で結果を出す
- どの画面にも「もどる」がある。ゲーム中の「やめる」は確認を1回はさむ

## ④骨格：いちばん大きいのは店の3D、次がアクションボタン

- **ゲーム画面**：3Dの店が全面。上の中央に残り時間（大）、その横に自分の荒らし度、相手の荒らし度は小さく。左上に「やっちゃダメリスト」（スマホでは折りたたみ、達成したときだけ開いてハンコを押す）
- **コンボ**：倍率は自分のキャラの頭上と画面右に出す。途切れるまでの残り時間を細い帯で見せる
- **スマホのボタン**：左下に移動スティック（触れた所が中心になる）。右下に大きなアクションボタン（直径96px以上、文字は状況で変わる）、その上にダッシュとジャンプ（64px以上）
- **店員の接近**：画面の端に赤い「！」の矢印。近いほど大きくなる
- **カメラ**：斜め上から追いかける。向きは固定で、プレイヤーが回す必要はない。キャラとカメラの間にある棚は、キャラの周りだけ透かす
- **結果画面**：勝者を大きく見せ、その下に内訳・称号・シェア・もう一回を並べる

## ⑤表層：明るい「おもちゃの店」

- **3D**：Kenney の Mini シリーズ（丸っこいローポリ）で統一する。床は白とミントの市松、照明は白い蛍光灯に少しだけ暖色を混ぜる
- **色**：画面の地はクリーム #FFF8EC、文字は #2B2B3A。差し色は特売の赤 #E8423F・レジの青 #2F7DE1・値札の黄 #FFC93C・青果の緑 #3BAA5C の4つ。プレイヤーは1P赤●・2P青▲・3P黄■・4P緑◆とし、**色だけでなく形と番号でも区別する**
- **文字**：端末の日本語フォントを使う。点数は数字の幅をそろえる。見出しは値札POPのような太い字にする
- **動き**：崩れる・飛ぶは物理に任せる。点数は「ポン」と跳ね、達成したらハンコを押す。端末で「視差効果を減らす」を選んでいる人には、画面の揺れとフラッシュを止める
