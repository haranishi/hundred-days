# 04 店の配置と3Dの決まり

## 店の地図（上が奥＝北。座標はメートル、x は東、z は手前＝南が正）

店の内側は x −18〜18、z −14〜14（36m×28m）。正本は `src/shared/layout/store.ts` の純データで、描画・当たり判定・経路・配置はすべてここから作る。店の配置を変えても、見える棚と通れる場所が食い違わないようにする。

```
z=-14 ┌─放送ブース─┬─スタッフ扉──────────── 立型冷凍ケース ────┬── パン ──┐
      │ (マイク)    │  [平台の冷凍ケース×4]                       │ [試食台]  │
z=-8  │            奥の横通路（z −11〜−8）                                    │
      │ 青果     ┃お菓子┃ 飲料 ┃缶詰・調味料┃ 日用品 ┃                  飲料の │
      │ バナナ   ┃ (A)  ┃ (B)  ┃   (C)      ┃ (D)    ┃ ←奥にピン10本     冷蔵 │
      │ 果物台   ┃      ┃      ┃            ┃        ┃                  ケース│
z=2   │          ┃      ┃      ┃ [缶ピラミッド] [スイカのワゴン]                 │
      │            手前の横通路（z 3〜7）＝カートで走る広場                       │
z=8   │                                        [レジ1] [レジ2] [レジ3]          │
      │       [サービスカウンター（ベル）]  ▼出入口▼  [カート置き場]              │
z=14  └──────────────────────────────── 自動ドア x 2〜6 ──────────────────────────┘
```

- **棚の列**：中心 x = −9, −4, 1, 6, 11 の5列。1列は棚5台（z −8〜1、両面）。両端に端の棚（shelf-end）。通路の幅は約3.4m
- **出入口**：南の壁 x 2〜6。プレイヤーは入って2mほど奥（z 9.8）に並んで始まる（round3。入口のアーチがキャラにかぶらず、店の外が映りすぎないように。これより奥だと缶ピラミッドまで5m未満になり、CPU の最初の行き先の選び方が変わる）。ベルは数m先にあるので、最初の成功は数秒で取れる
- **手前の横通路**：缶ピラミッド（C通路の南端、x 3.5, z 3）とスイカのワゴン（D通路の南端、x 8.5, z 3.5）が並ぶ。カート置き場から走ってくると、ここで缶に突っ込める
- **ボウリング**：D通路そのものがレーンになる。棚が両側のガターの役を果たし、奥（z −7.5）にトイレットペーパーのピン10本を三角に並べる
- **奥**：西の角に放送ブースとスタッフ扉（店員はここから出てくる）。中央に平台の冷凍ケースの島。東の角にパン売り場と試食台。北の壁の立型ケースの列は東へ1.2m寄せ、ケースの裏に抜けられるすき間（1.3m）を残す（round3。追われて逃げ込むと行き止まりになっていた）
- 南の壁はカメラ側なので、出入口の枠を残して腰の高さまで下げる（中が見えるようにする）

## 「やっちゃダメ」の場所には、店の注意書きを立てる

各悪事の場所に「ベルは1回だけ押してください」「冷凍ケースに入らないでください」「試食はお一人様1本まで」「放送室 関係者以外立入禁止」「お菓子売り場で寝転ばないでください」「カートで遊ばないでください」「商品を積み直さないでください（崩さないで）」の札を立てる。**店の注意書きがそのまま遊び方のヒントになる**。説明を読まなくても「書いてあることの逆をやればいい」とわかる。

## 大きさと素材

- **縮尺**：Kenney の Mini シリーズを 2.3 倍にする。キャラの背は約1.6m、棚は約1.85m、カートの取っ手は約0.9m。食品キットは品目ごとに目標の大きさ（缶0.35m、ペットボトル0.55m、スイカの直径0.55m など）へ合わせる。商品は実物より大きく、上から見てもわかる大きさにする
- **素材**（すべて Kenney・CC0・表記不要）：Mini Market（壁・床・棚・冷凍ケース・レジ・カート・カゴ・店員）、Mini Characters（プレイヤーと買い物客。補助具と車いすは使わない）、Food Kit（商品）。使用するモデルは `public/models/` にある。取得元とライセンスは [3Dモデルの来歴](../public/models/LICENSES.md) を参照
- **棚のモデルは「枠」と「商品」が別の部品**になっている。描くのは**枠だけ**で、商品はすべて1個ずつ物理で動く物として置く。🔴 three は同じ名前の2つ目以降に `carton_1` のような別名を付けるので、名前で飾りの商品を外す方式だと1つ目しか外れない（round2 まで、飾りの箱が全部の棚に描かれ続けていた）。枠だけを選ぶ仕組みは `dress-store.test.ts` が見張る
- **通路ごとに主役の色を決める**（遠目で札なしでも通路がわかるように）：お菓子＝黄とピンクの袋と箱／飲料＝6本パック・ボトル・青い缶・牛乳パック／缶詰＝赤い缶とトレー／日用品＝白いロールと淡い色のボトル。色はテクスチャの色見本の升をずらして塗り替え、seed と商品の番号から決める（主と参加者で一致する）
- 立型の冷凍ケースはガラス戸がモデルの +z 側にある。壁に向けて置くと濃い灰色の箱に見える
- **壁と奥の飾り**（round4・`render/decor.ts`）：壁の内側に腰板・ポスター6種・秋の三角旗、壁の上面は日よけの縞（どの壁も薄い赤と白。濃い赤は開始時に画面の下いっぱいに出て、赤い「蹴る」とぶつかった）。奥の壁の上に看板の帯・時計・バッジを立て、空のクリームは塗らずに輪郭をにぎやかにする
- **レジ3台は見分けられるようにする**：1番＝袋の台と多めの品、2番＝かご、3番＝「休止中」。**レジに店員の人形は置かない**（追いかけてくる店員と見分けがつかなくなる）。壁ぎわのケースと青果のかごは、同じ形を塗り替えで描き分ける
- **自作する部品**（コードで組む）：トイレットペーパーの束、試食台、放送ブースとマイク、呼び出しベル、レジのベルトコンベア、天井の照明、床の市松、札と値札（日本語は canvas で描いてテクスチャにする。外部フォントは読まない）
- **人物の役**：プレイヤーは6体から選ぶ（female-b・male-f・female-f・male-a・female-e・male-e）。店員は Mini Market の character-employee、店長はスーツの male-d。買い物客は female-c・male-b・female-d。警官の帽子の male-c は使わない（捕まる演出が逮捕に見えるため）
- **アニメーション**：キャラのGLBには32種類の動きが入っている。歩く・走る（sprint）・ジャンプ・落下・カートを押す（drive）・拾う（pick-up）・蹴る（attack-kick）・なぎ払い（attack-melee）・食べる（interact）・転ぶ（die を短く）・駄々（die と crouch の組み合わせ）に割り当てる

## 見た目の決まり

- **色の出どころを1か所にする**：照明・床・壁・UIの色は `src/client/render/palette.ts` だけから取る。02 の色と同じ値を使う
- **光**：空と地面の半球光に、北西の上からの白い光（影あり、影の範囲はプレイヤーの周り約30m）。天井の蛍光灯は光らせるだけで、光源にはしない（スマホの負荷を抑える）
- **透かし**：キャラとカメラの間の棚は、画面上でキャラの周りの円の中だけ透かす
- **講評の仕分け**：見た目の指摘は「足りない・平ら・同じ」に分けて直す。足りない＝人や札や散らかりを足す、平ら＝接地の影・汚れ・出っ張りを足す、同じ＝商品・人・札の種類を増やす
- **固定ショット**：`tools/shots.mjs` で、乱数・時刻・カメラを固定した次の6枚を撮り、周回ごとに並べて比べる。S1 入口から見た店内／S2 お菓子の通路／S3 缶ピラミッドの前／S4 荒らした後の店（台本どおり壊してから撮る）／S5 スマホ縦のゲーム画面／S6 結果画面

## 重さの予算（スマホで毎秒30コマ以上）

- 動く商品は全部で約350個まで。止まった物は物理の計算を休ませる（sleep）
- 同じ形の商品は InstancedMesh で1回の描画にまとめる。描画の回数は1コマ150回以内、三角形は30万以内
- 画素の密度はスマホで最大1.5倍、PCで2倍。毎秒の描画数が落ちたら自動で画質を下げる（低：影なし・影の代わりに丸い影、中：影1024、高：影2048）
- 最初の読み込みは、**圧縮後の転送量で**合計5MB以内（物理エンジン Rapier は compat 版で生のまま4.3MB・gzip で1.7MB あるため）。物理エンジンはタイトルの表示中に後から読み、キャラは試合の開始時に読む
