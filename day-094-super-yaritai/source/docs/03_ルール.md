# 03 ルール（数値は体験ループで調整する。正本は `src/shared/rules/`）

## 試合の流れ

- 開始前に3秒のカウントダウン。試合は120秒（部屋の主は90・120・180秒から選べる）
- **開店直後の20秒**は店員が追いかけない。最初の成功体験をここで作る
- **残り60秒**で店長が出てくる（追いかける役が1人増える）
- **残り10秒**はラストスパート。BGMが速くなり、入る点数が1.5倍
- 時間切れで終了。荒らし度がいちばん高い人が勝ち。同点なら、達成したやっちゃダメの数が多い人が勝ち

## 荒らし度の数え方

- 1回の悪事の点 ×コンボ倍率（×ラストスパート1.5）
- やっちゃダメを**初めて達成**したら +300（倍率はかけない）。10個すべてで「完全制覇」+3000。ひみつは +800
- 棚・台の商品を床に落とすと、どの悪事でも1個10点。落とした人の決め方は「最後に触った人」（3秒以内に触った体・投げた物・乗っていたカート）
- **コンボ**：点が入るたびに5秒の猶予が始まる。猶予のうちに**別の種類**の悪事をすると段が1つ上がる（倍率 1.0 → 1.2 → 1.5 → 2.0 → 3.0）。同じ種類を続けると猶予だけが延びる。ベル・試食・放送・冷凍・駄々で点が入っている最中は猶予が減らない（round2。連打や長押しの間に切れて損をしないように）。猶予が切れるか、捕まると段は0に戻る

## 元に戻るもの（対戦で取り合いにならないように）

- 缶ピラミッドは崩れて25秒後に積み直される。ピンは8秒後に並び直す。試食は20秒後に補充される
- スイカはワゴンに6個。全部なくなったら15秒後に補充される。バナナの皮は1人2枚まで置け、40秒で消える
- 棚の商品は戻らない。店が荒れていくこと自体が見どころになる。結果画面に「店の被害率」（定位置から動いた商品の割合）を出す

## 目立ち度と店員

- 目立ち度は人ごとに0〜100。点が入るたびに「点÷10」（1回最大25）上がる。試食は1本+8、放送は+40。2秒間なにもしないと毎秒5ずつ下がる
- **店員**は最初2人、残り60秒から店長が加わる。ふだんは決まった道を歩く（秒速2.2m）
- 店員が気づく条件：目立ち度30以上の人が9m以内で見えている。または6m以内で悪事が起きた。気づくと頭上に「！」が出て、その中でいちばん目立つ人を追う（秒速4.4m、店長は4.8m）
- プレイヤーは走ると秒速5m、ダッシュは0.35秒だけ秒速9m（1.5秒ごと）、カートは最大秒速10m。4秒見失うと店員はあきらめ、逃げ切った人に+100が入る
- **捕まる**：「！」が出てから1秒たつまでは確保されない（その間にダッシュで逃げられる）。そのあと店員と1m以内に入ると確保。0.6秒その場でつかまれ、サービスカウンターへ連れ戻されて3秒動けない（round2。誰に捕まったかを見せるため）。目立ち度とコンボは0に戻り、持っている物は落ちる。その店員は5秒休む
- 店員はバナナで3秒転ぶ。放送をジャックされると、全員が放送ブースへ向かう（10秒間は誰も追わない）
