# Day 094「スーパーやりたい放題」

スーパーで「やっちゃダメ」なことを2分間やりまくり、荒らし度（点数）を競う3Dブラウザゲームです。ベルの連打・棚のなぎ払い・カートで爆走・缶ピラミッド崩し・スイカでボウリング・試食の食べ尽くし・店内放送ジャックなど、10個の悪事をつなぐとコンボになります。目立つほど店員と店長に追われます。ひとりならCPUと勝負、リンクで友だちと、または知らない人と対戦できます。スマホでもPCでも、登録なしで遊べます。

- 公開サイト: https://day94.rairakku.com/
- `rairakku.com` の中の住所: https://rairakku.com/day94/（`day94.rairakku.com` へ転送します）

舞台は架空のお店です。現実のお店では、まねしないでください。

## できること

- **10個の「やっちゃダメ」と、ひみつ2個**：ベル連打・棚のなぎ払い・カート爆走・缶ピラミッド崩し・スイカでボウリング・試食の食べ尽くし・冷凍ケースで涼む・お菓子売り場で駄々をこねる・バナナの皮・店内放送のジャック
- **コンボと追跡**：別の種類の悪事をつなぐと点が上がり、最後の10秒は1.5倍。目立つほど店員が、さらに店長が追ってきます
- **ひとり・友だち・知らない人**：ひとりはCPU（3段階）と勝負。友だちとはリンクで部屋に集まって2〜4人で、知らない人とは2人で対戦できます
- **スマホとPC**：スマホはスティックとボタン、PCはキーボードで遊べます。結果は X・LINE・端末の共有・リンクのコピーで送れます

登録やログインは要りません。名前は8字まで、ランキングや成績の保存はありません。効果音とBGMはブラウザの中で合成していて、外部の音源やフォントは読み込みません。3Dの素材は Kenney（CC0）です。
