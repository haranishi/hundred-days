# Day064「漏洩の地図」プロモーション素材

32秒・1080×1920の縦型動画。実際のアプリを操作し、地球儀、日本の公表記録、自治体の掲載行、原資料、備えの学習を字幕で紹介する。音なしでも読める字幕と、コードで合成した控えめなBGMを使う。

## 再生成

リポジトリのPlaywright / Chromium、ffmpeg / ffprobeを使用する。撮影前に `source` のデータ・ビルド・`tools/release.mjs` の生成物を更新する。大きな中間ファイルは、利用できる開発用ドライブを `--work` に指定して保存する。

```sh
node day-064-breach-atlas/tools/promo/render-promo.mjs \
  --work <撮影素材の保存先> \
  --demo day-064-breach-atlas/demo.mp4
```

`--work` 内へ `Day064_breach_atlas_promo.mp4`（H.264 / AAC、30fps）と実画面・検査記録を生成する。一覧用 `demo.mp4` は720×1280・25fps・音声なし。元映像は540×960の実画面を拡大したもので、1080px幅のネイティブ撮影ではない。

字幕に使うローカルのZen Kaku Gothic New Boldは `PROMO_FONT` で指定できる。書体ファイルは動画やアプリに同梱しない。字幕は `timeline.mjs`、独自の合成音源は `promo-audio.mjs`。

| 秒 | 実画面と字幕の内容 |
|---|---|
| 0–4 | 漏洩のニュースを次の備えへ。全記録の地球儀 |
| 4–9 | 日本4,652件・全18,001件の公表記録。日本へ切り替え |
| 9–15 | 横浜市（神奈川県）を検索し、一括公表の2,039掲載記録を一覧で読む |
| 15–21 | 所管課、掲載行、数字と日付、原資料へのリンク |
| 21–27 | 更新・認証などの学習テーマとIPA資料へのリンク |
| 27–32 | 「知ることから、備えることへ」と公開URL |
