# ことば辻 — 要件（入口）

江戸風のクロスワード。盤は毎回組み立てられ、**最初からほぼ埋まっている**。空いた「辻」（縦と横の言葉が交わるマス）に、両方の言葉に合う一字を入れていく。腕前が上がるほど埋める字が増える（手習い1・一人前7・免許皆伝15）。スマホで数十秒〜数分・登録なし・広告なし。依存ゼロの静的サイト（HTML・CSS・ES modules）。

## 腕前
手習い（**埋める字1**・言葉5・辻4・7×7）／一人前（**埋める字7**・言葉8・辻9・9×9）／免許皆伝（**埋める字15**・言葉12・辻15・11×11。辻はすべて空き）。空きは辻にだけ置き、ほかのマスは最初から答えの字が書いてある（書き換え不可）。値の正本は `lib/levels.js`。画面の数字は必ずそこから読む。

## 画面と流れ
タイトル →［いざ、参る］→ 腕前選び → 対局 → 結果 →［もう一局／腕前を変える／盤を見返す］
タイトルからは［続きから］［番付］［指南書］［しつらえ］。果たし状のリンク（`#c-…`）で開いたら、タイトルの代わりに果たし状の画面。
- 対局の「退く」は保存してタイトルへ（確認なし）。途中の一局がある状態で新しく始めるときだけ札で確認する
- 対局中は自動で保存（字を書くたび・問を移るたび）。再読み込みしても続きから戻れる
- 経過時間は対局画面が見えている間だけ進める（`visibilitychange` で止める）

## 完了の条件（テストの門。1つでも落ちたら採点に進まない）
1. `npm run test:unit` 全部通過（エンジン・単語帳）。空きについて：3つの腕前それぞれ500盤で、空きの数がちょうど埋める字の数・空きはすべて辻・同じ seed なら同じ空き・一人前はどの言葉も最低1字が見えている
2. `npm run test:e2e` 全部通過。E2E は 100日チャレンジのリポジトリの Playwright を借りる。配信サーバーはテストの中で spawn して最後に kill する（Bash の `&` で起こさない）。最低限、次を確かめる
   - タイトル：コンソールのエラー0件。390×844 の最初の画面に題字と「いざ、参る」。動きを減らす設定では暖簾が出ない
   - 3つの腕前それぞれで、盤の空きマスがちょうど埋める字の数（1・7・15）あり、五十音盤で空きだけを埋めると結果に「天晴」・番付・時間が出る（答えはテスト用の窓口から読む）。**手習いは五十音盤を1回押す（濁る字なら「゛」を足して2回）だけで結果に進む**
   - 最初から書いてある字は、押しても打っても「消す」でも変わらない
   - 空いた辻にいるとき、いまの問の帯に横と縦の問が両方出る。見出し帯に「残り n字」
   - 濁点（か＋゛→が）、ローマ字（neko→ねこ）、消す、同じマスを2回押して縦横が入れ替わる
   - 助太刀（一字・一問）で数が増え、結果に出る。吟味で間違いの印と台詞。降参で「無念」
   - 途中で再読み込み → 「続きから」で同じ字が戻る
   - `#c-2-<seed>-192` で開く → 果たし状 → 受けて立つ → テスト用の窓口で見た盤と空きの位置が、同じ seed の盤と一致
   - 共有：Xの投稿画面のURLに果たし状のリンクが入る、LINE、リンクのコピー（`navigator.share` があるときだけ「共有…」）
   - しつらえの3項目が再読み込み後も残る。記録を消すの札が動く
   - 375・390・430・768・1024・1440px で横スクロールなし。375×667・390×844・390×660 で対局画面がページのスクロールなしに収まる（3つの腕前すべて）。五十音盤のキーは幅28px以上・高さ36px以上
   - 外部への通信は無い（単体の版では Google Fonts だけだった）。コードに `alert(` `confirm(` `prompt(` が無い
   - WebKit でもタイトル→対局→1字入力まで動く（前例の launchWebkit を使う）
3. スクショ（単体の版の `npm run shots`）：390／768／1440px で、タイトル（暖簾が開いた後）・腕前選び・対局（途中）・問の一覧・助太刀の札・結果・番付・指南書・しつらえ・果たし状 を撮る。撮る前に動きが止まるのを待つ（`document.getAnimations()` が全部終わるまで）
