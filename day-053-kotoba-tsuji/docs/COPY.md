# COPY — 画面の言葉と案内役の台詞

案内役は江戸の侍。一人称は使わず、相手を「そなた」と呼ぶ。**見出しとボタンは素直な言葉**にし、口調は一言・台詞・問に出す。語尾は「〜でござる」を軸に「〜じゃ」「〜であろう」「〜だろう」「〜ぞ」で散らす。**意味は現代の言葉ですぐ分かること**を優先し、古語で読み手を止めない。数字（時間・件数・字数）は算用数字、問の番号だけ漢数字（縦の三）。

台詞に「{label}」などの差し込みがある。候補が複数ある所は毎回ランダムに1つ選ぶ（同じ台詞が2回続かないように）。

## タイトル
- 題字：ことば辻　／　副題：江戸のクロスワード
- 口上：言葉と言葉が交わる辻が、ところどころ空いておる。縦にも横にも合う一字を入れて、盤を仕上げるでござる。（v2）
- 口上の下の小さな一行：登録なし・広告なし・盤は何局でも
- ボタン：いざ、参る（主）／続きから（途中の一局があるときだけ）／番付／指南書／しつらえ
- 共有欄：100日チャレンジの全アプリ共通の部品（`shared/share.js`。見出しは「このアプリを共有する」、Xの投稿画面・LINE・リンクのコピー・端末の共有）。単体で作った版の見出し「この遊びを広める」は、Day 053 として載せるときにこの部品へ置き換えた
- 続きからで戻ったとき：おかえりなされ。続きから参ろう。

- 札（名・読み・数・一言）
  - （v2：いちばん大きな数字は「埋める字」。言葉と辻の数を小さく添える。盤の大きさは実物と合わないので出さない。数は lib/levels.js から読む）
  - 手習い（てならい）｜埋める字 1｜言葉 5・辻 4｜まずは一字、気楽に参られよ。
  - 一人前（いちにんまえ）｜埋める字 7｜言葉 8・辻 9｜骨のある問じゃが、そなたなら解けるであろう。
  - 免許皆伝（めんきょかいでん）｜埋める字 15｜言葉 12・辻 15｜辻はすべて空いておる。腕に覚えのある者だけ、参られよ。

## 対局
- 見出し帯：退く ／ 一人前・埋める字7 ／ 残り 3字 ／ 線香の印＋3:12（v2）
- いまの問：横の三・4文字 ＋ 問の文。解けた問は答えと書き方も出す：ねこ（猫）
- （v2）空いた辻にいるときは、横と縦の問を2段で出す。いまの向きを上に、太く。空きでないマスを押したときは、その言葉の問を1つだけ出す
- 道具：助太刀／吟味／問の一覧／縦⇄横（いまの向きが分かる表示にする）
- 問の一覧の見出し：縦の問・横の問。解けた問に「済」の印。（v2）空きの無い問（最初から埋まっている）は印を付けず、薄く出す
- 初回の案内（最初の1局だけ・1行・盤に重ねない・数秒か最初の1字で消える）：朱の枠に、縦にも横にも合う一字を入れるべし。（v2-r2）
- 始まりの一言：いざ尋常に、勝負でござる！／さあ、やるでござるよ！／空いた辻は{n}か所。易しい所から埋めるが吉であろう。（v2）

### 反応
- 言葉が解けた：{label}、見事でござる！／{label}、お見事！／うむ、{label}は正解じゃ。／冴えておるな。{label}、あっぱれ！
- 埋まったが違う（一問ごとの判定が有りのとき）：むむ、{label}はどこか違うようでござる。／{label}…惜しい。一字、見直してみるがよい。
- （v2）1字で縦横2つの言葉が同時に解けた：一字で{a}と{b}、二つとも解けたり！ 見事でござる！／{a}も{b}も、一挙に片付いたな。あっぱれ！
- 残り1字になった（v2）：残るは一字のみ。もうひと踏ん張りじゃ！
- （v2）空きはすべて埋まったが、違う字が残っている：すべて埋まったが、どこか違うようでござる。「吟味」で確かめるがよい。

- 吟味・間違いあり：朱で印を付けた字が違うておる。{n}字、直すがよい。

## 指南書
（v2 で1と2を差し替え、5に一文を足した）
1. 盤はほぼ埋まっておる。朱の枠のマスが、空いた辻（縦と横の言葉が交わるマス）じゃ。
2. 空いた辻を押すと、そこを通る横と縦の問が出る。両方の言葉に合う一字を、下の五十音盤で書き入れるべし。濁りは字のあとに「゛」、半濁りは「゜」を押す。
3. 小さい「ゃ・ゅ・ょ・っ」も大きく書くのが決まりじゃ。きゅうり → きゆうり、きって → きつて。
4. 困ったら「助太刀」。一字だけ、または一問まるごと教えてしんぜよう。「吟味」を押せば、違う字に朱で印を付ける。
5. 空いた辻がすべて埋まれば、あっぱれ！ かかった時間と助太刀の数で番付が決まる。腕前が上がるほど、埋める字が増えるでござる。
- PCの方へ：ローマ字で書ける（neko → ねこ。「ん」は nn でも書ける）。矢印で動き、スペースで縦と横を入れ替え、Enter で次の空き辻へ。
- ボタン：閉じる（v2-r3：しつらえと呼び名をそろえる。PCは Esc でも閉じる。しつらえも同じ）
