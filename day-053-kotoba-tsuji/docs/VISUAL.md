# VISUAL — 見た目・動き・音・配置（実装者向け）

## 世界観
江戸の町の「辻」。タイトルは店先の藍の暖簾をくぐって始まる（暖簾が左右に分かれて題字が現れる）、対局は行灯の光を透かす障子の盤、ボタンは木札。紙・墨・朱・藍・木の5つの素材だけで組む。和風の記号（桜吹雪・扇・金屏風など）を全部盛りにしない。**見せ場は開幕の暖簾と完了の朱印の2か所だけ**。定式幕（黒・柿・萌黄の縞）は歌舞伎座の登録商標なので使わない（事前リサーチで確かめた）。菊の紋・実在の家紋も使わない。

## 色（`:root` に置く。夜の配色は作らない＝昼の和紙1本。`color-scheme: light`）
```css
--washi:#F2E8D5;      /* 地の和紙（生成り） */
--washi-deep:#E4D4B4; /* 影になった紙・空きマス */
--sumi:#26221E;       /* 墨：本文・盤の字 */
--usuzumi:#5B5147;    /* 薄墨：補足の文 */
--shu:#B33A2B;        /* 朱：主ボタン・印・間違い */
--ai:#22406B;         /* 藍：解けた言葉・選択中の向き */
--kinari-light:#FBF6EA;/* 光る障子（いまの言葉） */
--akari:#F6DFA4;      /* 行灯の灯り（いまのマス） */
--wood:#6B4428; --wood-face:#C99E6E; --wood-light:#E2C49A; /* 木（素材・枠・木札） */
```
朱・藍・墨はどれも和紙の上で4.5:1以上になる値にする（上の値のまま使えば足りる）。間違いは朱だけでなく「×」の小さな印でも示し、解けた言葉は藍の字に加えて問の一覧で「済」の印を付ける。

## 書体（同梱の woff2・`font-display: swap`、必ず代わりの書体を並べる）

はじめは Google Fonts から読んでいたが、Day 053 として載せるときに同梱へ変えた（`fonts/`。画面に出る字だけに絞り、OFL.txt を添える）。アプリ配下のCSPが外の書体とCSSを止めるのと、外への通信をなくすため。
- `--font-display: "Shippori Mincho B1", "Hiragino Mincho ProN", "Yu Mincho", serif` — 題字・見出し・ボタン・盤の字・問・台詞
- `--font-ui: "Zen Kaku Gothic New", "Hiragino Sans", "Yu Gothic", sans-serif` — 時間・件数・マスの番号・小さな説明
- 題字は縦書き（`writing-mode: vertical-rl`）。数字は `font-variant-numeric: tabular-nums`

## 部品
- **木札ボタン**：角を斜めに落とした長方形（`clip-path`）。木目は重ねたグラデーションで軽く。押すと1〜2px沈み、影が詰まる。主ボタンだけ朱塗り（朱の地に和紙色の字、細い金茶の縁）。フォーカスは藍の2pxの輪郭＋2pxのすき間
- **障子の盤**：木の枠（--wood）の中に、字の入るマスは和紙、空きマスは --washi-deep の沈んだ面。桟（マスの境）は木の色の細線。いまの言葉のマスは --kinari-light に光り、いまのマスは --akari＋朱の内枠2px。マスの左上に番号（--font-ui・小）。字は墨の明朝で太め。解けた言葉の字は藍。助太刀で入った字の右下に小さな朱の点
- **五十音盤**：小さな木札のキーが並ぶ。列は右から あ・か・さ・た・な・は・ま・や・ら・わ、左端の列に ゛・゜・消す（消すは縦に2段分の大きさ）。押すとキーの上に大きな字が0.12秒だけ浮く（指で隠れても何を押したか分かるように）
- **いまの問（短冊）**：細長い和紙の帯。左に「横の三・4文字」（藍の小さな見出し）、本文は明朝。左右に前の問・次の問の矢印
- **札（ダイアログ）**：画面中央の高札風の板。背景は墨の半透明。`alert` / `confirm` / `prompt` は使わない
- **案内役の一言**：盤の上に短冊が0.2秒で降りてきて約2.5秒で消える。重なったら新しいほうに置き換える。`aria-live="polite"`
- **印**：屋号風の丸に「辻」の字（オリジナル。実在の家紋は使わない）

## 動き
- **開幕（タイトル）**：藍染めの暖簾（中央で2枚に割れ、白抜きで屋号の印「丸に辻」と「ことば辻」）が画面の上から垂れた状態から、0.25秒待って1.1秒で左右に分かれながら上へ払われる（布が少し揺れる）。押せば即座に開き切る。`prefers-reduced-motion` か しつらえの「控えめ」なら暖簾を出さない
- **画面の切り替え**：襖が左右から閉じて開く（合計0.45秒以内）か、0.15秒のフェード。控えめならフェードだけ
- **言葉が解けた**：その言葉のマスが端から順に0.04秒ずつ藍に染まる
- **埋まったが違う**：その言葉が左右に2回だけ小さく揺れる（0.25秒）
- **完了**：朱印「天晴」が大きめから落ちて止まり（0.18秒・少し傾く）、背景に花火（canvasの粒・朱／金茶／藍・2.5秒）。控えめなら印が出るだけ
- どの動きも入力を止めない。操作できるまで待たせない

## 音（録音素材を使わず Web Audio で合成。最初の操作で AudioContext を作る・再開する）
- 拍子木（チョン、チョン）：開幕と対局開始。帯域を絞った雑音の短い破裂＋高めの正弦波を速く減衰。2打目は0.18秒後
- 木の打鍵音：キーを押すたび。ごく小さく短く
- 三味線（Karplus-Strong の撥弦）：言葉が解けたとき、都節の音階で2音
- 鼓（ぽん）：埋まったが違うとき。音程が下がる正弦波
- 太鼓（どん）＋柝（チョーン）：完了
- しつらえで「鳴らさない」なら何も鳴らさない。音量はどれも控えめ（主音量0.5程度）

## 配置
- **スマホ縦（〜599px）**：対局画面はページをスクロールさせず、`height:100%` の1画面に収める。上から 見出し帯（44px）→ 盤 → いまの問 → 道具の列 → 五十音盤。盤のマスの大きさは「幅に収まる大きさ」と「残りの高さに収まる大きさ」の小さいほう。キーの高さは画面の高さ740px以上で44px、それ未満で38px（既存アプリの不満で多いのは「ボタンが小さい」）
- **タブレット（600〜1023px）**：同じ並びで中央寄せ、最大幅560px
- **PC（1024px〜）**：左に 盤・いまの問・五十音盤、右の列に縦の問と横の問の一覧（常に表示・列の中でスクロール）
- タイトル・腕前選び・番付・指南書・しつらえ：中央の1列（最大幅480px）。左右の余白は16px以上。横スクロールを出さない
- 390×844 で、タイトルの題字と「いざ、参る」が最初の画面に収まる。375×667 でも対局画面が1画面に収まる

## 公開先の制約（claude.ai の Artifact でも動かすため）
- 外部から読むものは無い（書体も同梱）。スクリプトは全部自前のファイル
- `localStorage` の読み書きは全部 try/catch。無くても遊べる
- `navigator.share` は無い環境がある。あるときだけ「共有…」を出す
- 画面の高さは `100vh` でなく `html, body { height:100% }` から取る。上下の安全域（`env(safe-area-inset-*)`）を足す
- 果たし状は URL の hash（`#c-2-k3f9a2-192`）。クエリ文字列は使わない
