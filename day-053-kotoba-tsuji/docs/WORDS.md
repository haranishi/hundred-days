# WORDS — 単語帳の仕様（実装者向け）

問の面白さは単語帳で決まる。量より「読めば答えが1つに決まる問」を優先する。

## ファイルと形
`data/words.js`：
```js
export const WORDS_VERSION = 1;
export const WORDS = [
  { r: 'ねこ', k: '猫', t: 1, g: '動物', c: 'にゃあと鳴いて鼠を捕る、家の用心棒でござる' },
  // …
];
```
- `r` 読み（ひらがな。小さい字はそのまま書いてよい：'きゅうり'）。盤では小さい字を大きくして使う（'きゆうり'＝4マス）
- `k` ふだんの書き方（漢字かカタカナ。解けた後に「きゅうり（胡瓜）」と見せる）
- `t` 難しさ：1＝子どもでも知る身近な言葉／2＝大人なら知る一般の言葉・行事・道具／3＝江戸の暮らしの言葉・やや難しい言葉
- `g` 分類：動物／鳥・魚・虫／草木・花／食べ物／菓子・飲み物／暮らしの道具／着る物／体／天気・季節／自然・地形／町・建物／仕事・人／遊び・行事／芸能／江戸の言葉／その他
- `c` 問（かぎ）。下の「問の書き方」に従う

## 量の目安（検証スクリプトで確かめる）
- 合計 **520件以上**。t1 ≥ 230、t2 ≥ 170、t3 ≥ 110
- 盤での長さ（小さい字を大きくした後）：2字 50〜90、3字 ≥ 170、4字 ≥ 150、5字 ≥ 80、6字 ≥ 35、7字 ≥ 15
- t1 だけで2〜5字が230件以上（手習いは t1 しか使わない）
- 1つの分類が全体の15%を超えない

## 答えの決まり
- 盤での形（正規化後）が**単語帳の中で重複しない**。同じ読みの別の言葉（橋・箸・端）は1つだけ採る
- 「ー」を含む言葉、ゔ、ゐ・ゑは採らない。正規化後に使えるのは清音46・濁音20・半濁音5だけ
- 名詞を中心にする。形容詞・動詞は読みが1つに決まるものだけ少数
- 採らない：人名、会社・商品名、差別につながる言葉（江戸の身分に関わる語を含む）、死・暴力・性に関わる言葉、酒・たばこ

## 問の書き方
- 江戸の町人や侍が語る口調。ただし**意味がすぐ取れる現代の言葉で**書く。12〜38字
- 文末を散らす：「〜でござる」「〜じゃ」「〜であろう」「〜とな」「〜なり」「〜にござる」「〜かの？」「〜ぞ」「〜よ」など。**「ござる」で終わる問は全体の40%以下**
- 答えそのもの（ひらがな・カタカナ・k の漢字）を問に入れない。答えの一部の漢字も避ける（「雪だるま」の問に「雪」と書かない）
- 同じ字数で別の答えが立たないよう、決め手を1つ入れる。悪い例「赤くて甘い果物」（りんご・いちご）→ 良い例「赤い粒々を身にまとう、春の甘い実」（いちご）
- 事実を誤らない。季節・色・数などは確かなものだけ書く。迷う事実は使わない
- 江戸の言葉（t3）は、知らない人でも問を読めば想像がつくように説明を足す：「手紙を担いで街道を駆ける、江戸の走り便」（ひきゃく）

例：
| r | k | t | c |
|---|---|---|---|
| さくら | 桜 | 1 | 春に咲き誇り、花見の宴の主役となる木じゃ |
| ふうりん | 風鈴 | 2 | 軒先でちりんと鳴り、夏の暑さをやわらげる音色よ |
| かわらばん | 瓦版 | 3 | 事件や噂を刷って町で売り歩いた、江戸の読み物にござる |
| ちょうちん | 提灯 | 2 | 竹の骨に紙を張り、中のろうそくで夜道を照らす道具なり |

## 検証
- `tools/validate-words.mjs`：上の決まりを機械で確かめ、分類・字数・難しさ・文末の内訳を表で出す。違反があれば一覧を出して exit 1
- `tests/unit/words.test.mjs`：検証関数を import して違反0件を確かめる
- 正規化は docs/ENGINE.md の `normalizeAnswer` と同じ規則（カタカナ→ひらがな、ぁぃぅぇぉっゃゅょゎ→大きい字、ALLOWED 外が残れば不採用）
