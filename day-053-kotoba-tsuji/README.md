# Day 053 ことば辻

盤がほぼ埋まった、江戸風の日本語クロスワード。空いた「辻」（縦と横の言葉が交わるマス）に、両方の言葉に合う一字を入れて盤を仕上げる。腕前は3段で、埋める字は手習い1・一人前7・免許皆伝15。登録も広告もなく、スマホで数十秒から数分で遊べる。

https://hundred-days.pages.dev/day-053-kotoba-tsuji/

## 遊び方

- タイトルの［いざ、参る］から腕前を選ぶ。朱の枠のマスが空いた辻で、ほかのマスには最初から答えの字が書いてある（押しても打っても消しても変わらない）
- 空いた辻を押すと、そこを通る横と縦の問が2段で出る。下の段を押すと縦と横が入れ替わる
- 字は下の五十音盤で入れる。濁る字は字のあとに「゛」、半濁りは「゜」。PCはローマ字でも書ける（neko → ねこ。「ん」は nn でも書ける）
- 小さい字（ゃゅょっ）は大きく書く（きゅうり → きゆうり）。日本のクロスワードの決まりに合わせた
- 見出しの帯に「残り n字」。困ったら「助太刀」（一字・一問まるごと）、「吟味」（違う字に朱の印）、「降参」
- すべて埋まると朱印「天晴」。かかった時間と助太刀の数で番付が決まる
- 結果の「果たし状を送る」で、同じ盤のリンクを友に出せる。秒の付いた果たし状から受けて立つと、差出人との決着が出る
- 途中でページを閉じても、タイトルの［続きから］で同じ盤に戻れる

## 作り

### 盤の生成

単語帳（`data/words.js`・679語。問はすべてこのアプリのために書いた）から、腕前ごとの語の数と辻の数を満たす盤を組む。手習いは5語・辻4・7×7、一人前は8語・辻9・9×9、免許皆伝は12語・辻15・11×11。値の正本は `lib/levels.js`。

盤は乱数の種（seed）だけで決まる。果たし状のリンク（`#c-<腕前>-<seed>-<秒>`）は種を運ぶだけなので、サーバーは要らない。新しい局は候補8つの種から、この端末で最近出た答え（最大60語）と重ならない盤を選ぶ。盤の組み方そのものは変えない。

### 空きの選び方

- 空きは辻にだけ置く。1字が縦と横の2つの問で裏付けられるので、当て推量にならない
- 免許皆伝は辻をすべて空ける。一人前は、どの言葉にも空きでないマスを最低1つ残し、1語に空きが偏らないように選ぶ
- 空きの乱数は盤の組み立てと別の系列にしてある。空きの数を変えても、同じ種なら同じ盤ができる

### 入力と見た目

- 端末のキーボードは使わない。漢字に変換されると1マス1字が崩れるので、五十音盤を自前で持つ
- 紙・墨・朱・藍・木の5つの素材だけで組む。開幕は藍の暖簾にした。歌舞伎の定式幕（3色の縞）は歌舞伎座の登録商標なので使わない
- 音は録音素材を使わず、Web Audio でその場で合成する

### 書体

Shippori Mincho B1（500・700・800）と Zen Kaku Gothic New（500・700）を同梱している（SIL Open Font License 1.1。`fonts/` に OFL.txt を添えた）。Google Fonts から読むと、アプリ配下のCSP（`font-src 'self'`）で止まるうえ、外への通信も生じるため。

画面に出る字（1,915字。一覧は `fonts/chars.txt`）だけに絞った woff2 で、5つで約1.8MB（明朝が各440〜460KB、ゴシックが各230KB）。問や台詞を足したら、`fonts.test.mjs` が一覧に無い字を知らせる。元の TTF を `tools/cache/` に置いて作り直す。

```sh
node day-053-kotoba-tsuji/tools/subset-fonts.mjs   # pyftsubset（fonttools・brotli）が要る
```

元の TTF は google/fonts の `ofl/shipporiminchob1/`・`ofl/zenkakugothicnew/` から取った（2026-09-30）。

### 通信と端末への保存

外への通信は無い。端末の localStorage に残すものは次のとおり。

- `kotoba-tsuji.settings.v1`：音・一問ごとの判定・動き・操作の案内を見たか
- `kotoba-tsuji.records.v2`：腕前ごとの解いた数・最速の秒数・最高の番付
- `kotoba-tsuji.current.v2`：途中の一局（盤の種・入れた字・経過時間など）
- `kotoba-tsuji.recent.v1`：最近出た答え（最大60語）

保存できない環境でも遊べる（記録が残らないだけ）。しつらえの「記録を消す」で番付の記録を消せる。

## テスト

- 単体：`node --test day-053-kotoba-tsuji/tests/`（盤の生成・対局の状態・かなとローマ字・番付・保存・果たし状・単語帳の決まり・問の折り返し・書体の字の一覧）
- E2E：`tests/e2e/day-053-kotoba-tsuji.spec.mjs`。答えはテスト用の窓口（`window.__KOTOBA_TEST__` を立てると出る `window.__kotoba`）から読む。外への通信は塞いで数え、1件でもあれば落とす
- 設計の文書は `docs/`（UX5・UX5-v2・ENGINE・COPY・VISUAL・WORDS・REQUIREMENTS）

## 分かっている課題

- 空きの残っていない言葉の字を押すと、カーソルと入力先がずれる
- 390px 幅で、問の文が語の途中で改行されることがある

## やらないこと

漢字のクロスワード、リアルタイムの対戦、ランキング・アカウント・広告・アクセス解析、夜の配色、BGM。
