# 「ことば辻」プロモーション動画

縦型1080×1920・34秒・BGM付きの動画を、アプリを実際に操作して撮る。絵コンテと秒は `timeline.mjs`、BGM は `promo-audio.mjs`、撮影から検査までは `render-promo.mjs` が受け持ち、アプリ本体（`index.html`・`app.*`・`lib/`・`data/`・`fonts/`）には手を入れない。土台は Day 052 の同名ツールで、下見と本番の二度通し、ページの中の時計で出す字幕、カチンコで決める頭の切り落とし、Day のフォルダを空きポートで配る作りはそこから引き継いだ。

## 1コマンドで、下見から検査まで約1分半

リポジトリ直下で実行する。ffmpeg・ffprobe と Playwright の Chromium が要る。

```sh
PLAYWRIGHT=/path/to/playwright/index.js \
  node day-053-kotoba-tsuji/tools/promo/render-promo.mjs --day 53
```

`PLAYWRIGHT` を省くと、このリポジトリの node_modules の playwright を読む。書き出すのは `promo.mp4`・`promo-first-frame.png`・`preview-contact.jpg`（2秒おき17コマ）・`promo-audio-a.wav`・`promo-audio-b.wav` で、どれも gitignore 済み。`--audio b` でB案を重ね、`--day` でエンドの Day 番号を変え、`--shots <dir>` で下見の各場面のスクショを残す。画面がロックされて Chromium が起動しないときは `KOTOBA_BROWSER=webkit` を付ける（WebKit ではまだ撮っていない）。検査に落ちても mp4 とシートは残るので、目で見てから直す。

## 字幕は iframe の上の帯に置き、盤・問・五十音盤に掛けない

対局の画面は盤・問の帯・五十音盤で縦がほぼ埋まり、Day 052 のように字幕を画面へ重ねる隙間がない。そこで撮影用の台紙（`STAGE_HTML`。ツールの配信が返し、ファイルは作らない）を540×960で開き、上の215pxを字幕の帯、その下の540×745にアプリの iframe を置いた。字幕の箱は安全域（上下左右10%）の上端と帯の下端の間に収まり、長い行は横幅に合わせて字を小さくする。注目の枠・指の輪・幕・エンドも台紙が描く。

## 場面の切り替えは暖簾の幕で隠し、組み替えの時間は書き出しで切り落とす

一人前から免許皆伝へ、免許皆伝から果たし状へ移るには、アプリの中で「退く→リンク→受けて立つ→途中の局を消す」と画面を何枚も通る。これを映さないよう、藍の暖簾が閉じている間（撮影では2.6秒と2.0秒）に組み替え、その時間を ffmpeg で切り落とす。ページの予定表はその間だけ動画の秒を止めるので、字幕・枠・音の秒は `timeline.mjs` の「動画の秒」のまま書ける。定式幕の3色の縞は歌舞伎座の登録商標なので、アプリの開幕と同じく藍一色にした。

## 乱数で決まる所は、押す直前の1回だけ固定する

腕前選びから始めた局の種は `crypto.getRandomValues` から作られる。一人前の札を押す直前にだけ、`randomSeed` が求める9語の配列を差し替えて `edo0d3` にする。案内役の台詞も候補から `Math.random` で選ばれるため、「二つとも解けたり」（手習い）・「いざ尋常に」（一人前）・「空いた辻は15か所」（免許皆伝）が出るよう、その1回だけ値を固定する。どれもアプリが実際に出す台詞で、結果の番付の一言だけは固定していない。

## 書体は同梱の fonts/ だけを使い、外へは取りに行かない

字幕とエンドも、アプリと同じ `fonts/` の書体（字の組を `fonts/chars.txt` の字に絞った woff2）で描き、外への通信はすべて断って記録する。絞った書体に無い字は別の書体で描かれて浮くので、字幕とエンドの字がすべて `chars.txt` にあるかを起動時に確かめ、無ければ止まる。いま無いのは「□」だけで、これは盤の空き辻と同じ朱の点線の枠を CSS で描いている。録画の前には `chars.txt` の字を全部の太さで並べて読み込ませ、撮影中に書体が差し替わらないようにしている。

## 盤の種は、一目で解けて1押しで書ける字で選んだ

| 腕前 | 種 | 選んだ理由 |
|---|---|---|
| 手習い | `edo01p` | 空き辻の縦が「ひよ□」、横が「□たつ」。答えの「こ」は1押しで書ける |
| 一人前 | `edo0d3` | エンジンが進める順に「た・な・さ・い」と書くと、1字ごとに言葉が1つ解ける |
| 免許皆伝 | `edo042` | 9×9で辻15がすべて空く。みの・まとい・いんろうなど江戸の言葉が入る |

単語帳か盤の組み方が変わると、同じ種でも別の盤になり、「1押しで書けない字です」か「画面と字幕が食い違っています」で止まる。選び直すときは `generatePuzzle` と `Game` で6字の種（`randomSeed` が6〜8字しか作らないため）の盤を組み、手習いは「空き辻を通る縦横2語が身近な語（単語帳の t1）で3〜4字、答えが1押し」、一人前は「進む順に4字とも1押しで、毎回言葉が1つ以上解ける」、免許皆伝は「空き15・縦横の差1以内・幅10以下」で絞る。

## 字幕の数字は画面と突き合わせ、食い違えば録画の前に止まる

`render-promo.mjs` の `SCREEN` が、下見と本番の両方で画面の文字を読む。**食い違ったら字幕を画面に合わせる。逆はしない。**

| 場面 | 字幕 | 照合する画面 |
|---|---|---|
| S1 | 1字で／縦も横も解ける | 台詞「二つとも解けたり」・解けた言葉2語 |
| S1 | 「天晴」の朱印 | 結果の朱印の字 |
| S2 | 埋める字 1・7・15 | 腕前の札の数字 |
| S3 | 埋める字が7つ | 見出し「一人前・埋める字7」と残り7。4字のあとは残り3・解けた言葉4語 |
| S3 | 縦と横、2つの問を | 問の帯が2段 |
| S4 | 免許皆伝は／辻がすべて空き | 見出し・辻の数と空きの数と盤の空き（15）・台詞「空いた辻は15か所」 |
| S5 | 果たし状で友に送れる | 書状の「果たし状が届いたでござる」「免許皆伝（埋める字15）」「5分12秒」 |

## 検査は書き出した動画そのもので測る（2026-09-30 の値）

| 検査 | 合格の条件 | 値 |
|---|---|---|
| 尺・寸法・形式 | 34±0.1秒・1080×1920・30fps・H.264/AAC | 34.000秒・すべて一致 |
| 音量 | −16〜−18 LUFS・真のピーク −1.5 dBTP 以下 | −17 LUFS・−2.1 dBTP（A案） |
| 冒頭の音 | 0〜0.3秒の RMS が −40 dBFS より大きい | −21.2 dBFS |
| 字幕の入れ替わり | 8回（エンドを含む）とも予定の±0.4秒 | 字幕は最大 +0.04秒、エンドは +0.10秒 |
| 1コマ目 | 手習いの盤で、光る空き辻のまわりが0.1秒後と違う（差が2より大きい） | 差 15.2 |
| 字幕の置き場所 | 安全域の内側で、盤・問・五十音盤などに重ならない | 違反0 |
| 押した時刻 | 予定より0.25秒以上遅れない | 遅れは最大0.01秒 |
| 幕・外への通信 | 閉じている間に組み替えが済む・外へ出ない | 済んだ（操作は約0.25秒）・0件 |

空き辻の光は1秒周期で脈打つ。-0.45秒に点けたら1コマ目が脈の山に当たり、差が2.2しかなかった。いまは-0.75秒に点け、縮むのがいちばん速い所を1コマ目に合わせている。押した瞬間の見た目は、音の刻みより0〜0.04秒（1コマ）遅れる。

## BGM：A案は陽音階の祭囃子、B案は都節の端唄

A案（既定）は D の陽音階（D・E・G・A・B）で、三味線の旋律に締太鼓・鉦・大太鼓が付く。B案は D の都節（D・E♭・G・A・B♭）で、琴の旋律に三味線・小鼓・大鼓・拍子木が付く。旋律は音階の段で書いてあるので、同じ節回しが音階によって明るくも陰りを帯びても聞こえる。曲の形は共通で、フックは拍子木と爪弾きだけ、腕前から太鼓が入り、一人前と免許皆伝で山を作り、果たし状で薄くなって、エンドは主音の和音とりんで終わる。

`node day-053-kotoba-tsuji/tools/promo/promo-audio.mjs --variant all` で両案を作り直し、`LIMITS`（hundred-days のプロモの BGM の決まり）と比べる。`--spectrum` を付けるとスペクトログラムを OS の一時フォルダに描く（このフォルダの .gitignore は png を1コマ目しか除外しないため）。測り方は ffmpeg の2極フィルタと astats の RMS に合わせた。低域（<120Hz）はどちらも全体比 −6.1 dB で、下限の −6 すれすれにある。大太鼓の胴鳴りが RMS を占めやすく、低音の三味線を D3 より下に置いたら −2 dB まで膨らんだ。そこで低音は120Hzより上に置き、仕上げで110Hz以下を下げている（A 5.5dB・B 3.5dB）。一人前の4字は大太鼓の拍に合わせ、打った直後は刻みを止めた（決め）。直前の拍の太鼓の余韻が前の区間に残り、正解の音が埋もれていたためだ。**人の耳ではまだ聴いていない。**

## 分かっている限界

- 録画は25fpsで、540×960で撮って2倍に拡大する。字の輪郭はやや甘い
- 画面の切り替わり（8.0秒・13.3秒）では、アプリの0.15秒のフェードで1〜2コマ和紙の地だけに近くなる
- アプリ自身の効果音は入らない。正解の音は BGM が受け持つ
- 結果の番付の一言は撮るたびに変わる。`--out` で別の名前にした mp4 は .gitignore の対象外になる
