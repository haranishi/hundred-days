# 名画の一部分から、30作品の図録へ

30秒の縦型プロモーション動画。増補版の公開後に使う下書きで、動画の生成はアプリの公開やSNS投稿を行わない。
元のアプリをローカルのiframeで操作し、撮影用に文字と余白を調整する。ゲームの判定や解説内容は差し替えない。

## 再生成

リポジトリのルートで実行する。既存のPlaywright、Chromium、ffmpeg、ffprobeを使い、外部サービスへのアップロードはしない。

```sh
node day-050-art-uncovered/tools/promo/render-promo.mjs --preview
node day-050-art-uncovered/tools/promo/render-promo.mjs
```

試し画像は無視対象の `tools/cache/promo/`、完成動画はこのフォルダの `promo.mp4`。
一覧ページ用には、同じ映像の冒頭18秒を720×1280にした `demo.mp4` をアプリ直下へ出力する。
中間画像は実行時に表示するOSの一時フォルダに残す。変更したゲームや作品データで再撮影するときは、冒頭の作品と出題数の検査を外さない。

## 絵コンテ

| 秒 | 実画面・構成 |
| --- | --- |
| 0–6 | 北斎の波の一部から始まり、3段階で全体へ。1コマ目から拡大解除の途中を見せる |
| 6–10 | 回答して、正解と作品全体を表示 |
| 10–16 | 制作背景・連作の狙い・所蔵館の出典までスクロール |
| 16–21 | 30作品の図録を巡り、ルノワールで検索 |
| 21–26 | 「二人の姉妹」の実画像と、モデルが姉妹ではないという解説 |
| 26–30 | 作品3点とアプリ名、「今日の5作品、見に行こう。」 |

字幕は16字以内、上下左右10%の安全領域内。音を出せない状況でも流れが分かるよう、字幕と実操作を対応させる。
BGMは本ツールのコードで新たに合成した音源。既存の曲や録音を使わず、アプリ本体に音楽機能があるとは表示しない。ナレーションはない。
