# Day 037「バイトの法律、原文はこう」

バイトで気になることを選ぶと、根拠になる条文の原文がそのまま出ます。

公開URL: https://hundred-days.pages.dev/day-037-baito-law/

## できること

- 10個の札から気になることを選ぶと、その根拠になる条文が出る
- 漢数字に算用数字のルビが振ってある（六箇月→6か月、四十五分→45分、十分の一→10分の1）
- 「使用者」＝雇う側、「労働者」＝働くあなた、を色で分けている
- いつ時点の条文かが出る。原典（e-Gov法令検索）へ直接飛べる
- 通信に失敗しても、原典へのリンクは残る

## やらないこと

**個別の判断をしません。** 勤務日数や雇用形態を入力させる機能はありません。
条文を並べて見せるところまでで、「あなたの場合はこうなる」とは言いません。

実際に困っている人には条文ではなく人が要るので、総合労働相談コーナー
（厚生労働省・全国378か所・無料・予約不要）を必ず案内します。

## 条文をどう扱っているか

**本文の文字列を1字も変えていません。** ルビと色は `<ruby>` と `<span>` を重ねるだけです。
`lib/kansuji.js` が返すのは「この範囲に、この読みを重ねる」という指示だけで、置き換えはしません
（`flatten(annotate(text)) === text` をテストで固定しています）。

漢数字にルビを振るのは**単位が続くときだけ**です。「一般」の般や「一部」の部は単位ではないので
素通りします。唯一ぶつかるのが「十分」で、あとに「な・に・だ・で・の」が続いたら「じゅうぶん」
として飛ばします。分数（「十分の一」）は分数として先に見ます。

## データ

条文は同梱していません。**法律は改正されるので、毎回 e-Gov 法令API から取ります。**

```
GET https://laws.e-gov.go.jp/api/2/law_data/{法令ID}?response_format=json&elm=Article_{条}
```

出典・ライセンス・加工した旨は画面の脚注に出しています。規約と法律面の確認の記録は
リポジトリ外（作成者のメモ）にあります。要点は次のとおりです。

- 条文そのものは著作権法13条1号により権利の目的とならない
- e-Gov のコンテンツとしては公共データ利用規約（PDL1.0）が適用される。出典の記載、
  加工した旨と主体の記載、国が作ったかのような見せ方の禁止
- 弁護士法72条がかかるのは「報酬を得る目的」での個別の鑑定・代理。無料で条文を出すだけなら外れるが、
  「あなたの場合は」と答えないことを設計の制約として固定している

## 原典リンクのアンカーについて

e-Gov 法令検索のページ内アンカーは**条番号から組み立てられません**。章番号が入ります
（労基法39条は `Mp-Ch_4-At_39`、民法627条は `Mp-Pa_3-Ch_2-Se_8-At_627`）。
`lib/topics.js` が10件ぶんを持っています。e-Gov 側の構成が変わると外れますが、
そのときもリンク先は正しい法令のページです。
