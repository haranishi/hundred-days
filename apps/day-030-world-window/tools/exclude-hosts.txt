# 直読み（<img>・<video>）を止める提供元のホスト名を、1行に1つ書く。
# ここに書いたホストは、実測の種別が img・hls でも page（提供元へのリンクだけ）へ落ちる。
# 地点そのものは地図に残り、押せば提供元のページが開く＝掲載をやめるのではなく、読み込みだけをやめる。
#
# 書くのは、次のどれかに当たったとき。
#   - 利用条件が埋め込み（hotlink・framing）を禁じている
#   - 出典表示やリンクなど、このアプリの画面では満たせない条件が付いている
#   - 提供元から掲載を控えてほしいと連絡があった
# どの条件をどこで読んだかは PROVIDER-TERMS.md に、確認したURL・逐語引用・確認日を添えて残す。
# 条件が見つからなかっただけのホストはここに書かない（「分からない」は「禁止」ではない）。
#
# 書き方: ホスト名だけ。www. は省いてよく、サブドメインにも当たる
#         （例: example.org と書けば cam.example.org も落ちる）。# 以降はその行の注記。
# 追加したら node tools/build-data.mjs を再実行して data/cameras.json を作り直す。

# 埋め込みを許していない提供元（2026-09-13 調査・逐語引用は PROVIDER-TERMS.md）
trafficnz.info        # NZTA: 複製の許可は「photography and imagery」に及ばず、個人利用を超える公開は事前の書面許可が必要
ctroads.org           # CTDOT: framing その他の手段による再配信・再公開を、事前の書面同意なしに禁止
hak.hr                # HAK: 許諾なしの複製・改変・公表を禁止（画像を配信している m.hak.hr も同じ）

# 条件はあるが、このアプリでは満たせない提供元
tirol.gv.at           # ティロル州: 個人的な情報取得を超える利用は事前申請が要る。単なるリンクは自由なので page なら条件を満たす
                      # （webcams. と luft. の両方に掛ける。Impressum は tirol.gv.at 全体の条件）
