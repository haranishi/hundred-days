# Day 043：退去費用、相談の準備

請求内容、相談したいこと、手元の資料をまとめる静的Webアプリ。
金額の妥当性や支払義務を判断せず、相談窓口へ持っていくメモを作る。

## 使い方

1. 退去・支払状況と、わかる金額を入力する。
2. 請求の費目と、気になる点を選ぶ。
3. 手元の資料が「ある／ない／未確認」か選ぶ。
4. メモをコピー、テキスト保存、または印刷する。PDFは印刷画面で保存先を選ぶ。

未回答でもメモを作れる。請求書の金額から敷金を自動で引かない。
内訳の合計が請求額と違う場合は、相談時の確認事項として知らせる。

## プライバシー

入力用の外部APIは使わない。氏名・住所・書類・自由記述も求めない。
下書き保存を選んだ場合だけ、`day043-consult-draft-v1` キーで端末内に保存する。
オフへの変更で端末の下書きを削除し、全消去では画面の入力も消す。
アプリ共有の本文・URLには入力を含めない。保存したテキストやPDFの管理は利用者が行う。

## 構成・開発

- `lib/model.js`：金額検証、内訳の整理、メモ生成、保存形式の検証。
- `app.js`：フォーム、メモ表示、コピー・保存・印刷。
- `app.css`：レスポンシブ表示と印刷スタイル。
- `shared/`：リポジトリ共通の紹介用共有ボタン。

リポジトリのルートで `npm run shared:sync`、`npm run build` を実行し、
`node scripts/serve-dist.mjs` でローカル確認する。ESモジュールのためHTTP経由で開く。
`meta.json` の `status` は既存ビルドへの収録指定であり、デプロイの実施記録ではない。

## テスト
