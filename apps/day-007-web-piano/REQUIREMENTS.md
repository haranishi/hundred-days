# Day 007 要件定義：ひといきピアノ

## 目的

休憩中にブラウザを開き、インストールや登録なしですぐ音を鳴らせるようにする。

## 主要アクション

画面の鍵盤またはPCキーを押して、単音や和音を演奏する。

## Day 1–10の範囲

- 外部依存、外部通信、保存は使わずブラウザ内で完結する
- 1つの公開URLと1つの主要アクションに絞る
- アカウント、課金、個人を特定できるデータを扱わない

## 必須要件

- C4からC6までの25鍵を表示する
- クリック、タッチ、PCキーボードで演奏できる
- 複数音の同時発音、サステイン、音量変更、全停止に対応する
- スマートフォンでは鍵盤部分を横スクロールできる
- 鍵盤をフォーカスし、EnterまたはSpaceでも演奏できる
- Web Audio APIで音を合成し、音声ファイルを同梱しない
- 録音、外部送信、Cookie、ストレージを使用しない

## 対象外

- 実物のピアノ音源の忠実な再現
- 録音、再生履歴、楽曲保存
- MIDI機器との接続
