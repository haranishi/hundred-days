# Day 010: いま、誰かが書き直している

世界中のウィキペディアで、いまこの瞬間に書き換えられている記事の**場所**が世界地図に立ち続けるページです。

公開URL: `https://hundred-days.pages.dev/day-010-wikipedia-live/`

## 見かた

開くだけで始まります。押すボタンは「音を出す」と「一時停止」の2つだけです。

- **地図のピン** = いま書き換えられた記事が指している場所。5分かけて薄れるので、**集中している地域ほど濃く**なります
- **いちばん書き換わっている場所** = 直近5分のピンを国ごとに数えて、いちばん多い国を名指しします
- **右（スマホでは下）の一覧** = 日本語版ウィキペディアの記事だけ。5〜6秒に1件なので記事名と直した内容が読めます
- **音** = 日本語版の編集が届いた時だけ鳴ります

読みたい編集を見つけたら一時停止してください。

## これは「編集した人の場所」ではありません

地図に立つのは、**書き換えられた記事そのものが持つ座標**です。「東京駅」が編集されれば東京に立ち、「カレーライス」は座標を持たないので立ちません。

世に多い「Wikipedia編集の世界地図」は、**匿名編集者のIPアドレスを地理変換**して人の居場所を出しています。このアプリはそのIPを受け取った時点で捨てているので、同じことはしませんし、できません。

実測すると、編集された記事のうち座標を持つのは**約18%**です。残りは地図に出せないので、その件数を画面に出しています。

## データの出どころ

- 編集: [Wikimedia EventStreams](https://stream.wikimedia.org/?doc)（認証不要の公開ストリーム）
- 座標: 各ウィキペディアの `action=query&prop=coordinates`。**言語版ごとにまとめて・2.5秒に1回まで・上位の言語版だけ**に絞って聞いています（日本語版は常に対象）
- 地図: Natural Earth 1:110m Admin 0 – Countries（パブリックドメイン）を間引いて同梱（176か国・63KB）

記事名と編集要約はウィキペディアの内容なので [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/deed.ja) です。

## 数えているもの・数えていないもの

数えるのは**編集（edit）と新規作成（new）**だけです。カテゴリへの追加やログ操作は数えません。編集の本文そのものは取得していないので、分かるのは増減したバイト数だけです。

一覧に出すのは日本語版ウィキペディア（`ja.wikipedia.org`）の記事本体だけです。

## 利用者名を表示しない理由

このストリームは、ログインせずに編集した人のIPアドレスを `user` フィールドにそのまま流します。受け取った時点で捨てていて、画面にも内部にも持ち込んでいません。編集要約に混ざったIPアドレスや利用者ページへのリンクは伏せ字（`●●●`）にし、「利用者名を伏せました」と表示します。

```bash
node --test apps/day-010-wikipedia-live/tests/
npx playwright test tests/e2e/day-010-wikipedia-live.spec.mjs

# 世界地図のデータを作り直す（手で実行するときだけ走る）

```

E2Eは上流のストリームにも座標APIにもつながず、`tests/fixtures/` の固定データを流し込みます。テストデータのIPアドレスは文書用に予約された範囲（RFC 5737 / RFC 3849）で、実在の編集者のものではありません。
