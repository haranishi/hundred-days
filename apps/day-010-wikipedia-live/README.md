# Day 010: いま、誰かが書き直している

世界中のウィキペディアで、いまこの瞬間に行われている編集が届き続けるページです。

公開URL: `https://hundred-days.pages.dev/day-010-wikipedia-live/`

## 見かた

開くだけで流れ始めます。押すボタンは「音を出す」と「一時停止」の2つだけです。

- **水面に落ちる粒** = 世界中の編集。毎秒13〜14件ほど届くので、数えるものではなく量として見るためのものです
- **右（スマホでは下）の一覧** = 日本語版ウィキペディアの記事だけ。だいたい5〜6秒に1件なので、記事名と直した内容が読めます
- **音** = 日本語版の編集が届いた時だけ鳴ります。大きい編集ほど低い音です。全部の編集で鳴らすと毎秒13回以上になるので鳴らしていません

読みたい編集を見つけたら一時停止してください。止めているあいだに届いた編集は数えません。

## データの出どころ

[Wikimedia EventStreams](https://stream.wikimedia.org/?doc) の公開ストリーム（`recentchange`）に、ブラウザから直接つないでいます。中継サーバーは置いていません。

記事名と編集要約はウィキペディアの内容なので [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/deed.ja) です。

## 数えているもの・数えていないもの

数えるのは**編集（edit）と新規作成（new）**だけです。カテゴリへの追加やログ操作は「編集」として数えません。編集の本文そのものは取得していないので、何がどう変わったかは分かりません。分かるのは増減したバイト数だけです。

一覧に出すのは日本語版ウィキペディア（`ja.wikipedia.org`）の記事本体だけです。ノートや利用者ページ、ウィクショナリーなどの別プロジェクトは一覧に出しません（世界の件数には入ります）。

## 利用者名を表示しない理由

このストリームは、ログインせずに編集した人のIPアドレスを `user` フィールドにそのまま流します。受け取った時点で捨てていて、画面にも内部にも持ち込んでいません。

編集要約にIPアドレスや利用者ページへのリンクが書かれていることもあるので、そちらは伏せ字（`●●●`）にしたうえで「利用者名を伏せました」と表示しています。表示するのは「人間かボットか」の区別だけです。

## 先にあった作品

同じ発想の [Listen to Wikipedia](https://listen.hatnote.com/) が先にあります。あちらは世界中の編集を音にする作品で、記事名までは読めません。このアプリは、世界の量を粒で見せながら、日本語版だけを読める形にしたものです。

## テスト

```bash
node --test apps/day-010-wikipedia-live/tests/
npx playwright test tests/e2e/day-010-wikipedia-live.spec.mjs
```

E2Eは上流のストリームにつながず、`tests/fixtures/stream.mjs` の固定イベントを流し込みます。テストデータのIPアドレスは文書用に予約された範囲（RFC 5737 / RFC 3849）で、実在の編集者のものではありません。
