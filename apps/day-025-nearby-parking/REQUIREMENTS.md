# Day 025 ちかくの駐車場 要件定義

## 1. 誰の何を解くか

**車で出かけた人が、着く前か着いた直後に「この辺に停められる場所はあるか」を知りたい。**
既存の地図アプリでも探せるが、駐車場だけを距離順に並べてはくれず、
有料か無料かも1件ずつ開かないと分からない。

**やらないこと**：満空情報（無料APIが存在しない）、料金の比較（データが無い）、
経路案内そのもの（Googleマップに渡す）、会員登録、履歴の共有。

## 2. ユーザーストーリー

1. 初めての街に着いた人が、**現在地から**近い順に候補を見て、いちばん近いところへ案内を始める
2. 出かける前の人が、**行き先の地名から**周辺の駐車場を見て、無料があるかだけ確かめる
3. 料金を気にする人が、**無料だけに絞って**、少し歩いてでも安く済ませられるか見る

## 3. UX5階層

| 層 | 決めたこと |
|---|---|
| 戦略 | 「近い順に、正直に」。分からないものを埋めない。空振りさせない |
| 要件 | 現在地/地名検索・地図とリストの同時表示・料金3値フィルタ・私有の除外・ルートへの受け渡し |
| 構造 | リストが主、地図が従。選択は双方向。0件なら半径を1度だけ広げる |
| 骨格 | 検索後はヒーローを1行に畳む。全件にルートを置く。件数は上限に当たったら「◯件中50件」 |
| 表層 | 4色以内・ライト/ダーク両対応・料金は色＋語＋記号の三重化（色覚特性に依存しない） |

**通した結果、実装が変わった箇所**：①全件にルートリンクを置いた（名前も料金も不明な駐車場が
多数あり、それでも位置だけは確実に分かるため、そこだけは必ず渡せるようにした）
②料金フィルタを「絞り込み」ではなくタブにした（3値のどれが何件あるかを先に見せる）
③リスト主導にした（当初は地図中心の案だったが、名前が無い駐車場が65%あり、地図上のピンだけでは
選べない）④フェイルオーバーを仕様に昇格した（実測で504が普通に出たため）
⑤表示を50件で打ち切り、打ち切ったことを件数表示に出した。

## 4. データの前提（実測 2026-08-31／2026-09-01）

| 項目 | 秋田駅400m圏 | 東京駅 |
|---|---|---|
| 件数 | 81件（800mまで広げると225件・1600mで500件） | 26〜224件 |
| `fee`（有料/無料） | 12/81件＝**15%**（全部 `yes`。`no` は0件） | **74%**（2026-08-31実測） |
| `charge`（金額） | **0%** | ほぼ0% |
| `opening_hours` | 0% | 2〜9% |
| `name` | 35% | — |
| `access`（私有等） | 44% | — |

→ 金額比較は成立しない。3値が無料APIで出せる正直な上限。

## 5. 外部APIの扱い（公開の条件）

**ブラウザから上流を直接叩かない。** Overpassは「全利用者の合計で数える」「常設なら1日100クエリ・
10MB未満」「識別できるUser-Agent」「キャッシュとレート制限」「429/406で30秒待つ」を、
Nominatimは「毎秒1件まで」「識別できるUser-Agent（ライブラリ既定は不可）」「結果のキャッシュ」を
求めており、ブラウザの `fetch` では満たせない。

`functions/api/day-025/parking.js` と `place.js` が満たすこと：

- 識別できるUser-Agent（`hundred-days-day025 (+公開URL)`）を付ける
- **座標を約110m四方に丸めて**からキャッシュキーにする（近い場所からの検索は上流に行かない）
- エッジで7日キャッシュ（`s-maxage=604800`）
- 画面が使うタグだけに削って返す
- 半径は800/3200だけ許可（任意の半径を通すと上流の負荷を制御できない）
- 上流の429/406は**追い打ちせず**、`Retry-After: 30` を付けて429で返す
- 引数が不正なら上流へ行かずに400

**保証していないこと**：Nominatimの毎秒1件は、エッジをまたぐ確実な制御ができないため保証しない。
上限に当たったら利用者にそう伝えて止まる。

## 6. 受け入れ条件

- ユニット：クエリ組み立て・引数検証・座標の丸め・タグの削り・フェイルオーバー・429の非再試行・
  半径拡大・表示上限・距離と単位・ルートURL・キャッシュキー
- E2E：現在地→地図とリストに同時／3値フィルタ／行の選択が地図に届く／ルートがGoogleマップを指す／
  0件で3200mまで広げるが往復2回／429で専用文言かつ叩き直さない／上限時に「◯件中50件」／
  **ブラウザから上流ホストへ1本も出ていない**
- 実ネットワーク：`wrangler pages dev` で中継APIごと通し、コンソールエラー0
- 公開前チェック5点（機械スキャン・目視・権利・ファクト・本番動作）
