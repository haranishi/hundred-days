# Day 033「揺れた？」

## 何をするか

**いまの揺れは地震だったのか。** 気象庁の発表を確かめ、1行で答えます。場所を選ぶと「揺れました」とあなたの街の震度、まだ発表が無ければ「15分以内の発表はありません」。きょう日本で震度1以上の地震が何回あったかと、過去24時間の帯も出します。

## なぜ作ったか

「いま揺れたのは地震か」をXで検索し直していることが出発点です。知りたいのは、自分の街が揺れたかとその震度。場所を選ぶ前にも全国の答えを出し、確かめるまでの手間を減らします。

## 答えの出し方

発表の一覧を地震の識別子ごとにまとめます。「いま」より後の発表を先に除き、取消がある地震、国外の地震、解説や更新のお知らせは数えません。

市区町村の震度を含む発表を優先し、まだ無いときは都道府県単位の第一報を使います。震源とMは、その情報を持つ最新の発表から補います。発生から15分以内の地震が複数あれば最新の1件を答えにし、ほかの件数を添えます。

市区町村は名前ではなくコードで照合します。政令市の区は20市へ寄せ、同じ市の複数の区で観測されていれば最大の震度を出します。東京23区は区のままです。「きょう」は日本時間の日付、帯は現在の時間帯を右端にした24コマ。日付の集計も時刻の表示も端末のタイムゾーンに左右されません。

## 設計上の判断

- **場所なしでも答えを出します。** 位置情報の許可を断っても、そのまま使えます。
- **発表が無いことと、揺れが無かったことを分けます。** 発表は揺れてから1〜5分かかる旨を添えます。
- **場所を変えても再取得しません。** 起動時とボタンを押したときだけ一覧を取り、前回の取得から20秒未満なら手元の一覧を使います。
- **地図は描きません。** 主役は答えの1行で、震源地とMは副文です。
- **第一報では街の震度を断定しません。** 県の震度を出し、市区町村ごとの発表を待っていると伝えます。
- **保存するのは場所だけです。** localStorageには市区町村コードと選び方だけを残します。座標は端末の外へ送らず、一覧も保存しません。

## 出典と規約

出典：[気象庁ホームページ 地震情報](https://www.jma.go.jp/bosai/map.html#contents=earthquake_map)を加工して作成。

[気象庁ホームページ利用規約](https://www.jma.go.jp/jma/kishou/info/coment.html)と[公共データ利用規約（第1.0版）の原文PDF](https://www.digital.go.jp/assets/contents/node/basic_page/field_ref_resources/f7fde41d-ffca-4b2a-9b25-94b8a701a037/24afdf33/20240705_resources_data_outline_05.pdf)に従い、出典と加工したことを画面にも明記しています。

仕様の継続や運用の案内が約束されたAPIではない一方、政府標準利用規約に準拠して利用できる、という気象庁担当者の説明を伝える記事：[MindTech](https://mindtech.jp/?p=1754)、[加納靖之「気象庁の新しい地震情報をみてみた」](https://note.com/ykano/n/n93ec73290e25)。これは2021年の説明の紹介で、現在の利用条件は上の公式規約を参照します。

- 市区町村名：[令和2年国勢調査（総務省統計局）](https://www.stat.go.jp/data/kokusei/2020/)
- 地点：[境界データ（総務省統計局・e-Stat統計GIS）](https://www.e-stat.go.jp/gis)の小地域重心から人口加重で独自に計算した代表点

地点データ1,741件はDay 032の同梱データをそのまま複製しました。新たな画像・フォント・音源や外部ライブラリは使っていません。

## 制約

**気象庁の発表そのものではありません。身の安全にかかわる判断は公式の情報で。** 緊急地震速報・津波情報は扱いません。震度1未満の揺れは発表に載りません。

外部データの取得は気象庁の一覧1本だけです。8秒で取得を中断し、形が変わった場合もエラーを出します。一覧には約30日ぶんしかないため、街の最後の地震はその範囲での表示です。観測が見つからない場合は最古の日付を添えます。自動更新はしません。

テストはユニット（`node --test apps/day-033-did-it-shake/tests/`。`TZ=UTC` でも同じ結果になることを含む）とE2E（`tests/e2e/day-033-did-it-shake.spec.mjs`）です。固定データは2026年9月8日に取得した実物の一覧365件で、E2Eとデモはこの一覧と止めた時計で動きます（例：秋田市で最後に揺れたのは8月27日 04:21・震度1・三陸沖 M6.1）。

デモは2026年8月23日 02:07 の水戸市を実データで再現しています（茨城県南部 M5.9・最大震度5弱・水戸市は震度4）。架空の地震は作っていません。
