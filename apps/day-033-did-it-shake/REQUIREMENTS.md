# Day 033「揺れた？」要件定義

**いまの揺れは地震だったのか。**ボタンを1回押すと、気象庁の発表を確かめて1行で答える。「揺れました。4分前、あなたの街は震度2」か「15分以内の発表はありません」か。その上に「きょう、日本で震度1以上の地震は◯回」の数字を置く。

## 背景と狙い

- 100日チャレンジ Day 33。S2（Lv.2）の3日目で、解禁表のとおり**外部API（無料・認証不要）を1個**だけ使う。その1個が気象庁ホームページの地震情報一覧（`https://www.jma.go.jp/bosai/quake/data/list.json`）
- 困りごとは「いま揺れた気がする。地震か、トラックか、自分か」。多くの人はXを開いて「地震」と検索する。答えは「揺れたか・どこで・どれくらい」の3つだけなのに、そこへ辿り着くまでにタイムラインを読まされる
- 差がつくのは地図でも警報でもなく、**「あなたの街の震度」を1行で返す**こと。震源の場所は副文で足りる
- 位置情報の許可より先に価値を出す。開いた瞬間に全国の答えを見せ、場所を選ぶとその街の震度に切り替わる
- 地名から座標を引く外部サービスは**使わない**。市区町村の代表点（1,741件）は Day 032 のものをそのまま同梱する

## 規約（2026-09-09 確認）

| 項目 | 確認した内容 |
|---|---|
| 認証・費用 | 不要・無料。気象庁ホームページの一部として配信されている JSON で、ブラウザから直接読める（`Access-Control-Allow-Origin: *` を実測） |
| 利用規約 | 気象庁ホームページの利用規約は「公共データ利用規約（第1.0版）」。複製・公衆送信・翻案が許され、条件は**出典の記載**と、**編集・加工したことの明示**。編集・加工した情報を「あたかも国が作成したかのような態様で」公表してはいけない |
| 出典の書き方 | 「出典：気象庁ホームページ 地震情報（URL）を加工して作成」。画面のフッターと README に置く |
| 「APIではない」 | 気象庁の担当者は「仕様の継続性や運用状況のお知らせを気象庁は約束していないという意味で、APIではない」が「政府標準利用規約に準拠して利用できる」と公に説明している（2021年・一次情報は README にリンク）。**仕様変更で止まる前提**で、取得の形が想定と違えば `error` に落として画面で伝える |
| 気象業務法 | このアプリが出すのは**観測された震度という過去の事実**であって予報でも警報でもない。緊急地震速報・津波情報は扱わない。「速報」「警報」という語を画面で使わない（第一報の意味では「第一報」と書く） |
| 負荷 | 一覧は `Cache-Control: max-age=60`。取得は開いたとき1回と、ボタンを押したとき。押しても前回から20秒未満なら再取得しない |

- 同梱する地点データの出典は Day 015・032 と同じ2つ。市区町村名は「令和2年国勢調査」（総務省統計局）、代表点は「境界データ」（総務省統計局・e-Stat統計GIS）の小地域重心から人口加重で独自計算
- ⚠️ 画面に「**気象庁の発表そのものではありません。身の安全にかかわる判断は公式の情報で**」を常設する

## データ（気象庁 地震情報一覧）

一覧は直近の発表が新しい順に並ぶ（実測 365件・2026-08-10〜09-08 の約30日分）。使う項目は次のとおり。

| 項目 | 意味 | 使い方 |
|---|---|---|
| `eid` | 地震の識別子 | 同じ地震の複数の発表をまとめるキー |
| `ttl` | 発表の種類 | 下の表 |
| `ift` | 発表／訂正／取消 | 「取消」が1件でもある `eid` は数えない |
| `rdt` | 発表時刻（`+09:00`） | **`rdt` が「いま」より後の発表は無いものとして扱う**（固定時計のテスト・デモと本番を同じコードで動かすため。端末の時計が数秒遅れていても、遅れる分だけ表示が遅れるにすぎない） |
| `at` | 発生時刻（`+09:00`） | 「◯分前」「きょう」「帯」の基準 |
| `anm` / `mag` / `cod` | 震源地名・マグニチュード・座標と深さ | 副文。`cod` は `+32.4+130.4-10000/` の形で末尾が深さ（m）。深さは出さなくてよい |
| `maxi` | 最大震度（`1`〜`4`・`5-`・`5+`・`6-`・`6+`・`7`） | 並び順はこの配列で持つ。表示は「5弱」「5強」「6弱」「6強」 |
| `int[]` | 都道府県ごとの震度。`code`=都道府県2桁・`maxi`・`city[]` | `city[].code` は市区町村コード5桁＋`00`（例 `0520100`＝秋田市）。政令市の区は区コード（例 `4310300`＝熊本市中央区） |

| `ttl` | 中身 | 扱い |
|---|---|---|
| 震源・震度情報 | 震源・M・都道府県と市区町村の震度 | **本命**。同じ `eid` に複数あれば `rdt` の新しいほう |
| 震度速報 | 震度3以上のとき、揺れの1〜2分後に地域単位で出る。`int[].city` は空、`mag`・`anm` は無い | 「震源・震度情報」がまだ無い `eid` では**第一報**として使う（都道府県単位の震度だけ分かる） |
| 震源に関する情報 | 震源・M。震度は無い | 震源・M の補完にだけ使う |
| 遠地地震に関する情報／南海トラフ地震関連解説情報／顕著な地震の震源要素更新のお知らせ | 国外の地震・解説・更新 | 数えない |

### 市区町村コードの照合（`lib/towns.js`）

- `city[].code` の先頭5桁が同梱データ（`data/places.json` の `c`）にあれば、その市区町村
- 無ければ**政令市の区**なので市へ寄せる。同じ都道府県の政令市（`01100 04100 11100 12100 14100 14130 14150 15100 22100 22130 23100 26100 27100 27140 28100 33100 34100 40100 40130 43100` の20市）のうち、区コード以下で最大のもの。例：`14104`（横浜市中区）→`14100` 横浜市、`14131`（川崎市川崎区）→`14130` 川崎市、`27141`（堺市堺区）→`27140` 堺市、`43103`（熊本市中央区）→`43100` 熊本市。東京23区は同梱データに区として入っているので直接一致する
- 固定データの一覧に含まれる区コードは117種類。**全部がどこかの政令市に解決すること**をユニットで固定する
- 都道府県の一致（第一報のとき）は `place.c` の先頭2桁と `int[].code`

## ユーザーストーリー

| ユーザー | 欲しいことと理由 | 受け入れ条件 |
|---|---|---|
| いま揺れた気がした人（本命） | 地震だったのか、1秒で知りたい | 開くと何も押さなくても全国の答えが出る。場所を選んであれば「揺れました／観測されていません」が見出しになる |
| 揺れの直後に開いた人 | まだ発表が無いことを、地震が無かったことと混同したくない | 「15分以内の発表はありません」と、発表が1〜5分遅れることを一緒に出す。「地震はありませんでした」とは言わない |
| 位置情報を許可したくない人 | 現在地を渡さずに使いたい | 市区町村を選べる。選んだ場所は次回も残る。全国の答えは場所なしで出る |
| 「震度いくつだった？」と聞かれた人 | 自分の街の数字を言いたい | 見出しに「あなたの街は震度◯」。震源の街ではなく自分の街 |
| 地震が多い気がしている人 | 感覚を数字にしたい | 「きょう◯回」と24時間の帯。毎日いくつも揺れている事実がひと目で分かる |
| 引っ越してきた人 | この街はよく揺れるのか知りたい | 「あなたの街で最後に揺れたのは◯月◯日（震度◯）」。一覧の期間（約30日）の範囲で |
| 結果を人に言いたい人 | 「きょう日本は◯回揺れた」を共有したい | 回数と答えの入った投稿文が出る |

## UX5階層

- **戦略**: 防災アプリではなく**「いまの揺れは地震だったか」の1問**。成功＝開いて1秒で「揺れました／観測されていません／発表はまだ」のどれかが読めること。失敗＝地図・震源リスト・警報を並べて、結局ユーザーがXで検索し直すこと。差別化の源泉は「あなたの街の震度を1行で返す」の一点
- **要件**: 載せるもの＝いま揺れた？ボタン、答えの1行、副文（発生時刻・震源地・M・最大震度）、場所（現在地／市区町村／未設定）、きょうの回数、24時間の帯、あなたの街で最後に揺れた日、直近の一覧（折りたたみ）、出典と但し書き。対象外＝地図、緊急地震速報、津波、通知・音、震源の深さ、海外の地震、長周期地震動
- **構造**: 単一画面で `loading → ready` ＋ `error`。**場所は任意**で `none / current / picked` の3値。場所を変えても再取得しない（取得済みの一覧から計算し直す）。ボタンは再取得。取得は開いたとき1回と押したとき、前回から20秒未満なら再取得せずに「◯秒前に確認」と出す
- **骨格**: いちばん大きい要素は**答えの1行**（見出し級・ページ内で最大の文字）。次にバッジ「あなたの街は震度◯」、回数の数字はそれより小さくする。場所が未設定のあいだは主ボタンを「市区町村から選ぶ」に入れ替え、「いま揺れた？」は枠線のボタンにする。その真下に副文と「あなたの街は震度◯」。次に「いま揺れた？」ボタン（幅いっぱい・56px以上）。その下に場所の行、きょうの回数と帯、あなたの街の最後、折りたたみの一覧、フッター。上から下へ「答え→確かめ直す→場所→背景の数字」の順
- **表層**: 落ち着いた夜の紺と白。地は白に近い灰（`#f5f6f8`）、文字は墨紺（`#1c2430`）。答えが「揺れました」のときだけ見出しの下地を薄い橙（`#fbe9d7`）に、「ありません」は薄い青灰（`#e8eef5`）。震度の色は**気象庁の震度配色**（1 `#f2f2ff`・2 `#00aaff`・3 `#0041ff`・4 `#fae696`・5弱 `#ffe600`・5強 `#ff9900`・6弱 `#ff2800`・6強 `#a50021`・7 `#b40068`）を帯と震度バッジに使い、**色だけに頼らず必ず数字を添える**（震度1は白に近いので枝線を付ける）。動きは、ボタンを押したあと答えの1行が下から現れる1つだけ。`prefers-reduced-motion` では即時表示

### UX5階層を通したことで決まった実装（9件）

1. **場所なしでも答えを出す**（戦略・構造）。位置情報の許可ダイアログより先に「◯分前、熊本県天草・芦北地方で地震がありました」が出る。許可を断られてもアプリは成立する
2. **「発表はありません」と「地震はありませんでした」を区別する**（要件）。気象庁の発表は揺れの1〜5分後。直後に開いた人へ「ありませんでした」と言うのは嘘になる。文言は「15分以内の発表はありません。発表は揺れてから1〜5分かかります」
3. **主役は答えの1行、震源とMは副文**（骨格）。震源地名を見出しにすると「熊本で地震」という他人事のニュースになる。見出しは「揺れました」か「観測されていません」
4. **第一報だけの段階を分ける**（要件・構造）。震度3以上のとき最初の1〜2分は都道府県単位の震度しか無い。市区町村が出ていないのに「観測されていません」と言わず、「第一報：あなたの県で震度◯以上」と出す
5. **街の判定はコードで機械照合、政令市の区は市へ寄せる**（構造）。名前の部分一致は「上天草市」と「天草市」のような取り違えを起こす。同梱データに区が無いことは Day 031 で分かっている
6. **取得は1本、押しても20秒は再取得しない**（構造）。一覧は60秒キャッシュなので連打しても新しくならない。押した手応えは「◯秒前に確認」の更新で返す
7. **地図を描かない**（要件）。地図を置いた瞬間に防災アプリに見え、公式の情報と誤認されやすくなる。位置関係より「自分の街が揺れたか」
8. **「きょう◯回」と24時間の帯を答えの下に常設する**（戦略）。日本は毎日数回揺れている。この数字が共有の核で、地震の無い日でも開く理由になる
9. **「いま」より後の発表は無いものとして扱う**（構造）。本番では起きないが、固定時計のE2E・デモ・プロモが本番と同じコードで動く。8月23日 02:05 の画面（第一報だけ）と 02:07 の画面（市区町村の震度あり）を同じ一覧から再現できる

## 判定（`lib/quakes.js`・純関数・DOMに触れない）

### まとめ方

```
一覧 → 「いま」より後の発表を除く → 国外・解説・更新を除く → eid ごとにまとめる
  intensity = 市区町村つきの震度（震源・震度情報）の最新
              無ければ 震度速報 の最新（provisional=true・都道府県単位）
  hypo      = mag を持つ発表の最新（震源・震度情報 か 震源に関する情報）
  取消が1件でもあれば除く。intensity が無い eid（震源に関する情報だけ）は数えない
```

### 答え

`answer({ events, now, place })` は次を返す。`RECENT_MINUTES = 15`。

| kind | 条件 | 見出し | 副文 |
|---|---|---|---|
| `shook` | 15分以内の地震があり、`place` の市区町村が `city[]` にある | 揺れました | 「◯分前（HH:MM）に発生。震源 ◯◯ M◯・最大震度◯」＋バッジ「あなたの街は震度◯」 |
| `shook-pref` | 15分以内の地震が**第一報のみ**で、`place` の都道府県が `int[]` にある | 揺れました（第一報） | 「◯分前・あなたの県で震度◯以上を観測。市区町村ごとの発表を待っています」 |
| `elsewhere` | 15分以内の地震があるが、`place` の市区町村（第一報なら都道府県）が無い | あなたの街では、観測されていません | 「◯分前に◯◯で地震（最大震度◯・M◯）」。第一報なら「震度◯以上の揺れを観測（第一報）」 |
| `recent` | 15分以内の地震があり、`place` が無い | ◯分前、地震がありました | 「◯◯・M◯・最大震度◯」＋見出しの下に「あなたの街は未設定。場所を選ぶと震度が出ます」 |
| `none` | 15分以内の地震が無い | 15分以内の発表はありません | 「発表は揺れてから1〜5分かかります。少し待って、もう一度押してください」＋別行で「最後の地震：◯時間前 ◯◯（最大震度◯）」 |

- 15分以内が複数あれば最新の1件を主役にし、副文に「ほかに◯件」
- `place` があって震度が出ていないとき（`elsewhere`・`none`）だけ、小さく「震度1未満の揺れは発表に載りません」
- 相対時刻：1分未満「いま」、60分未満「◯分前」、24時間未満「◯時間前」、それ以上「◯日前」。絶対時刻は同じ日なら「HH:MM」、前日以前は「◯月◯日 HH:MM」

### 数字

- `todayCount`: `at` の日本時間の日付が「いま」と同じ地震の数（`eid` 単位・国内・震度1以上）
- `strip`: 「いま」を含む時間帯を右端にした24コマ。各コマは `{ hourStart, count, maxi }`（`maxi` はそのコマで最大の震度、無ければ `null`）
- `lastAtYourTown`: `place` の市区町村が `city[]` に出る最新の地震と、その街の震度。答えに出ている地震は除く（同じ事象を2回言わない。文言は「その前にあなたの街で揺れたのは」）。無ければ `null` と、一覧の最古の `at`（「◯月◯日以降、観測なし」の期間表示に使う）
- `recentList`: 国内の地震を新しい順に10件（時刻・震源地・M・最大震度）

## 機能要件

### 画面と状態

- `<main id="app" data-state="loading|ready|error" data-place="none|current|picked">`
- **loading**: 「気象庁の発表を確かめています…」。300ms 未満なら出さない
- **ready**:
  - `#answer` 答えの1行（見出し級）。`data-kind` に kind を持つ
  - `#answer-sub` 副文、`#your-intensity` 震度バッジ（該当時）、`#fine-print`「震度1未満の揺れは発表に載りません」（場所あり時）
  - `#check` ボタン「いま揺れた？」（幅いっぱい・高さ56px以上）。取得中は `disabled` で「確かめています…」。直下に `#checked-at`「◯秒前に確認（発表 HH:MM）」
  - 場所の行：`#place-name`（「秋田県秋田市」「現在地（秋田市あたり）」、未設定なら「場所」）＋ `#use-location`「現在地」＋ `#pick-place`「市区町村から選ぶ」＋ `#clear-place`「場所を外す」（設定時のみ）
  - `#today-count` きょうの回数（数字を大きく）＋ `#today-label`「きょう、日本で震度1以上の地震」
  - `#strip` 24コマの帯（`role="img"`・`aria-label` に文章の説明。例「24時間で7回。最大は21:02の震度2」）と震度の凡例
  - `#your-town` あなたの街の最後（場所あり時）：「あなたの街で最後に揺れたのは 8月27日 04:21（震度1・三陸沖 M6.1）」または「8月10日以降、震度1以上は観測されていません」
  - `#recent` `<details>`「直近の地震（10件）」：時刻・震源地・M・最大震度の表
  - `#post-result`「この結果をXに投稿」（`shared/share.js` の投稿と同じ導線。文面は「『揺れた？』きょう日本で震度1以上の地震は◯回。＋答えの1行」）
- **error**: `role="alert"`。見出し「発表が取れません」（答えと同じ大きさ・1行に収まる長さ）＋ `#retry`「もう一度確かめる」。形が想定と違うときも同じ画面で「発表の形が変わったようです」
- **場所選び**（`<dialog id="place-dialog">`）: Day 032 と同じ都道府県→市区町村の2段セレクト。`places.json` は開いたときに初めて読む
- **現在地**: `navigator.geolocation` → 同梱データでいちばん近い市区町村。座標は端末の外に出さない（画面にもその旨を1行）。拒否・失敗は `#geo-note` に理由を出して、場所なしのまま続ける

### 通信（`lib/jma.js`）

- `GET https://www.jma.go.jp/bosai/quake/data/list.json`。8秒で諦める。配列でなければ形の不一致として失敗にする
- 前回の取得から20秒未満の再取得はしない（呼び出し側が判断できるよう、取得時刻を返す）
- 取得できた一覧は画面が開いている間だけメモリに持つ。保存しない

### 保存（`lib/store.js`）

- `localStorage` に最後の場所（`{ code, mode: 'picked' | 'current' }`）だけ。定数名は `STORAGE_NAME`（`key` を含む名前は使わない）。使えない環境でも動く
