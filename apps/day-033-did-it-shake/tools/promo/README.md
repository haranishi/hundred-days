# 「揺れた？」プロモーション動画

Day 032 の同名フォルダを複製し、Day 033 の絵コンテ・操作・固定応答・配色へ差し替えた生成ツールです。1コマは時刻 t の純関数のHTML合成。Playwrightで連番撮影し、ffmpegで36秒・1080×1920・30fpsのMP4にします。アプリ本体は変更せず、iframe内のDOMに合成用の動きを上書きします。

## 人間が描画するとき

リポジトリのルートから実行します。Node.js、Chromiumを導入済みのPlaywright、ffmpeg、ffprobeが必要です。依存パッケージの追加はありません。

```sh
PLAYWRIGHT=/path/to/playwright/index.js node apps/day-033-did-it-shake/tools/promo/render-promo.mjs --preview
PLAYWRIGHT=/path/to/playwright/index.js node apps/day-033-did-it-shake/tools/promo/render-promo.mjs
```

出力はこのフォルダの `preview-contact.jpg`、本番は `promo.mp4`・`promo-first-frame.png`・`promo-audio.wav` です。部分確認は `--from 18.4 --to 24.4`、別の動画出力先は `--out <絶対パス>`。空きポートのローカルHTTPサーバーで配信します。今回の実装作業では画像・動画・音声ファイルを生成せず、実描画は未確認です。

本番描画ではWAVが無いときだけA案を自動合成します。場面や音を変えた後は、先に明示的に再生成してください。

```sh
node apps/day-033-did-it-shake/tools/promo/promo-audio.mjs --variant a
```

## 固定するもの

- 時計は `FIXED_NOW = '2026-08-23T02:07:00+09:00'`。`page.clock.setFixedTime` で止めます。
- 場所は `PLACE_CODE = '08201'`、`PLACE_LABEL = '茨城県水戸市'`。起動前にlocalStorageの `day-033-did-it-shake` へ `{ "code": "08201", "mode": "picked" }` を書きます。S4だけ保存場所を外して起動し、選び直します。
- `context.route('https://www.jma.go.jp/**', ...)` が `tests/fixtures/jma-list-2026-09-08.json` を返します。実通信で発表を取りません。固定時計より未来の発表はアプリ自身が除外します。
- 画面は「揺れました」「あなたの街は震度4」、副文は「7分前（02:00）に発生。震源 茨城県南部 M5.9・最大震度5弱」。きょうは1回、24時間の帯の右端は5弱、直近の一覧は10件です。実データの過去時点の再現です。
- `known` は `127.0.0.1:<port>` と `www.jma.go.jp`。想定外のホストは描画後に報告します。
- 撮影は `reducedMotion: 'reduce'`。アプリの `rise` は使わず、`overrideApp` / `setEntrance` で見出し・バッジ・帯の動きを毎コマ決めます。

## 操作と確認点

- **0秒がXのサムネです。** タップは−0.08秒、見出しは−0.12秒、バッジは−0.09秒から出現。0秒には押した指と両方の文言が出現途中で見える設計です。見出しの読みやすさと指の重なりを最初に確認してください。
- `ready` は場所なしでも待ちます。場所ありでは非同期の保存場所復元も待ち、`data-place="picked"`・`data-kind="shook"`・水戸市名・震度4を確認してから撮ります。
- 指の的は `#check`・`#pick-place`・`#place-confirm`・`#recent > summary`・`#pref-select`・`#town-select`。S4のタップは19.1、20.3、21.5、22.7秒。22.92秒に確定し、その直後の指は閉じる前のボタン矩形を使います。
- OSのネイティブ選択メニューは撮りません。県・市区町村の値とchangeイベントを段階別に適用し、セレクトへの指・輪・フォーカスで選択を見せます。茨城県へ切り替えると水戸市が先頭候補として表示されるため、市区町村タップでは同じ水戸市を選びます。
- S2は答えを中央へ寄せます（上へのスクロール限界では0）。S3は回数〜凡例の中央、S4は場所の行、S5は最後の揺れの上22pxを基準にし、合成側でページ末尾の余白を確保して表の開閉前後をそろえます。**実描画でスクロール位置、表10行の収まり、開閉時の跳ね、ダイアログ前後の指の的を確認してください。**
- `__seek(t)` で任意の時刻を描けます。逆順のシークでも同じ画になるか、場面の切り替わりも確認してください。フォントは端末のシステムフォントなので環境によって折り返しが変わります。
- 字幕のはみ出し、エンドURL、出典を読める時間、意図しない通信の有無を確認してください。音量は今回未実測です。試聴時はS5が落ち着くこと、タップ音と指の同期も確認してください。

## BGM

Day 032の純JS合成を継承しています。外部音源・サンプル・依存ライブラリは使いません。A案はローファイのエレピ、B案は撥弦音。固定シード・Fメジャー・92 BPM・48kHz・16bit・ステレオです。`SECTION` はS1タイトル、S2答え、S3帯、S4場所、確定タップ、S5最後の揺れ、S6約束、S7エンドへ対応します。拍への丸めは従来どおり最大約0.33秒。`RESULT_START` はいちばん静かにするS5の24.4秒です。
