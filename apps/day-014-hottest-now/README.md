# Day 014「いま、日本でいちばん暑い場所」

https://hundred-days.pages.dev/day-014-hottest-now/

気象庁アメダスの実測気温を10分ごとに受け取り、**いま**日本でいちばん暑い場所と寒い場所、
そして自分の街が全国で何番目かを出します。予報ではありません。

## 地図は海岸線を持っていない

**地図データを一切読み込んでいません。** アメダス1,286地点を緯度経度どおりに置くと、それだけで
日本列島の形になります。地図そのものが観測網の姿なので、線を引くより点を置くほうが正しい。
点の色はその地点のいまの気温です。

- 点を押すと、その土地に寄って、気温と全国順位が出る
- 地方のボタンで行き先を選べる。寄ると地名が読める
- **南西諸島は全体表示のときだけ別枠**に出し、寄ったら本物の緯度経度に切り替える
  （別枠のままだと、そこだけ「行けない場所」の絵になってしまう）
- 地名を出すかどうかは拡大率ではなく**画面に見えている点の数**で決める。
  広くても点が少ない場所は、寄らなくても名前が読めたほうがいい

## 作りの要点

- 気象庁が配っている静的ファイル3つ（最新時刻・地点表・観測値）だけを読む。
  `access-control-allow-origin: *` が付いているので中継サーバーは置いていない
- 現在地は最寄りの観測所を選ぶ計算にだけ使い、どこにも送らない
- 1時間前の同じファイルも読んで増減を出す。取れなくても画面は成立する

## 数字の扱いで気をつけたこと

- **順位の母数は気温が読めた地点だけ。** 2026-08-21時点では全1,286地点のうち370地点が雨量などしか
  測っていない。品質フラグが立っている値も採らない。地点は増減するので、画面の数字はその日の実数を出している
- **同率は競技方式**（1, 2, 2, 4）。0.1℃刻みで900地点以上あるので同率はほぼ必ず起きる
- **いちばん寒い場所は、ほぼ毎回、山の上**になる。標高を併記し、標高1,000m未満に限った最低気温も出す
- 都道府県は地点番号の上2桁（気象庁の府県ブロック）から引いている。
  配信データに県名が無いための推定で、県庁所在地47地点と全国の著名地点45地点で照合して合わせた
- 表示は**速報値**。あとで訂正されることがある

出典：[気象庁ホームページ](https://www.jma.go.jp/bosai/map.html#contents=amedas)

気象庁の「公共データ利用規約（第1.0版）」は、出典の記載に加えて、**編集・加工した場合はその旨を
出典とは別に書くこと**と、**国が作成したかのように見せないこと**を求めている。順位・気温差・
都道府県名はいずれもこちらの計算なので、画面の末尾にその旨を明記している。
