# Day 002 — ドット絵メーカー

画像を1枚入れるとドット絵に変換して、PNGで保存できるツール。

## 使い方

- 画像をドロップする（ドロップゾーンをクリックしてファイルを選んでもよい）
- スライダーで横のドット数（8〜128）を変える。減色は「なし / レトロ8色 / 緑4階調」の3つ
- 「PNGで保存」で書き出す（ファイル名は `dot-art-48dot.png` の形式）

## 制約（このチャレンジの「1日アプリ」ルール）

- 外部ライブラリ・外部フォント・外部APIなし（ブラウザ内蔵APIのみ）
- 画像はブラウザの中だけで処理し、どこにも送信しない
- データ保存なし・アカウント不要・課金なし

## 技術メモ

- 変換は2段階。オフスクリーンcanvasへ「横Nドット」に縮小 → 表示用canvasへ `imageSmoothingEnabled = false` で最近傍拡大
- 表示しているcanvasをそのまま `toBlob` で書き出すので、画面とPNGが一致する。拡大は整数倍のみで、長辺が1024pxに最も近くなる倍率を選ぶ
- 縮小は半分ずつ段階的に行う（一気に縮めると細部が飛ぶため）。読み込んだ画像は長辺2048pxに丸めてから使い回す
- 減色は、レトロ8色＝RGB距離が最小の色を選ぶ／緑4階調＝輝度を4等分して割り当てる
- 画像は `FileReader` でデータURLにしてから `<img>` に渡す。file:// で開いても読めて、canvasが汚染されないため `getImageData` と `toBlob` が使える
