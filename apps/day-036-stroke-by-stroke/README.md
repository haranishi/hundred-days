# Day 036「一画ずつ」

名前や言葉を入れると、その字が筆順どおりに一画ずつ書かれていきます。

公開URL: https://hundred-days.pages.dev/day-036-stroke-by-stroke/

## できること

- 8字まで入れて「書く」を押すと、1字目の1画目から順に書かれる
- まだ何も書いていないときは「たとえば」の3語が出て、押すとそのまま書ける
- 速さは3段（ゆっくり・ふつう・はやい）。書いている最中でも変えられる
- いま何画目か・全部で何画かが出る
- これから書く画を薄い下書きで出す／画の番号を出す／筆の音を鳴らす、の切り替え
- 書き終わったものを動画とPNGで保存できる
- 前に書いた言葉を5つまで覚えて、押すとすぐ書き直せる（「たとえば」と同じ場所に出る）
- 筆順データの無い字は、そのマスだけ破線の枠と断り書きにして、残りの字は書く

## 筆づかい

KanjiVG のパスは線の中心を通る1本の線なので、そのまま引くと均一な太さになります。
このアプリは道のりの位置ごとに太さを変えた輪郭（多角形）を組んで塗っています。

終わり方は KanjiVG が持つ画の種別から決めています。

| 種別 | 終わり方 |
|---|---|
| ㇒ ㇓ ㇖ ㇛ ㇜ ㇀ ㇇ ㇗ | 細く抜く（払い・提） |
| ㇆ ㇚ ㇟ ㇁ ㇂ ㇃ ㇈ ㇉ ㇋ ㇞ ㇡ | 跳ねる |
| ㇏ | 送りで太らせてから抜く（捺） |
| それ以外 | 太さを保って止める |

## データ

筆順データは同梱で、外部APIは使いません。出典とライセンス、作り直し方は
[`data/SOURCES.md`](data/SOURCES.md) に書いてあります（**KanjiVG・CC BY-SA 3.0**）。

## 動かす

このディレクトリを配信して開きます（`data/kvg/*.json` を読むので `file://` では動きません）。

```
npx serve .
```
