# Day 022「その備蓄、何日もつ？」

水・食料・簡易トイレの手持ちを、家全体で何日もつかに換算する1画面の道具です。いちばん先に尽きるものと、3日／7日の目標までに足す量を表示します。

## なぜ作ったか

備蓄品の一覧を作るだけでは、種類ごとの単位が違うため「家全体で何日もつか」が見えにくいと感じました。水・食料・簡易トイレを同じ日数に換算し、次に足すものを1つ決められる形にしました。不安を強める表現ではなく、今ある量から始められることを重視しています。

## 設計上の判断

- 必須3行は公的資料の目安だけを使い、年齢係数など根拠のない数字は作りません。
- 乳幼児、ペット、薬など家庭ごとに違うものは追加の行にし、1日の量を本人が決めます。
- 期限は品目台帳にせず、行ごとのいちばん早い日付1つだけを扱います。
- 入力は端末内の `localStorage` だけに保存し、外部へ送信しません。保存できない環境でも計算は続けます。

## 数字の出典

- [首相官邸「災害が起きる前にできること」](https://www.kantei.go.jp/jp/headline/bousai/sonae.html?vm=r) — 飲料水1人1日3L、3日分、大規模災害では1週間分
- [農林水産省「災害時に備えた食品ストックガイド」](https://www.maff.go.jp/j/zyukyu/foodstock/chapter01.html) — 食品は最低3日〜1週間分×人数分
- [内閣府「避難所におけるトイレの確保・管理ガイドライン」](https://www.bousai.go.jp/taisaku/hinanjo/pdf/1605hinanjo_toilet_guideline.pdf) — 便袋は1人1日5回

## やらないこと

- 品目ごとの在庫台帳、バーコード、期限通知
- 年齢・性別による必要量の補正
- 生活用水・燃料・電源の必要量計算
- 商品推薦、買い物リンク、アフィリエイト
- アカウント、同期、サーバー保存
