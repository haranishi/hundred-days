# 「潮、いまどっち？」プロモーション動画

Day 033 の同名フォルダの7ソースを複製し、Day 034 の絵コンテ・操作・固定応答・配色へ差し替えた生成ツールです。1コマは時刻 t のHTML合成。Playwrightで連番撮影し、ffmpegで36秒・1080×1920・30fpsのMP4にします。アプリ本体は変更せず、iframe内のDOMに合成用の動きを上書きします。

## 人間が描画するとき

リポジトリのルートから実行します。Node.js、Chromiumを導入済みのPlaywright、ffmpeg、ffprobeが必要です。依存パッケージの追加はありません。

```sh
PLAYWRIGHT=/path/to/playwright/index.js node apps/day-034-tide-now/tools/promo/render-promo.mjs --preview
PLAYWRIGHT=/path/to/playwright/index.js node apps/day-034-tide-now/tools/promo/render-promo.mjs
```

出力はこのフォルダの `preview-contact.jpg`、本番は `promo.mp4`・`promo-first-frame.png`・`promo-audio.wav` です。部分確認は `--from 18.4 --to 24.4`、別の動画出力先は `--out <絶対パス>`。空きポートのローカルHTTPサーバーで配信します。今回の実装作業では画像・動画・音声ファイルを生成せず、Chromiumの起動・実描画・目視・試聴は未確認です。

本番描画ではChromiumの起動とアプリの準備が成功し、WAVが無いときだけA案を自動合成します。場面や音を変えた後は、描画担当が先に明示的に再生成してください。

```sh
node apps/day-034-tide-now/tools/promo/promo-audio.mjs --variant a
```

## 固定するもの

- 時計は `FIXED_NOW = '2026-09-10T15:00:00+09:00'`。`page.clock.setFixedTime` で止めます。
- 地点は `PLACE_CODE = 'TK'`、`PLACE_LABEL = '東京'`。iframe起動前にlocalStorageの `day-034-tide-now` へ `{ "code": "TK", "mode": "picked" }` を書きます。S4だけ保存なしで起動し、東京都→東京→この地点にする、と選びます。各段階を独立に組み立てるため逆順にもシークできます。
- `context.route('**://www.data.jma.go.jp/kaiyou/data/db/tide/suisan/txt/*/*.txt', …)` が `tests/fixtures/{CODE}-{YYYY}.txt` を返します。年・地点記号を検査し、無いものは404。実通信で潮位表を取りません。
- 画面は「いま、満ち潮」「次の満潮は 16:57（201cm）」「あと1時間57分」、バッジ「大潮」、「いまの潮位 およそ165cm」、「きょうの干満差 171cm（東京では大きい方）」。文言はアプリが計算し、合成側で固定値との一致を待ちます。
- カーブは満潮03:53・200cm／16:57・201cm、干潮10:30・30cm／22:53・81cm。15:00に「いま」の赤い縦線。固定fixtureによる推算値の再現です。
- `known` は `127.0.0.1:<port>` と `www.data.jma.go.jp`。想定外のホストは描画後に報告します。
- 撮影は `reducedMotion: 'reduce'`。アプリの `appear` アニメーションは使わず、`overrideApp` / `setEntrance` で見出し・カーブの動きを毎コマ決めます。

## 操作と確認点

- **0秒がXのサムネです。** 見出しと赤い縦線は−0.12秒から0.6秒かけて出現するので、0秒で動きの途中になります。冒頭の指はありません。初期スクロールは0。見出しと「いま」の縦線が同時に端末内に見えるか確認してください。
- 保存ありは `ready`・`data-place="picked"`・`data-kind="rising"`・上記の東京の文言・満干点4個・両日の表各4行を待ちます。保存なしのS4は `pick` を待ち、取得しないアプリの動作を保ちます。
- 指の的は `#pick-station`・`#pref-select`・`#station-select`・`#station-confirm`。タップは19.1、20.3、21.5、22.7秒。22.92秒に確定し、その直後の指は閉じる前のボタン矩形を使います。
- OSのネイティブ選択メニューは撮りません。東京都・東京の値とchangeイベントを段階適用し、指・輪・フォーカスで選択を見せます。東京が東京都の先頭候補なら、地点タップでも同じ東京を選びます。
- S2は `#headline` を中央へ、S3は `#curve` を中央へ0.7秒でスクロール。S4は `.place-row` の上180pxを基準にします。S5前半は `#range` の上に見出しの高さ＋22pxを残してバッジも見せ、26.5秒から0.7秒で `#events-today` の上22pxへ。S5は末尾の余白を確保します。表2日分の収まり、地点確定時のスクロールと指のずれを確認してください。
- S3の `.water-line` は `getTotalLength()` と `stroke-dasharray` / `stroke-dashoffset` で12.9〜14.05秒に描きます。面の塗りも進捗でクリップ。`.event-dot` と直後の時刻文字は横座標で並べ直し、14.1秒から順に出現。最後に `.now-line` / `.now-dot` / `.now-label` が15.4〜15.95秒に出ます。線の滑らかさ、時刻文字の重なり、面のクリップと赤い縦線の見え方を確認してください。
- `__seek(t)` で任意の時刻を描けます。逆順でも同じ画になるか、場面境界も確認してください。システムフォントによって折り返しが変わるため、字幕・タイトル・約束のはみ出し、エンドURL、出典を読める時間も確認してください。
- 意図しない通信の有無と、音量・S5が最も落ち着くこと・タップ音と指の同期は描画後に確認してください。今回の音量は未実測です。

## BGM

Day 033の純JS合成を継承しています。外部音源・サンプル・依存ライブラリは使いません。A案はローファイのエレピ、B案は撥弦音。固定シード・Fメジャー・92 BPM・48kHz・16bit・ステレオです。`SECTION` はS1タイトル、S2答え、S3カーブ、S4地点、確定タップ、S5表、S6約束、S7エンドへ対応します。拍への丸めは従来どおり最大約0.33秒。`RESULT_START` はいちばん静かにするS5の24.4秒です。S5は境界0.3秒で全体を約8dB下げ、表の読み取りに集中できるようにしています（冒頭・末尾のフェードを除く音量感は要試聴）。指の効果音はS4の4回だけです。
