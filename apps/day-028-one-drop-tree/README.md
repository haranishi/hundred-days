# Day 028「ひとしずくの木」

## 何をするか

開くと、端末ごとの種から生まれた鉢植えの木がいます。「水をあげる」を1日1回押すと、その日のぶんだけ枝葉が増えます。育った過程は再生でき、現在の木は1080×1080のPNGで保存できます。

## なぜ作ったか

毎日の積み重ねを、連続日数やスコアではなく、1本の木の形で残すためです。忘れた日は失敗にせず、葉が少ししおれるだけにしました。戻って水をあげれば葉は持ち上がり、木は減りません。

## 設計上の判断

- 同じ現地日付では2回目の水やりを受け付けません。時計が最後の水やり日より前でも押せません。
- 木の形は種と水やり回数から毎回計算します。ステップごとに独立した乱数列を使うため、育つ前の形は変わりません。
- 80日目からは枝を増やさず、葉と花だけを足します。400日でも描画量を抑えます。
- しおれは最後の水やりからの日数に応じた見た目だけです。最大7日で頭打ちにし、構造は変えません。
- 水やり演出は、しずく、波紋、新しい枝葉がほどける1.4秒だけです。動きを減らす設定では即座に結果を表示します。
- やり直しは行内の2段階確認にし、誤操作で記録を消しにくくしています。

## 保存するもの・プライバシー

端末のlocalStorageに保存するのは、版、種の番号、最初に水をあげた日、水をあげた日付の一覧、更新日時です。木の座標や画像は保存しません。外部通信、登録、通知はありません。保存できない環境でも、ページを閉じるまでは育てられます。

## やらないこと

- 通知、連続日数、スコア、ランキング
- 複数の木、名前付け、着せ替え
- 天気や季節との連動
- サーバー保存、同期、アカウント
