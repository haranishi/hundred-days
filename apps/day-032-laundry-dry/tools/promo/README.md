# 「いま干していい？」プロモーション動画

Playwright で決定的な1コマを撮り、ffmpeg で36秒・1080×1920の MP4 にします。音声は本番描画時に未生成なら自動で合成されます。土台は Day 031 の同名フォルダで、差し替えたのは絵コンテ・アプリの動かし方・固定応答・配色です。

```sh
PLAYWRIGHT=/path/to/playwright/index.js node tools/promo/render-promo.mjs --preview
PLAYWRIGHT=/path/to/playwright/index.js node tools/promo/render-promo.mjs
```

`apps/day-032-laundry-dry/` で実行します。プレビューは `preview-contact.jpg`、本番は `promo.mp4`・`promo-first-frame.png`・`promo-audio.wav` を同じフォルダへ出します。部分確認は `--from 16 --to 22`、別の出力先は `--out <mp4>`。配信は毎回空きポートを取るミニサーバーなので、E2E の 4173 とは取り合いません。

1コマは時刻 t の純関数です。撮影は `reducedMotion: 'reduce'` なので**アプリ自身のアニメーションは動きません**。見せたい動きは全部この合成ページ側で描きます（アプリ本体には手を入れず、iframe の DOM へ毎コマ上書きするだけ）。

## このアプリで要る3つの仕掛け

**時計を止める。** アプリは「いま」から乾く時刻を計算するので、止めないと撮るたびに数字が変わります。`render-promo.mjs` が `page.clock.setFixedTime(FIXED_NOW)` で 2026-09-08 09:30 に固定します。

**天気は実APIを叩かない。** `context.route` が `tests/fixtures/akita-2026-09-08.json`（E2E と同じ固定応答）を返します。固定応答と固定時計の組で、画面には必ず 12:17（ふつう）・14:57（厚手）・取り込み 18:00 が出ます。想定外の通信先が出たら撮り終わりに報告します。

**場面ごとに localStorage を書いてから開く。** アプリは起動時に「最後に選んだ場所・干し方・干し場所」を読むので、`PLANS` の `save` を書いてから iframe を開き直せば、その設定の画面がそのまま出ます。指のタップは「押した結果の画面」を先に用意しておいて、そこへ指を運ぶ形です。

## 気をつける点

- **1コマ目がXのサムネ**です。12:17 が出ていて、24時間の帯が伸びかけ、指が「厚手」へ向かう画にしてあります。
- **帯と根拠の場面は日なたに戻します。** 日かげのまま最後まで進むと見出しが「乾きません」になり、動画が「乾く時刻を出すアプリ」に見えなくなるためです（日かげの「今日は乾かない」は S4 で一度だけ見せます）。
- 字幕は1行16字以内・2行以内。左右108px（10%）のセーフ領域の内側です。
- **アプリの UI を変えたら撮り直しが要ります。** 指の的は要素の id と `data-fabric` / `data-place` を見ています。
- 端末の下端にはアプリの共有ボタンが映り込みます（アプリのとおりで、隠していません）。

## BGM（音）

`promo-audio.mjs` が依存ゼロの純JSで合成します（サンプル・外部音源は使わない）。同じ入力なら必ず同じ WAV になるので、撮り直しても音と画がずれません。**2案**あり、`--variant a`（既定・ローファイなエレピ）と `--variant b`（アコースティック寄りの撥弦）。`render-promo.mjs` は常に A を使います。

構成は `timeline.mjs` の絵コンテに追従します。場面名は Day 031 から引き継いだまま（曲の役割を表しているため）で、この Day では S1 タイトル／S2 場所／S3 乾く時刻／S5 帯（見せ場）／S6 根拠（いちばん静か）／S7 約束／S8 終止和音に割り当ててあります。

直近の実測：統合 **-16.98 LUFS**・True Peak **-2.74 dBTP**・LRA 6.0（目標 -17.0±0.5 LUFS）。検証は耳だけに頼らず、`loudnorm`・帯域別の `astats`・場面ごとの RMS・スペクトログラムで確かめます。

## 他の Day へ流用するときに差し替える場所

- `timeline.mjs` — 絵コンテ（`STORYBOARD`）・字幕（`CAPTIONS`）・タップと指の道筋（`TAPS`・`FINGER`）・場面の切れ目（`appSceneAt`）・固定時刻（`FIXED_NOW`）
- `promo.js` — `PLANS`（どの設定で開き、どのボタンを順に押すか）・`targetBox`（指と輪の的）・`overrideApp`（毎コマ上書きする内容）・`scrollFor`（表示位置の決め方）
- `promo.html` / `promo.css` — iframe の URL、背景の図形、タイトル・約束・エンド画面の文言と配色
- `promo-audio.mjs` — 場面の割り当て（`SECTION`）・音列とシード
