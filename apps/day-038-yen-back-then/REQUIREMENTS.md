# Day 038「昔の1000円、いまいくら」要件定義

昔のお金が、いまのいくらにあたるのかを出す。年を選ぶと、その年の1,000円が
いまの物価で何円ぶんかが出る。逆に、いまの1,000円がその年なら何円だったかも同時に出す。

計算の土台は、世界銀行 World Development Indicators が配っている日本の消費者物価指数
（FP.CPI.TOTL・2010年=100・年平均・原データはIMF International Financial Statistics）。
起動のたびに取りに行き、同梱しない。指数は毎年追加・改定されるため。

ユーザーストーリーとUX5階層は Obsidian 側に置いた（この文書は実装の契約だけを書く）。

## 1. 絶対に守ること（破ったら作り直し）

- **将来の予想をしない**。指数の外挿をしない。取得できた最新年より先の金額は出さない
- **賃金・給料を扱わない**。物価と賃金を同じ画面に並べない
- **為替を扱わない**。国際比較は「物価が何倍になったか」の倍率だけ。金額に換算しない
- **総合指数・年平均という限界を画面の本文に書く**（注釈の小さい字に逃がさない）
- **最新年が何年かを画面に書く**。2026年の途中でも確定しているのは前年までという事実を隠さない
- **端末に何も保存しない**（localStorage を使わない）。どこにも何も送らない
- **出典と CC BY 4.0 と「加工した」ことを常時表示**する
- 実在の硬貨・紙幣の意匠を描かない

## 2. 機能要件

### 2-1. 年を選ぶ（主要アクション）

- スライダー（`input[type=range]`）で 1960 〜 取得できた最新年 を1年ずつ動かせる
- 10年ごとの飛び石ボタンで一息で飛べる（1960 / 1970 / 1980 / 1990 / 2000 / 2010 / 2020）
- 初期値は **最新年の30年前**（データが変わっても勝手に決まる）
- 動かすたびに即座に再計算する。確定ボタンは置かない

### 2-2. 答えを出す

- 主役：**「◯年の N円 は、いまの M円」**。M は `N × 指数(最新年) / 指数(選んだ年)` を四捨五入
- 逆向き：**「いまの N円 は、◯年の L円」**。L は `N × 指数(選んだ年) / 指数(最新年)` を四捨五入
- 倍率（小数第2位まで）と増減率（%・小数第1位）を添える
- 金額 N は 1,000 / 5,000 / 10,000 / 30,000 のボタンと自由入力。全角数字とカンマを受け取る。
  1 〜 100,000,000 に収める。空・0・数字でないものは 1,000 に戻す
- 選んだ年が最新年のときは倍率 1.00 で、文言も「同じ年です」に変える

### 2-3. 見せる

- **硬貨の大きさ比べ**：当時の1,000円と、いまの同じ価値の玉。**面積を価値に比例**させる
  （直径 ∝ √価値）。最小の見た目の直径を決めて、小さすぎて消えないようにする
- **折れ線**：1960年〜最新年の指数をインラインSVGで。選んだ年から最新年までを塗り、
  選んだ年に点と年号を置く
- **分かったこと**を2行：
  1. 選んだ年から最新年までで、前年からの変化が±0.5%未満だった年が何年あったか
  2. 同じ期間に日本の物価が何倍になったか／同じ期間のアメリカは何倍か（倍率のみ）。
     両国そろう最新年で比べ、その年を明記する。米国の指数が取れなければこの行を出さない

### 2-4. 4つの状態

- **loading**：取得中。骨組みだけ出す
- **ready**：上記すべて
- **error**：取りに行けなかった。何が起きたかを1行で書き、もう一度ためすボタンと
  世界銀行のページへのリンクを出す
- **empty**：起動直後の一瞬だけ。年は既定値が入っているので、利用者から見れば loading → ready

## 3. 非機能要件

- 外部APIは世界銀行の1本（`api.worldbank.org`）。**1回の起動で1リクエスト**（日本と米国を同時に取る）
- CSP の `connect-src` に `https://api.worldbank.org` を足す（`scripts/build.mjs`）
- 依存パッケージなし。バニラJS・ESモジュール
- 横スクロールを作らない。390px 幅で崩れない
- 共通のシェア欄を入れる（`shared/share.css` と `shared/share.js`）

## 4. テストで固めること

### ユニット

- `parseSeries`：`value: null` の年を落とす／昇順に並べる／国ごとに分ける
- `convert`：指数の比と四捨五入。同じ年なら入力と同じ金額
- `convertBack`：逆向き。`convert` と往復しても大きくずれない
- `flatYears`：±0.5%未満の数え方。境界（ちょうど0.5%）は数えない
- `ratio`：倍率と増減率
- `commonLatestYear`：2国そろう最新年を選ぶ
- `parseAmount`：全角数字・カンマ・空・0・負・上限超え
- `coinDiameter`：面積比＝直径は√に比例。下限を下回らない

### E2E

- 読み込むと既定年（最新年の30年前）の答えが出る
- スライダーを動かすと金額が変わる
- 飛び石ボタンで年が飛ぶ
- 金額ボタンを押すと答えが変わる
- 通信が失敗したとき error の画面が出て、もう一度ためせる
- 出典（世界銀行・CC BY 4.0）が ready でも error でも見えている
- 横のはみ出しが 0px
