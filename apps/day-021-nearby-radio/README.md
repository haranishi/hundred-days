# Day 021「ちかくのラジオ」

現在地（または選んだ都道府県・世界のどこかの街）の近くにあるインターネットラジオ局を距離順に並べ、ワンタップで流すプレイヤー。芯は「5万局から選ばせる」ことではなく、**いま居る場所の空気の音を最短で鳴らす**こと。

公開URL: https://hundred-days.pages.dev/day-021-nearby-radio/

## データ源と規約（2026-08-28確認）

- 局データは [Radio Browser API](https://www.radio-browser.info/)（無認証・無料・CORS可。有償/無償ソフトでの利用可と明記された完全オープンなAPI）。運営のお願いに従い、再生開始時に `/json/url/{uuid}` へクリック報告を送る（同一局は1回まで・失敗しても無視）
- **radikoには一般利用できる公式APIがなく、非公式な取得は規約上の問題があるため非対応**。JCBAサイマルラジオ等のポータルも許諾制のため使わない。対象はRadio Browserに登録された局だけで、日本の在庫は薄い（座標つきは1桁）。その薄さは0件時の半径自動拡大（25→100→300→1000km）と旅モードで吸収する設計
- 公開ページはHTTPSなので、http配信の局は混在コンテンツとしてブラウザに止められる。**APIの段階で `is_https=true` に絞り、整形時にもhttpsだけ通す**

## プライバシー

現在地の座標は、局を検索するために radio-browser.info へ送られる。それ以外にはどこにも送らず、保存もしない。ブラウザのlocalStorageに残すのは半径と最終モード（現在地/県/旅）だけ。位置情報を許可しなくても、都道府県から同じ体験ができる。

## 作りのメモ

- 依存ゼロのvanilla JS（ES modules）。`lib/` はfetchを注入できる純関数（haversine・検索/整形/半径拡大/ミラーfallback）
- 再生に失敗した局（4秒でcanplayしない場合も含む）は自動でNGマークを付けて距離順の次の局へ進む。カーラジオのザッピングを途切れさせない
- 検索結果の距離順はAPIの `order` を信用せず、クライアント側でhaversineを計算して並べ直す
