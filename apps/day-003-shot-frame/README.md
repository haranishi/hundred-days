# Day 003 — スクショ映えメーカー

スクリーンショットを1枚入れると、余白・角丸・影・グラデ背景をつけたSNS映えする画像に整形して、PNGで保存できるツール。

※ いまは制作記録のみ（`meta.json` の `status` が `draft`）。公開したらここに公開URLを追記する。

## 使い方

- スクショを入れる（ドロップ／ドロップゾーンをクリックしてファイル選択／⌘V・Ctrl+V で貼り付け）
- 背景プリセット6種と、余白（長辺の4〜20%）・角丸（短辺の0〜6%）・影（0〜100）を動かす
- 「PNGで保存」で書き出す（ファイル名は `shot-1440x1040.png` の形式）

## 制約（このチャレンジの「1日アプリ」ルール）

- 外部ライブラリ・外部フォント・外部APIなし（ブラウザ内蔵APIのみ）
- 画像はブラウザの中だけで処理し、どこにも送信しない
- データ保存なし・アカウント不要・課金なし

## 技術メモ

- 合成はcanvasへの4層描画。①背景を全面に塗る → ②角丸矩形を「背景と同じ塗り」で塗って影を落とす → ③同じ角丸矩形で `clip()` → ④ `drawImage` で等倍に置く。②の塗り色を背景と同じにしてあるので、影だけが増えて中身は変わらない。透過PNGを入れても背景がそのまま透けて見える
- 余白・角丸・影はすべて元画像の解像度を基準に計算する。出力は「元解像度＋余白」で、プレビューの縮小率には影響されない
- 影の強さ0〜100は、blur＝余白×0.75×比率／offsetY＝余白×0.25×比率／不透明度＝0.55×比率 に線形マッピングする。余白を基準にしているので影の下端が余白ちょうどに収まり、余白を細くしても影がキャンバスの外で切れない
- プレビューは出力用canvasを縮小したコピー。縮小先は devicePixelRatio を掛けた実ピクセル数にする（CSSで縮めるだけだと高解像度のスクショがぼやけるため）。見えているものと保存されるPNGは必ず一致する
- 縮小は半分ずつ段階的に行う（一気に縮めると細部が飛ぶため）。読み込んだ画像は長辺4096pxに丸めてから使い回す
- 画像は `FileReader` でデータURLにしてから `<img>` に渡す。ローカルのファイルを直接開いても読めて、canvasが汚染されないため `toBlob` で保存できる
- 背景プリセットの色見本チップは、canvasの塗りと同じプリセット定義から作る（見本と実物の色がずれないようにするため）

## actualMinutes について

`meta.json` の `actualMinutes` は、この実装セッションの開始から終了までの実経過分数（実装・ローカルでの動作確認・このREADMEまで。要件定義の時間は含まない）。
