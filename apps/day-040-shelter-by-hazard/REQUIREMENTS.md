# Day 040「その避難場所、洪水でも？」要件定義

場所と災害の種類を決めると、その災害のときに使える「指定緊急避難場所」を近い順に出し、
もっと近いのに使えない場所があれば、それも名指しで出す。

データは国土地理院が配信する「指定緊急避難場所」のタイル（GeoJSON）。市町村が登録し、公開に同意した場所だけが載る。
災害の種類は8つで、タイルも8種類ある。利用条件は国土地理院コンテンツ利用規約（出典の記載で利用可）。

## 1. 絶対に守ること（破ったら作り直し）

1. **避難の判断をしない。** 出すのは指定の情報であって、いま逃げるべきかではない。「逃げてください」「安全です」を書かない
2. **名前・住所・備考を言い換えない。** 仙台では名前に「（大雨時に初動で開設しません）」が入っている。原文のまま出す
3. **「指定緊急避難場所」と「指定避難所」を混同させない。** 扱うのは前者だけ。違いを画面に一言書く
4. **登録が無い市町村があることを隠さない。** 「市町村が登録し公開に同意したものだけ」と画面に書く
5. **距離は直線距離。徒歩の目安は80m/分。** どちらも画面に明記する。経路案内はしない
6. **使える・使えないを色だけで区別しない。** ピンは塗りと白抜きの形で分ける。文字でも書く
7. 外部APIは国土地理院の1系統だけ（避難場所タイル・住所検索・地図タイル）。他のサービスへは一切出ない
8. 依存パッケージを増やさない。素のJavaScript（ESモジュール）。地図は Day 039 と同じ同梱の MapLibre GL JS を使う

## 2. データ

### 2-1. 避難場所タイル

```
https://cyberjapandata.gsi.go.jp/xyz/skhb0{N}/10/{x}/{y}.geojson   N = 1〜8
```

| N | 災害の種類（画面に出す正式名） |
|---|---|
| 1 | 洪水 |
| 2 | 崖崩れ、土石流及び地滑り |
| 3 | 高潮 |
| 4 | 地震 |
| 5 | 津波 |
| 6 | 大規模な火事 |
| 7 | 内水氾濫 |
| 8 | 火山現象 |

- **ズームは10だけ**（z9・z11は404）。1区画は約30km四方
- 各 feature は Point。`properties` は `name` `address` `remarks`（null あり）と `disaster1`〜`disaster8`（該当時 `1`、無いキーもある）
- N のタイルに入っている場所は、災害Nで使える。同じ場所が別のタイルにも入るので、`name` + 経度緯度（小数5桁）で同一判定し、フラグは和集合にする
- **その区画に該当が無い種類は、タイル自体が404**（秋田の 07・08）。404は「0件」として扱い、失敗にしない
- CORS `*`。gzip は無い。`Access-Control-Expose-Headers` に `last-modified` が入っているので、**配信日を読んで画面に出す**
- 実測の大きさ：秋田駅の区画は6種類で約30万バイト、東京駅の区画は8種類で約160万バイト（洪水だけで35万バイト）

### 2-2. 取り方（通信量を絞る）

1. 選んだ場所の区画 (x, y) を計算する。`x = floor((lon+180)/360·2^10)`、`y = floor((1 − ln(tan φ + sec φ)/π)/2·2^10)`
2. **選んだ災害の種類**：その区画に加え、場所から**区画の辺まで5km未満**なら、その方向の隣の区画も取る（角なら斜めも。最大4区画）
3. **残り7種類**：選んだ場所の区画だけ取る
4. 8種類を並列に取る。応答はURLごとにメモリ内で持ち、災害の種類を切り替えても再取得しない。切り替えた種類の隣区画が未取得なら、そのときだけ取る
5. 404 → 空。それ以外の失敗（通信エラー・5xx・不正なJSON）→ 失敗状態（再試行ボタン）。25秒で打ち切る
6. 場所を変えたら進行中の取得を中止する（AbortController・世代カウンタ。Day 039 と同じ）

### 2-3. 住所検索

```
https://msearch.gsi.go.jp/address-search/AddressSearch?q={文字列}
```

- 応答は GeoJSON の配列（`properties.title`・`geometry.coordinates`）。CORS `*`
- 候補が1件なら自動で選ぶ。2件以上は候補を並べて選ばせる（最大10件）。0件は「見つかりませんでした」
- 「秋田駅」は「北海道中頓別町秋田」が先頭に来る。**掴んだ場所の名前を必ず画面に出す**（Day 029 の教訓）

### 2-4. 地図タイル

```
https://cyberjapandata.gsi.go.jp/xyz/pale/{z}/{x}/{y}.png   （淡色地図・256px・最大ズーム18）
```

MapLibre の raster ソースに `attribution: '<a href="https://maps.gsi.go.jp/development/ichiran.html">地理院タイル</a>'` を持たせ、
帰属はソースから出す（自前で `customAttribution` を足すと同じ文が2つ並ぶ。Day 039 の教訓）。

## 3. 計算

- 距離：ハバーサイン。表示は 1km未満なら10m単位で「170m」、1km以上は「1.2km」
- 徒歩の目安：`ceil(m / 80)` 分。「徒歩およそ3分」
- **使える場所**：選んだ災害のフラグを持つ場所を近い順に。一覧は5件
- **それより近い使えない場所の数 n**：いちばん近い「使える場所」より近い、使えない場所の数
- **近いのに使えない一覧**：使える一覧の最後（5件目、5件未満ならその最後）より近い、使えない場所。近い順に最大8件、残りは「ほか◯か所」
- 秋田駅（140.1025, 39.7186）の実測：洪水でいちばん近いのは「中央市民サービスセンター」174m、次の「山王第一街区公園」217m は洪水では使えない。近い5か所のうち洪水で使えるのは1か所
- 高知駅（133.5432, 33.5665）の実測：洪水で最初に使えるのは近い順18番目「江ノ口小学校」500m。**n = 17**（17か所は津波専用）

## 4. 画面（骨格）

`#app[data-state]` は `empty` / `loading` / `ready` / `none` / `error` の5つ。状態の切り替えは `lib/ui.js` の `setState()` 1か所に集める（Day 032 の教訓）。

### 4-1. 上から順（スマホ）

1. **見出し**：eyebrow「DAY 040 / 指定緊急避難場所」、h1「その避難場所、洪水でも？」、副文「災害の種類で、逃げていい場所は変わる。」
2. **答え**（`.answer-area`・操作より上・`aria-live="polite"`）
   - `#answer`：h2 `#answer-text`「洪水のとき、いちばん近い指定緊急避難場所は「中央市民サービスセンター」。170m、徒歩およそ3分。」
     p `#answer-sub`：n>0「それより近くに17か所ありますが、洪水では使えません。」／n=0「いちばん近い場所が、そのまま洪水で使えます。」
   - `#no-sites`（none）：h2「この区画には、津波の指定緊急避難場所が登録されていません」 p「津波の危険がない地域では指定されないことがあります。ほかの災害の種類に切り替えるか、お住まいの市町村の情報を確かめてください。」
   - `#failure`（error）：h2「避難場所を表示できません」 p `#failure-text` ボタン `#retry`「もう一度ためす」
   - `#status`（loading）：「国土地理院の避難場所データを読み込んでいます…」
3. **災害の種類** `#hazards`：radio 8つ（`name="hazard"`・`value="1"`〜`"8"`・既定 `1`）。ラベルは正式名。取得後は各ラベルに区画内の件数を添える（例「洪水 178」「火山現象 0」）。切り替えは再取得せず即時に答え・一覧・ピンを書き換える
4. **場所を決める** `#picker`
   - `#locate`「現在地から探す」
   - 住所検索：`<input id="address">`（placeholder「住所・町名（例：秋田市山王）」）＋ `#search-address`「探す」。候補は `#candidates` にボタンで並べる
   - `#place-name`：掴んだ場所「選んだ場所：秋田県秋田市山王」／「現在地」／「地図で選んだ場所」
   - `#map`（MapLibre・高さ330px・押した場所で検索）、`#map-status`、`#pick-center`「地図の中心で探す」
   - `.privacy`「現在地は端末内で扱います。国土地理院へ送るのは約30km四方の区画の番号だけで、正確な位置は送りません。住所検索の文字列は国土地理院の検索APIへ送ります。」
5. **使える場所** `#usable`（ready）：h2「洪水で使える、近い順5か所」。`ol` の各項目に、名前（`<strong>`）／距離と徒歩／住所／備考（あれば）／「ほかに使える災害：地震、津波」／リンク「地図アプリで開く」（`https://www.google.com/maps/search/?api=1&query={lat},{lng}`・`rel="noopener"`・新しいタブ）
6. **近いのに使えない場所** `#unusable`（ready）：h2「近いのに、洪水では使えない場所」。各項目に名前／距離／「指定されている災害：崖崩れ、土石流及び地滑り、地震」。0件なら p「近い5か所の範囲に、洪水で使えない場所はありません。」。9件以上は末尾に「ほか◯か所」
7. **注意** `.notes`（常時）
   - 「ここに出るのは「指定緊急避難場所」です。命を守るために緊急に逃げる場所で、危険が去るまで滞在する「指定避難所」とは別です。このアプリは指定避難所を扱いません。」
   - 「市町村が登録し、公開に同意した場所だけが載っています。登録の無い市町村もあります。必ずお住まいの市町村の情報で確かめてください。」
   - 「距離は直線距離、徒歩の目安は80m/分で計算しています。指定されていても、その日に開設されているかは市町村の発表によります。」
8. **出典** `.sources`：
   - 避難場所：`<a href="https://www.gsi.go.jp/bousaichiri/hinanbasho.html">国土地理院「指定緊急避難場所データ」</a>`＋`#data-date`「（2026-09-14 配信）」（last-modified から。取れなければ出さない）
   - 利用規約：`<a href="https://www.gsi.go.jp/kikakuchousei/kikakuchousei40182.html">国土地理院コンテンツ利用規約</a>`
   - 地図：`<a href="https://maps.gsi.go.jp/development/ichiran.html">地理院タイル（淡色地図）</a>`
   - 住所検索：国土地理院 住所検索API
   - `<div id="share"></div>`（共通の共有部品。`npm run shared:sync` が入れる）

### 4-2. PC（min-width 900px）

2カラム。左に「災害の種類」と「場所を決める」、右に答えと一覧。Day 038 で「PCが1カラムで左右が空く」と2周指摘された。

### 4-3. 地図のピン

- 自分の場所：ひし形（`.pin-self`）
- 使える場所：塗りの丸に順位の数字（`.pin-usable`）
- 使えない場所：白抜きの丸（`.pin-unusable`）
- 各ピンに `aria-label`（「1 中央市民サービスセンター 170m 洪水で使える」など）。結果が出たら自分と一覧の全ピンが入るように `fitBounds`（padding 48）
- 押せるものの枠線は背景と3:1以上。ボタンは44px以上

## 5. 状態と文言

| 状態 | 見せるもの |
|---|---|
| empty | 見出し・災害の種類・場所の操作・注意・出典。答えと一覧は隠す |
| loading | `#status` と `#skeleton`（一覧の骨組み3本）。地図と操作は使える |
| ready | 答え2行・使える5か所・使えない一覧・ピン |
| none | `#no-sites`。災害の種類は切り替えられる（別の種類には結果があることが多い） |
| error | `#failure` を最上部。一覧は隠す。`#retry` で同じ場所をやり直す |

- 日本の範囲外（緯度20〜46.5・経度122〜154の外）：error「日本の範囲で場所を選んでください。」
- 現在地が使えない：error「現在地の利用が許可されていません。住所か地図で場所を選べます。」／「現在地を取得できませんでした。住所か地図で場所を選ぶか、もう一度おためしください。」
- 住所検索0件：`#candidates` に p「「◯◯」に当たる場所が見つかりませんでした。住所や町名で試してください。」（状態は変えない）
- `getCurrentPosition` は `{ enableHighAccuracy: false, timeout: 10000, maximumAge: 60000 }`

## 6. テスト

### 6-1. ユニット（`tests/*.test.mjs`・`node --test`・`tests/index.mjs` から import）

- 区画の計算：(140.1025, 39.7186) → 910/388、(139.767, 35.681) → 909/403、(133.5432, 33.5665) → 891/410
- 隣区画の判定：区画の中央では1区画、辺から5km未満で2区画、角で4区画。5km以上では増えない
- 同一判定と和集合：同じ場所が2つのタイルに出たら1件になり、フラグは両方持つ。`disasterN` キーが無くても壊れない
- 順位：秋田の実応答（fixtures）で、洪水のいちばん近い使える場所が「中央市民サービスセンター」、n=0、使えない一覧に「山王第一街区公園」が入る
- 高知の実応答で、洪水の n=17、最初に使えるのは「江ノ口小学校」
- 火山現象（秋田・タイル404）で none になる
- 距離と徒歩：174m → 「170m」「徒歩およそ3分」、1234m → 「1.2km」「徒歩およそ16分」
- 文言：答え2行が要件どおりの文字列になる（n>0 と n=0）
- 住所検索の応答の解釈：1件→自動選択、複数→候補、0件→見つからない
