# Day 016「回線の犯人さがし」要件定義

## 目的

速度の数字ではなく、**遅さの原因の場所**を返す。ルーターを買う前に犯人を知れる状態にする。

## スコープ外（先に決めた）

ブラウザでは原理的にできないため、要件から外す。

- Wi-Fiの電波強度・チャンネル・リンク速度（OSのAPIのみ）
- IPv4/IPv6の測り分け（接続先のIPバージョンを指定できない）
- バックグラウンドの定期自動測定（タブを閉じると止まる）
- パケットロス（WebRTCのTURNサーバーの自前運用が必要）

## ユーザーストーリー

- **US-001** 遅さの犯人を知りたい → 30秒以内に、数値ではなく日本語の診断が出る
- **US-002** 速いはずなのに詰まる理由を知りたい → 待機中／下り通信中／上り通信中の反応を並べ、A+〜Fで採点する
- **US-003** 1回の測定で判断してよいか知りたい → 履歴3件未満では時間帯判定を出さない
- **US-004** 何日か様子を見たい → 測るたび履歴が貯まり、3時間刻みで見える。CSVで持ち出せる
- **US-005** 結果を人に見せたい → 共有できる。ただし個人を特定できる情報は一切含めない

## 機能要件

| ID | 内容 |
|---|---|
| FR-001 | 帯域測定。助走を捨て、サイズを上げながら並列で測る。速度はヘッダ受信後から本文読了までで計算＝接続確立とTTFBを含めない |
| FR-002 | 遅延。待機中／下り通信中／上り通信中の3フェーズで往復時間を測り、中央値とジッターを出す |
| FR-003 | グレード。`max(下り通信中, 上り通信中) − 待機中` を A+/A/B/C/D/F に採点。自分の待機中を基準にするので測定先が遠くても不利にならない |
| FR-004 | 診断8分岐（下記） |
| FR-005 | 履歴。localStorageに最大200件。壊れていたら捨てずに「読めません」と出して利用者に選ばせる |
| FR-006 | 4状態（空・測定中・エラー・不正入力） |
| FR-007 | 通信量の事前告知と節約モード。`saveData` が立っていれば自動で節約側にする |
| FR-008 | IPv6接続かどうかの表示。IP・地名・座標は取得後すぐ捨てる |
| FR-009 | 共有（共通のシェア機能） |

## 診断ロジック（FR-004）

| ID | 条件 | 結論 |
|---|---|---|
| DX-1 | 下り<30Mbps かつ 上り>下り×3 | 下り方向だけが遅い。宅内の機器は原因になれない |
| DX-2 | 上り<10Mbps かつ 下り>上り×3 | 上り方向だけが遅い |
| DX-3 | グレードC以下 | 通信中に遅延が跳ねる。ルーターのQoSで改善しうる |
| DX-4 | 履歴3件以上・夜(18時〜)の平均が他の半分未満 | 夜だけ遅い＝混雑。買い替えでは直らない |
| DX-5 | 履歴3件以上・全体平均が30Mbps未満 | 時間帯によらず遅い。機器か回線の不具合 |
| DX-6 | 履歴3件以上・変動係数>0.6 | 不定期に落ちる。宅内の他端末が占有している可能性 |
| DX-7 | 履歴3件未満 | 1回では判断できません |
| DX-8 | 上のどれにも当たらない | 大きな異常なし |

当てはまったものを全部、重い順に出す。DX-4〜6は夜と昼の両方の測定が揃うまで評価しない。

## 4状態（FR-006）

| 状態 | 中身 |
|---|---|
| 空 | 説明・通信量の告知・節約モード・測定ボタン。オフラインならボタンを無効化 |
| 測定中 | 現在のフェーズ・経過秒・進み具合・中止ボタン。読み上げ対象 |
| エラー | 理由（オフライン／通信失敗／中止）と再試行。**途中まで取れた値は保存しない** |
| 不正入力 | ①測定中にタブが背面へ回った＝結果を破棄 ②履歴が壊れている ③オフライン |

## 非機能要件

- 測定は通常30秒以内・節約モード12秒以内／初期表示1秒以内／npm依存なし
- 結果を第三者へ送信しない。localStorageのみでCookieなし
- CSPの `connect-src` に測定先を追加する（足し忘れると本番だけ黙って止まる）
- 色だけに意味を載せない。進み具合と結果は読み上げ対象。コントラスト比4.5:1以上
- 375pxから。表は横スクロールの箱に入れ、本文を横に流さない

## 保存の形

キー `day016.history.v1`、`{ v: 1, items: [...] }`。1件は `t / dl / ul / li / ld / lu / jit / grade / v6 / eco` の10項目のみ。**IP・地名・座標は入れない。** 版番号が想定外なら黙って読み替えず、broken として利用者に選ばせる。
