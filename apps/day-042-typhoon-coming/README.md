# Day 042 台風、うちに来る？

市区町村をひとつ決めると、その地域が**台風の暴風域に入る確率**を、気象庁の発表そのままに1行で答える。
3時間ごとの帯で「何時が山か」を、地図で予報円との位置関係を見られる。台風が無い日は「いま、台風はありません」と答える。

## なぜ作ったか

台風の進路は「予報円」の絵で伝わるが、読み方が難しい。予報円は**中心が70%の確率で入る範囲**であって、
円の外の街も暴風域には入りうる（暴風域は中心の外側へ半径で広がる）。
気象庁はこの読み違いを避けるために「暴風域に入る確率」を地域ごとに出している。
ところが地方→都道府県→地域とたどる必要があり、**市の名前からは直接引けない**。そこだけを埋めた。

## やらないと決めたこと

- **独自の予想をしない**（気象業務法17条）。補間・平均・独自の指数を作らず、発表された整数と基準時刻だけを出す
- **「安全です／危険です」と言わない。** 避難の判断は気象庁と自治体へ。キキクルと Day 040 へリンクで送る
- **警報・注意報、雨量、河川、高潮を持たない。** 別の情報体系なので範囲を絞った（Day 033 と同じ）
- **通知・自動更新をしない。** 開き直せば最新になる
- **eventId を覚えない。** 終わった台風はディレクトリごと消えるので、毎回 `targetTc.json` から取る

## 設計で迷ったところ

**帯の高さを何に合わせるか。** 系列の最大を100%にすると、山が1%の街と22%の街が同じ高さに見える。
0〜100%の絶対目盛にした。ほとんどの街でほぼ平らになるが、そちらが事実に近い。5%以上の棒には数字を添えている。

**現在地から市区町村を当てるとき、どの点で比べるか。** 外接矩形に入るものを集めるところまでは
気象庁の台風ページと同じだが、複数当たったときの比べ方は**矩形の中心**にした。
代表点（市役所の位置など）で比べると、東京駅で中央区が千代田区より近く出る。

**都道府県名をどこから取るか。** `area.json` の `offices` は、北海道7・沖縄4・鹿児島2の計14件が
気象台の管轄名（「石狩・空知・後志地方」など）になっている。候補を「◯◯市（◯◯県）」で見分けたいので、
その14件だけコードの上2桁で都道府県名に寄せた（→ [`data/SOURCES.md`](data/SOURCES.md)）。

**地図ライブラリを入れなかった。** 停電の前に開くことがある。タイルもフォントも外から読まず、
canvas に直接描いて、陸の輪郭だけ108KBで同梱した。投影は `lib/project.js` の20行で足りる。

## 落とし穴（次に触る人へ）

- 🔴 **`validtime` は3時間区間の「終わり」。** 終わりの時刻だけを出すと3時間ずれて読まれる。
  画面では必ず区間（「21日（月）9時〜12時」）で書く。防災情報XMLの `TimeDefine` は同じ区間の**始まり**なので、
  両方を見るときは3時間ずれる
- 🔴 **`Object.keys(probability)` はファイルの並び順を返さない。** 先頭が0でない6桁コードが
  配列添字とみなされて前に回るため、北海道〜九州が全部うしろへ行く（実測で先頭は群馬、末尾は鹿児島）。
  一覧の順は同梱データの `order`（`area.json` のファイル上の出現順＝北→南）で決める
- 🔴 **階層をまたいで同じコード文字列が使われる。** 小笠原諸島の `130040` は class15s にも class10s にもある。
  全階層を1つの辞書に混ぜると都道府県がたどれなくなる
- 🔴 **404 は「台風なし」ではない。** 終わった台風のディレクトリは消えるので404が出る。
  台風の有無は `targetTc.json` が空配列かどうかだけで決める
- 🔴 **`connect-src` に `https://www.jma.go.jp` を足す。** `scripts/build.mjs` の `CONNECT_BY_APP` に
  このDayの行が無いと、ローカルのテストは通って**本番だけ**が黙って止まる（Day 014 で実際に起きた）
- **bosai の台風JSONは公式に案内されたWebAPIではない。** サイト内部のデータなので形が予告なく変わる前提で読む。
  `lib/jma.js` の形の検査を緩めない（壊れたら「取得できませんでした」で止めるのが正しい）
- **台風が2つ以上あるときの `targetTc.json` は未実測。** 複数要素を受ける実装にはしてあるが、実物は見ていない
- **カタカナ・半角カナの検索は正規化に依存している。** 同梱データの読みはひらがなだけなので、
  入力を NFKC してからカタカナをひらがなへ寄せている（`lib/towns.js`）

## データと利用条件

実行時：気象庁「[台風情報](https://www.jma.go.jp/bosai/map.html#contents=typhoon)」の
`bosai/typhoon/data/` 配下4本（一覧・3時間確率・積算確率・諸元・地図の幾何）。
[気象庁ホームページの利用規約](https://www.jma.go.jp/jma/kishou/info/coment.html)。

同梱：市区町村1805件（気象庁 `area.json`・`class20relm.json` と Day 015 の代表点）と、
陸の輪郭（[Natural Earth](https://www.naturalearthdata.com/) 1:50m・パブリックドメイン）。
加工の内訳は [`data/SOURCES.md`](data/SOURCES.md)、実応答の出どころは [`tests/fixtures/SOURCES.md`](tests/fixtures/SOURCES.md)、
実測の記録は [`docs/data-discovery.md`](docs/data-discovery.md)。

利用規約は出典の記載だけでは足りず、加工した旨と、国が作成したものではない旨を別に求めている。
画面の出典欄はこの3つを常時出している。

**入力した語も現在地の座標も外に出さない。** 確率は全国ぶんが1本で届くので、地域をURLに載せる必要がない。
覚えるのは最後に選んだ市区町村の7桁コードだけ（`localStorage`・座標は保存しない）。
