# 「台風、うちに来る？」プロモーション動画

縦型1080×1920・35秒・BGM付き。絵コンテは `timeline.mjs`、音は `promo-audio.mjs`、画は `render-promo.mjs` の3本で完結する。

```sh
PLAYWRIGHT=/path/to/playwright/index.js node day-042-typhoon-coming/tools/promo/render-promo.mjs
```

出力は `promo.mp4` と `promo-first-frame.png`（どちらも gitignore 済み）。`promo-audio.wav` が無ければ `--variant a` で自動生成する。

## このDayで気をつけること

- **気象庁への通信は全部、固定資料に差し替えて撮る。** `tests/fixtures/bosai-*.json`（2026-09-18 15時／18時45分の発表）を
  `page.route` で返す。台風が去れば本物の発表は「台風はありません」に変わり、同じ画は二度と撮れない。
  差し替えているのは実際の発表そのものなので、映る数字は本物と同じ
- **「いま」も 2026-09-18 21:00 に固定する**（`page.clock.install`）。帯の「いま」の印が毎回同じコマ（18日21時〜24時）に出る。
  `clock.install` を入れても `requestAnimationFrame` は実時間で回るので、冒頭の `panTo()` はそのまま動く
- **気象庁以外の宛先は断つ。** このアプリは地図も同梱データ（`data/land.json`）で描くので、外から取るものは何も無い。
  実行後のログに「断った宛先: なし」と出れば、外を読みにいっていないことの裏付けになる
- 千代田区は現在地（東京駅の座標）から、八丈町は市区町村名で決める。**「八丈」は同梱の1805件で八丈町だけに当たるので候補は出ない**。
  「探す」を押した時点で答えが 30% から 78% に入れ替わる（そこが山）
- 冒頭のスクロールは `panTo()` が秒数を指定して動かす（`smooth` は数百msで着いてしまい1コマ目が静止画になる）

## 字幕の数字は画面と突き合わせてある

`render-promo.mjs` の `expect()` が、書き出す前に画面の文字と字幕の数字を照合して、違っていたら止まる。

| 場面 | 字幕 | 画面のどこ | 照合する文字 |
|---|---|---|---|
| S1 | 千代田区は5日以内に30% | `#place-name` `#answer-text` | `千代田区` `30%` |
| S2 | 山は21日9時〜12時、22% | `#answer-sub` | `21日（月）9時〜12時 の 22%` |
| S5 | 街を八丈町に変えると／八丈町は78% | `#place-name` `#answer-text` | `八丈町` `78%` |

字幕は画面より短く書いてある（1行16字以内）。**食い違ったら字幕を画面に合わせる。逆はしない。**

## 判断は書かない

このアプリは気象庁の発表を街の名前で引き直すだけで、危険・安全の判断はしない（気象業務法17条）。
字幕とエンド画面も同じ方針で、「危険」「安全」「大丈夫」「避難」を書かない。S6 では画面の但し書き（`#caveat` と
「この数字で分からないこと」の1・3番）と一緒に「気象庁の発表そのまま。／判断はしません」を出す。

## 画と音は0.2秒ほどずれる

音は t0（時間割の0秒）に合わせて作るが、映像の頭は「録画開始から t0 までの実測値」で切り落とす。
録画の開始は `newContext()` の直後より少し遅いので、**画のほうが0.2秒ほど早い**。
Day 041 と同じ性質で、聴いて分かる差ではない。気になるなら `render-promo.mjs` の `head` に足して調整する。

## BGM

Day 039〜041 と同じ生成器（F メジャー・92BPM）を**中身を変えずに複製**した。場面の秒数は `timeline.mjs` の
`STORYBOARD` と `T_CONFIRM_TAP` から読むので、絵コンテを動かせば音も一緒に動く。
A案（ローファイ鍵盤）とB案（アコースティック寄り）の2本を書き出せる。

```sh
node promo-audio.mjs --variant a --out promo-audio-a.wav
node promo-audio.mjs --variant b --out promo-audio-b.wav
```

音量は実測 **-16.59 LUFS / true peak -3.51 dBTP**（Day 041 は -16.60 / -3.52。生成器が同じなので同じ値になる）。

## 一覧カード用の demo.mp4 を切る秒数

`scripts/record-demo.mjs --day 42` が撮る `demo.mp4` は **21.56秒**で、頭に現況カードと地図が出るまでの間が入る。
`tools/trim-demo.mjs` で15〜20秒に切る。実測した目安は次のとおり。

```sh
node day-042-typhoon-coming/tools/trim-demo.mjs 4.4 21.4   # 17.0秒
```

| 秒 | 画面 |
|---|---|
| 0.0〜1.5 | 現況カード（台風第25号） |
| 1.5〜3.9 | 地図へ下りて、経路と予報円を見せる |
| 3.9〜4.55 | 先頭へ戻る（**ここが動いている。1コマ目に使う**） |
| 4.58 | 千代田区の答え 30% が出る |
| 6.9〜17.8 | 帯 → 地図 → 確率が高い地域 |
| 18.6〜18.9 | 「八丈」と打って「探す」。答えが 78% に入れ替わる |
| 〜21.56 | 八丈町 78% のまま終わる |

切る前後で1コマ目を必ず目視する。

```sh
ffmpeg -ss 4.4 -i demo.mp4 -frames:v 1 /tmp/thumb.png
```
