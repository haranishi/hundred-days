# Day047 — ねこ、光になる

猫の画面を上下にこすると猫が加速する3Dブラウザゲーム。カタツムリから20の速さを追い越し、道の先に並ぶ物を弾き飛ばしながら、牧場→街→空→軌道→太陽系→星間へ進む。光速の99.999%に達したら自動で結果へ。光速そのものは超えない。

## 遊び方

「はじめる」を押し、猫の画面を指で上下にこする。指を送った量が推力になり、離すと最大450msで推力がなくなって減速する。右端44pxの↕はページ移動用。PCは長押し・Space・Enter・ホイール。最後まで押し続けると約49秒。

## v3で変えたこと（2026-09-23）

改善計画は [PLAN-v3.md](PLAN-v3.md)、採点表は [EVAL-v3.md](EVAL-v3.md)。旧設計の原本は [DESIGN-v2.md](DESIGN-v2.md)（素材・入力の経緯はそちら）。採点は3周（11→13→13／20点・合格ライン16点）で、計画と採点は別のAI、実装はClaude。人の初見プレイ・実機での滑らかさ・音の聞こえ方は自動の証拠では確かめられず、持ち主の確認が残っている。

- **序盤から変化が続く加速**：v2は最大推力でも8秒で0.9km/h、街まで24秒、完走まで91秒かかった。最大推力で最初の通過0.8秒・街9秒・空15秒・軌道20秒・太陽系25秒・星間30秒・光速の90%が37秒・完走49秒（`lib/physics.js` の `PACE`）。
- **こする速さに比例する推力**：送った距離の蓄え（離して450msで0）に、直近の指の速さ（約0.12秒で薄れる勢い÷120px/秒）を足した。ゆっくり小さくこすってもゆっくり進む。往復で勢いが戻るたびに、猫の走りと背景の流れが一瞬強まる。指を置いた場所に波紋、推力バーは毎コマ更新。
- **追いかける構図**：猫を斜め後ろ上から撮り、道の先が画面の奥へ伸びる。弾く的が3〜5個先まで見え、近づいて当たって飛ぶまでを目で追える。鳴くときだけ猫がカメラ側へ振り向く。モデルに目鼻の色が無いので、頭の骨に目の玉を付け、鼻先と口元を頂点色にした。
- **追い越す相手**：カタツムリ・新幹線・旅客機・宇宙ステーションの4種をコードで描き、追い越す前後の約2.4秒だけ猫の奥側を並走させてから後ろへ下げる（`lib/rivals.js`）。
- **世界ごとの象徴と動き**：牧場は道・木立・納屋、街は車道・家並み・高層ビル、空は雲海、軌道は画面下の地球の弧（回りながら少しずつ遠ざかる）、太陽系は太陽と、右から左へ通り過ぎる環のある惑星、星間は斜めの天の川（光速に近いほど進行方向へ寄る）と、奥を通り過ぎる明るい星。
- **読める衝突**：1列に的を置き、最大推力で0.6〜1秒おきに当たる。的の列は頭の真後ろから少しずらし、空と宇宙では頭より下を通す。弾いた物は画面の右へ飛び、顔の前を通らない。重い物ほど低く遅く飛ぶ。衝突音は材質で3種の録音を使い分ける。
- **光の猫**：光速の90%で縁が白青に光り、99%から毛色が白へ寄り、99.9%で8割以上が白になる。90%からは「猫の時計」と「地球の時計」を並べ、結果には頭から尾まで収めた光の猫の写真を出す。
- **1画面の構成**：上に速度と次の相手、残りは3D、下に速報（フィクション）。結果の間は速度欄と速報欄を畳む。追い越した瞬間は画面上部に一言。操作説明は最初の入力から2秒で畳む。プレイ中の入力面では2本指の拡大をしない。

## 数値と音

[速さの出典・概数・注意点](data/SOURCES.md) に21段階を記載。**ゾウガメ1.4km/hの計測出典は未確認**で、指定値を保持している。時間配分（何秒でどこへ着くか）はゲームの設計で、物理ではない。

同梱した本物の猫の鳴き声は加速するほど高く、間隔が短くなる。音速で1回のソニックブーム、その後の鳴き声は0.75秒遅れる演出。軌道速度以降は真空と扱い、予約済みの音も止める。衝突音は小物・木・大型で録音を選び、最大4声。

## 構成

- `app3d.js`：画面・入力・進行・結果、検証窓口 `window.__day047`
- `lib/physics.js`（加速曲線）・`game.js`・`milestones.js`（21段階）・`worlds.js`（6世界）・`input.js`（指の量→推力）・`impacts.js`（的と衝突・描画なし）・`audio-state.js`・`store.js`
- `lib/scene.js`（カメラ・猫・光・流線・象徴の投影）・`sets.js`（6世界の背景）・`impact-view.js`（的の見た目）・`rivals.js`（追い越す相手）・`cat-model.js`（猫・目・縁の光）・`cat-light.js`・`sound.js`

`window.__day047.snapshot()` は `contractVersion: 3` と `experience`（進行イベント・象徴の投影矩形・光の段階・揺れと流線の数）を返す。形は PLAN-v3.md の「テストAPI契約」。

## 検証

リポジトリ直下で `npm run build`、`npm run test:unit`、`npx playwright test tests/e2e/day-047.spec.mjs`、`npm run precheck`。Day047だけの単体は `node --test day-047-cat-lightspeed/tests/`。
