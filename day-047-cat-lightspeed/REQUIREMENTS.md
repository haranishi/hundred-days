# Day047「ねこ、光になる」要件（v3）

猫の画面を上下にこすると猫が加速し、実在の20の速さを追い越して光速の99.999%で自動的に結果へ進む。1本道でアカウントは不要。改善の理由と受け入れ基準は PLAN-v3.md、採点は EVAL-v3.md が正本。

## 変えない枠

- 21段階のkm/hは `lib/milestones.js` の指定値のまま。光速は壁で、追い越すのは20件。出典・概数の扱いは data/SOURCES.md。
- 6世界の境界は100 / 1,000 / 10,000 / 100,000 / 1,000,000 km/h。境界ちょうどから次の世界。
- 光速は超えない。0.99999cで終了。γの瞬間値と、γを積分した地球の経過秒を分けて表示する（簡略モデルと明示）。
- 実行中の外部通信はゼロ。保存はベスト（速度・秒数・日付）とミュートだけ。保存できない環境でも最後まで遊べる。
- 持ち主の依頼で入れたもの（スマホは指を送った量で加速、物を弾く衝突、録音のニャー、同梱GLBの猫）は残す。

## v3の要件

- 加速：最大推力で最初の通過0.3〜1.5秒、4km/hまで4秒以内、20km/hまで6秒以内、街8〜12秒、空14〜18秒、軌道19〜24秒、太陽系24〜29秒、星間29〜34秒、完走45〜60秒。各世界に4秒以上、光速の90%から完走まで8〜15秒。推力0で減速し、下限は0。
- 入力：スマホは指で上下にこする。送った距離の蓄え（最大0.45秒ぶん・離して450ms以内に推力0）と、直近の指の速さに比例する推力の大きい方を使う。震え防止に最初の2pxは反応しない。推力が0の間は減速する。PCは長押し・Space・Enter・ホイール。
- 追い越す相手（P1）：カタツムリ・新幹線・旅客機・宇宙ステーションの4種を、追い越す前後の約2.4秒だけ猫の奥側に出す。同時に1体。
- 画面：390×844・390×664で、見出しと速度欄は160px以下、3D描画域は画面高の60%以上。猫の投影は高さ18〜38%・中心x 40〜60%・四辺2%内側。操作説明は最初の入力の2秒後に畳み、推力バーは残す。速度の数字は360〜700px幅でも欄からはみ出さない。
- 世界：各世界に象徴（牧場＝道と木立、街＝道路と建物、空＝雲、軌道＝画面幅70%以上の地球、太陽系＝画面幅18〜28%の太陽と12〜20%の環のある惑星、星間＝星の帯）。空から先は流線を12〜120本（星点と合わせて180以下）。
- 衝突：見える未破壊の的は3〜5個。同時に飛ぶ本体4個以下・破片12個以下（動きを減らす設定では4個以下）。最初の接触は最大推力で2秒以内、以降は0.6〜1.2秒おき。揺れは最大2px・120ms。
- 光：光速比90%未満は毛色、90%以上は縁の光（glow）、99.9%以上は白い猫（light・毛色の8割以上が白）。90%以降は猫の時計と地球の時計を並べる。結果には高さ80〜112pxの光の猫、「あなたの1秒のあいだに、地球では223.6秒」、かかった時間、20/20、もう一度、共有を出す。
- 動きを減らす設定：揺れ0・流線0・背景の流れは通常の20%・破片4個以下。入力・速度式・時計・到達条件は同じ。
- 描画：48ドローコール以下・18,000三角形以下・描画倍率1.5以下。影・後処理は使わない。
- 検証窓口 `window.__day047`：state() / snapshot() / setManual() / advance(ms) / start() / inputSample()。snapshot は contractVersion 3 と experience（events・landmarks・light・motion・reducedMotion）を返す。
