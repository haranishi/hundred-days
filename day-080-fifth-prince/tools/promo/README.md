# Day80 第五王子の予告編
36秒・縦1080×1920・30fps。実際の操作画面を中心に、商い・仲間・兄弟・戦闘を見せる。
最終的な加護の種明かし、魔王の勝敗、結末の画面は映さない。

| 秒 | 映像と伝える遊び |
|---|---|
| 0–3.6 | 森の番獣への一撃から開始。魔法を持たない王子が挑む |
| 3.6–9.6 | 市場へ歩き、麦を仕入れる。所持金と在庫が変わる |
| 9.6–15.6 | 町で出会った仲間と森を歩く |
| 15.6–21.6 | 五人で向き合い、返事を選ぶ。能力の正体は見せない |
| 21.6–30 | 雷の試練で攻撃・防御・仲間への支援を選ぶ実戦 |
| 30–36 | 仲間と歩く実画面を背に題名とプレイ案内 |

## 再制作
このフォルダで `npm ci --ignore-scripts`。Day80の公開物をローカル配信し、`PROMO_BASE`でURLを指定できる。
`npm run capture` → `npm run audio` → `npm run stills` → `npm run render` → `npm run audit`。
録画は正規の進行で作るチェックポイントからUIを操作し、数値・コマンド・結果は書き換えない。
映像・音・プレビューはgitignoreされた `output/`。本体へ公開する動画はDay直下の `demo.mp4`。

## 権利と制作
ゲームのNinja Adventure（CC0）とDotGothic16（OFL）の素材を使用する。
BGM・効果音はゲームの正規素材をカットへ同期し、足音は同じ音響モデルから生成する。
画面操作・字幕・編集・検証はAIが担当。本人の声や顔、体験談を作らない。
Remotionは固定4.0.535、個人用の編集環境でローカル描画する。外部レンダリングや画像生成は使わない。
https://www.remotion.dev/docs/offthreadvideo
https://www.remotion.dev/docs/license

映像で終盤の加護名を見せないため、戦闘は覚醒前の番獣と雷の試練を撮影する。
