# 第五王子と、名もなき加護
魔法を持たない第五王子リュカが、商いと人との出会いで勇者になる短編2D RPG。

麦を仕入れて届け、町の人と働き、仲間を集める。四人の兄と和解し、協力して魔王へ挑む。
序章・六つの小章・選択式の戦闘・終章とクレジットまで遊べる。

## 遊び方
移動は矢印/WASD、Shiftで走る。地面・人物のクリックやタップ、画面の十字キーにも対応。
会話はE/Enter。選択肢・戦闘・出入口は矢印で選びEnter/E/Spaceで決定する。
「目標へ歩く」と手帳（J）で次の用事を確かめられる。
所持金を使い切ってもパン屋の仕事から再開でき、敗北で依頼や資金は失わない。
音は初期オン。開始・再開の操作でBGMが鳴り、草・道・石・橋で足音が変わる。
右上の音ボタンと手帳の音量を使える。進行と音の設定は同じブラウザ・同じ公開URL内だけに保存する。
最終勝利は保存し、終章途中の再読込でも再戦しない。クリア後は手帳から結末を見返せる。
