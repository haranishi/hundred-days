# Day 088「Bouquet Studio」

画面の中で花を選んで花束を作り、リンクにして贈れるWebアプリ。受け取った人がリンクを開くと、包まれた花束がひらいて花が咲き、メッセージカードが出る。花は3Dで、動かすと花びらが落ちる。自分の写真を背景にもできる（写真は端末の中だけで使い、リンクに入るのは写真をぼかした約50バイトの色合いだけ）。ログイン不要で、サーバーには何も保存しない。スマホでも指だけで作れる。

- 公開サイト: https://day88.rairakku.com/
- `rairakku.com` の中の住所: https://rairakku.com/day88/（`day88.rairakku.com` へ転送します）

## 素材

花・包み紙・リボンは自作の描画です。3D描画に three.js（MIT）を同梱しています。アプリの中では、外部の画像・書体・音は使っていません。

宣伝動画（`tools/promo/` で作った32秒の縦型動画と、一覧のデモ動画）の素材は次のとおりです。

- 映像: Bouquet Studio の公開用ビルドをローカルで配り、本番と同じ住所（day88.rairakku.com）で開いて録った実画面です。外へは通信していません。字幕・窓の枠・「あるある」の場面の質問カード・終わりのカードだけを、後から重ねました。
- 背景の写真（「写真を背景にする」の見本）: Poly Haven「Qwantani Dusk 2」（https://polyhaven.com/a/qwantani_dusk_2）の画像から切り出したものです。CC0。人・ロゴ・読める文字は写っていません。
- 字幕の書体: Zen Kaku Gothic New（SIL Open Font License 1.1）
- BGM: スクリプトが計算だけで合成した音です。第三者の音源やサンプルは使っていません。
