# Day 088「Bouquet Studio」

画面の中で花を選んで花束を作り、リンクにして贈れるWebアプリ。受け取った人がリンクを開くと、包まれた花束がひらいて花が咲き、メッセージカードが出る。花は3Dで、動かすと花びらが落ちる。自分の写真を背景にもできる（写真は端末の中だけで使い、リンクに入るのは写真をぼかした約50バイトの色合いだけ）。ログイン不要で、サーバーには何も保存しない。スマホでも指だけで作れる。

- 公開サイト: https://day88.rairakku.com/
- `rairakku.com` の中の住所: https://rairakku.com/day88/（`day88.rairakku.com` へ転送します）

## 素材

花・包み紙・リボンは自作の描画です。3D描画に three.js（MIT）を同梱しています。外部の画像・書体・音は使っていません。
