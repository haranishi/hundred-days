# Day 023「MAGTRACE」

気になる言葉を題名に含む雑誌記事が、1997〜2026年にいつ、どれだけ現れたかをたどる1画面の道具です。年別推移、機械的に決めた転機、該当年の原典リンクをまとめて表示します。

## なぜ作ったか

ある言葉がいつから使われ、どの時期に掲載が増えたのかを検索結果の一覧だけから読み取るのは難しいため、雑誌記事の題名を年別に並べ直しました。数字の前に一文の発見を置きつつ、取得日時、数え方、収録範囲も同じ画面で確かめられるようにしています。

## 設計上の判断

- 掲載誌名や本文に検索語があるだけの記事は数えず、記事タイトル一致に限定します。
- 転機は、確定年のうち最低件数と前年差の条件を満たし、前年からの増加数が最大になる年として決定します。同点なら新しい年を選び、2026年は集計途中なので判定から外します。
- 代表記事は転機、ピーク、初出の年について、検索適合順の上位3件までを表示します。社会的な代表性を示す選定ではありません。
- 500件以下は取得した記録を集計し、500件を超える場合は年ごとの件数を最大5本ずつ取得します。一部の年を取得できなかった場合は欠損を隠しません。
- 同じ言葉のAPI応答は24時間キャッシュし、取得から60秒以上たった結果には「保存済みの結果」と表示します。
- 最近調べた言葉は端末内の `localStorage` に最大5件だけ保存します。サーバーには保存しません。
- グラフは表示領域の実幅で座標を計算し直し、700px未満ではx軸ラベルを4点に絞ります。集計途中の断りは折れ線・点線・丸印と重ならないよう、プロットの外（x軸の2026ラベルの下）に置きます。画面幅が変わったときはアニメーションなしで再描画します。
- 表への切替は推移カードの見出し行に置き、再検索とホームへの導線はボタンの役割が分かる配色に統一しています。原典リンクは枠のあるボタンにして、記事カードの中で押せる場所だと分かるようにしました。
- 文章は数字＋単位＋助詞と、定型文の文節（「なりました」「現れ、」「数えました。」など）を改行の禁止単位にしています。狭い画面で語の途中や助詞1字だけが行末・行頭に取り残されるのを防ぐためです。
- 画面でいちばん大きい文字は「今回の発見」の一文ひとつに固定し、見出し・年見出しはその下の大きさに揃えています。朱色は主要な操作と転機の印だけに使い、記事の年は補助文字色にしています。

## データの出典

- [国立国会図書館サーチ](https://ndlsearch.ndl.go.jp/)の雑誌記事索引メタデータ（`dpid=zassaku`）
- 数える期間は1997〜2026年。2026年は集計途中です。
- メタデータのライセンスは CC BY 4.0 です。
- 本文や表紙は取得しません。結果は社会全体ではなく、NDLサーチの収録範囲内の件数です。

## やらないこと

- 2語の比較、関連語の自動抽出
- 本文、表紙、要約の取得や表示
- 月別などへの粒度変更、期間変更
- 共有用画像の動的生成
- アカウント、サーバー側の検索履歴、アクセス解析
