# Day096 UXレシピ

予約・購入・応募など、目的を選ぶと、そのためのページが部品の並びとして組み上がる。部品は入れ替えられ、触るたびに「UXの流れ」と、理由つきの診断が更新される。
登録もインストールも要らない。作ったページは、このブラウザの中だけに保存される。共有を選んだときだけ、リンクや書き出したファイルを相手に渡す。

（作り込み中。使い方・仕組み・検証の記録は、仕上げの段階で書き直す。）

## 開発と検証
リポジトリのルートで実行する。

```sh
node --test day-096-ux-recipe/tests/
node day-096-ux-recipe/tools/serve.mjs   # 開発サーバー（本番と同じCSP）。部品ギャラリーは /tools/gallery.html
npm run build
npm run publish:check -- --day 96
```

外部のライブラリ・画像・書体・音は使っていない（書体は端末標準）。仕様と検証記録は [Day096仕様](../.kiro/specs/day-096-ux-recipe/tasks.md) を参照。
