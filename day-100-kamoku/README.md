# Day 100「kamoku」

日本の個人事業主向けの会計ソフト kamoku（Rust製のオープンソース・最初のアルファ版）を、ブラウザだけで試せるようにした回です。100日チャレンジの最後のDayです。

- 公開: https://rairakku.com/100days/day-100-kamoku/
- 本体のコード: https://github.com/haranishi/kamoku （コードは MIT OR Apache-2.0、文書と雛形は CC BY 4.0）
- ここに置いた画面とプログラムは、kamoku の main から組み立てたものです。どのコミットかは `build-info.json` にあります。手で直さず、本体を直して取り込み直します。

## 仕組み

kamoku は本来、手元のパソコンで小さなサーバーを動かし、ブラウザで画面を開くソフトです。このお試し版では、会計の処理と SQLite（メモリ上）もブラウザの中で動かし、画面からの要求をブラウザの中で受けます。サーバーはありません。

- 開くと、架空の事業の2026年の帳簿が入っています。
- 入力はそのブラウザの中だけにあり、再読み込みで最初の帳簿に戻ります。配信元以外への通信はしません。
- 帳簿が9月分までなので、画面の「今日」は2026年9月30日にそろえています。
- 帳簿の控え（バックアップ）は作れません。自分の帳簿をつけるときは、kamoku をソースから動かします。

## このDayで足したもの

- `day100/`: 画面の上の帯と、共有の窓。`shared/` は全アプリ共通の共有部品です。
- `tools/import-build.mjs`: kamoku で組み立てた結果を、このフォルダに取り込む道具です。
- このサイトの設定では、このDayにだけ、ブラウザ内のプログラム（WebAssembly）の実行を許しています。

取り込み直すときは、kamoku の作業フォルダで `bash tools/build-web-demo.sh` を実行してから、このリポジトリで次を実行します。

```
node day-100-kamoku/tools/import-build.mjs <kamoku>/target/web-demo <kamoku>
npm run shared:sync && npm run build
```

## 正直に書いておくこと

- 消費税の集計は、本則課税の見込みだけの参考値です。簡易課税や2割・3割の特例は計算せず、経過措置の適用条件も見ません。税理士の確認は済んでいません。
- 申告書の作成も、電子帳簿保存法への対応もしていません。
- 実際の帳簿で長く使った記録は、まだありません。
- 名前「kamoku」の商標は調べていません。
- スマートフォンの幅では表示と操作を確かめていますが、実機では確かめていません。
