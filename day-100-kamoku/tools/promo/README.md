# Day100「kamoku」の宣伝動画

縦 1080×1920・30fps・32.000秒（120 BPM・16小節・960コマ）。日本の個人事業主向け帳簿「kamoku」の実画面を、問いかけから行動まで一本で見せる。絵コンテの正本は `timeline.mjs`。映像と音が同じ表を読む。

出力はリポジトリの外。`mp4`・`wav`・`png`・`jpg` はコミットしない。

## 作り直し

先にリポジトリ直下で `npm run build` する。配信は撮影スクリプトが `scripts/serve-dist.mjs` を空きポートで起動する。

```sh
promo=day-100-kamoku/tools/promo
OUT="$HOME/day100-promo"   # リポジトリの外のフォルダ（省略すると一時フォルダ）
node "$promo/render-promo.mjs" --selftest
node "$promo/render-promo.mjs" --out-dir "$OUT" --no-encode
node "$promo/promo-audio.mjs" --variant a --out-dir "$OUT"
node "$promo/promo-audio.mjs" --variant b --out-dir "$OUT"
node "$promo/verify-audio.mjs" --out-dir "$OUT"
node "$promo/render-promo.mjs" --out-dir "$OUT" --encode-only --audio-dir "$OUT" --mux a,b
```

- `--selftest` はブラウザなしで、960コマ・字幕・安全域・合図を検査する。
- `--frames 0-90` は先頭から操作を再現し、その範囲だけ `preview-0-90/` に置く。書き出しはしない。
- 音の検査は −16 LUFS ±1、真のピーク −1.5 dBTP 以下、クリップ 0、無音の穴なし、合図 ±5ms。耳での試聴は未了。
- 単体試験は `node --test day-100-kamoku/tests/`。

## なぜこの作りか

上の y=0..210 は字幕専用の帯（紺一色。字幕と小さな札だけ）。その下（y=218）にアプリの窓（全幅・角丸）を置き、字幕はアプリに一切重ねない。アプリは幅 415px・高さ 560px の iframe を 540/415 倍にして窓にぴったり入れるので、横の金額も下の案内も切れない。寄りは「CSVで書き出す」（22.2秒〜）だけ。問い（0–1.5秒）・利益の札・自分のPCの札では窓の中をぼかす。締めは紺一色。

公開 URL `https://rairakku.com/100days/day-100-kamoku/` を配信用サーバーへ中継し、手元のアドレスは映さない。時計は画面が出てから `page.clock` で 1/30 秒ずつ進める。件数・売上・利益・仕訳のプレビューは画面から読み、固定で書かない。「早送り」の区間（9.0–10.7秒）は、2コマに1行ずつ実際に科目を入れる。

## 踏んだ罠

- 未確認の科目欄は、名前「科目（必須）」では見つからない。行の中の combobox を使う。登録画面の科目は名前で見つかる。
- `label.cand` を押すとチェックが二度切り替わる。`input.cand-check` の `check()` を使う。確定ボタンは、行を選ぶまで出ない。
- 「科目のある行をすべて選ぶ」は、科目が入っている行だけ。空のまま押すと 0 件になるので、先に科目を入れる。
- 「CSVで書き出す」はリンクなので、輪を置くだけで押さない（押すと画面が離れる）。
- 上の「お試し版」と 100日の帯は、スクロールで画面の外に出す。DOM からは消さない。
- 道具の先頭で `@playwright/test` を読むと、依存を入れる前の単体試験が落ちる。撮影関数の中で `await import()` する。
- 字幕は透明にせず、下から 14px 上げるだけ。JPEG は全範囲なので、書き出しは `in_range=pc:out_range=tv`。
- 止める子プロセスは、自分で起動した配信用サーバーの PID だけ。`pkill` は使わない。
- 時計を止めたあとは、`requestAnimationFrame` ではなく Node 側で要素を待つ。
- iframe の中を Playwright で押すと、外側のステージまでスクロールして字幕が画面の外へずれた。`stage.apply` が毎コマ原点へ戻す。
- 拡大したステージ越しのクリックは、下の案内で隣の項目（登録）に当たって止まった。下の案内は要素そのものを `click()` する。
- 画面（wasm-bindgen）は外した部品の `requestAnimationFrame` を取り消さず、偽の時計で進めると「closure invoked … after being dropped」で撮影が止まった。この例外だけ記録して先へ進む（実ブラウザでも捨てられるだけ）。
- 確定の直後は件数の表示が古い。前の値から変わるまで 50ms ずつ進めて読む（まとめての札が「24件 → 24件」になった）。
- ロゴは、アプリを3倍に拡大してステージから撮る。最初の apply の前は空の字幕の帯や数字札が左上に出ているので、撮る間はステージの飾りを全部隠す（隠さないと、ロゴに点と下線が写った）。写しの要素を作って撮ると、幅415を超えて欠けた。
- 札の行に `visibility: visible` を付けると、親の札を隠しても行だけ残った（利益の行が締めまで映った）。隠すときは行の指定も外す。
- 幅の狭い画面の仕訳のプレビューは1行の要約で、口座を打ち直す間は消え、決めたあとも少し遅れて変わる。空のときは直前の仕訳のまま見せ、普通預金と売上高が出そろったコマを記録して、保存まで1.5秒以上あるかを撮影中に確かめる。
- 上の帯（`#banners`）は、毎コマ上に貼りつく見出しの裏まで送る（字幕の裏に切れ端を映さない）。
- ぼかした背景で寄るだけの区間は、ffmpeg の `freezedetect`（n=0.005・0.8秒）で「止まっている」と判定された。札をゆっくり上下させる。
- 字幕はアプリの文字と重なると読めないので、紺の帯（不透明度0.9）に載せる。小さな札はその下（y=158）。

## 字幕と画面の照合

| 秒 | 字幕 | 画面 |
|---|---|---|
| 0.0–2.0 | 帳簿、また後回し？（札: 個人事業主の方へ） | 0–1.5秒はぼかした窓の上に問いと札「未確認 25件」（数字は橙・ホームの件数）。1.5秒で未確認の一覧を開く |
| 2.0–4.0 | 気づけば、未確認が25件。 | 「未確認 25件」の一覧が流れる |
| 4.0–9.0 | 科目を選んで、確定。 | 1行目: 4.0秒「消耗」→4.4秒 消耗品費→4.7秒 選ぶ→5.1秒「1件を確定しますか」→5.7秒 確定。2行目も同じ手順で8.5秒に確定。札「25件 → 24件」→「25件 → 23件」 |
| 9.0–12.0 | まとめて片づく。 | 9.0–10.7秒「早送り」で残り23行に科目。10.7秒「すべて選ぶ（23件）」→11.2秒に確定。ぼかさない「未確認 0件」の画面に札「25件 → 0件」 |
| 12.0–18.0 | 打つそばから、仕訳ができる。 | 収入・売上高・サンプル銀行 普通預金を先に決め、13.6–14.6秒に 220000 を1桁ずつ。下の札は画面のプレビューを毎コマ読み、打つたびに金額が変わる。15.6秒に保存、16.2秒にホームへ |
| 18.0–21.0 | 利益が、その場で分かる。 | 9月の数字: 売上 500,500円→720,500円、利益 335,489円→435,179円、増えた分 +99,690円（緑。画面の2値の差） |
| 21.0–24.0 | 帳票もCSVも、すぐ出せる。 | 月次推移→損益計算書→貸借対照表→22.2秒から「CSVで書き出す」へ寄る（押さない） |
| 24.0–27.0 | 本物の帳簿は、自分のPCの中だけ。 | 画面幅の9割の白い札（48px・注記24px）。小さく（ソースから動かす版） |
| 27.0–32.0 | （締めの札） | 紺一色に切り替え。ロゴ、無料・登録なし、CTA、枠で囲んだ URL 2行、100本目、断り書きを 27.0–29.7秒に段階で出す |

12.0–18.0 の字幕は幅のため2行。結合すると上の文になる。秒と数字は 2026-11-26 の撮影（`capture-report.json` の `reads`）で確かめた値。数字が画面と違うときは、字幕は変えず、札には読んだ値を出す。

## 音と権利

A案「未確認の朝」（ニ長調）、B案「帳簿の灯」（変ロ長調）。どちらも 0–4 秒は静かな導入、4.0 秒で拍が入る。確定と保存に合図を合わせる。音は Node の計算だけ。書体は Mac の Zen Kaku Gothic New（SIL OFL）。同梱しない。画面は架空の帳簿。
