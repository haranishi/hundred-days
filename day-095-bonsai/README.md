# Day095 盆栽日和

3Dの盆栽を、指で切る・針金で曲げる・芽を摘む。時間を進めると、モミジは芽吹き・新緑・紅葉・落葉と姿を変え、黒松は緑の針葉を保ち、梅は花を咲かせる。できた盆栽は、写真にして残せる。
登録もインストールも要らない。盆栽の手入れと途中保存は、このブラウザの中だけで行う。共有を選んだときだけ、アプリのリンクや写真を共有先に渡す。

## 使い方
1. 下の帯で道具を選ぶ。**見る**は、回す・寄る。**切る**は、枝を押さえると切る位置と切り落とされる枝が色づき、指を離すと切れる。枝のない所へ動かして離すと、何も切らない。**曲げる**は、枝を押さえたまま動かすと、そこから先が曲がる。離すと銅色の針金で固定される。**芽摘み**は、枝先を押さえる。
2. 「1週間」「1か月」「次の季節」で時間を進める。冬は伸びない。針金のある枝は、季節をまたいでも形を保つ。
3. 「元に戻す」で、30回までさかのぼれる。
4. 「写真」で、操作部のない縦長の画像を保存できる。対応する端末では、そのまま共有もできる。
5. 樹種（紅葉・黒松・梅）、樹形、鉢、光は、メニューから選ぶ。

スマホは1本指で回し、2本指で寄る。PCは、マウスとキーボードでも同じ操作ができる（`[` `]` で枝を選ぶ・Enter・矢印・Z・R・数字・Space。一覧はメニューの「キー操作」）。
作りかけは、この端末のブラウザだけに自動で保存される。動きを減らす設定では、動かさずに結果の姿へ切り替える。

## 仕組み
- 木は、節をつないだ骨格で表す。各節の向きは親の節を基準にするので、曲げると先の枝も一緒に動き、各節の長さは変わらない。太さは、分かれた先の枝の断面積を合計して親の太さの目安にする。一度太くなった枝は、切っても細くならない。
- 成長は、週ごとの刻み。季節ごとの係数で伸び、ゲームの中では冬は伸びない。乱数は固定するので、同じ樹種・樹形・シード値の苗から、同じ手入れと時間の進め方をすれば、同じ姿になる。
- 葉は、枝先ごとの塊に、小さな葉の板を重ねて描く。季節の色・量・花は、日付から連続して決まる。
- 鉢・卓・壁・樹皮・葉・音は、すべて実行時に作る。第三者の画像・音・書体・3Dモデルは使っていない。

## 手入れの説明について
アプリ内の手入れの説明は目安で、実際の栽培の指示ではない。作業の時期は、地域や樹種で違う。

## まだないこと
画面から針金を外すこと、複数の盆栽を同時に育てて保存すること、アカウントとオンライン保存、他の人の盆栽を見ること。

## 開発と検証
リポジトリのルートで実行する。

```sh
node --test day-095-bonsai/tests/
npm run build
npm run test:e2e -- tests/e2e/day-095.spec.mjs
npm run publish:check -- --day 95
```

3Dの描画には、three.js 0.186.0（MIT）をまとめたDay087と同じファイルを `vendor/` に同梱している（未改変）。書体は端末標準。
撮影・確認用の道具は `tools/`（配信しない）。仕様と検証記録は [Day095仕様](../.kiro/specs/day-095-bonsai/tasks.md) を参照。
