# Day095「盆栽日和」の宣伝動画

29.333秒（11小節）の縦型動画（1080×1920・30fps）。公開用ビルド（dist）を実際に操作して撮った画面だけで作る。
流れは、切りすぎると戻らない実物の盆栽の痛み → 枝を切る → 30回まで戻せると分かる → 針金で曲げる → 季節が巡る → 黒松と梅 → 写真にする → まず1本切ってみる。
絵コンテの正本は `timeline.mjs`。映像とBGMの両方がこの表を読む。

## 再生成

リポジトリのルートで実行する。公開用の dist を用意し、その親から `scripts/serve-dist.mjs` で読み取り専用で配る。既定は 127.0.0.1 のポート4292で、`--port` で変更できる。
撮影にはセットアップ済みの Playwright / Chromium、書き出しには ffmpeg / ffprobe が要る。実行ファイルは `FFMPEG`・`FFPROBE` でも指定できる。
字幕の既定書体は `~/Library/Fonts/ZenKakuGothicNew-{Bold,Black}.ttf`。`PROMO_FONT`・`PROMO_FONT_BLACK` で変更できる。

```sh
promo=day-095-bonsai/tools/promo
node "$promo/promo-audio.mjs" --variant a --out-dir "$PROMO_OUT_DIR"
node "$promo/promo-audio.mjs" --variant b --out-dir "$PROMO_OUT_DIR"
node "$promo/verify-audio.mjs" --out-dir "$PROMO_OUT_DIR"
node "$promo/render-promo.mjs" --site-dir "$PROMO_SITE_DIR" --frames-dir "$PROMO_FRAMES_DIR" --out-dir "$PROMO_OUT_DIR" --mux a,b
```

- dist の場所・コマの置き場・書き出し先は上記の引数か環境変数で渡す。コマの置き場と書き出し先はリポジトリの外に用意する。
- `--lanes 1` でブラウザを1つずつ使う（`--lanes 2` で並列）。`--only story --no-compose` で1テイクのみ、`--only overlay --no-compose` で重ねのみ。`--compose-only --mux a,b` で保存済みのコマから合成し直せる。
- `--only story --frames 96-145` は動画全体でのコマ番号（0始まり、両端を含む）。先行操作を再現し、指定範囲だけをコマの置き場の `preview-96-145/` に保存する。範囲指定では動画を合成しない。
- CSS 540×960・DPR 2のモバイル表示。ページの時計を止め、1/30秒ずつ進めて撮る。配信元以外のリクエストは遮断する。
- 画面はソフトウェア描画で撮るため、実機よりやや荒い。字幕、タップの輪、指、フラッシュ、終わりのカードは別ページで撮り、透明PNGとして重ねる。

| テイク | 撮る内容 |
|---|---|
| `story`（0–16秒） | 同じ紅葉で、枝を3本切る → 元に戻す3回 → 針金 → 季節送り3回。ボタンは実際の位置に輪を出して押し、枝は CDP のタッチで指を置いて操作する。切る間は視点がゆっくり回り、指は切る枝の画面位置を毎コマ追う。曲げる間は視点を止める |
| `trio`（16–21.333秒） | 黒松・梅を別々のページで開き、それぞれの木の周りを回す（黒松は逆向きに回し、卓の傾きが同じにならないようにする） |
| `photo`（21.333–24秒） | 直前の梅を正面から見て「写真」を押す。プレビューが読み込まれるまで実時間で待ち（ページの時計は止めたまま）、読み込み後にシートが上がる動きを撮る |
| `overlay`（0–29.333秒） | 字幕や指を重ねる。24秒からの終わりのカードは、梅（trio の最終コマ）を薄くぼかして背景にし、ゆっくり寄る |

切る枝と曲げる枝は、`timeline.mjs` の `node`（アプリの節のID）で指定する。候補をすべて実画面で試し、画面がいちばん変わるものを選んだ（切る：左の長い枝・左上の葉の塊・頂部の葉の塊、曲げる：左の枝の先）。指は、アプリの選択処理が同じ節を返す点に置く。`node` を書かない場合は `selectBranch` が、葉の被覆率（約4〜15%）で選ぶ。
視点は撮影用の軌道で動かす（使うカメラは普段の操作と同じもの）。木が画面に収まり、枝先が端に触れず、冠の上に字幕の余白が空くよう、距離13.3・注視点 [-0.5, 2.2, 0] まで引いてある。
`capture-report.json` で選んだ節のIDと座標、剪定・針金の実測コマ、効果音とのずれ、戻す前後の節数、季節遷移、写真の読み込みを確認する。

書き出しは `Day095_bonsai_promo_{silent,a,b}.mp4`、`first-frame.png`、`contact-sheet.jpg`（1秒ごと）、`cut-check.jpg`（切替の前2コマ・切替コマ・次の1コマ）、`capture-report.json`、`bgm_{a,b}.{wav,mp3}`、`audio-report.json`、`spectrogram-{a,b}.png`。

## BGMの展開

90 BPM・11小節。ドラムなしの弦と風のイントロ → 剪定の小節でドロップ → 元に戻す・曲げる場面で一定の拍 → 季節で音を足す → 木を見せる場面で厚くする → 写真で副旋律 → 終止和音と1.8秒のフェード。
A案は陽旋法の箏風の撥弦、低い太鼓、拍子木、パッド。B案はヘ長調のマリンバとベル。鋏、元に戻す、針金、季節、シャッター、タップの効果音も絵コンテのキューに従う。
検査では29.333秒の48 kHz・16bitステレオPCM、−16 LUFS±1、真のピーク −1.5 dBTP 以下、クリップ0、冒頭の立ち上がりとクリック、途中の無音、末尾0、ドロップ、鋏とシャッター前後100msのRMS差3 dB以上を確認する。
