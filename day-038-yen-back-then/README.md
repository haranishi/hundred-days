# Day 038「昔の1000円、いまいくら」

年を選ぶと、そのころの1,000円がいまのいくらにあたるかが出る。
逆に、いまの1,000円が当時いくらだったかも同じ画面に出す。

公開URL: https://hundred-days.pages.dev/day-038-yen-back-then/

## なぜ作ったか

「昔は安かった」は誰でも言うのに、**自分の年と結びついた金額**は誰も知らない。
ニュースが言う「物価上昇率3.2%」も「1994年比で…」も、自分の財布の話にならないまま流れていく。
物価の話が自分ごとになるのは、率ではなく具体的な金額を見たときだと考えて作った。

## データ

- 出典：世界銀行 World Development Indicators「Consumer price index (2010 = 100)」
  （指標ID `FP.CPI.TOTL`・年平均）
- 原データ：International Monetary Fund, International Financial Statistics
- ライセンス：CC BY 4.0。帰属と「加工した」ことを画面に常時表示している
- 取得先：`https://api.worldbank.org/v2/country/JPN;USA/indicator/FP.CPI.TOTL?format=json&per_page=400`
- **同梱しない**。指数は毎年あとから追加・改定されるので、古い数字を焼き付けない。
  起動のたびに1リクエストだけ投げ、日本と米国をまとめて取る

## 作らないと決めたこと

足が生えやすいので、着手前に決めて要件定義にも書いた。

- **将来の予想**。指数を外挿しない。確定した最新年より先の金額は出さない
- **賃金・給料**。物価と賃金を同じ画面に並べない（実質賃金の議論はデータの出どころが違う）
- **為替**。国際比較は「物価が何倍になったか」の倍率だけ。金額に換算しない
- **品目別**（「ラーメンは当時◯円」）。出典が別に要る。今日は総合指数1本で通す

## 設計で迷ったところ

- **丸の大きさは面積を価値に比例させた**（直径は平方根に比例）。直径を価値に比例させると、
  6倍の差が円の面積では36倍に見える。作図で嘘をつかないための平方根
- **答えを操作より上に置いた**。スライダーが上だと、親指がスライダーにある間ずっと
  答えが画面外に押し出される
- **前年比の丸め**。`flatYears` は比を小数第3位で丸めてから閾値と比べる。丸めないと
  100→100.5 が 0.49999999999998934 になって「ちょうど0.5%」が数に入り、
  100→99.5 は 0.50000000000000044 で入らない。同じ0.5%なのに上下で答えが変わる

## 構成

- `index.html` / `app.css` / `app.js` — 画面
- `lib/cpi.js` — 換算・倍率・前年比の数え方。DOMに触らない純粋関数だけ
- `tests/` — ユニット（`node --test`）と、E2Eが使う実応答のフィクスチャ
- 依存パッケージなし。バニラJS・ESモジュール
