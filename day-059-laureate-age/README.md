# Day 059 — その歳で、受賞した人

年齢を1つ入れると、その歳でノーベル賞を受けた人の数と顔ぶれが出ます。
0人なら「まだいません」と答え、近い歳と最年少・最年長の人も添えます。
分野を選ぶと、答え・一覧・年齢の帯が一緒に変わります。

## なぜ作ったか

受賞のニュースは「◯◯氏（54歳）」と年齢を添えますが、公式の一覧は年と分野からしか引けません。
「自分の歳で受賞した人はいるのか」を、年齢だけで引けるようにしました。
予想や評価は加えず、公式データから数えた事実だけを出します。

発表日の満年齢で数えると、30歳未満で受賞したのは1901年から3回だけです（17歳1回・25歳2回）。
20代が入れると、ほとんど「0人」になります。そこで、0人の答えを画面の主役にしました。

## 数え方

- 年齢は、受賞が発表された日の満年齢。同じ人が2回受けたら2回と数え、団体は数えません。辞退した人も数えます
- 生まれた月日が分からない人（20人）は7月1日生まれとして数えます。発表はどれも7月より後なので、実際は1歳若いことがあります
- 発表の前に亡くなっていた人（3人）は、亡くなった日の年齢です
- 辞退は公式データの状態のとおりに書き分けます。1958年のパステルナークは「辞退を強いられた」です
- 2026年10月6日時点で、個人のべ999回。年齢は17〜97歳、真ん中は60歳

## 今年の発表と端末への保存

今年（2026年）の6分野は、発表待ち・発表済み・データ待ち（発表予定の時刻を過ぎたが、まだデータに無い）を文字で示します。
発表の時刻は公式の予定を日本時間に直したもので、平和賞以外は「以降」です。
今年の分は Nobel Prize API の2本の応答から取り、取得時刻と一緒に localStorage へ保存します。
規約が負荷を抑えてキャッシュを使うよう求めているので、発表週は30分、それ以外は24時間は取り直しません。
取得に失敗しても、答えと帯の図は同梱データで出ます。前回の年齢も端末にだけ保存し、外へは送りません。

## データと出典

- 受賞者と賞：[Nobel Prize API 2.1](https://www.nobelprize.org/about/developer-zone-2/)（CC0・[利用条件](https://www.nobelprize.org/about/terms-of-use-for-api-nobelprize-org-and-data-nobelprize-org/)）
- 日本語の名前：[Wikidata](https://www.wikidata.org/wiki/Wikidata:Licensing) のラベル（CC0）。無い1人と、同梱の後に発表された人は英語のまま

同梱の `data/laureates.json` は `tools/build-data.mjs` で作ります。**生年月日と没年月日は配りません。**
画面と同じ計算（`lib/age.js`）で発表日の年齢にしてから書き出し、必要な項目だけを残しています。
コードはMIT、データは各提供元のライセンス（どちらもCC0）です。詳細は `data/SOURCES.md`。

API規約の商標の項（アプリの題名やロゴに名前・商標を使わない）に従い、題名・見出し・OG画像に「ノーベル」を入れていません。
名前を出すのは、説明の文と出典の欄だけです。このアプリはノーベル財団・Nobel Prize Outreach とは関係ありません。

## やらないこと

予想・候補者・推薦の話、写真や肖像（公式の写真は著作物）、メダルの絵、受賞理由の翻訳、国籍の表示（APIにあるのは生まれた国で、国籍ではない）、「遅咲き」のような評価の言葉。実行時に Wikidata へは接続しません。
