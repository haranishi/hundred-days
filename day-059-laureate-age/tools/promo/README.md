# 「その歳で、受賞した人」プロモーション動画

縦型1080×1920・34.5秒・BGM付き。絵コンテは `timeline.mjs`、音は `promo-audio.mjs`、画は `render-promo.mjs` の3本で完結する。

```sh
PLAYWRIGHT=/path/to/playwright/index.js node day-059-laureate-age/tools/promo/render-promo.mjs
```

出力は `promo.mp4` と `promo-first-frame.png`（どちらも gitignore 済み）。`promo-audio.wav` が無ければ `--variant a` で自動生成する。

## このDayで気をつけること

- **今年の分は固定資料で撮る。** `tests/fixtures/*-2026-1006-physics.json`（2026-10-06 18:53、物理学賞の発表後の実応答）を `page.route` で返し、時計も `?now=2026-10-06T21:00:00+09:00` に固定する。発表が進むと本物の画面は変わり、同じ画は二度と撮れない。映る数字は本物と同じ
- **api.nobelprize.org 以外の宛先は断つ。** 実行後のログに「断った宛先: なし」と出れば、外を読みにいっていない
- **字幕で賞の名前を出すのは話題としての言及。** 題名とエンド画面の大きな文字には使わない（API規約の商標の項）。エンド画面には出典と、ノーベル財団・Nobel Prize Outreach と関係がないことを小さく出す
- **評価の言葉を書かない。** 「遅咲き」「天才」のように人を測る言い方はしない（API規約は人をおとしめる使い方を禁じている）

## 字幕の数字は画面と突き合わせてある

`render-promo.mjs` の `expect()` が、書き出す前に画面の文字と字幕を照合して、違っていたら止まる。食い違ったら字幕を画面に合わせる。逆はしない。

| 場面 | 字幕 | 照合する画面の文字 |
|---|---|---|
| S1 | 1901年から、まだ0人 | 答えの読み上げ「26歳で受賞した人は、まだいません」、帯の下の「1901〜2026年」 |
| S2 | 26歳より若い受賞は999回のうち3回だけ | `#answer` の「のべ999回のうち3回」 |
| S3 | 最年少は17歳、最年長は97歳 | `#band` の「最年少 17歳」「最年長 97歳」 |
| S4 | 82歳なら、9人 | 答えの読み上げ「82歳で受賞した人は、9人」 |
| S5 | 今年の物理学賞も82歳での受賞 | 一覧の先頭「フランシス・ハルツェン」「2026年 · 物理学賞 · 82歳」 |
| S6 | 今年の発表も、そのつど入ります | 今年の欄の「発表済み」「フランシス・ハルツェン · 82歳」 |

## BGM

Day 039〜042 と同じ生成器（F メジャー・92BPM）を**中身を変えずに複製**した。録音やサンプルは使わず、コードで合成した音だけでできている。場面の秒数は `timeline.mjs` の `STORYBOARD` と `T_CONFIRM_TAP` から読むので、絵コンテを動かせば音も一緒に動く。
