# Day 059「その歳で、受賞した人」要件

## 何を答えるアプリか

年齢を1つ入れると、**その歳でノーベル賞を受けた人が何人いて、誰なのか**を1行で答える。

> 26歳で受賞した人は、まだいません。
> いまのあなたより若くして受賞したのは、のべ998回のうち3回。近いのは25歳の2人と30歳の1人。
> 最年少は17歳のマララ・ユスフザイ（2014年・平和賞）。

年齢を入れる前でも、受賞したときの年齢の幅（17〜97歳）と真ん中（60歳）が読める。
画面の下半分には、今年（2026年）の発表が並ぶ。発表済みの賞は受賞者と年齢、まだの賞は発表の日時。

## なぜ作るか

2026年10月5日〜12日は受賞の発表週で、ニュースは「◯◯氏（◯歳）が受賞」と年齢を添えて伝える。
見た人が思うのは「自分の歳で受賞した人はいるのか」。ところが受賞者の一覧は年や分野で並んでいて、年齢からは引けない。
年齢から引けるようにするのがこのアプリの仕事。独自の予想や評価はしない。出すのは公式データと、そこから数えた年齢だけ。

| 今年の分 | `nobelPrizes?nobelPrizeYear=2026`（6分野・発表日入り）と `laureates?nobelPrizeYear=2026`（生年月日入り）。合わせて約20KB | 2本を取って端末に保存し、同梱分に足す |
| 規約 | 負荷を抑える作りにし、何度も呼ぶ代わりにローカルのキャッシュを検討するよう求めている | 今年の分は端末に保存して、発表週は30分・それ以外は24時間おく |
| 件数 | 個人993人・のべ998回（2回受けた人がいる）、団体28・のべ31回 | 年齢は個人だけで数える。団体は数えないと画面に書く |

| 30歳未満 | 3回だけ（17歳1・25歳2）。18〜24歳と26〜29歳は0 | **0人が普通の答えになる**。0人のときの答えを主役として作る |
| 生年月日 | 20人は年しか分からない（`1948-00-00`）。7月1日生まれとして数えると、発表は7月より後なので実際は1歳若いことがある | 注記「生まれた月日が不明」。数え方の欄で1歳若いことがあると書く |
| 発表前に亡くなっていた人 | 3人（1931年カールフェルト・1961年ハマーショルド・2011年スタインマン） | 亡くなった日の年齢で数え、「発表の前に死去」と書く |
| 辞退 | 1958年パステルナーク（restricted）・1964年サルトル・1973年レ・ドゥク・ト（declined） | 数には入れる。declined は「辞退」、restricted は「辞退を強いられた」 |

## 使う人と、そのときの気持ち（ユーザーストーリー）

1. ニュースで「受賞（54歳）」と見た大学生として、**自分の歳で受賞した人がいるか**を、年齢を入れるだけで知りたい。いなければ、いないとはっきり言ってほしい
2. 0人と出た人として、**「いない」で終わらず**、いちばん近い歳の人と最年少の人を知りたい
3. 自分の歳が、受賞者みんなのどのあたりかを**帯の図で**見たい（何回の受賞が自分より若いか）
4. 今週ニュースを追っている人として、**今年の受賞者が何歳で受けたか**と、まだの賞は**いつ発表か**を知りたい
5. 物理だけ・文学だけのように**分野で絞りたい**
6. 名前を見て気になった人について、**何で受賞したか**（公式の受賞理由の原文）と公式の紹介ページへの入口がほしい
7. 結果を**Xに貼りたい**。「26歳で受賞した人は、まだいない」をそのまま共有したい
8. 回線が遅くても**すぐ答えが出てほしい**。次に開いたときは前の年齢が入っていてほしい

## UX5階層

- **戦略**：発表週のニュースを「自分の歳」に引き寄せる。1つの操作（年齢を入れる）で1行の答え。数字は公式データから数えたものだけで、評価や予想はしない
- **要件**：年齢の入力と即時の答え／0人のときの近い歳・最年少／年齢の帯の図に自分の位置／分野の絞り込み／今年の6分野の状態（発表済み・発表待ち・データ待ち）／受賞理由の原文と公式ページへのリンク／結果の共有／今年の分の端末保存と前回の年齢の保存
- **構造**：1画面。上から 題名 → 年齢の入力と分野 → 答え → 帯の図 → その歳の受賞者の一覧 → 今年の受賞者 → 数え方と出典
- **骨格**：スマホ縦1列が基本。答えの数字を最も大きく。分野のボタンは44px以上で、選択中は文字でも示す。PC（1280px）は最大幅を決めて中央、帯の図だけ広く
- **表層**：紙とインクの落ち着いた配色。金色とメダルの意匠は使わない（賞の商標・意匠に寄せない）。帯の図は単色で、自分の歳の列だけ1色を足し、文字の「あなた」を添える。ダークモードにも対応する

## 画面の仕様

### 題名と説明

- 題名は「その歳で、受賞した人」。**`<title>`・見出し・OG画像・アプリ名に「ノーベル」を入れない**（API規約の商標の項）
- 説明の文と出典では名前を出してよい（規約は出典としての表記を勧めている）。例：「1901年からのノーベル賞の受賞者を、受賞が発表された日の年齢で並べます」
- 出典の欄に「データ：Nobel Prize API（nobelprize.org・CC0）／日本語の名前：Wikidata（CC0）／このアプリはノーベル財団・Nobel Prize Outreach とは関係ありません」

### 年齢の入力

- 数字の入力欄1つ（`inputmode="numeric"`）。入れたそばから答えが変わる（送信ボタンは無い）
- 受け付けるのは 1〜120 の整数。それ以外は答えの代わりに「1〜120の整数で入れてください」
- 前回の年齢は端末に保存し、次に開いたときに入れておく

### 答え

- 1人以上：「54歳で受賞した人は、◯人」。0人：「26歳で受賞した人は、まだいません」
- 2行目：「いまのあなたより若くして受賞したのは、のべ◯回のうち◯回」
- 0人のとき3行目：「近いのは25歳の2人と30歳の1人」（下と上で最も近い歳。片側しか無ければ片側だけ）
- 最年少（と最年長）の人を、名前・年・分野つきで1行
- 分野で絞っているときは主語に分野を入れる（「物理学賞で、26歳で受賞した人は…」）
- 数え方の1行：「年齢は、受賞が発表された日の満年齢。1901〜2026年・個人のべ◯回（団体は数えない）」
- 結果の共有：X の投稿画面と、文をコピーするボタン。文は「26歳で受賞した人は、1901年からまだいません。— その歳で、受賞した人」＋URL

### 帯の図（SVG）

- 横軸が年齢（15〜100歳）、1歳ごとの棒の高さが受賞の回数。分野の絞り込みに従う
- 入れた年齢の列に印と「あなた ◯歳」。0回の歳でも印は出す
- 最年少・最年長の端に年齢の文字。図には `role="img"` と要約の `aria-label`

### その歳の受賞者の一覧

- 新しい年から。行に：日本語の名前（無ければ英語）・年・分野・年齢・注記（生まれた月日が不明／発表の前に死去／辞退）
- 受賞理由は原文（英語、`lang="en"`）を小さく。公式の紹介ページ（`https://www.nobelprize.org/laureate/{id}`）へのリンク
- 30行を超えたら「残り◯人を見る」

### 今年の受賞者（2026年）

- 6分野を発表順に。発表済み：受賞者と年齢、「10月5日（月）に発表」。発表待ち：「10月7日（水）18時45分以降の予定」。発表予定の時刻を過ぎたのにデータに無い：「発表予定の時刻を過ぎました。結果がデータに入りしだい出ます」（時刻を過ぎただけで発表済みと書かない）
- 取得に失敗し保存も無いとき：この欄だけ「今年の受賞者を取得できませんでした」と再試行ボタン。答えと帯の図は同梱分で動き続ける
- 保存した分を出しているとき：「◯時◯分に取った分を表示しています」
- 10月13日以降は見出しを「2026年の受賞者」にし、日時の列を外す

### 状態

`#app` の `data-state`（`loading`／`ready`／`error`）と、今年の欄の `data-live`（`loading`／`ready`／`stale`／`error`）、入力の `data-input`（`empty`／`valid`／`invalid`）。状態は色だけで伝えず、必ず文字を添える。

## 数え方（lib に純粋関数として置き、テストで固定する）

- 基準日は `dateAwarded`（発表日）。無ければその年の12月10日（いまのデータには無い）
- 生年月日の月か日が `00` なら7月1日とみなし、「生まれた月日が不明」の印
- 亡くなった日が基準日より前なら、亡くなった日の年齢で数え、「発表の前に死去」の印
- 同梱分は `tools/build-data.mjs` がこの計算を済ませた年齢を持つ。生年月日が届いた行（今年の分）は数え直す
- 同じ人が2回受けたら2回として数える（「人」は1回ごと。合計は「のべ◯回」）
- 同梱分と今年の分が重なったら、今年の分（API の新しい値）を使う。重なりの判定は（id・年・分野）
- 日時の比較は日本時間の文字列を `+09:00` 付きで `Date` にして行う。端末のタイムゾーンに依存させない。画面の時刻は `Intl.DateTimeFormat`（`timeZone: 'Asia/Tokyo'`）
- 確認用：マララ・ユスフザイ17・ローレンス・ブラッグ25・ジョン・グッドイナフ97・ラルフ・スタインマン68（発表の前に死去）・湯川秀樹42・坂口志文74

## 外部との通信

- 開くたびに `https://api.nobelprize.org` へ2本（今年の分）。端末に保存した分が新しければ取りに行かない
- 年齢はどこへも送らない。保存は端末の localStorage だけ（今年の分・前回の年齢）
- `scripts/build.mjs` の `CONNECT_BY_APP` に `https://api.nobelprize.org` を足す。`static/privacy.html` に送り先と中身を書く

## 動作確認の口

- `?now=2026-10-06T19:00:00+09:00` のように時計を固定できる（E2E・デモ・プロモ用。表示が変わるだけで、取得先は同じ）
- E2E では api.nobelprize.org を `tests/fixtures/` の実応答で返す

## やらないこと

予想・候補者・推薦の話／写真・肖像（公式写真は著作物）／メダルの絵／受賞理由の翻訳／国籍の表示（API にあるのは生まれた国で、国籍ではない）／ランキングや「遅咲き」のような評価の言葉
