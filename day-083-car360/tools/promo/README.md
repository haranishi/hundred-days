# Day083「カー360」のプロモーション素材

32秒の縦型動画（1080×1920・30fps）。公開版のアプリを実際に操作して撮った画面だけで作る。
夕暮れの橋を走る絵から始め、ショールームで車を選んで回し、ドアと色を変え、そのまま湾岸へ走り出し、最後は指で運転する。
音なしでも伝わるように字幕を重ね、BGM は別のスクリプト（`promo-audio.mjs`）が同じ絵コンテ（`timeline.mjs`）に合わせて作る。

## 再生成

リポジトリのルートで、依存関係と Playwright の Chromium を用意して実行する。
アプリは、隣に置いた公開版のビルド（`../car-360-public/dist-public/`）を、その中の `scripts/serve_public.mjs` で配って開く（読むだけで、ビルドし直さない）。別の場所にあるときは `--app-dir` で渡す。
ffmpeg / ffprobe と、ローカルの Zen Kaku Gothic New Bold が要る。別の場所の書体は `PROMO_FONT` で渡す。

```sh
node day-083-car360/tools/promo/render-promo.mjs --frames-dir <コマを置く場所>
node day-083-car360/tools/promo/render-promo.mjs --frames-dir <同じ場所> --compose-only --audio <BGMのファイル>
```

- 3Dの走行は実時間の録画では描画が間に合わない。ページの時計（`requestAnimationFrame`・`performance.now`・`Date.now`）を止め、1/30秒ずつ進めては撮る。1コマは約0.4〜1秒、全体で約15〜25分。
- 撮るのは CSS 540×960・DPR 2（実画素 1080×1920）。アプリの描画の解像度は、スマホ幅では 1.5 倍に抑える作りなので、撮影のときだけ 2 倍にする。
- テイクは4つ。`hook`（S0。2ショット。前半は夕暮れの橋を長めに撮り、`--hook-pick` のコマから2.13秒を使う。後半は同じ走行のまま撮らずに先へ進め、橋を渡った先の街並みの見える直線（約4,980m）を昼に撮る。夜に持ち上げを掛けた案と1秒ごとに並べて比べ、空と路面が明るく赤い車が際立つ夕暮れにした。`--hook-theme`・`--hook-lift` で別案を撮れる）・`showroom`（S1〜S3）・`drive`（S4。ショールームから続けて、実際に「ドライブを始める」を押し、アクセルを踏んでから約3秒は撮らずに進め、速度の乗った所から撮る。場所ごとのモンタージュで、ショットの頭で撮らずに次の場所へ進めて時間帯を替える。場所はコースを15か所×3時間帯で試し撮りして選んだ。`DRIVE_SHOTS` を参照）・`finger`（S5）。`--only drive` のように1つだけ撮り直せる。
- 字幕・帯・注記・進行バー・閃光・タップの輪・指・終わりのカードは、透明のコマとして別に撮り、ffmpeg で重ねる。
- 視点は全区間、追従（車の後ろ姿）。ボンネット視点は画面の下3分の1が塞がるので使わない。
- 走行のアクセルはキー、ハンドルは画面のハンドルをタッチで押さえて動かす（S0 の前半・S4 の PA 出発で車線をゆるく1回替える）。昼・夕暮れ・夜の3ショットとカーブは、アプリのクルーズで走る。S5 はハンドルとアクセルを指2本で押す。ハンドルは、コースの曲がり方と車の向き・横ずれから切れ角を出す簡単な制御。撮る区間が直線かは、アプリのコースの曲率で確かめて記録する。
- 撮影中は、配信元のほかへの通信をすべて止める。ページを開く前に `pointerlock-guard.mjs` を掛け、使っている人のカーソルを動かさない。
- 書き出し先は `output/`（Git の対象外）：`Day083_car360_promo_silent.mp4`（音なし）、`--audio` を付けたときは `Day083_car360_promo.mp4`（AAC・長さは32秒に固定）、`first-frame.png`、`contact-sheet.jpg`（1秒ごと）。

S2（ドアと色）の字幕だけは、詳細パネルが開いて操作パネルが上がるので、3Dの表示面の上側（上の帯と車の間）に置く。
路面に出る細い横線は、アプリが橋に25mごとに描く伸縮継手（意図した細工）。

字幕と帯には、メーカー名・車名・ロゴを出さない（「実在の名車」と書く）。車名が見えるのは、アプリの画面の札とメーターだけ。

## BGM を付ける

BGM の2案（`promo-audio.mjs --variant a|b`。検査は `verify-audio.mjs`）は、音なし版の映像を再エンコードせずに、音だけを AAC にして付ける。絵は音なし版と同じになる。

```sh
cd day-083-car360/tools/promo/output
ffmpeg -y -i Day083_car360_promo_silent.mp4 -i Day083_car360_bgm_a.wav \
  -map 0:v:0 -map 1:a:0 -c:v copy -c:a aac -b:a 192k -ar 48000 -ac 2 \
  -af apad=whole_dur=32 -t 32 -movflags +faststart -map_metadata -1 Day083_car360_promo_a.mp4
```

B 案は `bgm_b.wav` と `promo_b.mp4` に替えて同じ。
