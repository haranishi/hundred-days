# Day 083「カー360」

車を360度まわして見て、架空の湾岸コース（約5.8km）を運転できる3Dアプリです。ログインは要りません。最初に案内ページで、プライバシーポリシー・利用条件・著作権と商標・素材の出典を読み、確認して同意した人だけが使えます。スマホでも、指だけで操作できます。

- 公開サイト: https://day83.rairakku.com/
- `rairakku.com` の中の住所: https://rairakku.com/day83/（`day83.rairakku.com` へ転送します）

車は、コードで作ったオリジナル（架空）と、実在の車種の3Dモデルから選べます。実在の車種のモデルは、メーカーとは関係のない第三者が作り、Sketchfab で CC BY 4.0 として公開しているものを、作者の表示つきで使っています。ロゴ・エンブレム・ナンバーなどの部品は取り除きました。メーカーの公認や協力は受けていません。車名・商標・意匠は各社に帰属し、CC BY は商標や意匠の許諾ではありません。エンジン音は、実際のエンジンの録音（CC0）を回転数に合わせて重ねたものです。車種そのものの録音ではありません。コースは架空で、実際の道路の再現ではありません。
