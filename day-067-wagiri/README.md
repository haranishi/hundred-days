# Day 067「輪切り」

日本語のサイトの広告を減らし、本文を読みやすくするChrome拡張です。無料で使え、アカウント登録は不要です。

## できること

- 広告全般と日本語サイト向けのフィルタで広告をブロックする。
- 表示が崩れたサイトでは、そのサイトだけ輪切りをオフにする。
- 残った広告や不要な部分を、自分で指定して消す（無料版は10か所まで）。
- 広告の判定はブラウザ内で行い、閲覧履歴の一覧を記録・外部送信しない。

## 使う

- [Chrome ウェブストアで追加する](https://chromewebstore.google.com/detail/aalgejlgocflbdjlkoalkoolmcmednmn)
- [輪切りの紹介サイト](https://wagiri.pages.dev/)
- [プライバシーポリシー](https://wagiri.pages.dev/privacy/)
