# 外部アンケートの参考資料

調査確認日：2026年10月28日。以下は質問を増やす際の参考資料です。このゲームの回答票・普通度・サバイバル判定には使いません。初期データに外部の票を登録する処理もありません。

## 日常：カレーの食べ方

- 出典：[Jタウンネット編集部の読者投票（2017年4月28日公開）](https://j-town.net/2017/04/28242645.html?p=all)。
- 期間・人数：2017年3月23日〜4月19日、1,252票。サイト上の任意参加投票を都道府県別に集計。無作為抽出調査ではありません。
- 確認できた結果：ご飯とルーを混ぜる回答が29.6%、混ぜない回答が70.4%。
- 本ゲームとの差：本ゲームは「食べ始める前」に限定。元調査は混ぜる時点を限定していません。古い任意参加投票なので、現在の全国割合や本ゲームの正解にはできません。

## 恋愛：初デートの食事代

- 出典：[結婚相談所「オーネット」調査（2026年4月28日公開、5月8日更新表示）](https://onet.co.jp/announce/release/2026/20260428/)。
- 期間・人数：2026年4月8〜15日、全国25〜34歳の独身者373人（男性194人・女性179人）。インターネットによるクローズ調査。
- 確認できた結果：初デートの支払い方を複数の選択肢から1つ選ぶ設問で、状況に応じて考える回答27.1%、男性負担を基本とする回答26.0%、割り勘を基本とする回答23.9%。
- 本ゲームとの差：これは二択ではありません。残る選択肢を除いて割合を二択に変換すると別の集計になるため、そのまま流用しません。年齢・婚姻状況も限定されています。

## お金：現金かキャッシュレスか

- 出典：[クロス・マーケティング「2025年総決算！あなたはどっち？」（2025年12月24日公開）](https://www.cross-m.co.jp/news/release/20251224)。
- 期間・人数：2025年12月19〜21日、全国47都道府県の20〜69歳男女1,100人。QiQUMOを使ったインターネット調査。
- 確認できた結果：日頃の支払いについて現金かキャッシュレスかを選ぶ二択で、キャッシュレスを選んだ回答が60.5%。
- 本ゲームとの差：金額や場面を限定する問いに変えると比較対象が変わります。日本全体の決済金額に占めるキャッシュレス比率とも異なります。
