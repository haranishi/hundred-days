# あなたの普通、何％？

3Dの道を選んで「普通度」を知る、登録不要のブラウザゲームです。
Next.js App Router / TypeScript / Tailwind CSS / three.js。
データベース・認証・回答の自動収集はありません。

## ローカルで遊ぶ

```sh
npm ci
cp .env.example .env.local
npm run dev
```

http://localhost:3017 を開きます。最初の依存インストール後、
ゲームの進行は外部サービスに依存しません。
割合は**練習用のお試しデータ**です。実際の参加者の集計ではありません。
プレイヤーの選択は割合に加算せず、何度でも自由に選び直せます。

## 遊び方

- 日常・恋愛・お金の各7問。タップ・スワイプ・←→キーで走る道を選びます。
- 短いカウントダウンの後、ゲートが約6秒で接近。通過後は割合を表示し、自動で次の問いへ進みます。
- 未選択ならゲート手前で待機。右上の一時停止やEscapeキーで休めます。
- BGM・足音・効果音は、初回のプレイ開始でオンになります。右上のスピーカーで切り替えられます。
- 停止画面でBGMと足音/効果音の音量を別々に調整できます。ミュートと音量は次のプレイにも引き継ぎます。
- 問いに応じて「はい/いいえ」やA/Bを使い、自分の回答が書かれたゲートを選びます。
- サバイバル：練習データの少数派を選ぶと転倒し、その時点で終了。
- 7問完走：割合にかかわらず最後まで進みます。
- 同数は続行。将来実調査を入れた場合も、30回答未満では終了しません。
- 普通度は選んだ側の割合を平均し、最後に四捨五入した値です。
- 途中終了時は回答済み問題だけの平均です。科学的な性格診断ではありません。
- 結果URLには固定した練習結果を含みます。誰でもURLを知れば読めます。

プレイ状態はこの端末内に保存します。保存を拒否してもメモリ上で遊べます。
保存を利用できない場合、ページを閉じるとプレイ状態は消えます。
結果の共有はX・LINE・端末共有・リンクコピーに対応します。
共有ボタンを押すまで外部SNSに結果を送信しません。

## 外部アンケートを反映する手順

1. 運営者がDMやGoogleフォームで「調べてほしいテーマ」を受け取る。
2. 運営者が設問・二択・対象者を決め、ゲーム外でアンケートを実施する。
3. 元の集計を確認し、対象者・実施日・出典URLを記録する。
4. `src/data/survey-results.ts` の該当データを更新する。
   現在は全21問が `kind: 'practice'` の練習割合です。
   実調査の形式は `VerifiedSurveyData` 型を参照してください。
5. 表示ラベル・出典・対象者・サンプル数を実調査に合わせて更新し、再検証する。

実調査を入れる前は、練習データを実際の投票として表示しないでください。
外部調査とプレイヤーの回答を自動で混ぜる処理はありません。
参考に調べた公開アンケートは `docs/` にありますが、現在の割合には使っていません。

テーマ受付リンクは `.env.local` の `NEXT_PUBLIC_SURVEY_FORM_URL` と
`NEXT_PUBLIC_SURVEY_DM_URL` に公開HTTPS URLを設定します。
未設定のリンクは表示しません。秘密情報や認証付きURLを設定しないでください。
公開先URLは `NEXT_PUBLIC_SITE_URL` に設定し、canonical/OGPに利用します。

## 検証と起動

```sh
npm test
npm run typecheck
npm run lint
npm run build
npm run start
npm run test:e2e
```

単体テストはスコア・終了条件・自由な再プレイ・二重入力の無害化・
固定結果の検証、音声の開始・停止・再利用と設定保存、保存領域が利用できない状況を確認します。
E2EはPlaywrightとChromeが必要です。
本番デプロイや外部DBの作成は行いません。
音の既定オンと3周の品質確認の記録は [.agent-harness/runs/verification-v5.md](.agent-harness/runs/verification-v5.md) を参照してください。

E2Eは通常GPUで実行します。ソフトウェア描画の確認は `PLAYWRIGHT_SOFTWARE_GL=1 npm run test:e2e`。
Chromeの場所を変更する場合は `PLAYWRIGHT_CHROME_PATH` を設定してください。
