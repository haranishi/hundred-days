# Day64 日本の公表・報道記録を2,522件へ拡充

その後の地球儀・地理探索の改善と最新の検証は [地球儀の報告](GLOBE_REPORT.md) に保存しています。この報告は国内拡充時点の記録です。

実施日: 2026-10-11。依頼は「日本の侵入されたデータを、今の10倍・100倍くらいに増やす」。[工程契約](../../../.agent-harness/contracts/day064-japan-expansion.md) に沿って、公開資料の取得、取込、確認状態と出所の表示、実ブラウザとローカル配信物の検証まで完了しました。前段のUI改善は [以前の報告](READABLE_UI_REPORT.md) に保存しています。

固定コミットは `17fb7a537b6afa106f509a5ad77cbed7712cd3c2`。各入力の取得URL・SHA-256・件数は [取込マニフェスト](../research/japan-notice-manifest.json)、全3,122行の判断と対応IDは [全行の取込台帳](../research/japan-notice-coverage.json) に保存しています。既存201記録のID・数値は保ち、資料の一致した64行は参照を追加しました。

取込はPython標準ライブラリの `import-japan-notices.py` で行います。日付の形式・未来日、海外主体、対象外の障害、資格情報入りURL等を除外します。同じ組織内の同一日付、事案ID、原発表URL、明示された続報参照でまとめます。共有ホームページ・年代別一覧のURLだけでは異なる事例をまとめません。

公表本文・記事本文・写真・見出し・アーカイブのプログラムはアプリへ複製していません。組織名・日付・参照URL等の事実項目と、独自に記述した説明を収録しています。取得ZIPとHTMLは作業用の一時領域に保持し、配信物へ入れていません。記事・一覧のリンクと説明には媒体名「サイバーセキュリティ.com」を表示しました。[同媒体の引用方針](https://cybersecurity-jp.com/topics/32835) も確認しています。

## 公表と情報流出を区別する実装

追加2,321記録の入力元は公表文の公開アーカイブ1,504、国内事例索引817です。原発表を確認した1記録を別途更新したため、最終データの出所区分はアーカイブ1,504・報道一覧816・公式発表確認1です。入力マニフェストの817は、取込時点の入力元を示しています。

一括収録した追加記録の基本状態は「公表・報道記録」。全例を流出確認済みとして扱いません。原因は資料の用語から整理した分類で、侵入経路・攻撃者・情報流出を独立に認定していません。全2,321記録の人数・件数の集計値は未確定のまま保持しています。

報道一覧の日付は公表日・発生日・報道日が混在します。詳細にその定義を表示し、年グラフと一覧も「記録の年」「記録の日付」としました。原発表・保存された公表文・報道記事を見分けられる出所表示とリンク名を使用しています。古い原発表リンクが失効している場合もあるため、保存版の参照を併記し、全リンクの現在の到達を保証する表示にはしていません。

代表例の原発表を読み、[照合結果の更新ファイル](../research/japan-notice-reviews.json) へ反映しました。

| 代表例 | 原資料で確認した結果 | データへの反映 |
|---|---|---|
| 川崎市・かわさき新産業創造センター | 最終報で個人情報等の流出なしと公表 | 流出なしの説明・状態表示。調査対象27件/22人を流出人数に置き換えない |
| 慶應義塾大学 | 不正アクセスと改ざんを公表。個人情報等の流出は未確認 | 情報流出未確認と表示し、合計値を設定しない |
| ローソン | 第三者の不正アクセスによる情報流出を公表。対象は215万5,345件と別区分26件 | 公式発表へのリンクを先頭にし、流出確認へ更新。「件」を人数へ変換せず、区分間の重複が不明なため合算しない |

原資料: [KBICの最終報](https://kbic.jp/news/2327/)、[慶應義塾大学の公表](https://www.keio.ac.jp/ja/news/20260619-2/)、[ローソンの公表](https://www.lawson.co.jp/contents/cont07/1533174_3310.html)。公開アーカイブは保存された公表文の照合に利用していますが、追加全件を各発表元の現在のサイトで個別に再確認したものではありません。

「日本の外部侵入を見る」を追加し、国内・外部侵入の1,622記録へ一操作で進めます。確認状況・年・検索でさらに絞れ、ランサムウェア280記録は原因の選択から開けます。出所と確認状態は別々に表示します。

全15,871記録のRustとJavaScriptの検索・条件集計・並べ替えが一致し、159個の分割詳細が全IDを一度ずつ解決することを確認しました。追加「公表・報道記録」のフィルタは2,320記録を返します。ローソン1記録は原発表に基づいて流出確認へ更新したため、この状態の対象外です。国内の外部侵入かつ公表・報道記録は1,497です。

増加後の検査では、旧検査の「組織名で見つかった先頭が既存の一件」という前提を調整しました。尼崎市の既存事例はIDで確認し、LINEヤフーは複数記録の中に既存事例が残ることを確認します。参照URLの検査にも取得元の事例一覧URLを加え、資料との対応・URLの安全な形式を保持しています。既存の訂正値や確認状態を、新しい別記録へ置き換えていません。

実ブラウザでは国内の入口、流出なし・流出確認・報道一覧の表示、媒体名、日付定義、原資料、24件のページと末尾7件を確認しました。既存の検索・規模単位・共有・キーボード・描画喪失からのSVG復帰、Wasm/Worker/索引/詳細の取得失敗時の復帰も成功しています。一覧の日付説明を整えた後も、最終版の全22件を実行しました。

390/768/1440/1920pxの画像と1024pxの検索導線を検査しています。主担当が [デスクトップ](japan-expansion/history-desktop.png)、[日本のスマホ表示](japan-expansion/history-mobile-japan.png)、[日本のタブレット表示](japan-expansion/history-tablet-japan.png)、[流出なしの表示](japan-expansion/japan-no-leak.png)、[報道一覧の表示](japan-expansion/japan-news-reference.png)、[OGP](japan-expansion/history-og.png) を実際に閲覧しました。
