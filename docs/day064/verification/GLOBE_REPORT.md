# Day64 公表記録を地球儀から探す

実施日: 2026-10-11。[Kasperskyのサイバー脅威マップ](https://cybermap.kaspersky.com/ja) を実ブラウザで確認し、暗い地球儀・光点・回転・ズーム・平面表示を参考にDay64を改修しました。[工程契約](../../../.agent-harness/contracts/day064-globe.md) と [UX5・設計](../globe-design.md) に沿ったローカル版です。

初期画面は地球儀。光点または地域選択から記録を絞り、24件ずつの一覧と詳細・原資料へ進みます。検索、原因、年指定、過去資料の年代再生、既存の記録一覧・単位別比較・原因マップが連動します。3Dが使えない時・操作中に失われた時は平面地図へ復帰し、条件・記録・フォーカスを保ちます。

## 地図で表しているもの

全15,871記録を92の国・地域へ集約し、各記録が一つの地域にだけ対応することを全件照合しました。日本2,522、米国13,349の収録数・規模・確認状態・出典は保っています。記録数は独立した事故数・被害者数ではありません。現在の攻撃を検知・表示する機能はありません。

| 対応 | 記録数・根拠 |
|---|---|
| 国内の都道府県 | 221記録・38都道府県。組織名に一意に明記された都道府県名のみ |
| 日本・地域未特定 | 2,301記録。資料に関連する国の代表点へ集約 |
| HHS | 報告組織の州・地域。無効・未記載は米国・地域未特定 |
| California | 通知対象の州としてCaliforniaへ。事故地点や本社の州とは扱わない |
| 国単位の全記録 | 日本2,301＋米国23＝2,324 |

都道府県名の照合は非重複の語として行います。「東京都府中市」を「東京都」と「京都府」の二重一致にしない回帰検査も追加。複数の都道府県が明記される名称や、名称に地域がない企業は日本へまとめます。

位置は地域の代表点で、事故・攻撃元・サーバー・本社の座標ではありません。推測した攻撃経路は描画しません。各詳細に対応地域と根拠を併記しています。地形127ポリゴンと地域代表点101件は [Natural Earthのパブリックドメインデータ](https://www.naturalearthdata.com/about/terms-of-use/) から生成。[固定入力とSHA-256](../research/geo-manifest.json) を保存し、画面と同梱通知にクレジットを入れています。Kasperskyのコード・画像・ブランド・検知データは使っていません。

## 軽量化と実測

地域フィルタをRust/Wasmへ追加。既存の28バイトの索引レコードの予備1バイトへ地域IDを置き、レコードのバイナリサイズは増やしていません。検索Workerは座標・名称のカタログを含めず地域コードだけを取得。コード分離前16.94KBから最終6,052バイトへ縮小しました。

地球儀は全検索結果を地域ごとにまとめて描画し、15,871個の個別事例を一度に描画しません。動いていない時は連続描画せず、変更時だけ描画します。全件索引3,838,832バイト、地形86,325バイト、Wasm52,644バイト。全件JSON28,659,725バイトはダウンロード用で初期表示では取得しません。詳細は100件ごとの159ファイルから必要時のみ読み込みます。

[ローカルChromium実測](globe-ui/performance-browser.json): 全15,871記録・72試行でRust検索/集計の中央値0.4ms、p95 0.6ms、Worker往復中央値0.5ms。通常一覧の入力から表示まで12試行の中央値188ms、p95 200ms（90msの入力待機を含む）。地球儀描画のFPS、物理スマホ、公開環境の速度は未測定です。Three.jsの共有描画コードは約560.55KB（gzip138.28KB）で、地図を開く時に取得する分割コードです。ビルドの500KB警告はこのコードに対するもので、失敗ではありません。

## 残る制約と優先度

1. 位置の確かさ: 国内の大半は地域未特定。資料がない都道府県や本社位置を推測しない。根拠のある地域情報を追加できれば、国内表示をさらに細かくできる。
2. 密度: 日本周辺の点は集中する。地域選択・集約・衝突を避けるラベルで探索を補う。点の一覧には全92地域を保持する。
3. 小さい画面: 操作は動くが、4表示タブ・原因凡例は横スクロール。検索や条件解除は現在の視野を保つため、地域が視野外の場合は地域選択・「日本へ」・表示を戻す操作を使う。入口と視野移動には改善余地がある。
4. 性能: 3D初期取得にはThree.jsの共有コードが必要。物理端末のGPUと低速回線での描画は別途実測が必要。
5. 更新とデータ範囲: 静的スナップショット。日本・米国の公表資料であり、世界の全事故・リアルタイム検知や長期の利用体験を保証する資料ではない。
