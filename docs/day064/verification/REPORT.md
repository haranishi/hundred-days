## 改善TOP5と実施したループ

1. **単位と確定範囲の誤読を避ける**: 件/人/IDを分離し、上限・概数・推計・可能性・不明をノートとノードに表示。
2. **スマホのラベルを読めるようにする**: 狭い画面の配置、他のラベル・球・原因ハブ・下の説明を考慮した位置を調整。単位タブの改行も解消。
3. **ゼロ件からの復帰を確保する**: 空の一覧を閉じ、結果パネルをスクロール可能に変更。別単位へ直接移れるボタンを追加。
4. **入力方法と画面幅で導線を失わない**: 1024pxの年フィルタ、スマホのスキップリンク・フォーカス復帰、SVGピンチ後の誤選択を検査。
5. **回転後も選びやすくする**: 初期のラベル衝突は修正済み。強い回転の密集には全体表示・一覧が使える。追加の自動配置調整は今後の改善候補。

製品の改善は最大3周に収めました。第1周でラベル・文字・フィルタ・スキップ導線、第2周でゼロ件パネルと別単位への移動・タッチ操作を改善。第3周はSVGの初回描画前にviewBoxを読んだテスト側の待機を修正し、17件成功。後の5分評価の修正は、製品変更を含まない記録処理の復旧です。同じ製品不具合を2周続けて残していません。

## 2026-10-11 再開: 操作中の3D表示喪失からの復帰

`fail3D()` から既存の `setMode('2d')` を呼び、描画要素とモードの状態を一緒に更新するように修正。選択企業と事例URLを保ち、フォーカスが3Dマップにあった場合はSVGへ引き継ぎます。

- 修正後の回帰検査: 成功。SVGの表示、3Dボタンの無効化、選択ノート・URLの維持、フォーカス、矢印で移動、全体表示への復帰、ノード選択、検索後の選択と公式資料への導線を確認。
