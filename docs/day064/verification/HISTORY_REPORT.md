## 実装と機械検証

- Rust標準ライブラリ以外のCargo依存を追加せず、検索・フィルタ・全件数・条件別の年代/原因/単位等の集計・ソートをWasm化。Workerで実行します。実ブラウザで `rust-wasm-worker` の稼働を確認。
- 初期表示は軽い全件索引と24件のページ。詳細は100件ごとの136ファイルから必要時だけ取得。全件JSONと3Dコードは初期表示で取得しないことをリクエストで検査。
- 3Dは必要時に読み込み、最新120記録まで。古い選択記録も120件の枠内で保持。全記録は時系列・検索・ページ送りで探索できます。
- Rustネイティブ **5/5成功**。データ・主要ロジック・実Wasm・分割詳細の検査 **13/13成功**。Rustと代替処理を全件・地域・資料・単位・原因・状態・年代・別名・順序の条件で照合し、索引13,550件すべてを検査。
- Chromiumの通常ブラウザ検査 **19/19成功**、失敗・スキップ・再試行0、18.2秒。[実施結果](browser-history-results.json)。390/768/1440px、1024px、検索・履歴・比例棒グラフ・原資料、キーボード、フォーカス、動きを減らす設定、共有URLを確認。
- 実際の `WEBGL_lose_context` による描画喪失から、選択・URL・フォーカスを保ってSVGへ復帰。WebGL不可・Wasm取得失敗・Worker起動失敗・初期データ/詳細の取得失敗も復帰できました。

検査用の数値期待を修正した箇所は、HHSの空欄分類1件と人数未記載1件です。元データを架空の値で埋めて検査を通したものではありません。

## 体験と改善ループ

初回の長時間探索では、3Dから初めてSVGへ切り替えた直後に、検査が初回描画前の球をクリックしました。選択が切り替わらず6場面の後で中断。短い診断で描画後の実ポインターイベントと球の中心位置を記録すると、DIONの3,996,789人へ選択が変わりました。[診断](sphere-diagnostic.json)。記録処理をSVGの初回描画完了を待つ形へ修正。製品の球選択は通常検査と実クリックで確認しています。

製品の改善は3周内です。初期画面を確認し、数値の注意に残った実装用語・カード間隔を修正。次にグラフ更新時のキーボードフォーカスとスクリーンショットのスキップリンク表示、原資料の重複数えを修正しました。同一の製品不具合を2周続けて残していません。

修正後の長時間探索は **1/1成功、308.8秒、10場面、ブラウザエラー0**。[操作記録](history-experience.json) に各場面の選択・数値・出典・実Wasmの稼働状態を保存しました。全履歴の分布、KDDIの別事故、ぷららの訂正値、2014年の同単位比較、HHSの報告人数、CAの通知日と発生日、3D操作とSVGの球選択、ゼロ件からの復帰と最古のページ、390pxでの検索とノート、取込記録と共有を実際のChromiumで操作しました。10場面の画像と出典ノートを主担当が確認しています。自動操作と画像レビューによる評価で、人のユーザーテストではありません。
