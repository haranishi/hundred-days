# Day64 公開前の規約・著作権・法令確認

確認日: 2026-10-12。対象: Day64の配布ファイル、公開リポジトリへ追加するソース・調査台帳・検証記録、32秒のプロモーション動画。公開前に確認した一次資料と、実際に配布する内容を照合した技術的なレビューであり、弁護士の法律意見・適法性の保証ではない。

## 確認結果と修正

原資料の本文・写真・ロゴ・漏えいした本人情報を転載する構成ではない。収録するのは公表主体・組織名・資料に記載された日付・規模・参照URL等の事実項目と、本アプリ独自の整理・説明である。以下を修正した上で、今回の範囲をPRに進める。将来の全文転載・一覧の販売・転載許可の一般化まで認める判断ではない。

- 自治体の掲載行から原資料の件名と所管課に混入した電話番号を削除。件名は本アプリ独自の「紛失・盗難など」等の整理区分へ置換し、原資料へのリンク・掲載No.・ページ番号を残した。全3,149行の取込台帳にも同じ処理を適用した。
- サイバーセキュリティ.comの対象記録の本文付近に媒体名・著作権・加工説明を明記。PPC・IPAの資料を用いる記録にも出典と本アプリによる整理・加工を明記した。
- リポジトリ全体のMIT表記から第三者データ・資料・ライブラリを明示的に除外。PyMuPDFを利用する3つのオフライン抽出ツールとその取込テストはAGPL-3.0-or-laterとし、完全な許諾本文・対応ソースを公開する。
- Wasmのビルド時にローカルパスを除去し、公開するブラウザ検査報告からホーム・作業ディレクトリを除去した。私的な検査パターンは公開しない。
- 35MB超の非圧縮公開JSONをgzipに変更。18,001記録の内容を保ったまま約2.54MBで配布し、ホスティングの単一ファイル制限に収めた。

事実項目と創作的な本文・選択・配列は区別する。これは著作権法第2条、第12条、第12条の2と、文化庁の[事実・アイデアの説明](https://www.bunka.go.jp/seisaku/chosakuken/seidokaisetsu/chosakukensha_fumei/)を確認した上での今回の実装判断である。出典を付ければ無制限に転載できるとは扱わず、第32条・第48条も確認した。公開JSONを包括的なMITデータとして販売・再配布できるとの許諾は出さない。第三者の一覧の創作性・契約の適用範囲は残る判断論点であり、全文・大量の原表・有料提供へ範囲を広げる場合は権利者への確認を含む別の審査が必要。

検索語は端末内で処理し、URL・解析サービスへ送信しない。本アプリに閲覧履歴の記録・解析・広告機能はない。一方、ページ・分割データの取得はCloudflare PagesへHTTP通信し、IPアドレス等のアクセス情報・共有IDを含むURLは配信先へ渡り得る。「外部送信が一切ない」との保証はせず、画面とREADMEに[Cloudflareの方針](https://www.cloudflare.com/privacypolicy/)と境界を明記した。

## 個人情報・名誉・アクセス方法

流出した顧客名・住所・メールアドレス・電話番号・認証情報・原本の漏えいファイルを収集・配布しない。公表上の事業者・組織名には個人事業者名が含まれ得るため、「個人名を一切扱わない」とは宣言しない。公開されている情報であってもプライバシーや名誉の問題が消えるわけではない。

資料の「おそれ」「当局への届出」「公表・報道」「未確定」を区別し、規模不明を推計しない。例えばKDDI DIONの原因を根拠なしに不正アクセスへ分類しない。記録数を被害者数・独立した事故数・地域の危険度へ読み替えず、学習を目的としたUI・動画にする。訂正窓口は[リポジトリのIssues](https://github.com/haranishi/hundred-days/issues)を表示し、個人情報を添付しない案内を置く。

[刑法第230条・第230条の2・第233条](https://laws.e-gov.go.jp/law/140AC0000000045)と[民法第709条](https://laws.e-gov.go.jp/law/129AC0000000089)を確認。真実・出典・免責表示があるだけで名誉毀損等の責任がなくなるとの説明はしない。

取得元は認証なしの公表ページ・公式CSV・公表リポジトリ。ログイン回避、脆弱性の利用、他人の認証情報、盗難データ売買、流出先へのアクセスは行わない。[不正アクセス禁止法第2条・第3条](https://laws.e-gov.go.jp/law/411AC0000000128)を確認。robotsの不存在は転載許可と解釈せず、取込はスナップショットで、Webアプリが閲覧者ごとに出典を大量取得する構成ではない。

法令はe-Gov法令API v2の全文から該当条文を確認した。[著作権法](https://laws.e-gov.go.jp/law/345AC0000000048)の取得版 `345AC0000000048_20260624_508AC0000000048`、刑法 `140AC0000000045_20260521_507AC0000000039`、民法 `129AC0000000089_20260624_508AC0000000045`、不正アクセス禁止法 `411AC0000000128_20250601_504AC0000000068`。法律・規約が変わるため、取得済みの判断を将来へ無条件に延長しない。
