# Day64 社会的意義とUI整理の検証

2026-10-11。公表内容の確認を、個人の理解と組織・授業の備えの学習につなげる構成へ改善しました。設計は [ユーザーストーリー・UX5](../purpose-ui-design.md)、工程範囲は [契約](../../../.agent-harness/contracts/day064-purpose-ui.md) にあります。

## 変更と役割

- 読む部分を明るくし、暗い地球儀を地図の中に限定。常設の左側条件を外して中央を広げました。
- 主な入口を「地図で見る・一覧で読む・備えを学ぶ」に整理。比較・原因マップは分析ツール、条件はPC・スマホ共通のパネルへ移しました。
- 詳細では会社名・原資料・公表要旨・規模と確認状況を先に表示。対象範囲・数字の注意・地理の根拠・全資料は補足を開いて読めます。
- 学習画面は6テーマ・12の問い。日本の原因別記録、同じ学習テーマ、公的な対策・対応資料へ往復できます。IPA等の原文や図表を複製せず、一般的な確認の問いを独自編集しています。
- 原因が不明な記録は一般的な学習入口へ進み、特定のテーマを強調しません。個別事故をどの対策で防げたかの認定は行いません。
- 米国を探索してから日本企業を検索する場合、検索結果の地域へ地図が移動。解除時も初期の表示へ戻ります。年代・原因だけの変更では手動で動かした地図を保ちます。

15,871公表記録、日本2,522、92地域、159詳細チャンク、5,090参照資料の数値を保持しました。件数は独立した事故数や危険度ではありません。

## 不具合と検査上の修正

初回の通常検査は23成功・5失敗。PCの条件パネルが内容の高さになり、戻るボタンが画面外へ出ていました。ビューポート内の高さへ固定して修正。分析時の記録選択についても、常設一覧が消えた新しい導線に検査を合わせました。修正後は31項目すべて成功。 [初回ログ](purpose-ui/initial-checks.log) を保存しています。

体験検査の初回はDION2006に「外部侵入」の学習ボタンを誤って期待してタイムアウト。続く期待値変更も不正確だったため、その実行を中断し、収録データの原因が `unknown` であることを照合しました。実装・データを変更せず、一般的な学習入口と強調なしを確かめる検査へ修正し、最終8場面が成功しました。 [初回](purpose-ui/experience-first-attempt.log)、[中断](purpose-ui/experience-interrupted-attempt.log)、[最終](purpose-ui/experience-checks.log)。これらは検査の期待値の問題で、実装が原因を推測したものではありません。
