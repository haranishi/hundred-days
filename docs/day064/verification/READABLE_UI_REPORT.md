# Day64 Obsidianのデザインメモを反映したUI改善

この報告は国内201・全13,550記録時点のUI改善を保存したものです。その後の国内2,522・全15,871記録への拡充は [最新の国内拡充報告](JAPAN_EXPANSION_REPORT.md) を参照してください。

実施日: 2026-10-11。依頼は「もっと分かりやすいUI」「Obsidianにあるデザインのメモを参考に探す」。[工程契約](../../../.agent-harness/contracts/day064-readable-ui.md) と [設計](../design.md) に沿って、既存の13,550記録とRust/Wasm検索を維持したまま画面を改善しました。データの取得範囲と取込根拠は [13,550記録版の報告](HISTORY_REPORT.md) を参照してください。

## 調査と採用した考え方

Obsidian CLIは `Vault not found.` を返したため、ローカルの保管場所を探し、実際のノートを読みました。中心にしたのは「UI_コンポーネントとパターン」「レイアウト・視覚的階層」「データ可視化の基礎」「アクセシビリティとUXライティング」。関連する「徹底解剖_デザイントークン集」と日本語の文字組み・Web制作のノートも参照しました。保管庫や設定ファイルの内容はアプリへ複製していません。

検索を主役にする、関連する要素を近くに置く、8/16/24/32pxを基準に余白を整える、数値には単位と直接ラベルを付ける、補足情報を段階的に開く、操作後もキーボードのフォーカスを保つ、という方針を採用しました。

公開例は [Datawrapperのチャート紹介](https://www.datawrapper.de/charts) と [Linearの機能紹介](https://linear.app/features) を確認しました。読み取れる比較、直接ラベル、整った余白と操作のまとまりを参考にしています。Linearの実アプリを操作した評価ではありません。明るい背景について任意の質問を出しましたが回答はなく、待機後に初期案として進める旨を伝えました。本人が配色を承認したという記録にはしていません。

## 実装した画面

- 明るい背景、濃い本文、青の主要操作へ整理。総収録数と現在の検索結果を別の場所で表示します。
- 最初の画面に企業・サービス名の検索欄を置き、KDDI・ベネッセ・NTTドコモの例からすぐ探索できます。
- 条件を一覧の上に表示し、一つずつ解除できます。検索語だけを消す場合は地域等を保持し、ゼロ件の画面にも解除ボタンを置きました。
- 「01 / 記録を選ぶ」から「02 / 選んだ記録」へ進み、概要・正確な数値・対象範囲と「原資料を開く」を確認できます。通常の一覧では重複する補助リストを隠しました。
- 記録一覧・同じ単位の規模比較・原因マップを明確な名前で切り替えます。年の棒の高さも記録数に比例させ、最低高さの補正を除きました。
- スマホでは年代・原因のグラフを初期状態で折りたたみ、検索を先に表示。選択した記録から一覧へ戻る操作を加えました。
- 3D/SVG、24件ずつの表示、136個の詳細ファイルの遅延取得、共有、原資料、失敗時の復帰は維持しています。公開記録13,550、日本201、米国13,349のデータは変更していません。

新しい検査は、初期画面の検索→例の選択→条件の個別解除→原資料と、スマホの検索→記録→原資料→一覧への戻り方を実操作で確認します。検索欄の同期、フォーカス維持、横はみ出し、初期グラフの開閉、開いた年軸も検査しました。年の棒の実際の高さの比率を表示件数と照合しています。

既存の検査で、13,550記録、最後の14記録、24件のページ、実Rust Workerの稼働、3Dと全件JSONを初期取得しないことを再確認。WebGLコンテキスト喪失→SVG、Wasm取得・Worker起動・索引/詳細取得の失敗、キーボード、共有ID、原資料リンクも通っています。390/768/1440/1920pxの画面と1024pxの検索導線を確認しました。Rustネイティブの5件は前段階で成功しており、今回のUI変更では再実行していません。

初回の通常検査は20件成功・1件失敗（27.1秒）。地域の選択と入力待機の更新で条件ボタンが作り直され、キーボードのフォーカスが失われる問題を直しました。製品側で更新前のフォーカスを復元し、解除後は次の条件または検索欄へ移します。検査側も地域の選択反映を待つようにしました。その後の全件検査と、入力待機中の再描画を確認する追加検査が成功しています。改善は3周以内で、同じ製品不具合を繰り返し残していません。

Day64のビルドを配信フォルダへ同期し、164ファイルをバイト照合。古いハッシュ付きアセットはなく、HTML・索引・先頭/末尾の詳細・Wasm・Rust著作権表示・第三者表記・OGPの8応答がビルドと一致しました。WasmのContent-Typeは `application/wasm`。アプリ用画像も最新1440px画像へ更新しています。
