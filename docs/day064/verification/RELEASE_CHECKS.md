今回の変更は出典表示・権利・配信の整備が中心。UI・体験の採点を形式的に増やさず、[前回の自己点検と体験確認](PURPOSE_UI_REPORT.md)に、今回の実ブラウザ操作・390/768/1440pxの実画像確認を追加した。独立した評価者・実利用者の評価ではない。
