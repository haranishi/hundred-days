# 公表記録を地球儀から探す

参考: https://cybermap.kaspersky.com/ja 。主担当がブラウザの実画面を確認。地球儀を中央に大きく置き、地域の発光・ズーム・平面切替と周辺の操作のまとまりを参考にする。描画コード・ブランド・素材は複製しない。

## ユーザーストーリーと受け入れ条件

日本の不正アクセスを調べたい人が、地球儀の日本から関連地域を選び、公表された事例と原資料を確認する。全体の分布に関心がある人は国・地域、原因、年代を変えて比較する。位置が未特定の場合も、収録から消さず国単位でたどれること。

地域選択と記録一覧・数値・ノートが一致する。光点の位置と数値の意味、公表記録と現在の攻撃の違いが画面で読める。390pxでも選択・詳細・戻る・失敗からの復帰に到達できる。

## UX5階層

- 戦略: 記録を地理から見つけることと、根拠へ進むことを中心にする。記録の見た目を現在の攻撃に見せない。
- 要件: 大きな暗い地球儀、資料に関連する地域の集約、3D/平面、ズーム、日本/米国への移動、地域選択、年指定と過去資料の再生。検索・既存時系列・同単位比較・原因マップ・出典・共有を保つ。
- 構造: 地球儀を初期表示 → 地域を選択 → 同じ条件の記録を読む → 右のノートから原資料へ。記録一覧の表示も一操作で開ける。地図は全検索結果を地域集約し、個別事例を15,871個一度に描画しない。
- 骨格: 上部は短い説明、総数と検索。中央に地球儀、地図上端に表示/移動/ズーム、下部に年代と地域の記録。右に選択記録。スマホは地球儀→地域選択→一覧→ノートを縦に並べる。
- 表層: 深い紺の背景、青緑の海岸と大気、原因の光点、明るい本文と選択。装飾的なグリッチ・点滅・外部フォントは加えない。動きを減らす設定とキーボードを保ち、動いていない時は描画し続けない。

日本の都道府県は名称に一意に明記されたものだけ採用する。HHSは報告組織の州、Californiaは通知先の州として区別する。国しか分からない記録は「地域未特定」。Natural Earthの地域代表点と地形を使い、実際の事故地点やサーバー位置を示すピンではないことを説明する。

UI/UX Pro Maxのデザイン候補とThree.jsの操作・負荷・アクセシビリティ指針を参照した。自動候補の外部フォント、グリッチ、リアルタイム表現、過剰な発光は採用しない。既存のHTML/CSS・Three.js・Rust/Wasmに合わせて実装する。
