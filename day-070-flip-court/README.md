# フリップコート — 60秒の陣取りラリー

返す、塗る、挟んで反転。1人でCPUと60秒対戦する、球打ちと陣取りのゲーム。
着地したマスを自分の色にし、相手の列を縦・横・斜めに挟むと、その間をまとめて取り返せる。
60秒後に陣地が多い方の勝ち。同数なら引き分けになる。

現在は下書き。標準ビルドの公開一覧と配信先から除外している。

## 手元で遊ぶ

リポジトリ直下から、Node.jsで次を実行する。

```sh
node day-070-flip-court/tools/serve.mjs
```

表示されたローカルURLを開き、「CPUと対戦する」で開始する。遊ぶための追加依存やログインは不要。

- スマホ：コートを左右にドラッグして、下のラケットを動かす。
- PC：左右矢印またはA・Dキーで移動する。
- ラケットの中央で返すと奥へ、端で返すと左右へ浅く飛ぶ。

返球を逃しても陣地は減らず、次のサーブへ自動で進む。
一時停止、別タブへの移動、遊び方や共有を開く操作で時計とラリーが止まる。
「つづける」で再開し、結果の「もう一度遊ぶ」で18対18・残り60秒から始め直せる。

## 色と印で陣地を見分ける

暖色の丸が自分、青緑の菱形がCPU。実線の枠は着地、破線の枠は反転したマスを示す。
残り時間・陣地数・変化したマス数を文字でも表示する。
画面の向きが変わっても試合を保ち、端末の「視差効果を減らす」設定に応じて装飾を抑える。

## ゲームのリンクを共有する

X・LINE・リンクコピーと、対応端末では共有シートを使える。
コピーできないときは共有画面のURLを選択して手動でコピーする。
共有シートを閉じても結果は残り、別の共有方法や再戦を選べる。
公開時の正規URLは `https://hundred-days.pages.dev/day-070-flip-court/`。
このURLの公開やSNS投稿はまだ行っていない。

## 構成と検査

`lib/rules.js` が8方向の反転、`lib/match.js` がCPUと試合の進行、`lib/view.js` が描画を担当する。
`app.js` が入力・時計・画面をつなぐ。共有はリポジトリ共通の `shared/` を同期して使う。
試合中の通信、サーバー処理、外部素材・フォント、進行の保存は使わない。

```sh
node --test day-070-flip-court/tests/
node day-070-flip-court/tools/capture-og.mjs
```

紹介画像の再生成には、リポジトリ既定のPlaywrightとChromiumが必要。
`og.png` はこのゲームのCanvas描画と自作の文字・図形を組み合わせた1200×630画像。
`tools/` と `tests/` は公開用ビルドへ含めない。
CPU版は単体85件、Chromium・WebKit各15件の主要フロー検査と、5分16秒・5試合の実時間操作で確認した。

## 制作記録

本人は企画①を選び、要件と後続工程を承認し、最近追加したスキルも使うよう依頼した。
Codexが調査・設計・実装・検査を担当した。既存コードの再利用を優先し、新しい実行時依存は追加していない。

制作中には、端数の影響で60秒の終了が確定しないケースを修正した。
横向きで開始・結果の操作がはみ出した問題は、コートと操作を左右に並べて直した。
再戦・再開で古いキー入力が復活した問題は、新たな押下を待つ処理と両ブラウザの回帰検査で直した。
本人によるプレイや面白さの評価は未確認。
