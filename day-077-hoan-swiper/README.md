# Day 077：保安検査スワイパー — その荷物、機内？預け？没収？

3Dの空港保安検査場のベルトコンベアから流れてくる手荷物トレイを見て、国土交通省（航空法・危険物運送基準）および国際民間航空機関（ICAO）の基準に基づき、**「機内持ち込み（←）」「預け荷物（↑）」「持込不可・没収（→）」** の3方向へ瞬時に仕分けるWebゲーム＆手荷物ルール早見図鑑です。

- 公開URL: https://hundred-days.pages.dev/day-077-hoan-swiper/

## ゲームのはじめ方

画面中央でモードを選び、「ゲームスタート」を押します。押すまでは仕分けは始まりません。
研修は全10問で時間制限なし。60秒モードはスタートからカウントし、図鑑やガイドを開くと一時停止します。
操作が初めてなら、同じ開始画面の「操作を試す・1問練習」から試せます。

## 3D版について

Three.js r186で空港、検査機、ローラー、トレイと36品目の模型を描画します。
荷物は選んだ方向へ移動し、次のトレイが入ります。視点切替で荷物に近づけます。
X線表示は内部構造を説明するゲーム用の模式図です。実際の検査画像ではありません。
金属と樹脂の材質、影と日光、搬送の動きを一つの3D空間で表現しています。

Three.jsはMITライセンスで同梱し、CDNや外部のモデルへ接続しません。
模型とテクスチャは独自の手続き生成です。記録はこの端末に保存します。
3DにはWebGL2が必要です。利用できない場合もボタン操作と図鑑を使えます。
図鑑・ガイド・背景タブでは60秒モードを一時停止し、戻ると再開します。

## 主な機能

1. **3方向スワイプ仕分けアクション**:
   - **60秒タイムアタック**: 次々と流れてくる荷物を60秒間で素早く仕分け、スコアとコンボを競います（ゲームスタートを押すとタイマー開始）。
   - **厳選10問・研修シフト**: 時間制限なしで、空港で最も引っかかりやすい10品目をじっくり確認できます。
   - トレイのスワイプ（左・上・右）、画面ボタン、キーボード（`←`/`A`＝機内、`↑`/`W`＝預け、`→`/`D`＝不可）のすべてに対応。
2. **即時理由フィードバック＆復習シート**:
   - 仕分け直後に「なぜ預けNGなのか」「なぜ100ml超容器が国際線機内NGなのか」を1行で表示し、シフト終了後には間違えた荷物の詳細解説を復習できます。
3. **手荷物ルール早見図鑑（全36品目）**:
   - 電池・電子機器、液体・化粧品、刃物・工具、スプレー、喫煙具・火気、飲料・薬の6カテゴリとキーワード検索で、旅行・帰省前の荷造りチェックに使えます。
   - 国土交通省および主要航空会社（JAL・ANA・Peach・Jetstar）の公式手荷物案内ページへのリンク集を併設しています。
