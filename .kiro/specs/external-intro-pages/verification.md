## 画面の採点

別の担当者（画像だけを見る・毎回ゼロから）が、10項目×0〜2点で採点した。合格は16点以上で、0点の項目がないこと。上限の3周を回した。

| 周 | 点 | 1点の項目 |
|---|---:|---|
| 第1周 | 16 | 視覚階層・余白と整列・タイポグラフィ・CTAと導線 |
| 第2周 | 16 | 視覚階層・余白と整列・タイポグラフィ・一貫性 |

3周とも合格。点は単調には上がらず、評価者ごとに重視する点が変わる（改行を均すか均さないかは、周によって逆の指摘が出た）。指摘が実在するかをコードと画像で確かめて、次のように分けた。

### 直したもの

- 「アプリを開く」が、注意より下に出ない → 注意のあと、フッターにも置いた
- 画面写真と動画ポスターが同じ絵 → ポスターをデモ動画の別のコマにした（`intro.poster`）
- 紹介文が塊になる・PCで1語だけが次の行に落ちる → 文ごとに行を分け、1行の長さをそろえた。1文目だけ本文と同じ明るさにした
- 「方／針」のように、語が行をまたいで割れる → 短い箇条書きに `text-wrap: balance` を使った（できることの一覧は、意味が取り違えられないよう `pretty`）
- 見出しと本文の大きさの差が小さい → 見出し 22/28px、リード 17/20px、小見出し 14px にした
- 節の間の余白がばらつく → 1つの値（スマホ 56px・PC 64px）にした
- 「→」の補足の2行目以降がそろわない → 「→」を別の列にして、文の頭にそろえた
- 「できること」の枠がボタンに見える → 枠を外し、制作メモと同じ箇条書きの書式にした（点は灰色）
- 小見出しの書式が3通り → 色・大きさ・太さを1つにそろえた
- 期間とタグが、制作メモの項目に見える → 区切り線で別のまとまりにした。タグは枠をやめて文字だけにした
- PCで、動画の右が空く → 動画と説明を横に並べた。説明は動画の下端にそろえた
- 2つ目のボタンの幅が1つ目と違う → 同じ幅にした
- 矢印が細い／形が3種類 → 線の太い図（SVG）の2種類（外へ移る・下へ）にそろえた。外のサイトへのリンクすべてに付けた
- 共有ボタンが2個＋1個に折り返す → 2列に並べた
- URLの枠が入力欄に見える・名前の途中で折れる → 枠を外して見出しを添え、パスの区切りごとにまとめた
- ボタンの形・高さ・太さがばらばら → 押せるものは角丸で高さ44px以上、文字の太さもそろえた
- 一覧への導線の呼び方が上と下で違う → 「一覧を見る」にそろえた
- フッターのリンクが小さい → 1行に1つ（PCは横並び）、高さ44px以上にした
- PCの「使う前に」の枠の中で、文字が左に寄る → 文字を枠いっぱいに流した
- 制作メモを読みに来た人への近道が無い → 「制作メモを読む」のリンクを足した
- 英字と日本語の間の空きが混ざる（自前の文）→ 空けない形にそろえた
- 補足の文が暗めに見える → 一段明るい色にした

### 直さないもの

- ポスターの白い斜めの線・細い弧がポインターに見える → 撮影上のずれ。動画の枠に出る、読み込み中の丸（スピナー）の一部（上の「動画の枠」を参照）。ポスターの画像ファイルにも、画面写真にも、その線は無い
- 行頭の「「」が半字下がって見える → 実測で、行頭の括弧の幅は 0.5em。半角分を詰める設定が効いている
- 助詞で始まる行（「に決め、」）・文節の切れ目での早めの改行 → 日本語の文章では許される形。語の途中で割れるより、文節の切れ目で折れるほうを選んだ。評価者によって逆の指摘も出ており、語句ごとに手で改行を止める作りは、`meta.json` の文には向かない
- 「使う前に」の本文が、スマホで右端がでこぼこ → 文節ごとに折るための結果。通常の折り返しに戻すと、語が割れる
- 画面写真の下端がカードの途中で切れ、保存バーに重なる → カード一覧と共通の素材で、撮影時の切り取り。今回は変えない
- 共有ボタンにも外へ移る印を付ける → 共有は「押すと別の窓が開く操作」で、リンク先のサイトを読む行為ではないため付けない

撮影の継ぎ目（画像の分割による文字の切れ）は、採点者が自分で除外していた。
