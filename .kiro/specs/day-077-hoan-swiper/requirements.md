# Day77 保安検査スワイパー — その荷物、機内？預け？没収？

## 背景と目的
空港の保安検査場において、「モバイルバッテリーをスーツケース（預け荷物）に入れてしまう」「国際線で100mlを超える容器の液体を手荷物に入れてしまう」「電池が外せないコードレスヘアアイロンを持ち込んでしまう」といった手荷物ルールの誤解によるトラブルが日常的に発生している。
国土交通省（航空法・危険物運送基準）および国際民間航空機関（ICAO）の公式基準をもとに、コンベアから流れてくる手荷物トレイを **「機内持ち込み（←）」「預け荷物（↑）」「持込不可・没収（→）」** の3方向へ瞬時に仕分ける2.5D風スワイプアクションゲームと、旅行前にすぐ調べられる「手荷物ルール早見図鑑」を1つのWebアプリとして提供する。

## 2026-10-26 実3Dへの更新

ユーザーから実3Dへの刷新を再依頼。描画・操作・品質の受け入れ条件は [3D設計](3d-design.md) を優先する。以下の36品目・モード・図鑑・共有の要件は引き継ぐ。

## 受け入れ条件（Requirements）

- **R1（データと根拠の正確性・X線透視情報）**：
  - 国土交通省「航空機への危険物の持込み・お預けについて（代表例）」および主要航空会社の共通基準に準拠した36品目の手荷物データを収録する。
  - 各品目には「品名」「補足仕様（Wh・ml・刃渡り・度数など）」「X線検査所見（内部バッテリー構造・発熱体・液体容量・危険物分類）」「カテゴリ」「許容される仕分け先（`carry_on` / `checked` / `prohibited`）」「一言の理由（ミス時・解説用）」「詳細な法令・安全根拠」を持たせる。
  - 現実の規則で「機内持ち込み・預け入れのどちらも可」の品目（例：100ml以下の目薬、爪切り、T字カミソリ、コード式ヘアアイロン等）は、`carry_on` と `checked` のどちらに仕分けても正解と判定し、バッジで「両方OK」と明示する。
  - 航空会社や路線（国内線／国際線）で条件が異なる点があることを免責・注意事項として明記し、国土交通省および主要航空会社（JAL・ANA・Peach・Jetstar）の公式手荷物案内ページへのリンクを備える。

- **R2（スタート画面・段階的オンボーディング・1問おためし練習）**：
  - 初回表示時はいきなりタイマー画面に放り込むのではなく、2.5D検査場ステージ上に **「保安検査シフト開始（スタート画面）」** を表示し、初見3秒で「何をするゲームか」「←機内／↑預け／→没収の3方向ルール」「どのボタンを押せば始まるか」が分かるようにする。
  - スタート画面には明確な主CTAボタン **「▶ 検査シフトを開始する（START）」**、モード選択（**🎓 厳選10問・研修シフト** ／ **⏱️ 60秒タイムアタック**）、および **「🖐️ 1問おためし練習（操作チュートリアル）」** を備える。
  - ゲーム開始直後の第1問（およびおためし練習時）には、トレイ上に「どちらへスワイプ／タップするか」のステップガイド（コーチマーク）を表示し、誰でも迷わず最初の1個を仕分けられるようにする。

- **R3（2.5D空港検査レーン・X線透視ギミック・判定フィードバック）**：
  - 天吊りデジタル電光掲示板HUD、奥のX線スキャナーゲートと次トレイ、斜め立体ローラーコンベア、3D成形プラスチック検査トレイ、3方向の発光シュートパッドを備えた2.5D検査場ステージを提供する。
  - コンベア中央の検査トレイに対し、ドラッグ／スワイプ操作（左・上・右、ドラッグ量に応じた傾きと検印スタンプ表示）、画面上の3方向仕分けボタン、キーボード操作（`←` / `A` ＝機内、`↑` / `W` ＝預け、`→` / `D` ＝不可）のすべてで同一の仕分け判定が行える。
  - **「🔍 X線透視スキャン」** ボタン（または `Space` キー）で、トレイ内の荷物をX線モニター風（シアン・アンバー透過表示）に切り替え、内部構造ヒント（リチウム電池の取外し可否・Wh数・液体量など）を確認できる。
  - 仕分け直後に正誤判定・獲得スコア・コンボ数・判断理由（「なぜ預けNGか」等）を検査モニターに明快にフィードバックし、結果画面では称号ランク、スコア、今回間違えた品目の復習リストと解説を表示する。

- **R4（出発前チェッカー・手荷物図鑑）**：
  - 全36品目をカテゴリ別（すべて／電池・電子機器／液体・化粧品／刃物・工具・長尺／スプレー・日用品／喫煙具・火気・危険物／飲料・食品・薬）およびキーワード検索で即座に絞り込み、「機内」「預け」の可否と条件を確認できる図鑑タブを提供する。

- **R5（音響・アクセシビリティ・端末保存・品質ゲート）**：
  - Web Audio APIによる合成効果音（開始音、X線スキャン音、通過ピンポン音、警告ブザー、コンボ音、終了ファンファーレ）を実装し、ワンタップ切替と `localStorage` 保存に対応する。
  - `prefers-reduced-motion` 有効時はコンベアやトレイの過度な移動アニメーションを抑止する。
  - 独立したサブエージェントによるハーネス評価（体験評価・画面評価とも16/20点以上かつ0点なし）、単体テスト、`npm run check`、`npm run publish:check -- --day 77`、Playwright E2E（360px / 390px / 768px / 1440px）をすべて通過する。
