# Day77 保安検査スワイパー — その荷物、機内？預け？没収？

## 背景と目的
空港の保安検査場において、「モバイルバッテリーをスーツケース（預け荷物）に入れてしまう」「国際線で100mlを超える容器の液体を手荷物に入れてしまう」「ハサミや工具を持ち込んでしまう」といった手荷物ルールの誤解によるトラブルが日常的に発生している。
国土交通省（航空法・危険物運送基準）および国際民間航空機関（ICAO）の公式基準をもとに、コンベアから流れてくる手荷物トレイを **「機内持ち込み（←）」「預け荷物（↑）」「持込不可・没収（→）」** の3方向へ瞬時に仕分ける2.5D風スワイプアクションゲームと、旅行前にすぐ調べられる「手荷物ルール早見図鑑」を1つのWebアプリとして提供する。

## 受け入れ条件（Requirements）

- **R1（データと根拠の正確性）**：
  - 国土交通省「航空機への危険物の持込み・お預けについて（代表例）」および主要航空会社の共通基準に準拠した36品目の手荷物データを収録する。
  - 各品目には「品名」「補足仕様（Wh・ml・刃渡り・度数など）」「カテゴリ」「許容される仕分け先（`carry_on` / `checked` / `prohibited`）」「一言の理由（ミス時・解説用）」「詳細な法令・安全根拠」を持たせる。
  - 現実の規則で「機内持ち込み・預け入れのどちらも可」の品目（例：100ml以下の目薬、スマートフォン本体、折りたたみ傘など）は、`carry_on` と `checked` のどちらに仕分けても正解と判定し、バッジで「両方OK」と明示する。
  - 航空会社や路線（国内線／国際線）で条件が異なる点があることを免責・注意事項として明記し、国土交通省および主要航空会社（JAL・ANA・スカイマーク・Peach・Jetstar）の公式手荷物案内ページへのリンクを備える。

- **R2（3方向仕分けゲーム体験）**：
  - **通常シフト（60秒タイムアタック）** と **研修シフト（時間制限なし・厳選10問）** の2モードを提供する。
  - コンベア中央の検査トレイに対し、スワイプ操作（左・上・右）、画面上の3方向仕分けボタン、キーボード操作（`←` / `A` ＝機内、`↑` / `W` ＝預け、`→` / `D` ＝不可）のすべてで同一の仕分け判定が行える。
  - 仕分け直後に正誤判定・獲得スコア・コンボ数・判断理由（「なぜ預けNGか」等）を即時フィードバックし、結果画面では称号ランク、スコア、今回間違えた品目の復習リストと解説を表示する。

- **R3（出発前チェッカー・手荷物図鑑）**：
  - ゲームを遊ばない利用者や復習したい利用者が、全36品目をカテゴリ別（すべて／電池・電子機器／液体・化粧品／刃物・工具／スプレー・日用品／喫煙具・火気／飲料・食品）およびキーワード検索で即座に絞り込み、「機内」「預け」の可否と条件を確認できる図鑑タブを提供する。

- **R4（音響・アクセシビリティ・端末保存）**：
  - Web Audio APIによる合成効果音（通過音、警告ブザー、コンボ音、終了音）を実装し、初期状態は消音またはワンタップ切替可能とし、ミュート状態を `localStorage` に保存する。
  - ハイスコア・最高ランク・クリア履歴を `localStorage` に安全に保存し、不正なJSONや改ざん値が入っていても例外を起こさず初期値へフォールバックする。
  - `prefers-reduced-motion` 有効時はコンベアやトレイの過度な移動アニメーションを抑止する。

- **R5（公開契約・セキュリティ・品質ゲート）**：
  - `meta.json`、`index.html` のOGP・canonical・`share:text`、共通シェア欄（`shared/share.js`）、`og.png`、`favicon.svg`、`README.md` を揃え、`npm run check` および `npm run publish:check -- --day 77` を通過する。
  - 外部API通信を一切行わず（`connect-src 'self'`）、DOM操作は `textContent` と安全な要素生成のみを用いてXSSを防止する。
  - 390px（モバイル）・768px（タブレット）・1440px（デスクトップ）の3画面幅で横スクロール溢れや文字重なりがないことを実ブラウザ（Playwright E2Eおよびスクリーンショット目視）で検証する。
