# Day77 保安検査スワイパー — 技術設計・UX5階層・脅威モデル

## 1. UX5階層設計

1. **戦略層（Strategy）**：
   - 誰に：飛行機に乗る前の旅行者・帰省客・出張者、および短時間で判断ゲームを楽しみたいプレイヤー。
   - 何を：「これ機内に持ち込める？預けられる？」という現実の困りごとを、30〜60秒の直感的なコンベア仕分けゲームと早見図鑑で楽しく解決する。
2. **要件層（Scope）**：
   - 3方向仕分けゲーム（60秒タイムアタックモード／10問じっくり研修モード）
   - 即時フィードバック（正誤・法令根拠の1行解説）とリザルト復習シート
   - 全36品目の検索・カテゴリ絞り込み対応「手荷物ルール早見図鑑」＋国交省・航空会社公式リンク集
3. **構造層（Structure）**：
   - 単一画面内で完結する2タブ切り替え構造（「🎮 検査レーン（ゲーム）」タブ ／「📖 手荷物ルール図鑑（早見表）」タブ）＋「遊びかた・基準」ダイアログ＋「共有」ダイアログ。
   - 初回訪問時でもダイアログが画面を強制ブロックせず、すぐにプレイ開始または共有ボタンへアクセスできる構成（横断テスト `shared-share.spec.mjs` との完全互換）。
4. **骨格層（Skeleton）**：
   - 上部：空港ターミナル案内板風ヘッダー（タイトル、モード切替、音ON/OFF、遊びかた、共有ボタン）
   - 中央（ゲーム領域）：デジタル掲示板風HUD（TIMER / SCORE / COMBO / 残り個数）＋ 3方向仕分けゾーン（上：🟡預け荷物、左：🟢機内持ち込み、右：🔴持込不可）＋ 中央の2.5D風コンベア＆プラスチック検査トレイ（SVGイラスト・品名・仕様バッジ）＋ 直近の判定フィードバックバー。
   - 下部：図鑑タブ切り替え・公式リンク・免責事項フッター。
5. **表層（Surface）**：
   - 明るく清潔感のある空港保安検査ターミナル配色（ミントグリーン・スレートグレー・視認性の高いサインボードカラー：緑 `#10b981`、琥珀 `#f59e0b`、赤 `#ef4444`、濃紺 `#0f172a`）。
   - 各アイテムの特徴が一目でわかるカスタムSVGアイコン群（モバイルバッテリー、化粧水ボトル、カッター・ハサミ、ライター、スプレー缶、アルコール瓶など）。

## 2. アーキテクチャとファイル責務

- `day-077-hoan-swiper/`
  - `index.html`: 固定canonical/OGP、ヘッダー、検査レーン（ゲームUI）、リザルト画面、手荷物ルール図鑑、公式リンク集、共有欄（`#share`）。
  - `app.css`: 2.5Dアイソメトリック風コンベア・トレイ演出、3方向仕分けボタン、レスポンシブ設計（390px / 768px / 1440px）、高コントラスト設計、`prefers-reduced-motion` 対応。
  - `app.js`: DOMイベント結線、ポインター/タッチスワイプ操作、キーボードショートカット、タイマー駆動、図鑑フィルタリング、効果音呼び出し。
  - `lib/items.js`: 国交省・ICAO基準に基づく36品目のマスターデータ（ID、名称、サブタイトル、カテゴリ、正解アクション配列、推奨アクション、理由、詳細解説、アイコン種別、重要度）。純粋データとして単体テストから検証可能にする。
  - `lib/engine.js`: ゲーム状態管理・出題デッキ生成（偏り防止シャッフル）・仕分け判定・スコア＆コンボ計算・ランク算出・復習リスト抽出を担う純関数群。
  - `lib/storage.js`: `localStorage`（キー：`day077_hoan_swiper_v1`）へのハイスコア・研修クリア数・音設定の読み書きとスキーマ検証。
  - `lib/sound.js`: Web Audio APIによる効果音合成（通過ピンポン音、警告ブザー、トレイ移動音、フィニッシュファンファーレ）。
  - `favicon.svg` / `og.png` / `meta.json` / `README.md`
  - `tests/`:
    - `items.test.mjs`: 36品目のデータ整合性、必須フィールド、カテゴリ網羅性、正解アクションの妥当性テスト。
    - `engine.test.mjs`: 仕分け正誤判定（機内のみ／預けのみ／両方OK／不可）、コンボ・スコア計算、タイムアップ、研修10問完了、復習抽出の単体テスト。
    - `storage.test.mjs`: 保存データの読み書きと破損データのフォールバック検証。
- `tests/e2e/day-077.spec.mjs`:
  - ゲーム開始、3方向仕分け操作（ボタン・キーボード）、フィードバック表示、研修10問完走→リザルト画面→復習リスト表示、図鑑タブでの検索・カテゴリ絞り込み、3画面幅でのレイアウト崩れ・横溢れゼロ検証。

## 3. 脅威モデルとセキュリティ設計

1. **CSPおよび外部通信検査との整合（重要）**：
   - `tests/e2e/security-headers.spec.mjs` はJSファイル内の `const X = "https://..."` を通信先（`connect-src`）として検出する。そのため、国交省や各航空会社への公式案内リンクはJSの変数に持たず、`index.html` 内の静的な `<a href="https://..." target="_blank" rel="noopener noreferrer">` として記述する。
   - アプリ自体は外部通信を一切行わない（`connect-src 'self'`）。
2. **XSS防止（DOM安全性）**：
   - 図鑑の検索入力や `localStorage` の復元値を `innerHTML` に流し込まない。動的テキストはすべて `textContent` で設定し、SVGアイコンは定義済み `<symbol>` の `<use href="#icon-...">` 参照のみで描画する。
3. **未信頼ストレージ耐性**：
   - `localStorage` から読み出した値が壊れたJSON、負数、巨大数値、想定外の文字列であっても、`lib/storage.js` で安全な整数範囲・真偽値にクランプして初期化する。
4. **法務・免責の明示**：
   - 本アプリは国土交通省の代表例に基づく学習・確認用ゲームであり、実際の搭乗時は利用する航空会社・路線（国内線／国際線）・機材ごとの最新規定が優先される旨を画面内とREADMEに明記する。
