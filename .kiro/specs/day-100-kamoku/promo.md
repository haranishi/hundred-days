# Day100 kamoku の宣伝動画（2026-11-26）

## 依頼と方針
本人の依頼「このアプリを使いたいと思わせられるような動画を作ってほしい」。機能を順に並べず、問いかけ → あるある → 片づく → 触りたくなる → 自分の数字 → 安心 → 行動の流れにした。字幕は、画面で実際に起きることだけを書く。「申告できる」「自動で仕訳」「他より速い」は書かない。

## 成果物
- 縦1080×1920・30fps・32秒（120 BPM・16小節）。A案・B案・無音の3本。BGM は Node の計算で合成した自作（A「未確認の朝」を採用、B「帳簿の灯」は予備）。
- 道具: `day-100-kamoku/tools/promo/`（作り直し方と字幕の照合表は README）。試験は `tests/promo/`。
- 出力（mp4・wav・画像）はリポジトリに入れない。X の投稿文（`meta.json` の `social.x`）は、動画の出だしに合わせて本文を直した。

## 検証
- 撮影は公開版と同じ組み立てを実際に操作し、件数・金額・仕訳は画面から読んだ値を使う。手元のアドレスは映らない。
- selftest・単体試験16件・音の検査22項目（A・B とも、−16 LUFS、真のピーク −2.5 dBTP 前後、合図のずれ 1ms 未満）・静止検出0件。
- `npm run x:prepare -- --day 100 --video <A案> --media-reviewed` が通った。
- 画像だけの採点（別系統の Grok・20点満点・上限3周）: 1周目 11、2周目 10（毎回白紙で採点）。指摘を画像で確かめて直し、3周目で打ち切った。

## 残る弱点（本人の確認）
- 音は耳で聴いていない。
- 打つ場面の仕訳の札は、画面の表示に約1打鍵遅れる。
- 早送りの区間で入れた科目は、取引先名から選んだ見本。
