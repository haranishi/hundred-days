# UX: ユーザーストーリーと5階層（実装前に書く・2026-11-19）

## ユーザーストーリー

| ユーザー | 欲しいことと理由 | 受け入れ条件 |
|---|---|---|
| **本命**：盆栽に惹かれるが、置く場所・値段・枯らす不安で始められない20〜30代 | スマホを開いたらすぐ盆栽があり、触ると気持ちよく反応する。すき間時間に、癒やされたい | 開いて3秒以内に回せる。説明文を読まずに最初の「切る」が成功する。登録なし |
| **このアプリが救う相手**：実物の盆栽を始めたい初心者 | 剪定や針金かけを、失敗しても元に戻せる場で試して、勘どころをつかみたい | 30回まで元に戻せる。切れない・曲がらない理由が1行で出る。実際の手入れは目安と明記 |
| 形にこだわりたい人 | 曲げた形が針金で保たれ、時間を進めても崩れない。自分の形に仕立てたい | 曲げた枝は、季節をまたいでも同じ形のまま太る |
| 季節を楽しみたい人 | 時間を進めて、芽吹き・新緑・紅葉・落葉を見たい | 1年（52週）を進めると、季節ごとの見た目が連続して変わる |
| 見せたい人 | できた盆栽を写真にして、人に見せたい | 操作部のない縦長の写真が保存でき、Xなどへ共有できる |
| キーボード・読み上げの利用者／動きが苦手な人 | 画面の動きに頼らず、手順どおり操作したい | 要件9.3・9.4。状態は文章でも読める |

## UX5階層

| 階層 | 決めたこと |
|---|---|
| ①戦略 | 目標：「切る・曲げる」の気持ちよさを、失敗の怖くない3Dで味わう。**差別化の源泉**：既存の盆栽シミュレーター（itch.io等）は英語・PC・数値中心。ここは、日本語・スマホの指・季節で姿が変わる見た目・写真に残せる、にしぼる。「世界で最もリアルな盆栽」は目指さない（その勝負は下りる） |
| ②要件 | 載せる：見る・切る・曲げる・芽摘み・時間・鉢と光・元に戻す・写真。載せない：アカウント・他人の盆栽・売買・病害虫（requirements 対象外）。水やりと夜の光は P1 |
| ③構造 | 画面は1つ。3Dの舞台が全面で、下に道具の帯（見る/切る/曲げる/芽摘み）と時間の帯。設定・新しい苗・このアプリについては「メニュー」の下の面に隠す。迷う分岐は「道具を選び間違えた」だけで、枝のない所をドラッグすれば、どの道具でも視点が回る。復帰は「元に戻す」1タップ |
| ④骨格 | いちばん大きい要素は、3Dの盆栽1つ。操作部は下端に寄せ、親指の届く範囲に道具4つ＋時間3つ＋元に戻す。上端は題名・メニュー・写真・共有だけ。押している間は、候補の枝と切られる範囲が色で見える（指で隠れても分かるよう、枝の色を変える） |
| ⑤表層 | 和紙のような生成り（#f3eee3）・墨（#26221d）・苔（#5b7a4e）・朱（#c4452c）の4色。朱は「いま選んでいる道具」と「確定する操作」だけに使い、赤と緑の違いだけで意味を伝えない（アイコン＋文字＋下線）。見出しは明朝系、本文はゴシック。動きは、ゆっくり出てゆっくり止まる。すべての動きは、動きの軽減で止まる |

## この5階層を通して実装が変わった点（報告用）

1. **切る操作を「押している間に候補が見え、離すと切る」にした。** 当初は「押したら切る」。親指で枝が隠れる・細い枝で誤タップする問題を、②③の「失敗しても怖くない」から導いた（要件2.1）。
2. **ドラッグが枝に当たらなければ、どの道具でも視点が回る。** 当初は道具ごとに視点操作を止める案。迷わない構造（③）に反するので、やめた（要件1.3）。
3. **曲げる角度に、太さに応じた上限と「曲がらない理由」を入れた。** 当初は無制限。「切れない・曲がらない理由が1行で出る」（受け入れ条件）と、盆栽の実際（太い幹は針金では曲がらない）を合わせた（要件3.2）。
4. **水やりと夜の光を P1 に下げた。** ①の差別化は「切る・曲げる・季節」なので、そこに時間を集中した（要件5.6・6.3）。
5. **共有は共通部品に任せ、「写真」を独立の操作にした。** 見せたい人の受け入れ条件（操作部のない縦長の写真）を満たすには、画面の共有ボタンでは足りないため（要件8.1）。

## 評価の観点（体験・見た目の採点者へ渡す）
- 体験：初見で最初の「切る」まで何秒か／切る・曲げるの手応え／失敗の納得感／時間を進める楽しさ／3分で単調にならないか。
- 見た目：盆栽が主役か／季節ごとの色／葉の塊の立体感／鉢と卓の質感／390pxの操作部の密度。
- 前提として受け入れる設計判断：1画面・1鉢・外部モデルなし・日本語のみ・水やりと夜は P1。
