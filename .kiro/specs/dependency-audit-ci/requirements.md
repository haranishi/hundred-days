# 入れ子の依存監査とglob警告の修正
2026-10-30。本人のDependabot画像（警告53）と、原因調査・再発防止CIの依頼に基づく。

## 継承と境界
既存の依存更新仕様と手引きを継承し、これまで対象外だった継続的な監査を追加する。
Day79のOpenNext→AWS→node-minify/core→glob 10.3.3が、GHSA-5j98-mcp5-4vw2に該当する。
公開物は静的なSPAでsourceを配信しない。今回の依存修正でDay79の公開物を変えない。

## 受け入れ条件
1. globの該当経路を同じ主版本の最小修正版へ固定し、lock再生成でも戻らない。
2. 変更前に警告を再現し、変更後に解消を確認する。公式配布元・整合値・公開日を照合する。
3. ルート・source・toolsを含む全ての管理対象npm lockを自動発見する。Day番号の固定リストを使わない。
4. npm auditで開発依存も含めてhigh/criticalを検出したら失敗する。通信失敗・不正応答・lock欠落も成功扱いにしない。
5. PR/mainの必須チェックへ接続し、定期実行でも新しい勧告を検出する。秘密値やアプリのinstall scriptを必要としない。
6. 入れ子の新規lock、既知の脆弱性、不正応答・通信失敗を試験し、検査の見逃しを防ぐ。
7. 既存CIと配信内容を維持し、マージ後に警告53の終了と公開サイトの動作を確認する。

## 適用範囲
他のアプリの機能、Next.js API、認証・請求設定、Xへの実投稿、mainへの直接pushは変更しない。
