# フリップコートのプロモーション素材

2026-10-19、本人から「プロモーション動画とXの投稿文を作成してほしい」と追加依頼を受けた。
既存CPU版の紹介素材を作る制作ブリーフで、ゲームの機能・要件や対人モードの承認状態は変えない。

## 目的
初めて見る人へ、返球と陣取りが結びつく遊びを30秒で示す。Xで動画と短い紹介文を使えるようにする。

## 制作方針
- 縦1080×1920、30fps、約30秒、H.264/yuv420pとAAC。無音でも字幕で内容が分かる。
- このアプリの実CanvasとDOMから撮り、実際のCPU戦・着地・反転・結果を使う。
- 画面の文字・得点・ルールを捏造しない。撮影用の固定seed/時計や編集は記録する。
- 紙色・深緑・暖色/青緑の陣営を引き継ぎ、大きな文字と控えめな動きで紹介する。
- 外部の曲・録音・素材を追加せず、自作の音と図形、システム書体で作る。
- X本文は280換算字以内。AIと本人の担当を事実に合わせ、未実装の2人対戦を宣伝しない。
- 制作時はアプリと投稿文をdraftとする。2026-10-19の本番公開依頼後はpublication.mdでURLを確認し、Xへの投稿は別に扱う。

## 絵コンテ
| 秒 | 伝えること |
|---|---|
| 0–3.2 | 返すだけじゃ、勝てない。球打ち×陣取り |
| 3.2–8 | 返す。着地を塗る。落ちた1マスが陣地になる |
| 8–14.8 | 相手を挟めば、まとめて反転 |
| 14.8–21.4 | 中央なら奥へ、端なら左右へ。実プレイを見せる |
| 21.4–25.8 | 60秒後、陣地の多さで決着。終了画面へ編集でつなぐ |
| 25.8–30 | 題名、1人でCPU戦、スマホ/PC、次の一打への案内 |

## 受け入れと保管
- 実ファイルの寸法・尺・codec・メタデータ・音量を検査し、代表フレームと全編の内容を確認する。
- 文字が切れず、本文と画・音がずれず、ブラックフレームや長い無音がないことを確認する。
- 完成品・X下書き・確認用画像はDriveの100日チャレンジ/Day070へ保存し、Obsidianから追えるようにする。
- 再生成コードと素材の説明はtools/promo、一覧用の短い無音映像だけはdemo.mp4へ置く。
- toolsと中間生成物は公開ビルドから除外。ゲームの検証済みruntimeは変更しない。
- 全公開X準備は既存x:prepareに従い、公開URLが有効になるまで未実施として残す。
