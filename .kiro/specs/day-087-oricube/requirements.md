# 要件: OriCube

折り紙の折り方を、紙が折れる動きとして3Dで見せる。作品は紙飛行機・白鳥・立方体の箱（ふた無し）の3つ。

## 1 作品と手順
- 1.1 When 利用者がアプリを開くと, アプリは作品の切替（紙飛行機・白鳥・立方体の箱）と、選ばれた作品の最初の手順を表示する。難しさ・目安の時間・使う紙を示す。
- 1.2 While 手順を表示している間, アプリは何手順目か、手順名、1〜2文の説明、山折りと谷折りの凡例を示す。
- 1.3 When 再生を押すと, アプリは折り線の案内を見せてから紙が折れる動きを再生し、次の手順へ自動で進む。一時停止で止められる。
- 1.4 When 前へ・次へ・手順の指定をすると, アプリは該当手順の始まりの姿勢へ移る。同じ手順を何度でも見直せる。
- 1.5 When つまみを動かすと, アプリは動かした位置の途中の姿勢を連続して表示する。
- 1.6 When 最後の手順が終わると, アプリは完成を示し、もう一度見る・別の作品へ進む導線を出す。
- 1.7 When 速度（0.5倍・1倍・2倍）を選ぶと, アプリは再生の速さを変える。
- 1.8 When 手順の一覧の項目を押すと, アプリはその手順の始まりへ移る。現在の手順を強調する。
- 1.9 While 「手順ごとに止める」が入っている間, アプリは再生を各手順の終点で止め、再生の操作で次の手順へ進む。

## 2 3Dの見え方
- 2.1 While 表示している間, 利用者は1本指で回し、2本指で拡大縮小できる。操作の後も紙全体が画面に入る。
- 2.2 When 視点ボタン（真上・斜め・元に戻す）を押すと, アプリは視点を滑らかに切り替える。
- 2.3 When 重なりを広げる操作をすると, アプリは層の間隔を広げて隠れた層を見せる。戻すと元に戻る。
- 2.4 紙は表と裏を別の色で描き、折って裏返った部分が分かる。折った跡は細い線として残る。
- 2.5 When 折る手順に入ると, アプリは折り線（谷折りは破線、山折りは一点鎖線）と動く向きの矢印を、動き出す前に示す。
- 2.6 While 手順の途中でも, 利用者はいつでも視点を回せる。手順が進んでも視点は勝手に戻さない。
- 2.7 When 作品が完成すると, アプリは紙をちょうど1周ゆっくり回して見せ、始めの向きで止める。触る・視点の操作で止める。動きの軽減では回さない。
- 2.8 アプリは、その手順で使う線の種類（谷折り・山折り・中割り折り）だけを凡例に出す。
- 2.9 重なった層は、紙の縁の線と、下の層ほど淡く暗い色で見分けられる。

## 3 折りの正しさ
- 3.1 紙は伸び縮みしない。どの姿勢でも、各三角形の辺の長さは元の紙と一致する。
- 3.2 平らに折りたたんだ姿勢では、重なる三角形の前後が一意に決まり、紙は互いを貫通せず、折り目をまたいで別の層が挟まらない。
- 3.3 作品データが、つながった部分を引きちぎる折りや、前提を満たさない選択を含む場合、アプリは構築時にどの作品のどの手順かを示して失敗する。
- 3.4 完成形は、作品ごとに決めた寸法と形の基準（models-*.md）を満たす。

## 4 品質・公開
- 4.1 When 390・768・1440px幅（縦と横）で使うと, アプリは横にはみ出さず、操作部は44px以上で、キーボード・読み上げ・動きの軽減に対応する。
- 4.2 When 利用者が動きを減らす設定にしていると, アプリは動きを再生せず、手順の終わりの姿勢へ切り替える。
- 4.3 アプリは外部通信をしない。選んだ作品や手順を端末に保存しない。
- 4.4 When 共有すると, アプリはX・LINE・端末の共有シート・リンクのコピーを提供し、OGPと正規URLを持つ。
- 4.5 公開用にビルドすると、一覧・canonical・OGP・同梱ライセンス・CSPが揃い、公開ゲート（`npm run publish:check -- --day 87`）を通る。
- 4.6 If WebGLが使えない場合, アプリは理由と、手順を文章で読める一覧を表示する。

## 対象外と隣接する責任
折り紙の手順の正しさは作品データが持つ。実物の紙の厚み・弾性・しわは再現しない。鶴・ほかの作品、手順の自作、AR、音声、保存とアカウントは含まない。
