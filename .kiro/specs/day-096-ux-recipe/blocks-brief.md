# 部品ごとのデザイン指示（B1・B2）

共通: 1つの部品に「目を引く要素」は1つ。見出し→中身→（あれば）補足の順で視線が流れる。余白は広めに。スマホ（390）で最初に整え、広い幅で足す。
項目の数が1〜最大で変わるので、grid は `repeat(auto-fit…)` か、件数に応じたクラスを使わず崩れない作りにする。

## B1
| 部品 | 見た目 | 狙い・注意 |
|---|---|---|
| hero | 0 中央／1 左寄せ＋図形／2 大見出し | 見本あり。4テーマで質を揃える。v1 の図形は広い幅で見栄えを上げる。v2 の下線マーカーは2〜3行でも崩れない |
| pain | 0 チェック／1 カード | 共感の部品。0は丸いチェックの行。1は2列のカード（引用符の飾り）。`lead` は結論の帯（accent-soft）で、下向きの矢印 |
| benefits | 0 アイコン／1 番号つき／2 左右交互 | 0はアイコンの角丸バッジ（項目ごとに check heart shield clock spark leaf を順に）＋3列。1は大きな番号（01…）＋区切り線。2は広い幅で左右交互、狭い幅は縦 |
| steps | 0 縦／1 横 | 0は番号の丸を線でつなぐ縦の流れ。1は広い幅で横に流れ（矢印）、狭い幅は0と同じ。番号は順番どおり（空の項目を飛ばしても詰める） |
| proof | 0 横ならび／1 カード | 大きな数字（`.uxr-num`）と説明。0は仕切り線つき、狭い幅は2×n。1はカード。数字が長い（8字）でも折り返して崩れない |
| voices | 0 カード／1 大きな引用 | 0は引用符の飾りと名前の頭文字の丸。1は最初の声を大きく、残りを小さく。引用は文字を読みやすく（行間・字間） |
| story | 0 文章／1 引用風 | 160字を読みやすい行長で。署名（who）は「— 名前」。1は左に太い線の引用風で、文字は大きめ |
| team | 0 丸／1 カード | 名前の頭文字を丸のアイコンに（顔写真は使わない）。名前・役割・ひとこと。1〜4人で整う |

## B2
| 部品 | 見た目 | 狙い・注意 |
|---|---|---|
| menu | 0 一覧／1 カード | 0は名前と値段を点線でつなぐ行（値段は右揃え・`.uxr-price`）。一言は名前の下。1は値段を大きく見せるカード。`foot` は小さな注記 |
| plans | 0 横ならび／1 縦ならび | `pick` のプランに「おすすめ」のリボンと強い枠。`lines`（改行区切り）は✓の箇条書き。0は広い幅で2〜4列、狭い幅は縦。1は1行1プラン |
| schedule | 0 縦／1 カード | 0は左に時間（等幅の数字）・右に内容・縦の線と点。1は時間のチップつきカードのグリッド |
| faq | 0 開閉／1 一覧 | 0は `details/summary`（開閉の印は＋−をCSSで。キーボードで開閉できる）。1は Q の丸い印＋答えが常に見える |
| compare | 0 表／1 チェック | 0は `table`（`th scope`）。左（leftName）を強調色で、右は控えめ。狭い幅でも横スクロールしない（`table-layout:fixed`）。1は2列の✓と—のリスト |
| guarantee | 0 帯／1 シール | 0は盾のアイコン・見出し・説明・一言のチップの帯。1は円形のシール（見出しを中に）と説明 |
| limited | 0 帯／1 バッジ | 細い強調の帯（ラベルのチップ・説明・数字を太く）。焦らせる赤・点滅・カウントダウンは使わない。1は小さなバッジ。`real` はページに出さない |
| form | 0 縦／1 ひとこと | 0は項目を縦に並べた枠とボタン（狭い幅は全幅）。1は先頭の1項目だけの枠とボタン（広い幅は横並び）。preview は押せない枠・export は本物の入力欄 |
| cta | 0 帯／1 カード | 見本あり。0は強調色の帯。1は左に太い線のカード。4テーマで質を揃える |
| access | 0 カード／1 シンプル | 0はピンのアイコンの見出しと、項目名のチップ＋内容の行。1は区切り線の定義リスト。地図は置かない（外部通信になるため） |
| footer | 標準 | 控えめ。名前・注意書き（小さく）・リンク名（リンクにはしない）。余白は広め・濃い地に反転してよい |
