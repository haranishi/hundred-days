# 見た目の方針（ページ・道具）

## 1. ユーザーが作るページ（`.uxr-page`）の人格
4つのテーマは、同じ部品を「別の店の顔」にする。トークンの実体は `lib/page-themes.js`。

| テーマ | 人格 | 特徴 |
|---|---|---|
| soft やわらか | あたたかい・親しみ | 生成りの地・丸ゴシック・大きな角丸・ふんわりした影・丸いボタン |
| crisp きりっと | 誠実・実務的 | 白地・太い見出し・角は小さい・影なし・細い線 |
| lively にぎやか | 元気・遊び心 | 黒い太枠・ずらした硬い影・極太の見出し・強調色が前に出る |
| calm しっとり | 静か・上質 | 灰みの生成り・明朝の見出し・字間が広い・角はほぼ無し・線は細い |

- 6つの強調色は、白い文字を載せて 4.5:1 以上（`ACCENTS`）。薄い地の上の強調色の文字は `--uxr-accent-text`（少し濃くした色）を使う。
- 写真を使わない代わりに、**線の絵・CSSの図形・グラデーション・大きな数字・活字の組み方**で質感を作る。余白と行間を惜しまない。
- 避ける: 紫のグラデーションの背景・どこにでもある3列のカード・意味のない丸い飾り・全部が中央揃い・影の重ね過ぎ。見出しは `text-wrap:balance`、本文は `pretty`。
- 日本語の組み: 行間 1.75・見出し 1.38。長い単語で崩れないよう `overflow-wrap:anywhere`。字間を詰めすぎない（calm 以外は 0〜.02em）。

## 2. 道具の画面（アプリ自体・app.css と panels.css）
ユーザーのテーマと喧嘩しないよう、**無彩色寄り**にする。強調は1色。

| 変数 | 値 | 用途 |
|---|---|---|
| `--app-bg` | #EEF0F3 | 画面の地 |
| `--app-panel` / `--app-panel-2` | #FFFFFF / #F7F8FA | パネル・入力欄 |
| `--app-ink` / `--app-muted` | #1D2430 / #5A6372 | 文字（地に対して 4.5:1 以上） |
| `--app-line` | #D9DDE3 | 区切り線 |
| `--app-accent` / `--app-accent-ink` | #24406B / #FFFFFF | 主ボタン・選択 |
| `--app-focus` | #1B5FD6 | フォーカスの輪（3px・2px離す） |
| `--app-danger` | #B3261E | 削除（色＋文字の両方で示す） |

- 段階の色は `STAGE_COLORS`（`lib/contract.js`）。チップは「薄い地＋濃い文字＋記号（気・わ・信・動・安）」。**色だけで見分けさせない**。
- 角丸 10/14/20・影は2段階だけ（細い／持ち上がり）・区切りは1px線。間隔は 4px の倍数。見出し 20/16/14・本文 14〜15・補足 12（最小）。
- 診断の✓と！は、アイコン＋文字。点は円のリング（数字を中に）。動きは 150〜220ms の ease。`prefers-reduced-motion` で止める。
- 押せる所は 44px 以上（指）。つまみ・▲▼・チップも。ホバーが無い端末で情報が隠れない。
- プレビューの枠: スマホ幅（390）は丸みのある枠の中、パソコン幅（960）は細い枠。**ページが主役**で、枠は薄く。選択中の部品は2px の `--app-accent` の外線＋左に小さなタグ（部品名）。
- 画面全体で、ユーザーが選んだ強調色（ページ側）以外に彩度の高い色を出さない。
