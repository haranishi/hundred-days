# Web版の画面文言

## 使い始め
- 見出し：スマホが、発表のリモコンに。
- 説明：PCでPDFを選び、スマホでQRを読み取る。インストール不要。
- 主ボタン：PDFを選ぶ
- 接続：スマホで読み取って接続
- QRの補足：QRを知る人が操作できます。接続する相手だけに見せてください。

## 資料
- 読込：このPCのブラウザでPDFを開いています。
- 制限：25 MiB・100ページまで。
- 確認見出し：資料を確認
- 確認説明：全ページを確認してから切り替えます。取消すると、今の資料を続けられます。
- 採用：この資料で発表する
- 取消：元の資料を続ける
- PowerPointの案内：PowerPointはPDFに書き出してから選んでください。アニメーション・動画は静止画になります。

## 接続と終了
- 待機：PCの準備完了・スマホでQRを読み取り
- 切断：接続が切れました。つなぎ直しています…
- 無効/期限：この接続は終了しています。PCで新しく始め、QRを読み直してください。
- 終了：接続を終了
- 消去：資料とカンペはこのタブに保持します。終了・再読込・タブを閉じると消えます。
- 処理の説明：元のPDFはこのPCで表示します。スマホへ渡すプレビューとカンペは暗号化して中継します。接続は最長4時間です。

技術名や開発用コマンドを使い始めの導線へ入れない。QRは投影枠の外に置き、全画面へ重ねない。
