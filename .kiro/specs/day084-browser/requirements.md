# Day84 AirPresenter：ブラウザで使う

本人の「ダウンロードせずリンクから使う」「Webアプリは基本ブラウザだけで完結」による改修。
既存day084-airpresenterのローカル配布の方針1.2を、このWeb版の通常導線で置き換える。ローカル実装と私的資料は保持する。

## 1. ブラウザから始める
- 1.1 公開URLを開くと実際のアプリを使える。インストール、ZIP入手、Node.js、ローカルサーバー起動を利用者に要求しない。
- 1.2 PCで資料を選び、PCのQRまたは接続リンクからスマホを接続する。初回サンプルも操作でき、接続待ち・失敗・再試行を文字で示す。
- 1.3 公開URLは既存のhttps://rairakku.com/100days/day-084-airpresenter/を維持する。他のDay・既存の3084サーバー・私的な元資料を変更しない。

## 2. 資料をPC内で表示する
PowerPointの直接読込は[day084-powerpoint](../day084-powerpoint/requirements.md)が優先する。以下のPDF限定2.2は旧版の記録。
- 2.1 PDFをブラウザ内で読み込み、順序・縦横比・日本語を表示する。25MiB・100ページまで。PDF原本を外部へ送信しない。
- 2.2 PowerPointは「エクスポート/名前を付けて保存→PDF」の方法を案内する。PPTX/PPTをPDFと誤認して表示せず、直接選択時に対処を示す。
- 2.3 差し替えでは処理段階・経過時間・実際のページ数を示す。全ページの確認→採用/取消を用意し、失敗・取消で旧資料を維持する。
- 2.4 プレビュー・読込画面・ドロップ画面・全画面操作バーを採用後に重ねない。新しい画像の表示を待って切り替える。

## 3. スマホと同期する
- 3.1 推測困難な部屋・ホスト/スマホ別の権限を発行し、別部屋・無権限・権限違いの操作を拒否する。QRに操作権限があることを示す。
- 3.2 送り/戻り・暗転・長押しポインター・カンペ・共通時計をPCとスマホで同期する。PCを唯一の状態の正本とし、1操作を重複適用しない。
- 3.3 画像プレビューとカンペを含む同期内容はブラウザで暗号化し、中継側は鍵・平文の内容を保管しない。鍵と権限をログ・通常のクエリ・公開物に出さない。
- 3.4 切断時は古い操作を止め、復帰時は現在の状態へ同期する。ポインターは解放・切断・一定時間更新なしで消す。PCから離れても同じWi-Fiの端末を操作できる。
- 3.5 接続は最長4時間。終了ボタンで接続を無効化し、ブラウザの資料・カンペを消去する。再読込・タブを閉じた場合の扱いを明示する。

## 4. 公開と品質
- 4.1 390/768/1440px、キーボード、PCクリックによる実全画面、テキスト入力中のショートカット抑制、タッチ操作を確認する。
- 4.2 実Workers/DO runtimeと別PC/スマホブラウザでPDF採用・取消・再選択・暗転・カンペ・時計・再接続・不正権限・期限を検証する。
- 4.3 静的配信をasset-firstとし、部屋作成・接続数・メッセージサイズ/頻度を制限する。有料プランや外部変換サービスを有効化しない。
- 4.4 公開ゲート・全体check・独立レビュー・PRの最新head必須CIを通し、マージ/公開後のURLから実際に2ブラウザを接続して確認する。SNS投稿は行わない。
