# 手がかりを集める旅 — UI改修

## 目的とユーザーストーリー
志望業界が未定の学生として、答えるたびに発見が積み重なる感覚を得たい。
結果を受け身で読むだけでなく、気になった仕事を自分から開いて調べ始めたい。
受け入れ条件はR17–R20。12問/5択・分岐・判定・保存・旧ワークの仕様を引き継ぐ。

## UX5階層
- 戦略: 自己分析の重さを減らし、「次も答えてみたい」「この仕事を見てみたい」につなげる。
- 要件: 導入のカード体験、12問の道のり、6観点の収集、短い選択の反応、結果の探索。
  外部サービス、音、連続する装飾アニメーション、適合率、ランキングの変更は追加しない。
- 構造: 出発前のカード → 前半6問「興味をひろう」→ 後半6問「場面を深める」→ 結果。
  結果は軸 → 業界 → 企業への質問。各場所へ移動でき、仕事例から詳細を開ける。
- 骨格: 主CTAを導入の左/上、開けるカードを右/下に配置する。
  質問を主役にして上に12地点の道、右/下に6観点のパスポートを置く。
  結果は完了のスタンプと軸を先に見せ、持ち出し操作と探索の導線をまとめる。
- 表層: 生成り・深緑を継承し、ライム色・朱色・淡い紫を小さな紙片に使う。
  大きな見出し、丸みのあるカード、地図の線、自作の線画を一貫して用いる。
  読む部分は静かに保ち、動きは選択と発見の瞬間に絞る。

## 導入と収集
導入カードの内容はGUIDE_EXAMPLEから計算した軸/業界/企業への質問を使う。
開閉はbuttonのaria-expandedで示し、架空ラベルと見本閲覧の補助導線を添える。
収集の6観点は各0/1/2問の回答数だけを表示する。不明や否定でも同じように埋まる。
12地点は完了・現在・未回答を形と数字で区別し、native progressも維持する。
収集は回答配列から再描画するため、戻る/修正/保存復帰で古い状態が残らない。

## 動きと状態遷移
選択直後に回答を反映・保存し、選んだカードを短時間示して次へ進む。
選択肢の連打を抑止する。画面移動ではタイマー/アニメーションを取り消し、
古いrequestAnimationFrameによるフォーカス移動を世代番号で無効にする。
質問中はルートのscroll-behaviorをautoにし、先に始まった自動スクロールが押下中に続かないようにする。
確定はclickで行い、押したまま外へ移動した場合は回答しない。入力の既定フォーカス操作は保つ。
質問/結果の登場はtransform/opacityのみの短い動きにし、内容を操作不能にしない。
prefers-reduced-motion時は待ち演出と登場演出を省略する。モーダルのフォーカスを奪わない。
結果を再表示したときも全情報を即時に読める。結果を開くための追加操作は設けない。

## 結果の探索・印刷
軸カードに観点別の線画を添え、根拠の質問・回答は常時見せる。
業界カードは名前/概要/仕事例/接点を表示し、確認事項と公的リンクをdetails内に置く。
否定された観点など重要な注意は折りたたまない。txt/コピーにも追加根拠・注意・公的URLを残す。
印刷時はdetailsを開いた状態で表示し、移動操作・装飾・演出だけを省略する。
不明/肯定なし/同点の誠実な案内を保ち、無理に「適職発見」と祝わない。

## 変更範囲と検証
Day72のHTML/CSS/ガイドDOM、README/meta/OG、既存仕様と関連E2Eを変更する。
判定・質問データ・旧ワーク・共通共有・依存は変更しない。既存formatterの持ち出し情報は補完する。
新しい状態遷移、連打、画面移動、導入カード、折りたたみ/印刷、収集復帰をE2Eで検証する。
390/768/1440pxの実画像、通常/低減動作、キーボード、5〜10分の実操作を独立評価する。
構文・全体単体・ビルド・公開ゲート、PR CIとmainデプロイ、本番の操作確認まで行う。
