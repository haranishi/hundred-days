> 注意：Web検索の要約だけを根拠にした調査（ページ全文は未確認）。数値の多くは「推定」で、JSONの confidence は mixed。**3Dモデルの形に使う目安であり、公開文に事実として書かない**。

## 結論・前提

魚8種（マアジ・マイワシ・マサバ・サンマ・マダイ・ヒラメ・シロギス・カツオ）について、手続き的3Dモデル生成およびさばく位置（頭・ヒレ・腹腔・中骨・腹骨・血合い）の再現に必要な外部形態・内部構造・体色の数値表（A〜J）と、機械可読JSON（各1件、計8件）を以下に全文出力する。

- **変更したファイル**：なし（読み取り専用・ファイル作成なし）
- **根拠の取得方法とURLの扱い**：本環境にはWebページを直接開くツールがなく、`search_web` の検索要約結果のみを参照している。そのため「実際に開いて読んだページのURL」は**未確認（記載なし）**とし、各表では出典の種類（FishBase／機関の資料／図鑑／論文／推定）と参照元名（FishBase、FAO種カタログ、水産研究・教育機構・自治体の資料、査読論文等）を記載した。
- **未確認・推定項目の扱い**：全8種とも、計数形質（鰭条数・脊椎骨数・稜鱗数等）や主要体長比は FishBase・FAO・論文・機関資料から取得したが、最大体高位置・体幅・尾柄高（カツオ・シロギス除く）・各ヒレの終点/高さ・脊椎径比・皮厚・16進カラーコード等は原典の横断数値が未確認のため**「推定」**と明記し根拠を付した（JSON の `confidence` は全種 `"mixed"`）。一覧は末尾の第3節にまとめた。
- **共通仕様**：寸法は標準体長 `SL = 100%` 基準、頭部の細部（吻長・眼径・口の裂け目長）は頭長 `HL = 100%` 基準。数値は半角、範囲は `中央値（最小〜最大）` で表記した。

## 3. 確認できなかった項目（未確認）と、その代わりに置いた推定の一覧

| 区分・項目 | 対象魚種 | 未確認の理由 | 代わりに置いた推定の根拠 |
| :--- | :--- | :--- | :--- |
| 直接開いて読んだページURL | 全8種 | 読み取り専用の検索要約ツール（`search_web`）のみで直接ページ取得不可のため未確認 | URL欄は空とし、検索結果で確認できた出典種別・機関名・論文著者名のみ記載 |
| 最大体高の位置（`maxDepthPos_pctSL`） | 全8種 | FishBase・FAO等の定型計測項目に「最大体高の吻からの距離」が掲載されないため | 各魚種の分類図・標本写真における背腹輪郭の最大点を目測して設定 |
| 最大体幅＝厚み（`maxWidth_pctSL`） | カツオ以外の7種（およびヒラメの厚み/体高比） | 標準的な分類計測では体高が主で、成魚体幅の横断的 %SL 表が未確認のため（カツオのみFAOに「体高の約2/3」記載あり） | FishBase/FAOの断面記載（円筒・紡錘・側扁）と一般的魚体縦横比から推定 |
| 尾柄の最小高さ（`peduncleDepth_pctSL`） | マアジ・マイワシ・マサバ・サンマ・マダイ・ヒラメ（カツオ・シロギス以外） | 検索範囲内で6種の成魚 %SL 実測範囲が直接確認できなかったため | 各科の標本図からの目測と遊泳型（細尾柄型 vs 太尾柄型）の傾向より推定 |
| TL / SL 比（`TL_over_SL`） | サンマ・ヒラメ | FishBase の Length-Length 表に両種の直接換算式が掲載されていなかったため | 尾ビレ形状（サンマ小ぶり二叉、ヒラメ大型丸尾）と標本図測より推定（1.12 / 1.19） |
| 吻長・眼径（`snout_pctHL`, `eyeDia_pctHL`）および目の高さ | サンマ（両者）、ヒラメ（吻長）、全8種（体軸からの目の垂直位置） | サンマ・ヒラメの成魚 %HL 範囲および目の垂直座標が定型表で未確認のため | ヒラメはFAO記載「吻≦眼径」と眼径比から、サンマは標本図測から推定。水平位置 `eyePos_pctSL` は `HL × (吻長% + 眼径%/2)` で幾何計算 |
| 口の裂け目の長さ（%HL） | カツオ以外の7種 | 上顎長の %HL 数値はカツオのみFAO記載が確認でき、他7種は「眼の前縁下に達する」等の相対記載のみのため | FAO・論文の上顎後端と眼の位置関係記述＋吻長・眼径から幾何算出 |
| ヒレの終点・最大高・一部起点/長さ | 全8種の背・尻ビレの終点と高さ、胸ビレ長（マアジ・マサバ・サンマ・マダイ・ヒラメ・シロギス）、腹ビレ起点（マイワシ・サンマ・ヒラメ・シロギス）、尾ビレ二叉切れ込み比 | FishBase MorphMetrics は起点（pre-dorsal等）が中心で、基底終点・鰭高・切れ込み深さ比の定型データが網羅されていないため | FAO・図鑑の相対位置記述（例：マアジ胸ビレが第2背ビレ起点を越える、カツオ第1・第2背ビレ間隔≦眼径等）と標本図測から整合推定 |
| サンマの腹椎・尾椎の内訳 | サンマ | FishBaseは総脊椎骨数62〜69のみ掲載、個別論文の厳密な腹椎＋尾椎数が未確認のため | 骨学文献の「腹椎40超＋尾椎20超」の記述および肛門位置（約70% SL）から `41 + 24 = 65` と推定 |
| 脊椎の太さ（`vertebraDia_pctDepth`） | 全8種 | 椎体径の体高比を魚種横断でまとめた公的データ・論文が未確認のため | 各魚種の体高・骨格の頑丈さ（細長魚7.5〜10%、通常紡錘5.5〜8%、体高の高いタイ・ヒラメ4.5〜5%）から推定 |
| 腹腔・肛門・鰾・肋骨・小骨・さばく部位の %SL 範囲 | 全8種 | 形態・調理資料では「鰓蓋後〜肛門」「背骨沿い」等の解剖学的記述のみで、%SL 数値化が未確認のため | 頭長（鰓蓋後縁）と Pre-anal 位置を基準に、肛門＝尻ビレ起点の直前（約1〜3% SL手前）、腹腔＝頭後〜肛門直前として幾何整合推定 |
| 皮の厚さ（mm） | 全8種 | 魚種別の実測 mm 値を横断比較した学術データベースが存在しないため（サイズ・部位依存） | 調理科学・加工上の扱い（手剥き可能な薄皮0.25mm前後、中厚0.6〜0.8mm、炙りが必要な厚皮1.2mm前後）から目安を推定 |
| 16進カラーコード（`colors`） | 全8種 | 生鮮魚体の標準色票（HEX）の公的データベースが未確認のため | FishBase・図鑑・水産機関の体色記述（暗青緑・桜色・飴色・暗褐色等）から生鮮時の代表的近似色をHEX化 |
