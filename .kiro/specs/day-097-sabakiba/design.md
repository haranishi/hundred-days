# 設計の全体（さばき場）

## 層（上が下を呼ぶ。下は上を知らない）
1. **データ**: `lib/species/*.js`（魚の形・色・骨）・`lib/procedures/*.js`（手順）。純データ。契約の検証を通る。
2. **解剖（純JS・three不要）**: `lib/anatomy.js` 体の輪郭・部位の点（アンカー）・線（カーブ）・内外判定。Nodeだけで試験できる。
3. **形（three）**: `lib/loft.js`・`lib/pieces.js`・`lib/bones.js`・`lib/fins.js`・`lib/head.js` 部品（piece）ごとのBufferGeometry。
4. **見た目（three）**: `lib/materials.js`・`lib/textures-*.js`・`lib/stage.js`（まな板・光・環境）・`lib/knife.js`（包丁の模型）。
5. **時間（純JS）**: `lib/timeline.js` 手順と進み具合（手順番号・0〜1）から、全部品の状態を返す純関数。**状態は進み具合だけで決まる**（巻き戻し・飛ばし・撮影が同じ結果）。
6. **表示（three）**: `lib/view3d.js`（描画ループ）・`lib/scene-fish.js`（状態を部品に反映）・`lib/camera.js`・`lib/controls*.js`・`lib/gfx*.js`（画質3段と自動降格）。
7. **画面（DOM）**: `app.js`・`lib/ui-*.js`・`lib/persist.js`・`shared/`（共有）。3Dが使えないときは文章の手順だけで動く。

## 決めたこと（捨てた案と理由）
- **魚は手続きで作る**。捨てた案＝外部の3Dモデル（権利と帰属の管理が重い・中の骨がない・身を切り離せない）。
- **部品は4分割＋骨で統一**: 背側・腹側 × 左右の4つの身（quarter）＋中骨＋頭＋内臓。三枚おろし＝左2つ・右2つをまとめて動かす／五枚おろし＝4つ別々／手開き・背開き＝左右を蝶番で開く／節取り＝4つを別々に取る。方法ごとに別の形を作らない。
- **身は輪郭の連なり（断面のループ）をつないで作る**。捨てた案＝ボクセルや面の切り抜き（重い・荒い）。切り口は断面の内側の辺がそのまま作る。
- **切り込みはシェーダーで描く**（切り線と進み具合を渡す）。形は切り離しの瞬間にだけ分かれる。
- **皮は身と別の殻**（皮引きで剥がれる）。**うろこは形でなくシェーダー**（量を0〜1で消す）＋飛び散る粒。
- **時間は純関数**（上の5）。捨てた案＝その場のトゥイーン（巻き戻し・スライダーで食い違う）。
- 左利きは**シーン全体の左右反転**＋文章の記号置換。
- ブラウザで完結。サービスワーカーは入れない（古いキャッシュの事故を避ける）。

## 決定性
魚の形の乱数は `lib/rng.js`（種つき）。`Math.random()` は使わない。撮影・試験は `?seed=`・`?t=`（時計を止める）で再現する。

## 試験
単体（node:test・`tests/index.mjs` に登録）: 契約・解剖・形（閉じた体・体積）・時間（飛ばしても同じ）・練習の採点・手順データの検証（全種）。
E2E（Playwright・Chromium・WebKit・指）: 全種の全手順を最後まで進める・左利き・透視・練習・共有・外部通信0・本番CSP。見た目は固定ショットの採点（体験→見た目・各最大3周）。

## 公開の門（下書きのうちに通す）
`npm run publish:check -- --day 97`・`npm run check`・`shared:sync`・`index:sync`・THIRD_PARTY（three.js）・LICENSE・本番CSPでのE2E（`script-src 'self'`＝`waitForFunction` に文字列を渡さない）。

## 危うい所（先に潰す）
1. 断面ループの切り口が閉じない・法線が割れる → 最初にアジ1匹の形だけを作り、閉じ方を数値で試験してから広げる。
2. 手順の内容の誤り → 調査（research/）と照合し、別系統のAIに手順だけを読ませる。
3. iOS の描画の重さ・WebGL2 未対応 → 画質の自動降格と、文章だけの代替。
4. 3Dの動きと文章のずれ → 手順データは1か所（`procedures`）。文章は動きから別に書かない。
