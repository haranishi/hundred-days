# 影討ち スマホ対応：ユーザーストーリーとUX5階層
2026-11-03。実装の前に、戦略層から書いて設計判断を導く（Web制作ハーネス§1-1）。設計書の「入れない：スマホ操作」は、本人の依頼でこの仕様が上書きする。

## ユーザーストーリー
| ユーザー | 欲しいことと理由 | 受け入れ条件 |
|---|---|---|
| 本命：Xのリンクを押したスマホの人（片手で持って来る） | 10秒で遊び始めたい。説明書は読まない | 縦向きでもタイトルまで進める。出陣すると「横向きに」と案内が出て、横にすれば続きから遊べる |
| 同上（遊び始めて30秒） | 指がどこで何をするか、画面を見れば分かる | 左を押して歩く／右をなぞって見回す、が最初の数秒だけ出る。ボタンは文字つき |
| 慎重に忍ぶ人 | 音を立てずにそっと動きたい | 歩きの最高速までは音の大きさが変わらない。走るには、わざと外へ倒す |
| 見つかった人 | すぐ逃げ、すぐやり直したい | 走る・しゃがむが親指のまま届く。「討たれた」画面からワンタップで再挑戦 |
| 小石を使う人 | 狙って投げ、迷ったらやめたい | 押している間ねらい、離して投げる。ちょんと押せば、ねらいを保ったまま両手で調整できる。やめるは常に見える |
| このゲームが救う相手：キーボードを持たない人 | 同じ本能寺を、同じ規則で遊びたい | 見つかり方・速さ・音はキーボード版と同じ |
| 安い機種の人 | カクつくより、少し粗くても動いてほしい | 重ければ自動で画質を下げる。止まったままにはしない |
| 作る人（本人） | 手元のスマホで確かめられる | 実機で見る点が一覧になっている（最終報告） |

## UX5階層
| 階層 | 決めたこと |
|---|---|
| ①戦略 | 差別化はキーボード版の緊張感を、そのままスマホの親指に載せること。スマホの人の多くはXから来る＝待てない・読まない。勝ち筋は「操作が迷わない」と「忍びの精度（そっと歩く・すぐしゃがむ）が落ちない」 |
| ②要件 | 入れる：スティック・視点ドラッグ・4ボタン・一時停止・横向き案内・スマホ用HUD・自動の画質調整。入れない：設定画面と保存（設計書の方針）、縦向きで遊ぶこと、ピンチ拡大、全画面、振動、ゲームパッド |
| ③構造 | 縦向きは「出陣」まで。遊ぶ画面で縦向きになったら自動で止めて案内する（戻したら一時停止の画面から再開）。アプリを離れても止める。迷う分岐は、小石のねらい（やめる）と、縦横の切り替え |
| ④骨格 | 左下＝スティック（触った所に出る浮動型。薄い目印あり）。右下＝いちばん大きい「当て身」、その弧に「しゃがむ」「小石」「攻撃」。右上＝一時停止（小）。それ以外の右半分は視点。明るさの目盛りは常に見えるよう、親指が隠さない上部へ置き、前方の番兵の印が出る真ん中を避けて右寄せ（体験の採点 第2周で、真ん中に置いたら番兵の「？」を隠した） |
| ⑤表層 | 墨黒・朱・金・生成りと明朝をそのまま使う。半透明で、背後の闇と灯りを邪魔しない。状態は色だけで示さない（しゃがむ・走るは文字、押せる当て身は朱の縁＋ラベル） |

## この5階層を通して変わる実装（実装前の予定）
1. 「全力で倒す＝走る」にしない。歩きの最高速を出そうと全力で倒す人が、走って音を立てて見つかるため（戦略）。走るはスティックの外側の輪
2. 「当て身」ボタンの文字を状況で変える（当て身／討つ／使う）。デスクトップにあった「E 討ち取る」の行は、ボタンの文字と光り方に統合する（骨格）
3. 小石は「押す間ねらう」と「ちょん押しでねらいを保つ」の両対応。やめるを常に出す（構造）
4. 設定画面を作らない代わりに、視点の速さは1か所の定数、音の入切は一時停止の画面だけに置く（要件）
5. 縦向きは自動で止める。出陣の瞬間に案内が出るので、戻したら「再開」を押すだけにする（構造）
6. 明るさの目盛りを左下から上部（右寄り）へ動かす（骨格。設計書の「常に出す」を守るため）
7. 状態は文字と形でも示す（表層）
8. 端のスワイプ・引っ張って更新・ダブルタップ拡大・長押しの吹き出しを止める（構造）

実装後に「実際に何個変わったか」を最終報告に書く（0個なら通し直す）。

## 結果（2026-11-03・実装と評価のあと）

- 予定の8個は、すべて実装に反映された（走りは外側の輪／当て身ボタンの文字と光り方／小石の2経路とやめる／設定画面なし・視点の速さは1か所・音の入切は一時停止／縦向きの自動停止／明るさの目盛りの移動／状態を文字と形でも／端のスワイプ等の抑止）。0個ではなかったので、通し直しはしていない
- 評価の周回で、実装の外から足したもの：攻撃の向きの補助（タッチのみ）／案内の帯の置き場所／ボタンの言葉の統一／低い横画面での結果・討たれた画面／明るさの帯を右寄せ（真ん中を番兵の印のために空ける）／他の指が触れたままでも押せる画面のボタン
- 範囲外として本人に返したもの：入口の地図表示、途中からのやり直し、動作中に押した攻撃の取り置き、小石を狙うときのカメラ
