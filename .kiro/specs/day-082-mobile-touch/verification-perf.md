# 重さの実測（4段と影・ブルーム）

2026-11-03 に tasks 4.2 の担当が測った。自動の引き下げの実測は [verification-adaptive.md](verification-adaptive.md)、全体は [verification.md](verification.md)。

**これはこの Mac（Apple M4 Pro の GPU）での値で、スマホの実機の値ではない。** スマホの GPU は桁違いに弱く、とくに画素数に比例する重さ（塗りつぶし・後処理）の効き方が違う。ここで言えるのは「段のあいだの相対の差」と「引き下げの仕組みが働くか」まで。

### 測った条件

- 道具：`tools/quality-bench.mjs`（`node tools/quality-bench.mjs a3 --parts A|B|C|S`）。生の数字は `.captures/a3/quality-bench-*.json`、表は同じ場所の `.md`、見比べの画像は `.captures/a3/quality-shots/`
- ブラウザ：Playwright の Chromium 153.0.8010.12（`--use-angle=metal --enable-gpu --ignore-gpu-blocklist`。A・B は垂直同期とコマ数の上限を外す `--disable-gpu-vsync --disable-frame-rate-limit`、C は外さない）
- GPU：`ANGLE (Apple, ANGLE Metal Renderer: Apple M4 Pro, Unspecified Version)`
- 端末：844×390・画素比2・hasTouch・isMobile。URL は `?touch=1`。各段の画素比の上限（1.5・1.25・1・0.75）はどれも 2 未満なので、画素比3の端末でも描く画素数は表と同じ
- A・B：`?autostart=1&god=1&seed=1&touch=1&quality=<段>&perf=<構図>`。先頭 30 コマを捨てた 360 コマの、コマの間隔（rAF の間隔）と1コマの CPU 時間（`__perfResult`）。条件を交互に回して3周し、表は3周の中央値（右端に各周の値）
- GPU の時間：`EXT_disjoint_timer_query_webgl2` で、ゲームの rAF 1回の間の GPU 時間を測った（道具がページの rAF を包む。描画したコマの後ろ 360 個）。**絶対値は信用しない**：high では GPU p50 が 1コマの間隔 p50 より長く出ており、ANGLE/Metal の待ちや他のプロセスの GPU 利用を含んでいると見られる。段のあいだの相対の目安としてだけ使う。測る道を入れても間隔の p50 は変わらなかった（garden の1周で、入れて 5.5/2.0/1.9/1.9ms、入れずに 6.4/3.2/2.1/2.1ms。負荷の揺れの範囲）
- 負荷平均（uptime の1分値）：A は 10.5→9.4、B は 10.0→10.0、C は 6.8→6.6（ほかの作業と同じ機械で測った。揺れが大きいので「各周の値」も見ること）

読み方：
- この Mac では、垂直同期を外しても1コマの間隔は CPU 時間（約 1.5〜3ms）でほぼ決まり、画素数の差は間隔に出にくい。mid・low・min の間隔の差は 0.1〜0.4ms で、周ごとの揺れと同じ大きさ

見た目（`.captures/a3/quality-shots/<構図>-min-<版>.png` を目で見た）：
- 影を切ると、courtyard の上の建物の影の帯と、植え込み・人物の足元の影が消え、地面が均一に明るく見える。画面の暗がりと、規則（sim）の明るさの判定が食い違って見えるおそれがある（sim の明るさが影を数えているかは確かめていない＝未確認）
- ブルームを切ると、灯籠・提灯の光のにじみが弱くなる。この大きさの画面では差は小さい
- どちらも描画のエラー・崩れは無かった（撮影の console.error 0）

## 限界

- GPU はこの Mac（M4 Pro）で、スマホの GPU ではない。間隔はほぼ CPU で決まり、段の差（画素数）は GPU の目安にしか出ていない。スマホでの体感・fps は実機で確かめる（未確認）
- CPU を遅くするのは Chromium の擬似（メインスレッドを止める）。スマホの CPU・GPU・熱による性能低下とは違う
- 機械はほかの作業と共用で、負荷平均は 6〜20。各条件を交互に3周して中央値を取ったが、周ごとの揺れは 0.5〜3ms ある
- GPU の時間クエリの値は、待ちを含むとみられ絶対値は使えない（上の「測った条件」）
- 「間隔」は rAF の間隔。垂直同期を外した Chromium の値で、画面への表示の回数とは限らない
