全体は [verification.md](verification.md)。評価者は、作った人と別のセッションの AI（Opus・Claude API 経由の `claude -p`）。合格は16点以上かつ0点なし。AI の採点は代理の指標で、**最後の判定は本人が実機で5分遊んで下す**。

## 方法と守ったこと

- 体験評価：試遊ツール（`pt.mjs`。本物のタッチを CDP で送り、画像を保存する。時間は止めてあり `step`／`play` で進める）で、評価者が自分で2回以上通して10項目を採点。ゲームのコードは読ませない
- 見た目の評価：端末7種×全画面の撮影（`tools/touch-shots.mjs`）の画像だけを見て10項目を採点。画像は評価者が自分で開く
- 評価者の指摘は、そのまま直さず、コード・機械試験・計算で裏を取ってから「採用／却下／範囲外」に仕分けた。評価者は画面の大きさ（px）の見積もりを外すことがある
- 同じ指摘が2周続いたら、そこで止めて本人へ返す（NEEDS_HUMAN）
