# Day075 雨雲倉庫番
雲を押し、畑へ必要量ちょうどの雨を配る20面のパズル。
公開URL：https://hundred-days.pages.dev/day-075-amegumo-sokoban/

## 遊び方
PCは矢印キー/WASD、タッチは方向ボタン・スワイプ・隣接マスのタップで移動する。
雲を畑へ入れると1滴を消費する。空の地面では雨を使わず、すべての畑が必要量ちょうどでクリア。
Zまたは「一手もどす」で位置・雨・雨玉を戻せる。はじめからは確認後に初期状態へ戻る。
初回は図解3ステップと1滴のお試し。「遊びかた」から読み直せる。

## 四章・二十の庭
- 01–05 雫の庭：再入場と周回、二雲の順番。
- 06–10 石段の庭：雲は矢印の方向だけ通れる。庭師は両方向へ歩ける。
- 11–15 雨玉の庭：雲が拾うと1滴を補充。一つの玉は一度だけ使える。
- 16–20 風の庭：雲を風穴A/Bへ入れると対の出口へ移る。出口が塞がると押せない。
各章の導入で新しい仕掛けを覚え、後半は複数の条件を組み合わせる。
手帖から全20面を選べる。達成と最少手数をこの端末だけに保存する。

## 音と動き
「音をつける」で自作BGMと効果音を開始する。BGMと効果音の音量を別々に調整でき、ミュートも可能。
音量設定では開花音を試せる。説明と結果ではBGMが休み、非表示やミュートでは予約音も止まる。
雨→芽→開花は操作結果に同期し、クリア音は一度だけ。動きを減らす設定では完成形をすぐ表示する。
