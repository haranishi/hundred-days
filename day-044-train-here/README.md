# Tokyo Railscape — 東京の電車を、風景として眺める。

東京の5路線をイメージした3Dミニチュアを眺める、Day44の架空デモです。
48編成の動きは独自のサンプルで、実運行・実ダイヤとは連動しません。
鉄道会社の公式サービスではなく、乗車判断や到着時刻の確認には使えません。

## 街を眺める

リポジトリ直下で `node day-044-train-here/tools/serve.mjs` を実行し、
`http://127.0.0.1:8444/day-044-train-here/` を開きます。
初期表示からデモが動きます。路線パネルで電車を選ぶと追従できます。
「前方の風景」で進行方向を眺め、「都心の全景」で元の視点へ戻れます。
ドラッグで回転、ホイール／2本指で拡大縮小。ボタンと列車一覧でも操作できます。
キーボードでは「次の電車を見る」へTab移動し、SpaceまたはEnterで順に選べます。
動きを減らす設定では停止して開始し、再生ボタンを押すと動きます。

山手線・中央線・総武線・京浜東北線・埼京線の都心側区間が対象です。
列車本数、停車パターン、編成両数、運行状況を再現したものではありません。

## 3Dモデルと出典

Wikidataの駅座標（CC0）を丸め、独自の曲線で結んだ概略モデルです。
取得日・項目ID・版番号を `lib/station-coordinates.js` に記録しています。
線路間隔・高架高さ・4両の車体・駅の屋根・街並みは実物の精密な復元ではありません。
併走区間は車体が重ならないよう位置をずらしています。
追従中は視線を遮る建物を一時的に隠し、駅の屋根を半透明にします。
第三者の車両モデル、写真、地図タイル、音源は使用していません。
BlenderファイルやPLATEAUの建物モデルも含みません。

WebGLとThree.js 0.186.0を使用し、コードを自己配信しています。
依存の再生成はアプリ内で `npm ci --ignore-scripts` → `npm run vendor`。
MITライセンス全文は `vendor/LICENSE-three.txt` に同梱しています。
詳しい出典は [SOURCES.md](data/SOURCES.md)、設計は [REQUIREMENTS.md](REQUIREMENTS.md)。
