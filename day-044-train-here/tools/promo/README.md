# Day 044 紹介動画

`node day-044-train-here/tools/promo/render-promo.mjs` で30秒の縦型動画（1080×1920・BGM付き）を作る。
アプリを実際に操作して録画する。合成した画面は足さない。

## 流れ

東京駅へ寄る → 都心の全景 → 一覧から1編成を選ぶ → 追従 → 前方の風景 → 新宿 → 架空デモの明示 → タイトル。
絵コンテと字幕は `timeline.mjs`、音は `promo-audio.mjs`。秒数はこの1本に集約してある。
1コマ目はカメラが東京駅へ降りている途中から始める（止まった絵をサムネにしない）。

## 実画面で撮ることの制約

**この公開版は架空デモ専用**で、走る48編成は実際の運行・ダイヤとは無関係。
だから画面には「架空の運行デモ」を最後のタイトルまで出し続け、字幕にも
「いま」「現在位置」「リアルタイム」「運行状況」「公開中」は書かない。
字幕の数字（5路線・48編成・路線名）は書き出し前に画面の文字と突き合わせ、
食い違えばその場で止まる。

## 実GPUで撮る（headless では時間がずれる）

既定は headed。3Dの描画が重く、headless（SwiftShader）では録画のコマが不揃いになり、
**場面ごとに最大2秒、画と音がずれた**（2026-09-20 実測）。headed にすると、ずれは一定になった。
`PROMO_HEADLESS=1` で headless に戻せるが、下読みのばらつき検査で止まる可能性が高い。

## 切り出し位置は録画そのものから決める

録画が始まる時刻は実時間では測れない（実測で t0 の見積もりと0.3〜1.7秒ずれた）。
そこで**字幕が入れ替わった時刻を録画から読み**、絵コンテの並びと重ねて頭を切る。
書き出したあとにもう一度読み、予定と0.4秒以上ずれていたら失敗させる。

## 素材

映像は実アプリの操作だけ。外部の画像・音源・3Dデータは使わない。
127.0.0.1 以外への通信は録画中に断ち、断った宛先を最後に報告する（通常は0件）。
BGMは Day 042 の純JavaScript合成器をそのまま複製し、30秒の場面構成で作り直したもの。
`node promo-audio.mjs --variant b` でB案も書き出せる。生成物（wav・mp4・png・jpg）はGit追跡しない。

公開・SNS投稿は行わない。完成ファイルを見て、画面と字幕の一致・文字切れ・音量を確認する。
