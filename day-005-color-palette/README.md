# Day 005: その写真、何色でできてる？

画像をドロップすると、その画像を構成する主要な6色を取り出して、カラーコード（HEX）をタップでコピーできるツールです。デザインや資料づくりで「この写真の色をそのまま使いたい」ときに、デザインソフトを開かずに済ませるために作りました。

公開URL: `https://hundred-days.pages.dev/day-005-color-palette/`

## 使い方

1. 画像をドロップゾーンへドラッグ＆ドロップします（タップしてファイル選択、Ctrl/Cmd+Vのペーストでも可）。
2. 主要な6色が、占有率の大きい順にパレットとして表示されます。
3. 色をタップすると、そのHEXコード（例: `#4F9CFF`）がクリップボードにコピーされます。「6色まとめてコピー」で全色を改行区切りでコピーできます。

画像を持っていなくても、「夕焼け」「新緑」「夜の街」のサンプルで試せます。サンプル画像はファイルとして同梱しているのではなく、開いたときにブラウザの中で描画しています。

## 色の取り出し方

メディアンカット法を使っています。画像を小さく縮小してから、全ピクセルを「いちばん色の幅が広い方向」で半分に割る操作を繰り返して6つのグループに分け、各グループの平均色を代表色にします。ほぼ透明なピクセル（alpha < 128）は数えません。

- 縮小サイズは最大辺120pxです。抽出される色は縮小の影響を受けるため、原寸のピクセルを1つずつ拾う「スポイト」とは結果が異なることがあります
- 占有率が25%・12.5%のような刻みに揃うのは、この方法が画素数を半分ずつに割っていくためです。色ごとの実面積そのものではなく、6グループに振り分けたあとの画素数の割合です
- 単色に近い画像やべた塗りの画像では、グループが6つに満たなかったり、平均色が同じHEXに丸まったグループを1つにまとめたりするため、表示される色が6色より少なくなることがあります

## プライバシー

**画像はどこにも送信されません。** 色の抽出はすべてこの画面の中（ブラウザのcanvas）だけで行われ、外部通信・保存（localStorage・Cookie）は一切ありません。ページを離れると読み込んだ画像は消えます。

## 対応していないこと

- 色数の変更（6色固定です）
- パレットの保存・履歴
- スポイト（1ピクセル単位の色取得）
- ブラウザが表示できない画像形式。HEICなどは環境によって読み込めません（読み込めない場合はその旨を1行表示します）
