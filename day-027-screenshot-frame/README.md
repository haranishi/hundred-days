# Day 027「スクショに額縁を」

## 何をするか

スクショを貼る、落とす、または選ぶと、余白・角丸・影・背景を付けたPNGに整えます。背景は10種、比率は6種です。ウィンドウ風の枠も選べます。結果は保存するか、対応ブラウザで画像としてコピーします。

## なぜ作ったか

スクショをそのまま載せると、端が画面や資料の地色へ沈みます。余白と背景を足すだけの作業を、貼ってすぐ終わる形にしました。業務画面にも使えるよう、画像を外へ送らない道具にしています。

## 設計上の判断

- 元画像は切らず、縦横比も変えません。固定比率では背景を足して中央へ置きます。
- Canvasは出力解像度そのものです。画面ではCSSだけで縮めます。
- 余白・角丸・影は元画像の幅を基準にします。画像の大きさが変わっても見た目の比率を保ちます。
- 長辺は4096pxまでです。超える場合は全体を同じ比率で縮めます。
- 枠は無彩色の帯と灰色の丸3つです。特定の端末やOSは模しません。
- 設定変更は1フレームにまとめて描画します。

## 出力の仕様（計算式と検算値）

余白は `round(画像幅 × 0.25 × 設定値 / 100)` です。既定値40では画像幅の10%になります。角丸は `画像幅 × 0.06 × 設定値 / 100`、影のぼかしは `画像幅 × 0.08 × 設定値 / 100` です。

800×500px、既定値、枠なし、自動比率では余白80px、出力960×660pxです。1:1では960×960pxです。枠ありでは帯29px、出力960×689pxです。6000×3000pxでは長辺を4096pxへ縮め、出力4096×2389pxになります。

## プライバシー

画像はブラウザの中だけで処理し、外部へ送りません。ページを閉じると消えます。端末に保存するのは背景・比率・余白・角丸・影・枠の設定と、その保存日時だけです。

## サンプル画像の出どころ

`sample/sample.webp` はDay 026「今夜の月」の一覧用スクリーンショットです。自作で、他人の画像は使っていません。

## やらないこと

- トリミング、回転、文字や図形の追加
- 複数画像の合成、端末のモックアップ
- JPEG・WebP出力、画質調整
- 画像の履歴、同期、サーバー保存、アカウント
