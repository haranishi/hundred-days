# Day 007: ひといきピアノ

クリック、タッチ、PCキーボードで演奏できる25鍵のWebピアノです。
インストールやログインなしで、思いついたときにすぐ音を出せます。

公開予定URL: `https://hundred-days.pages.dev/day-007-web-piano/`

## 設計上の判断

- 音源ファイルや外部SDKを使わず、Web Audio APIで端末内合成する
- 外部通信、アカウント、録音、演奏データの保存を持たない
- 画面操作とPCキーの両方を使え、スマートフォンでは鍵盤だけ横スクロールさせる
- 音程ごとに発音を管理し、和音とサステインを扱えるようにする

本物のピアノ音源の再現、録音、楽曲保存は今回の対象外です。
