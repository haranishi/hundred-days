# Day 003: タップ花火

**公開URL: https://hundred-days.pages.dev/day-003-tap-fireworks/**

暗い夜空をタップすると、画面下からその場所へロケットが上がり、6種類の花火からランダムに開花するブラウザのおもちゃです。

## 使い方

1. 夜空の好きな場所をタップします。
2. 押し続けると、同じ場所へ約250ms間隔で連発します。
3. 何もせず眺めると、ウェルカム花火と放置時の花火が自動で上がります。

## 技術メモ

- Canvas 2Dを毎フレーム半透明の夜空で塗り、前の光を徐々に消して残像を作っています。
- `lighter`合成で粒子の色を加算し、`shadowBlur`なしで発光を表現しています。
- 最大3,000個の粒子を固定プールで再利用し、上限に近いときは新しい開花の粒子数を絞ります。
- 牡丹・菊・柳・二色咲き・リング・ラメの6種類を、速度、色、重力、抵抗、寿命、点滅で描き分けています。
- 音源ファイルは使わず、ヒュー・ドン・パチパチをWeb Audioでリアルタイム合成します。ブラウザの制約により、音は夜空を最初にタップした後から鳴ります。
- `prefers-reduced-motion: reduce`では自動打ち上げを止め、タップ花火の粒子数を半分にします。

## 制約

外部ライブラリ、外部通信、音源ファイル、アカウント、課金、データの永続化は使用していません。

`actualMinutes`は、要件確認を始めてから実装とセルフ検収を終えるまでに実際に作業した分数です。
