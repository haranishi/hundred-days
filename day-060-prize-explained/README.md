# Day 060 — 今年の受賞の解説

今年の受賞者は、何をした人で、暮らしや研究の何が変わったのか。論文や機関の発表をもとに、すでに起きたことと、これからの計画を分けて、出典つきで解説します。
先頭には、いちばん新しく発表された賞の解説カード。ページの下には、年齢を入れてその歳で受賞した人を引く機能（Day59初版）も残しています。

## なぜ作ったか

受賞の見出しは「光遺伝学」のような専門用語のまま流れ、受賞者が何をして、何が変わったのかは伝わりません。
1つの賞を「何をした人か」「何が変わったか」「発見から受賞まで何年か」の3つで説明します。基礎研究が暮らしに届くまでの長さが見えるようにしました（2026年は、医学賞が24年、物理学賞が13年、化学賞が40年と31年。いずれも「論文の出版年と2026年の差」で、月は数えていません）。

## 守っていること

- **公式サイトの文章は、写さず・訳さず・言い換えません。** 解説は、論文などの出典の事実から、作者が自分の言葉で書いています。受賞理由だけは、公式のデータ（CC0）の原文のまま出します
- **すでに起きたことと、まだ期待の段階のことを、別の欄に分けます。** 文ごとに出典の番号を付け、確認日を添えます。出典のない文は載せません
- **文学賞と平和賞は、評価を加えず、事実だけを載せます**
- 受賞者の年齢は、解説のカードには出しません。年齢検索の欄だけが、公式データ（CC0）から数えた発表日の満年齢を出します
- 題名・見出し・共有の文・最初の画面に提供元の名前を入れません（API規約が、題名やロゴに名前・商標を使うことを禁じているため）。写真・メダル・ロゴも使いません
- 解説の検査（`tools/check-commentary.mjs`）と、ブラウザでの権利の関門（E2E）が、これらを機械で見張ります。検査の各項目は、わざと壊して落ちることを確かめてあります

根拠にした規約と線引きは [`COMMENTARY_RULES.md`](COMMENTARY_RULES.md)、仕様は [`REQUIREMENTS.md`](REQUIREMENTS.md) にあります。法律の専門家には確認していません。

## 毎日の更新

発表のたびに `data/commentary.json` へ解説を足します（手順は `COMMENTARY_RULES.md`）。発表されたのに解説がまだない賞は、受賞者と公式の受賞理由だけを出し、「準備中」と表示します。取得に失敗しても、同梱の記録にある賞は解説つきで読めます。

## 数え方（年齢の検索）

- 年齢は、受賞が発表された日の満年齢。同じ人が2回受けたら2回と数え、団体は数えません。辞退した人も数えます
- 生まれた月日が分からない人（21人）は7月1日生まれとして数えます。発表はどれも7月より後なので、実際は1歳若いことがあります
- 発表の前に亡くなっていた人（3人）は、亡くなった日の年齢です
- 辞退は公式データの状態のとおりに書き分けます。1958年のパステルナークは「辞退を強いられた」です
- 2026年10月7日時点で、個人のべ1,001回。年齢は17〜97歳、真ん中は60歳

## 今年の発表と端末への保存

今年（2026年）の6分野は、発表待ち・発表済み・データ待ち（発表予定の時刻を過ぎたが、まだデータに無い）を文字で示します。
発表の時刻は公式の予定を日本時間に直したもので、平和賞以外は「以降」です。
今年の分は Nobel Prize API の2本の応答から取り、取得時刻と一緒に localStorage へ保存します。
規約が負荷を抑えてキャッシュを使うよう求めているので、発表週は30分、それ以外は24時間は取り直しません。
取得に失敗しても、同梱データにある発表済みの賞は解説つきで出ます。前回の年齢も端末にだけ保存し、外へは送りません。

## データと出典

- 受賞者と賞：[Nobel Prize API 2.1](https://www.nobelprize.org/about/developer-zone-2/)（CC0・[利用条件](https://www.nobelprize.org/about/terms-of-use-for-api-nobelprize-org-and-data-nobelprize-org/)）
- 日本語の名前：[Wikidata](https://www.wikidata.org/wiki/Wikidata:Licensing) のラベル（CC0）。無い1人は英語のまま
- 解説の出典：各カードの下に、論文（DOI）・研究機関のページなどを番号つきで載せています

同梱の `data/laureates.json` は `tools/build-data.mjs` で作ります。**生年月日と没年月日は配りません。**
画面と同じ計算（`lib/age.js`）で発表日の年齢にしてから書き出し、必要な項目だけを残しています。
コードはMIT、データは各提供元のライセンスです。詳細は `data/SOURCES.md`。

## やらないこと

予想・候補者・推薦の話、写真や肖像、メダルの絵、公式サイトの文章の複製・翻訳・言い換え、受賞理由の翻訳（原文のまま出す）、国籍の表示（APIにあるのは生まれた国で、国籍ではない）、評価や順位や誇張の言葉。実行時に Wikidata へは接続しません。

## 確認

- `node --test day-060-prize-explained/tests/`（単体）・`npx playwright test tests/e2e/day-060.spec.mjs`（E2E）
- `node day-060-prize-explained/tools/check-commentary.mjs`（解説の検査。`--online` を付けると、出典のURLの応答と、受賞者番号のAPI照合も見る。論文の出版社は機械からのアクセスに403を返すことがあるので、DOIはCrossrefで確かめる）
- `?now=2026-10-07T19:05:00+09:00` で日本時間の時計を固定できます。取得先は同じAPIのままです
