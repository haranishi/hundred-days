# 「今年の受賞の解説」紹介動画

縦型1080×1920・34.5秒・BGM付きの紹介動画（`promo.mp4`）と、一覧のカードに出す無音のデモ（`../../demo.mp4`・540×960・19.4秒）を作る。アプリを実際に操作して録画し、合成した画は足さない。

```sh
node day-060-prize-explained/tools/promo/render-promo.mjs          # promo.mp4 と promo-first-frame.png
node day-060-prize-explained/tools/promo/render-promo.mjs --demo   # ../../demo.mp4
```

絵コンテと字幕は `timeline.mjs`、音は `promo-audio.mjs`（Day 042 の生成器を中身を変えずに複製。F メジャー・92BPM。`--variant b` でB案）、画は `render-promo.mjs`。秒数は `timeline.mjs` の1か所に集めてあり、画も音も、そこから読む。

## 流れ

先頭の化学賞のカード（何をした人か）→ 確かめられた事実と、これからの期待は別の欄 → 発見から受賞まで40年と31年 → 出典の番号を押すと、出典の一覧へ（押した番号の出典に枠）→ 医学賞・物理学賞も同じ形（医学賞の「解説を読む」を開く）→ 年齢を入れる（26歳は、まだ0人）→ エンド。
音のいちばんの山は、出典の番号を押して一覧へ着く瞬間（`T_CONFIRM_TAP`）。

## 固定資料で撮る

今年の分は `tests/fixtures/*-2026-1007-chemistry.json`（2026-10-07 の化学賞の発表後の実応答。医学賞・物理学賞・化学賞が入っている）を `page.route` で返し、時計は `?now=2026-10-07T21:00:00+09:00` に固定する。発表が進むと本物の画面は変わり、同じ画は二度と撮れないため。映る文字は本物と同じ。
`api.nobelprize.org` 以外の宛先は断つ。実行後のログに「断った宛先: なし」と出れば、外を読みにいっていない。
**`data/commentary.json` を変えると画面が変わり、下の照合が止める。** そのときは字幕を画面に合わせて直す（逆はしない）。

## 字幕の数字・固有名詞は、画面と突き合わせてある

`render-promo.mjs` が、書き出す前に画面の文字と字幕を照合し、違っていたら止まる。

| 字幕 | 照合する画面 |
|---|---|
| 10月7日発表の化学賞も | 見出し「今日の受賞」・カードの「化学賞」・発表日「10月7日」 |
| 確かめられた事実と、これからの期待は別の欄 | 「何が変わったか」の箱・「まだ実現していません」の札 |
| 40年と31年 | 年表の「40年」「31年」 |
| 押すと、出典の一覧へ | 押した番号の出典が画面に入る・出典に「論文」 |
| 医学賞・物理学賞も、同じ形で読めます | 医学賞の「解説を読む」・開いた解説のひとこと「光に反応するたんぱく質」 |
| 26歳で受賞した人は、まだ0人 | 答えの読み上げ「26歳で受賞した人は、まだいません」 |

## 切り出しは録画から決める

録画が始まる時刻は実時間では測れない（Day 044 で0.3〜1.7秒ずれた）。録画から字幕の入れ替わりを読み、絵コンテの切れ目と最も多く重なる位置で頭を切る。書き出したあとにもう一度読み、予定と0.4秒以上ずれていたら失敗させる。今回の実測は、8か所とも予定どおり（±0.1秒）。

## 字幕と画に書いてはいけないこと

- **提供元の名前を、題名・エンド画面の大きな文字・字幕に入れない**（API規約の商標の項）。エンド画面には出典と、ノーベル財団・Nobel Prize Outreach と関係がないことを小さく出す
- **評価の言葉を書かない**（「天才」「偉大」など）。人をおとしめる使い方を、規約が禁じている
- **「やさしい」と書かない。** 化学賞の文は、専門用語が並んで、まだ読みにくい

## 音

録音もサンプルも使わず、コードで合成した音だけ。実測（`ffmpeg -af ebur128=peak=true`）：A案 −16.8 LUFS・真のピーク −3.4 dBTP、B案 −17.1 LUFS・−3.1 dBTP。B案は、動画の絵はそのままで音だけ差し替える（`ffmpeg -i promo.mp4 -i promo-audio-b.wav -map 0:v -map 1:a -c:v copy -c:a aac -shortest promo-b.mp4`）。
