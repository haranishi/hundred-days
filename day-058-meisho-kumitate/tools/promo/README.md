# Day58 の宣伝動画

縦1080×1920・約25秒。実際のゲームを録画し、字幕と効果音を足して、音量を −17 LUFS にそろえる。
録画と書き出し物（`cache/`・`out/`）は Git に入れない。完成品は Drive の `100日チャレンジ/Day058_名所くみたて早押し/` に置く。

```sh
npm run build                                              # リポジトリ直下。dist/ を作る
node day-058-meisho-kumitate/tools/promo/record-game.mjs   # 画面のあるブラウザで録画する（約1分）
node day-058-meisho-kumitate/tools/promo/render-promo.mjs  # 字幕・締めのカード・音声を合成して書き出す
```

## 流れと決めごと

- 場面は「タイトル → 金閣寺が白→色と組み上がる → 早押し → 4択 → 正解と答えあわせ → 富士山 → ふたりでのピラミッド（1Pが外して−200、2Pが取り返す） → 締めのカード」。台本は `timeline.mjs`。
- 字幕と効果音は、録画中に記録したゲームの出来事の時刻（`cache/events.json`）に合わせて置く。
- BGM と効果音は、ゲームの中の合成（`source/src/client/audio/`）と同じ旋律・同じ作りを `promo-audio.mjs` で計算する。音源ファイルは使わない。
- 字幕の書体は Zen Kaku Gothic New（SIL OFL 1.1）。置き場所は環境変数 `PROMO_FONT` で変えられる。

## 落とし穴

- 進み具合は `__MMB__.state()` の値だと出来事のときにしか変わらない。押せる時間の経過から、その場で計算する（`record-game.mjs` の `__liveProgress`）。
- 録画用の窓が裏に回ると、ページの監視が間引かれてゲームに追いつかない。監視は一定間隔にし、裏でも間引かない起動の設定を付けている。
- 問題の順番とガイドさんが押す時機は、乱数の種と描画の設定で変わる。`probe-seeds.mjs`（軽い描画）の結果は目安で、本番の描画で撮った記録で確かめる。
- 宣伝の主役にしない名所（許可や配慮を求める方針がある）が出た回は、`record-game.mjs` が止まる。種を変えて撮り直す。
