# Day058 — 名所くみたて早押し

組み上がっていく名所のミニチュアを見て、どこかを早押しの4択で当てるゲーム。
日本32・世界36の68名所を収録している。

[公開ページ](https://hundred-days.pages.dev/day-058-meisho-kumitate/)

WebGLに対応したブラウザで動く。無料・登録不要。PCでもスマホでも遊べる。

## 遊び方

- 1ゲーム8問。白い模型が組み上がり、色が付き、最後に周りの景色が出る。手がかりは後になるほど増える。
- わかった時点で押して4択に答える。正解は早いほど高得点（1000点から200点まで）。まちがいと時間切れは−200点で、その問題はもう押せない。
- ひとりで：見習い・ベテラン・伝説の3段階のガイドさんと対戦する。出題は日本／世界／ぜんぶから選ぶ。
- ふたりで：1台の画面を2人で囲んで早押しする。画面の左右のボタンか、キーボードのF（1P）とJ（2P）。

## 100日チャレンジ版で変えたこと

元は、100日チャレンジとは別に作っていた試作。Day58として公開するにあたり、次を変えた。

- **ネット対戦を外した**：元の試作には、あいことばの部屋と自動の相手探しがある。どちらも部屋ごとのサーバーが要る。このサイトにはサーバーを置かない方針なので、ひとりで・ふたりでの2つだけにした。
- **タイトルに一覧へ戻るリンクと「共有する」を足した**：共有の欄はサイト共通の部品（`shared/share.js`）。X・LINE・端末の共有シート・リンクのコピーに対応する。
- **結果画面のシェアの名前を変えた**：ゲーム側の結果シェアも `share` という名前で、共通の共有欄と見た目を取り合っていた。ゲーム側を `result-share` にした。

## データと通信

外部への通信はない。外へ出るのは、押したときに開く豆知識の出典ページと、共有ボタンの投稿画面だけ。
効果音・BGMのオンとオフ、選んだ設定、最近出た名所は、このブラウザの localStorage にだけ保存する。

## 権利と出典

- 模型はすべてコードで組んだ簡略形状。写真・ロゴ・看板の文字は使っていない。
- 運営者・管理機関が、外観（形・シルエット・CGを含む）や似姿、名前の利用に許可を求めている名所は入れていない。東京スカイツリー、東京タワー、通天閣、ウルルなどがそれに当たる。題材として重い名所（原爆ドーム）も入れていない。
- エッフェル塔は昼の姿だけを作り、公式の照明演出は再現していない。
- 宣伝の画像や動画では、許可や配慮を求める方針のある名所（マチュピチュ、平安神宮など）を主役にしない。
- 名前は、2023年のハッカソン作品「ミニチュア観光名所バトルAR」と取り違えないよう、公開前に「名所くみたて早押し」へ変えた。
- three.js（MIT）、world-atlas（ISC。元データはパブリックドメインのNatural Earth）を使っている。許諾の全文と、豆知識の出典の一覧は、ゲーム内の「クレジット」にある。

## ソースと配信

`source/` が TypeScript のソース、直下の `index.html` と `assets/` がそのビルド結果。
公開するのはビルド結果だけで、`source/` はサイトの配信から外している（`scripts/build.mjs`）。

```sh
cd day-058-meisho-kumitate/source
npm ci
npm test          # ルール・模型・ガイドさんの単体テスト
npm run release   # 型検査とビルドをして、index.html と assets/ を1つ上へ写す
npm run e2e       # ひとりで・ふたりでの画面の試験（手元で実行）
```

CI（`.github/workflows/day058-game.yml`）は、ソースから作り直したビルド結果が、リポジトリに入っているものと一致するかを確かめる。
