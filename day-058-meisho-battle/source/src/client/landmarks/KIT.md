# 模型の作り方（KIT）

名所1つ＝1ファイル（例 `eiffel-tower.ts`）に `export function build(kit: Kit)` を書き、`index.ts` の `LANDMARK_BUILDERS` に id で足す。id は `src/shared/landmarks.ts` と同じ綴り（テストが照合する）。見本は `tokyo-tower.ts`・`kinkakuji.ts`・`pyramids-giza.ts`。

## 座標と大きさ

- 台座は半径5の円盤。原点は台座の上面の中心、y が上。**+Z が正面**（既定のカメラ側）、+X が右
- 置いてよいのは中心から 4.93 以内、高さ 6 程度まで。人の背丈は 0.1 前後（実物より大きめ）
- `at` は**形の底の中心**。`rotY` は Y 軸まわりの回転（度）、`rot` は傾け、`scale` は拡大（負の値は使わない）
- `kit.at({ at, rotY, scale }, () => …)` で座標をずらした中に作れる（入れ子可）

## 段階の付け方（docs/04 と 03）

`kit.stage(n)` 以降の部品がその段階になる。出る時刻は段階の区間の中で、**下から上・中心から外**の順に自動で決まる。

| 段階 | 出る p | 中身 | 見た人の感じ方 |
|---|---|---|---|
| 1 | 0.05–0.40 | 地面の起伏・水面・大きな塊 | 塔かな、城かな |
| 2 | 0.40–0.62 | 形の特徴（屋根の重なり・格子・アーチ） | 2〜3候補に迷う |
| 3 | 0.62–0.72 | 決め手の細部（展望台・鳳凰・スフィンクスなど） | 知っている人なら当たる |
| 色塗り | 0.72–0.80 | 段階1〜3と地面が下から上へ本当の色になる | 多くの人が当たる |
| 4 | 0.80–1.00 | 周りの景色・人・木・車・船・動物（最初から色つき） | ほぼ全員が当たる |

- 見本のこつ：大きな形は**高さで分けて**段階1・2・3に割る（ピラミッドは下45%・次35%・てっぺん、東京タワーは帯ごと）。白いうちは似た名所（docs/04 の組）と迷う形にとどめ、決め手は段階3と色に回す
- `kit.order(n)` で同じ段階の中の順番の組を変えられる（小さい組が先）
- `kit.part(() => { … })` の中で作った形は**1つの部品**として一緒に落ち、着地の知らせも1回。細かい形はまとめて部品数を節約する
- 出方は既定が上から落ちる `drop`。丘・水面・木は地面から伸びる `grow`（`kit.appear()` や各道具の `appear` で変更可）

## 道具

| 道具 | 主な指定 |
|---|---|
| `box` / `cylinder` / `cone` / `sphere` | `w h d` / `r h rTop seg` / `r h` / `r squash` |
| `frustum` / `pyramid` | 四角すい台 `w d h topW topD` / 四角すい `w d h` |
| `lathe` | 回転体 `points: [半径, 高さ][]`。半径0で始めて半径0で終える（影のため） |
| `extrude` | 上から見た輪郭 `points: [x, z][]` を高さ `h` 持ち上げた柱（星形の堀・池の縁など） |
| `torus` | 輪 `r tube arc flat`。既定は正面向きに立つ |
| `beam` | 2点 `from to` を結ぶ角材。`width` で平たい板 |
| `gableRoof` / `hipRoof` | 切妻・寄棟（棟は X 方向、`overhang` は軒の出） |
| `curvedRoof` | 反り屋根。`style`: `irimoya`（入母屋）・`yosemune`・`hogyo`（方形）・`skirt`（下の階の屋根。`top` に上の壁の大きさ） |
| `arch` / `lattice` / `stairs` | アーチ `w h d thick` / 格子の塔の一節 `w0 w1 h bays post member faces` / 階段 |
| `water` / `mound` | 水面 `r` か `points` / 丘 `r h rx rz` |
| `tree` | `kind`: `round`・`cone`・`pine`（松）・`sakura`・`palm`、`h` |
| `person` `car` `boat` `deer` `camel` | `at rotY`。色は省略すると種から選ぶ。`boat` は `row`/`ship`、`camel` は `rider` |
| `ring` / `scatter` | 円周に並べる / 輪の中にばらまく（`gap` 以上離し、`ok(x, z)` で避ける） |
| `groundAt(x, z)` | それまでに作った丘の上の高さ。斜面に木や人を置くとき `-0.03` ほど埋める |

## 色の決め方

- 色は部品ごとに**本当の色**（`#RRGGBB`）を渡す。白い段階では無視され、色塗りで出る。まず `COLORS` から選び、名所どうしで調子をそろえる
- `finish`: `matte`（既定）・`satin`・`gloss`・`metal`・`gold`・`water`。白いうちはどれもつや消しの粘土
- 地面の色は `kit.ground(色)`。**水・砂・雪の色は強い手がかり**なので、地面と水面は段階1で白く出し、色塗りで初めて見せる
- 空・日差し・霧・机の色は描画側（`render/palette.ts`）が1か所で持つ。模型で光や空を作らない

## 置き方の規則（docs/04）

- 木は水辺と道に沿って、人は入口と広場に、車は道路の上に、船は水面の上（水面の高さ 0.03〜0.04）に置く
- 文字・ロゴ・看板・提灯の文字は作らない。公式の照明演出やキャラクターも作らない（名所の権利の確認による。要点は ../../../../README.md の「権利と出典」）
- 乱数は `kit.rand / range / int / pick / chance / scatter` だけを使う（名所 id から作った種）。`Math.random` は使わない

## 上限と決まり（`tests/unit/assembly-landmarks.test.ts` が確かめる）

- 1か所あたり部品 350 個・三角形 6万枚まで。円柱は 8〜16 分割で十分
- 台座からはみ出さない、段階1〜4をどれも使う、同じ id なら毎回同じ形
- 形は閉じた立体にする（裏側から影を描くため、開いた面は影を落とさない）

## 先に作った人が踏んだ落とし穴

- 段階の中では下から順に出るので、高い所にある決め手（塔の上半分・上の歩道橋）は段階の最後に落ちてくる。先に出したいときは `kit.order(-1)` を付ける
- 高さで帯に分けた回転体（山など）は、角に点を2つ置かないと継ぎ目に暗い輪が出る。上の帯を下の帯よりわずかに外へ出して継ぎ目をおおう
- `mound` を `rotY` で回すと、`groundAt` が返す高さとずれる。回した丘の上に物を置くときは高さを確かめる
- 鳥居・五重塔・岸と川など、2か所以上で使う形はまだ道具に無く、各ファイルの中にある（厳島神社と伏見稲荷・清水寺と富士山・ビッグ・ベンとタワーブリッジ）。3か所目で使うときに道具へ移す

## 確かめ方

`npm run shots -- --id <id>` で p=0.30/0.55/0.70/0.85/1.00 の5枚が `shots/<id>_p055.png` などに出る。全部を目で見て「白いうちはあいまい・色塗りで決め手・完成形はひと目で当たる」かを確かめる。宙に浮いた部品は落下中なので正常。

## 短い例

```ts
import { COLORS, type Kit } from './kit'

export function build(kit: Kit): void {
  kit.ground(COLORS.lawn)
  kit.stage(1) // 大きな塊と地面
  kit.water({ r: 1.2, at: [2, 0, 2] })
  kit.box({ w: 2, h: 1.2, d: 1.4, color: COLORS.white })
  kit.stage(2) // 形の特徴
  kit.curvedRoof({ w: 2, d: 1.4, h: 0.6, at: [0, 1.2, 0], style: 'irimoya' })
  kit.stage(3) // 決め手の細部
  kit.cylinder({ r: 0.05, h: 0.3, at: [0, 1.8, 0], color: COLORS.gold, finish: 'gold' })
  kit.stage(4) // 周りの景色
  kit.tree({ kind: 'pine', h: 0.6, at: [1.2, 0, 2.2] })
  kit.person({ at: [0, 0, 1.2] })
}
```
