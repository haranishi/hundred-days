# Day 046「泣ぐ子は、いねがぁ」要件定義

大晦日の夜、なまはげが山を下りて里の家々を回る横スクロールアクション。全20面。
設計の根拠は Obsidian「2026-09-22 Day046 ユーザーストーリーとUX5階層」。ここは実装の契約だけを書く。

## 動かない前提

- 素のES Module・依存ゼロ・Canvas 2D。**外部通信ゼロ**（fetchもCDNも使わない）。
- 描画は内部解像度 **320×192**（16pxタイル＝20×12マス）を**整数倍**で拡大する。`imageSmoothingEnabled = false`。
- 更新は**固定1/120秒**の積み上げ。同じ入力列からは必ず同じ結果になる（テストとデモ撮影がこれに依存する）。
- 乱数を使わない。敵と床の動きはすべて位置と時間の関数。
- 操作は**移動とジャンプだけ**。攻撃ボタンを作らない。

## 面データの形式

1面 = `{ name, world, sky, wind, rows }`。`rows` は同じ長さの文字列の配列（高さ12・幅は面ごと）。

| 字 | 意味 | 当たり |
|---|---|---|
| `.` | 空 | なし |
| `#` | 雪の地面 | 四方から乗れる |
| `=` | 細い足場 | **下から通り抜け**、上からだけ乗れる |
| `~` | 氷 | 乗れる。摩擦が1/4 |
| `^` | つらら | 触れると被弾。真下にプレイヤーが入ると0.4秒後に落ちる |
| `o` | 餅 | 取ると1段階進化。最大段階なら得点 |
| `*` | 米俵 | 取ると得点。20個で残機+1 |
| `C` | カラス | 左右に3マス往復して飛ぶ。踏める |
| `D` | 野犬 | 床の上を左右に歩き、端で折り返す。踏める |
| `R` | 雪うさぎ | 床の上で待ち、予告のあと跳ぶ。踏める |
| `B` | 雪かきイノシシ | 近づくと構え、予告のあと突進する。踏める |
| `F` | 風呂敷 | 取ると12秒、押し続けている間の下降が遅くなる |
| `S` | 駆け鈴 | 取ると8秒、最高速150・加速1000で走れる |
| `J` | 雪台 | 上から乗ると跳ね上がる。当たりはタイル上端16×8 |
| `%` | 崩れる枝 | 乗って0.4秒で消え、2秒後に戻る。当たりは上端16×4 |
| `M` | 動く床 | 2マス幅。左右または上下に4マス往復 |
| `P` | 開始位置 | プレイヤーはここに立つ（面に1つ） |
| `G` | 家の戸口 | 触れたら面クリア（面に1つ） |

1面 = `{ id, name, world, sky, wind, parTicks, secretMochi, entityOptions, routes, rows }`。
`parTicks` は早駆けの上限（tick）。**`safe` の自動操作が戸口へ着いた tick を1.25倍し、120の倍数へ切り上げた値**とし、
面ごとに旧値・新値・根拠のコメントを `lib/level-data.js` に残す。`secretMochi` は任意ルートの餅がある `rows` 上の `{col,row}`、
`entityOptions` は `"col,row"` ごとの `{axis, phaseTicks}`（`M` の軸はここで決める）、
`routes` は検証用の矩形（px）で、物理には使わない。

`sky` は背景色の番号（1=夜の山 / 2=杉林 / 3=吹雪 / 4=里）、`wind` は横風の加速度（px/s²・0で無風）。

## プレイヤー

| 段階 | 見た目の高さ | 当たり判定 | できること |
|---|---|---|---|
| ちび | 14px | 10×14 | 基本のジャンプ。被弾したらミス |
| なまはげ | 20px | 12×20 | ジャンプが高い（-330）。被弾で「ちび」へ |
| 荒鬼 | 24px | 12×24 | **二段ジャンプ**。被弾で「なまはげ」へ |

数値（px・秒）: 重力 900 / 歩きの加速 700 / 最高速 110 / 地上の摩擦 900 / 空中の摩擦 120 /
落下の上限 420 / ジャンプ初速 -300（なまはげ以上は -330）/ **離したら -120 で打ち切る**（長押しで高く跳ぶ）/
床を離れてからジャンプを受け付ける猶予 0.08 / 着地前の先行入力 0.10 / 踏んだ反動 -220 / 被弾後の無敵 1.2。

3マスの穴48pxを体幅込みで越える約60pxの飛距離を確保するため、最高速とジャンプ初速を引き上げた。

ミスは**落下**と**ちびでの被弾**の2つだけ。ミスしたら0.8秒おいて同じ面の頭から。残機は3から始め、0でゲームオーバー（面えらびへ戻る）。

## 能力（スロットは1つ）

`F` 風呂敷（1440tick）と `S` 駆け鈴（960tick）。異種を取ると即置換、同種は残り時間を規定値へ戻す。
被弾・ミス・R・面移動で失う。餅の3段階とは独立で、能力を取っても段階は上がらない。
**各面の主路はちび・能力なし・二段跳びなしで通れる**。能力が要るのは米俵・近道・余裕のある着地だけで、
能力がないと必ず落ちる強制ゲートは作らない。能力ルートの下には必ず受け床を置く。

### 上段（米俵3個＋任意餅）へ入る手段

各面につき**1つだけ**を、雪台 `J`／崩れる枝 `%`／風呂敷の滑空／駆け鈴の助走／踏んだ反動 から選び、
**面の頭の1行説明にその手段を書く**。棚の真下は必ず雪床にして、失敗しても主路へ落ちるだけにする（＝戻る道）。
面ごとの割り当ては `lib/level-data.js` のコメントに書く。

## 得点と3つのお札

米俵50・餅100・任意餅+200・クリア500・無傷300・福集め300・早駆け `10*floor(max(0,par-経過)/120)`。
敵は C/D/R=100・B=150。着地せず続けて踏むと ×1 → ×2 → ×3（着地・被弾・ミスで1へ戻る）。

| お札 | 条件 |
|---|---|
| 早駆け | `elapsedTicks <= parTicks` |
| 福集め | 同じ挑戦の中で米俵6/6と任意餅1/1 |
| 無傷 | 面の開始から被弾0・ミス0 |

ミスすると面内の敵・収集物を復元し、**その面で得た点・米俵・残機を面の入口の値に戻す**（回収→落下の無限稼ぎを防ぐ）。
`runHits` `runMisses` `elapsedTicks` は維持する。

## 20面の並び

4ワールド×5面。**1面につき新しく覚えることは1つまで**。各面に米俵6個（主路3・任意路3）・餅2個（うち任意餅1）。
幅は40〜64マスで、面の番号が進むほど長い。早駆けの目標は自動操作の実測から決めるので8〜17秒になる。

- ワールド1 山（sky1・無風）: 1-1 `R`を踏む / 1-2 `J`雪台 / 1-3 `F`滑空 / 1-4 二マスの穴 / 1-5 連続踏み
- ワールド2 杉林（sky2・無風）: 2-1 `%`崩れる枝 / 2-2 枝を2枚続けて / 2-3 `C`の高さ / 2-4 `M`縦の動く床 / 2-5 枝＋滑空
- ワールド3 吹雪（sky3・風120）: 3-1 横風の着地 / 3-2 `S`駆け鈴 / 3-3 `B`を誘う / 3-4 `~`氷で止まる / 3-5 氷から雪床へ

初登場は1面に1つだけなので、**床の穴は 1-4 まで出さず**（1-1〜1-3の床は穴なし）、**氷は 3-4 まで出さない**（3-3の床は全面が雪）。
そのぶん**荒鬼の二段跳びはどの面でも必須にしない**（1-4 の上段は既習の雪台で取れるようにする）。
- ワールド4 里（sky4・無風）: 4-1 屋根と下道 / 4-2 野犬の群れ / 4-3 能力の持ち替え / 4-4 `^`つららを誘う / 4-5 最後の戸口

**4-5の最後の16列は敵・穴・つららを置かない**安全な雪床にして、結果画面に専用の締め文と訪問数・お札合計を出す。

各ワールドの1面目は**クリアで次のワールドを解放**しない。**5面クリアで次のワールドが開く**。

### 地形の寸法（全面共通）

主路の穴は最大2マス（32px）・段差は最大2マス・静止して着地する場所は3マス（48px）以上。
1画面（20マス）の敵は3体まで。新しい要素の初登場は、その前後64pxに穴・つららを置かない。
**高い足場の右端から6マス以内の地面に穴を置かない**（端では必ず一度跳ぶので、着地点がそこまで伸びる）。

## 画面

タイトル → 面えらび → プレイ → クリア の4つ。面えらびは解放済みだけ押せて、**各面のお札0〜3枚とベスト時間**を出す。
プレイ中のHUDは**上端1行だけ**（面番号・姿・残機・米俵 n/6・能力と残秒・経過時間・お札3枠）。
能力の残りが2秒を切ったらHUDの枠と足元のアイコンが点滅する。得点は加算のたびに対象の上へ60tickだけ浮かせ、HUDには常設しない。
**面の頭に「新しく覚えること」と「上段へ入る手段」を1行だけ3秒**出す（空のある画面上端に重ね、地面を隠さない）。
1-1 だけは2行を使い、**踏みの説明は最初のうさぎが画面にいるうちに**出す（1.2秒〜4.2秒）。
クリアは面の上に重ねて、面内得点・通算・ベスト更新・3条件の実数を出し、「次へ」「もう一度」「面えらび」の3つを置く。
**戸口に着いた刻みで得点の浮き文字を全部消す**（クリア加点の総額が結果の面内得点と並んで見えるのを防ぐ）。
**ミスのときはボタンを出さない**（自動でやり直す）。4-5だけは締め文を見せるため1.5秒おいてからボタンを押せるようにする。

## 保存（端末内のみ）

`localStorage` に `namahage.v1` の1件だけ。中身は
`{ unlockedWorld, rulesVersion: 2, recordsV2: {"1-1": {bestTicks, bestScore, seals}}, muted }`。
`seals` は 早駆け1・福集め2・無傷4 のビット和（0〜7）。旧 `bestMs` は面を作り直したのでベスト表示には使わず、消さずに残すだけ。
プレイ中の状態は保存しない。保存が読めない・壊れている場合は初期値で動く。非整数・負値・未知IDは捨てる。

## 入力

- キーボード: `←/→` `A/D` 移動、`Space` `↑` `W` `Z` ジャンプ、`R` やり直し、`Esc` 面えらびへ。
- タッチ: 画面**下端**に左・右・ジャンプの3つ。キャラの立つ高さに重ねない。押している間だけ効く。
- ゲームパッドは扱わない。

## 音（Web Audio の合成・音源ファイルなし）

跳ぶ／踏む／餅／被弾／戸口 の5つと、BGM 1ループ。**最初の入力があるまで鳴らさない**。ミュートの切り替えを持ち、設定は保存する。

## 絵

主人公と敵はドット絵のデータ（パレット番号の2次元配列）として `lib/sprites/` に持つ。**PNGを読み込まない**。
動きはドットの組み替えで作る（歩き2コマ・跳び1コマ・被弾1コマ）。パレットは全体で16色以内。

## テスト

`tests/` に単体テスト、`../tests/e2e/day-046.spec.mjs` にE2E。`tests/index.mjs` に**必ず登録**する。

単体で必ず押さえる: 固定刻みの決定性（同じ入力列＝同じ座標）／`=` を下から通り抜けて上に乗れる／
氷の摩擦が地面の1/4／ジャンプを離すと打ち切られる／踏むと敵が消えて反動がつく／連続踏みは×3で頭打ち／
被弾で段階が1つ下がりちびなら残機が減る／能力の取得・置換・失効・被弾消失／雪台と崩れる枝のタイマー／
ミスを挟んだときの巻戻し／20面すべてが**開始位置と戸口を1つずつ持ち、行の長さがそろっている**／
20面すべてが**敵・つららを有効にしたまま到達可能**で、**新記号を消した地形でも到達可能**／
20面すべてで**報酬を狙う自動操作が米俵6個と任意餅を回収できる**／1-1は**右だけを押し続ける走りで最初のうさぎを踏める**／
戸口に着いたら浮き文字が0件になる／
描画がつららを実座標に出し、予告・退場・枝の揺れを座標のずらしで作る／保存の読み書きと壊れた値の無視。

E2Eで必ず押さえる: 読み込みでエラーが出ない／1-1をクリアできて3条件の実数が出る／面えらびの施錠とお札の表示／
4-5の締め文と1.5秒の待ち／タッチの3ボタンが出る／共有とOGPが出る。
