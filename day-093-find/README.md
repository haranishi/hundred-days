# Day 093「find — 気分で出会うファッション」

スワイプ操作で好みを学習し、自分好みの服をテンポよく探せるファッション探索 Web アプリです。会員登録やログインなしで、最初の質問と8枚のスワイプによる系統診断から、その後の無制限スワイプ・お気に入り保存・好みグラフの確認・外部販売ページ（楽天市場／Yahoo!ショッピング）への遷移までそのまま体験できます。

- 公開サイト: https://day93.rairakku.com/
- `rairakku.com` の中の住所: https://rairakku.com/day93/（`day93.rairakku.com` へ転送します）

## できること

- **6ステップの導入診断**：探したい服のジャンル・年代・予算感と、16パターンのスタイル写真から「好き」を選ぶだけで初期の好みを設定
- **直感スワイプ & アンドゥ**：右（好き）／左（ちがう）のカードスワイプと1手戻し、詳細シート表示に対応
- **お気に入り & 好み分析**：右スワイプした服はお気に入り一覧へ即時反映され、設定タブで系統別の好みバランスと累計スワイプ数を確認可能
- **外部ストア連携**：各アイテム詳細やお気に入りカードから外部ショップの商品ページへ遷移（PR・アフィリエイト広告を含みます）

登録なしで利用でき、好みやお気に入りはブラウザの端末識別子（`localStorage` 等）に紐づけて保持します。API サーバーは検索結果への直接露出を抑止（`noindex`）しています。

## このDayの記録

このDayの成果物はWebアプリです。コードは公開していません。ここにあるのは、一覧に載せるための記録（meta.json・スクリーンショット）です。

もとになったのは、ログイン登録制として開発していたファッションスワイプアプリです。Day93 では、未公開だった写真ベースの初期導入フロー（Onboarding v4）と視覚嗜好ベクトルの仕組みを統合し、誰でもログイン不要で試せる公開版として仕上げました。
