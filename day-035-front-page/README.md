# Day 035「きょうの一面」

記事のリンクを貼ると、その見出しとリード文が縦書きの新聞の一面に組み上がる。3本まで足せる。できた紙面はPNGで保存できる。写真は画面には出るが、保存する画像には入らない（理由は下）。

https://hundred-days.pages.dev/day-035-front-page/

## 何を取ってくるのか

貼られたページから読み取るのは **OGPと標準のメタだけ**（`og:title` `og:description` `og:image` `og:site_name` `article:published_time`、無ければ `<title>`）。**記事の本文は取得しない。** 他人の記事をまるごと複製しないための線引きで、だから「読める新聞」ではなく「見出しが立つ一面」になる。

取得はユーザーが貼ったURL1本につき1回だけ。巡回はしない。SNSのリンク展開（unfurl）と同じ範囲にとどめている。

紙面には媒体名とホスト名を必ず刻む。題字「一面新聞」は**架空**で、実在の新聞社とは関係がない。

### 写真は、読み取るのはURLだけ

`og:image` から取るのは**画像のURLだけ**で、画像そのものはこちらでは取得も保存もしない。

- **画面**：提供元から `<img>` で直接読んで、紙面の上に重ねて見せる（読み込むのは閲覧者のブラウザ。こちらのサーバーは通らない）
- **保存するPNG**：写真を入れない。見出し・リード・媒体名・出所だけで組み直す

報道写真は、見出しと違って明確に各媒体の著作物である。中継サーバーで取りに行けばそれは複製になり、エッジにキャッシュして公開URLから配れる状態にすれば公衆送信に当たり得る。PNGに焼けば、その複製が利用者の手で際限なく配られる。**「見出しが立つ一面」を作るのに、写真の複製は要らない**ので、複製が起きる経路（中継・キャッシュ・PNGへの焼き込み）を全部やめた。以前あった画像の中継 `functions/api/day-035/image.js` は削除してある。

写真が抜けたぶん紙面が白く残らないよう、保存するPNGは**写真なしのレイアウトで組み直す**（下の「紙面の組み方」）。画面には「保存する画像に写真は入りません」と出す。

## なぜ中継が要るのか

ブラウザから他オリジンのHTMLは読めない（CORS）ので、`functions/api/day-035/page.js` が代わりに `<meta>` だけを取りに行く。中継はこの1本だけ。

中継は数値のホスト（`127.0.0.1`・`2130706433`・`[::1]`）や `localhost`・`*.local` を拒み、リダイレクトは自分で追って**飛び先も毎回同じ検証にかける**。HTMLは先頭256KBで打ち切る。

## 縦書きで手がかかるところ

`lib/vertical.js` が引き受けている。

- 倒して描く文字（長音・括弧・ラテン文字）と、マスの右上へ寄る文字（句読点・小書き）
- 数字は桁数で扱いを変える。1桁は正立、2桁は縦中横、3〜4桁は小さくして1マスへ
- 行頭に句読点を置かない禁則（来たら前の行から追い出す）
- 送りは文字ごとに変える。ラテン文字を全角と同じ1マスで送ると「100 DAYS」が間延びする

## 紙面の組み方

紙面は**写真の枠を空ける版（画面）**と**空けない版（保存するPNG）**の2通りを、同じ `renderPaper` で刷り分ける（`photos: true | false`）。canvas は写真に触れないので汚れず、`toBlob` も落ちない。

- 記事1本・枠あり：上の帯に見出しと本文、下の帯が写真（`lib/layout.js` の `SOLO`）
- 記事1本・枠なし：本文の帯を紙面の下端まで伸ばし、字をひとまわり大きく（上限46→64px）組む
- 2〜3本・枠あり：右から左へブロックを並べ、右の記事ほど大きい。写真の枠は一番手のブロックの左下に接地
- 2〜3本・枠なし：一番手の本文が写真の場所まで流れ、字の上限も40→48pxに上がる
- 見出しと本文の大きさは字数から決める（`fitHeadline` / `fitSize`）。固定にすると、短いリードの日に紙面が白く残る
- それでも余るときは、字を大きくするのではなく**列の間を広げて**左端まで散らす（`spreadGap`）。大きさで埋めようとすると、リードが見出しより大きくなって新聞に見えなくなる

枠を空けないときは、写真の上に出していた「全文は ○○ で読めます／公開日」を**本文の末尾に入れる**。出所が欄外だけにならないようにするため。

画面に重ねる写真は、CSSでグレースケールにして45度の点の格子を掛け、刷り上がりに寄せている（`app.css` の `.photo`）。canvas で網点にしていた `lib/halftone.js` は、写真を紙面に描かなくなったので削除した。

## 制約

- 保存する画像は1080×1528。2倍で書き出し、`toBlob` が null を返したら等倍で刷り直す（iOS Safari の canvas 面積上限）
- **保存する画像に写真は入らない**。画面と保存物で紙面の組み方が変わるので、保存する前に画面へその旨を出す
- 写真は提供元の任意のホストから読む＝この Day の CSP は `img-src` に `https:` が要る（`scripts/build.mjs` の `IMG_BY_APP`）。`connect-src` は中継が同一オリジンなので `'self'` のまま
- 明朝体は端末にあるものを使う（埋め込みフォントは持たない）。明朝が無い端末ではゴシックで組まれる
- 貼ったURLと読み取った結果は端末の localStorage に置く。こちらのサーバーが外へ出るのは、メタの取得1回だけ（写真は閲覧者のブラウザが提供元から直接読む＝閲覧者のIPが提供元へ届く）
