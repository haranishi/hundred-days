# Day 035「きょうの一面」要件定義

リンクを貼ると、そのページが新聞の一面になる。見出し・リード・媒体名を取ってきて、縦書き・段組の紙面に組み、PNGで保存できる。写真は画面にだけ出し、保存するPNGには入れない（下の「権利と規約」）。

## 背景と狙い

読んだ記事のリンクはブックマークやXの下書きに溜まるが、「きょう何を読んだか」は形にならない。URLをそのまま貼ると、どこも同じ横長のカードになる。ここでは同じ情報を**縦書きの紙面**に組み替える。情報量は増えないのに、置き場所が変わるだけで「読み物」に見える、という一点に賭ける。

## 権利と規約（2026-09-11 確認／2026-09-13 写真の扱いを改訂）

- **取得はユーザーが貼ったURL1本につき1回**。SNSのリンク展開（unfurl）と同じ範囲にとどめる。巡回はしない
- **取るのは OGP と標準メタだけ。本文は取らない**（`og:title` `og:description` `og:image` `og:site_name` `article:published_time` `<title>` `link[rel=canonical]`）。本文を取ると他人の記事の複製になる
- 中継の User-Agent で自分を名乗る（`hundred-days-day035 (+https://hundred-days.pages.dev/day-035-front-page/)`）
- **紙面に出所を必ず刻む**。各記事の末尾に媒体名、欄外にホスト名
- **題字は架空固定「一面新聞」**。実在紙を装わない。欄外に「個人が作った架空の紙面です」と入れる
- 実測（2026-09-11・ボットと名乗るUA）：NHK・朝日・ITmedia・note・Zenn の5サイトすべて 200 でOGPを返す。`og:image` も 200。本リポジトリ自身のアプリページも取れる

### 写真（2026-09-13 改訂）

**`og:image` は URL だけを読み、画像そのものは取得も保存もしない。**

- 画面：提供元から `<img>` で直接表示する（読みに行くのは閲覧者のブラウザ）
- 保存するPNG：**写真を焼き込まない**。写真なしのレイアウトで組み直す
- 画面に「保存する画像に写真は入りません」と出す。保存してから気づく形にしない

初版は `functions/api/day-035/image.js` が写真を中継し、エッジに24時間キャッシュし、PNGに網点で焼き込んでいた。報道写真は各媒体の著作物で、取得とキャッシュは複製、公開URLから配れる状態は公衆送信に当たり得る。見出しとリードのほうは、利用者が1本ずつ手で貼る非営利の使い方なので、ヨミウリ・オンライン見出し事件（知財高判 平成17年10月6日）が不法行為とした「営利の目的をもって、かつ反復継続して」という要件からは距離がある。**線は写真にある**と判断し、中継・キャッシュ・焼き込みの3つをやめた（`image.js` は削除）。

副作用として、CORSヘッダの無いサイト（実測4件中2件）の写真を canvas に描くと汚染されて `toBlob` が落ちる。**canvas が写真に一切触れない**設計にしたので、この問題は構造的に起きない。

## データ（中継）

ブラウザから他オリジンのHTMLは読めないので Cloudflare Functions を挟む。雛形は `functions/api/day-029/place.js`。**外部依存は「貼られたページの取得」1個**として数える（Day31-40の枠内）。

### `functions/api/day-035/page.js`（メタ取得）

- 入力 `?url=`。**http/https のみ**・2048字まで・NFKC正規化・制御文字を除去
- **SSRF対策**：ホストが `localhost` / `*.local` / 数値IP（IPv4・IPv6）/ 認証情報つきURL なら 400。リダイレクトは `redirect: 'manual'` で最大3回まで自分で追い、**毎回同じ検証を通す**
- タイムアウト15秒。本文は**先頭256KBだけ**読んで打ち切る
- 抽出は `HTMLRewriter`。文字コードは `content-type` の charset を見て、UTF-8以外は `TextDecoder` を試し、失敗したら `encoding_unsupported`
- 返す：`{ title, lead, image, site, publishedAt, canonical, host }`。取れなかった項目は `null`
- ステータス：不正URL 400 ／ 取得失敗 502 ／ タイムアウト 504 ／ 成功 200（`s-maxage=3600`）

### 画像の中継は持たない

写真はブラウザが提供元から直接読む。中継もキャッシュも置かない（初版の `functions/api/day-035/image.js` は削除済み）。

## ユーザーストーリー

| ユーザー | 欲しいことと理由 | 受け入れ条件 |
|---|---|---|
| 読んだ記事を勧めたい人（本命） | リンクを貼るより目を引く形にしたい | URLを貼って3秒で紙面が出て、PNGで保存できる |
| きょう読んだものをまとめたい人 | 3本を1枚に | 「記事を足す」で最大3本。2番手・3番手が自動で組まれる |
| 自分の作品を宣伝したい人 | 自分のページを一面トップに | 自分のURLでも同じように組める |
| 写真が無いページを貼る人 | 写真が無くても成立してほしい | 文字だけの紙面へ自動で切り替わる |
| 保存して人に渡す人 | 渡してよいものか知りたい | 保存する前に「画像に写真は入らない」と分かる。保存物は見出し・リード・媒体名・出所だけ |
| 出所を気にする人 | どこの記事か分かる形で渡したい | 記事末に媒体名、欄外にホスト名 |
| 縦書きの崩れが気になる人 | 読める組版 | 行頭に句読点が来ない。数字は縦中横。長音と括弧が倒れる |
| スマホしか持っていない人 | 指で完結 | 貼り付けボタン（クリップボード）と保存ボタン。44px以上 |

## UX5階層

- **戦略**: リンクプレビューの置き換えではなく**「紙面にする」体験**。成功＝貼ってから3秒で「新聞だ」と分かること。失敗＝OGPカードの焼き直しに見えること。差別化の源泉は縦書き・網点・漢数字の日付という**組版そのもの**
- **要件**: 載せる＝題字・号数・漢数字の日付・大見出し・リード・媒体名・2番手3番手・欄外の断り書き・PNG保存・シェア。写真は**画面だけ**（紙面の上に重ねる／保存するPNGには入れない）。対象外＝本文全文、AI要約・書き換え（Day61解禁）、レイアウトの手動編集、記事の並べ替え、フォント選択、複数ページ
- **構造**: `empty → loading → ready`＋`error`。記事は0〜3本の配列。**URLを貼った瞬間に組む**（「組む」ボタンを押させない）。2本目以降は紙面を組み直す。1本目が失敗したら `error`、2本目以降の失敗は紙面を保ったまま行内に出す
- **骨格**: 画面の上半分が紙面（原寸を縮小表示・縦長）、下に入力欄1本と「記事を足す」。紙面内で最大の要素は**大見出し**（Canvas上72px前後）。画面のボタンは塗り1つだけ（empty＝「一面にする」、ready＝「画像を保存」）。紙面は右から左へ読む縦書きで、一番手が右
- **表層**: 紙 `#f4efe4`（わら半紙）、インク `#1b1b1b`、罫線 `#2b2b2b`、見出しの下地なし。網点は45度・セル4px。画面UIは紙面の邪魔をしない灰（地 `#e9e6df`、文字 `#22201c`）。動きは紙面が下から差し込まれる1つだけ。`prefers-reduced-motion` では即時

### UX5階層を通したことで決まった実装（10件）

1. **「組む」ボタンを置かない**（構造）。貼った瞬間に組む。ボタンを1つ挟むと「フォームに入力する作業」になり、紙面が主役でなくなる
2. **`og:title` からサイト名の接尾辞を落とす**（骨格）。多くのサイトが「記事名｜媒体名」を返す。見出しに媒体名が入ると新聞に見えない。`｜ | - – —` で割り、`og:site_name` と一致する側を捨てる
3. **見出しは全角20字で切る**（骨格）。新聞の一面見出しは短い。超過は「…」
4. **リードは2文まで**（骨格）。`og:description` は3文以上あることが多く、縦書きで流すと紙面が文字で埋まる
5. **写真が無い紙面を別レイアウトで持つ**（要件）。`og:image` が無いページは実在するので、写真欄を空けずに見出しとリードで組み直す
6. **紙面の日付は「きょう」固定**（要件）。記事の公開日は記事末に小さく置く。紙面の日付が記事ごとに違うと新聞にならない
7. **記事は貼った順に一番手・二番手・三番手**（要件）。並べ替えUIを作らない＝1アクションを守る
8. **PNGは2倍解像度で書き出し、`toBlob` が null を返したら等倍で再試行**（非機能）。Day 027 で iOS Safari の canvas 面積上限に当たった前例がある
9. **題字は架空固定＋欄外に断り書き**（戦略・権利）。実在紙を装わないことを設計で担保する
10. **エラーを理由で分ける**（構造）。「取りに行けなかった」「ページは読めたが見出しが無い」を別の文言にする。写真が読めなかったときは文言を出さず、写真なしの紙面に組み直す（保存物は元から写真なので、利用者の手は止めない）

## 機能要件

### 画面と状態

- `empty`：説明1行＋URL入力＋貼り付けボタン＋「一面にする」。紙面の位置には空の紙（罫線だけ）を置く
- `loading`：紙面の位置に「刷っています…」。`aria-busy`
- `ready`：紙面＋「画像を保存」「記事を足す」（3本目まで）「作り直す」＋シェア
- `error`：理由の文言＋「もう一度」。入力値は保つ

### 紙面（Canvas・1080×1528・出力は2倍）

上から題字帯（右に題字「一面新聞」・左に「第三十五号」と漢数字の日付）、横罫、本体、欄外。本体は右から左へ。

- 1本：右端に大見出し（縦書き・最大3行）、その左にリードを段組で流し、下の帯が写真
- 2本：右2/3が一番手、左1/3が二番手（見出しは小さく・写真なし）
- 3本：右1/2・中1/4・左1/4
- 各記事の末尾に媒体名。欄外に「出典 ○○.jp ／ 個人が作った架空の紙面です」

**保存するPNGは「写真の枠を空けない版」**（`renderPaper(..., { photos: false })`）。同じ関数で刷り分ける。

- 本文の帯を紙面の下端まで伸ばし、字の上限を上げる（1本 46→64px／2〜3本の一番手 40→48px）
- それでも余る幅は、字を大きくするのではなく**列の間を広げて**左端まで散らす（`spreadGap`・上限は字の3.4倍）
- 写真の上に出していた「全文は ○○ で読めます／公開日」を本文の末尾に入れ、出所を紙面に残す

### 縦書きの組版（`lib/vertical.js`・純関数・DOMに触れない）

- 90度回転して描く：`ー 〜 （ ） 「 」 『 』 【 】 ： ；` とラテン文字の連続
- 右上へずらす：`、 。` と小書き（`ぁぃぅぇぉっゃゅょ`）
- 縦中横：半角数字が2桁までなら1マスに横並び。3桁以上は1字ずつ縦
- 行頭禁則：`、。」）』】ー` ／ 行末禁則：`「（『【`。はみ出しは追い出し
- 入力：文字列・1行の字数・字送り。出力：`[{ ch, x, y, rotate, scale }]`

### 画面に重ねる写真（`app.css` の `.photo`）

紙面が空けた枠の位置（紙面座標）をパーセントに直して `<img>` を重ねる。CSSでグレースケールにし、45度に傾けた点の格子を `mix-blend-mode: multiply` で掛けて刷り上がりに寄せる。**canvas では描かない**ので、初版の `lib/halftone.js`（網点の純関数）は削除した。

### その他

- 日付の漢数字（`lib/kanji.js`）：`2026 → 二〇二六`、`9 → 九月`、`11 → 十一日`、`35 → 第三十五号`
- 保存（`lib/store.js`）：貼ったURLと取得結果を localStorage に持ち、再訪で紙面を復元する。「作り直す」で消す
- シェア：`shared/share.js` を `</head>` 前に1行。`<meta name="share:text">` にアプリ名を残す

## 非機能・共通ルール

- 依存ゼロ（バニラJS・外部ライブラリなし）。CSPの `connect-src` は `'self'` だけで足りる（中継が同一オリジンのため）。**`img-src` には `https:` が要る**（写真を提供元から直接読むため。提供元のホストは事前に列挙できない）
- 貼られたURLと取得結果は**端末とCloudflareの中継の外に出さない**。ログに残さない
- ただし**写真は閲覧者のブラウザが提供元から直接読む**＝閲覧者のIPとブラウザ情報が提供元に届く。画面と `static/privacy.html` に書く
- 44px以上のタップ領域。文字対比4.5:1以上。キーボードだけで完結
- 390px幅で紙面が横スクロールしない（縮小表示）
