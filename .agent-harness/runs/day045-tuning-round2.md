# Day045 難易度調整・2周目

目的：プレイヤーの強化に敵側の3軸を連動させ、固定5 seedの中央値を90〜130秒・W8〜12・LV25〜30にする。
変更範囲：fleet/gameの敵弾数・間隔・弾速、単体テスト、決定的測定ツール、この記録。
強化表、ライフ3、無敵1.2秒、移動速度320、読まれ度、艦隊の移動・敵数・開始位置、各波の3秒猶予は変更していない。

## 測定方法

`node day-045-read-your-shots/tools/tune.mjs`（Node v24.12.0）。seedは1, 2, 3, 4, 5で全候補共通。
createGame("playing")から実際のstepを1/60秒で進める。最初は左へ移動し、x=24/456で往復方向を反転する。
配列順で最初の y>300 かつ |弾x−自機x|<60 の敵弾から150px離れる位置を優先。xが一致した場合だけ往復方向に逃げる。
ゲーム状態の改変やアイテム追尾はしない。読まれ度は遷移・無敵中も含む全フレームの時間平均。裏をかいた回数はbonusKills。
中央値は各列独立で算出。600秒で終了しない候補は打ち切りとして記録し、死亡扱いにはしない。最終ツールもその場合は中央値null・終了コード1を返す。
変更前の予備測定はseed 1が600秒でも終了せず停止したため、5 seed中央値は未測定。
