# Day086 おすすめの店名から地図まで（2026-11-05）

本人の再依頼: 最終結果に具体的なおすすめの店名とマップまでの案内を出したい。

## 再現と原因
- 選んだ料理で180/600m以内が0件だと、店名カードと地図案内が表示されず空状態で終わった。
- 渋谷付近の公開地点で焼き魚が0件になることを実APIで再現した。本人の現在地は使用していない。
- 1500mに店を返す回帰E2Eを先に追加し、旧実装では店名がhiddenのままで失敗することを確認した。

## 修正
- 希望180/600m→1500m→5000mと同じ料理で検索。有効な候補が出た時点で止める。
- それでも0件の場合だけ、選んだ親ジャンル内の4料理で探す。別案と表示し、選択回答は変更しない。
- 各段階の半径をクライアントでも検証。最大4回・合計12秒・1回10秒で打ち切る。
- 通信失敗を0件扱いせず、取消後に次の通信・遅い結果の描画をしない。
- 「あなたにおすすめのお店」と具体的な店名を表示し、同じカード内へ地図案内ボタンを移した。
- 希望圏外の候補では拡大の理由と実距離の目安を表示。メニュー未確認も明記する。
- スマホでは装飾を縮め、390×667で店名と地図ボタンが見えるようにした。
