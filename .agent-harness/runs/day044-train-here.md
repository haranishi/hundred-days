## 動作と機械検証

- 単体14件成功：方向、環状境界、終着駅、鮮度、欠測、不正応答、キー非露出。
- ChromiumのE2E12件成功：初回、デモ切替、駅入替、同じ駅、クリック・タッチ・ドラッグ、追跡、キーボード、再試行、期限切れ。
- 合成ライブ応答の期限切れで列車・選択詳細が消えた。実API応答を使った試験ではない。
- 390／768／1440pxで横はみ出しと主要駅ラベルの見切れを検査した。
- 実ブラウザで駅・列車・追跡・全体表示・デモ終了を操作し、各幅の画像を確認した。
- `npm run build` 成功。公開済み43件に影響せず、draftのDay044を除外した。
- `npm run precheck` は漏洩パターンなし。既存のメール・バイナリ警告494件は今回の変更外。

2. 地図のポインター捕捉をドラッグ開始時に変更し、列車タップを修正。
   独立コードレビューでも同じ不具合を再現。クリック・タッチ・ドラッグの回帰テストが成功。

4. スマホでは一覧から選んだ列車の地図へスクロールするようにした。
