## スマホ対応の記録（2026-11-20・要件11）
- 依頼：本人の「スマホのレスポンスとか、スマホでも使えるように」。実測で、画質の自動選択が無く（スマホでも常に最高画質）、CPUを4倍遅くした起動は7.5秒・画面が6.8秒止まることを確かめてから設計した（`.kiro/specs/day-095-bonsai/mobile.md`）。
- 分担：設計・計測・通し試験・検証＝親（Claude）。実装と単体試験＝Codex（`gpt-6.2-sol`・会社用）。独立レビュー＝Codex（`gpt-6.2-astra`・読み取り専用）が中4件・低2件を指摘し、Codex（`gpt-6.2-sol`）が単体試験つきで直した。
- 結果：単体 247 件・通し試験 26 件（Chromium）・WebKit 23 件（残り3件は Chromium 専用の指の再現のため対象外）・`npm run check`・公開ゲートが成功。起動（CPU 4倍・Macの GPU）は、最高画質 5.3秒→標準 1.5秒（最長の連続処理 265ms）・軽め 0.9秒。実機は未計測（本人の端末で）。
- 公開ゲートが、Day044 の共有試験の30秒の時間切れで落ちた（2回）。重い撮影・計測と同時に走らせたため。Day44 だけ単独で4件成功・他の処理を止めた全体の再実行で合格。
