## 5. 懸念と、評価者に見てほしい点

- 文節の折り返し（`word-break: auto-phrase`）はChrome系だけが対応しています。Safariでは、長い段落は1文字単位で折れます。短い固定文言は `nowrap` や `<wbr>` で守りましたが、iPhoneの実機では確かめていません。
- 第1現場の×は、逃げるときにポップアップの枠の外まで動くことがあります（従来どおりの罠の挙動）。プレイテストでは、2回目のタップが枠の外の何もない所に当たりました。
- 語の途中の検出は `Intl.Segmenter` の辞書に頼っています。「情報はいりません」が「はい」という語に読まれる誤検出があったので、文言を「要りません」に直しました。今後、文言を変えると同じ種類の誤検出が出る可能性があります。
- 第4現場の公的見解は「ガイドラインにおいて」が390で語の途中で折れたため、「ガイドラインでは」に言い換えました。意味は変えていませんが、本人監修の文なので確認してください。
- 音は確かめていません（聞けない環境のため）。
- `meta.json` のX投稿文に「全5問」が残っています。meta.json は触らない約束なので変えていません。公開前に「全5現場」へ直すかの判断をお願いします。
- 音のボタンは2つあります。開始画面と結果画面ではヘッダー、捜査中はHUDの中です。状態は共通です。捜査中はヘッダーを畳んで上部を240px以下に収めたため、HUD側にも置きました。

## 6. 要件書と食い違ったところ

1. **結果一覧の「未達 (時間切れ)」は半角のまま**：X3は括弧を全角に統一としていますが、不変仕様1が表記をこの形で指定し、既存E2E（時間切れ→B）もこの文字列で固定しています。不変仕様を優先しました。
2. **罠解除の合図の幅**：V4の「枠幅−32pxまで」は偽ブラウザ枠の中に置く場合の上限と読みました。HUD直下のゲーム側の帯に置いたので、幅はHUDと同じです（偽サイトとは重なりません）。
3. **「リンクをコピー」でコピーするもの**：Day057の先例に合わせ、結果の文とURLをまとめてコピーし、「結果とリンクをコピーしました」と表示します。
4. **×の一言の文言**：E4の例「このチャンスを本当に見逃しますか？ 画面内のリンクから選んでください」を「本当に見逃しますか？ 画面内のリンクから選んでください」に縮めました（「相当」の範囲と判断）。第1現場のミッションも26字に縮めました。どちらも、毎秒8字で×を2回押しても残り4秒以上を確保するためです。
