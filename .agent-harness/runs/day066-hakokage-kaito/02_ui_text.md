## あそびかた（`<dialog>`・3行と、キーの1行）

1. 白い覆面があなた。見張りと警備員の光、レーザーが自分のマスに当たると見つかる。いま光っているマス（縞）に入ると、光が動く前に、その場で見つかる。点線の枠は、次の1手で光るマス。
2. 箱で光をさえぎると、後ろに影ができる。影の中なら見つからない。箱をどかすと、光は戻る。箱は押せるが、引けない。
3. 宝を取ると出口が開く。警備員は道を行き来し、箱があると引き返す。見張りはその場で向きを変える。

（修正1周目で1・2を変更。体験評価で「いま光っているマスへ踏み込むと、次の手で光が去る場合でもその場で見つかる」という順番と、自分の駒がどれかが、どこにも書かれていないと指摘されたため。「箱をどかすと、光は戻る」は、箱を押す手では予告と結果がずれる（B6）ことの説明）

キー：矢印かWASDで移動・スペースで待つ・Zでひとつ戻す・Rで最初へ ／ 切替：文字のキー（WASD・Z・R）を使う（はじめは使う）／ ボタン：とじる
文字のキーを使わない設定のときのキー（盤の横とあそびかたの両方）：矢印で移動・スペースで待つ・Backspaceでひとつ戻す（効かない WASD・Z・R を案内に出さない。オンに戻せば上の文に戻る）
