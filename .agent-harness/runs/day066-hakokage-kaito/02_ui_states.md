## キーとフォーカス

- Tab の順＝見た目の順（DOM を見た目と同じ順に置く）：帯（ホーム→〔tiny：あそびかた→音〕→共有）→ 題字の行（あそびかた→音）→ 面の帯（◀→中央→▶→〔ヒント〕）→ 盤を文で読む → 状態の行（お手本）→ 操作（戻す→↑→最初へ→←→待つ→→→↓）→ フッター。
- ゲームのキーは document の keydown で受ける。フォーカスがボタン・リンク・summary・窓の中にあるとき、Space と Enter はゲームに使わない（ボタン本来の動作だけにする。Space で「待つ」とボタンの両方が動く事故を防ぐ）。矢印・WASD は窓が開いていなければいつでも使う。ゲームに使ったキーは `preventDefault`（ページのスクロールを止める）。
- キーの押し続けの繰り返し（`event.repeat`）は受ける（連打と同じ）。十字ボタンの長押しは1手だけ。ボタンは `click`（指を離したとき）で動かす。`pointerdown` では動かさない（押しかけてやめられるように）。
- 文字のキー（W・A・S・D・Z・R）は、あそびかたの窓の切替「文字のキーを使う」で止められる（音声入力で誤って動かないため。保存する）。止めても矢印・Space・Backspace・Esc は使える。
- 見つかった・詰み：Z・Backspace＝ひとつ戻す、R＝最初へ。矢印・WASD・Space は何もしない。成功：R＝もう一度遊ぶ（主ボタンにフォーカスがあるので Enter で次の面へ）。お手本：Esc＝とめる、ほかのキーは受けない。
- フォーカスの移動：結果の欄が出たら主ボタンへ。欄を閉じたら（戻す・最初へ）、同じ働きの `#btn-undo`・`#btn-restart` へ。面を変えたら `#btn-wait` へ。窓を閉じたら、開いたボタンへ戻す。
- 戻す記録が無いときは「戻す」を、最初の状態では「最初へ」を無効にする（`aria-disabled`。押しても一言を出さない）。

## ARIA

- 窓は `<dialog aria-labelledby>` を `showModal()` で開く。結果の欄は `<section role="region" aria-labelledby>`。欄の文は `#live` でも読む。
- 面の一覧の今の行に `aria-current="true"`。ヒントの切替は `aria-expanded` と `aria-controls="hint"`。
- 盤の SVG は `role="img"` と `aria-label`。中の図形は `aria-hidden="true"`。十字ボタンには `aria-keyshortcuts`（例 `ArrowUp W`）。

## 端の場合

- 文字は省略（…）しない。長さの上限：面の名前9字（320px の面の帯で1行）、ヒント36字（2行）、見つかった文34字、一言20字。02_ui_text.md の文言はすべて収まる。
- 読み込み中：HTML だけで帯・題字・面の帯・空の盤の枠（面1の大きさ）・操作が出る。`<noscript>`「このゲームは JavaScript を使います。」。
- 音が作れない端末・保存できない端末：音なし・記録なしで続ける。エラーを出さない。
- 画面の回転・幅の変化：型とマスを計算し直す。動きの途中なら終わりの位置へ飛ばす。裏のタブに回ったら（`visibilitychange`）お手本を止めて最初へ戻す。
- タッチ：十字ボタンに `touch-action: manipulation`（2回たたいた拡大を止める）・`user-select: none`・`-webkit-touch-callout: none`。盤は `touch-action: pan-y`。
- 拡大200%：ブラウザの拡大は CSS の画面幅を縮めるので、型が切り替わって収まる（1440×900 の200%は 720×450 の short）。
