# Day066 評価者向けの追加メモ（発注側が Day065 の評価依頼書と合わせて組み立てる）

## 前提として受け入れる設計判断（覆す提案は不要）

1. 1手ずつ進む。乱数なし。光は直線だけで、画面に見えている光が判定。次の1歩で光るマスは点線の枠（予告）。
2. 警備員は一直線の道を往復し、道の端と箱の前では1手使って向きを変える。見張りはその場で向きを変える（面4・8は4方向に回る）。
3. 箱は押すだけ（引けない・2つ並びは押せない）。出口は宝を取るまで閉じた扉。「最初へ」は確認なしで、ひとつ戻すで取り消せる。
4. 操作は十字ボタンとキーだけ。盤のタップ・スワイプは無い。結果の欄は十字ボタンの場所に出る（窓ではない）。
5. 星は最少手数（par）が基準。同じ面で2回失敗すると「お手本」（最短解の自動再生）が出る。見ても星は減らない。
6. 暗い配色だけ。絵文字なし（★☆は文字）。全8面を最初から選べる。
7. 予告は、箱を動かさずに待った場合の次の光。その手で箱を押したときだけ、遮光・巡回が変わるため、予告と結果が違うことがある（仕様）。

## 企画の反証を実プレイで確かめる手順

- ①押さずに抜ける：面1・面3で、箱に触らずに宝へ行こうとする。光が切れ目なく塞いでいれば合格。
- ②視野が予測できない：見つかるたびに「点線の予告を見ていれば避けられたか」を記録する（避けられた回数／見つかった回数）。
- ③三役：面2で交わるマスに箱を置き、2本とも止まるか。面5で道の端に箱を落とし、警備員が手前で引き返すか。面3で箱を真下のレーザーへ落とし（右へ4回・下へ2回）「もう出られない」が出るか。面7で1つの箱がレーザーと警備員の両方を止めたと感じたか。

## デザイン系スキルの使い方（06_design_skills.md）

- 見た目の評価者：`design:design-critique` で、390×844 と 1440×900 の5画面（面1の最初・面8の途中・成功・見つかった・あそびかたの窓）を講評する（第一印象・使いやすさ・視線の順・一貫性・アクセシビリティ）。10項目の採点に**足す**（置き換えない）。講評の表と優先3つを評価書に貼る。
- 見た目と体験の評価者：`design:accessibility-review` を実ページに当て、点検表を貼る。**重大（Critical）が残るなら合格にしない。**
- Skill ツールで呼べなければ、型を手で再現し、そう書く。
