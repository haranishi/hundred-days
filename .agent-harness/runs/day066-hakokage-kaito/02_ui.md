## 画面の型（reference/layout.mjs が正。lib/layout.js へ写し、`<html data-layout>` に入れる）

CSS はメディアクエリでなく `[data-layout="…"]` で並びを変える。境目を JS と CSS で二重に持たないため。リサイズと向きの変更で計算し直す。

| 型 | 条件 | 並び（上から） |
|---|---|---|
| tall | 幅<700・高さ≥760 | 帯 → 題字（h1・一行説明・[あそびかた][音]）→ 面の帯 → ヒント（2行まで）→ 盤 → 状態 → 操作（60px） |
| compact | 幅<700・高さ620〜759 | 帯 → 題字（h1のみ）→ 面の帯（右端に[ヒント]）→ 盤 → 状態 → 操作（52px） |
| tiny | 幅<700・高さ<620 | 帯（[あそびかた]と[音]を44pxの絵のボタンで帯へ移す）→ 面の帯（[ヒント]つき）→ 盤 → 状態 → 操作（48px）。h1 は帯の中に置く |
| short | 幅≥700・高さ<500 | 帯（h1・[あそびかた][音][共有]）→ 2列：左に盤、右に 面の帯・ヒント・状態・操作（52px） |
| wide | 幅≥700・高さ≥500 | 最大幅1120を中央に。帯 → 題字 → 2列：左に盤（最大560px）、右に面の帯・ヒント・状態・操作（64px）・キーの説明 |

- 盤のマス：`cellSize({ vw, vh, cols, rows, reserve })`（reserve は実測の高さ。下の「アクセシビリティ」）。下限36px・上限56px（wide は64px）。`node reference/layout-table.mjs` で、全8面×7つの画面幅（390×844・375×667・320×568・844×390・1440×900・768×1024・360×800）のマスの大きさと余りの高さが出る。全組み合わせで、盤と操作が最初の画面に収まり、8px以上余る（CSS の誤差の吸収分）。
- 盤の SVG の幅を `cols × cell` px にし、CSS 変数 `--cell` にも入れる。各部品の高さは layout.mjs の `SIZES` を下限（min-height）として作る。盤の大きさは実測の reserve で決めるので、部品が少し高くなっても盤は操作の下にもぐらない（E2E で確かめる）。
- 操作は全部の縦の型で `position: sticky; bottom: 0`（背景 `--bg`・上に1pxの `--line`）。収まる設計なので通常は動かないが、文字の拡大で溢れたときに操作が画面から消えないようにするため。

## 盤の描き方（SVG・1マス＝100単位・viewBox は `0 0 cols×100 rows×100`）

重ねる順（下から）：①床（格子線）②影 ③今の光（警備員の光のマス・レーザーの線）④次の1歩の予告（点線）⑤巡回の道 ⑥壁・レーザーの台 ⑦出口・宝 ⑧箱 ⑨警備員（予告の矢印つき）⑩怪盗 ⑪見つかった印。

- 影：箱に止められた光の向こう側を `--shadow`（ほぼ黒）で塗る。箱に接する辺に、影の向きへ伸びるくさび形のグラデーション（不透明→透明・マスの半分）を足し、「箱が落とした影」に見せる。題名の由来なので、どの画面でも影が一番はっきり見えること。
- 警備員の光：マスを `--lit-cell` で塗り、45度の斜線（`--light` 不透明度0.35・幅8単位・間隔24単位）を重ねる。
- レーザー：マスの中心を通る線。下に `--laser-case` の太線（18単位）、上に `--laser` の芯（8単位）。台の壁には稲妻の印。斜線は使わない（警備員の光と柄で区別する）。
- 予告（次の1歩で光るマス）：マスの内側10単位に `--light` の点線の枠（太さ4・dasharray 6 8）。下に太さ8の `--shadow` の線を敷く（光のマスの上でも見える）。いま光っていて次も光るマスにも描く。レーザーは動かないので予告を描かない。
- 予告の矢印：進むなら次のマスへの点線矢印、端や箱の前で向きを変えるならUの字の矢印、見張りなら回る向きの弧。どれも `--light`。
- 巡回の道：道のマスの中心を結ぶ破線（`--guard`・太さ6・下に太さ10の `--shadow`）。端に小さな丸。予告の点線（枠）とは形で区別する。
- 警備員：丸い体（`--guard`・縁 `--guard-rim` 5単位）、向いている側に懐中電灯のくさび（`--light`）と目の印。同じ種類（見張り・警備員）が2つ以上いる面だけ番号札（`--badge` の丸に `--badge-ink` の文字34単位＝最小のマスでも12.6px）。見張りは立ち姿にランプ、巡回の警備員は歩く姿と道の破線で、形でも種類を分ける。
- 箱：角丸の四角（内側10単位）`--box`・縁 `--box-edge` 5単位・中央にテープの帯。宝：金の塊 `--gold`・縁4単位の `--shadow`。出口：閉じた扉に錠の印と `--line` の縁、開いた扉に外向きの矢印（色と形の両方で区別）。壁：`--wall` に上面の帯 `--wall-top` と3単位の `--shadow` の縁。
- 怪盗：頭と外套のシルエット（`--player`・縁 `--player-rim` 5単位）、目元に白い帯。光の上でも影の上でも縁で見える。
- 見つかった印：原因の光のマスを、外 `--danger`（8単位）＋内 白（3単位）の二重枠で囲み、怪盗のマスに二重の輪と「！」の札（02_ui_style.md）。原因の警備員・レーザーの台を少し揺らす（動きを減らす設定では揺らさない）。
- 盤の外枠：角丸12px・太さ3px `--wall-top`。各マスの `<rect>` に data 属性（02_ui_hooks.md）を付け、E2E が「見えている光＝判定」を確かめられるようにする。

## 操作

- 十字ボタン：3×3の格子（すき間は型ごと・layout.mjs）。中央「待つ」、左上「戻す」（ひとつ戻す）、右上「最初へ」（名前は「最初へ戻す」）、上下左右に矢印。左下と右下は空ける（親指の誤タップ防止）。
- 盤のタップ・スワイプは入れない。縦スクロールとぶつかり、誤って光へ踏み込む事故が起きるため。盤は押せる部品にしない。
- キー：矢印・WASDで移動、Space で待つ、Z・Backspace でひとつ戻す、R で最初へ、Esc で開いている窓を閉じる（文字のキーは切替で止められる。02_ui_states.md）。入力欄や窓にフォーカスがあるときは盤を動かさない。
- 連打：動きの途中で次の入力が来たら、今の動きを終わりの位置へ飛ばしてから次の手を進める。入力を捨てない・ためない。
- 無効な手：怪盗がその方向へ6pxだけ揺れて戻り（120ms）、理由を一言だけ出す（02_ui_text.md）。手数は増えない。
- 結果の欄は操作の場所に差し替えて出す（盤は見えたまま）。見つかった・詰み・成功の3種類。窓（dialog）にはしない。欄を出す間は状態の行を隠し、その高さも欄に回す。欄の主ボタン（ひとつ戻す・次の面へ）は、どの型でもスクロールせずに最初の画面に入ること（E2E で測る）。見つかった欄の文は3行まで（最も長い文で2行＋共通の1行）。
- お手本：同じ面で2回失敗（見つかる・詰み）すると「お手本を見る」を出す（失敗の欄と、状態の行の右端）。押すと最初からにして、見本の解を1手400msで再生する。再生中は操作を止め、「とめる」だけ押せる。終わったら最初の状態に戻す。お手本で出口に着いても星と記録は付けない。

## 動き・音

- 1手：怪盗・箱・警備員を同時に150ms（ease-out）で動かす。光・影・予告は動きの終わりに一度で描き直す（光をなめらかに動かさない。途中の光が判定と食い違って見えるため）。
- 宝：300msのきらめき＋扉が開く。成功：怪盗が扉へ消え、結果の欄。見つかった：原因の光が2回点滅（合計1000ms。1秒に3回を超えない）。
- `prefers-reduced-motion: reduce` では、移動はすぐ終わり、点滅・揺れ・きらめきをしない。結果の欄はすぐ出す。
- スクロールは `behavior: 'auto'` だけを使う（なめらかなスクロールの途中に押すと位置がずれる。Day065 の CI で実際に落ちた）。
- 音は Web Audio の合成（02_ui_states.md）。最初の操作で AudioContext を作る。音を切っても、同じ内容が文と動きで分かる。

## アクセシビリティ

- 盤の SVG は `role="img"` と、面の名前・自分の位置・宝の状態を入れた `aria-label`。盤の下に「盤を文で読む」（`<details>`）を置き、光っているマス・次の手で光るマス・影のマスを「左から3・上から4」の形で文にする。
- 1手ごとに `#live`（`aria-live="polite"`）へ短い文を出す。見つかった文・成功の文・一言もここで読む。見える一言 `#toast` は `aria-hidden="true"`（同じ文を二度読ませない）。
- `<html lang="ja">`。目印：帯は `<header>`、本体は `<main id="app">`、面の帯は `<nav aria-label="面をえらぶ">`、フッターは `<footer>`。見出し：h1（題名）→ 見えない h2 `#level-title`「面{n} {名前}」（盤の前）→ 結果の欄と窓の見出しは h2。
- 盤のマスの大きさは、実際に描いた帯・題字・面の帯・ヒント・状態・操作の高さを `getBoundingClientRect` で測った合計（reserve）を `cellSize` に渡して決める（文字だけの拡大でも盤が操作の下にもぐらない）。帯や欄は `height` でなく `min-height` で作る。
- フォーカスの輪は3px `--focus`・2pxの外側。窓を閉じたら、開いたボタンへフォーカスを戻す。
