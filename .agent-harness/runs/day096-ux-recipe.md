- 採点（合格＝16点以上かつ0点なし・最大3周）: 体験（実際に操作・Opus）13→15→**17 合格**／見た目（画像のみ）14（Codex）→14（Opus）→14（Opus）＝**3周で16点に届かず、周回を打ち切り、残件を記録**（完成度の0点は2周目で解消）。見た目の残件のうち、安全に直せるものは修正F2fで直した（再採点は参考値）。

- 修正は担当ごとの隔離コピー（Codex 約25本）で並行し、`collect.py` で範囲内のファイルだけを回収した。**回収の罠**: 作業コピーを「いまの本体」から作ると、回収が `work/baseline`（初回）との差分を見るため、**コピーを作った後に本体で直したファイル（範囲内）を、古い版で上書きする**（F2f の回収で、直前に直した `form.js` と試験が戻った。`git diff` で気づいて戻した）。回収の後は必ず `git diff` で、担当の成果以外が戻っていないか確かめる。
- 偶発失敗の原因: E2E の共有リンクのテストが `browser.newContext()` を2つ閉じ忘れ、後続のテストが20〜40倍遅くなった（全体2〜3.5分→34秒）。
