## Round 2 に向けた改善必須ポイント（Must-Fix リスト）

1. **【最優先】スタート画面（スタンバイ状態）のファーストビュー収まりと未開始ステージの非表示化**
   - スマホ（390×844px / 360×780px）でページを開いた瞬間（スクロール量0px）に、**「3方向ルール説明」と「STARTボタン（60秒／10問研修／1問おためし練習）」がすべてファーストビュー内に確実に収まる**よう、上部の余白・モード選択バー・電光掲示板の高さを圧縮・整理すること（現状 `btnStartShift.top: 1079px` → 目標 `top < 650px` かつ `bottom < 820px`）。
   - スタンバイ中（スタート画面表示中）は、**背後の検査コンベア・検査トレイ・3方向仕分けボタン（「↑ 預け荷物へ」等）・NEXTアイテム予告を非表示（`hidden`）**にし、スタート画面の後ろや下に未開始のボタンや問題が露出して混乱しないようにすること。

2. **【最優先】プレイ画面の1画面完結化（トレイ＋3方向ボタン＋判定フィードバックの近接配置）**
   - スマホ（360×780px / 390×844px）でもPC（1440×900px）でも、プレイ中にスクロールすることなく**「コーチ／判定フィードバック」「検査トレイ」「3方向仕分けボタン」が1画面（ファーストビュー内）に同時に収まる**レイアウトに再設計すること。
   - 特にPC（1440px）でトレイの真上に巨大な「↑ 預け荷物へ」ボタンが独立して縦幅を圧迫している構造を見直し、検査トレイのすぐ近くに3方向ボタンと判定モニターがコンパクトに収まるようにすること。

3. **【最優先】即時理由フィードバック（判定モニター）の視線移動ゼロ化とCLS完全ゼロ化（`feedbackHeightDeltaPx === 0`）**
   - 仕分け直後の正解／ミス理由フィードバックを、画面最下部の離れた場所ではなく、**検査トレイの直上または直下のすぐ目に入る位置**（コーチバナーと統合、またはトレイ直近の固定モニター枠）へ移動し、仕分けと同時に理由が読めるようにすること。
   - 判定モニターの高さを完全固定（`height` 固定＋`overflow: hidden`）にし、待機中と正解／ミス長文表示時の高さ差分 **`feedbackHeightDeltaPx` を現在の `18.72px` から完全に `0px` にすること**。

4. **X線透視ON時のトレイ高さ膨張と画面下端見切れの解消**
   - 「🔍 X線透視」をONにした際（`02-tutorial-coach.png` / `04-playing-xray.png`）、追加される所見ボックスによってトレイ全体が縦に大きく伸びて画面下端で見切れないよう、トレイ内部のパディング・アイコンサイズ・所見ボックスのレイアウトをコンパクトに収めること。

5. **シフト完了リザルト表示時の不要要素の非表示化**
   - リザルト画面（`07-result-panel.png`）を表示しているときは、直前の問題の判定バナー（「◯ 正解 +280pts...」）や検査レーンの操作要素を非表示にし、リザルトカードがすっきり主役として見えるようにすること。
