## Round 2 に向けた改善必須ポイント（優先度順）

### 1. 【最優先】スタート画面（`01-start-standby`）のファーストビュー収まりと背後要素の非表示化
- スタンバイ（スタート画面）表示中は、検査トレイ・ベルトコンベア・3方向仕分けボタン（「↑ 預け荷物へ」含む）・NEXT荷物ピルを完全に非表示（またはスタートパネルで置換）にし、下にダブって見えないようにすること。
- 上部のモード切替カードやステータスボードの高さを圧縮・統合し、360px / 390px のファーストビュー（スクロールなし）内にスタートパネル全体と「START」ボタン・サブボタンが確実に収まるようにすること。

### 2. 【最優先】プレイ画面（`02`, `03`, `04`）のファーストビュー圧縮（モバイル＆デスクトップ）
- プレイ中（チュートリアル・本番シフト中）は、プレイに不要な上部要素（モード選択ボタン2枚、最高スコアバー等）を非表示にするか1行のコンパクトなスリムバーに統合すること。
- 吊り下げステータスボード、DEPARTURES看板、X-RAY SCANNERバー、コーチバナーのパディング・フォントサイズ・行数を大幅に引き締め、360px / 390px のファーストビュー内に「スコアボード ＋ 判定/コーチモニター ＋ 検査トレイ（X線ON時含む） ＋ 3方向仕分けボタン」がすべてスクロールなしで収まるようにすること。

### 3. 【最優先】判定モニター（`05`, `06`）の配置見直しとCLS解消
- 判定モニター（正解／ミス理由）およびコーチバナー（おためし練習・第1問ガイド）をコンベア上部（またはトレイ直上の固定高さモニター枠内）の同一スロットに統合し、どの画面幅（360px〜1440px）でもファーストビュー内で即座に正誤と理由が全文読めるようにすること。
- 1問目→2問目移行時やX線ON/OFF時にトレイや3方向ボタンの位置が大きく上下しないよう高さを安定させ、シフト完了（リザルト画面 `07`）時は判定モニターを非表示にすること。

### 4. 3方向仕分けパッドの配色統一とレイアウト整理
- 3方向パッドの配色を「青（ブルー／シアン系）＝機内持ち込み」「琥珀（アンバー／イエロー系）＝預け荷物」「赤（レッド／ローズ系）＝持込不可」に明確に塗り分けること（3原則ガイドモーダルの丸アイコンやスタート画面の3分類カードも同色に揃える）。
- `768px` / `1440px` でも縦高を圧迫しないよう、3方向ボタンの配置・高さをコンパクトに整理し、900px高のデスクトップ画面で全プレイ要素＋判定モニターが余裕をもって1画面に収まるようにすること。

### 5. モバイルでの比較スマホ表示と細かい見切れ・はみ出しの修正
- `360px` / `390px` でも検査トレイ内に比較スマホイラストを表示し、手荷物のサイズ対比が一目で分かるようにすること。
- `360px` で `NEXT ...` バッジが右枠外へ飛び出さないよう、`min-width: 0` と `text-overflow: ellipsis` 等で枠内に収めること。
- 3原則ガイドモーダル（`360/09`）でモーダル下部の「わかった！検査レーンに戻る」ボタンが画面内に収まるよう、パディング・行間を調整すること。
- 早見図鑑（`08`）で検索プレースホルダーがモバイル幅で途中切れしないよう文言を短くし、見出しの `（全36品目）` が括弧の途中で改行されないよう `white-space: nowrap` を適用すること。
