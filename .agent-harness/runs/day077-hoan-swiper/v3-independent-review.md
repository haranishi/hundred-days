# Day77 実3D版・独立体験／画面評価

2026-10-26。UI・描画の実装者とは別の担当が、配信プレビューをChromeで実操作した。
仕様は `.kiro/specs/day-077-hoan-swiper/3d-design.md`、評価基準は体験／Web・UIハーネス。
環境：Playwright 1.62.1、Chrome 155.0.8059.85、1440×1000／768×1024／390×844。
主要操作を92秒連続で行い、追加でタッチ入力・低減モーション・故障復帰・修正後の操作を確認した。
画像の撮影・閲覧・指摘と修正後の確認を含め、約9分の評価。実機の指操作や長期継続の調査ではない。

## 実操作の証拠
- 3幅で実WebGLの検査機・ローラー・トレイ・荷物・影を確認し、横はみ出しなし。
- 1問練習：預け荷物への誤答で理由を表示し、問題を維持。機内への正答で本編の1/10へ進んだ。
- 近景／全景を切替、X線で内部構造と模式図の注記を確認。Spaceでも切替できた。
- 実マウスの左ドラッグで1/10→2/10、矢印キーとAキーで仕分けできた。
- 研修10問を8/10で完走。誤答2件の品名・誤選択・正解・理由を結果で復習し、再挑戦で1/10に戻った。
- 図鑑は全36件。検索「バッテリー」は6件。6カテゴリの件数は9／4／8／2／9／4件。
- 60秒は最初の仕分け前は1:00のまま。初回回答後0:59、ガイドで2.1秒停止しても0:59、閉じると0:58へ再開。
- 図鑑でも0:58のまま停止し、検査へ戻ると再開。実時間で0:00に到達し結果を表示した。
- 結果から研修へ切替できた。音ONと研修最高8/10はリロード後も保存されていた。
- 実タッチイベントのtouchCancelは1/10を維持し、通常の右スワイプだけで2/10になった。
- 低減モーションでも3D・仕分け・X線が動いた。390pxの遊び方ボタンにアクセシブル名があった。
- 描画APIのsortに故障を注入し、エラー案内後もテキストで2/10へ進んだ。再読込ボタンで実際に再ナビゲーションした。
- 修正後の390px開始CTAはy727.5–783.5で初回844px内。タップ開始成功。完了時のfocusはresult-headingへ移動した。
- 最終buildの390／360pxではHUDの1 / 10が高さ22pxの1行に収まり、横はみ出しなし。CTA下端は770.1／768.1pxで初回内。
- 各品目を約2秒見て回答後の説明を約2秒読む追加プレイでも、異なる10品目を10/10で完走し、結果見出しへfocusした。
- 通常の連続操作でpageerror・外部リクエストは各0件。音は切替と保存を確認し、聴感品質は評価していない。

## 改善TOP5と採否
1. 3D API例外でゲーム進行まで停止する経路：修正採用。故障注入でも2/10へ進むことを再確認。
2. 障害案内の再読込ボタンがトレイのpointer captureに奪われる：修正採用。2回目のナビゲーションを確認。
3. モバイルで開始CTAが初回画面外：修正採用。390pxで開始CTA全体が初回内に入った。
4. 結果へ移ってもfocusがBODYのまま：修正採用。結果見出しへfocusすることを再確認。
5. 小さい補助文字と390pxのHUD折返し：折返し修正を390／360pxで再確認。補助文字拡大は次の磨き込み候補。
