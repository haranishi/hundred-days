## 3. Round 1 指摘事項の解消確認サマリ

1. **【解消】待機画面（ファーストビュー）の開始ボタン画面外落ち（R1: `top: 1079px` → R2: `top: 428px`）**
   - 待機オーバーレイ（`.standby-overlay`）のパディング・タイポグラフィ・3方向ルールカードがコンパクトに再設計され、`360×800` でも `#btn-start-shift`（`top: 428px, bottom: 468px`）、`#btn-start-training`（`top: 473px, bottom: 505px`）、`#btn-start-tutorial`（`top: 511px, bottom: 543px`）のすべてがファーストビュー内に余裕をもって収まった。
   - `.inspection-stage.is-standby` クラスによって開始前の検査レーン・下部ボタンが完全に隠蔽され、初見プレイヤーが「開始前のダミートレイ」を誤タップする導線ノイズがなくなった。

2. **【解消】プレイ中の1画面完結性（モバイル `360×800` / `390×844`・デスクトップ `1440×900`）**
   - プレイ中のトレイ内部レイアウトを横並び（`.tray-main-row`）に圧縮し、モバイルのプレイ中は補助ピル（`.record-pills`）を非表示化することで、HUD・コーチ/フィードバック・検査トレイ・下部3方向ボタン＋X線ボタンが1画面内に完全に収まった（`shots-r2/360/03-playing-normal.png`〜`06-feedback-wrong.png`、`shots-r2/1440/03-playing-normal.png`〜`06-feedback-wrong.png`）。

3. **【解消】即時フィードバックの視線配置とレイアウトシフト防止（CLS: `18.72px` → `0px`）**
   - `#feedback-banner` を検査ステージ内のコンベア直上へ移動し、高さ `68px` 固定（`min-height: 68px; max-height: 68px; overflow: hidden;`）としたことで、スワイプ直後に視線移動ゼロで理由を確認でき、かつ `feedbackHeightDeltaPx: 0` でトレイやボタンが一切ガタつかなくなった。

4. **【解消】X線透視ON時のトレイ膨張防止**
   - `.tray-telemetry-slot`（高さ `52px` 固定）内で通常時のヒントバーとX線ON時の3セルテレメトリ表示を切り替える構造にしたことで、X線ON/OFFを切り替えてもトレイ高さが一切変化せず、下部ボタンが画面外に押し出されなくなった（`shots-r2/360/04-playing-xray.png`）。
