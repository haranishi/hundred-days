## 主な改善内容
1. **捜査官アンビエントBGM**: Web Audio API による低音ミニマルシンセを実装（緊張感の演出）。
2. **リアルな引き留め工作**: STAGE 1でチェックを外そうとすると警告ダイアログが出現。STAGE 2で逃げる×ボタンを搭載。STAGE 3で割り込みトースト通知を実装。
3. **視覚フィードバックの強化**: 画面全体の赤/緑フラッシュアニメーションとカットインバナーを追加。
4. **二重否定＋配色逆転**: STAGE 4に最終確認モーダル（赤の維持ボタン vs 薄灰の退会ボタン）を追加。
5. **E2E自動プレイテスト**: 全5面を実際に走破してSランクとXシェアを検証するPlaywrightテストを完備。
