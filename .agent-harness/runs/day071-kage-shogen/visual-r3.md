## 4. 改善TOP5

**1. 折返しを、推理画面と同じ句の切れ目にそろえる**
- **どこを：** 04・04bの現場メモ（360・390）、14の注記、15のURL、12の判定文。
- **どうする：** 現場メモにも、推理画面と同じ「句の切れ目で改行する」指定を当てます。URLは「/」の後ろでだけ改行させます。「出し入れ」「175cmの桐谷」は1行に収めます。
- **合格の条件：** 360・390幅で、行頭に助詞（は・を・が・に・て）や語の後半が来ないこと。「立って」「紳士は」「灯りは」「出し入れ」「kage」が行の中に収まること。URLの行頭が「-」にならないこと。

**2. 道具を壁から色で分け、はみ出した影に印を付ける**
- **どこを：** 05〜08（全幅）、特に07。
- **どうする：** 道具の塗りを、今より暗い紙色にします。たとえば #c8a66e 前後なら、壁に対して1.88:1、影に対して7.24:1、輪郭に対して3.29:1です。または、輪郭を2 CSSpx以上にして薄い落ち影を付けます。夜5の壁の上で切れた影には、壁の上端に小さな▲を付けるか淡いフェードをかけて、はみ出していると分かるようにします。
- **合格の条件：** 道具の塗りと壁の比が1.5:1以上（または輪郭が2 CSSpx以上）であること。360幅の07で5つの道具が一目で数えられること。紺の帯が描画の欠けに見えないこと。

**3. 夜5の道具チップを最初の画面に全部出す**
- **どこを：** 07（360・390）。
- **どうする：** チップを2行に折り返します（1440幅の07と同じ形）。または、隠れている数を「+2」のように示します。
- **合格の条件：** 360・390幅で、灯りと道具5つのチップ6個が横スクロールなしで見えること。そのうえで、下げる／上げるまでが最初の画面に残ること。

**4. 768・1440幅の列の幅と寄せ方をそろえる**
- **どこを：** 03・09・10・11・12・13と01・02の最終段。
- **どうする：** 文章の画面の列を、ヘッダーと同じ幅にそろえます（768幅なら24〜743.5、1440幅なら204〜1235.5）。そろえない場合は、全画面で同じ幅の中央寄せにします。1440幅の概要は、再現室と同じ2列（左にスケッチと証言、右に本文とボタン）にします。推理も2列（左に手がかり、右に容疑者）にして、右側の空きをなくします。事件簿で夜5が1枚だけ残る段は、カードを横いっぱいにするか中央に置きます。
- **合格の条件：** 768幅の全画面で、本文の左右の端がヘッダーの端と一致すること。1440幅で、列の片側に幅の30%以上の空きが残る画面がないこと。

**5. 主ボタンと焦点表示の型をそろえる**

- **どうする：** 「はじめる」を、ほかの主ボタンと同じ角丸の四角にし、高さを44〜48にします。夜カード全体を押せる範囲にする方法もあります。焦点の輪は琥珀系と別の見た目にします（例：白 #f1ecff の2 CSSpxの輪に2 CSSpxの隙間）。プログラムで焦点を移す見出しには輪を出しません。

## 5. 残すべき良い点

- 紺の舞台、紙の壁、琥珀の灯り、朱の印の4色でまとまった世界観。本文の文字も8.3〜9.2:1のコントラストがあります。
- 再現室では壁がいちばん大きく明るく、灯りの玉の光と上下の矢印が「ここを動かす」と示しています。
- 近さの手応えが何重にもあります。「遠い／近い／すこし似ている」の文字、4段のメーター、近いときの黄色い壁の枠、夜1の朱のガイドで、色だけに頼っていません。

- 推理画面の状態の出し方。外した容疑者は破線と取消線と「× 外した（戻す）」で戻し方まで分かります。誤答は朱の枠と「ちがう」の判子と計算の説明で示し、360幅では説明が1文1行です。
- 事件簿の状態の出し方。開ける夜は琥珀の枠と光、ロック中は破線と錠前と理由、解決済みは★とn/3で示しています。
- 判子の演出と、「星2つ（誤った推理があった）」のように星の理由を言葉で添える書き方。
- モバイルの土台。左右16の余白があり、ページの横はみ出しがなく、再現室の主要な操作は360×640でも最初の画面に入ります。
- ダイアログの作り。英字の小見出しと明朝の見出し、44の×ボタン、朱の塗りの破壊的操作と輪郭のキャンセルを使い分けています。共有はX・LINE・リンクのコピーに、IG/YTの注記とURLの手動コピー欄が付いています。
