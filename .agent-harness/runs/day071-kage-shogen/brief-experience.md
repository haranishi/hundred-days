## 対象
スマホ向けの影絵×推理パズル（ブラウザ・1人用・全5夜）。URL：`<PREVIEW>`。
あなたが知っているのは「影絵×推理パズル」という一言だけ。遊び方は、画面に出ている文字と見た目だけで判断する。

## 前提として受け入れる設計判断（覆す提案は不要）
1. 灯りは縦にだけ、棚の上の道具は横にだけ動く。
2. 灯りの高さ ÷ 0.6 ＝ 灯りを提げた人の身長（月影荘の決まり）。夜4は踏み台の高さを引いてから割る。
3. 夜1だけ、最初から朱のガイドが重なっている。ガイド・ヒント・誤答は星を減らす。
4. 夜5には、人影に関係ない邪魔な道具があり、壁の端へすべらせて影を追い出す。
5. 容疑者は3人で、アリバイと灯りの高さから1人に決まる。
6. 音は無い（音は評価しない）。
上記以外（説明の量・文言・演出・難しさ・並び・画面の情報量など）は**評価・提案の対象**。
**減点対象**は「原因の分からない失敗」「操作不能・詰み」「表示と判定の矛盾」「単調・情報過多・理不尽」。

## 操作ツール（実プレイ用サーバー）
人の指のように、座標でつかんで動かす道具を用意した（サーバーは依頼側が起動済み。`<PORT>` は依頼文の値）。ポインターは本物のヒットテストを通る（重なり・つかみにくさ・誤タップがそのまま起きる）。
操作はすべて、次の形のコマンドで行う（`curl` は使えない環境があるので、Nodeのクライアントを使う）。

```
node .agent-harness/runs/day071-kage-shogen/tools/playtest-client.mjs <PORT> <コマンド> [引数...]
```

| 操作 | コマンド |
|---|---|
| 今の画面の文字・押せる部品の一覧（中心座標・大きさ）と、ゲームの状態（phase・灯りの高さ・近さ・壁の枠の位置） | `state` |
| スクショ（`name`は自由。`full`を付けると縦に全部）。返った `path` を Read で見る | `shot s1-start` / `shot s1-start full` |
| タップ（座標、または表示文字） | `click 195 588` / `click-text 再現室へ` |
| **ドラッグ**（押す→少しずつ動かす→離す） | `drag 195 300 195 340`（x1 y1 x2 y2） |
| キー（回数で連打） | `press ArrowDown 5` / `press Shift+ArrowDown 3` / `press Tab` |
| スクロール | `scroll 300` |
| 待つ（ms） | `wait 800` |
| やり直す（幅・高さ。`unlock N` で最初のN夜を解決済みにして始める） | `restart 1440 900 0` |
| 再読み込み（保存の復元の確認用） | `reload` |
| 起きたエラー・警告の記録 | `events` |

- スクショの座標は、そのままCSS pxの座標（390×844のとき画像も390×844）。`state` の `game.wallOnScreen` が壁の枠。灯りの玉・道具は画像で見つけて、その中心を `drag` の始点にする。
- 時間制限は無い。ただし、**1夜を解くのに何手（ドラッグ・キー・タップ）かかったか**を数えて記録する。
- 音は聞こえない。音は「未確認」とし、減点も加点もしない。

## 遊び方（必須）
各パスで、**毎回スクショを撮り、画面を実際に見てから次の操作を決める**（スクリプトで一気に流さない）。

1. **P1 初見・390×844**：夜1から夜5まで順に1周。詰まったら、ヒント → ガイド → はじめから、の順に使ってよい（使ったら記録する）。各夜で「画面を見て何が分かったか／何をしたか／何が起きたか／手数」を残す。
2. **P2 わざと失敗する**：夜1の推理で、わざと誤った人を選び、返ってくる文を見る。「ヒント」「ガイド」「はじめから」「考え方を見る」の挙動。夜5で、邪魔な道具を残したまま他を合わせたときの表示。
3. **P3 慣れた2周目**：`restart 390 844 0` で新しく始め、夜1〜2を速く遊ぶ。1周目と比べて判断が変わったか、飽きるか。累計で「3分遊んで単調か」を判断できる量を遊ぶ。
4. **P4 PC幅**：`restart 1440 900 2` で夜3を1周。レイアウトと押しやすさ。
5. **P5 キーボードだけ**：夜1を、Tab・矢印・Enter・Spaceだけで。焦点の見え方・詰まり・画面が変わったあとの焦点。
6. **P6 保存**：夜2まで解決して `reload`。事件簿に星と解放が残るか。

最低でもP1〜P6を実際に遊ぶこと。実プレイしていない項目は「未確認」と書き、勝手に満点・減点しない。
