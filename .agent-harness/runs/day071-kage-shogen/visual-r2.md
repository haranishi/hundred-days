記録者の注記：評価者（別セッションのサブエージェント）の最終報告を、本文はそのまま保存した。評価対象は、改修1のあと（コミット `9ef5e9d` の複製）。評価者は、コードも仕様も第1周の評価書も読まずに、144枚のスクリーンショット（幅360・390・768・1440 × 18画面、表示領域と縦長）だけを見て採点した。画像と計測用の作業ファイルは作業用の一時領域に置いたままで、リポジトリには含めない。作業ファイルの置き場の1行だけ、説明に替えた。

**合計は15/20点で不合格です**（合格は16点以上・0点なし。0点の項目はありません）。画像は2倍密度なので、寸法はすべて CSS px（画像の画素÷2）で書きます。色は画像から拾った実測値、コントラストは WCAG の相対輝度で計算しました。

## 1. 結論

減点の大きい問題は次の3つです。

- **360×640 で主要操作が1画面に入らない。** 夜5（360-07）では「下げる/上げる」が下端で切れ、高さ50pxのうち27pxしか見えません。「ヒント/ガイド」の行は、夜1〜5のどれでも1画面目の外です。
- **再現室の手がかりカードが詰まっている。** カードどうしの隙間が0で、枠線が二重に見えます。360幅では本文の列が約200px（13〜14字）しかなく、5行のでこぼこな段落になります。同じカードが推理画面では8px空いていて、画面ごとに余白がそろっていません。左端の線も画面ごとに変わります（768で24/44/64px）。
- **壁の目盛り数字が AA を満たさない。** 色は #8A7A52、紙は #F1E7CD で 3.42:1、字は約10px です。

## 3. 不具合・崩れ（点数とは別）

1. **360-07**：「下げる/上げる」が画面下端で切れます（y613〜640、50pxのうち27pxだけ見える）。チップ6個が2段になるのが原因です。390-07 では y730〜784 で収まっています。
2. **360-04〜08**：「ヒント/ガイド」の行が1画面目の外です。360-04 では y620〜663.5 で、上20pxだけ見えます。
3. **04・04b（全幅）**：手がかりカードどうしの隙間が0で、枠線が二重です（360-04-full y915〜916.5、390-04-full y962〜963.5、1440-04-full y694〜695.5）。

6. **04/05/07/08（全幅）**：指示・ヒント枠の高さが固定（54/62/85px）なので、1行の指示のときは下が20〜60px空きます。

### 撮影の疑い（欠陥としては数えない）

- **10（全幅）の問いを囲む琥珀の枠**：画面に入った直後のフォーカス表示と思われます。11 では消えています。実機のタッチ操作でも出るなら直すべきです。枠が本文の列の外まで出ていて（360で x11〜348.5、768で x39〜728.5）、文字との間が約2pxしかありません。

- **360-12・390-12 の「次の夜へ」**：塗りが #FFC352 で、他の幅の #FFB84D より明るくなっています。直前にタップした位置にポインターが残り、ホバー表示になったものと思われます。

## 4. 改善TOP5

1. **360×640 で主要操作を1画面に収める**（04〜08、特に 360-07）
   - どうする：
     - 指示枠の高さを「その夜の指示の最大行数」に合わせます（夜5とヒントは1行＝約34px）。同じ夜の中で高さが変わらなければ、部品は動きません。
     - チップを1段の横スクロールにし、6個でも段を増やさないようにします。
     - それでも足りなければ、高さ700px未満の画面では壁を約200pxに抑えます。
     - 768/1440 の 62/85px の空きも同じ考え方で詰めます。
   - 合格の条件：360×640 で夜1〜5すべて、「下げる/上げる」が下端から8px以上離れて全部見え、「ヒント/ガイド」の行も入ること。04→04b、05→06、08 で「下げる/上げる」の y が変わらないこと。

2. **手がかりカードの間隔と本文の幅を直す**（04/05/07/08 の「現場メモと手がかり」、10・11）
   - どうする：カードの間を8px空けて、二重線をなくします（推理画面と同じ間隔）。480px未満では、タグ（証言・足跡など）を本文の上に置き、本文をカード幅いっぱい（360で約290px）に使います。
   - 合格の条件：360幅で「証言」「足跡」「踏み台」がそれぞれ3行以内に収まること。再現室と推理画面でカード間がどちらも8pxであること。枠線が重ならないこと。

3. **推理画面で外した人を目立たせない**（11、全幅）
   - どうする：「外す」を押したカードでは「この人だ」を枠だけのボタンに落とすか、隠します。「×外した（戻す）」の白枠は、他の「外す」と同じ #3B3573 に戻します。カード全体の不透明度も下げます。
   - 合格の条件：11 で外した人のカードに琥珀の塗りが1つもないこと。画面で最も明るい塗りが、残っている候補の「この人だ」だけになること。

4. **壁の目盛り数字を読めるようにする**（04〜09 の壁の左端、全幅）
   - どうする：数字の色を #8A7A52 から濃くし（#6E5A33 なら5.4:1、道具の輪郭と同じ #6B4F2A なら6.1:1）、字を12px以上にします。目盛りの線も同じ色にそろえます。
   - 合格の条件：目盛り数字が紙に対して4.5:1以上で、数字の高さが8.5px以上（2倍画像で17px以上）であること。

5. **画面どうしの左端と部品の様式をそろえる**（768・1440 の 03/09/10/11/13、15）
   - どうする：
     - 768 では、全画面の内容の左端をヘッダ「‹事件簿」の左端（24px）にそろえます。読みやすさのために列を絞るときは、右側だけを絞ります。
     - 1440 で中央の列を使う画面（03/10/11/13）は、列の左端をヘッダの左端（204px）にそろえるか、ヘッダも同じ列に入れます。
     - 15 の共有ボタンを、他の副ボタン（#3B3573 の枠・太字）と同じ様式にします。Instagram の注記は、説明文と同じ灰 #B9B2D8 に下げます。
   - 合格の条件：768 の 01〜13 で、最初の要素の左端が全画面で同じ x（±1px）であること。1440 でも左端の線が1種類であること。15 のボタンの枠色と文字の太さが、ヒント・外す・事件簿へと同じであること。

## 5. 残すべき良い点

- **世界観がぶれない。** 停電の夜の雰囲気が、紺の地・紙の壁・紺の影・琥珀の灯り・朱の判子で、全画面・全幅に一貫して通っています。
- **壁が主役で、近さを色以外でも示している。** 壁はどの幅でも最大の要素です。目盛りの琥珀の印、大きな「灯り150cm」、4つの進み具合、「遠い/すこし似ている」の文言で、正解にどれだけ近いかを色に頼らず伝えています。
- **操作の位置が状態で動かない。** 「下げる/上げる」の y は全状態で同じです。指示枠の高さ固定はレイアウトのずれ対策として効いているので、固定そのものはやめず、固定の単位を「夜ごと」にする方向で直すのがよいと考えます。
- **基本のアクセシビリティを満たしている。** ボタンは44px以上、文字のコントラストは7〜16:1、フォーカス枠ははっきり見えます。
- **推理の筋が一目で追える。** 09 の側面図と強調箱「灯り99cm。6割で割ると、身長は165cm。」、10 への「再現」カードの引き継ぎ、11 の誤答の計算の説明がつながっています。
- **主ボタンが統一されている。** 各画面の主ボタンは1つで、琥珀＋矢印の形にそろっています。
- **描画できない環境への配慮がある。** 17 では空白にせず、理由と次にすることを文章で示しています。
- **360 の解決画面（12）の構図が良い。** 判子・題名・説明・星・ボタンが中央にまとまり、バランスが取れています。
