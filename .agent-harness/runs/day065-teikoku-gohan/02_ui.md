# 画面と操作（390×844を基準に設計。幅320〜1440で崩さない）

## 構成（上から）

1. 帯（44px）：左「100 DAYS / 065」、右「共有する」（shared/share.js の窓）。
2. 題字「定刻ごはん」と一行説明。[あそびかた]（<dialog>・ルール5行）と [🔊/🔇] の切替。
3. 面チップ（1〜6）：星つき。全面タップできる。現在の面を強調。
4. 面の見出し（「3 ふたつの焼き場」）とヒント1行（levels.json の hint）。
5. 注文票（横スクロール可）：食材の絵文字・料理名・工程アイコン列・締切「〜11分」。再生後に ✔／✘ を重ねる。
6. マップ（SVG・viewBox 360×240・幅100%）：線路・駅・分岐・出庫・配膳。
7. 編成（出発順の列車カード）：番号・食材の絵文字・「→料理名」・今の進路で通る工程アイコン列・▲▼。タップで選択。
8. 発車ボタン（画面下に固定・高さ56px）。再生中は「2倍」「スキップ」に変わる。
9. 結果シート（再生後に編成の位置へ差し込む）：星・完食時刻・列ごとの結果と原因・運行図・ボタン。

デスクトップ（幅900以上）：左にマップ、右に注文票と編成。結果シートは右側。

## 進路と出発順

- 列車カードをタップ＝選択。選んだ列車の進路を、列車の色の太線でマップに重ねる（他の列車は薄く）。
- 分岐（出口が2本以上の junction）は、列車を選んでいる間だけ「切替ボタン」（半径22の円）を出す。タップするたびに出口を順に切り替え、選ばれた出口へ矢印が伸びる。
- 列車を選ばずに分岐をタップしたら、「先に列車を選んでね」と一言出す（無視しない）。
- ▲▼で出発順を入れ替える。最上段が1番手。入れ替えても選択は保つ。
- 進路が変わったら、カードの工程アイコン列を更新する（事実の表示だけ。正誤は出さない）。
- 分岐の切替ボタンは、SVGの上に重ねた絶対配置のHTML button にする（Tab・Enter・Spaceで操作でき、aria-label に「分岐 焼く駅へ」のように行き先を入れる）。

## 発車と再生

- 発車で lib/sim.js を一回だけ走らせ、timeline で再生する。再生中は編集を無効にする。
- 1分＝0.5秒（1倍）、2倍＝0.25秒。時計「N分」を表示。スキップで結果へ。
- 線路の区間：入った分から所要分で、始点→終点へ等速（via があれば折れ線に沿う）。駅の区間：駅に重ねて停止し、動きを出す（切る＝トントン揺れ、焼く＝炎、煮る＝泡）。
- 仕上がり後に待っている火の駅の列車には「ジリジリ」（揺れと赤み）。猶予（1分）を過ぎたら煙と「焦げた！」。
- 到着：配膳駅で料理の絵文字がはじけて鈴が鳴る。注文票に ✔／✘ と理由の短いラベル。
- prefers-reduced-motion：再生せず、すぐ結果シートを出す。

## 結果シート

- 星（★★★／★★／★／失敗）と一行（「完食！ 22分 最短ダイヤ！」「あと1分で★★★」「3つの注文のうち1つが焦げた」など）。
- 列ごとの結果と原因（01_rules.md の文）。
- 運行図：横軸が分。行は「出庫線」「使われた駅（pos.x の順）」「配膳手前の線路」。列車の占有を、列車の色の帯で描く。仕上がり後の待ちは斜線、焦げた所に✖。role="img" で aria-label に要約し、同じ内容を文でも出す。
- ボタン：「組み直す」（編集に戻る）／「次の面へ」（クリア時）／「結果を送る」（Xの投稿画面とリンクのコピー）／「見本のダイヤを見る」（2回失敗後）。
- 結果を送る文：「定刻ごはん Day65｜面{n}「{題}」★{星} {finish}分で完食 #100日チャレンジ #個人開発」＋ URL（origin+pathname）。

## 見た目

- 色（CSS変数）：--bg #fff6e5／--ink #2b2118／--rail #5c4a3a／--cut #2f6fd6／--grill #d9481c／--simmer #7a45c9／--serve #b7791f／--ok #1f8f4e／--ng #c62828。駅の文字は白（配膳は暗い文字）。文字のコントラストは4.5以上。
- 列車の色：t1 #e4572e／t2 #2e86ab／t3 #7b8f2a／t4 #a23b72／t5 #f2a900（絵文字の下地）。
- 線路は2本の平行線＋枕木。枕木の数＝len（時間が目で分かる）。駅は角丸の建物＋絵文字＋「切る 2分」。分岐は小さな円。出庫は車庫、配膳は旗。
- 書体は端末のもの。絵文字はOSのもの。SVG内の文字は最小11px相当。インライン style は避け、class と属性で表す。

## 音（lib/audio.js・Web Audio合成・外部ファイル禁止）

発車（低いガタン）／切る（短いトン）／焼く（ノイズのジュッ）／煮る（ポコポコ）／配膳（鈴）／焦げ（短いブザー）／クリア（上がる音）／失敗（下がる音）。
音量は控えめ（最大0.15）。AudioContext は発車の操作で作る。切替は保存。音が無くても情報は欠けない（焦げ・到着は視覚でも出す）。

## 保存

定数名は STORAGE_NAME = 'teikokuGohan.v1'（「_KEY」で終わる名前は使わない＝gitleaks が誤検知した前例）。
形：{ muted, levels: { L1: { stars, best, tries, usedSample } } }。読み書きは try/catch で囲み、保存できなくても遊べる。
