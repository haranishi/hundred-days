# ルール（正は reference/sim.mjs。これは読みやすい要約）

## 線路網

- 一方通行で、行き止まりは配膳駅（serve）だけ。分岐はあっても輪にならない。
- ノードの種類：yard（出庫）／junction（分岐・合流）／cut・grill・simmer（駅）／serve（配膳）。
- yard から出る線路は1本だけ（出庫線）。junction は、出口が2本以上なら「分岐」、入口が2本以上なら「合流」。
- 線路（edge）は len 分、駅は調理時間ぶん、その区間を「占有」する。同時に1列車だけ。
- 調理時間の既定：切る2分・焼く3分・煮る4分。駅ごとに time で上書き。座標は pos、曲げたい線路は via。

## 列車の動き（1分ごと。時間は整数のみ・乱数なし）

1. 出発順の k 番目（0始まり）の列車は、k 分になったら出庫線へ入ろうとする。
2. 区間を終えた列車（入った分＋所要分）は、次の区間が空いていれば、同じ分のうちに入る。
3. 空いていなければ、今の区間に残って待つ。待つ間はその区間を占有し続ける＝後ろの列車を塞ぐ。
4. 同じ区間に同じ分に入りたい列車が複数いたら、出発順が早い列車が先。
5. 駅を出た時点で、その駅の工程が料理に加わる（steps に追記）。通る順番＝工程の順番。
6. 最終区間を終えた分に配膳駅へ到着する。配膳駅には何台でも入れる。

## 焦げ

- 火の駅（焼く・煮る）で、仕上がり（入った分＋調理時間）から burnGrace(=1) 分を超えて出られなかったら焦げる。
- 切る駅は何分待っても焦げない。駅の手前の線路で待つのも焦げない。
- 判定は「駅を出る瞬間」。典型的な原因は、出口の線路が前の列車でふさがっていること。

## 成功・失敗・星

- 列車ごとに注文が決まっている（trains[].order）。成功＝工程が注文と同じ＋焦げていない＋到着 ≦ 締切。
- 失敗の種類と優先順位：焦げ(burnt) ＞ 工程違い(wrong) ＞ 遅れ(late)。1列車につき1つだけ報告する。
- 面クリア＝全列車が成功。完食時刻（finish）＝最後の到着の分。
- 星：finish ≦ par なら★★★、≦ par+1 なら★★、それ以外のクリアは★。見本を使ったクリアは★まで。失敗は0。

## プレイヤーの状態と経路

- order：列車IDの並び（出発順）。choices：列車ID → { 分岐ノードID: 次のノードID }。
- 経路は buildPath(level, choices[列車ID])。未指定の分岐は edges 配列の先頭の出口になる（これが「初期設定」）。
- 初期状態：order は trains の並び、choices は空。

## 料理名（lib/recipes.js）

食材：carrot 🥕にんじん／beef 🥩牛肉／fish 🐟魚／egg 🥚卵。工程：cut 🔪切る／grill 🔥焼く／simmer 🍲煮る。
料理（食材:工程列）：carrot:grill 焼きにんじん／carrot:simmer にんじんの煮物／beef:grill ステーキ／beef:cut>grill ひと口ステーキ／beef:grill>cut ローストビーフ／beef:cut>simmer 角煮／fish:cut お刺身／fish:grill 焼き魚／egg:simmer ゆで卵。
表にない組み合わせは「なぞ料理」。注文票と列車カードには、料理名と工程アイコン列を必ず並べて出す。

## 結果の文（原因を必ず出す）

timeline[列車] の各区間は { enter, ready, leave, waited, blockedBy } を持つ。waited>0 の区間が「待たされた場所」、blockedBy が相手の列車。

- 焦げ：「🔥焼く駅で、仕上がってから{n}分待たされて焦げた。出口を『{相手の料理名}』の列車がふさいでいた」
- 工程違い：「通った駅は 🔪→🔥。注文は 🔥 だけ」（通った工程が空なら「どの駅も通らなかった」）
- 遅れ：「{料理名}が{by}分遅れ。{場所}で合計{n}分待った（先にいたのは『{相手の料理名}』）」
- 成功：「{料理名} {到着}分（締切{due}分）」
- 場所の呼び方：駅の区間は「🔥焼く駅」。線路の区間は行き先で呼ぶ（「🔥焼く駅の手前」「配膳駅の手前」「分岐の手前」）。
- 面の結果の一行：クリアなら「完食！ {finish}分」と、最短なら「最短ダイヤ！」。失敗なら、失敗した料理の数。

## 見本のダイヤ

同じ面で2回失敗すると「見本のダイヤを見る」を出す。押すと solution の order と choices を画面に反映する（自動発車はしない）。
反映した状態で発車してクリアしたら、星は1つにする。進み具合には usedSample を記録する。面を切り替えたら失敗の数は0に戻す。
