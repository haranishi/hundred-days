## 6. 撮影の疑い

1. **全長画像の途中にある固定帯・ボタン**  
   指定された全長画像には紺のヘッダーが途中に現れる。面6の全長画像では組み直すも途中にある。追加確認した横向き全長画像では発車がカードに重なる。依頼書で説明された合成影響に該当し、これらを実画面の重なりとして減点していない。

2. **`07b-l2-sample-result.png`の形式**  
   `full`の表記がないが、画像は全長形式で、途中に固定帯がある。内容評価には使ったが、844pxの画面内配置や固定位置の判断には使っていない。

3. **面の「initial」とスクロール位置**  
   面3以降の複数画像ではタイトルや注文が途中から始まる。375pxの面6も同様。名称だけで「初期表示から内容が消えている」とは断定しない。画面端の切れは、写っているスクロール位置での視認性として評価した。

4. **再生中の列車・駅の重なり**  
   面1と面4の列車表示は駅に重なる瞬間がある。アニメーション途中の可能性があり、恒常的な欠損とは扱わない。ただし、その瞬間に番号・食材・工程を判別しにくい点は所見に含めた。

5. **横向き初期画面の発車ボタン**  
   通常の`844x390-00-start.png`では上端だけ、選択後の通常画像では全体が見える。常時操作不能とは断定しない。撮影位置またはスクロールに依存する配置の可能性があり、初期表示での実確認が必要。

6. **「null」は撮影影響では説明しにくい**  
   通常のスマホ画像とPC画像の複数状態で、結果見出しと列車結果の間に同じ文字が出る。合成画像だけの現象ではなく、画面上の不要表示として評価した。

7. **速度・フォーカス・スクロール後の到達性**  
   静止画では実速度、フォーカス表示、画面外の操作へ到達できるかを確認できない。未確認事項を操作不能・速度良好・アクセシビリティ適合と断定していない。
