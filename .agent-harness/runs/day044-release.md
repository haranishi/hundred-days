# Day044 架空3Dデモの公開前検証

2026-09-20。本人のDay44公開・PR作成・マージ依頼に基づく工程。
前の試作・監査記録から、公開対象を架空デモ専用へ変更した。

## 公開対象

- 5路線・48編成の3Dミニチュア。実運行・実ダイヤとは連動しない。
- 列車選択・追従・前方視点・地区移動・回転・拡大・路線切替・停止・速度変更。
- アプリと新規静止画のみ。Claude動画制作・X投稿・実データ接続は未実施。

## 権利監査への対応

- H1：東京タワー・東京スカイツリーのモデルとラベルを削除し、画像を再撮影した。
- H2・H3・M1：実データ取得を公開対象外とした。フロントエンドに運行API呼出しなし。
  本番ハンドラはキー・確認フラグに関係なく503・DEMO_ONLYを返す。
  実データの用途・二次提供・表示義務・期限は未解決で、将来の有効化前に別途確認する。
- M2：59駅の座標をWikidata P625（CC0）のデータへ置換。取得日・項目ID・版を同梱。
  独立レビューが全59件を公式APIと照合し、吉祥寺の版番号の転記ミス1件を修正した。
- M3：動画・音源なし。画像はアプリの1440×1000px画面。通知・タブ・別案件情報なし。
- Three.jsのMIT全文を同梱し、出力にも存在する。外部モデル・画像・配信フォントなし。

## 修正と限界

初回の全体単体はテスト入口不足で失敗。既存Dayと同じ入口を追加して成功した。
ネイティブselectのキー選択は自動操作環境で再現せず、正常と断定しない。
代替の標準ボタンを実装して、キーボードだけで列車を順に選べる経路を検証した。
タッチ試験は不要な別画面の描画を終了し、3D初期化の待機を他の試験と統一して成功した。
これらは公開工程の第2検証で成功。以前の試作の保留項目を成功に書き換えていない。
Safari・Firefox・iPhone実機は未検証。法的な非侵害保証ではない。
PR・CI・本番公開の結果はGitHubのPRとActionsに記録される。
