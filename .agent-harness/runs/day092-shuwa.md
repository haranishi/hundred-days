# Day092「てことば」の作業記録

2026-11-13。登録なし・無料で、日本の手話の指文字・数字・あいさつを1日5分ずつ覚える入門Webアプリ。公開先は https://rairakku.com/100days/day-092-shuwa/。この記録は、公開の手順と、事実と権利の確認の証拠。

## 公開の構成（Day089 と同じ、元のコードを同梱する形）

- `day-092-shuwa/` に、組み立てた本体（`index.html`・`assets/`・`mediapipe/`・`icons/`・`shared/`）と、元のコード（`source/`・MIT）を置く。`source/` は配信しない（`scripts/lib/dist-files.mjs`）。
- 組み立ては `source/tools/build-day092.mjs`。相対の住所（`base: './'`）で組み、サブパスの下でも動く。
- カメラ判定（任意）は、MediaPipe の wasm とモデルを同梱して端末の中で動かす。そのため、Day092 のパスにだけ、wasm の実行（CSP の `wasm-unsafe-eval`）とカメラの許可（`camera=(self)`）を付けた（`scripts/build.mjs`）。ほかのDayの設定は変えていない。
- 共有の欄は全アプリ共通の `shared/share.js`。最初の画面と記録の画面の「このアプリを共有する」から、共有の窓を開く。
- 元のコードのうち、作業の生ログ・調査の生データ・採点の画像は入れていない。入れたファイルに、手元の絶対パスと個人のメールアドレスは残っていない（アプリ側の `npm run publish:check` で確かめる）。
