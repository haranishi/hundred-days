# Day68 第1話「映像の嘘」実行記録

本人の「会話を増やしても物語が足りない」という評価を受け、相棒を探す話へ作り直した。
第1話は約束→伝言→駅の探索→追及→鍵→閉鎖ホーム→再会まで。面白さの本人評価は未確認。

## 実装
- 待合室・閉鎖ホーム・港の映像を新規制作。人物画と独自の3D鉄道を再利用。
- カメラと発車案内はどちらからでも調査できる。手がかりを二つ選び、理由とともに示す。
- 正解で栞の言葉と関係が変わり、鍵が増え、別背景の閉鎖ホームへ入れる。
- 冒頭と再会の返事、信頼を伝える方法を選べる。冒頭の返事は後の言葉に戻る。
- 栞の証言中に港の映像を表示。カメラの記録は故障した壁時計と区別する。
- 進行・証拠・選択・会話を保存。旧版はclassic.html、旧保存データはそのまま保持。
- 音は任意の合成音。列車の再現時刻を動かしても物語の時刻は進まない。

## 改善の経過
1. 初回：誤答・保存・完走を確認。写真の構図、画面下端、操作寸法を調整。
2. WebKit：クリック時のactiveElementに頼らず、開いたボタンをイベントから記録して焦点を復帰。
3. 体験と画面：証言中に映像を表示し、扉ラベルと発見通知を顔から離した。最終3幅を再撮影。
この3周で終了。旧自己採点を、今回の面白さの根拠にしない。
