## 発見された欠陥・改善指示 TOP5

### 1. 時間切れを「全罠の契約成立」にすり替えるな

**重大度：高。** `app.js:172–175` は現場の状態を無視して全罠を加算する。第1現場では定期と補償を外していてもタイムアウトの結果は¥5,530。第3現場でも無料キャンセルのプランを選んだまま予約を確定しなければ、¥18,000の罠を踏んだ扱いになる。未注文・未契約で請求される根拠も画面から分からない。

ゲームの都合による失敗を、実在のダークパターンのように説明している。これは「騙された悔しさ」ではなく、判定への不信を作る。時間切れはミッション未達として区別し、請求は実際に確定した選択に対応させること。誤操作した罠名・その条件・加算額を失敗画面に個別表示すること。

**再検証条件：** 第1現場で両オプション解除後に待つ、第3現場で安全プラン選択後に待つ。どちらも未選択の罠の料金を請求しない。

### 2. 失敗を学習に変える最短経路がない

**重大度：高。** 失敗モーダルにも途中HUDにも「この現場を再挑戦」がない。最初のミスを理解しても、残り4現場を処理しなければ試し直せない。結果画面の `result-mobile.png` でも共有が先に出て、リトライは画面下に続く。失敗した人を共有へ先に誘導する優先順位は、遊び直す体験を支えていない。

現場単位の練習リトライを追加し、失敗から2タップ・3秒以内で同じ課題へ戻すこと。初回は安全な操作を一つずつ試せる導入を設けること。第1現場に二つの罠・確認ダイアログ・短い制限を同時投入しておきながら、第2現場を1タップにする順序は整理すること。

**再検証条件：** 第1・第4現場で故意に失敗し、2タップ・3秒以内で同じ現場を操作できる。練習と正式スコアの扱いも明示する。

### 3. 教材を読むほど最高ランクから遠ざかる

**重大度：高。** `startTime` はゲーム開始、`endTime` は全解説後の完了で取り、その差をランクへ渡す（`app.js:113, 236–243`）。解説モーダルで各現場のタイマーは止まるが、総捜査時間には読む時間が入る。関数検証では同じ¥0でも30秒はS、90秒はA。`result-mobile.png` の12秒・Sは答えを指定した自動撮影経路の結果であり、初見の理解力の証拠ではない。

防犯知識を読ませたいのに、評価制度は解説を飛ばす人を優遇している。操作中の時間と閲覧時間を分けること。速度だけで「神の洞察眼」を与える設計を改め、罠を特定する理解確認や初見での正確さを報酬へ結び付けること。

**再検証条件：** 同じ正解・同じ操作時間で、解説を即閉じる場合と60秒読む場合の成績が一致する。

### 4. 重複確定と画面外の導線を放置している

**重大度：高／要ブラウザ再現。** `recordStageResult()` は現場の確定済み状態をチェックせず、呼ばれるたびに加算・記録する。関数を2回呼ぶと同一現場が2件・被害額2倍になることを確認した。結果モーダルは背後の操作を `inert` にせず、フォーカス移動・トラップもない。実際のキーボードで背後を再操作できるかは未確認だが、防御がない事実は残る。

また、指定の第4現場の画像では最終ボタンが画面外。HUDは固定されず、スクロールすると残秒・目的を失う。結果モーダルの `.modal-card` に `max-height` とスクロール制御がなく、短い画面高での収まりも未保証。**この時点で進行不能を実機再現したとは断定しない。**

現場の確定を一度きりにし、確定後の背景入力を遮断すること。結果ダイアログへフォーカスを移し、閉じた際の戻り先も管理すること。短い画面でも主要ボタンへ到達できるスクロール領域を設計すること。

**再検証条件：** 同一結果の重複呼出しで記録・金額が増えない。Tab・Enter・Spaceで背景の請求操作が再発火しない。390×667と横向きの低い画面で全モーダルの主要操作に到達できる。

### 5. 「5種類ある」を繰り返し遊べる設計と混同するな

**重大度：中。** 第1現場はチェックを触らず単品購入ボタンを押すだけでも¥0となる（`app.js:415–417`）。これはボタンの文言とは整合しており、誤判定ではない。しかし定期解除・引き留め突破を経験せず「完全看破」が得られる。第4現場の二重否定も選択肢の括弧に答えがあり、第5現場は規約を開いてチェック1個。正解位置と文言を覚えれば探索は終わる。

第2現場の逃げる×だけをランダムにしても、問題そのものは変わらない。プラン条件、正解位置、文言の組合せを変え、同じ判断原則を別の条件に使わせること。チェック解除・安全な契約・最終確定などの小さな成功を個別に返すこと。第3現場の通知はタップを遮断しないが、画像では警告文に重なっており、情報を読む難しさと判断の難しさを整理すること。

**再検証条件：** 3分以上、少なくとも2周操作し、2周目にも条件を読み直す必要がある。成功が「前回と同じ位置を押した」だけにならない。

**20/20点を正当化する証拠はない。今回の暫定7点も実プレイによる最終採点ではない。** 優先すべきは装飾の追加ではなく、請求判定・リトライ・時間計測の修正と、その後の独立した5〜10分のブラウザ評価である。人間の最終プレイ判定も未実施。現段階で体験合格・公開可能とは判定しない。
