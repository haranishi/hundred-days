# Day089「FROSTLINE」の作業記録

2026-11-11。ブラウザで滑る、オリジナルの雪山ゲーム。公開先は https://rairakku.com/100days/day-089-frostline/。この記録は、公開の手順と、事実と権利の確認の証拠。

## 公開の構成（Day082 と同じ、元のコードを同梱する形）

- 最初は外部Day（`day89.rairakku.com`・コード非公開）で用意した。本人が「コードは公開してよい。100日チャレンジのリポジトリに入れる。MIT」と決めたので、このリポジトリの中で配る形に変えた。
- `day-089-frostline/` に、組み立てた本体（`index.html`・`assets/`・`world/`＝山のデータ約32MB・`models/`・`about/`・`licenses/`）と、元のコード（`source/`）を置く。`source/` は配信しない（`scripts/lib/dist-files.mjs`）。
- 組み立ては `source/tools/build-day089.mjs`。相対の住所（`--base=./`）で組み、サブパスの下でも読めるようにした。山のデータ・模型の読み込みも、相対の住所に直した。
- 共有の欄は、全アプリ共通の `shared/share.js`。ゲームは全画面なので、共有の窓（`dialog`）の中に置き、題字の画面・一時停止・読み込み中の表示の「共有」（読み上げの名前は「このアプリを共有する」）から開く。
- 元のコードのうち、作業の生ログ・試作・手元専用の道具・他の道具の雛形は入れていない。入れたファイルに、手元の絶対パスは残っていない。

- 名前：J-PlatPat で確認した。本人の候補「シュプール」は、集英社の登録商標（第5498388号・存続）の指定に「オンラインゲームの提供」「家庭用テレビゲーム機用プログラム」が入っていたため使わない。
  「FROSTLINE」「フロストライン」は、第9類・第41類に登録が無い（登録5件は第18・25・30類）。海外のゲーム『DayZ』の拡張版「Frostline」（米国で「DAYZ FROSTLINE」として出願）があることは、本人に伝えた。
