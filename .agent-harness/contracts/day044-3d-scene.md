# Day 044 — 東京の電車を眺める3Dシーン

## 目的と変更範囲

2026-09-20の補足を反映。目的は乗車案内ではなく、東京周辺の街・線路・動く電車を立体で眺めること。
旧契約day044-train-here.mdの駅選択・乗車候補中心の要件を、この3Dビューの要件で置き換える。
変更範囲はDay044本体、対応テスト、メタデータ、出典、必要な配信設定。
データ接続の安全策は維持する。公開・commit・push・登録・規約同意は範囲外。

## ユーザーストーリーと受け入れ条件

- 東京の鉄道に関心がある人が、街の中を複数路線の列車が走る様子を見渡せる。
- 実際に奥行きのある車両・線路・建物が描画され、カメラを回転・拡大できる。
- 列車を選ぶと、街並みと走行方向がわかる距離でカメラが追跡する。
- 駅や地区に視点を移し、全体表示へ戻れる。路線の表示を切り替えられる。
- 未接続の実データと架空の動作サンプルを混ぜない。古い実位置は表示しない。
- 390／768／1440px、キーボード、動きを減らす設定、WebGL非対応時を確認する。

## UX5階層

1. 戦略：東京の鉄道網を動く風景として理解し、好きな電車を眺める。
2. 要件：WebGLの3D、複数路線、編成の形、カメラ操作、追跡、地区視点、表示切替、データ状態。
3. 構造：街の全景→列車選択→追跡／近接視点→全景。経路検索は置かない。
4. 骨格：3Dを画面の主役にし、路線・視点・再生の操作を小さなパネルで重ねる。
5. 表層：昼のミニチュア都市。白系の建物、路線色の車両、陰影で立体を伝える。

## 表現とデータの境界

- 山手線・中央線・総武線・京浜東北線・埼京線の都心側区間を3D化する。
- 駅の代表座標を使った概略の線形。高さ・編成・街並みは見やすさを優先した独自の簡略モデル。
- 実測の建物・軌道・高架高さを再現したものではない旨を画面に表示する。
- Three.jsを固定バージョンで自己配信。巨大な外部モデルの常時取得は行わない。
- ODPTの利用登録・用途確認・キー設定は未解決。接続済みとは表示しない。
- 既存中継で扱える実データは山手線のみ。ほかの路線は実応答未検証のためデモだけにする。
- 実時刻表・到着予測・乗車案内は今回の目的から外す。

## 検証

経路の連続性、編成の追従、環状／折返し、路線非表示、停止／速度変更、鮮度を単体検証。
3Dの実描画・回転・列車選択・追跡・再生・復帰・デモ退出をブラウザで確認する。
全3幅の画像を見て、実装と別の読み取り専用セッションで評価する。
最大3周、同一失敗2周で残件を返す。Claudeは認証できるまで未実施として扱う。
