# Day095 制作契約

目的: 3Dの盆栽を、指で「切る・曲げる・芽を摘む」、時間を進めて育てる。登録なし・無料・外部通信なし。ログインなしでスマホの指だけで遊べる。
仕様: `.kiro/specs/day-095-bonsai/`（requirements・ux・design・interfaces-core/view/app・visual-direction・tasks・verification）。
変更範囲: `day-095-bonsai/` 一式、専用のE2E、根のREADME一覧・THIRD_PARTY_NOTICES、仕様・検証記録。
対象外: 他Dayの機能改修、アカウント、オンライン保存、他人の盆栽、売買、外部の3Dモデル・画像・音・書体。
成功条件: 主要フロー（見る・切る・曲げる・芽摘み・時間・元に戻す・保存・写真・共有）と失敗からの復帰、3幅の表示、指・マウス・キーボードの操作、共通検査と公開ゲートが成功する。
役割: 設計・統合・検収は親（Claude）／木のモデルは Codex／描画は Grok／卓と鉢は Antigravity／画面と操作は Codex／体験の採点は Grok（実際に遊ぶ）／見た目の採点は Antigravity と Grok（画像のみ）／独立コードレビューと文言の事実の照合は Codex（読み取り専用）。
検証: 単体・ブラウザ・実画面の目視・固定ショット。体験と見た目の採点は最大3周、同一指摘が2周続いたら停止して残件を報告。担当の「完了」は受け取らず、親が試験を再実行して確かめる。
通常作業: 分離ブランチでの仕様・実装・検証・commit/push/PRまで。git の操作は親だけ。マージは本人の承認を得てから。X投稿は本人。
破壊的変更・追加課金（Meshy 等のクレジット消費）・秘密情報の外部送信は行わない。
