# Day64 公開前の権利確認・PR・プロモーション動画

2026-10-12。ユーザーは100daysへのPR作成とマージを依頼し、その前に規約・著作権・法律を調べること、並行してプロモーション動画を作ることを指定した。

- 目的: 配布する資料・データ・依存ライブラリ・映像を確認し、必要な修正と検証を済ませてDay64を公開リポジトリへ統合する。
- 範囲: Day64の出典・利用条件・表示の確認、公開前チェックの指摘修正、公開用ファイルの整備、実画面を使った字幕付き縦型動画と一覧用デモ、PR本文とマージ。
- 対象外: 有料素材の購入、漏えいした個人情報の取得、問い合わせやSNSへの送信、他のDayの仕様変更。動画には本製品の画面、独自字幕・独自合成音源を使う。
- 権利確認: 現在の公式規約と法令・公的説明を参照し、原文の転載、データベースの構成、出典・加工表示、商標、プライバシー、表現の正確さを配布実体と照合する。公開されていることだけを利用許諾と扱わない。
- 成功条件: 権利確認の根拠と対応が文書で追える。公開前チェック・必要なテスト・ビルドが通る。動画の数字と実画面が一致し、映り込み・第三者素材・メタデータを確認できる。PRのCIを確認してマージし、公開URLの応答と主要操作を確認する。
- 許可: 今回のユーザー指示によりcommit・push・PR作成・mainへのマージを実施する。mainへのマージに連動する既存の公開ワークフローを含む。SNSへの投稿は別の指示が必要。
- 保存: 大きな撮影素材・ビルド・検証出力は、識別と空きを確認した外部SSDに置く。既存の入力と未コミット変更を容量確保のために削除しない。
- 検証: 全データ・ライセンスの機械点検と変更ファイルの読み取り、Wasmと代替処理、実ブラウザ、公開成果物、動画フレームと音源・メタデータを確認する。自己点検を独立レビューと呼ばない。
- 修正は最大3周。同じ製品不具合が2周続く場合や、解消できない公開阻害がある場合は、根拠と残件を本人へ報告する。法律上の保証や弁護士の意見として結果を表現しない。
