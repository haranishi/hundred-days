# Day64 Obsidianのデザインメモを踏まえたUI改善

2026-10-11。本人の依頼は「もっと分かりやすい形で再現」「ObsidianのUI・デザインメモを参考に探す」。調査を、継続中のDay64の画面改善へ反映する。

- 目的: 初めて訪れた人が、検索→記録選択→概要・数値・出典の確認へ迷わず進める。
- 参考: Obsidianの「UI_コンポーネントとパターン」「レイアウト・視覚的階層」「データ可視化の基礎」「アクセシビリティとUXライティング」「徹底解剖_デザイントークン集」。関連する公開例のDatawrapper・Linearも確認。
- 範囲: Day64のHTML/CSS・表示用JS・関連ブラウザ検査・説明と検証記録。既存の13,550記録・Rust検索・ソート・分割詳細を引き継ぐ。
- 方針: 主役となる検索、全体と現在の検索結果を区別する見出し、余白と文字サイズの段階、直接ラベル付きの2Dグラフ、段階的な補足表示。明るい背景を初期案とし、本人の回答があれば反映する。
- 対象外: 新しいデータ収集、フレームワーク移行、他のDayの変更、Obsidianメモの編集や内容の丸ごと複製。
- 成功条件: 390/768/1440pxで検索が見つかり、単位・地域を区別できる。検索語と個別条件を解除でき、一覧の選択が詳細・原資料に対応する。ページ送り・3D/SVG・キーボード・取得失敗からの復帰を維持。
- 検証: 既存データ/実Wasm検査、意味のある新UI導線検査、関連する既存ブラウザ検査、Day64とルートビルド。3幅の実画像を閲覧し、実ブラウザで主要操作を確認して自己評価を記録。独立レビューと自己レビューを区別する。
- 改善は最大3周。同じ製品不具合が2周続けば原因・残件を本人へ返す。
- commit・push・PR・公開・外部送信は今回の許可に含めない。ローカルの実装・ビルド・配信ファイル同期まで進める。
