# Day058 名所くみたて早押し（旧名：ミニチュア観光名所バトル）

目的：別プロジェクトとして作っていた早押し名所当てゲーム（71名所版）を、Day58として公開する。公開前の見直しで名前を変え、3つの名所を外して68名所にした。
範囲：day-058-meisho-kumitate（source とビルド結果）、Day索引、配信の除外設定、Day58のCI、対象テスト、第三者表記、検証記録。
対象外：ネット対戦（部屋ごとのサーバーが要る）、元リポジトリの仕様変更、既存Dayの仕様変更、SNS投稿。
許可：本人がDay58としての公開と、PR作成からマージまでを明示指示（2026-10-05）。mainへのマージによる既存CIの公開もこの依頼に含める。
最大3周、同一失敗2周で残件を本人へ返す。

## ユーザーストーリーとUX5階層

ゲーム本体の設計は元のプロジェクトのものを引き継ぐ。Day58で足した部分だけをここに書く。

- 100日チャレンジの一覧から来た人が、登録なしで1ゲーム（8問・数分）遊び、一覧へ戻るか、アプリを人に送れる。
- 戦略：遊びの入口（ひとりで・ふたりで）を目立たせたまま、一覧への帰り道と共有を見つけられるようにする。
- 要件：一覧へ戻るリンク、サイト共通の共有欄（X・LINE・端末の共有シート・リンクのコピー）、結果画面の得点シェアは残す。
- 構造：タイトルの上に帯を1本置き、左に「100 DAYS / 058」、右に「共有する」。共有欄は窓（dialog）で開く。
- 骨格：帯の2つは44px以上。共有の窓は画面幅に収め、見出しは1つにする。
- 表層：ゲームの白い札（題字の下の説明と同じ地色）に合わせ、遊びのボタンより弱く見せる。

## 受け入れ条件

- ネット対戦の入口と、サーバーとの通信のコードが公開物に無い。
- 東京タワー・通天閣・ウルルと前の名前が公開物に無い（運営者・管理機関が外観や似姿の利用に許可を求めているため。前の名前は既存作品と紛らわしいため）。
- 本番と同じCSPで開き、エラー・CSP違反・外部への通信が0件。外へ出るのは本人が押した出典ページと共有の投稿画面だけ。
- ひとりで8問を通して結果へ進み、「もう一回」で1問目に戻る。ふたりででは2つの押すボタンが並ぶ。
- 390×844・320×568・844×390・1440×900で横にはみ出さず、帯と遊びのボタンが44px以上で画面内にある。
- サイト共通の共有試験（OGP・canonical・共有欄・枠のコントラスト・押せる大きさ）を通る。
- ソースから作り直したビルド結果が、リポジトリのものと一致する（Day58のCI）。
- 独立した読み取り専用レビューを実施する。実機で確かめていないことは区別して書く。
- PRのCI合格後にmainへマージし、公開URLと主要操作を確認する。
