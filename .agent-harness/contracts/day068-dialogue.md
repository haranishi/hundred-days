# Day68 会話と追及の追加
- 依頼：面白さを増やし、人物が話す場面とセリフを入れる。
- 観察：前版は数表の比較が中心。本人から「つまらない」との評価があり、前版の自己採点では面白さを確認できていなかった。
- 目的：人物に質問し、時刻表の証拠を選んで反証し、隠していた事情と切符の行方を知る。
- 変更範囲：Day68の画面・会話データ・追及判定・人物素材・テスト・説明、Day68の権利表記。
- 対象外：他のDay、外部公開、音声API、認証、実在の鉄道・人物。
- 成功条件：3人の大きな人物画、話す／驚く表情、送れるセリフ、選択質問、会話の読み返し。
- 成功条件：人物だけでは正解せず、証拠も選ぶ。誤った人物・証拠から再調査できる。
- 成功条件：各章の追及後の告白、3章をつなぐ切符の結末、調査進捗が見える。
- 制約：会話で時刻表の事実を改変しない。動き軽減・消音・保存不可・2Dでも遊べる。
- 検証：既存の到達判定、新しい証拠判定、会話→追及→告白→次章、途中切替の回帰試験。
- 実画面：390・768・1440px、Chromium・WebKit、キーボード、初回と再挑戦。
- 体験→UIの自己点検を行い、証拠をruns/day068-dialogue.mdへ残す。改善は最大3周。
- commit・push・PR・デプロイ・共有先への送信は行わない。
