# Day047 v2 2周目契約（面・画面・録画証拠＝Claude Opus）
前提: 1周目の採点 `（評価用の作業フォルダ）/score-round1.md` を読む（TOP5 の 1〜4 があなたの担当分を含む）。境界 day047-v2-boundary.md は据え置き。所有ファイルも1周目と同じ。物理担当は同時に自動操作の改良（1-1でうさぎを踏む／collectで全回収）と観測ログの整備をしている＝待たずに進める。
やること:
1. **1-1 で「踏んではずむ」を必ず経験させる**（採点項目1）。最初のうさぎを、通常の走り込みで自然に上から踏める配置に（例: うさぎの手前に1マス段差を置き、段差から降りる軌道が敵の上面に乗る）。踏んだ反動で乗れる棚をすぐ右に置き、棚の上に米俵3個。回避路（下を抜ける）も残す。踏みの説明は最初の敵が画面内にいる間に出す。
2. **初登場を1面1つに戻す**（採点項目5）: 1-2 の「J と穴」、3-3 の「B と氷」を分ける（1-2 は穴を無くして J だけ、3-3 は B の区間を雪床にして氷は 3-4 から）。
3. **全回収の経路を成立させる**（採点項目6）: 各面で、上段の米俵3個と任意餅へ「入る手段」と「地上へ戻る道」が実在するように配置を直す。手段は J・%・F（滑空）・S（助走）・踏みの反動のいずれか1つに絞り、面頭の1行説明にその手段を書く。あなたの検証は「新記号を `.` にした地形で主路到達」（1周目と同じ）に加え、**現在の `createAutopilot(level,{mode:'collect'})` で面ごとに米俵n/6・任意餅を測って報告**する（自動操作は直さない。取れない面は「人ならどう取るか」を1行添える）。
4. **早駆けの目標を締める**: 各面の `parTicks` を「safe自動操作の所要tick×1.25 を120の倍数に切り上げ」に置き換え、`level-data.js` の各面に `// par: 旧1440→新840（safe 656tick×1.25）` の形で旧値・新値・理由を残す。
5. **結果画面の浮き文字**（採点項目6）: clear 時は浮き文字を全部消し、結果には面内得点だけを出す。`collectPops()` が clear の総得点を拾わないようにする。
6. **録画証拠を残す**（採点項目2・7・8・9 の「未確認」を埋める）。Playwright（`<リポジトリの node_modules/playwright/index.js>`・ミニHTTPサーバー経由・`window.__day047.setManual(true)`＋`advance(ms)` で時計を進める）で次を撮り、`（評価用の作業フォルダ）/round2/` に置く:
   - `rabbit-seq.png`: 1-1 のうさぎ「待機→予告(!)→跳ぶ→踏まれて退場」を0.2秒刻みで8コマ横並び（連番を1枚に合成）
   - `boar-seq.png`: 3-3 のイノシシ「待機→予告→突進→休息」を同様に8コマ
   - `miss-restart-seq.png`: 1-5 で野犬に当たってミス→0.8秒後に再開、の前後を0.2秒刻みで8コマ
   - `ending-4-5.png`: 4-5 をクリアした直後の締め文（訪問数・札合計）の画面
   - `select-after.png`: 面えらびに戻り、お札とベストが付いた状態
   - `ability-F.png` / `ability-S.png`: 能力取得直後の HUD と足元アイコン
   各画像の撮り方（面・開始tick・入力）を `（評価用の作業フォルダ）/round2/README.md` に書く。
7. `README.md`/`REQUIREMENTS.md` を同期（100行以内）。
