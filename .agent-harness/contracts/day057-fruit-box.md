# Day057 夜店のくだもの箱

目的：既存の果物合成ゲームを、独自の表現・音楽と操作改善を加えてDay57として公開する。
範囲：day-057-fruit-box、Day索引、配信CSPの必要箇所、対象テスト、検証記録。
対象外：既存Dayの仕様変更、元リポジトリの更新、SNS投稿。
許可：本人がPR作成・マージを明示指示。mainへのマージによる既存CIの公開もこの依頼に含める。
最大3周、同一失敗2周で残件を本人へ返す。

## ユーザーストーリーとUX5階層
- 暇つぶししたい人が登録なしで果物を落とし、合成の手応えと記録更新を楽しむ。
- 戦略：縦持ちでもすぐ始められ、短い休憩で遊べる。
- 要件：合成・加点・ベスト保存、NEXT、危険予告、再挑戦、BGMと効果音の独立設定、共有。
- 構造：1画面。中断は一時停止、終了は結果と再挑戦。
- 骨格：得点→木箱→NEXT・進捗・44px以上の操作。一時停止に音量設定。
- 表層：藍と提灯色、顔のない果物画、外部素材を使わない軽い夜店の音。

## 受け入れ条件
- 公開名・イラスト・音・進化順を公式作品から区別し、依存ライセンスを同梱する。
- ページ内のゲーム操作では外部通信しない。X・LINE・共有シート・コピーは本人操作。
- 390/768/1440pxで画面が欠けず、タッチ・キーボードで落下、停止、再挑戦できる。
- 音は操作後だけ開始。BGM/効果音/音量は保存し、中断・非表示で止まる。
- 合成・加点・危険判定・音停止の回帰検証、対象E2E、precheck、buildが成功する。
- 独立した読み取り専用レビューを実施。実機でない確認は区別する。
- PRのCI合格後にmainへマージし、公開URLと主要操作を確認する。
