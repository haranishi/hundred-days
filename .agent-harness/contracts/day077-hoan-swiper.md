## 受け入れ条件
1. **スタート画面＆段階的オンボーディング**：
   - 初回表示で「シフト開始（スタート）」主ボタン、モード選択（🎓10問研修／⏱️60秒ラッシュ）、3方向（←機内／↑預け／→没収）の視覚ガイド、および「🖐️ 1問おためし練習」が1画面内に明快に配置され、初見3秒で「何を押せば始まるか」が分かる。
   - ゲーム開始後の第1問にはコーチマーク（矢印と操作ガイド）が表示され、迷わず最初の仕分けを行える。
2. **2.5D空港保安検査レーンのビジュアルと操作手応え**：
   - 天吊り電光掲示板HUD、奥のX線スキャナーゲートと待機荷物、斜め立体ローラーコンベア、3D成形プラスチック検査トレイ、3方向の発光シュートパッドを備えた2.5D検査場ステージを構築する。
   - ドラッグ時のトレイ傾き・検印スタンプ（`CARRY-ON` / `CHECKED` / `PROHIBITED`）表示・送出アニメーションを実装する。
   - **「🔍 X線透視スキャン」** ボタン（および `Space` キー）でトレイ内の荷物の内部スペック（Wh数、電池取外し可否、液体容量ml、危険物種別）をX線モニター風に透視できる。
3. **判定フィードバックと復習の納得感**：
   - 仕分け直後に「直前に仕分けた品目・選んだ方向・正解の方向・国土交通省基準の理由」が検査モニターにはっきり残り、誤答時にはなぜNGなのかを確実に把握できる。
4. **独立ハーネス評価と品質ゲート**：
   - コード・仕様を見ない独立評価サブエージェントによる **体験評価（10項目×0〜2点＝20点満点）** と **画面評価（360/390/768/1440pxの全状態画像・10項目×0〜2点＝20点満点）** を実施し、指摘を修正して **両方16点以上かつ0点なし** を達成する。
   - 単体テスト、`npm run check`、`npm run publish:check -- --day 77`、Playwright E2E（`tests/e2e/day-077.spec.mjs`）をすべて通過する。
