# Day046 実装契約
目的：3Dの猫を押し続けて実在の速度を追い越し、光速の99.999%で時間の遅れを体験して結果へ進む。
対象：day-046-cat-lightspeed/、tests/e2e/day-046.spec.mjs、READMEのDay一覧、権利表、privacy、共有同期、検証記録。
対象外：git操作、公開、外部素材取得、外部API、E2E実行。precheck内部のgit読取は指定コマンドの既存処理としてのみ実行する。
成功条件：指定21段階、6世界、コード生成の猫と合成音、光速未満の加速、描画領域限定入力、Space/Enter開始・再挑戦、結果、保存、テスト登録。
検証：共有同期、build、test:unit、precheck。E2Eは作成のみ。実ブラウザ評価は未実施として区別する。改善は最大3周。
ユーザーストーリー：短時間遊びたい人が、押すだけで現実の速度と時間の尺度の変化を楽しめる。
UX戦略：桁・世界・速報の三つが加速の報酬。要件：1本の成功経路、アカウントなし、保存はベストと音設定だけ。
構造：開始→長押しと減速→99.999%で自動結果→再挑戦。骨格：上に速度、中央に猫と世界、下に押下ヒント、共有は描画領域の外。
表層：暗い観測画面にライム色の数字、牧場の暖かい色から宇宙の冷たい色へ。システムフォント、低ポリゴン、動きを減らす設定にも対応。
設計判断：約90秒の連続押下を基準。猫の時計をプレイ時間とみなす簡略モデル。音速後の遅延はゲーム演出で、音源自身に届く厳密な物理モデルとは区別する。
