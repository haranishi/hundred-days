# Day050 作品増補とプロモーション素材

## 範囲と順序
- 本人の依頼：クイズを先に増やし、その後にプロモーション動画とX文案を作る。
- 9作品から30作品を目標に増補。1回5問、4択、段階表示は維持する。
- 当初はローカル実装と素材制作。後続の依頼でPR作成・マージまで追加された（末尾参照）。SNS投稿は含めない。

## ユーザーストーリーとUX5階層
- 続けて遊ぶ人が、異なる画家・時代の作品に出会える。
- 解説を読みたい人が、図録で作品名・作者名から探せる。
- 戦略：正解数だけでなく、次の絵を見たくなる体験を増やす。
- 要件：実画像30点、出典付き解説、動機と鑑賞上の解釈の区別、図録検索。
- 構造：既存の5問フローを維持。検索は図録内に閉じる。
- 骨格：既存画面に作品数と検索欄を反映。空検索結果からすぐ復帰できる。
- 表層：既存の美術館デザインを維持し、実作品を主役にする。

## 検証と受け入れ
- 所蔵館ID・作品名・年代・画像・権利を照合。解説は一次資料を日本語で要約。
- 30点のファイル、ハッシュ、表示、全作品の図録からの閲覧を検証。
- 5問完走、保存、検索の一致・不一致、390/768/1440pxを確認。
- 内容の独立レビューと実画面確認を行い、問題があれば修正する。
- 増補後の実画面を使う動画を制作。動画冒頭は作品が見える動きのある場面。
- X文案は実装事実のみ。動画・本文は外部投稿せず、増補版の公開前は下書きと明記。
- 最終素材はGoogle Driveへ保存し、場所と検証結果をObsidianへ記録する。

## 結果
- 30作品・実画像・出典付き解説を実装。図録の検索、位置保持、閉じる操作を追加。
- 追加21点の内容・年代・実画像を独立担当が照合。低解像度画像1点を差し替え。
- 単体12件、最終E2E17件、全体単体2,154件成功・1件スキップ。ビルド成功。
- 390/768/1440pxを実操作し、検出した図録の位置リセットを修正して再確認。
- 30秒の1080×1920プロモーション、18秒の720×1280デモを作成。BGMは独自合成。
- 動画の先頭・場面一覧を目視し、30fps・音声・尺・音量・メタデータを確認。
- X本文237字相当と3返信を用意。投稿前に30作品版の本番確認と本人の最終確認を行う。
- 完成素材は指定保管先へ複製し、制作記録に場所を記載。SNS投稿は行わない。

## PR・マージ工程
- 2026-09-27、本人からPR作成と前回同様のマージまで依頼された。
- 既存のDay051追加を保ち、Day050の増補・素材・X文案だけをcommit・pushする。
