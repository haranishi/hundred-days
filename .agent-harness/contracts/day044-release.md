# Day044 デモ版の公開工程

2026-09-20。本人の依頼はDay44公開とGitHub PR作成・マージまで。
前工程の公開禁止はこの依頼の範囲で解除する。X投稿とClaude動画制作は今回の工程外。

## 目的と範囲

東京の5路線を眺める3D架空デモを公開する。実運行・実ダイヤには接続しない。
変更はDay044本体、対応テスト、出典、一覧、配信に必要な設定と工程記録。
権利確認の残る2ランドマークは外す。駅位置の作成根拠を追跡可能にする。
ライブ実装は将来用に保管するが、本番のエンドポイントは明示的に無効にする。
動画がないことを隠さず、今回の公開はアプリと静止画で行う。

## 受け入れ条件

- 初期状態から「架空デモ」と明示し、48編成の再生・停止・速度変更・追従が使える。
- 実データ通信・公式サービスの誤認・未確認ランドマークを公開版に含めない。
- 単体、390／768／1440px、キーボード、共有、WebGL障害時を検証する。
- 機密チェック、公開ビルド、独立した読み取り専用レビューを行う。
- Draft PRを作成し、必要なCIを通してからReady・マージする。保護ルールは回避しない。
- mainのデプロイと本番URL、主要操作、ライセンス・OGPを確認する。

新規アカウント登録・利用規約同意・API有効化・外部投稿はしない。
改善は最大3周。同一失敗2周の場合は原因と残件を本人に返す。
