# Day64 日本の不正アクセス関連記録を拡充

2026-10-11。依頼は「日本の侵入されたデータを、今の10倍・100倍くらいに増やす」。主担当が国内の公表情報を調べ、Day64の検索可能なデータへ反映する。

- 目的: 日本の企業・自治体・教育機関等の公表記録を増やし、不正アクセスやランサムウェアを年代・組織名・原資料からたどれるようにする。現状は国内201記録、外部侵入124・ランサムウェア4。
- 目標: まず国内約2,010記録を目指し、入手できる公表情報の実件数で判断する。20,100記録に届くと事前に断定しない。
- 調査: 国内インシデント公表アーカイブの固定コミット、国内事例一覧にある原発表リンク、企業・自治体の公表資料。年度集計の件数を個別事故へ水増ししない。
- 範囲: 国内データの取込・再生成、原因/確認状態の表示、取込台帳と出典表記、関連する検査・説明・ローカル配信物。他のDayと既存の米国台帳は変更しない。
- 品質: 原文を丸ごと配布せず、組織名・日付・URL等の事実項目を中心に収録。未記載の人数・原因、侵入と情報流出を区別。既存URLとの一致・明示された事案ID・同一URLの続報を整理し、残る同一事故の別公表を独立事故数と呼ばない。
- 成功条件: 実在する国内の追加記録と、その取込/除外理由が追跡できる。国内・侵入・ランサムウェアの件数を別々に報告する。既存の訂正値、出典、検索・ページ送り・遅延取得・Rustと代替処理を維持。
- 検証: 取込の判断を確認する回帰検査、全索引・分割詳細・実Wasm、通常ブラウザの主要導線、追加した国内記録を原資料と照合、Day64とルートのビルド、配信ファイル一致とローカルHTTP。今回はデータ拡充が中心で、不要なUI採点・長時間テストは繰り返さない。
- 改善は最大3周。同一の製品不具合が2周続けば、原因と残件を本人へ報告する。
- commit・push・PR・公開・外部送信・有料データ購入は今回の範囲に含めない。ローカル実装・検証・配信フォルダ同期まで進める。
