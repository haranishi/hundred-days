# Day 045：その撃ち方、読まれてる

## 目的と範囲

固定画面の宇宙船シューティングを1本追加する。敵の艦隊が自機の撃ち癖・居場所癖を覚えて、よけ・狙いに使う。
範囲はローカルでの実装・検証・一覧用素材まで。commit・push・PR・公開・X投稿は本人が行う。

## 成果物

- `day-045-read-your-shots/` の画面、ゲームロジック（`lib/`）、要件、利用説明、メタデータ、同梱素材
- 単体テスト（`tests/`・node:test）と `tests/e2e/day-045.spec.mjs`
- 共有部品の複製（`npm run shared:sync`）、READMEのDay一覧（`npm run index:sync`）、第三者素材の記録
- 一覧用の `screenshot.webp` と `demo.mp4`、検証記録（`.agent-harness/runs/`）

## 受け入れ条件

1. 説明を読まずに開始でき、最初のウェーブで必ず1隻は落とせる難易度から始まる
2. ポインタ1本でも、キーボードだけでも通せる。主要アクションは「撃つ」の1つ
3. 読まれ度・熱の帯・予測マーカーが常時見え、ひるみと狙いの理由が画面で追える
4. 結果に点・ウェーブ・講評1行・ベストが出て、再挑戦が1操作・3秒以内
5. 外部通信0本。保存は端末内のベストとミュートだけ。名前・履歴は残さない
6. 素材が読めなくても図形描画で遊べる
7. 単体・E2E・`npm run build`・`npm run precheck` が通る。既存Dayのテストを壊さない
8. 体験評価（実プレイ・10項目）16点以上かつ0点なし → UI採点16点以上。上限3周

## 実装方針

既存のHTML/CSS/JavaScript構成（依存ゼロ・ESモジュール・Canvas 2D・Web Audio合成）。
乱数はseed付きで、E2Eとデモは `?seed=` と `window.__day045` で決定的に動かす。
既存作品の名称・絵・音を使わない。素材はAI画像生成で本作専用に作り、公開物に既存作品の固有名を書かない。

## 対象外

バリケード・ボス・アイテム・ランキング共有・アカウント・課金・外部API。
