# Day64 国内記録の追加取込

2026-10-12。ユーザーの「もっとデータを入れ込んで」「続きを実行」に対応する。主担当が調査からローカル反映・検証まで進める。

- 目的: 現在の日本2,522件・全15,871記録へ、出典を追える国内の過去の公表を追加する。実在する収録数で結果を報告する。
- 範囲: 公開資料の取得、再実行できる取込処理、取込・除外・既存記録への統合台帳、分割詳細・索引の再生成、出典表記、関連する検査とローカル配信物。
- 品質: 原資料URL、組織名、日付を確認できる記録を対象とする。本文を丸ごと配布しない。未確認の人数・原因を推定せず、公表日・報道日・発生日を混同しない。既存の確認状態と訂正値は自動で上書きしない。
- 重複: 同一の原資料URL、明示された続報関係を整理する。同じ組織・同じ日という理由だけで異なる公表を統合しない。残る別の公表を独立した事故数と呼ばない。
- 保存: 追加の取得資料と大きな作業用出力は、マウントと識別を確認した外部SSDを使う。既存のソースと元入力は保持する。
- 成功条件: 追加数、国内の原因別件数、各入力のSHA-256と判断理由が追える。既存IDとデータ・詳細の整合性が維持され、検索・ページ送り・地図・原資料表示が動く。
- 検証: 取込の重複・除外判断、全索引と分割詳細、実Wasmと代替処理、代表的な追加記録の原資料、ブラウザの主要操作、ビルドとローカル配信ファイルの一致を確認する。
- 許可が必要な操作: commit・push・PR・公開・有料データ購入・問い合わせ送信は今回の範囲に含めない。
- 最大3周。同じ製品不具合が2周続けば、原因と残件を本人へ報告する。独立レビューは実施できるときだけ行い、自己確認を独立レビューとは呼ばない。
