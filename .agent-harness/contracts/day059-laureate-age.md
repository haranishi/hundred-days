# Day059 その歳で、受賞した人

目的：年齢を1つ入れると、その歳でノーベル賞を受けた人の数と顔ぶれを1行で答えるWebアプリを、発表週（2026-10-05〜12）のうちにDay59として公開する。
範囲：`day-059-laureate-age/`、Day索引、`scripts/build.mjs` の接続先、`static/privacy.html`、`THIRD_PARTY_NOTICES.md`、`tests/e2e/day-059.spec.mjs`、検証記録。
対象外：既存Dayの仕様変更、実行時の Wikidata 参照、SNSへの投稿。
許可：本人がPR作成とマージを依頼済み。ただし権利と規約の確認を先に終え、問題が残るならPRを作らずに本人へ返す。
最大3周、同一失敗2周で残件を本人へ返す。

## 受け入れ条件

- 題名・見出し・OG画像に「ノーベル」が入っていない。出典と無関係の表記が画面にある
- 年齢17・25・26・54・97で答えが要件どおり。0人の答え、±1歳、没後、辞退の注記が出る
- 今年の欄が、発表済み・発表待ち・データ待ち・取得失敗・保存分表示の5つを文字で区別する
- 取得に失敗しても、答えと帯の図は同梱データで動く
- 外部への通信は `api.nobelprize.org` だけで、年齢を送らない
- 390/768/1280pxで横スクロールが出ない。押せるものは44px以上
- 単体テスト・E2E・build・precheck が通り、コンソールのエラーが0
