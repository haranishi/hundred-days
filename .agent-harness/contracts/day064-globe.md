# Day64 公表記録の地球儀マップ

依頼: Kasperskyのサイバー脅威マップを参考に、既存のDay64を地図から探索できる形にする。主担当が調査・設計・実装・検証を行う。

- 目的: 暗い地球儀、光る地域、3D/平面、ズームと地域選択を入口に、15,871公表記録と原資料を読む。
- 範囲: Day64の地理メタデータ、地球儀と既存表示の切替、地域・年代の探索、Rust/代替検索、関連する検査・説明・ローカル配信物。既存の記録数・数値・出典と他のDayは保つ。
- 根拠: 日本は組織名に一意に明記された都道府県、HHSは報告組織の州、Californiaは通知先の州。他は関連国の代表点へまとめる。表示地域は侵入サーバー・攻撃者の位置の認定ではない。
- 対象外: リアルタイム検知、攻撃元IP、推測した攻撃経路、漏洩個人情報、企業本社への無差別な推測配置、参考サイトのコード・画像・ブランドの複製。
- 表現: 地域の代表点と記録数を描画し、集約の意味と未特定を併記。過去資料の年代再生を現在の攻撃として表示しない。
- 成功条件: 全記録が一つの地域へ対応し総数が一致。地図→地域→記録→原資料、検索・条件・年代・ページ送りが連動。地球儀の回転、ズーム、平面、キーボード、スマホ、描画失敗時の復帰が動く。
- 検証: 地理対応と集約、実Wasm/代替処理、重要ブラウザ操作、390/768/1440px画像の閲覧、変更した地図操作の体験、自己UI/体験点検、ビルド、配信物/HTTP照合。独立レビューは今回の委譲制約に従い未実施として区別する。
- 地図データは出典・固定コミット・SHA-256を保存する。新規外部実行依存や外部地図APIは増やさない。
- 最大3周、同一製品不具合2周で原因・残件を本人へ返す。通常のローカル作業は継続する。commit・push・PR・公開・外部送信は今回の範囲に含めない。
