# Day 045 動画ツール

目的：デモの実イベントに同期した音声と、30秒の決定的なプロモ書き出しを用意する。
対象：Day 045 の検証窓口・シナリオ・tools・Nodeテスト・説明・本作業記録。
対象外：ゲーム仕様変更、meta.json変更、依存追加、build、dist、録画実行、git操作、公開。
受け入れ：既存47件と追加テストが通り、importで外部コマンドが動かず、別担当が録画・音重ね・プロモ描画を順に実行できる。
検証：純粋合成、時間対応、決定的ゲーム進行、字幕時間割、構文・import。実描画・聴取・E2Eは別担当へ引き継ぐ。
許可：指定範囲のコード変更とNode検証は許可済み。改善最大3周。

映像設計：初見の視聴者が30秒で撃ち癖の学習と得点2倍を理解し、公開URLから遊べるようにする。
戦略＝動く戦場から開始。要件＝実ゲーム・字幕・BGM・結果・URL。構造＝指定7場面。
骨格＝戦場を中央に大きく、字幕は下方の不透明な箱、文字は10%セーフ内。
表層＝アプリの紺・ミント・警戒色、時間駆動の強調。外部素材・フォントは追加しない。
字幕と絵の検査は書き出し側に組み込み、ブラウザ未確認の項目を合格扱いしない。
