# Day063「解約ボタンは、どれ？」体験評価ハーネス契約 (v1)

## 目的
ネットに潜む悪質UI（ダークパターン）を見抜き、無駄な課金を回避して生還する「欺瞞UI脱出ゲーム」の体験（面白さ・UX・手応え）を評価・改善する。

## 役割とモデル運用
- **設計・指揮**: Fable / Antigravity メインループ
- **体験評価（採点）**: 別セッション / 外部評価視点（ゲーム体験評価ハーネス10項目）
- **実装**: 自律ループ（Web Audioシンセシス、探索ギミック、CSSアニメーション、DOMインタラクション）
- **周回上限**: 最大3周（1周ごとに採点表と改善TOP5を記録）

## 採点表（10項目×0〜2点・計20点満点・合格＝16点以上かつ0点なし）
1. 30秒理解: ルールと初動が直感的にわかるか
2. コアループ: 探索→看破→解除の快感サイクルがあるか
3. 操作の手応え: タップ・クリック時の反応や気持ちよさ
4. フィードバック: 成功/失敗時の音・色・アニメ演出の納得感
5. 難易度カーブ: ステージ1から5への段階的な歯応えの進化
6. 失敗の納得感: 罠に引っかかった理由が明確で「やられた！」と思えるか
7. 目標の見える化: 今解除すべき罠と進行状況の明瞭さ
8. リトライ性: すぐに再挑戦したくなるテンポの良さ
9. 飽き耐性: 5ステージがそれぞれ異なる操作・探索ギミックを持つか
10. 進行の信頼: 詰み・レイアウト崩れ・誤判定がないか
