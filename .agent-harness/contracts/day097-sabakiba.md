# Day097 制作契約

目的: 魚のさばき方を、台所の手元と同じ向きの3Dで、骨まで透かして・刃の通り道を見ながら学べる。8種（アジ・イワシ・サバ・サンマ・タイ・ヒラメ・キス・カツオ）×5方法。なぞって練習・左利き・安全・部位と使い道つき。登録なし・無料・外部通信なし。スマホの指で使える。
仕様: `.kiro/specs/day-097-sabakiba/`（brief・requirements・ux・design・interfaces-geometry/timeline/app/render・visual-direction・research/・tasks・verification）。
変更範囲: `day-097-sabakiba/` 一式、専用のE2E（`tests/e2e/day-097.spec.mjs`）、根のREADME一覧・THIRD_PARTY_NOTICES・`scripts/lib/dist-files.mjs`（tools を配信しない）、仕様・検証記録。
対象外: 他Dayの改修、アカウント・クラウド保存・オフライン対応、フグなど毒魚の処理の手順、生きた魚の締め方、外部の3Dモデル・画像・書体・ライブラリ（three.js r186 を除く）。
成功条件: 8種の全手順が3Dと文章で最後まで進められる／透視・左利き・視点・練習・共有・さばく前に・部位と使い道が動く／3Dが使えない端末で文章だけの手順が動く／指・キーボード・WebKit・本番CSPで動く／共通検査と公開ゲートが成功する。
役割: 要件・設計・契約・統合・検収は親（Claude）／解剖と形・時間と包丁と採点・視点と描画・内容は Codex／画面・材質の見た目の磨きは Antigravity（撮影して自分で確認）／調査は Codex・Antigravity／体験・見た目の採点は Antigravity・Codex・Opus（Grok は残高が戻れば）／独立コードレビューと手順・安全の文言の照合は実装者と別系統の読み取り専用。
検証: 単体・ブラウザ・実画面の目視・固定ショット。体験と見た目の採点は最大3周、同一指摘が2周続いたら停止して残件を報告。担当の「完了」は受け取らず、親が試験を再実行して確かめる。
通常作業: 分離ブランチでの仕様・実装・検証・commit/push/PRまで（フックは回避しない）。マージは本人の承認を得てから。X投稿・実機・商標は本人。
