# Day060 今年の受賞の解説

目的：今年の受賞者が、何をした人で、暮らしの何が変わったのかを、発表のたびに、確かめた事実だけで解説するWebアプリを、発表週（2026-10-05〜12）のうちにDay60として公開する。10/6に作ったDay59初版「その歳で、受賞した人」（年齢検索）は、ページの下に残す。
範囲：`day-060-prize-explained/`、Day索引、`static/privacy.html`、`THIRD_PARTY_NOTICES.md`、`tests/e2e/day-060.spec.mjs`、`.agent-harness/runs/day060-*.md`。
対象外：既存Dayの仕様変更、実行時の Wikidata 参照、SNSへの投稿。
許可：作る・確かめるところまで。PR・マージ・本番公開は、権利の確認結果を本人に見せ、了承を得てから行う。本人の指示（2026-10-07）：「著作権とか規約とかを犯さないように作成してほしい」。
最大3周、同一失敗2周で残件を本人へ返す。

## 受け入れ条件

- 題名・見出し・ひとこと・共有の文・`meta description`・最初の1画面・OG画像に「ノーベル」「Nobel」が入っていない
- すべての解説の文に出典番号があり、出典は https のURL（論文は DOI）。公式サイトへは HTML のページだけ
- 事実（何が変わったか）と期待（まだ実現していない）が別の欄・別の見た目。期待の札がある
- 「作者が自分の言葉で書いた」「公式の文章ではない」の注記と確認日が全カードにある
- 文学賞・平和賞は事実のみ（変化・期待・年数の欄が無い）
- 発表済みで解説の無い賞は「準備中」。受賞者と公式の受賞理由（原文）は出る
- 取得に失敗しても、同梱の記録にある賞は解説つきで読める。端末の時計が狂っていても解説は消えない
- 外部への通信は `api.nobelprize.org` だけで、年齢を送らない。画像・動画・外部CSSは使わない
- 解説の検査（`tools/check-commentary.mjs`）が0件。検査の各項目は、わざと壊した例で落ちることを確かめてある
- 年齢検索（Day59初版の機能）は動きが変わらない。390/768/1280pxで横スクロールが出ない。押せるものは44px以上
- 単体テスト・E2E・共通E2E・build・precheck が通り、コンソールのエラーが0
