# Day68 第1話「映像の嘘」
- 依頼：面白さと物語が足りないとの評価を受け、提示した冒頭〜最初の追及の体験を制作する。
- 目的：相棒への関心から調査し、現場で得た証拠を示すことで証人と場所の状態が変わる。
- 範囲：Day68の入口、第1話の場面・会話・探索・証拠・進行・素材・検証と説明。
- 完成単位：相棒との約束→失踪の伝言→駅の探索→最初の追及→閉鎖ホーム→相棒との再会と新たな謎。
- 成功条件：人物を疑う理由、守る理由、探す理由が操作の前後で伝わる。
- 成功条件：カメラと時刻表を自分で調べ、2つの証拠と理由を選んで証言を反証できる。
- 成功条件：正解で栞が協力し、鍵が手に入り、閉鎖ホームへ入れる。文章だけで完結させない。
- 成功条件：誤った証拠から戻れる。鍵の先取り・再読み込み・人物会話の中断で進行が壊れない。
- 成功条件：390・768・1440px、動き軽減、キーボード、保存不可、2Dでも第1話を完了できる。
- 既存：3D鉄道、経路計算、人物画を再利用。旧版はclassic.htmlと既存保存へ残す。
- 対象外：第2話以降、外部API音声、公開、commit・push・PR、他のDayの改修。
- 検証：進行と証拠判定の単体試験、実ブラウザで初回・誤答・復帰・再会、画面確認。
- 体験→UIの自己点検。改善は最大3周、同じ失敗が2周続けば残件を返す。
- 記録：.agent-harness/runs/day068-first-episode.md。面白さは本人の再プレイで判断する。
