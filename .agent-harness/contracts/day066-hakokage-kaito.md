目的：押せる箱で、見張り・警備員の光とレーザーをさえぎり、影を通って宝を盗み出す、1手ずつ進む忍び込みパズルを作る。登録なし・外部通信なし・依存ライブラリなし。

## ユーザーストーリーとUX5階層

正本は Obsidian「2026-10-13 Day066 ユーザーストーリーとUX5階層」。要点だけを置く。

- 初めて来た人が、説明を読まずに面1で、箱を光へ押して影を作り、宝を取って出口へ出られる。面1も箱を押さないと解けない。
- 戦略：頼れる道具は押せる箱だけ。その一つが、光をさえぎる・警備員を引き返させる・押し間違えると逃げ道をふさぐ、の三役を持つ。理不尽さは「見えている光＝判定」と次の1歩の予告で消す。
- 要件：8面（1面に新しい発見を1つ）、全面を最初から選べる、盤は最大8×8、十字ボタンとキー、見つかった理由の文と光の通り道、押した直後の詰みの検出、星は最少手数、お手本、保存、音の切替、動きを減らす設定。
- 構造：面を開く → 盤を見る → 動く・押す・待つ → 見つかった（原因→ひとつ戻す）／詰み（→戻す）／成功（星→次の面へ）。
- 骨格：一番大きいのは盤。スマホ縦は帯・題字・面の帯・ヒント・盤・状態・十字ボタン（下に固定）。画面の型5つを1つの関数で決める。
- 表層：夜の美術館。光は黄の斜線、影は黒とくさび、レーザーは赤い芯と暗い外線。文字は13px以上、比は4.5以上。

## 受け入れ条件

- `node .agent-harness/runs/day066-hakokage-kaito/reference/verify-levels.mjs` が V1〜V7 合格で levels.json と一致する。単体テストでも同じ検査（V1〜V7・par・最短解の本数）が通る。
- reference/mutate.mjs の13個の変異を lib/sim.js に当てると、どれも単体テストが1件以上落ちる。
- 本番と同じ CSP で開き、エラー・CSP 違反・外への通信が0件。
- 390×844・375×667・320×568・844×390・1440×900 で横にはみ出さない。押せるものは44px以上。全8面で盤と操作が最初の画面に収まる。13px 未満の文字が無い。
- 全8面の見本の解の各手で、画面の光・予告・影のマスが lib/sim.js の scene() と一致する（E2E）。
- 面1を、タップだけでも、キーボードだけでも最後まで遊べる。見つかった理由の文（5種類）・詰みの欄・お手本・共有の窓が動く。
- 共通の試験（shared-share・security-headers）が通る。押すタイミングが関わる試験を、等速3回とページの CPU を5倍・10倍に遅くした実行で通す。
- 動きを減らす設定で、動き・点滅・揺れが止まる。音を切っても情報が欠けない。
- 実ページで design:accessibility-review の重大（Critical）が0件。design:design-system（audit）で直書きの値を数え、直した数を記録する。
- 体験評価（実際に遊ぶ）が16点以上で0点なし。見た目評価が16点以上で0点なし。
