# Day086 制作契約

目的: 質問で食べたいものを絞り、近くの1軒の提案で、外出先で場所が決まらない時間を短くする。
仕様: `.kiro/specs/day-086-chakuchiten/`。
変更範囲: Day086一式、専用テスト、共通ビルドの通信先、一覧、権利表示、仕様・検証記録。
対象外: 他Dayの機能改修、予約、履歴、店舗写真・評価、実際の経路計算。
成功条件: 主要フローと失敗からの復帰、3幅の表示、共通検査と公開ゲートが成功する。
検証: 単体・ブラウザ・実API接続・画像の目視、体験とUIの点検。最大3周、同一失敗2周で残件を報告。
通常作業: 分離ブランチでの仕様・実装・検証・commit/push/PRまで。マージ・SNS投稿は本人。
破壊的変更・追加課金・秘密情報の外部送信は行わない。
