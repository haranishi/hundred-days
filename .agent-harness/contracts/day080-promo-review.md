# Day80予告編の読み取り専用レビュー
目的：初見で遊びの内容が伝わり、楽しそうと思える実プレイ中心の36秒の告知にする。
対象：day-080-fifth-prince/tools/promo/output/stills/ の代表フレームと、完成後のfirst-frame/contact-sheet。
メインが編集する。製品ファイル・Gitは変更せず、ブラウザも起動しない。

## 見る点
- 1コマ目が実際の戦闘で、説明の文字だけで始まらない。
- 商い・仲間の同行・兄弟との返事・選択式の戦闘の違いが見える。
- 字幕と実画面の文字が読み取れ、端が欠けず、画を邪魔しすぎない。
- 最後に題名と遊べる案内を読める。能力の種明かしや結末は見せない。
- ゲーム用の同じドット素材を使う。別の生成イラスト、通知、ブラウザタブ、個人情報は入れない。

## 制作上の事実
1080×1920、30fps、1080フレーム。チェックポイントから正規のUIを操作し、戦闘の値や結果は変更しない。
音はゲームのCC0素材と同じ足音モデルから編集し、動画へ同期する。人が聴いていない音質を合格とは言わない。
静止画で分かる問題と、音・再生全体でしか分からない問題を分けて報告する。
