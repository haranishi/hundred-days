# 影証言：開発契約

## 目的
灯りの高さと道具の位置を動かして、目撃者が壁に見た「人影」を再現し、影の高さから犯人の身長を推理する5夜の推理パズルを、新しいDayとして作る。

## 変更範囲

他の作業場所にある未コミット変更の移動・削除・取り消し。公開（published・マージ・デプロイ）とSNS投稿。

## 受け入れ
- 夜1から夜5まで、1人で、再現 → 推理 → 次の夜 → エピローグが完結する。
- 5夜すべてで、正解の配置が合格し、開始の配置は不合格。灯りの高さは一意で、邪魔な道具が壁に残ると不合格。再現前は容疑者が2人以上残り、再現後は1人だけ。
- 灯り・道具をポインター・キー・微調整ボタンのどれでも動かせる。
- スマホ（幅360〜）とPCで操作でき、色以外でも状態が分かる。
- 既存の検査と、新作の実ブラウザ操作・体験評価・UI評価に証拠がある。
- 未検証の機器や、人間の面白さを合格扱いしない。

## 検証方法
`node --test day-071-kage-shogen/tests/`、構文・ビルド検査、Chromium/WebKitの重要フロー（`tests/e2e/day-071.spec.mjs`）。
実操作で5〜10分の体験評価（0〜2点×10項目、16点以上かつ0点なし）、続けて画像による画面評価（同じ基準）を、実装者とは別の評価者が行う。順番は体験 → 見た目。
別担当が使える工程では、読み取り専用の独立レビューを行う。実装者の「全テスト合格」は、メインが再実行して確かめる。
