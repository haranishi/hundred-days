# Day61：PC構成を組む前に確認する

## 目的

既存のPC構成シミュレーターを、データ・素材の利用条件に対応して100日チャレンジへ掲載する。
本人の依頼範囲は、各指摘への対処・検証・PR作成・100daysへのマージ。マージ後の既存CIによる公開も確認する。

## 公開版の方針

- 利用者が入力した寸法・ソケット等を使う互換性確認、電力の目安、構成共有を残す。
- メーカーサイトにも再掲載制限が確認されたため、提供側の実製品カタログは公開ソースを含めて取り除く。
- 作例は製品名を変えた流用ではなく、独立して作成する丸めた架空値で用意し、実製品ではないと明示する。
- 出典元の利用根拠が確認できていない価格・性能値を公開ソースと配布物から除く。
- 価格は利用者が入力する。性能ランキングは提供しない。
- 実製品固有の外観再現・配布モデル・参考写真を含めず、寸法と部品の配置を汎用の形状で示す。
- 依存ソフトの通知を配布し、メーカー等の公式アプリと誤認されないよう説明する。
- アフィリエイト・自動価格取得・外部データAPI・SNS投稿は追加しない。

## ユーザーストーリーとUX

- 手持ちや購入候補の部品を選び、寸法・組合せの注意を確かめたい。
- 自分が調べた価格を入れ、構成メモを持ち帰りたい。
- 戦略：組合せの確認と相談の準備。要件：互換性・電力・入力価格・共有。
- 構造：左に模式図、右に8カテゴリの入力、下に結果。スマホは模式図→入力→判定へ縦に辿る。
- 骨格：基本寸法を先に入力し、メモリ規格等の追加条件は必要時に展開する。入力から即座に3Dと判定へ反映。
- 骨格：スマホでも主要操作と注意点に到達できる。表層：既存の暗い背景・紫の主操作を保つ。
- 3Dは外観の再現ではなく、寸法と配置の模式図と分かるラベルを付ける。

## 範囲・担当

- 主担当：設計、100days統合、出典・通知の照合、公開物検査、PRとマージ。
- 実装担当：価格・性能表示、汎用3Dを別の担当へ分ける。
- 評価担当：実装者とは別のセッションで完成画面を操作し、UI・体験と公開物を検査する。
- 対象は `day-061-kumimae/` と必要な一覧・配信設定・検証の追加。ほかのDayの機能は変更しない。
- 元の非公開プロジェクトの履歴や素材を公開リポジトリへ持ち込まない。

## 受け入れ

- 公開ソース・ビルド・共有出力に未確認の価格・ベンチマーク・外部モデル・写真がない。
- OSSの著作権通知と許諾文が配布され、画面から読める。
- 仕様と価格の未入力、入力、修正、0円、異常値、保存拒否時の扱いが一貫する。
- 編集取消・保存復帰・共有URL復元・メモ／画像保存が動作する。URLは仕様のみ、価格はメモ／画像に含む。
- 単体、型検査、ビルド、公開前チェック、Day61のブラウザ検証、必要なサイト共通検証が通る。
- 390 / 768 / 1440pxで確認。UI・体験は16/20以上・0点なし、重大な未解決事項なし。
- 最大3周、同一の問題が2周続いたら残件を返す。CIを迂回せず、公開後も主要動作を確認する。
