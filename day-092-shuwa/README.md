# Day 092「てことば」

登録なし・無料で、日本の手話の指文字・数字・あいさつを1日5分ずつ覚える入門アプリです。手の形は自作の3Dで、指で回して確かめられます。指文字の表は相手の側から描かれているので、自分の手で作ると向きを取り違えがちです。このアプリでは「相手から見る」と「自分から見る」を切り替えられます。

- [アプリを開く](https://rairakku.com/100days/day-092-shuwa/)

## 使い方

- はじめに、利き手・1日の目標・どこから始めるか（指文字・数字・あいさつ）を選びます。4回押すと最初のレッスンが始まります。
- レッスンは10〜14問です。新しい項目の紹介、手→文字と文字→手の4択、ペア合わせ、指文字で読む・綴る問題、単語の手話の意味を選ぶ問題、自分の手でやってみる問題があります。まちがえた問題は最後にもう一度出ます。
- その日に1レッスン終えると、連続記録が1日延びます。忘れかけた項目は「復習」に出ます（1回12問まで）。
- 「図鑑」では、全部の手を回して見られます。出典と確信度も載せています。「ことばを指文字で再生」では、自分の名前などを指文字で流せます。
- 「やってみよう」の問題では、任意で「カメラで確かめる」を使えます。映像は端末の中で処理し、保存も送信もしません。
- 記録はこの端末のブラウザにだけ残ります。設定から書き出し・読み込み・全削除ができます。一度開けば、カメラ以外はオフラインでも使えます。

## 作り

- Preact と TypeScript で作り、Vite で組み立てています。3Dの手は three.js で、指の骨ごとの形から自作しました。指文字・数字・単語の形と動きは、1つの仕様データで持っています。表示、選択肢の小さな画像、カメラ判定の基準は、すべてこのデータから作ります。
- カメラ判定は MediaPipe の手の検出（wasm とモデルを同梱）を端末内で動かし、指の曲がり・親指の位置・手のひらの向きを比べてヒントを返します。読み取りには誤りがあるので、✗は付けません。
- MediaPipe は、利用状況の数値を Google へ送る機能を持っています。このアプリでは、その住所への送信を送らずに終わらせる仕掛けと、サイトのセキュリティ設定（CSP）の二重で止めています。偽カメラの試験で、送信が起きないことを確かめました。
- 外部への通信はありません。Cookie・アクセス解析も使っていません。
- 元のコードは [source/](source/README.md) にあります（MIT License）。仕様（要件・設計・タスク）は `source/.kiro/` にあります。

## 手話の中身の正確さ

- 指文字46文字と濁音などの変化5種、数字13（0〜10・100・1000）、単語16語を収録しました。形と動きは公開資料を2つ以上照らし合わせ、4つの自治体の指文字表（神奈川県・宇治市・朝来市・前橋市）とも1文字ずつ見比べています。表はアプリに入れていません。
- 作っていない確認者（別のAI）が、描いた手を表と調査の資料だけで3周照合しました。重大な食い違いは、直してから確かめています。
- **ろう者の監修は受けていません。** 資料で形が分かれる項目には、画面で「資料で分かれる」と示しています。アプリの「このアプリについて」には、手話は言語であること、指文字だけでは会話できないこと、地域差があることを書きました。
- 表どうしで形が分かれ、絵だけでは決められない項目と、公開前にろう者の実演で確かめたい項目は、わかる・はじめまして・大丈夫・も・ろ・の・数字0・数字10 の8つです。
- 誤りに気づいたら、このリポジトリの [Issue](https://github.com/haranishi/hundred-days/issues) で知らせてください。
