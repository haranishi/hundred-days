# てことば（tekotoba）

登録なし・無料で、日本の手話の指文字・数字・あいさつを1日5分ずつ覚える入門Webアプリ。ブラウザだけで動く。サーバー・ログイン・アクセス解析は持たない。
自作の3Dの手を指で回して、「相手から見る」と「自分から見る」を切り替えられる。指文字の表は相手の側から描かれているので、自分の手で作ると向きを取り違えやすい。そこを助けるのが一番の狙い。

公開先は https://rairakku.com/100days/day-092-shuwa/（100日チャレンジのDay92）。コードは MIT License で公開している。

**ろう者の監修は受けていない。** 形と動きは公開資料を2つ以上照らし合わせて作り、作っていない確認者（別のAI）が3周照合した。公開前にろう者の実演で確かめたい8項目は `.kiro/specs/sign-content/tasks.md` にある。
誤りの知らせ先は、100日チャレンジのリポジトリ（`haranishi/hundred-days`）の Issue。

## 動かす

```sh
npm ci
node scripts/fetch-model.mjs   # 手の検出モデル（約8MB）を取り、記録したSHA-256と照合する。カメラ判定にだけ使う
npm run dev                    # http://127.0.0.1:4321/
```

## 公開のしかた

```sh

node tools/build-day092.mjs <100日のリポジトリ>/day-092-shuwa
```

## 決めたことと理由

- **3Dの手は自作**（three.js）。写真や動画の手は視点を変えられず、権利も絡む。形は「指ごとの曲がり・親指の置き場・手のひらの向き」の仕様データ1つに持ち、表示・選択肢の小さな画像・カメラ判定の基準を、すべてそこから作る。
- **カメラ判定は任意で、✗を付けない**。手の読み取りには誤りがあり、正しく作れた手を誤りと言うほうが害が大きい。映像は端末の外へ出さない。
- **MediaPipe の利用状況の送信は二重で止める**。送信先への fetch を送らずに終わらせる仕掛け（`src/camera/no-telemetry.ts`）と、CSP の `connect-src 'self'`。
- **確信度は「中心の形が資料どうしで一致するか」で決める**。資料に無い細部（指の角度・距離など）は推定として、詳細の注記に書く。
- **書体は Zen Maru Gothic を、使う字だけに絞って同梱する**（`npm run fonts`）。文言を変えたら作り直す。足りない字は `publish:check` が見つける。

## 落とし穴

- BudouX は入口（`index`）から読むと Node 用の DOM（linkedom）まで読み込み、開発サーバーが起動できない。Parser と日本語のモデルを直接読む（`src/ui/ReadableText.tsx`）。
- 「・」は `word-break: keep-all` でも後ろで折れる。ReadableText が「・」と次の1文字を折れない塊にする。U+2060 などの文字は足さない（文字列の検索と読み上げの名前が変わる）。
- 画面の切り替えの見張りは `useLayoutEffect` で付ける。`useEffect` だと、起動の直後に URL が変わった時に取りこぼし、URL と画面がずれた。
- 記録はページを離れる時（`pagehide`）にも書き込む。試験で記録を入れる時は、読み込みの前（`addInitScript`）に入れる。読み込みの後に外から書き換えると、離れる時に上書きされる。
- 3Dの見え方は、実際のブラウザで撮らないと分からない。小さな画像は、札に置いた見え方（`dev-hands.html?set=cards`）でも確かめる。

## 確かめ方

```sh
npm run typecheck && npm test   # 型と単体試験（手話のデータの検査を含む）
npm run e2e                     # ブラウザ試験（スマホの Chromium・WebKit、PC、偽カメラ）
OUT=<書き出し先> npx playwright test -c playwright.capture.config.ts   # 採点用の撮影（決まった種と日付で画面を作る）
```

体験と見た目の良し悪しは、作った人と別の担い手が、実際の操作か画像で採点する。記録は `.agent-harness/runs/` にある（手元のみ）。

## やらないと決めたこと（いまは）

- ログイン・サーバー・端末どうしの同期・課金。登録なしで入門を最後まで、を守るため。記録は書き出しと読み込みで別の端末へ移せる。
- 手話の文法や会話の練習。3Dの手と指文字の入門に絞った。手話は言語で、指文字だけでは会話できないことを、アプリの中に書いた。
- 第三者の手話の動画や図の掲載。権利と地域差の扱いのため。資料は出典のリンクで示す。
