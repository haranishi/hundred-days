# ユーザーストーリーとUX5階層（実装前に作成・2026-11-13）

## ユーザーストーリー
| ユーザー | 欲しいことと理由 | 受け入れ条件 |
|---|---|---|
| 本命：手話に興味を持った聴者の大人 | 登録や準備なしで、今すぐ1レッスン目を始めたい。面倒だと始める前にやめるから | 初めて開いてから3画面以内（3回のタップ）で最初の問題が出る |
| 本命 | 指文字の形を、自分の手でどう作るかを知りたい。表は相手側から描かれていて向きを取り違えるから | どの手の表示でも「相手から見る／自分から見る」を1タップで切り替えられ、指で回せる |
| 本命 | 自分の手の形が合っているか確かめたい。独学だと誰も直してくれないから | カメラを使う問題で、違う点を「親指の先を人差し指の先につける」のような具体的な言葉で返す。カメラなしでも先へ進める |
| 本命 | 毎日少しずつ続けたい。まとめてやると忘れるから | 1レッスン終えた日は連続記録が延びる。忘れかけた文字が復習に出る。復習は1回12問まで |
| 救う相手：表を見て挫折した人 | 46文字を一度に覚えずに、少しずつ積み上げたい | 1レッスンの新しい文字は3つまで。前に覚えた文字が混ざって出る |
| 救う相手 | まちがえても嫌にならずに続けたい | まちがいでレッスンが止まらない。まちがえた問題は最後にもう一度出て、正解すると終われる |
| 左利きの人 | 自分の利き手で覚えたい | 設定で左手を選ぶと、すべての表示が左手になる |
| ろう・難聴の人や音を出せない場所の人 | 音なしで全部使いたい | 正誤は文字・色・形で示し、音は切れる。音にしかない情報がない |
| 機種変更する人 | 登録なしでも記録を引き継ぎたい | 進捗をファイルに書き出し、別の端末で読み込める |

## ① 戦略
- 目標：「手話をやってみたい」気持ちが消える前に、最初の成功（自分の手で1文字できた）まで連れて行く。その後は1日5分を習慣にする
- 差別化の源泉：視点を切り替えられる3Dの手（自分の手で再現しやすい）／端末内のカメラ判定とヒント／登録不要・無料・オフライン
- 成功の目安：初回の1レッスン完了率、翌日も開く率（端末内でしか測れないので、公開後の検討課題とする）

## ② 要件
- 載せる：指文字（46＋濁音など）、数字0〜10、あいさつ・自己紹介の単語。レッスン、復習、図鑑（全部の形を回して見られる、ひらがなを入れると指文字で再生）、記録、設定、進捗の書き出しと読み込み、シェア、スマホへの追加
- 載せない：ライフ制（理由：手の形は試行錯誤で覚えるもので、カメラ判定の誤りで罰したくない）、ランキング、ログイン、通知、広告

## ③ 構造
- 画面：はじめての案内（初回だけ）→ 学ぶ（道すじ）→ レッスン → 結果。下のタブで「学ぶ／復習／図鑑／記録」
- 道すじは3つのコース（指文字・数字・あいさつ）に分け、それぞれ最初のユニットは最初から選べる。案内の最後で「どこから始めるか」を選ぶ（おすすめは指文字）
- 迷う分岐と復帰路：レッスンの途中でやめる→確認を出し、やめても覚えた文字の記録は残す／カメラが使えない・許可しない→同じ問題を「自分でやってみる」形に切り替える／保存できない環境→画面の上に「この端末では記録が残りません」と出す

## ④ 骨格
- レッスン画面でいちばん大きい要素は「問題の主役」1つ（手の表示か、大きな文字）。答えの選択肢は2×2の大きなボタン。決定ボタンは画面下で、親指の届く位置
- 手の表示の下に小さなボタンを並べる：視点の切替／もう一度再生／ゆっくり
- 道すじは丸いボタンを縦に並べ、いま進めるボタンだけを大きくして「スタート」の吹き出しを付ける

## ⑤ 表層
- 配色は独自。赤と緑だけで正誤を分けない（✓・✗の記号と「正解」「おしい」の文字を必ず付ける）
- 書体は丸ゴシック（Zen Maru Gothic）。問題の文字は大きく（スマホで56px以上）
- 動きは短く弾むように。視差を減らす設定（prefers-reduced-motion）では動きを止める
- 案内役は独自のキャラクター「てまる」（丸い体に大きな手）。最初の案内・結果・空の画面に出す

## この5階層で変わった実装の判断（実装前の時点で8個）
1. すべての手の表示に視点の切替を付ける（戦略の差別化から）
2. 連続記録は「1レッスンで延びる」にする（1日の目標の達成を条件にしない。Duolingo の公開実験で、この変更が継続率を上げた）
3. 復習は1回12問まで（復習がたまると離脱するという調査から）
4. カメラ判定は✗を付けず、ヒントと「自分でできた」の選択肢を出す（判定が不確かな段階で努力を否定しない）
5. ライフ制を入れない
6. コースを3つに分け、指文字を飛ばしてあいさつから始められるようにする（学ぶ動機が人によって違う）
7. 登録なしの記録の引き継ぎとして、書き出しと読み込みを入れる
8. 画面遷移はURLの # で切り替える（直リンク・再読み込み・シェアのリンクが壊れない）
