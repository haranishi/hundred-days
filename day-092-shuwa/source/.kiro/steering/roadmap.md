# Roadmap

## Overview
「てことば」（仮称）は、日本の手話の入門アプリである。登録はいらない。ブラウザを開けば、指文字・数字・あいさつを1回3〜5分の短いレッスンで学べて、連続記録で続けられる。Duolingo の「道すじ・短い問題・連続記録・復習」という学び方の型を借り、名前・キャラクター・見た目はすべて独自に作る。

手の形は、写真や動画ではなく、自前で組み立てる3Dの手で見せる。理由は2つある。素材の権利を気にせず全部の形を用意できること、そして「相手から見た形」と「自分から見た形」を切り替えられることだ。指文字の表は相手側から描かれていて、自分の手で再現すると左右や向きを取り違えやすい。ここが既存の表や動画にない、このアプリの差である。

## Approach Decision
- **Chosen**: 静的なWebアプリ（端末内に進捗を保存）＋自前の3Dの手＋端末内で動くカメラ判定（任意）
- **Why**: ログイン不要・無料・オフラインでも動く。手の形を1つの仕様データから「表示」と「カメラ判定」の両方に使えるので、見せる形と判定する形が食い違わない
- **Rejected alternatives**:
  - ろう者の動画を使う：撮影・出演・権利の手当てができない。監修なしで他人の動画を使えない
  - AIで生成した手の画像：指の本数や向きが崩れやすく、学習教材として誤りを生む
  - 2Dのイラストを手描き：70以上の形と動きを描き分ける手間が大きく、回転もできない

## Scope
- **In**: 指文字46文字と濁音・半濁音・促音・拗音・長音、数字0〜10、あいさつ・自己紹介の基本の単語（調査で記述が一致したもの）、レッスン・復習・図鑑・記録・設定、連続記録と1日の目標、進捗の書き出しと読み込み、SNSシェア、スマホへの追加（オフライン利用）
- **Out**: ログイン・端末間の同期・ランキング・広告・課金・通知、文章や会話の翻訳、手話の文法（表情・視線の文法を含む）の授業、ろう者による監修済みの表示（監修は未実施と明記する）

## Constraints
- サーバーを持たない。データは端末内（ブラウザの保存領域）だけに置き、外へ送らない。カメラの映像も端末の外へ出さない
- スマホ（指の操作）で全機能が使えること。縦390px・360pxで崩れない
- 外部素材は商用・改変可の許諾（MIT・Apache-2.0・OFL・CC0）に限り、許諾の写しを同梱する
- 手話の中身は、調査の出典が2つ以上一致したものを優先し、確信度の低いものは載せないか「要確認」と表示する
- 100日チャレンジの Day92 として出す（2026-11-13 本人指示）。100日のリポジトリの中のDayにし、PRは公開ゲートを通した状態で出す。マージとX投稿は本人
- 名前は、PRの前に J-PlatPat で商標（第9類・第41類）を確かめてから決める（フォルダ名＝URLにも入る）
- 宣伝動画とX投稿の下書きも、他のDayと同じく作る（アプリが評価に合格した後）

## Boundary Strategy
- **Why this split**: 手の3Dモデルは、データ（どんな形か）とも画面（いつ見せるか）とも独立に試せる。中身のデータは、3Dモデルの形式に従って書けば、アプリ本体と並行して作れる
- **Shared seams to watch**: 手の形の仕様データの形式（hand-model が定め、sign-content が書き、camera-check が読む）。手の表示部品の使い方（hand-model が提供し、learning-app が使う）

## Specs (dependency order)
- [ ] hand-model -- 3Dの手（と上半身）を手の形の仕様データから描き、動き・視点切替・小さな画像の書き出しを提供する。Dependencies: none
- [ ] sign-content -- 指文字・数字・単語の形と動きのデータを、出典つき・確信度つきで作り、目視と自動の両方で検証する。Dependencies: hand-model
- [ ] learning-app -- 道すじ・レッスン・復習・図鑑・記録・設定・進捗保存・シェア・オフライン対応・公開ゲート。Dependencies: hand-model, sign-content
- [ ] camera-check -- カメラ映像から手の形を端末内で読み取り、目標の形との違いをヒントで返す（任意機能）。Dependencies: hand-model, sign-content, learning-app
