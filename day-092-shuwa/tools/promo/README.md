# Day092「てことば」の宣伝動画

32秒の縦型動画（1080×1920・30fps）を作る道具。画面はすべて公開用ビルドを実際に操作して撮った実画面で、字幕・タップの輪・指の印・最初の2小節の印（矢印と小窓）・終わりのカードだけを後から重ねる。
機能を順に並べる紹介ではなく、見た人が「使ってみたい」と思う気持ちの流れで組んだ:
問いかけ（指文字の表、そのまま真似してない？）→ あるある（表は相手から見た形。親指の向きを矢印で示す）→ 「自分から見る」で形が切り替わる（音のドロップ。2秒止める）→ 指で回して、向きを戻す → 動く手話をゆっくり → 1日5分のレッスン（4択とペア合わせ）→ 自分の名前を指文字で → 図鑑の幅 → 連続記録が2日にのびる → 無料・登録なし。
絵コンテは `timeline.mjs` の1つの表。映像（`render-promo.mjs`）とBGM（`promo-audio.mjs`、2案）が同じ表を読む。

## 再生成

リポジトリのルートで実行する。dist は読むだけで、ビルドし直さない（最新の画面で撮るときは、先に `npm run build` を済ませて dist のコピーを渡す）。
場所は引数か環境変数（`PROMO_SITE_DIR`・`PROMO_FRAMES_DIR`・`PROMO_OUT_DIR`）で渡す。ffmpeg / ffprobe（`FFMPEG`・`FFPROBE`、なければ PATH）と、ローカルの Zen Kaku Gothic New（Bold・Black。`PROMO_FONT`・`PROMO_FONT_BLACK`）が要る。

```sh
node day-092-shuwa/tools/promo/promo-audio.mjs --variant a --out-dir <書き出し先>   # bgm_a.wav と bgm_a.mp3（192kbps）
node day-092-shuwa/tools/promo/promo-audio.mjs --variant b --out-dir <書き出し先>
node day-092-shuwa/tools/promo/verify-audio.mjs --out-dir <書き出し先>
node day-092-shuwa/tools/promo/render-promo.mjs --site-dir <…/dist> --frames-dir <コマの置き場> --out-dir <書き出し先> --mux a,b
```

- 2026-11-13 の実測で、BGM 2案と検査は合わせて約10秒。撮り直し（最後の1行）は約3〜3.5分（撮影約2分・重ね約1分）で、ブラウザは常に1つ。
- `--only pairs,overlay` のように一部だけ撮り直せる（sign・inset・word・quiz・pairs・spell・dict・result・overlay）。`--compose-only` は重ねと書き出しだけ。
- 配信はリポジトリの `scripts/serve-dist.mjs` を dist の親フォルダで起動する（127.0.0.1・既定のポート 4392・`--port` で変更）。終わると自分の子プロセスだけを止める。
- 書き出し: `Day092_tekotoba_promo_{silent,a,b}.mp4`・`demo.mp4`（一覧のカード用。字幕なし・540×960・16秒・無音）・`first-frame.png`・`contact-sheet.jpg`（1秒ごと）・`cut-check.jpg`（各カットの前2コマ・後2コマ）・`capture-report.json`（止まったコマの秒数 `stillSeconds` を含む）・`bgm_{a,b}.{wav,mp3}`・`audio-report.json`・`spectrogram-{a,b}.png`。

## 撮影の仕組みと理由

- ページの時計（`requestAnimationFrame`・`performance.now`・`Date.now`・`setTimeout`・CSS/Web Animations）を止め、1/60秒×2回ずつ進めては撮る。3Dはソフトウェア描画で、実時間には追いつかない。
- アプリは CSS 540×760・DPR 2 で撮り、字幕の帯（上の400px）の下に置く。全面に字幕を重ねる配置だと、場面ごとに文字の札・問題文・結果画面のキャラクターのどれかを隠すことになる（撮った画面の配置を測って確かめた）ので、帯に分けた。
- テイクは8つ。どれも「前の日にレッスン1を終えて1日連続、今日はまだ0経験値」という同じ記録を `localStorage`（`tekotoba:v1`、途中のレッスンは `tekotoba:session:v1`）に入れてから開く。効果音と振動は切ってある（BGMと重なるため）。
  - sign: 図鑑の「あ」。「ゆっくり」は映る前に押し、1コマ目が形を作る途中になる。それより早い時点から映すと、開いた手の指先が3Dの枠の上で切れる（相手から見る・自分から見るのどちらでも切れる）。5.333秒に「自分から見る」、7.5秒から指で左へ約35度回し、9.0秒に「向きを戻す」。右へ回すと、袖が3Dの枠の横で切れる。
  - inset: 同じ頁を「自分から見る」にした1コマ。2小節目の小窓に使う（最初から「あ」の形）。
  - word: 図鑑の「ありがとう」。初回の注意書きは、アプリの「i」ボタンで閉じてから撮る。「ゆっくり」は場面の1コマ目で押すので、手が跳ぶ所は映らない。
  - quiz・pairs: レッスン2の途中（5 / 10問目と7 / 10問目）を入れ、「続きから」で開く。4択は手を選ぶ所まで（「チェック」の後はボタンが灰色を経て青に変わる）。ペア合わせは2組そろった所から始め、最後の組がそろった直後で切る。
  - spell: 先に図鑑の「あ」を開いて3Dの部分を読み込ませてから、「ことばを指文字で再生」へ移る。「り」の終わりの止まった0.5秒は使わない（`SPELL.skip`）。
  - dict: 3つのタブの小さな画像を、映る前に1度ずつ描かせておく（一度描いた画像は使い回される）。最後に指で一覧を送る。
  - result: レッスン2の最後の問題に答えて「つづける」を押した直後。映る前に画面を送り、「2日連続」の札を見せ、キャラクターは窓の上へ出しきる。25.67秒に「つづける」で道すじへ戻ると、上の炎が2になっている。「4:12」は再開したレッスンの開始時刻から出る値で、実際にかかった時間ではない。
- カメラ（sign のコマの切り出しだけ）: 7.33秒までは窓を説明カードの上で切り、自分から見る間も見出し「相手から見た説明」を映さない。7.33秒（回す場面の切れ目）からは寄りに切り替え、下端を3Dの枠の下端のすぐ上に置く。袖は動画の端から先へ続いて見え、枠でまっすぐ切れた所は映らない。場面の途中で寄りは変えない。
- 最初の2小節の印: 相手から見た手の親指の下に右向きの矢印（0.2〜0.8秒、手が形を作るのと一緒に描く）、2.75秒から左上の小窓に自分から見た手と左向きの矢印。切り替えの瞬間に、大きい矢印は手と一緒に左向きになり、小窓は消える。座標は撮ったコマで測った値（`MARKS`）。
- タップの輪は押した部品の実際の位置に出て、0.4秒で消える。押した直後に頁が動いたり、画面が替わったり、押したボタンが消えたりしたら、そのコマで消す。場面の1コマ目で押す時は、前の場面に輪を出さない。
- 撮影中は配信元のほかへの通信をすべて止める。Service Worker は止め、登録用の `registerSW.js` は空で返す（Playwright が登録を断ると、コンソールに警告が出るため）。
- 重ねのコマは全部 rgba にそろえてから重ねる（Day083 の抜け対策）。切替はコマ番号で比べる。カットに白い閃光は入れず、進み具合の線も入れない。
- 音の合図は `SHAPE_CUES`（形ができた時刻と、名前の各文字が始まった時刻）と `TAP_CUES`（タップの時刻）。撮り直してずれたら、`capture-report.json` の `shapeCueDrift`・`tapCueDrift` を見て直し、BGMを作り直す。

## 画面と字幕の照合

字幕は、その時に画面で起きていることか、アプリの機能の事実だけを書く。「正しい手話」「話せるようになる」「ろう者監修」などは書かない（このアプリはろう者の監修を受けていない。アプリ内にも明記）。

| 秒 | 字幕 | 実画面で確認すること |
|---|---|---|
| 0–2.67 | 指文字の表、／そのまま真似してない？ | 1コマ目から「あ」が「ゆっくり」で形を作る（0.8秒に完成）。同時に親指の下へ右向きの矢印を描き、0.8秒に「相手から見ると」 |
| 2.67–5.33 | 表は、相手から見た形。／自分から見ると、左右が逆。 | 2.75秒から左上の小窓に、自分から見た「あ」と左向きの矢印 |
| 5.33–7.33 | てことばなら、／自分から見た形に切り替わる。 | 5.333秒に「自分から見る」→同じコマで手の甲側の形。矢印も左向きに。2.0秒止める |
| 7.33–10.33 | 指で回して、／横からも見られる。 | 寄りに切り替え、指で左へ約35度回す。9.0秒に「向きを戻す」で正面へ |
| 10.33–13.33 | 動く手話も、／ゆっくり再生。 | 「ありがとう」で、1コマ目に「ゆっくり」→半分の速さの動きを2.1秒 |
| 13.33–16.0 | 1日5分、／4択とペア合わせで。 | 4択（5 / 10問目）で「お」の手を選ぶ。14.33秒からペア合わせ（7 / 10問目）で「え」「お」をそろえる |
| 16.0–21.0 | 自分の名前も、／指文字で。 | 上に「1日・今日の目標0/20」。入力欄に「りん」→「指文字で再生」→「り」（17.33秒〜）「ん」（18.63秒〜） |
| 21.0–24.0 | 指文字・数字・あいさつ。／図鑑で、いつでも。 | 図鑑の一覧。指文字51項目→数字13項目→あいさつ16項目。指で一覧を送る |
| 24.0–28.0 | 毎日1レッスンで、／連続記録がのびる。 | 結果画面（+15経験値・100%・4:12・「2日連続　今日も学べたね。記録が延びました！」）→「つづける」→道すじで上の炎が2 |
| 28.0–32 | （終わりのカード） | てことば・3Dの手で覚える手話と指文字の入門・無料・登録なし・ブラウザですぐ・スマホは指で回せる・rairakku.com/100days/day-092-shuwa（meta.json の publicUrl と一致）・DAY 092 / 100。28.2秒から全部読める |

字幕は 1080×1920 の y=172〜372 にあり、投稿アプリの UI に隠れる上端8%・下端20%の外に収まる。アプリの画面は y=400 から下。

## BGM

90BPM・12小節。フック（IV の和音）はドラム無し → あるある（V）はドラムを抜き、上がっていくノイズで張る → 「自分から見る」の5.333秒に主和音でドロップ（キック・ベース・小さなシンバル）→ 回す・動きで厚み → レッスン・名前・図鑑でコーラス → 連続記録で副旋律 → 終わりのカードの28.0秒（11小節目の途中）に終止和音、最後の1.6秒でフェード。
A案「やわらかいピアノポップ」はト長調で、エレピの旋律を3+3+2のリズムで弾く。B案「カリンバと手拍子」はイ長調で、カリンバの8分の分散和音に、2拍目と4拍目の手拍子。
どちらの旋律もこの動画のために小節ごとに書いた。Day087（陽旋法の弦・ヘ長調のマリンバ）とは調も楽器も違い、音程の並びが5音以上続けて一致する所も無い。
`verify-audio.mjs` が見るのは、−16 LUFS±1・真のピーク −1.5 dBTP 以下・クリップ0・頭のクリック無し・途中の無音無し・末尾0・形の合図の立ち上がり・ドロップの上がり3dB以上・mp3（192kbps）。

## 使用素材と権利

- 映像: てことばのビルドをローカルで配って操作した実画面。3Dの手と体、案内役のキャラクターはアプリ自作。作り物の画面・第三者の素材・AI生成映像・実在の人の顔や手は使わない。カメラ判定の画面は撮らない。
- 字幕・印・終わりのカード: Zen Kaku Gothic New（Bold・Black）、SIL Open Font License 1.1。終わりのカードの印はアプリ自身の favicon.svg。
- BGM: `promo-audio.mjs` が Node の計算だけで合成する（サンプル素材なし）。音の試聴はしておらず、数値とスペクトログラムで確かめた。
