# Day62 終電サドンデス

居酒屋や職場の「まだ終電まで時間があるから大丈夫」という油断を断ち切り、店を出るべき本当のデッドラインを突きつける帰宅権脱出シミュレーター。

[公開URL](https://hundred-days.pages.dev/day-062-last-train/)

## 使い方

1. **駅と終電時刻を選択**
   - 新宿・渋谷・東京・横浜・梅田・秋田などの主要駅プリセット、または任意の駅名と終電発車時刻を入力します。
2. **タイムロス因子のチェック**
   - 「お会計・割り勘（+5分）」「上着・退店（+3分）」「トイレ寄り道（+4分）」「改札〜ホームダッシュ（+3分）」をチェックし、店から駅までの徒歩分数（1〜25分）をスライダーで合わせます。
3. **カウントダウンと警戒レベル**
   - 終電時刻から合計タイムロスを差し引いた「店を出る限界時刻」を算出し、ミリ秒単位でカウントダウンします。
   - レベルに応じて警戒カラー・メッセージ・警告音（Web Audio API）が変化します。
     - **LEVEL 1 平穏 (SAFE)**: 30分以上
     - **LEVEL 2 警戒 (CAUTION)**: 15〜30分
     - **LEVEL 3 臨界 (CRITICAL)**: 5〜15分
     - **LEVEL 4 サドンデス (SUDDEN DEATH)**: 5分未満（赤点滅・警報音・心拍音）
     - **DEAD END (終電死亡)**: デッドライン超過（始発サバイバルモードへ移行）
4. **脱出完了**
   - 店を出たら「脱出完了」ボタンを押し、帰宅権防衛の報告をXでシェアできます。
5. **始発サバイバルモード**
   - 間に合わなかった場合、翌朝05:00の始発までの残り時間タイマーと「夜明かし行動ルーレット（サウナ・ネカフェ・ファミレス等）」が表示されます。

## 機能・技術的特徴

- **完全クライアントサイド動作**: 外部API通信を必要とせず、完全オフラインでも動作。
- **Web Audio API シンセシス**: 外部音声ファイルを使わず、ブラウザ標準のWeb Audio APIで心拍音・秒針音・警告ビープ音・ファンファーレをリアルタイム波形生成。
- **URLパラメータ対応**: `?train=23:55&station=新宿駅&walk=7` で友達や同僚に設定済みタイマーを即座に共有可能。
- **LocalStorage自動保存**: 最後に設定した駅・終電時刻・タイムロス設定を端末に保持。
