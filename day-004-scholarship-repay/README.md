# Day 004: 奨学金、何歳まで返す？

奨学金の返還年数は、自分では選べません。借りた総額から自動的に決まります。そのことを、日本学生支援機構（JASSO）の算出表どおりに計算して見せるツールです。

公開予定URL: `https://hundred-days.pages.dev/day-004-scholarship-repay/`（デプロイ後に有効になります）

## 使い方

1. 種類（第一種＝無利子／第二種＝有利子）を選びます。
2. 毎月借りる額・借りる期間・卒業時の年齢を選びます。第二種のときは利率も選びます。
3. 返し終わる年齢、毎月の返還額、返す総額、手取りに対する割合がその場で出ます。
4. 「なぜこの年数になるのか」を開くと、年数がどう決まったかの道筋（借りた総額 → 該当区分の基礎額 → 割り算 → 切り捨て）が見られます。

## 計算のしかた

JASSOは、借りた総額を「奨学金返還年数算出表」の割賦金の基礎額で割り、**小数点以下を切り捨てた数**を返還年数にします（月賦返還・定額返還方式）。3,400,001円以上は基礎額が「総額の20分の1」になるため、返還年数は20年が上限です。

- **第一種（無利子）**: 毎月の返還額 = 借りた総額 ÷ 返還回数（切り捨て）
- **第二種（有利子）**: 元利均等返還。返還開始が貸与終了の7か月後なので、据置6か月分の利息を上乗せしています

## 数字の検証結果

JASSOが公開している大学の返還例と、実装したコードを突き合わせました。

| | 検証した件数 | 結果 |
|---|---|---|
| 第一種 | 10件 | 借りた総額・毎月の返還額・返還回数がすべて完全一致 |
| 第二種 | 60件 | 返還回数は全件一致。毎月の返還額は公式より **1〜11円高め**（返す総額で +0.006%〜+0.026%） |

第二種のずれは、JASSOが公開していない据置期間の利息計算の細部によるものです。6つの計算モデルを公式60件に当てて誤差が最小のものを選んでいます。**常に公式より高く出る方向**なので、返済計画を立てるうえでは安全側に倒れます。

正確な金額は必ず[JASSOの公式シミュレーション](https://www.jasso.go.jp/shogakukin/oyakudachi/document/simulation.html)で確認してください。

## 対応していないこと

所得連動返還方式、半年賦併用返還、減額返還、返還期限猶予、繰上返還、第一種と第二種の併用貸与。

貸与月額は**大学（2018年度以降の入学者）**のものだけを扱います。短期大学・高等専門学校・専修学校専門課程・大学院は選べる額が違います。私立大学の医・歯学課程（+40,000円）、薬・獣医学課程（+20,000円）の増額（第二種で120,000円を選んだ場合のみ可能）にも対応していません。

第一種の貸与月額は、国公立か私立か・自宅か自宅外かで選べる額が変わります。このアプリは全区分の和集合（20,000／30,000／40,000／45,000／50,000／51,000／54,000／64,000円）を並べているので、実際には自分の区分で選べない額も表示されます。

## 立場と免責

**これは個人が趣味で作った非公式のツールです。JASSOが提供・監修したものではありません。** 制度は改正されることがあり、内容の正確性・最新性は保証しません。実際の返還額は必ず[JASSOの公式シミュレーション](https://www.jasso.go.jp/shogakukin/oyakudachi/document/simulation.html)で確認してください。

第二種の利率は貸与が終わるときに決まります。このアプリの利率は、JASSOが公式の返還例で使っている0.5%・1%・2%・3%をそのまま選択肢にしています（法律上の上限は年3%）。「現在の利率」を断定して表示することは、値が動くうえに調べた情報源どうしで食い違いがあったため、あえてしていません。

## 制約

外部ライブラリ、外部通信、アカウント、課金、データの永続化は使用していません。入力はすべてスライダーとボタンなので、不正な値を入れられる状態が存在しません。

`actualMinutes` は、要件確認を始めてから実装とセルフ検収を終えるまでに実際に作業した分数です。
