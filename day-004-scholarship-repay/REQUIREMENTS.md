# Day 004 要件定義：奨学金、何歳まで返す？

## 1. 何を解くか

奨学金を借りている学生・これから借りる学生が、「卒業後にいくらを何年払うのか」を具体的な数字で把握できていない。特に**返還年数は自分で選べず、借りた総額から自動的に決まる**という仕様が知られていないため、一般的なローン計算機で試算すると実態と合わない。

需要の根拠：大学生が将来もっとも不安に思うことの1位は「お金」で約3割（2年連続、就活不安を上回る／マイナビ キャリア意識調査）。行動としては「貯金」「節約」「金融教育」に向かっている。

## 2. 主要アクション（1本のハッピーパス）

条件を選ぶ → 返し終わる年齢と毎月の返還額が出る。

## 5. 出力

- 返し終わる年齢（最大表示）
- 毎月の返還額
- 返還年数・返還回数
- 借りた総額／返す総額／うち利息
- 手取りに対する返還額の割合（バー付き）
- 年数が決まるまでの道筋（借りた総額 → 該当区分の基礎額 → 割り算 → 切り捨てた年数）

算出表を丸ごと画面に出す案（当初案）は取りやめた。理由は §7-2 を参照。該当する1区分と実際の割り算だけを見せる形にしたことで、数字の羅列ではなく「年数がどう決まるか」という手順そのものが読めるようになり、結果的に主題は強まっている。区分の一覧はJASSOの該当ページへリンクする。

## 6. 計算仕様

### 6.1 返還年数

JASSOの「奨学金返還年数算出表」に従う。貸与総額を割賦金の基礎額で割り、小数点以下を切り捨てる。

| 貸与総額 | 基礎額 | | 貸与総額 | 基礎額 |
|---|---|---|---|---|
| 200,000円以下 | 30,000円 | | 1,500,001〜1,700,000 | 120,000円 |
| 200,001〜400,000 | 40,000円 | | 1,700,001〜1,900,000 | 130,000円 |
| 400,001〜500,000 | 50,000円 | | 1,900,001〜2,100,000 | 140,000円 |
| 500,001〜600,000 | 60,000円 | | 2,100,001〜2,300,000 | 150,000円 |
| 600,001〜700,000 | 70,000円 | | 2,300,001〜2,500,000 | 160,000円 |
| 700,001〜900,000 | 80,000円 | | 2,500,001〜3,400,000 | 170,000円 |
| 900,001〜1,100,000 | 90,000円 | | 3,400,001円以上 | 総額の1/20 |
| 1,100,001〜1,300,000 | 100,000円 | | | |

3,400,001円以上は総額÷(総額/20) = 20 になるため、返還年数の上限は自動的に20年になる。

### 6.2 毎月の返還額

- 第一種：`floor(貸与総額 ÷ 返還回数)`
- 第二種：元利均等返還 `P·r/(1-(1+r)^-n)` に、据置6か月分の単利 `P × 年利 × 0.5` を上乗せし、`floor(総額 ÷ 回数)`

### 6.3 検証

公式の返還例（大学）と突き合わせ済み。

- 第一種10件：貸与総額・毎月の返還額・返還回数がすべて完全一致
- 第二種60件：返還回数は全件一致、毎月の返還額は +1〜+11円、返す総額は +0.006%〜+0.026%

第二種は6つの計算モデル（据置なし／据置を別途加算／元本に加算・単利・複利／据置7か月／期間延長）を60件に当てて誤差最小のものを採用した。据置月数を連続値で最適化すると5.85か月で誤差0.0026%まで下がるが、根拠のない定数になるため、制度どおりの6か月を採用している。

## 7. 扱わないもの

所得連動返還方式、半年賦併用返還、減額返還、返還期限猶予、繰上返還、第一種と第二種の併用貸与、保証制度（機関保証の保証料）。

貸与月額は大学（2018年度以降の入学者）のみ。短期大学・高等専門学校・専修学校専門課程・大学院は月額区分が異なる。私立大学の医・歯学課程（+40,000円）、薬・獣医学課程（+20,000円）の増額にも非対応。

第一種の月額は区分ごとに選択肢が違うため、全区分の和集合を並べている。

| 区分 | 選べる月額 |
|---|---|
| 国公立 自宅 | 20,000 / 30,000 / 45,000 |
| 国公立 自宅外 | 20,000 / 30,000 / 40,000 / 51,000 |
| 私立 自宅 | 20,000 / 30,000 / 40,000 / 54,000 |
| 私立 自宅外 | 20,000 / 30,000 / 40,000 / 50,000 / 64,000 |

## 7-2. 法務上の整理（2026-08-11）

- **金融商品取引法・貸金業法**：非該当。金融商品の売買・媒介・助言をせず、貸付も行わない計算ツールにすぎない。
- **弁護士法72条**：非該当。法律事務を扱わない。
- **個人情報保護法**：非該当。入力値を送信も保存もしない（localStorage・Cookie・外部通信がゼロであることをブラウザ上で実測確認済み）。
- **JASSOサイトポリシー**：リンクは「ご自由に設定ください」と明記されており問題なし。一方で「本機構または情報提供者からの許諾を受けていない無断転用は、禁止いたします」とも書かれている。

  算出表16行を画面に再現することについて、著作権法上のリスクは低いと判断した（単なる数値データの表には創作性が認められにくく、著作権法13条は独立行政法人が発する告示・訓令・通達その他これらに類するものを権利の目的外としている）。ただしJASSOの掲示文言は著作権法が与える権利より広く書かれており、「法的には問題ないが先方の掲示には反する」状態はあり得る。

  **2026-08-11、本人判断で表の全体再現をやめ、該当する1区分と計算式だけを表示する形に変更した。** 区分の一覧は転載せずJASSOの該当ページへリンクする。
- **公式との誤認防止**：ヘッダーに非公式である旨を常時表示し、末尾に免責を置いた。JASSOのロゴ・書体・配色は一切使用していない。

「現在の利率」は表示しない。値が変動するうえ、調べた情報源のあいだで食い違いがあったため（2026年2月時点で固定2.512%とする情報と、2026年3月時点で固定3.000%とする情報）。JASSOが公式の返還例で使っている4つの利率をそのまま選択肢にすることで、すべての結果が公式表と直接照合できる状態にした。
