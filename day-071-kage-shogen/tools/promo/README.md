# Day071「影証言」プロモ動画の道具

縦1080×1920・30fps・約33秒・音ありの、X の自動再生向けの動画を、**実際のゲームを指で操作した録画**から作る。
画はアプリの実画面そのもので、足すのは字幕・指の印・終了カードの重ね物だけ。音は外部の音源を使わず、コードだけで合成する。

## 再生成は1コマンド、約1分

```sh
node day-071-kage-shogen/tools/promo/render-promo.mjs
```

必要なもの：リポジトリの Playwright（Chromium）、ffmpeg / ffprobe、Zen Kaku Gothic New の Bold と Black（既定は `~/Library/Fonts/`。別の場所なら `PROMO_FONT`・`PROMO_FONT_BLACK`）。
配信は `tools/serve.mjs` を空いている番号で起こし、終わったら止める。撮ったコマ（約1,300枚・1枚約0.24MB）で一時的に約0.3GB使い、撮り直しが重なると最大でその3倍になる。置き場は `PROMO_WORK` で変えられ、その中の `_work` だけを毎回空にする。
画面ロック中は Chromium が落ちることがあるので、`caffeinate -d -i -u` で包んで流す。

| 指定 | 内容 |
|---|---|
| `--reuse-video` | 録画をやり直さず、音と検査だけやり直す |
| `--video-only` | 録画と書き出しだけ（音なし） |
| `--keep-work` | 撮ったコマを残す |

出力は `output/`（Git管理外）。本編 `Day071_kage_shogen_promo.mp4`、サムネになる `firstframe.png`、`endcard.png`、1秒ごとの場面一覧 `contactsheet.jpg`、`spectrogram.png`、録画中の画面の照合 `capture-checks.json`、書き出した動画の検査 `qa.json`。

## 撮り方で決めたこと

- **撮影は JPEG（品質95）の `Page.captureScreenshot` の連続。** PNG は1枚約42msかかり、30fps に足りなかった。品質95の字は、拡大しても崩れていない。
- **入力は CDP のタッチ。** 撮影と入力は別のセッションから送り、撮影の命令の順番待ちに入力を巻き込まない。
- **ドラッグは「時刻と値（cm）」の折れ線で書き、アプリと同じ換算で指を動かす。** 押した所からの相対の動きで、壁の上では 1cm ≈ 1.94px。合格の判定・そろえる動き・光る演出はアプリに任せる。離した値と近さの言葉は、ルール本体で同じ操作を再生した値と照合し、違えば止まる。
- **字幕の札は不透明で、字だけをフェードで入れ替える。** 札ごと半透明にすると、下の注記の文が札の中に透けた。札は下のアプリの文字（注記の欄・推理の見出し）を隠しきるため、左右に最大18px だけ安全余白にかかる。字はすべて安全余白（左右64・上150・下350px）の内側。
- **画面ごと替わる字幕は、時刻でなく、新しい画面の最初の描画で出す。** 成功の画面と推理の画面は字幕の置き場所が変わり、0.2秒先に出すと、新しい場所の札が古い画面の壁の絵に重なるため（0.2秒先の決まりの、ここだけの例外）。夜3の成功の画面では字幕を消す。
- **押した輪は、押した結果で画面が替わったら消す。** 残すと、「この人だ」の輪が次の画面の「次の夜へ」を押したように見えた。
- **終了カードでは、灯りを約0.1秒ごとに揺らがせ、影を1px だけ震わせる。** 入りの動きが終わると絵がほぼ止まり、検査で1.6秒の静止と判定されたため。

## 音

96BPM・イ短調。フェルトピアノ風のプラック、薄いパッド、低い刻み（ピチカートと時計の刻み）。
場面の頭（4.375・8.75・10・13.75・23.75・27.5秒。どれも拍に乗る）で和音を替え、終了カードで Am(add9) に終止してフェードする。
効果音は、灯りを動かす音（2.5cm ごと・その時の和音の音）、すべらせる音、近さが上がる音、吸い付く音、成功のチャイム、判子、ボタン、外す、場面の切れ目、終了の音。

- **判子の音は、書き出した動画で判子が紙に着いたコマに置く。** 判子の CSS は大きく薄い所から0.38秒で縮み、行き過ぎて戻る。最終の形との差が谷になるか十分に小さくなった最初のコマ（画面の切り替わりから2〜3コマ）を、着いたコマとする。CSS から計算した見込み（切り替わりの0.118秒後）とも照合し、1コマより大きくずれたら止まる。
- 吸い付く音とチャイムは、成功の画面が出たコマから逆算する（アプリの定数：そろえる0.42秒・光る0.6秒）。
- −17 LUFS に合わせ、リミッタは −2.9 dBTP。WAV では −3.0 dBTP で、AAC にした mp4 では書き出しのたびに −3.4〜−2.3 dBTP と揺れた。

実測（2026-10-20・最終の mp4 を ffmpeg で測定）

| 項目 | 値 |
|---|---|
| 尺・形式 | 33.13秒・994コマ・H.264 High・yuv420p・AAC 48kHz・4.6MB |
| 音量 | −17.1 LUFS・真のピーク −3.1 dBTP・クリップ0・頭0.5秒 −19.1 dBFS |
| 判子の音と画のずれ | 再現 0.000秒・解決 +0.001秒・再現 −0.002秒 |
| 同じ絵が続く最長 | 0.93秒（結末の画面） |
| 黒画面・0.5秒以上の無音 | なし |

音は機械で測った値だけで、人の耳では聞いていない。

## 落とし穴

- **`Page.captureScreenshot` に clip を付けないと、撮影のあいだタッチの座標が半分に化ける**（315→158）。clip は文書の座標なので、いまのスクロール量だけずらす。撮る前後でスクロール量が変わったコマは捨てる（成功の画面では、アプリが「推理する」へ焦点を移して100pxスクロールする）。
- **光る演出の0.6秒は、撮影が約13コマ/秒に落ちる。** アプリが壁を影のぼかしつきで毎コマ描き直すため。撮り直しても同じなので、想定内として数える。
- **判子の音の立ち上がりは、7kHz 付近で測る。** 3kHz 付近では、0.6秒前に鳴った成功のチャイムの倍音が残り、3つのうち2つを測れなかった。
- **「解決」の判子は1.35倍から縮むので、行き過ぎが小さい。** 差の谷だけで着いたコマを探すと、谷がはっきりせず1コマ遅れた。
- **夜1の灯り128.65〜128.05cmでは、近さの言葉が「すこし似ている」と「遠い」の間で揺れる。** 格子で数える重なり率がしきい値の近くで上下するため。指を1コマより速く通す。
- 結末の題「第1夜　玄関の紳士」の全角空白は、`\s` で空白をそろえると半角になり、照合が落ちる。

## 使った素材と権利

- 映像：このリポジトリのアプリをローカルで操作した実画面。アプリのファイルは変えず、録画のときだけ、ページに重ね物の要素とその見た目の指定を足す（アプリの見た目で隠すのは、フォーカスの輪とスクロールバーだけ）。終了カードの絵は、自作の `favicon.svg` の形を描き直したもの。
- 音：`promo-audio.mjs` が純JSで合成（固定シード・外部の音源やサンプルなし）。楽器の関数と仕上げは Day066 の `promo-audio.mjs` から続くもの。
- 書体：Zen Kaku Gothic New Bold・Black（SIL Open Font License 1.1）。端末の書体を読み込み、字を映像に焼き込む。書体ファイルは配布しない。
- 絵文字・実在の商標・他作品の名前は字幕に書かない（`checkTexts()` が止める）。
