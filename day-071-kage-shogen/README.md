# 影証言 — 灯りの高さで、証言の嘘を暴く

停電の夜、壁に映った人影は本物か。目撃者が見たという影を、灯りの高さと道具の位置を動かして再現する。
再現できると、灯りの高さが決まり、そこから灯りを提げた人の身長が分かる。手がかりと合わせて、3人の容疑者から1人を選ぶ。5つの夜の影絵×推理パズル。

標準ビルドの公開対象。[公開ページを開く](https://hundred-days.pages.dev/day-071-kage-shogen/)。

## 手元で遊ぶ

リポジトリ直下から、Node.jsで次を実行する。

```sh
node day-071-kage-shogen/tools/serve.mjs
```

表示されたローカルURLを開き、夜1から始める。遊ぶための追加依存やログインは不要。

## 遊び方

1. 壁に落ちる影を、目撃者のスケッチの形に重ねる。
2. 灯りは、足跡の位置で上下にだけ動く。棚の上の道具は、左右にすべらせられる。
3. 灯りに近い道具ほど、影は大きく、速く動く。
4. 再現できたら、灯りの高さを6割で割る。それが、灯りを提げた人の身長（月影荘の決まり）。夜4は踏み台の高さを引いてから割る。夜2以降は、灯りの高さまでが示され、身長への計算は自分でする。
5. 夜3は、身長が同じ人が2人いる。アリバイを読んで、1人に絞る。夜5は、身長178cmと180cmの2人を、灯りの高さの正確な読み（106.8cmと108cm）で分ける。

操作は、灯りの玉や道具をつかんでドラッグ、画面の「上げる・下げる」「左へ・右へ」ボタン、パソコンでは壁をクリックしてから矢印キー（Shiftで5cm）のどれでもできる。
ガイド・ヒント・誤った推理を使うと星が減る。夜1のガイドは練習用なので、何度出し入れしても減らない。ヒントは、押すたびにまだ出していない文を1つ出す（いまいちばんずれているものの名指し、その夜の考え方、「ここまで」の順）。使った補助は、夜を出て入り直しても、解決するまで星の計算に残る。進行（解決した夜と星）はこの端末に保存する。

## 影の計算と判定

壁から z だけ手前にある平らな切り絵の影は、灯りを中心に k = D / (D − z) 倍した写しになる（D は灯りから壁までの距離）。
灯りの高さを変えると、灯りに近い道具の影ほど大きく動く。この差で、縦の位置は灯りの高さだけで決まる。

合格は、次の3つがそろったとき。

- 影の全体とスケッチの重なり率（IoU）がしきい値以上。
- 道具ごとに、自分のねらいの部分を一定以上覆っている。
- 邪魔な道具の影が、壁の上に残っていない（壁の端へすべらせると、影が壁の外へ出る）。

各夜で、正解の配置は合格し、開始の配置は不合格になる。正解から12cm以上離れた灯りの高さは、道具をどう動かしても合格しない（灯りの高さは一意）。
再現前は2人以上の容疑者が残り、再現すると1人だけが残る。夜3は、灯りの高さに合う身長の人が2人いて、アリバイが決め手になる。夜5は、身長が近い2人を、灯りの高さの小数まで読んで分ける。これらは `tests/cases.test.mjs` と `tests/deduction.test.mjs` が機械的に確かめる。
数値の根拠と、捨てた案は `.kiro/specs/day-071-kage-shogen/research.md` にある。

## 構成と検査

`lib/geometry.js`（投影・塗りつぶし・重なり率）、`lib/score.js`（合否）、`lib/cases.js`（5夜の物語と数値）、`lib/deduction.js`（推理）、
`lib/diagnose.js`（ヒントの名指し）、`lib/stage.js`（1夜の操作）、`lib/game.js`（星・解放・保存）、`lib/text.js`（数字・単位の途中で行を割らない範囲）、
`lib/view.js`（Canvas描画）、`app.js`（入力・画面・共有）。
共有はリポジトリ共通の `shared/` を同期して使う。通信、サーバー処理、外部素材・フォント、音は使わない。

```sh
node --test day-071-kage-shogen/tests/
node day-071-kage-shogen/tools/design/run.mjs   # 事件の数値を逆算し、許容幅と一意性を測る設計ツール
```

`tools/` と `tests/` は公開用ビルドへ含めない。

## 制作記録

本人が「影証」の作成を依頼し、要件から検証まで自律して進めるよう指示した。Codexが画面の動きと試験の一部を、別のAI（Opus）が評価後の画面の改修を、設計と検証は設計側が担当した。
制作中には、次を直した。

- 灯りを2次元で自由に動かす案は、道具も動かせると灯りが意味を持たなくなるので、灯りを縦のレールだけにした。
- 近さを許容した一致度は、見た目が違う配置まで高く出たので、素の重なり率に戻し、部品ごとの被覆と邪魔な道具の判定を足した。
- 非表示のパネルにあるcanvasへ描くと例外になったので、大きさが足りないときは描かないようにした。

独立した評価者（AI）による評価を3周行った。体験は 12 → 15 → 17/20 で、第3周で合格した（16点以上かつ0点なし）。画面は 14 → 15 → 15/20 で、3周とも合格に届かず、残件は `.kiro/specs/day-071-kage-shogen/research.md` の「第3周の結果と、続けるなら次に直すこと」にある。Codexによる読み取り専用のコードレビューで見つかった不具合3件は直した。

本人によるプレイや面白さの評価は未確認（AIの評価は代理指標）。題名の商標は、J-PlatPatの簡易な自動検索（文字列・称呼とも一致0件）までで、公開前に本人の確認が要る。
