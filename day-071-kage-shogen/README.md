# 影証言 — 灯りの高さで、証言の嘘を暴く

停電の夜、壁に映った人影は本物か。目撃者が見たという影を、灯りの高さと道具の位置を動かして再現する。
再現できると、影の高さから、灯りを提げた人の身長が分かる。手がかりと合わせて、3人の容疑者から1人を選ぶ。5つの夜の影絵×推理パズル。

公開状態は下書き（`status: "draft"`）で、標準ビルドの公開対象ではない。公開は本人の指示を待つ。

## 手元で遊ぶ

リポジトリ直下から、Node.jsで次を実行する。

```sh
node day-071-kage-shogen/tools/serve.mjs
```

表示されたローカルURLを開き、夜1から始める。遊ぶための追加依存やログインは不要。

## 遊び方

1. 壁に落ちる影を、目撃者のスケッチの形に重ねる。
2. 灯りは、足跡の位置で上下にだけ動く。棚の上の道具は、左右にすべらせられる。
3. 灯りに近い道具ほど、影は大きく、速く動く。
4. 再現できたら、灯りの高さを6割で割る。それが、灯りを提げた人の身長（月影荘の決まり）。夜4は踏み台の高さを引いてから割る。

操作は、壁のドラッグ、壁に焦点を当てての矢印キー（Shiftで5cm）、画面のボタンのどれでもできる。
ガイド・ヒント・誤った推理を使うと星が減る。夜1の最初のガイドは減らない。進行（解決した夜と星）はこの端末に保存する。

## 影の計算と判定

壁から z だけ手前にある平らな切り絵の影は、灯りを中心に k = D / (D − z) 倍した写しになる（D は灯りから壁までの距離）。
灯りの高さを変えると、灯りに近い道具の影ほど大きく動く。この差で、縦の位置は灯りの高さだけで決まる。

合格は、次の3つがそろったとき。

- 影の全体とスケッチの重なり率（IoU）がしきい値以上。
- 道具ごとに、自分のねらいの部分を一定以上覆っている。
- 邪魔な道具の影が、壁の上に残っていない（壁の端へすべらせると、影が壁の外へ出る）。

各夜で、正解の配置は合格し、開始の配置は不合格になる。正解から12cm以上離れた灯りの高さは、道具をどう動かしても合格しない（灯りの高さは一意）。
再現前は2人以上の容疑者が残り、再現すると1人だけが残る。これらは `tests/cases.test.mjs` が機械的に確かめる。
数値の根拠と、捨てた案は `.kiro/specs/day-071-kage-shogen/research.md` にある。

共有はリポジトリ共通の `shared/` を同期して使う。通信、サーバー処理、外部素材・フォント、音は使わない。

```sh
node --test day-071-kage-shogen/tests/
node day-071-kage-shogen/tools/design/run.mjs   # 事件の数値を逆算し、許容幅と一意性を測る設計ツール
```

`tools/` と `tests/` は公開用ビルドへ含めない。

## 制作記録

本人が「影証」の作成を依頼し、要件から検証まで自律して進めるよう指示した。Codexが画面の動きと試験の一部を、設計と検証は設計側が担当した。
制作中には、次を直した。

- 灯りを2次元で自由に動かす案は、道具も動かせると灯りが意味を持たなくなるので、灯りを縦のレールだけにした。
- 近さを許容した一致度は、見た目が違う配置まで高く出たので、素の重なり率に戻し、部品ごとの被覆と邪魔な道具の判定を足した。
- 非表示のパネルにあるcanvasへ描くと例外になったので、大きさが足りないときは描かないようにした。
