# Day072 じぶんの手がかり

選択式の12問から、仕事選びで大切にしたい軸と、次に調べる業界の候補を整理する。
志望業界がまだ決まっていない学生が、仕事内容を比べる観点を持つためのアプリ。
根拠になった質問・回答、就活軸の文案、企業に確かめる質問まで見られる。

## 使い方
「手がかりを探しに行く」から、5つの選択肢で一問ずつ答える。文字入力は不要。
前半は6つの観点、後半は回答に応じた具体場面を聞く。各観点を2問ずつ確かめる。
結果を見て気になる回答から選び直せる。その位置以降の回答は取り消して再質問する。
架空の結果見本は、本人の回答を変更せずに見られる。
結果はコピー・テキスト保存・印刷で持ち出せる。
導入の3枚のカードを開いて、架空の結果の一部をのぞける。
12問の道と6観点のパスポートが回答数に合わせて埋まり、業界の詳細も開いて探索できる。
動きを減らす設定では選択後の演出と登場の動きを省略する。

## 結果の捉え方
質問・言い換え・業界候補との対応は、このアプリ独自の編集によるもの。
能力・採用可能性・適職の確定や、検証されていない適合率は表示しない。
不明・肯定なし・同点はその状態を明示する。同点の候補を3件で切り捨てない。
同じ業界でも企業や職種で仕事が変わるため、仕事例と確認ポイントを併記する。
公的な職業解説を調べるリンクもある。公的な検査の問題や得点は使用していない。

## 回答と保存
回答・結果は外へ送信しない。保存は既定オフで、オンにした場合だけ端末に残る。
保存を拒否されても回答を続けられる。別タブで保存が変わると保存を停止し、置換を確認する。
共有はアプリの公開URLだけ。回答や結果を共有文・URLに含めない。

## 経験から整理するワーク
導入の補助ボタンから、従来の4段階の経験ワークも使える。
保存済みの経験の形式・キーを保ち、選択式ガイドと分けて扱う。
経験ワークは、自分の行動と価値観を選んで自己PRの材料に整理する。
架空のカフェの経験から使い道を見る具体例も残している。
