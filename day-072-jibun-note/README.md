# じぶんの手がかり

就活で何を話せばよいか迷う学生が、身近な経験一つから、
自分の行動と大切にしたいことを整理するワークブック。

経験の種類を選び、場面・行動・変化・意味の4段階を振り返る。
強みの候補には、本人が選んだ行動と、書いた経験を併記する。
自己PRの素材・企業選びの問いを、コピー・テキスト保存・印刷で持ち出せる。

## 回答と保存
入力と結果は外部へ送信しない。保存は既定オフで、オンにすると
このブラウザの専用キーに保存する。保存オフ・初期化はそのキーだけを削除する。
端末の共有利用時は保存の扱いに注意する。別タブの保存変更時は自動保存を停止する。
共有ボタンはアプリの公開URLだけを渡す。

## 設計の範囲
強みは、自分で選んだ行動を言い換えた候補。心理検査、適職判定、採用予測ではない。
入力にない成果や実績は補わない。見本は架空であることを画面と出力で区別する。
質問・言い換え・見本・図案は独自作成。外部API・フォント・画像の読み込みはない。

振り返りの方針の参考は[厚生労働省マイジョブ・カード](https://www.job-card.mhlw.go.jp/column/jobseeker/strengths)。
同サイトの質問票や検査を転載したものではない。
