# CPRビート — 心肺蘇生テンポマスター

成人の胸骨圧迫の100〜120回／分を、30秒の入力で事前練習するWebアプリ。
合成クリックに合わせる練習と、音なしで試す練習がある。
画面タップ・キーボードを標準にし、対応スマホでは軽い上下動も参考測定できる。
振動は任意。未対応・権限拒否・応答なしはタップへ戻る。

## 測定と限界
平均テンポ、測定区間中の範囲内率、入力数、最長の入力間隔を表示する。
500〜600msを端点込みで範囲内とし、休止を集計から除外しない。
10区間未満または幅5秒未満ではデータ不足として、割合や平均を成績にしない。
圧迫の深さ・位置・力、救命技術の習得は測定できない。
緊急時はアプリより119番・AED・通信指令員の指示を優先する。
人の胸や端末を強く押して練習しない。

## 技術と権利
依存なしのJavaScriptとWeb Audioを使う。楽曲・歌詞・外部音源・外部フォントなし。
音は合成クリック、図は独自のSVGとCSS。赤十字標章は使わない。
練習・センサーのデータは外部送信せず、永続保存しない。
参考資料と確認日は画面、および仕様のresearch.mdに記録する。

## 検証
リポジトリの通常ビルド後、次を実行する。

```sh
node --test day-090-cpr-beat/tests/
npx playwright test tests/e2e/day-090.spec.mjs
npm run publish:check -- --day 90
```

仕様・設計・検証記録：`.kiro/specs/day-090-cpr-beat/`。
物理端末の動きの精度・振動・音声遅延は、実機確認が必要。
