# CPRビート — 心肺蘇生テンポマスター

成人の胸骨圧迫の100〜120回／分のリズムを、停止するまで連続再生するWebアプリ。
最初の画面から1操作で始まり、100・110・120回／分、2音色、アプリの音量を選べる。
大きな再生ボタンを再度押すか、Escapeでアプリの音を止める。
30秒のタップ練習は、下の「リズムを、手で覚える」から開く。

## 連続再生
PCMを端末内で生成し、Web Audioの音声ループで再生する。
拍ごとのJavaScriptタイマーに音を依存させず、時間制限・入力操作を設けない。
テンポ・音色変更は旧音を実際の引継時刻まで鳴らし、二重音や1拍抜けを避ける。
画面点灯維持は任意で、対応端末だけ。未対応・拒否・OS解除は画面に表示する。
通話・OS等の音声中断を検出したら音を止め、手動の再開を求める。
別の画面でも音声エンジンは動作可能な限り継続するが、継続を保証しない。
画面を開いたまま使い、ロック・通話・別アプリへの切替で音が止まる場合に注意する。
119番・AED・通信指令員の音声指示や周囲の声を妨げない音量で使う。

## 練習と限界
音に合わせる練習・音なし練習、画面タップ・キーボード、対応スマホの軽い上下動を使える。
平均テンポ、範囲内率、入力数、最長の入力間隔を示す。休止は集計から除外しない。
10区間未満または幅5秒未満はデータ不足とする。振動は対応端末で任意。
圧迫の深さ・位置・力、救命技術の習得は測定できない。医療機器・認定教材ではない。
人の胸や端末を強く押して練習しない。

## 技術と検証
追加依存・楽曲・歌詞・外部フォントなし。図は独自のSVG/CSS、音は合成。
練習・センサーのデータは外部送信・永続保存しない。一次資料と確認日は画面に記載。

```sh
node --test day-090-cpr-beat/tests/
npm run build
npx playwright test tests/e2e/day-090.spec.mjs tests/e2e/day-090-continuous.spec.mjs
npm run publish:check -- --day 90
```

仕様・設計・検証：`.kiro/specs/day-090-cpr-beat/`。
物理端末の音声・振動・動き・画面点灯維持は実機確認が必要。
