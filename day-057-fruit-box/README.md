# Day 057 — 夜店のくだもの箱

同じくだものを合わせて大きく育てる、夜店の落下パズル。ブルーベリーからスイカまで10種類。登録・課金・ランキングはない。

[あそぶ](https://hundred-days.pages.dev/day-057-fruit-box/)

## あそび方

- スマホ：木箱で左右に指を動かし、離すと落ちる。
- PC：左右キーで狙い、Space・Enter・下キーで落とす。
- 同じくだものが触れると合体して加点。スイカどうしは消えて640点。
- 落下直後の果物は終了判定から除外。落ち着いた果物が線より上に1.7秒残ると終了。
- Ⅱで一時停止。音量もここで変えられる。P・Escでも停止と再開。
- BGMと効果音は別々に切り替えられる。音は最初の操作後に始まり、画面が隠れると止まる。
- やり直しは確認のため2回押す。終了後は「もう一度」で再挑戦。

ベスト得点と音設定はこのブラウザだけに保存する。操作中の外部通信はなく、X・LINE・端末共有・コピーは結果画面で利用者が選ぶ。
共有ボタンからはゲームのリンクを送れる。共有画面を開いている間は箱が止まり、閉じると元の箱へ戻る。結果画面のコピーには今回の得点も入る。

## 設計と素材

元の個人試作 [suika-game](https://github.com/haranishi/suika-game) を基にした。Day57版では登録商標を公開名に使わず、果物の顔を外し、並び・得点・音楽を変更した。既存商品の公式版や許諾版という表示はしない。

果物・木箱・背景はCanvas/CSSで描き、BGMと効果音はWeb Audioで合成する。録音・Webフォント・外部CDNは使わない。物理エンジンの出典と権利確認は [CREDITS.md](CREDITS.md)。

低い画面でも木箱を縮めるため、物理座標は420×700に固定し、表示だけ拡縮する。停止中はゲーム時計を進めず、再開時には前のフレーム差を捨てる。端末やタブを離れたあとは、自動再開せず「つづき」を押す。
