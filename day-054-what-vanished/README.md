# Day 054 消えたのは、どれ？

3Dの家を60秒歩いて覚え、目を閉じているあいだに消えた物を1つ、みんなで当てる間違い探し。1つの画面をみんなで見て遊ぶ前提で作った。

- 公開ページ: https://hundred-days.pages.dev/day-054-what-vanished/
- 遊び方: 覚える60秒 → 目を閉じる → 探す60秒 → 候補から1つ選ぶ → 答え合わせ（消えた場所へ視点が飛ぶ）。3問で1ゲーム
- むずかしさ: かんたん＝大きな物が消えて候補4つ／ふつう＝中くらいで6つ／むずかしい＝小物で8つ

## 作りの要点（コードを読んでも分からないこと）

- **家具と小物は Poly Haven の3Dモデル（CC0）**。`scripts/fetch-assets.mjs` が公開APIから取り、面の数と画像の大きさを減らして `assets/` に書き出す。素材はすべて同梱で、実行中の外部通信はない。合計15MB以下を単体テストで守る
- **見えない物は消さない**。置き場所71か所のどれもが、同じ部屋の歩ける場所の25%以上から、壁や家具に隠れずに見えることを `lib/visibility.js` で計算し、単体テストの関門にしている。線は「ソファの裏の床（21%）は見落として当然」という見た目の判断で決めた。テレビ台の裏・ベッドの下・閉じた棚の中に置き場所を足すと落ちることも確かめてある
- **消えた物は、当たり判定と影ごと消す**。見えない物にぶつかったり、影だけが床に残ったりすると、それが答えの手がかりになってしまう
- **小物の置き場所は問題ごとに入れ替える**。大きな家具は動かさない。2問目が1問目の記憶で解けないようにするため
- **歩く当たり判定は、升目でなく壁や家具の形そのもので計算する**。体験評価の1周目で、見取り図の部屋ボタンの移動が34回中16回、出入口の角で止まった（道順から数cmずれると「進めない」と判断して歩くのをやめていた）。いまは、道順は壁から離れた通路の真ん中を選び、体は半径0.3mの円として壁や角に沿って滑る。止まったら道順を引き直し、それでもだめなら一瞬暗くして行き先へ移す。30通りの置き方×部屋の組み合わせで止まらないことを単体テストで確かめている
- **答えの画面は一時停止にしない**。時間が進まない画面なのに Esc で止まり、一時停止の画面が答えの画面の裏に隠れて「これにする」が効かなくなった（評価の1周目）。答えの画面の Esc は「選び直す」
- **候補の数は問ごとに増やす**（ふつうは4→6→8）。消える物の大きさはむずかしさで決まり、1ゲームの中では候補の数で歯応えを上げる
- **候補は家にある物だけで作る**。「そんな物あったっけ」で消去できないようにし、確かめたければ探す時間に見に行ける
- **色の意味は画面をまたいでそろえる**。だいだいは主ボタンと「正解の場所」、青は「自分たちが選んだ物」だけに使う。見た目の採点3周目で、候補の画面ではだいだい＝選んだ物、答え合わせではだいだい＝正解の場所と意味が入れ替わり、離れて見ている人が読み違えやすいと指摘された
- 鏡（ornate_mirror_01）は素材の色画像の鏡の部分が暗く、環境の映り込みを強めても黒い板に見えたので、同じ場所を風景画に替えた
- 額のガラスは素材の jpg に透明の情報が無く、黒い金属に見える。読み込み時にガラスの材質だけ作り直している

## 検証
