# Day 054 紹介動画

`node day-054-what-vanished/tools/promo/render-promo.mjs` で、34秒の縦型動画（1080×1920・BGM付き）を作る。アプリを実際に操作して録画し、合成した画は足さない。

## 流れ

廊下を歩いて覚える → リビングをのぞく → 目を閉じる → 目を開けると大きな振り子時計が無い → 候補から選ぶ → 消えた場所へ視点が飛んで正解 → 2問目へ → タイトル。
絵コンテと字幕は `timeline.mjs`、音は `promo-audio.mjs`。秒数はこの1本に集約してある。

## 見ている人への問題を1つ入れる

家は「かんたん・家の番号6」。1問目で廊下の突き当たりの時計が消える。目を閉じる前と開けた後を同じ位置（玄関から廊下の奥を見る）から見せるので、S3 の数秒が、動画を見ている人にとっての間違い探しになる。字幕も「…どれが、消えた？」で止める。

## 実GPUで撮る

3Dの描画が重く、ソフトウェア描画（headless の既定）では1秒に数枚しか描けない。録画のコマが間引かれ、絵と音がずれる（Day 044 で最大2秒）。既定は Metal を使う headed（撮影の約50秒だけ画面にブラウザの窓が出る）。`PROMO_HEADLESS=1` は Metal を使う headless だが、録画が画面の左上4分の1にしか写らず残りが灰色になった（2倍密度が録画に効かない）ので使わない。

## 字幕と画面を突き合わせる

字幕の数字は画面の文字で確かめ、食い違えば録画の前に止まる。**食い違ったら字幕を画面に合わせる。逆はしない。**

| 字幕 | 照合する画面 |
|---|---|
| この家を、60秒で覚えて | 覚える時間の最初の残り秒数が「60」 |
| …どれが、消えた？ | 時計（grandfather-clock）が消えている |
| 3問で1ゲーム | 「2問目」の帯と、左上の「/ 3」 |
| むずかしさは3段 | タイトルのむずかしさの選択肢が3つ |

## 切り出しは録画から決める

録画が始まる時刻は実時間では測れないので、字幕が入れ替わった時刻を録画から読み、絵コンテの並びと重ねて頭を切る。書き出したあとにもう一度読み、予定と0.4秒以上ずれていたら失敗させる（Day 044 の方式）。候補を選ぶ場面だけ字幕を上に置くが、下の帯から消えて出る変化で入れ替わりは読める。

生成物（wav・mp4・png）はGit追跡しない。1コマ目（`promo-first-frame.png`）は必ず目で見る。
