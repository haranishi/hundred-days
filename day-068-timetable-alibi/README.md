# 時刻表アリバイ — 23:47の約束

最終列車で一緒に帰るはずだった相棒・透が消えた。
雨の駅を調べ、写真と時刻表で嘘を崩す短編ミステリー。再会の先から、最後の一枚を撮る結末まで遊べる。

[公開版を開く](https://hundred-days.pages.dev/day-068-timetable-alibi/)

## 手元で遊ぶ

```sh
node day-068-timetable-alibi/tools/serve.mjs
```

[ローカル版](http://127.0.0.1:5418/)を開く。遊ぶための依存導入は不要。
前の版で透と再会済みなら「透の話を聞く」から続行できる。

1. 透と帰りの約束を交わし、途切れた伝言を読む。
2. 駅に残ったカメラや発車案内を調べ、二つの手がかりと理由で栞の証言を確かめる。
3. 鍵を受け取って閉鎖ホームへ進み、透を探す。
4. 写真を消すか残すか、透と港へ行くか栞と駅に残るかを決める。
5. 乗る列車と乗換えを選び、調査経路で得た証拠から最後の嘘を崩す。
6. 23:47、構図を選んでシャッターを切る。撮った写真と、ここまでの選択を振り返る。

写真を消すと、所持する写真もなくなる。どちらを選んでも解決できる。
調査経路によって出会い・証拠・移動が変わり、結末から再会直後に戻って別の道も試せる。
間違えた計画や反証では証拠を失わず、会話を読んでいる間に物語の時刻は進まない。

## 表示と保存

- 夜の駅・列車内・駅務室・港の背景と、人物の表情を組み込み画像生成で制作。[素材記録](ART.md)に記載。
- 文字送り中に人物の口が動く。全文表示・会話記録・動き軽減設定に対応。
- 鉄道資料は5駅の3D模型と2D路線図を切り替え、同じ時刻表で列車を再現できる。
- 列車の再現時刻と物語の時刻は別。資料内で列車を動かしても場面は進まない。
- 進行・手がかり・選択・行程・撮影構図・会話記録・音設定を、この端末に保存する。
- 会話中の再読み込みは、その場面の冒頭から再開する。記録と乗車行程は重複しない。
- 保存できないブラウザでも、画面を開いている間は最後まで遊べる。
- 音は任意の合成効果音。外部音声APIは使わない。

旧版の3夜・3事件は [classic.html](classic.html) に保存した。
旧版の解決データを保ち、現在の物語は別の保存先を使う。前の第1幕の保存にも対応する。

## 推理の条件

急行は、時刻表に記載した駅にだけ停まる。別の列車への乗換えは2分。
同じ列車に乗り続ける場合は加算しない。早く着いた場合は待てる。
反証と乗車計画は共通の経路計算を使い、3Dの停車駅も同じデータから描く。
カメラの保存時刻は記録として扱う。故障した壁時計は推理の根拠にしない。
