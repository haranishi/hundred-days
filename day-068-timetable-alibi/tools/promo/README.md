# Day68「時刻表アリバイ」予告編

36秒・1080×1920・30fps。ゲームの原画と実際の操作画面を使い、文字・路線・切符をアニメーションする。
結末と最後の反証は見せない。字幕だけでも内容が分かる構成。

## 再制作

ゲームをローカルで起動し、このフォルダで `npm ci --ignore-scripts`。
`npm run capture` → `npm run audio` → `npm run stills` で画と音を確認し、`npm run render`。
映像を再生成せず音だけ調整するときは `node render.mjs --reuse-video`。
`npm run audit` で尺・画角・黒フレーム・音量・メタデータを確認する。
操作の記録、素材、書き出し、静止画はすべてgitignoreされた `output/` に置く。
`PROMO_BASE` でゲームURL、`PROMO_FONT` でZen Kaku Gothic New Boldの場所を指定できる。
Chromeはインストール済みのものを使う。`CHROME_PATH` で実行ファイルを指定できる。
制作依存はこのフォルダだけに固定し、アプリの依存と公開ビルドには加えない。

## 素材と権利

- 背景と人物：このゲーム用の生成画像。記録はアプリの `ART.md` と `assets/` のプロンプト。
- ゲーム画面：Playwrightで正規の進行と操作を記録。UIの内容や列車時刻は改変しない。
- 路線、切符、波形、粒子、タイポグラフィ：この予告編のためにコードで作成。
- BGMと効果音：固定シードの音響合成。外部の曲、録音、音声モデルを使用しない。
- 字幕：Zen Kaku Gothic New（[SIL OFL 1.1](https://github.com/google/fonts/tree/main/ofl/zenkakugothicnew)）。端末の書体で描画し、書体ファイルはコミットしない。

- レンダー：[Remotion公式API](https://www.remotion.dev/docs/renderer/render-media)を利用。クラウドへの素材送信は行わない。
