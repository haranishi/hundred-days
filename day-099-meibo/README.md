# Day 099「meibo」

営業リストから新規開拓する個人・小さなチーム向けの、オープンソースのCRM（Rust・SQLite）です。取引先ごとの電話の結果、再架電の予約、商談ボード、月次の着地予測を、ひとつのアプリで扱えます。このDayは、そのmeiboを紹介する回です。アプリ本体は別のリポジトリにあり、ここには置いていません。

- 公開リポジトリ: https://github.com/haranishi/meibo （コードは MIT OR Apache-2.0）
- 触れる公開デモはありません。自分のPCかサーバーで動かします。手順はmeiboのREADMEにあります。
- 企業データは同梱していません。動画と画像の画面は、合成データです。

## 動画で見せたこと（実際の画面で確かめた範囲）

- 架電モードで「不在のため再架電を予約」にチェックして「保存して次へ」を押すと、「架電を記録し、再架電を予約しました。」と出て、その取引先の「次回対応」に、土日を除く翌日の朝9時が入る。
- 商談ボードで、カードの段階を選ぶと、カードがその段階の列へ移る。
- 月次集計に、月次受注額・受注率・確度加重見込み・着地予測（受注額と確度加重見込みの合計）が出る。担当別の表には、月間目標と、目標との差も出る。商談を「受注」へ動かすと、その分が着地予測に入る。
