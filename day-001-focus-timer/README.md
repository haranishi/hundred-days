# Day 001 — 集中タイマー

時間をセット→開始・一時停止・リセットできるカウントダウンタイマー。

**公開URL: https://hundred-days.pages.dev/day-001-focus-timer/**

## 使い方

- プリセット（5 / 15 / 25 / 45分）か自由入力（1〜600分）で時間をセット
- スペースキーで開始／一時停止、Rキーでリセット
- 終了するとビープ音（Web Audio APIで生成）と背景色の変化でお知らせ

## 制約（このチャレンジの「1日アプリ」ルール）

- 外部ライブラリ・外部フォント・外部APIなし（ブラウザ内蔵APIのみ）
- 外部通信なし・データ保存なし
- アカウント不要・課金なし

## 技術メモ

- 残り時間は「終了時刻との差」から毎回計算する。setIntervalの遅延やバックグラウンドタブでの間引きがあっても時間がずれない
- 状態は idle / running / paused / finished の4つだけ
- 終了音はWeb Audio APIで生成（音源ファイルなし）
