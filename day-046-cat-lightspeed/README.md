# Day046 — ねこ、光になる

押し続けると猫が加速する3Dブラウザゲーム。カタツムリから20の速さを追い越して、光速の99.999%に達したら自動で結果へ。光速そのものは超えない。

## 遊び方

「はじめる」を押し、3Dの描画領域を押し続ける。離すと減速。Space / Enterでも開始・長押し・再挑戦できる。連続押下は約90秒で最後まで到達する設計。音の切り替えと共有ボタンは描画領域の外にある。

牧場・街・空・軌道・太陽系・星間へ世界が変わり、猫は姿勢を伸ばし、尾を引き、発光し、最後は光の姿になる。速報はすべてフィクション。

## 数値と音

[速さの出典・概数・注意点](data/SOURCES.md) に指定21段階を記載。光速は定義値のkm/h換算を丸めた値。生物や巡航速度は代表値。**ゾウガメ1.4km/hの計測出典は未確認**で、指定値は保持している。全数値を検証済みとはしていない。

合成した鳴き声は加速するほど高く、間隔が短くなる。音速で1回のソニックブーム。その後の鳴き声は0.75秒遅延する演出。軌道速度以降は真空と扱い、予定済みの音も止める。

光速付近ではローレンツ因子を表示する。「あなたの1秒」の表示はその時点のγ、結果の「旅のあいだ、地球では」はγを猫の経過時間で積分した値。重力・現実の加速旅行を再現したシミュレーターではない。

## 保存・通信・権利

保存するのはベストの速度・秒数・日付とミュート設定のみ。ベストは速度優先、同速なら短い時間を優先。個人データやプレイ履歴は保持しない。ゲームの外部通信はゼロ。共有先を自分で開く場合を除く。

猫・地形・建物・星はコードで生成し、音はWeb Audioで合成する。外部の画像・音源・フォント・3Dモデルは使用しない。3DはDay044から複製したthree.js 0.186.0のESMバンドル（MIT）。[ライセンス](vendor/LICENSE-three.txt) を同梱。

## 検証と構成

リポジトリ直下で `npm run shared:sync`、`npm run build`、`npm run test:unit`、`npm run precheck`。Day046だけなら `node --test day-046-cat-lightspeed/tests/`。

- `boot.js`：読み込み失敗を案内。`app3d.js`：画面と入力、結果、検証窓口。
- `lib/milestones.js` / `physics.js` / `worlds.js` / `audio-state.js` / `game.js` / `store.js`：判定と進行、保存。
- `lib/scene.js` / `sound.js`：手続き的な3Dと合成音。
- `tests/index.mjs`：単体テストの入口。E2E仕様はリポジトリの `tests/e2e/day-046.spec.mjs`。
- `window.__day046`：state / snapshot / setManual / advance / start。snapshotのrenderに描画コール数・三角形数・描画倍率を含む。

E2Eは依頼どおり実行しない。実ブラウザでの画面・操作・音質・FPSも未確認。静的な独立レビューと単体検証を、実プレイの合格とは区別する。

## 負荷の設計

描画倍率は1.5まで、影とポスト処理なし。幾何形状と材質は再利用し、6世界のうち現在の世界だけ描画する。星180本は1つのLineSegmentsで描画し、HUDの更新は約12.5回/秒に抑える。動きを減らす設定では流れ・足振り・星の線の長さを抑える。

全世界は起動時に組み立てる。建物・柵・雲は個別Meshで描画コールが増え、古いスマホでは起動・描画が重い可能性がある。FPSの実測はまだない。
