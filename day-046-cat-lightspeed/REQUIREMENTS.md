# Day046「ねこ、光になる」

押し続けて猫を加速させ、速さ・世界・速報の変化を楽しむ。描画領域かSpace/Enterを押すと加速、離すと減速。99.999%で自動結果、再挑戦へ進む1本道。アカウント不要。

- 指定21段階のkm/hを保持。光速は壁で、追い越したものは20件。数値・出典・概数の扱いはdata/SOURCES.md。
- 6世界：100 / 1,000 / 10,000 / 100,000 / 1,000,000を境界とし、境界ちょうどから次の世界。牧場→街→空→軌道→太陽系→星間。
- 低速はゆっくり合成ニャー、加速で高音・頻回。1,225以上で一度の衝撃音、以後は鳴いた0.75秒後。27,600以上で予定済みの音も停止。
- v<0.9cは指数的加速、以降は光速との差を指数的に縮める。0.99999cで終了。減速は0を下限とする。
- 猫の1秒をプレイ1秒とみなした簡略モデル。現在のγと、γを積分した地球の経過秒を分けて表示。
- 速度・直前の通過・累計通過数・次の相手・光速比・時間の遅れ・フィクションの速報。
- 猫・背景はコード生成。three.jsはDay044の同梱ビルドとライセンスを複製。追加画像・音源・モデル・フォント・node_modulesなし。
- 外部通信・fetch・外部APIなし。共有先を明示的に開く操作のみ外部へ遷移。
- localStorageはベスト（到達速度・経過秒・日付）とミュートだけ。保存不可でも遊べる。
- 3D読み込み失敗・WebGLコンテキスト消失には再読み込み案内。
- 390×844 / 390×664を対象。結果では上部の速度パネルを畳み、結果の速度表示と共有操作に場所を使う。
- ロジックの単体テストをtests/index.mjsに登録。E2Eはリポジトリのtests/e2e/day-046.spec.mjsに作成するが、この環境では実行しない。
- window.__day046：state() / snapshot() / setManual() / advance(ms) / start()。manualでは自動時間進行を止め、advanceは本番と同じ1/60秒のtickを使う。
- 公開前の残件：ゾウガメ1.4の計測出典、実ブラウザ操作・音の聴取・スマホ描画負荷。未実施項目を合格扱いしない。
