# Day63 解約ボタンは、どれ？

「初月0円」の影に潜む年額自動更新、二重否定の質問文、罪悪感を煽るキャンセルリンク。ネットに潜む悪質UI（ダークパターン）を見破り、無傷で生還を目指す欺瞞UI脱出ゲーム。

[公開URL](https://hundred-days.pages.dev/day-063-dark-patterns/)

## 遊び方

1. **現場（ステージ）の状況を確認**
   - 架空のショッピングサイト、予約サイト、退会画面などが表示されます。
   - 画面上部のミッション指示を読み、達成すべき安全なゴールを把握します。
2. **巧妙な罠を回避して操作**
   - **事前チェックボックス**：不要な定期便や有料保証のチェックを外す。
   - **コンファームシェイミング**：「損をするのが大好きです」といった屈辱的な文言の拒否リンクを冷静に選択する。
   - **偽の緊急性**：「残り1室！」「38人が閲覧中！」の煽りに焦らず、返金不可プランを避けてキャンセル無料プランを選ぶ。
   - **二重否定＆ゴキブリホイホイ**：「解約の停止を取り消さないことを希望しますか？」という二重否定を論理的に見破り、最下部の目立たない解約リンクを押す。
   - **隠されたコスト**：アコーディオンを展開し、電話解約縛り・年額自動更新を回避してWeb解約プランへ切り替える。
3. **看破解説と防犯知識**
   - クリアまたは被弾時に、使われた心理誘導の手口と、消費者庁・OECDの指針に基づく防犯知識が表示されます。
4. **捜査報告書（リザルト）**
   - 被害総額と捜査時間に応じて捜査官ランク（S〜D）が判定され、結果をXでシェアできます。

| ステージ | テーマ | 主な手口 | 罠の内容 |
|---|---|---|---|
| STAGE 1 | お試し500円の罠 | スニーク・イントゥ・バスケット / 事前選択 | 定期便自動移行（+¥4,980）と有料保証（+¥550）のデフォルトON |
| STAGE 2 | 罪悪感の押し売り | コンファームシェイミング | 屈辱的拒否リンクと有料メルマガ（+¥980）のセット販売 |
| STAGE 3 | 偽の緊急性と閲覧者数 | Fake Urgency / 偽の社会的証明 | 架空タイマーと返金不可プラン（+¥18,000）のデフォルト選択 |
| STAGE 4 | 迷宮の退会アンケート | Roach Motel（ゴキブリホイホイ） / 二重否定 | 巨大な引き留めボタン、二重否定文、フッター端の極小リンク |

## 機能・技術的特徴

- **完全クライアントサイド動作**: 外部APIや外部サーバーとの通信不要。
- **Web Audio API リアルタイム波形生成**: 外部音声ファイルゼロ。看破音、コイン被弾音、心拍音、ファンファーレをブラウザ内で合成。
- **アクセシビリティ＆レスポンシブ**: スマホ・PCの両方で直感的に操作可能。
