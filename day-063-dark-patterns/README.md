# Day63 解約ボタンは、どれ？

「初月0円」の影に潜む年額自動更新、二重否定の質問文、罪悪感を煽るキャンセルリンク。ネットに潜む悪質UI（ダークパターン）を見破り、無傷で生還を目指す欺瞞UI脱出ゲームです。

[公開URL](https://hundred-days.pages.dev/day-063-dark-patterns/)

## 遊び方

1. 画面上部のミッションを読み、偽サイトで安全な選択をして手続きを終えます。
2. 罠を踏むと被害額が加算され、その場で手口の解説が出ます。失敗した現場は1タップでやり直せます。
3. 全5現場を終えると、被害総額と合計時間からランク（S〜E）が決まります。結果はX・LINE・端末の共有・リンクのコピーで送れます。

各現場には20〜30秒の制限時間があります。現場名の表示（約1秒）の間は、操作できず、時間も進みません。表示が消えた瞬間から数え始め、解説を読む時間は合計に入れません。合計は秒の切り捨てで数えます（45.9秒は45秒）。

時間切れは、被害0円でも未達として扱います。時間切れのまま次へ進むと、その周のランクは最高でもBです。失敗した現場は、時間切れも含めてやり直せます。やり直すとその現場の記録は取り消され、使った時間は合計に残ります。

## 5つの現場

| 現場 | テーマ | 主な手口 | 罠の内容 |
|---|---|---|---|
| 1 | 罪悪感の押し売りモーダル | コンファームシェイミング | 断る側に自分を責める文言を置き、有料メルマガへ誘導する |
| 2 | 隠された年額自動更新 | 隠されたコスト・電話解約縛り | 初月無料の陰に、電話でしか解約できない年額の自動更新を隠す |
| 3 | 偽の緊急性と閲覧者数 | 偽の緊急性・偽の社会的証明 | 「残り1室」や閲覧者数で急かし、返金不可プランを選ばせる |
| 4 | お試し500円の罠 | 事前選択・抱き合わせ | 定期便と有料の配送補償に、最初からチェックを入れておく |
| 5 | 迷宮の退会アンケート | 離脱妨害・二重否定 | 引き留めボタン、二重否定の質問、目立つボタンが周ごとに変わる最終確認 |

遊ぶたびに、次のところが変わります。

- 第1・第2現場：拒否リンクの文言と位置、注記の置き場所、チェックの文言と左右。直前の周と同じ組み合わせは続けて出しません
- 第3・第4現場：選択肢の並び順と金額
- 第5現場：選択肢の並び順と、最終確認でどちらのボタンが目立つか、その左右。金額（¥1,980）は変わりません

## ランクと自己ベスト

- S：被害0円・時間切れなし・合計45秒以内
- A：被害0円・時間切れなし
- B：被害0円だが、時間切れの現場がある
- C〜E：被害額が大きくなるほど下がる

結果画面には、次のランクまでの目標（例：「Sまであと5秒」）と自己ベストを出します。自己ベストには、初めて記録した周に「初記録！」、縮めた周に「更新！」の札が付きます。

## 外部通信と端末内の保存

外部との通信はしません。共有のリンクは、押したときだけXやLINEのページへ移動します。

端末に保存するのは自己ベストだけです。被害0円・時間切れなしで全現場を終えた周の、最短の合計秒数とそのときのランクを `localStorage` に残します。選んだ内容や操作の記録は保存しません。保存を拒否する設定でも遊べ、その場合はページを開いている間だけ記録を比べます。

## 作りの特徴

- 効果音とBGMは Web Audio API でブラウザ内で合成します。音声ファイルは使いません。
- キーボードだけでも遊べます。確認ダイアログを開いている間は背後を操作できず、閉じると元の位置にフォーカスが戻ります。
- 端末の「視差効果を減らす」設定では、揺れや点滅を止めます。
- 日本語は文節の切れ目で改行します（`lib/phrase.js`）。iPhone の Safari は `word-break: auto-phrase` に対応していないため、`Intl.Segmenter` の語を文節にまとめて切れ目に `<wbr>` を入れ、`word-break: keep-all` と組み合わせています。
- flex の入れ物の直下と `white-space: nowrap` の中の文字は、文節に区切りません。そこには1行に収まる短い文言だけを置きます。
- ボタンを素早く2回押しても、2回目がその場に新しく出た画面や部品を押すことはありません。現場名の表示（約1秒）の間は、偽サイトを操作できません。結果画面は出てから約0.4秒、解説と最終確認は出てから約0.5秒、入力を受け付けません。確認ダイアログを閉じた直後の偽サイトも、同じく約0.5秒は押せません。

## テストと確認

```sh
node --test day-063-dark-patterns/tests/
npm run build
npx playwright test tests/e2e/day-063.spec.mjs tests/e2e/day-063-layout.spec.mjs
npx playwright test tests/e2e/shared-share.spec.mjs -g "Day 063"
npm run precheck
```

E2Eは `dist/` を配信して検査します。コードを変えたら、先に `npm run build` を流してください。

`day-063-layout.spec.mjs` は、390×844・375×667・768×1024・1440×900 の4つの画面で次を測ります。

- 横のはみ出し
- 改行の位置：行頭が文節の切れ目か、ひらがなで始まる行がないか（文頭と句点のあとを除く）、語の途中や1文字だけの行がないか
- 文字の大きさとコントラスト：12px以上・4.5:1以上（大きい文字は3:1）

罠として意図して薄くした偽サイトの要素には `data-trap` を付け、下限を11px以上・3:1以上にしています。読めないほどは薄くしません。
