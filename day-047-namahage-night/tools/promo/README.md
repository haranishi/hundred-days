# Day 047 紹介動画

30秒・1080×1920・30fps。実物のゲームを iframe に入れ、手動の時計で進めながら900枚のPNGを撮り、ffmpegで動画にする。字幕・エンド画面・コード合成のBGM付き。依存パッケージは増やさない。

## 使い方

```sh
export PLAYWRIGHT='<playwright index.js>'
cd day-047-namahage-night
node tools/promo/render-promo.mjs --preview   # 下見（540×960で撮って拡大）
node tools/promo/render-promo.mjs             # 本番（1080×1920で撮影）
```

既定の出力は `tools/promo/promo.mp4` と `tools/promo/promo-first-frame.png`。連番PNGと中間WAVは `os.tmpdir()` に置き、終了時に消す。
BGMだけ試聴するなら `node tools/promo/promo-audio.mjs`（`promo-audio.wav` ができる）。

| 動画の秒 | 絵 | 字幕 |
| --- | --- | --- |
| 0–4 | 1-3 をゲーム内0.3秒から。雪山の坂をちびが走る | 大晦日、山を下りる |
| 4–8 | 1-1 の0.6秒から。餅を拾って「なまはげ」に変わる（2.1秒） | 餅で、大きくなる |
| 8–13 | 2-3 の0.6秒から。杉林とカラス | つららと、カラス |
| 13–18 | 3-2 の0.5秒から。吹雪と氷 | 吹雪の尾根をこえて |
| 18–22 | 4-1 の1.0秒から。里の屋根を渡る | 里の、家々へ |
| 22–27 | 4-1 の4.2秒から。戸口に着き、クリア画面まで | 泣ぐ子は、いねがぁ |
| 27–30 | タイトル・DAY 047・hundred-days.pages.dev | エンド画面 |

1回の通しプレイではなく、面ごとに撮り直す構成。各場面の頭で `begin(面)` → `setManual(true)` → `autopilot(true)` → `advance(gameFrom×1000)` を呼び、以後は毎コマ `advance(1000/30)` だけで進める。実時間や通知を待たない。

ゲームの中身は捏造しない。字幕は1行16字以内・2行以内で、上下左右10%のセーフエリアに収める。

## 検査

- 字幕の入れ替わり時刻を**書き出した動画から測って**絵コンテと突き合わせる（`checkVideo`）。ズレが0.4秒を超えたら失敗させる。
- 1コマ目が「遊んでいる画面」であることを `snapshot().status` で確かめる。
- 外部通信は `context.route` で全部止める。1件でも出たら失敗。
- 音は書き出し時に `loudnorm=I=-17:TP=-1.5` で揃える。素の合成は -25 LUFS 前後。

## 分かっていること

- ゲームは 320×192 を CSS で 480×288（1.5倍）にして置く。撮影は2倍、書き出しで2倍に拡大するので、元の1画素がちょうど3×3の正方形になり、拡大しても滲まない。`image-rendering: pixelated` を iframe 内のCSSで当てる。
- 場面の切り替えで面を変えるので、`gameFrom` は「その字幕の出来事だけが写る窓」を実測で選ぶこと。面の設計を変えたら選び直す。
