# Day 040 その避難場所、洪水でも？

場所と災害の種類を決めると、そのとき使える指定緊急避難場所を近い順に出す。
もっと近いのに、その災害では使えない場所も名指しで出す。

## なぜ作ったか

避難場所は「1か所」だと思われている。実際には災害の種類ごとに指定されていて、
秋田駅の近くでは、いちばん近い公園（山王第一街区公園・217m）が洪水では使えない。
高知駅の近くはもっと極端で、近い17か所はすべて津波専用、洪水で使える最初の場所は
500m先の小学校になる。ハザードマップを開けば分かるが、開くのは災害が起きてからになりやすい。

## やらないと決めたこと

- **避難の判断をしない。** 出すのは「指定されている」という事実だけ。「逃げてください」「安全です」を書かない
- **指定避難所を扱わない。** 緊急に逃げる「指定緊急避難場所」と、危険が去るまで滞在する「指定避難所」は別の制度で、
  同じ施設が両方を兼ねることもあれば片方だけのこともある。混ぜると危ないので前者だけに絞った
- **経路案内をしない。** 距離は直線距離、徒歩は80m/分の割り算。川や崖を跨いでいても、そうは書かれていない
- **名前・住所・備考を言い換えない。** 仙台では名前そのものに「（大雨時に初動で開設しません）」が入っている。
  読みやすく整えると、この手の但し書きが消える

## 設計で迷ったところ

**「近いのに使えない場所」を答えの2行目に置いた。** 当初は使える一覧だけを出す設計だった。
それだと「いちばん近い避難場所」を1つ知って終わりで、思い込みがそのまま残る。
n（いちばん近い使える場所より近い、使えない場所の数）を先に言うほうが、このアプリの言いたいことに近い。

**8種類を最初にまとめて取り、切り替えでは取り直さない。** 種類ごとにタイルが分かれているので、
切り替えのたびに取ると待たされる。逆に全部取ると、東京の区画は8種類で約160万バイトになる。
妥協点として、選んだ種類だけ隣の区画まで見て、残り7種類は真ん中の区画だけにした。

**隣の区画を取るのは、辺まで5km未満のときだけ。** 1区画はおよそ30km四方で、区画のすぐ向こうに
いちばん近い場所があると「いちばん近い」が嘘になる。常に4区画取れば確実だが通信量が4倍になる。
高知駅は東の辺まで約4.7kmなので2区画、秋田駅は6.5km以上あるので1区画で済む。

**同じ場所の同一判定は、名前＋座標（小数5桁）。** 同じ施設が8種類のタイルに別々に載る。
`properties` の `disaster1`〜`disaster8` は載っているタイル側にしか無いこともあるので、
「どのタイルに載っていたか」と合わせて和集合にする。

## 落とし穴（次に触る人へ）

- **配信されているのはズーム10だけ。** z9もz11も404を返す。ズームを変えて通信量を減らすことはできない
- **その区画に該当が無い種類は、タイルごと404。** 秋田の区画には内水氾濫と火山現象のタイルが存在しない。
  404を失敗として扱うと、内陸では常にエラー画面になる。0件として扱うこと
- **`last-modified` は `Access-Control-Expose-Headers` に入っている。** 配信日を画面に出せる数少ないデータ。
  ただし種類ごと・区画ごとに日付が違うので、選んでいる種類のものを出す
- **地図の帰属に `customAttribution` を足さない。** タイルのソースが持つ文言が常設表示に出るので、
  自前でも指定すると同じ文が2つ並ぶ（Day 039で実際にやった）
- **CSPは `connect-src` だけでなく `worker-src blob:` も要る。** MapLibre が blob から Web Worker を起こす。
  足りないとローカルでは動いて本番の地図だけが黙って白くなる。`scripts/build.mjs` の3つの表に登録する
- **ピンの当たりは `Math.round` して測る。** CI（Linux Chromium）では `getBoundingClientRect` が 43.99… を返す

## データと利用条件

国土地理院「指定緊急避難場所データ」・地理院タイル（淡色地図）・住所検索APIの3つで、いずれも
[国土地理院コンテンツ利用規約](https://www.gsi.go.jp/kikakuchousei/kikakuchousei40182.html)（出典の記載で利用可）。
外部へ出るのはこの1系統だけ。テストが読む実応答の出どころは [`data/SOURCES.md`](data/SOURCES.md)。

**載っているのは、市町村が登録して公開に同意した場所だけ。** 登録の無い市町村もある。
このアプリの結果を、その地域に避難場所が無いことの根拠にしてはいけない。
