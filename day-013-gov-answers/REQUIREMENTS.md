# 要件とUX5階層 — 政府はこう答えてきた（Day 013）

> 国会会議録APIから**政府側の答弁だけ**を抽出し、テーマごとに「政府がいつ・どの省庁で・何と答えてきたか」を時系列で見せる。
> 元は「議員の人物像＋矛盾抽出」案。**法務リスク（名誉毀損・公職選挙法・著作権40条1項）を避けるため政府答弁に限定**した（2026-08-20 本人指示）。

## ① 戦略：なぜ作るか

政策について「政府は実際どう説明してきたのか」を確かめる手段が実質的にない。ニュースは切り取りと解釈が入り、官公庁サイトは**現在の方針しか載せない**（過去にどう変わったかは残らない）。国会会議録は全文公開されているのに、発言単位で羅列されるだけで質問者と答弁者が混ざる。

**政府答弁に限る判断が、そのまま設計の芯になっている。** 政府答弁は国の公式見解なので、①個人の評価にならない ②時系列に並べると方針の変化が見える ③引用価値が最も高い。

## ② 要件：ユーザーストーリー

主対象は**レポート・卒論で政策の経緯を書く学生**（作者自身がこの立場）。副次で制度変更に振り回される実務者。

- US-1 テーマ語を入れると、政府答弁数の**年別推移**が見たい → いつから議論されているかを根拠つきで書ける
- US-2 山になっている年を選ぶと、その年の答弁が読みたい → 何が起きた年か分かる
- US-3 答弁を**古い順**に並べたい → 説明がどう変わったかを自分で判断できる
- US-4 **引用形式でコピー**したい → 出典つきでレポートに貼れる
- US-5 **どの省庁が答えたか**を見たい → 所管が分かる

## ③ 構造：1画面完結

検索欄 → 年別グラフ → 省庁別内訳 → 答弁リスト。グラフの棒を押すとリストがその年に絞られる。

## ④ 骨格

各答弁カードに「日付・会議名・**答弁者の役職**・冒頭抜粋・原文リンク・引用コピー」。4状態（初期／読込中／0件／エラー）を用意する。

## ⑤ 表層

資料として信頼できる見た目。装飾は抑える。**赤×緑を使わない**（青 #0072B2 × 橙 #D55E00）。

## 実測で確定した技術判断

| 論点 | 実測結果 |
|---|---|
| CORS | `access-control-allow-origin: *`（Origin送信時）。ブラウザ直叩き可 |
| 認証 | 不要 |
| 遡及 | 1947年〜。ただし**公開は3〜4週間遅れ**（8/20時点で最新7/27） |
| 政府答弁の判別 | `speakerPosition` が非空。ただし**民間参考人も肩書が入る**ため府省庁名＋政府役職の**ホワイトリスト**で判定（58種を政府と判定・除外5種は全て正しく非政府） |
| 会派 | `speakerGroup` は**会派であって政党ではない**（無所属を含む）。政党と書かない |
| 負荷 | NDLが「短時間の大量アクセスはご遠慮ください」と明記 → 総件数を先に見て**上限超過なら絞り込みを促す**設計にする |

## 著作権の整理

発言の著作権は**発言者個人**に帰属（NDL明記）。著作権法40条1項は政治上の演説の自由利用を認めるが「**同一の著作者のものを編集して利用する場合を除き**」とあり、一人の発言を集める設計は除外に当たる。→ **全文を自前で持たず原文URLへリンクし、表示は抜粋にとどめる。** 事実データ（日付・回数・役職・会議名）は著作物でないため自由。

## UX5階層を通して変わった実装判断（5件）

1. 「評価しない」が戦略から導かれ、**矛盾の自動判定を実装しない**と決めた（当初案の中核機能を落とした）
2. 「引用してレポートに貼る」を主目的に据えたことで、**引用コピーが必須要件に昇格**（当初案に無かった）
3. 「政府の公式見解」と定義したことで**民間参考人の除外が必要**と判明。`speakerPosition`の有無だけで判定する当初方針は誤りだった
4. 対象を学生に定めたことで**省庁別内訳を追加**し、逆に「議員の人物像」を落とした
5. 一次情報性を重視した結果、**全文を持たず原文リンク方式**に。著作権上の要請とも一致した
