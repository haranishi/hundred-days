# 影討ち（仮題）

歴史の転換点に忍び込み、名のある武将をひそかに討つブラウザの3Dステルスアクション。第一面は本能寺の変で、明智光秀として夜明け前の本能寺に忍び込み、織田信長を討つ。見つかるかどうかは「明るさ×構え×距離×向き」で決まり、隠れ方の中心は闇と灯りの使い分けにある。設計は [docs/DESIGN.md](docs/DESIGN.md)、数値の決まりは [docs/RULES.md](docs/RULES.md)、地図の考え方は [docs/STAGE-HONNOJI.md](docs/STAGE-HONNOJI.md)。

信長の背後で E を押して討ち取ればクリア。脱出や番兵の全撃破は不要。潜入→境内突破→護衛突破→討ち取りの4段階を案内し、板戸の開放・消灯・小石補充・偵察で攻略の道を選べる。遊べる面は本能寺のみで、桶狭間と関ヶ原は目的と予定のクリア条件を表示した準備中の面。

## 検証記録と残件

初回保存版（r07）は単体137件・ブラウザ27件・ビルドが成功し、独立した操作評価は18/20だった。実施条件と限界の検証記録・操作評価は元の開発リポジトリの作業記録（`.agent-harness/`）にあり、hundred-days へ取り込んだこのコピーには含めていない。

記録にある `.captures/` の画像・計測結果はローカル保存で、GitHubには含めていない。別の環境では下記の撮影・通しプレイのコマンドで生成する。参照ゲームと同等の写実度、単独負荷での描画性能、本人の試遊による評価は残る。

## 動かし方

```sh
npm ci
npm run dev          # http://localhost:5401
npm run typecheck && npm test && npm run build && npm run e2e   # 関門（E2E は 5403）
npm run capture -- <周の名前> --port 5409   # 全構図を .captures/<周>/ に撮る
npm run play -- <周の名前> --route ura       # 道順の台本で一面を自動で通す（mizunuki もある）
npm run perf -- <周の名前>                   # 遊ぶ画面の性能（負荷平均つき）
```

世界だけを見るページは `art.html`（`npm run dev:art`）、人物だけは `chars.html`（`npm run dev:chars`）。

## 操作

| キー | 働き | キー | 働き |
|---|---|---|---|
| WASD | 歩く | マウス | 見回す（画面をクリックで視点をつかむ） |
| Shift | 走る | C | しゃがむ |
| E | 背後から当て身・信長を討つ・仕掛けを使う | Q | 長押しで小石を狙い、離して投げる（狙いの最中に右クリックか Esc でやめる） |
| F | 正面から近接攻撃（番兵は2撃で制圧、音が大きい） | R | ステージの最初からやり直す |
| Esc | 一時停止 | M | 音を消す・戻す |

音は最初のクリックかキーで鳴り始める。

## URL の引数

| 引数 | 働き |
|---|---|
| `?view=greybox` | 箱と円柱の仮の表示に戻す（既定は art） |
| `?autostart=1` | 説明を飛ばしてすぐ遊ぶ |
| `?seed=N` `?god=1` `?speed=N` | 乱数の種、捕まらない、sim の速さの倍率 |
| `?debug=1` | 上から見た2Dの図を重ねる |
| `?overlays=0` | 視界の扇・頭上の印・物音の輪を出さない（重ねが地面の明るさを変えていないかの見比べ用） |
| `?shot=名前` | 種と時刻を固定して構図を撮る（title・start・gate・courtyard・bamboo・garden・nobunaga・finale・gameover・result） |
| `?perf=構図名` | その構図のプレイヤーの位置で 360 コマを測り `window.__perfResult` に出す |
| `?shade=0` | 人物の足元の暗さを切る（見比べ用） |
| `?tex=0` | 写真の質感（CC0）を切り、手続きの模様だけで描く（見比べ用、既定はオン）。`?tex=wood,stone` のように材質（wood・plaster・dobei・stone・ground＝地面の石畳）を並べると、その材質だけ写真を使う |

自動操作は `window.__input`、調べ用の口は `window.__game`（teleport・win・freeze・look など）。宣言は `src/contract/hooks.d.ts` の1か所にある。

## 決まり

- ステージは `src/stage/` の純データ1つで、描画・当たり・明るさ・番兵の動きがすべてそこから決まる。見えている灯りとゲームが使う明るさは、同じ半径と同じ減衰の曲線で食い違わない
- 規則は `src/sim/` にある。three を import せず、1/60 秒の固定刻みで決定的に進む
- 描画の部品（`src/art/`）は契約 `src/contract/` の口で使う。契約を変えるときは、使う側を同時に直す
- 調整する数値は `src/config/` に集め、直した値には札（`// rNN-担当: 理由 旧値→新値`）を残す
- 外の素材（画像・モデル・音・フォント）は CC0 のものだけ使い、取得元・作者・条件を [docs/CREDITS.md](docs/CREDITS.md) に書く（2026-10-06 に「使わない」から変更）。流血は描かない

## 設計の判断と捨てた案

- **扇と判定は同じ関数で決める。** 番兵の扇は、目から伸ばした線ごとに「その地点に立てば見える区間」を全部集めて描く。暗い隙間の向こうにある灯りの島も、帯で扇に出る。捨てた案は二つ。最初に見えなくなった所で線を止める案は、扇に出ない島で見つかる食い違いが残る。明るさの格子の近似で扇だけ速く作る案は、判定と境が数 cm ずれる
- **重ねの表示（扇・頭上の印・物音の輪）は、後処理の前の場面に置く。** 後処理の後に別の場面で重ねる案は、深さが無く扇が屋根の上に出るので捨てた。N8AO が透明物で重い道に入る心配は、世界の側が自動の切り替えを止めて消してある
- **カメラは寄せず、遮る物を抜く。** プレイヤーのまわりは網点の透かし、カメラが建物か町屋の列の箱に入ったらその建物を7割抜く。隠れている植え込みはプレイヤーのまわりだけ抜く
- **手提灯の灯りは紙の揺れに合わせて置く。** 明るさの計算は RULES の点（前 0.35・右 0.2・高さ 0.9）のままで、揺れは見た目だけ
- **竹林・軒下・蔵の陰の暗さは人物にも掛ける。** 世界の暗さの地図を CPU からも引き、人物の環境光と主光を下げる。灯りの光は下げない
- **討ち取りは演出を結果と別の段にした。** 炎上する本能寺を見せてから結果を出す。演出の色抜きは、明るい炎だけ色を残す
- **「！」の音は拍子木の二打ちと鉦の響きで作った。** メタルギアの電子音には寄せていない
- **追っ手は走りより 1.6 m/s 遅く（3.6）、案内は「視線が切れたら、その場を離れてしゃがめ」。** 追っ手は最後に見た位置まで来るので、視線が切れた所でしゃがむと、そこでまた見つかる（`tests/escape.test.ts`）。走りとの差が 0.9 m/s だった r02 は、表門で見つかると約 70m 走るまで視線が切れなかった
- **奥庭の提灯持ちは、池の南を東へだけ歩く輪にした。** 往復のままでは、西の端へ戻る間（最長 43 秒）西の切れ目から入れない。道を縮める案は、中門と信長のまわりを通る回数が変わり、最後の詰めの難しさまで変わるので捨てた
- **全景へ引くカメラは、先に真上へ上がってから横へ動く。** 寄りの位置から全景の位置へまっすぐ寄せると、初めは庭の低い所を通り、本堂の屋根の高さも横切った

## 落とし穴

- 灯りの数を途中で変えない。`visible` を切ると three は灯りの数が変わったとみなし、全部のシェーダーを作り直して1秒止まる。手提灯は9つの枠を使い回し、使わない枠は強さ 0 にする
- `renderer.render` を直接呼ばない。描くのは後処理の `post.render` だけ
- 開始時に、ふだん隠れている物（討ち取りの光の弧・頭上の印・炎上）もいったん描く数に入れてシェーダーを先に作る。混んだ機械では十数秒かかるので、終わるまで画面を出さない。撮影はこの準備を待つ
- 性能と撮影の時間は、機械の負荷で何倍にも伸びる。数字には `uptime` の負荷平均を添え、比べるときは同じ時刻に前の版も測る
- 画面がロック中だと Playwright の Chromium は起動しないので、道具は WebKit に切り替える（`tools/lib/browser.mjs`）。速さの数字は Chromium と比べない
- 音は本物のクリックかキーまで始まらない。`window.__input` の操作では始まらない
- 人物の当て身と討ち取りの動作は、決まった間合い（番兵 0.7m・信長 0.62m）で手を伸ばす。sim は動作の初めにその間合いまで踏み込む
- `src/art/render/n8ao.d.ts` が `declare module 'n8ao'` を持つ。別の宣言を足すと重なる
