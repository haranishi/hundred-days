# Day 082「影討ち」

歴史の転換点に忍び込み、名のある武将をひそかに討つブラウザの3Dステルスアクション。
遊べるのは第一面の本能寺の変で、明智光秀として夜明け前の本能寺に忍び込み、織田信長を討ちます。

- [アプリを開く](https://rairakku.com/100days/day-082-kageuchi/)

史実の再現ではなく、歴史上の戦場を題材にしたフィクションのゲームです。流血は描きません。番兵は当て身で気絶させ、信長は血を描かずに崩れ落ちるだけにしています。

## 遊び方

- 信長の背後で E を押して討ち取ればクリア。脱出や番兵の全撃破は要りません。
- 潜入→境内突破→護衛突破→討ち取りの4段階を案内し、板戸の開放・消灯・小石の補充・偵察で攻略の道を選べます。
- 見つかるかどうかは「明るさ×構え×距離×向き」で決まります。隠れ方の中心は闇と灯りの使い分けです。番兵の足元に視界の扇、頭上に「？」と「！」が出ます。
- 見つかったら理由つきの「討たれた」画面が出て、R ですぐやり直せます。結果には位（影・梟・狐・猪）が付きます。
- 桶狭間と関ヶ原は、目的と予定のクリア条件だけを表示した準備中の面です。
- キーボードとマウスで遊びます（スマホ操作・ゲームパッドには対応していません）。

| キー | 働き | キー | 働き |
|---|---|---|---|
| WASD | 歩く | マウス | 見回す（画面をクリックで視点をつかむ） |
| Shift | 走る | C | しゃがむ |
| E | 背後から当て身・信長を討つ・仕掛けを使う | Q | 長押しで小石を狙い、離して投げる（狙いの最中に右クリックか Esc でやめる） |
| F | 正面から近接攻撃（番兵は2撃で制圧、音が大きい） | R | ステージの最初からやり直す |
| Esc | 一時停止 | M | 音を消す・戻す |

音は最初のクリックかキーで鳴り始めます。

## 作り

- three.js（r186）を Vite と TypeScript で組んだ3D。ゲームの規則（`source/src/sim/`）は three を import せず、1/60 秒の固定刻みで決定的に進みます。
- ステージは `source/src/stage/` の純データ1つで、描画・当たり・明るさ・番兵の動きがすべてそこから決まります。見えている灯りとゲームが使う明るさは食い違いません。
- 音は Web Audio でその場で合成しています（録音の素材は使っていません）。
- 外部への通信はありません。アカウント登録も、端末への保存（localStorage など）もありません。

設計は [source/docs/DESIGN.md](source/docs/DESIGN.md)、数値の決まりは [source/docs/RULES.md](source/docs/RULES.md)、地図の考え方は [source/docs/STAGE-HONNOJI.md](source/docs/STAGE-HONNOJI.md)、開発の手順と URL の引数は [source/README.md](source/README.md) にあります。

## 検証

- 型検査（`tsc --noEmit`）とビルドが通ることを、`npm run build:day082` で確かめています。
- `tests/e2e/day-082.spec.mjs`（3本）が、本番と同じCSPを当てた状態で次を確かめます。仮の表示（`?view=greybox`）でタイトル→ステージ選択→説明→遊ぶまで進み、W キーで位置が変わること。信長を討つと演出を経て結果画面に出ること。既定の表示で写真の質感8枚を自分のフォルダから読むこと。どれもコンソールのエラー・外部へのリクエスト・404 が0件であること。
- `/100days/day-082-kageuchi/` のサブパスに載せた配信でも、素材が読めてエラーが出ないことを確かめました（`scripts/serve-mounted.mjs`）。
