# Day 069「年収の壁時計」

学生バイトの給料と予定から、2026年の年収の壁までの差額・時間、給料日1回あたりの目安、予定で越える回を表示します。健康保険の扶養は将来の見込みで判定されるため、税金とは分けて月額の目安と比較します。

2026年（令和8年分。住民税は令和9年度）、給与のみの人が対象です。年齢は2026年12月31日時点。掛け持ちは合計し、働いた月ではなく給料の支払日で数えます。初回は架空の例を表示します。

数字と文言は [rules-2026.js](lib/rules-2026.js) に集約しています。出典は国税庁・日本年金機構・自治体などの一次資料で、確認日は2026年10月17日。数字・導出・法務の調査経緯は [照合記録](../.kiro/specs/day-069-nenshu-kabe/research.md) を参照してください。

公表基準と入力との差を計算する概算です。税額や扶養の認定、個別の相談には対応しません。給与以外の収入、自治体・健康保険ごとの事情、手当・賞与・社会保険料控除などは反映しません。時間は差額を時給で割って切り捨てた値で、勤務できる時間の保証ではありません。

外部ライブラリ・外部フォント・外部画像は使いません。表示と計算のための外部通信はなく、保存は初期オフです。オンにした入力だけをこのブラウザに保存し、オフ・削除ボタン・サイトデータの削除で消せます。共有に渡すのは固定の説明とURLだけです。

単体テスト：`node --test day-069-nenshu-kabe/tests/`（リポジトリのルートで実行）。画面テスト：[day-069.spec.mjs](../tests/e2e/day-069.spec.mjs)。ビルドした配信物に本番と同じCSPを当てて確かめるので、配信物に入る状態（meta.json の status が published）でビルドしてから実行します。
