# データの出どころ

## `data/m/*.bin` と `data/index.json` — 人身事故 1,884,647件（2019〜2024年に発生）

- 取得元: 警察庁「[交通事故統計情報のオープンデータ](https://www.npa.go.jp/publications/statistics/koutsuu/opendata/)」
  本票 `honhyo_2019.csv` 〜 `honhyo_2024.csv`（Shift_JIS・6ファイルで計約375MB）
- 取得日: 2026-09-17
- ライセンス: [政府標準利用規約（第2.0版）](https://www.npa.go.jp/policies/application/pdf/riyokiyaku.pdf)。
  **出典の記載で利用可（商用可）**。出典表示はアプリ画面に常時出している
- **2025年ぶんは未公開**（2026-09-17 時点で 404）

### このリポジトリでの加工

元のCSVは同梱しない。`tools/build-data.mjs` が次のように変換したものだけを置いている。

1. 緯度経度（`430607590` ＝ 43度06分07.590秒）を十進度へ変換。範囲外・欠損の168件は捨てた
1b. **年は発生年の列から取った。** ファイル名の年は「統計年」（事故が確定した年）で、
   `honhyo_2024.csv` には2023年の事故が8,477件入っている。重複は無い（全件を突き合わせて確認）。
   2019年より前に起きた10,460件は、揃っていない年の端数なので捨てた
2. **年より細かい時点を捨てた**（月日・曜日・警察署コード・本票番号を持たない）。
   死亡事故の日付と場所が揃うと、遺族にとっては個人の記録になるため
3. 残した項目を1件6バイトに詰めた ＝ 位置（メッシュ南西角からの相対値・`uint16`×2）、年、時、
   フラグ7つ（歩行者・自転車・二輪車・死亡・65歳以上・交差点・夜）
4. 地域メッシュで分けた。2次メッシュ（約10km四方）で2,000件以上のものは単独ファイル、
   それ未満は親の1次メッシュ（約80km四方）へまとめた ＝ 371ファイル・10.8MB

元のCSVから作り直すには、上のページから6年ぶんを落として次を走らせる。

```
node tools/build-data.mjs --src <CSVの置き場> --out data
```

件数が合わなければスクリプトが止まる。2026-09-17 の実行結果は
`1,884,647件 / 371ファイル / 10.8MB / 歩行者233,567 / 自転車425,937 / 死亡16,257`。

### 列の数が年で違う

2019〜2021年は58列、2022〜2024年は68列。**列番号で引くと壊れる**ので列名で引いている。

## `tests/fixtures/address-*.json` — 住所検索の実応答

- 取得元: 国土地理院 住所検索API（`https://msearch.gsi.go.jp/address-search/AddressSearch?q=`）
- 取得日: 2026-09-16（Day 040 が取得したものを**未改変**のまま持ってきた）
- ライセンス: [国土地理院コンテンツ利用規約](https://www.gsi.go.jp/kikakuchousei/kikakuchousei40182.html)
- `address-akita-sanno.json`（「秋田市山王」＝1件）／`address-akita-eki.json`（「秋田駅」＝11件・
  先頭は北海道中頓別町秋田）／`address-none.json`（0件）
- `address-kochi-eki.json`（「高知駅」＝3件）は、プロモ動画（`tools/promo/`）で場所を高知駅に変える場面に使う。Day 040 の `tests/fixtures/` から**未改変**のままコピーした
