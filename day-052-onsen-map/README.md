# Day 052 湯けむり日本地図

日本地図の県庁所在地に都道府県ごとの柱を立て、温泉と銭湯の多さを比べる。県の柱か順位の行を押すと、その県の温泉・銭湯が地図の点で出て、1件ずつ Googleマップで開ける。

https://hundred-days.pages.dev/day-052-onsen-map/

## できること

- 柱の高さを4つの数で切り替える：源泉の数（最初はこれ）、温泉地の数、湧き出る量、銭湯の数。柱は開いたときと切り替えたときに地面から伸びる（動きを減らす設定では伸ばさない）
- 全国の地図は、主な4島が枠いっぱいに入るよう列島の向きに合わせて少し回し、40°傾ける（縦長のスマホは右へ5°、PCは左へ10°、横に広い画面は左へ15°）。視野角を15°に狭めて、画面の端の柱が斜めに倒れて見えないようにしている。沖縄は範囲の計算に入れず、画面の外にあるときは左下の「沖縄県 ↙」で知らせる
- 上位3県の柱の根元に「大分県 5,094」のように県名と数を出す（指標を変えると差し替わる。スマホは1位の1本だけ）
- 見出しの下の1行で、柱か順位を押すと県のお風呂が出ることを伝える。順位の見出しの横の「県を選ぶ」からも県の画面へ移れる
- 柱は細いので、押した位置のまわり（スマホは±22px・ほかは±12px）にある柱のうち、形がいちばん近いものを選ぶ。重なって見えるところでは、柱の軸が指に近い方にする。県に寄ったら柱は隠して、お風呂の点だけにする
- 見出しの1行で1位の県と数を読む。「源泉の数、1位は大分県。5,094か所」。銭湯のときは「全国の銭湯は4年で3,231軒→2,730軒（501軒減）」を添える
- 47行の順位の表（棒つき）から県を選ぶ。地図が出ない端末では、この表が主画面になる
- 県の画面：上の見出しに県名と、選んだ指標の数・全国での順位（「秋田県　源泉の数 616か所・全国11位」）。カードには残り3指標の短い一覧、地図に載っているお風呂の件数、名前順の一覧（日本語の名前が先・英字だけの名前が後ろ・50件ずつ）。種類で絞り込める（並びは すべて・温泉・種類の登録なし の順で、この県に0件の種類は末尾で押せない）。「銭湯の多くは『種類の登録なし』に入っています」を押すと、そのチップを選ぶ。ほかの県で選んだ種類が0件なら、国の統計の数を添えて知らせる
- 点の5色は色覚の違いでも見分けやすい Okabe-Ito の配色（温泉・銭湯・スーパー銭湯など・足湯・手湯）と灰色（種類の登録なし）
- お風呂のカード：名前、種類とその判断の根拠、地図データに記載のある営業時間・料金・露天風呂、「Googleマップで開く」「OpenStreetMapで見る」、「行った」の印
- 「行った」の記録は、1件目に印を付けると上に出る「行った記録（◯）」から一覧で見て、外せる
- 「近くを見る」で現在地へ寄り、20km以内のお風呂を近い順に10件まで出す
- 指標・県・お風呂は URL（`?m=sento&pref=05&bath=n123`）に残る。知らない値は捨てて、何を捨てたかを小さく知らせる

## データの出どころ

詳しい出典・加工・利用条件は [`data/SOURCES.md`](data/SOURCES.md)。

- 温泉の3つの数：環境省「令和6年度温泉利用状況」（2025年3月末時点）
- 銭湯の数：厚生労働省「令和6年度衛生行政報告例」第9表の一般公衆浴場（2025年3月末時点）。推移は同じ報告例の概況の表4
- お風呂の点：OpenStreetMap の `amenity=public_bath` 5,208件（2026年9月29日取得）。同じお風呂が点と建物の輪郭で二重に登録されていることが多いので、同じ県・同じ名前で100m以内のものは1件にまとめた（477件）
- 柱の位置：Day 015 の県庁所在地の点（人口の重心）
- 地図タイル：OpenFreeMap の `dark` スタイル。読み込んだあとに陸・海の色（コントラスト比1.3以上）、海岸線、県境の太さを変える。文字ラベルと道路の線は全国の画面（ズーム6未満）では出さず、6からは日本語名だけにする（文字色は背景との比4.5以上）。国名はどのズームでも出さない。地図の中の帰属表示は最初は（i）に畳む（下の帯にも出典を出している）。描画は同梱の MapLibre GL JS 5.24.0

## 気をつけてほしいこと

- 地図の点は OpenStreetMap に登録されたお風呂だけで、全部ではない。国の数と定義が違うので、割合は出していない
- 種類は地図データの記載と名前から判断している。名前だけでは銭湯と決めないので、銭湯の多くは「種類の登録なし」に入る
- 温泉地の数は、宿泊施設のある場所を数えたもの（環境省の表の注）
- 営業時間と料金は地図データの記載のまま。必ず施設に確かめる
- 柱の位置は県庁所在地で、県の中の分布ではない

## 通信と端末への保存

統計とお風呂の位置は同梱している。ブラウザが外へ接続するのは、地図タイルを取る OpenFreeMap だけ。お風呂の位置（653KB）は最初の描画のあとで読む。
現在地は端末の中で距離を測るのに使うだけで、どこにも送らない。
端末の localStorage（`day052.visited.v1`）に残すのは、「行った」を押したお風呂の番号・名前・都道府県・押した時刻だけ。保存できない環境でも、開いている間は画面の中で動く。

## データの作り直し方

元のファイルは `tools/cache/` に置く（リポジトリには入れていない）。

```sh
# OpenStreetMap（47都道府県ごと。キャッシュがある県は飛ばす）
node day-052-onsen-map/tools/fetch-osm.mjs
node day-052-onsen-map/tools/build-baths.mjs --date 2026-09-29

# 国の統計（pdftotext が要る。Day 015 の data/points.json も読む）
#   tools/cache/env-onsen-r6.pdf                  環境省の都道府県別の表
#   tools/cache/estat-r6-table9-public-baths.csv  e-Stat の第9表（Shift_JIS）
#   tools/cache/mhlw-eisei-r6-kekka3.pdf          概況の生活衛生関係
node day-052-onsen-map/tools/build-stats.mjs --date 2026-09-29
```

`build-stats.mjs` は、県の和が原本の「計」「全国」と合わないと止まる。

## テスト

- 単体：`node --test day-052-onsen-map/tests/`（分類・3つの表の読み取り・お風呂の変換・順位と見出し・URL・行った記録など）
- E2E：`tests/e2e/day-052-onsen-map.spec.mjs`。外への通信はすべて塞ぎ、地図タイルは空のスタイルで返す

## やらないこと

予約・口コミ・料金の比較はしない。営業時間や料金を保証しない。泉質は扱わない（公開データが無い）。人口あたり・面積あたりの比較はしない。名前だけで銭湯と決めない。
