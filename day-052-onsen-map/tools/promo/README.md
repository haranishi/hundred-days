# 「湯けむり日本地図」プロモーション動画

縦型1080×1920・35秒・BGM付きの動画を、アプリを実際に操作して撮る。絵コンテは `timeline.mjs`、音は `promo-audio.mjs`、画は `render-promo.mjs` の3本で完結し、アプリ本体（`index.html`・`app.js`・`lib/`・`data/` など）には手を入れない。土台は Day 040 の同名ツールで、仕上げの音量合わせは Day 048 から借りた。

## 描き方：1コマンドで、下見から検査まで約1分

リポジトリ直下で実行する。ffmpeg・ffprobe と Playwright の Chromium が要る。

```sh
PLAYWRIGHT=/path/to/playwright/index.js \
  node day-052-onsen-map/tools/promo/render-promo.mjs
```

書き出すのは `promo.mp4`・`promo-first-frame.png`・`preview-contact.jpg`（2秒おき18コマ）・`promo-audio-a.wav`・`promo-audio-b.wav` で、どれも gitignore 済み。`--audio b` でB案を重ね、`--sheet <jpg>` でコンタクトシートの置き場所を変え、`--keep` で録画の元（webm）を残す。GPU の無い機械では `--swiftshader` を付ける。検査に落ちても mp4 とシートは残るので、目で見てから直す。

## 撮り方の決めごと：タイルは下見で集め、字幕はページの中の時計で出す

- **地図タイルは本物の OpenFreeMap を読むが、本番では下見で届いた分を返す。** 下見では大分県へ寄ってから描き終わるまで4秒前後、竹瓦温泉で2秒前後かかった。そのまま撮ると、寄った先がぼやけたまま映る。試し描きの本番は37件すべてが手元から返り、外へ取りに行ったのは0件。OpenFreeMap 以外の宛先は断ち、ログに出す
- **字幕・注目の枠・エンド画面は、ページの中の時計（requestAnimationFrame）で出す。** Node 側の操作が遅れても字幕はずれない。Day 042 は操作の返事を待ってから字幕を進めていて、字幕が3秒遅れた
- **1コマ目の柱は、撮影の外で「温泉地の数」にしておき、t0 の0.15秒前にページの予定表が「源泉の数」を押し直して伸ばす。** 開いた直後の伸びはタイルの読み込みと重なり、描けていない地図の上で伸びてしまう。柱は1.2秒の ease-out で伸びるので、1コマ目はおよそ3割の高さになる
- **頭の切り落としはカチンコで決める。** t0 の1.6秒前に画面を0.24秒だけ赤紫に光らせ、録画の中でその光を探す。Day 040 の「録画開始からの実測」だと、3回の試し描きで0.10〜0.18秒切りすぎていた（Day 042 の README の「画が0.2秒ほど早い」と同じ向き・同じ大きさのずれ）
- **竹瓦温泉（`w338231731`）は「温泉」で絞った93件の58番目なので、「もっと見る」を押してから探す。** 並び順が変わって最初の50件に入れば、押さずに進む
- **GPU（Metal）で描く。** 同じ6秒の試し撮りで、動きの写ったコマが SwiftShader の87から95に増えた
- **下見と本番はブラウザの文脈を分けている。** 「行った」の記録（localStorage）は本番で毎回空から始まる
- **エンド画面の下に、地図と統計の出典を入れる。** 映っている地図は OpenFreeMap のタイルで、動画に使うなら「OpenFreeMap © OpenMapTiles Data from OpenStreetMap」が要る。OSMF の帰属ガイドラインでも、地図が主役の動画はエンドクレジットか説明文に openstreetmap.org/copyright を書く。地図の右下の出典は開いてから5秒か地図の操作で（i）に畳まれるので、エンドだけは必ず残す

字幕は地図の上端のすぐ下に置く。帯の高さは場面で変わる（銭湯の推移の1行が出る・県やお風呂の画面で畳まれる）ので、毎コマ測って滑らせて追い、下の一覧やカードのボタンには掛けない。

## 字幕の数字は、書き出す前に画面と突き合わせる

`render-promo.mjs` の `SCREEN` が画面の文字を読み、食い違えば下見の段階で止まる。**食い違ったら字幕を画面に合わせる。逆はしない。**

| 場面 | 字幕 | 画面のどこ | 照合する文字 |
|---|---|---|---|
| S1 | 源泉の数、1位は大分県／5,094か所 | `#headline` | 源泉の数、1位は大分県。5,094か所 |
| S2 | 銭湯の数だと／東京・大阪・青森 | `#headline`・順位の上から3行（`button.rank-row`） | 銭湯の数、1位は東京都／東京都・大阪府・青森県 |
| S3 | 銭湯は4年で／501軒減った | `#trend` | 4年で3,231軒→2,730軒（501軒減） |
| S4 | 県を押すと／その県のお風呂が地図に | `#pref-card`・`#headline` | 大分県・地図に載っているお風呂 |
| S5 | Googleマップで／すぐ開ける | `#bath-card` のGoogleマップのリンク | 竹瓦温泉・座標 33.27747,131.50598 |
| S6 | 行ったお風呂に／印をつけて | `#bath-visit` | `aria-pressed="true"` |

字幕の語は `SCREEN` の `caption` にも書いてあり、`timeline.mjs` の字幕と一致しないと起動した時点で止まる。1行16字・2行までに収まっているかも、同じく起動時に確かめる。

## 検査は書き出した動画そのもので測る（2026-09-29 の試し描き）

| 検査 | 合格の条件 | 試し描きの値 |
|---|---|---|
| 尺・寸法・形式 | 35±0.1秒・1080×1920・30fps・H.264/AAC | 35.000秒・すべて一致 |
| 音量 | −16〜−18 LUFS・真のピーク −1 dBTP 以下 | −17.0 LUFS・−3.7 dBTP |
| 冒頭の音 | 0〜0.3秒の RMS が −40 dBFS より大きい | −19.6 dBFS |
| 字幕の入れ替わり | 7回（エンドを含む）とも予定の±0.4秒 | 字幕は予定ちょうど、エンドは+0.13秒 |
| 1コマ目 | 地図の中の柱の橙が、伸び切った後の5〜85%で、0.1秒後に増えている | 53〜57%（4回。ページの伸びは0.31〜0.33） |
| 字幕の置き場所 | 安全域（上下左右10%）の内側で、見出し・推移・指標のボタン・枠の相手に重ならない | 違反0 |
| 押した時刻 | 予定より0.25秒以上遅れない | 遅れは最大0.01秒 |

字幕の入れ替わりは、字幕の箱の内側を30fpsのまま切り出してコマ差分で拾う（Day 048 で、20fpsに間引くと一律0.1秒遅れて測れた）。エンドは0.42秒かけて溶け込み、隣のコマとの差が毎コマ小さいので、窓の頭からの差で拾う（隣との差だけで判定したら、しきい値の境目で1回落ちた）。

音とのずれは自動では見ていないが、試し描きでは「銭湯の数」が押された見た目が7.53秒（音の刻みは7.50秒）、「行った」が28.00秒（同28.00秒）だった。

## 見た目が変わったら、同じコマンドで描き直し、止まった所だけ直す

1. 上のコマンドをそのまま実行する。約1分で、落ちても mp4 とコンタクトシートは残る
2. 「画面と字幕が食い違っています」で止まったら、`timeline.mjs` の `CAPTIONS` を画面に合わせ、`SCREEN` とこの README の表も直す。録画の前（下見）で止まるので、待つのは15秒ほど
3. 「字幕の置き場所」で落ちたら、帯が伸びたか地図の枠が縮んでいる。`render-promo.mjs` の `CAPTION_GAP` か、`OVERLAY_CSS` の字幕の文字の大きさ（28px）を下げる
4. 「1コマ目が『柱が伸びている途中』になっていない」なら、`timeline.mjs` の `GROW_LEAD` を動かす。大きくすると伸びが進んだコマで始まる
5. 「押すものが画面にありません」なら、下の約束のセレクタが変わったか、要素が540×960の画面の外に出た
6. 通っても、`promo-first-frame.png` とコンタクトシートは必ず目で見る

頼っているセレクタは、見た目の担当と約束した `.metric[data-metric]`・`button.rank-row[data-pref="44"]`・`#pref-card`・`button.type-chip[data-type="onsen"]`・`#bath-list button.bath-row`・`#bath-card`・`#bath-visit`・`#headline`・`#trend`・`#app[data-state="ready"]`。ほかに、地図の枠の `#map`（無ければ MapLibre の `.maplibregl-canvas`）、Googleマップのリンク（href で探す）、「もっと見る」（文字で探す）、E2E 用の窓 `__day052`（無ければ通信が静まるのを待つ）を使う。

## BGM：A案は琴と三味線、B案はローファイの鍵盤

A案（既定）は D のヨナ抜き（D・E・F#・A・B だけ）で、琴の分散和音と旋律（押し手と揺り付き）、三味線の撥、太鼓・鼓・拍子木・りんを鳴らす。0秒に琴の駆け上がり、0.62秒に水の「ぽちゃん」を置いて、無音で始めない。B案は FM のエレピ（テープの揺れ付き）、スイングしたドラム、レコードのノイズ。どちらも84 BPMで、場面の頭は拍に丸め、押す音とりんだけは画面と同じ秒ちょうどに鳴らす。

音量は合成の段階で BS.1770 の統合ラウドネスを測って −17 LUFS に合わせ、ピークはソフトニーで −2.5 dBFS に丸める。描画ツールは毎回、別のプロセスで両案を作り直す（約16秒・下見と並べて走る）。BGM だけを作るなら次のとおり。

```sh
node day-052-onsen-map/tools/promo/promo-audio.mjs --variant all   # a・b の両方。--variant b --out <wav> も可
```

作成時の実測（WAV）は A案が −17.00 LUFS・真のピーク −3.8 dBTP、B案が −17.00 LUFS・−3.9 dBTP。**人の耳ではまだ聴いていない。**

## 分かっている限界：録画は25fps、字幕は地図の端を少し隠す

- 録画は Playwright の25fps固定で、30fpsへは同じコマを足して変えている（6コマに1コマが重複）。540×960で撮って2倍に拡大するので、文字の輪郭はやや甘い
- 見出しは1コマ目から答え（大分県・5,094か所）を出している。アプリの実際の見え方なので隠していない
- S0〜S3 では北海道の柱の先が字幕の箱の下端に触れ、S4〜S5 では字幕が大分県の地図の北の帯を隠す
- 下見で OpenFreeMap からタイルを取るので、通信が要る。フォントは OS 依存（作成環境は macOS のヒラギノ）
- Day 048 のコマ撮り（時計を止めて1コマずつ撮る）は試していない。地図の描画とタイルの読み込みが止めた時計に付いてくるかを確かめていないため、Day 040 と同じ録画にした
