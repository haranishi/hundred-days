# Day73: offbeat.

レコードを擦り、ビートを重ね、次の曲へつなぐDJゲーム。
[アプリを開く](https://hundred-days.pages.dev/day-073-offbeat/)

## 遊び方
1. 「セットをはじめる」でAの音を鳴らす。
2. 盤面を前後にドラッグ。速さと方向で音が変わる。
3. パッドでドラムやホーンを重ねる。
4. SYNCで拍を合わせ、フェーダーでAからBへつなぐ。

自由演奏と、5つの目標に挑む60秒のライブがある。
スマホではA/B/ミキサーのタブを切り替えて演奏する。パッド・フェーダー・再生と、目標・時間・スコア・拍ガイドが同時に見える。
横向きでは盤面と操作を左右に並べる。MIXから両デッキのEQ・フィルター・音量・ECHOを調整できる。

| キー | 操作 |
| --- | --- |
| Space | 全体の再生・一時停止 |
| Z / M | A / Bの再生 |
| S / K | A / Bのスクラッチ |
| 1 / 2 / 3 / 4 | キック / クラップ / ハイハット / ホーン |
| ← / → | クロスフェーダー |

EQ、フィルター、テンポ、4拍ループ、ECHOも音に反映される。
「レコードを選ぶ」から4つのオリジナル曲を交換できる。

## 音源と保存
- 音源・図案は本アプリ用に独自作成。外部音源・画像・フォントは使わない。
- 音楽は端末内で合成し、最初の操作から鳴らす。音声の録音・マイク利用・アップロードはしない。
- ベストスコアはブラウザ内に保存する。保存できない場合も演奏を続けられる。
- Web Audio対応ブラウザが必要。Chromeで検証し、スマホはタッチエミュレーションで確認した。

## 開発と検証
リポジトリルートで `npm run build`、`node scripts/serve-dist.mjs` を実行する。
確認先は `http://127.0.0.1:4173/day-073-offbeat/`。

- ロジック: `node --test day-073-offbeat/tests/`
- ブラウザ: `npm run test:e2e -- tests/e2e/day-073.spec.mjs`
- 公開ゲート: `npm run publish:check -- --day 73`
- 仕様と検証: `.kiro/specs/day-073-offbeat/`
