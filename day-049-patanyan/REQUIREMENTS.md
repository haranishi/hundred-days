# ぱたにゃん（仮）要件定義

タップで猫が前足をぱたぱたさせて羽ばたき、爪とぎポールのすき間をくぐる、ダウンロードなしのワンタップゲーム。根拠は `research/competitors/competitors-report.md` と `research/positioning/positioning-doc.md`。技術の土台は `docs/TECH.md`。2026-09-25 の体験の改善（30本より先の難しさ・失敗の原因・近い目標・空の時間帯）は `docs/GAMEFEEL-v2.md`。名前は仮で、商標（J-PlatPat）と Google Play の同名は未確認。

## ① 戦略：開いた瞬間に遊べて、失敗してもかわいくて、明日も自分の猫でやりたくなる

- 相手は同じ Flappy 型より、数分の空き時間を奪う SNS とショート動画。開いて2秒以内に1回目の羽ばたきができないと負ける。
- 遊べて当たり前の4点（広告なし／取りこぼしゼロ／全端末で欠けない／2タップで再挑戦）は、競合の不満の上位の裏返し。ここは差ではなく入場券として必ず満たす。
- 差の源泉は組み合わせ：**失敗してもかわいい猫**＋**好みの猫を魚で解放**＋**きょうのコースと猫つき結果カード**。猫にするだけでは差にならない（Flappy Nyan 340万DL が先行）。
- 名前・見た目で原作に寄せない。「Flappy」、緑の土管、原作の鳥・数字・メダル・効果音、既存の猫キャラを使わない。
- 完了の証拠：単体と E2E が全部通る／体験評価 16/20 以上で0点の項目なし／本人の5分プレイで合格。

## ユーザーストーリー

| ユーザー | 欲しいことと理由 | 受け入れ条件 |
|---|---|---|
| 本命：アプリを入れられない端末で数分だけ遊ぶ人（10代中心） | URL を開いてすぐ遊びたい。インストールも登録も面倒 | 読み込みから2秒以内に1回目の羽ばたき。外部通信0。iOS Safari・Android Chrome・PC で欠けない |
| 本命 | 押したら必ず反応してほしい。取りこぼしは理不尽 | 100回の入力で100回羽ばたく。Space でページが動かない |
| 本命 | 落ちたらすぐやり直したい | 2タップ・3秒以内に次の飛行。Space だけでも再挑戦できる |
| 初めての人 | 最初は成功したい | 最初の障害物まで約1.6秒の助走。最初の3本はすき間が広い |
| 失敗した人 | なぜ当たったか知りたい | 当たった瞬間0.25秒止まり、当たった所が光る |
| 猫好き | 猫がひどい目にあうのは見たくない | 失敗はずっこけて目を回し、座り込む。痛がる・倒れたままの描写なし |
| 猫好き | 好みの猫で遊びたい | 6柄から選べ、魚で解放。選んだ猫は次回も残る |
| 翌日の人 | また来る理由がほしい | 日付で全員同じ「きょうのコース」と、その日のベスト |
| 見せたい人 | 点数を友達に見せたい | 猫が写った結果カード画像。X・LINE・共有シート・コピー。同じコースへの挑戦リンク |
| 競いたくない人 | 比べられたくない | ランキングなし。共有は自分で押したときだけ |
| 音を出せない場所の人 | すぐ消したい | 画面の隅でミュート。次回も残る |
| **救う相手**：広告と取りこぼしで Flappy 型をやめた人 | 流れを切られずに遊びたい | 広告・計測・ポップアップなし。結果画面から1タップで次へ |

## ② 要件：MVP に入れるものと入れないもの

- 入れる：1ボタン飛行／爪とぎポールの障害物／すき間の魚（取ると魚+1、点数とは別）／難しさの曲線／自己ベスト／肉球スタンプ（10・25・50・100本）／猫6柄と魚での解放（茶トラ0・ハチワレ3・黒8・白15・サバトラ25・三毛40匹）／きょうのコースといつでもモード／結果カード画像と共有4点セット／挑戦リンク（`?course=YYYYMMDD`）／ミュート／一時停止／OGP と canonical。
- 入れない：オンラインのランキング・アカウント・広告・計測・課金・対戦・英語 UI・オフライン対応（Service Worker）・BGM・練習モード。理由は13歳未満への配慮、外部通信ゼロの約束、1日で磨き切る範囲。

## ③ 構造：画面と遷移

- タイトル（猫がふわふわ待機。「タップでスタート」、モード切替、ねこ、音）→ 飛行 → 墜落 → 結果 → もう一回（待機に戻る）。
- 結果 → シェア（パネル）→ 結果。結果／タイトル → ねこえらび → もどる。
- 迷う所：結果画面での「もう一回」とボタンの押し分け。0.5秒は入力を受けず、その後はボタン以外のどこを押しても再挑戦にする。ボタンを押しても再挑戦にはならない。
- 迷う所：いまのモード。タイトルと結果に「きょうのコース 9/24」か「いつでもモード」を常に出す。

## ④ 骨格：一番大きいのは、飛行中は遊び場、結果ではスコア

- 飛行中は中央上のスコアだけを大きく出し、魚の数は左上に小さく出す。
- 結果の主ボタンは「もう一回」1つ。親指が届く下半分に置く。シェアとねこは副ボタン。どれも 44px 以上。
- 結果カード画像は 1080×1350。猫・点数・モードと日付・魚・スタンプを載せる。

## ⑤ 表層：夕方の屋根の上、生成りの爪とぎポール、まるい猫

- 背景は夕方の空と瓦屋根の町並み。地面は瓦屋根。ポールは麻縄の斜め模様の生成り色で、すき間の縁にパステルのクッション。緑は使わない。
- 猫は頭が大きい2頭身。目・口・前足がはっきり読める大きさにする（Day047 で顔が読めず減点された）。
- 羽ばたきで前足がぱたっと動き、体がつぶれて伸び、しっぽが揺れる。
- スコアは縁取りの太い数字をコードで描く（原作の数字に似せない）。文字はシステムの日本語ゴシック。
- 危険と安全を赤と緑で分けない。`prefers-reduced-motion` で揺れと背景の流れを止める。
- 音は合成：羽ばたき「ぱた」、通過「ちりん」、魚「ぽん」、衝突「ぽこっ」と短い鳴き声、ベスト更新の短いファンファーレ。

## 5階層を通して変わった実装（10個）

土管→爪とぎポール／死→ずっこけて座り込む／きょうのコースと挑戦リンク／猫つき結果カード／魚で柄を解放／誤タップ防止0.5秒とボタン以外で再開／ランキングを持たない／当たった所を光らせる／助走と広いすき間から始める／広告・計測・外部通信なし。

## 調整の記録

体験評価で数値を変えたら、ここに「何を・いくつから・いくつへ・なぜ」を1行ずつ書く。

- 猫が止まる天井：遊ぶ帯の上端（0）から画面の上端＋猫の半径へ（帯の座標で、高さ512なら -11、624なら -123。それより縦長の端末は画面の上端に合わせてさらに上）。縦長スマホで空の途中の見えない天井に止まって見えた（体験評価 v1）。すき間を置く帯420は変えない。
- 天井で止まる位置：画面の上端＋猫の半径9から、画面の上端＋24（`CEIL_PAD`）へ。半径で止めると耳が画面の外に切れた（fix-v1 の残り・メインで調整）。

- 30本以降のすき間：116一定から60本目106まで直線で縮小、以降106一定へ。序盤を保ちながら長い飛行にも難しさを足す（GAMEFEEL-v2 A）。
- 30本以降のポール間隔：155一定から60本目150まで直線で縮小、以降150一定へ。横速度110・中心差上限110を保って長い飛行に変化を出す（GAMEFEEL-v2 A）。
