# Day 049 ぱたにゃん

タップで猫が前足をぱたぱたさせて羽ばたき、爪とぎポールのすき間をくぐるワンタップゲームです。ダウンロードも登録も要りません。広告・計測・外部への通信もありません。何を作るかは `REQUIREMENTS.md` に書いてあります。

公開URL：https://hundred-days.pages.dev/day-049-patanyan/

## 遊び方

- 画面のどこかをタップすると猫が羽ばたきます。クリック・Space・↑・W でも同じです。すき間を1本くぐるごとに1点入ります。
- すき間に浮かぶ魚を取ると、点数とは別に魚が貯まります。魚の合計で新しい柄の猫が仲間になります（ハチワレ3・黒8・白15・サバトラ25・三毛40匹）。
- 「きょうのコース」は日本時間の日付で決まり、その日は全員が同じコースを飛びます。「いつでもモード」は毎回違うコースです。
- 結果が出てから0.5秒たつと、ボタン以外のどこを押しても（Space でも）もう一回遊べます。
- 右上の「音」ボタンか M キーで音を消せます。設定は次に開いた時も残ります。
- URL に `?course=20260924` を付けると、その日のコースに挑戦できます。結果のシェアで渡すリンクにはこれが付きます。

## シェアは2種類ある

結果画面の「シェア」は、自分の記録（猫つきの結果カード画像・本数・その日のコースへのリンク）を渡します。タイトル左上の「共有」は、100日チャレンジ共通の共有欄（`shared/share.js`）で、このゲームそのものを紹介します。

2つを分けたのは、全画面のゲームに共通の共有欄をそのまま置く場所がないためです。共通の欄はダイアログの `#share` に据え付け、タイトルからだけ開きます。ゲーム自前のシェア画面のクラス名は `cshare__*` にしてあります。共通の部品が使う `share__*` と重なると、全 Day 共通の E2E（`tests/e2e/shared-share.spec.mjs`）が要素を二重に数えるためです。

## テストの回し方

リポジトリの直下から回します。

```sh
npm run test:unit    # このDayの単体テストは day-049-patanyan/tests/unit/（80件）
npm run build && npx playwright test tests/e2e/day-049.spec.mjs
```

- `?test=1` を付けた時だけ、テスト用の `window.__patanyan`（時間を手で進める・状態を読む・シードを固定する・羽ばたく）が出ます。E2E はこれでゲームの時間を1刻みずつ進めて確かめます。
- E2E はブラウザの日付を 2026-09-24 に固定します。`?course=20260924` で「きょうのコース 9/24」の表示を確かめるためで、ゲームの時間は `performance` と `requestAnimationFrame` で進むので影響しません。
- 単独で作っていたときは WebKit でも E2E を回していました。このリポジトリの CI は Chromium だけなので、WebKit の分は移していません。

## ファイルの役割

- `app.js` は画面と入力の配線だけを持ちます。物理・当たり判定・コース・難しさ・画面の流れ・保存・共有文・描画は `lib/` に分けてあり、どれも DOM に触れません（単体テストで直接呼べるようにするため）。
- 絵はすべて Canvas の図形です。猫は `lib/cat.js`、背景とポールは `lib/render.js`、スコアの数字は `lib/digits.js`、結果カードは `lib/card.js` で描いています。`assets/og.png`（1200×630）も同じ描画コードから作りました。
- 公開URLは `lib/site.js` の `SITE_URL` と、`index.html` の canonical・og:url・og:image の2か所にあります。食い違うと単体テスト（`tests/unit/share.test.mjs`）が落ちます。

## 設計で決めたこと

- 点は、猫の中心がポールの後ろの縁を越えた時に入ります。「くぐった」と言えるのはその時点だからです。
- ベストはモードごとに分けました。違うコースの記録を比べても意味がないからです。
- すき間を置く帯と、猫が止まる天井は別の値です。帯を固定すると端末で難しさが揃う一方、縦長のスマホでは猫が空の途中の見えない天井で止まって見えたので、天井だけを画面の上端（猫の耳の先が残る位置、`CEIL_PAD`）に分けました。
- すき間は最初の3本が150、30本目で116、60本目で106まで狭まり、その先は一定です。横の速さと、前のすき間との中心の差の上限は変えていません（手触りが変わるため）。
- 当たった所の星は、接点から猫と反対側へ離して猫より後ろに描きます。顔が当たり判定の円より大きく、星が目や鼻に重なったためです。
- 結果カードの背景は墜落したときの時間帯（10本ごとに夕方→夜→星空→明け方）にします。遠くまで飛んだ人ほど違う絵になり、見せる理由になるからです。

## まだ確かめていないこと

- 実機の iPhone（Safari）と Android（Chrome）で、音が鳴るか、画像つきの共有シートが開くか、画像を保存できるか。E2E はヘッドレスの Chromium で代用しています。
- 人の指で遊んだときの手応え。体験の評価（19/20）は、評価役が操作ログとスクショを見て付けた点です。
- 名前「ぱたにゃん」の商標（J-PlatPat）と、Google Play に同名のアプリがないか。App Store（日本）では同名のアプリが見つかっていません。
