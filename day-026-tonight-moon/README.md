# Day 026「今夜の月」

今夜の月の形、月齢、自分の場所での月の出・月の入り、中秋の名月までの日数を1画面で見るアプリです。日付を前後30日なぞれ、実際に見た月は端末内の帳へ残せます。

## なぜ作ったか

月を見たい夜に必要なのは、たくさんの天文データではなく「どんな形の月が、何時ごろ出るか」だと考えました。形を主役にし、時刻、方位、日の入りとの差を同じ画面にまとめています。2026年の中秋の名月は満月の2日前なので、名月と満月が必ずしも同じ日ではないことも、その夜の形と一緒に分かります。

## 設計上の判断

- 暦日と表示時刻は端末のタイムゾーンに左右されないUTC+9固定です。海外の現地時刻には変換しません。
- 現在地はボタンを押したときだけ取得し、小数2桁へ丸めて端末内に保存します。地名への変換や外部送信はしません。
- 中秋の名月は2024〜2032年の表を同梱し、満月の瞬間だけを自前計算します。旧暦の月番号は計算しません。
- 見た月は今夜だけ記録でき、同じ日は1回、最大60件です。保存できない環境でも月の計算は動きます。
- Canvasの月は8種類の画像ではなく、輝面比と満ち欠けの向きからターミネーターを描きます。海の模様は固定シードで毎回同じです。

## 計算方法と精度

Jean Meeus『Astronomical Algorithms』第2版をもとに、太陽は第25章、月の黄経・距離・黄緯は第47章の周期項各60項、位相角と輝面比は第48章、朔弦望は第49章の補正項を実装しました。ΔTは69秒の定数です。

出入りは日本時間の0:00〜24:00を2分刻みで走査し、高度が基準値をまたぐ区間を二分法で秒単位まで絞ります。出没の定義は国立天文台の暦に合わせ、地平大気差を35′8″として、太陽は上辺（大気差＋視半径16′）、月は中心（大気差と実際の地平視差）を基準にしています。東京は北緯35.6581度・東経139.7414度です。
画面の月の入りは、その日の月の出より後の最初の入りを表示し、翌日になるときは「翌」を付けます。国立天文台の暦は暦日ごとの出入りのため、画面上の並びと異なる場合があります。

2026年9月2日の東京では、計算値は月の出20:38、月の入り10:16、日の出5:13、日の入り18:08で、国立天文台の値と分単位で一致します（秒まで見ると差は30秒以内）。朔弦望12件も暦要項の時刻に対して1分以内です。画面は分単位に丸めます。大気の状態や地形によっても実際の見え方は変わるため、観察では1〜2分の幅を見込んでください。

実装の途中で、Meeusの本にある月の基準高度 `0.7275π − 34′`（月の上辺基準）を使うと、月の入りが暦より約2分遅れました。JPL Horizonsの見かけの高度で照らし合わせると、暦の時刻は月の中心が地平線に来る瞬間と一致したため、月だけ中心基準に改めています。
