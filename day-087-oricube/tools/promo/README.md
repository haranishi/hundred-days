# Day087「OriCube」の宣伝動画

32秒の縦型動画（1080×1920・30fps）。公開用のビルド（dist）を実際に操作して撮った画面だけで作る。
機能を順に並べる紹介ではなく、見た人が「使いたい」と思う気持ちの流れで組む:
問いかけ（鶴の折り図、読める？）→ あるある（止まった線と矢印は分かりにくい）→ 同じ花弁折りが3Dで動く（音のドロップ）
→ 止めて回す・重なりを広げる → 手元の紙と1手順ずつ → 10作品 → 鶴の完成 → 無料・ログイン不要。
絵コンテは `timeline.mjs` の1つの表。映像（`render-promo.mjs`）とBGM（`promo-audio.mjs`、2案）が同じ表を読む。

## 再生成

リポジトリのルートで実行する。dist は読むだけで、ビルドし直さない（最新の画面で撮るときは、先に `npm run build` を済ませ、dist のコピーを渡す）。
dist の場所・コマの置き場・書き出し先は引数か環境変数（`PROMO_SITE_DIR`・`PROMO_FRAMES_DIR`・`PROMO_OUT_DIR`）で渡す。
ffmpeg / ffprobe と、ローカルの Zen Kaku Gothic New（Bold・Black。`PROMO_FONT`・`PROMO_FONT_BLACK` で別の場所も可）が要る。

```sh
node day-087-oricube/tools/promo/promo-audio.mjs --variant a --out-dir <書き出し先>   # bgm_a.wav と bgm_a.mp3（192kbps）
node day-087-oricube/tools/promo/promo-audio.mjs --variant b --out-dir <書き出し先>
node day-087-oricube/tools/promo/verify-audio.mjs --out-dir <書き出し先>
node day-087-oricube/tools/promo/render-promo.mjs --site-dir <…/dist> --frames-dir <コマの置き場> --out-dir <書き出し先> --mux a,b
```

- 撮り直しは最後の1行（2026-11-07、ブラウザ1つで撮影1.5分＋重ね1分）。`--lanes 1` でブラウザを1つに絞る（機械が混んでいるとき）。`--only story` のように1つだけ撮り直せる。`--compose-only` は重ねと書き出しだけ。
- 配信は、リポジトリの `scripts/serve-dist.mjs` を dist の親フォルダで起動する（127.0.0.1・既定のポート 4292・`--port` で変更）。終わると自分の子プロセスだけを止める。
- ページの時計（`requestAnimationFrame`・`performance.now`・`Date.now`・`setTimeout`・CSS/Web Animations）を止め、1/30秒ずつ進めては撮る。撮るのは CSS 540×960・DPR 2。
- テイクは4つ: `hook`（鶴の手順3、2倍速で再生中から）・`story`（鶴の手順4を真上・停止で開き、タップと指のドラッグを本当に行う1ページ）・`montage`（5作品の最後のひと折り）・`crane`（手順10から完成の札と回転）。速さ2倍と最初の再生は、撮る前にプログラムで押す（輪は出さない）。
- タップの輪は押す部品の実際の座標に出し、その部品を本当に押す（`el.click()`）。3Dのドラッグは CDP のタッチ操作で本当に回す。
- 撮影中は配信元のほかへの通信をすべて止める。重ねのコマは全部 rgba にそろえてから重ねる（Day083 の抜け対策）。字幕・光・終わりのカードの切替はコマ番号で比べる（秒で比べると1コマ遅れた）。
- 紙の音の合図（`PAPER_CUES`）は撮影で測った着地、タップの音（`TAP_CUES`）はタップの時刻。撮り直してずれたら `capture-report.json` の `paperCueDrift` を見て直し、BGMを作り直す。
- 書き出し: `Day087_oricube_promo_{silent,a,b}.mp4`・`first-frame.png`・`contact-sheet.jpg`（1秒ごと）・`cut-check.jpg`（各カットの前2コマ・後2コマ）・`capture-report.json`・`bgm_{a,b}.{wav,mp3}`・`audio-report.json`・`spectrogram-{a,b}.png`。

## BGM の展開

90BPM・12小節。フック＝ドラム無し → あるある＝ドラムを抜き、上がっていくノイズで張る → 紙が動く瞬間（5.33秒）にキック・ベース・小さなシンバルのドロップ（前の小節より a 8.5dB・b 9.5dB 大きい） → 止めて回す・広げるで厚み → 10作品でコーラス → 鶴で副旋律 → 終止和音と1.6秒のフェード。
`verify-audio.mjs` は統合ラウドネス −16 LUFS±1・真のピーク −1.5 dBTP 以下・クリップ0・頭のクリック無し・途中の無音無し・末尾0・紙の音の立ち上がり・ドロップの上がり3dB以上を見る。

## 使用素材と権利

- 映像: OriCube のビルドをローカルで配って操作した実画面。作り物の画面・第三者の素材・AI生成映像は使わない。紙と作品の形は自作の幾何。
- 字幕・終わりのカード: Zen Kaku Gothic New（Bold・Black）、SIL Open Font License 1.1。ロゴはアプリの index.html と同じ自作の図形。
- BGM: `promo-audio.mjs` が Node の計算だけで合成（サンプル素材なし）。A案は陽旋法の短い反復（弦をはじく音）、B案はヘ長調の短い反復（マリンバとベル）で、既存曲の旋律は使っていない。音の試聴はしておらず、数値とスペクトログラムで確かめた。
