# Day087 OriCube

折り紙の折り方を、紙が折れる動きとして3Dで見る。
平面の説明書では読み取りにくい「どこを、どちらへ、どれだけ折るか」と、紙の重なりを、止めて・戻して・回して確かめられる。
作品は紙飛行機（やり型）・白鳥・立方体の箱（ふた無し）の3つ。ログイン・インストール不要で、ブラウザだけで動く。

## 使い方
1. 上のタブで作品を選ぶ。開くと、紙飛行機がすぐ折れ始める。
2. 折る前に、折り線（谷折り＝破線、山折り＝一点鎖線、中割り折り＝破線に点2つ）と動く向きの矢印が出る。再生で、その通りに紙が動く。
3. 前へ・次へ・つまみ・手順の一覧で行き来できる。手元の紙と一緒に折るなら「手順ごとに止める」を入れると、各手順の終わりで止まる。
4. 1本指で回し、2本指で寄る。「重なりを広げる」で、隠れた層の中まで見られる。
5. 完成すると、ゆっくり1周回って見せる。触ると止まる。

通信はしない。選んだ作品や手順は端末に保存しない。動きを減らす設定では、動かさずに各手順の終わりの姿勢を見せる。

## 折りの計算
手順データ（折り線・動かす側・対象の層）から、三角形に分けた紙を折り線で切り、動く側を軸のまわりに回す。
紙は伸び縮みしない。平らに折りたたんだ姿勢では、重なる三角形の前後を決め、紙が互いを貫通しないことを検査する。
引きちぎる折りや、層が挟まる折りは、作品データの構築時に失敗として止める。
箱は、壁の立ち上がりに角の三角が連動する機構で、角の位置を三辺測量で求める。
物理シミュレーションではないので、厚み・弾性・しわは再現しない。
計算は `lib/` の純粋なJS（DOM・描画に依存しない）で、設計は [エンジンの契約](../.kiro/specs/day-087-oricube/engine.md) に置いた。
