# Day81 PageCrate のプロモ動画

36秒・縦1080×1920・30fps。公開中のデモ専用サイト（https://day81.rairakku.com/ ）を、スマホ幅の実画面のまま撮った。モックは使っていない。実サイトの取得はお休み中なので、映るのはアプリが自分で作ったデモ素材だけになる。

| 3.6–9.6 | 種類（動画→すべて）と名前（study）で絞り込む | ページの素材を、／一覧にして並べる。 |

| 21.6–28.8 | 入力欄の上の「お休み中」と、権利・プライバシーの注意へ戻る | ログイン不要。／運営者は、素材を保存しません。 |

## 作り直す

このフォルダとリポジトリの直下で、それぞれ `npm ci --ignore-scripts`（直下は撮影に使う Playwright）。
`npm run capture` → `npm run audio` → `npm run stills` → `npm run render` → `npm run audit`。生成物は gitignore された `output/` に出る。

- `PROMO_BASE` で撮る先（既定は本番）、`PROMO_FONT` で Zen Kaku Gothic New Bold の場所（既定は `~/Library/Fonts/`）、`CHROME_PATH` で Google Chrome を指定できる
- 音だけ作り直したときは `node render.mjs --mux` で、映像を描き直さずに重ね直せる
- 1回の撮影で本番へ送るのは、デモの取得2回・プレビュー数回・ZIP 1回。本番の1分あたりの上限より十分少ない

## 撮り方で決めたこと

- 撮るのは本番のデモ専用サイトだけ。本番のオリジン以外への通信は止めて記録する（撮影では0件だった）
- 初めての訪問で出るプライバシーポリシーの確認は、撮影の前に画面の操作で済ませた。確認は端末に残るので、撮る訪問では出ない
- 画面の文字は Zen Kaku Gothic New で描いた。アプリは書体を同梱せず端末の書体で表示するため、撮影機（macOS）の書体を動画に焼き込まないようにした。レイアウト・文言・動きは変えていない
- タップの印（点と輪）は映像側で足した。スマホ版 Chrome が触れた所に重ねる青い影だけは CSS で消した。消さないと、素材の画像が4コマほど青く見えた
- 一覧が出た瞬間に画面の上の図が消えて中身が詰まる。そこでタップの印は、押した要素の位置を撮影中に追って付ける
- スクロールはすべてスクリプトで1コマずつ動かす。アプリの滑らかなスクロールは実時間で進み、コマ送りの撮影と合わないため
- PageCrate に別窓のプレビューは無い。カードの中のプレビューを見比べて2点を選ぶ形にした
- 最小の幅の絞り込みは映していない。デモ素材の幅は960と320の2種類だけで、スマホ幅では絞っても見える範囲がほとんど変わらないため

## 音

A案は D メジャー・100 BPM のエレピとベル、B案は B♭ メジャー・84 BPM の撥弦とブラシ。外部の音源・サンプル・AI の音は使わず、`audio.mjs` が純JSで合成する（Day 031 の作りが土台）。

フックはドラムなしで始め、一覧でビートが入り、選ぶで旋律が加わる。ZIP の完了で明るく持ち上げ、安心は薄く静かにし、最後は終止和音とフェードで閉じる。ZIP の完了がちょうど小節の頭に来るよう、小節の位相をずらしている。タップには小さなクリック、完了には調に合わせた3音のチャイムを鳴らす。

目標と実測（ffmpeg の ebur128・astats）は `output/audit-report.json` に残る。

## 権利と制作

- 映像：PageCrate のデモ専用サイトの画面。デモ素材はアプリのコードが作った画像と動画で、第三者のページ・ロゴ・顔・声は映さない
- 書体：Zen Kaku Gothic New（SIL Open Font License 1.1。全文は `day-053-kotoba-tsuji/fonts/OFL-ZenKakuGothicNew.txt`、配布元は https://github.com/googlefonts/zen-kakugothic ）。手元にインストールした書体を描画用のフォルダへ写すだけで、リポジトリには入れない
- デモ素材の SVG の中の英字（PAGECRATE / STUDY など）は、ブラウザが撮影機の書体（Helvetica）で描く。素材の中身なので差し替えていない
- 画面操作・字幕・編集・音・検査は AI が担当した。本人の声・顔・体験談は作らない
- Remotion は 4.0.535 に固定し、個人の制作環境でローカルに描画する。外部のレンダリングは使わない（https://www.remotion.dev/docs/license ）
