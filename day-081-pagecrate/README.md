# Day 081「PageCrate」

公開されているページの画像と動画を一覧にし、選んだものを出典の記録つきのZIPで保存するWebアプリです。ログインは要りません。運営者は、入力されたURL・取得した素材・候補の一覧を保存しません。

取得できても、再利用してよいという許諾にはなりません。使う前に、権利者の許諾と対象サイトの規約を確かめてください。

いまは、実サイトの取得を止めています。権利と規約の確認が済むまでは、自作の素材を使うデモで、一覧から保存までの流れを試せます。

## できること

- 公開された1ページから、画像と動画の候補を集めて一覧にする
- 種類・名前・最小の幅で絞り込み、画像はプレビューで確かめる
- 選んだ素材を、取得日時と出典ドメインを書いた記録つきのZIPにまとめて保存する
- 外部のサイトに接続しないデモで、一覧から保存までを試す

## このDayの記録

このDayの成果物はWebアプリです。コードは別の公開リポジトリに置いています。ここにあるのは、一覧に載せるための記録（meta.json・スクリーンショット・動画）だけです。動画とスクリーンショットは、公開サイトと同じ停止中の構成で、内蔵のデモを録りました。
