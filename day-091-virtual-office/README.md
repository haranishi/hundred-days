# Day 091「バーチャルオフィス」

リンクを送るだけで、離れた人と同じドット絵のオフィスに集まれるWebアプリです。トップの「オフィスを作る」を押すと、オフィスのリンクができます。開いた人は、登録せずに名前と色を決めて入れます。中では、歩く・座る・「会議中」などの状態を出す・コーヒーや集中のタイマー・リアクション・短い会話ができます。部屋は3つ。執務室・会議室・休憩室を、扉で行き来します。ひとりのときはNPCの同僚が働いていて、NPCと卓球もできます。スマホでは、自分を追って拡大した地図を指で動かせます。

- 公開サイト: https://day91.rairakku.com/
- `rairakku.com` の中の住所: https://rairakku.com/day91/（`day91.rairakku.com` へ転送します）

名前・色・位置・会話は、同じ部屋の人へ届けるためにサーバーを通ります。データベースには保存しません。部屋全体への会話は直近50件まで、あとから入った人にも表示され、部屋に誰もいなくなってしばらくすると消えます。リンクを知っている人は誰でもそのオフィスに入れるので、知られたくないときは新しいオフィスを作ります。オフィスのページは、検索エンジンに載らない設定にしています。
