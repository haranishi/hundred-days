# Day 045 紹介動画

30秒・1080×1920・30fps。実ゲームのiframeを固定seed・手動時計で動かし、900枚のPNGからffmpegで動画を作る。字幕・エンド画面・コード合成BGM付き。依存パッケージは追加しない。

## 使い方

リポジトリのルートで、利用可能なPlaywrightのindex.jsを`PLAYWRIGHT`に設定する。ffmpeg・ffprobeとChromiumが必要。ローカル配信はツールが空きポートで起動・終了する。buildやdistは使用しない。

```sh
export PLAYWRIGHT='<playwright index.js>'
cd day-045-read-your-shots
node tools/promo/render-promo.mjs --preview
node tools/promo/render-promo.mjs
# 出力先を変える場合（カレントディレクトリ基準）
node tools/promo/render-promo.mjs --out tools/promo/promo.mp4
```

既定の出力は`tools/promo/promo.mp4`と`tools/promo/promo-first-frame.png`。
`--preview`も全30秒・900コマを撮り、描画解像度を540×960へ下げて1080×1920に拡大する。本番は1080×1920で撮影する。字幕検査は両方で実行する。
連番PNG・中間WAVは`os.tmpdir()`以下の専用ディレクトリに置き、終了時に削除する。任意の`--out`で作ったファイルは追跡しないこと。
BGMだけ試聴するには`node tools/promo/promo-audio.mjs`。`promo-audio.wav`を同じフォルダに生成する。

## 絵コンテ

| 動画の秒 | 絵 | 字幕 |
| --- | --- | --- |
| 0–4 | ゲーム0.3秒から開始。1コマ目に飛行中の弾と艦隊 | その撃ち方、読まれてる |
| 4–9 | その位置で連射。赤い熱の帯を枠と光で強調 | 同じ場所から撃つと… |
| 9–14 | ゲーム8.9秒から自動操縦を再生。艦隊のひるみ | 艦隊が、よける |
| 14–19 | ゲーム14.3秒から再生。▽と自機の位置を囲む | 居場所まで、狙われる |
| 19–24 | ゲーム18.3秒から再生。「裏をかいた ×2」の実表示 | 裏をかけば、得点2倍 |
| 24–28 | 手動で180秒進めてoverを確認。実結果パネル | あなたの癖を、1行で |
| 28–30 | タイトル・DAY 045・hundred-days.pages.dev | エンド画面に集約 |

1回の連続プレイではなく、同じseedのプレイを再現するカット構成。各カットは`setManual(true)`→`start()`→指定ゲーム時刻まで`advance()`し、撮影する毎コマで`advance(1000/30)`する。開始URLはrender側で組み立てた`index.html?seed=20260921#auto`。4–9秒だけ自動操縦を切って発射入力を固定し、9秒以降のカットで自動操縦へ戻る。ゲーム状態・得点・講評を捏造しない。

画面は`promo.html`・`promo.css`・`promo.js`。ゲームの見出しや操作欄をiframe内の撮影用CSSで隠し、実Canvasと実結果パネルを大きく出す。アプリのソースCSSは変更しない。
字幕と強調枠の切り替えは`timeline.mjs`の絶対時刻のみ。実時間・通知・音楽の完了待ちは使わない。字幕は1行16字以内・2行以内、文字は上下左右10%セーフ内。現在はすべて1行。

## 検査と未確認事項

書き出し後、動画の不透明な字幕欄をffmpegで切り出して差分を測り、4・9・14・19・24・28秒の**6回**と照合する。個数の不一致・0.4秒を超えるずれは失敗。1コマ目の弾、字幕のセーフ領域、結果到達、30秒の尺、寸法、音声トラックも検査する。エラー時は生成済みmp4を残す。
文字差分のしきい値はこの環境で実映像に対して未検証。検査が落ちたら動画と時刻を確認し、単に検査を無効にして成功扱いにしない。

Nodeテストは時間割とゲームロジックの再現を確認するが、実際に描かれた字幕・回避の見やすさ・音質を保証しない。別担当が実描画し、1コマ目、7場面、文字切れ、音量、ゲームとの対応を目視・聴取する。ブラウザ・OSによるフォントや画像デコードの差は残る。

## 音と素材

BGMは120 BPM、Em7→Cmaj7→Am7→Bm7。正弦波のパッド・分散和音・低音・キックをコード合成し、PCMピークを-6dBFSに揃え、最後の1.5秒でフェードアウト。前例の92 BPM・コード進行から変更した。BGMだけを付け、デモ用効果音は混ぜない。
映像にはDay 045同梱の画像を使う。外部音源・画像・フォントは追加しない。通信はこのツールが起動したローカル配信元だけ許可する。公開・投稿は行わない。
