# Day 045：その撃ち方、読まれてる

敵艦隊が、あなたの「撃った場所」と「居た場所」を覚える固定画面シューティング。
同じところから撃つほど弾はよけられ、同じところに立つほど敵弾がそこへ集まる。
勝ち筋は、読まれないこと。
なぜ外したのか、なぜ当たったのかが、そのつど画面に出ているシューティングを作りたかった。

## 遊び方

- 「はじめる」または Enter で開始。
- 戦場を押したまま左右へ動かすと、移動しながら自動で撃つ。
- ← → / A D で移動、Space / ↑ / Z で発射。P / Esc で一時停止、M でミュート。
- 自弾は画面に2発まで、再発射は0.25秒ごと。自機の下の細い線が、その残り時間。
- ライフは3。艦隊が防衛線まで降りても終わる。全滅させると次のウェーブへ進む。
- 各ウェーブの最初の3秒は敵が撃ってこない。立ち位置を決め直すための猶予。
- HUDには点数・ライフ・ウェーブ・ベストに加えて、残りの敵の隻数を出す。

## 読まれる仕組み

画面を12レーンに分け、撃つたびにそのレーンの「熱」を1つ上げ、5秒の時定数で冷ます。
上端の帯がその熱で、白い線が入っているレーンが、いまいちばん読まれている場所。
あわせて200msごとに自機の位置を覚え、減衰をかけた重心へ敵弾を撃つ。▽がその狙い先。
遊び始めて4秒、▽が自機と重なった最初の一度だけ「▽ ここを狙われている」と出る。

読まれ度（0〜100）は、最大の熱を0.6、居場所の集中を0.4で足した値。
HUDのメーターは40・70・90で色が変わり、90以上は数値も赤くなって点滅する。
熱が平均より低いレーンから撃って当てると「裏をかいた」で得点が2倍。
熱いレーンから撃つと艦隊が横へひるんでかわす。外れた理由が、その場で見える。

ウェーブを越えるたびに 50×ウェーブ 点。艦隊の歩みは1波ごとに18%速くなり、
敵の射撃間隔は0.85倍ずつ詰まって0.45秒で頭打ち、敵弾そのものも速くなる。
艦隊の開始行は5波目で止める。最下行が防衛線に近すぎると、腕ではなく運で終わるからだ。

## 設計で決めたこと

- **学習は隠さない。** 見えない難易度調整にすると、ただ理不尽なゲームになる。
  熱の帯・▽・読まれ度を常時出して、負けた理由をプレイヤーが説明できる状態にした。
- **熱は不透明度ではなく明るさで示す。** 暗い背景の上では、半透明の赤を濃くしても
  輝度がほとんど動かず、熱0.4と0.6を見分けられない。暗い赤から明るい橙へ輝度そのものを
  上げる階調にしてある（`lib/heat-color.js`）。熱0.3で背景比3:1、熱1.0で8:1を単体テストで固定した。
- **癖は時間で冷ます。** 一度読まれても、場所を変えれば数秒で読まれ度が落ちる。
  取り返しのつく難しさにしたかったので、熱は累積ではなく減衰させている。
- バリケード・ボス・アイテムは入れない。「撃つ・動く・よける」の3つだけで成立させる。
- ジャンルの型は借りるが、名称・絵・音・画面構成はほかのゲームから借りていない。

## 保存と通信

端末に残すのは `day045.best.v1`（ベスト点・ウェーブ・日付）と `day045.mute.v1` だけ。
名前も撃ち癖の履歴も残さない。保存を拒否する設定でも、記録が残らないだけで遊べる。
外部通信は0本。絵は同梱、音はWeb Audioで合成、書体は端末にあるものを使う。

## 絵が無くても遊べる

同梱の画像（背景1枚と宇宙船4種）が読めないときは、当たり判定を変えないまま図形描画に落ちる。
`#app` に `data-art="fallback"` が付き、画面にもその旨を小さく出す。テストはこの経路も通す。

## 動かす・調べる

- 単体テスト：`node --test day-045-read-your-shots/tests/`
