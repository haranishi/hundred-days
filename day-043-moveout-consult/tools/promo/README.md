# Day 043 紹介動画

`node day-043-moveout-consult/tools/promo/render-promo.mjs` で30秒の縦型動画を生成する。
1080×1920、BGM付き。画面と字幕は架空の入力例であり、実際の相談事例ではない。

## 流れ

請求の状況 → 気になる費目 → 手元の資料 → 相談メモ → 保存方法。
字幕は1行16字以内。請求の減額や法的判断を約束しない。
1コマ目は請求の金額欄へスクロールしている途中から始める。

## 素材

映像は実アプリの操作。外部の画像・相談事例・個人の書類を使わない。
BGMはDay042の既存の純JavaScript合成器を複製し、30秒の場面構成で生成する。
録画方法も既存の実画面撮影方式に合わせた。BGMと映像・生成途中のファイルはGit追跡しない。

公開・SNS投稿は行わない。完成ファイルを見て、画面と字幕の一致・文字切れ・音量を確認する。
