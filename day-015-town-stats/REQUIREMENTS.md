# Day 015「あなたの街のステータス」要件定義

2026-08-22。本人の題材指定（e-Stat × 国土地理院で街のステータス・地域ランキング）。
実装はローカルLLM（Ollama gemma3:27b）に下書きさせ、Fableが検収・修正する実験日。

## ユーザーストーリー

引っ越し・帰省・旅行で「この街ってどんな街？」と思った人が、市区町村名を入れて
30秒で「人口・年齢・世帯のかたち」を全国の中での立ち位置つきで眺め、
地元と今いる街を並べて「へえ、こんなに違うんだ」を誰かに見せたくなる。

## UX5階層

- **戦略**: 価値は「序列」ではなく「自分の街の輪郭を知る楽しさ」。良い/悪いを言わない。
  数字は国の統計そのまま、順位は「多い方から◯位」と方向を事実として言うだけ。
- **要件**: ①街を選ぶ（都道府県→市区町村＋文字検索） ②ステータスカード表示
  ③各指標に全国順位（1,741市区町村中）と全国中央値 ④2つの街の比較 ⑤URLで状態共有。
- **構造**: 単一ページ。選択→カード→（任意で）比較相手→出典・限界の順。
- **骨格**: カードはRPGのステータス画面風（項目名／値／順位バッジ／中央値との比バー）。
- **表層**: 落ち着いた紙色＋1アクセント。ランキング煽り色（赤・金）を使わない。

## 指標（10個・すべて出典内の値か単純な割り算）

| 指標 | 出典 | 備考 |
|---|---|---|
| 総人口 | e-Stat 国勢調査2020 | |
| 5年間の人口増減率 | 同上 | 2015→2020 |
| 面積 | 国土地理院 面積調 令和8年4月1日 | 境界未定は「参考値」注記を引き継ぐ |
| 人口密度 | e-Stat 国勢調査2020 | 調査の公式値（2026年面積と混ぜて再計算しない） |
| 平均年齢・年齢中位数 | 同上 | |
| 15歳未満割合・65歳以上割合 | 同上 | |
| 人口性比（女性100人あたり男性） | 同上 | |
| 単独世帯割合 | 同上から自前計算（単独世帯÷一般世帯） | 加工した旨を明記 |

## 規約・炎上ガード（実装で守る仕様）

1. 出典表記を常設: 「令和2年国勢調査（総務省統計局）を加工して作成」＋
   「全国都道府県市区町村別面積調（国土地理院・令和8年4月1日時点）を加工して作成」。
2. 非公式の明示: 国の公式サービスではない旨・数値の保証はない旨を1行。
3. 価値判断語の禁止: 良い/悪い/住みやすい/ワースト/やばい を画面にもコードにも書かない。
4. 合成スコア・偏差値・総合ランキングを作らない（編集的判断＝炎上の火種）。
5. 順位は必ず方向つき文言「人口が多い方から◯位」。逆方向の一覧を「ワースト」と呼ばない。
6. 属性の序列化につながる指標（外国人割合・母子/父子世帯など）は扱わない（意図的除外）。
7. 調査年（2020年10月1日時点）をカード上部に常時表示。5年前の数字であることを隠さない。

## データ仕様

- 収録: 1,741市区町村（市772＋政令市20＋町村926＋特別区23）。政令市の区は非収録（順位母数の一貫性）。
- `data/towns.json`: `{ meta:{sources,generatedAt}, towns:[{code,pref,name,en,pop,pop2015,rate,area,areaNote,dens,ageAvg,ageMed,u15,o65,sexRatio,single,general}] }`
  順位・中央値は実行時に計算（lib/stats.js）。JSONは200KB台を想定。
- 変換: `tools/build-data.mjs`（依存ゼロ・node単体）。入力は
  国勢調査xlsx（statInfId=000032143614・第1面シート・データは10行目から・地域識別コード 1/2/3の行＋特別区=コード0のうち13101〜13123）と
  面積調CSV（R8_04_mencho.csv・cp932・標準地域コード5桁ゼロ埋めで結合）。
- 検証値（変換テストに使う）: 全国人口126,146,099／秋田市05201=面積906.07㎢／北秋田市05213=人口30,198・平均年齢56.9。

## 4状態（Day11-20の解禁テーマ）

- 空: 検索0件→「見つかりません。都道府県から選べます」＋選択UIへ誘導。
- 読込中: towns.json取得中はスケルトンカード。
- エラー: 取得失敗→再読み込みボタンつきの説明（データは同梱なので実質ローカル起因のみ）。
- 不正入力: 検索は文字種を正規化（全半角・カナかな）し、記号だけ等は0件扱いで案内。

## 技術・チャレンジルール

- ランタイム外部通信ゼロ（CONNECT_BY_APP追加不要）。地理院タイルは使わない（面積調のみ）。
- vanilla JS・依存ゼロ・`lib/` は純関数でユニットテスト対象。共有シェア4点＋OGPは共通機構。
- URL状態: `?c=05201&vs=13104`（比較相手は任意）。
- E2E: `tests/e2e/day-015-town-stats.spec.mjs`（実データ同梱なのでモック不要・4状態と主要動線）。
