# Day 051「ハコニワ」

全国1,741市区町村・309,253施設から行き先を探す3Dミニチュア観光マップ。
都道府県・市区町村を選び、施設の検索、詳細表示、経路案内、共有を利用できる。
3Dモデルは施設の種類を表すイメージで、実際の建物の精密な再現ではない。

- [アプリを開く](https://hakoniwa-map.haranishi.workers.dev/japan/)
- [出典・ライセンス・データの入手](https://hakoniwa-map.haranishi.workers.dev/licenses/)
- [アプリの管理リポジトリ](https://github.com/haranishi/hakoniwa-map)

本体は独立リポジトリと既存のCloudflare Workersで管理する。
100daysには外部公開アプリとして紹介情報とスクリーンショットを登録する。
全国カタログやNext.jsのビルドを二重管理しないため、この構成を維持する。

Google マップの画像・3D形状を転載していない。Googleは外部経路案内のリンク先。
地図はOpenFreeMap、施設・自治体はOverture等の公開データを利用し、条件は出典ページに記載する。
1自治体あたり最大1,000件。全自治体が100件・1,000件に達しているわけではない。
施設の営業状況や道路の通行可否は全件実地確認していない。
