# Day085 最小ワリカン

旅行・飲み会の立て替えをまとめ、誰が誰にいくら送るかを最小回数で計算する。
2〜12人、支払い100件まで。ログイン不要で計算・保存はブラウザ内で完結する。
送金そのものは行わない。

## 使い方
1. メンバーの名前を2人以上追加する。
2. 支払った人・内容・整数円の金額・割り勘の対象者を登録する。
3. 精算票を確認し、精算文をコピーしてグループLINEへ貼る。

支払いの編集・削除で結果を計算し直せる。名前は押すと変更できる。
各支払いで割り切れない1円は、対象者のうちメンバー登録順に配分する。
最小回数は部分集合のゼロ和グループを最大化するDPで厳密に求める。
金額の合計が一致し、送金後に各人の過不足がゼロになる。

## 保存と共有
確定した入力を端末に自動保存する。共用端末では使い終わったら「最初から」で消す。
保存できない場合は画面で知らせる。入力中の未確定の支払いは保存・精算に含まない。
別タブの保存変更を検出した場合は保存を止め、今の画面を保持する。

「この精算のURL」には名前・金額・内容が入る。リンクを知る人は読めるため参加者へ送る。
URLの内容は共有時点のコピーで、同時編集や暗号化された保管ではない。
受取側は確認後に開く。通常のアプリ紹介の共有には入力を含めない。
