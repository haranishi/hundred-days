# Day 089「FROSTLINE」

ブラウザで開くだけで滑れる、オリジナルの雪山ゲーム。架空の盆地（一辺4km・標高差1,500m）を、スノーボードかスキーで自由に滑る。エッジを立てれば雪を切って曲がり、板を横へ向ければ雪を削って止まる。ジャンプ台では、回転・宙返り・板をつかむ技が出せる。スマホは、画面の舵とボタンで操作できる。

- 公開サイト: https://day89.rairakku.com/
- `rairakku.com` の中の住所: https://rairakku.com/day89/（`day89.rairakku.com` へ転送します）

## 素材

山の地形・人物・道具・建物と木の形は、自作のプログラムで作りました。音は、雑音と発振器から計算で合成しています。3D描画に three.js（MIT）を同梱しています。アプリの中では、外部の画像・書体・音源は使っていません。

デモ動画と一覧の画像は、公開用ビルドを手元で配り、物理を1/30秒ずつ進めて1コマずつ撮った実画面です。字幕と音は入れていません。
