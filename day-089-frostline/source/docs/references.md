使い道は、マップの配置と見た目を合わせるための参考だけで、**ゲームには画像そのものを入れない**。置き場所の `refs/` は Git に入れていない。
何で作った絵かは、確かめていない。画像そのものは、ゲームにも、このリポジトリにも入れない。

## 使い方の決まり

- 配置は、絵をなぞらずに「目印の位置と高さの表」へ直して使う（`.kiro/specs/valley-map/requirements.md` の 1）。絵どうしで細部が食い違うときは、表と全体の絵を優先する。
- 見た目は、同じ視点で撮った自分の画と並べて比べる（`world.json` の `views`）。建物や橋の形は、絵の雰囲気（木と石・雪の屋根）を参考に、形そのものは独自に作る。
- 既存のゲームの画面写真は、参考にしない。
