# 製品の方針：銀嶺 GINREI（仮称）

## これは何か

ブラウザのURLを開くだけで、雪山をスノーボードで滑り降りる手ごたえを味わえる、オリジナルの3Dゲーム。
舞台は架空の谷。北に山頂、西に岩壁と氷河、東にゲレンデとリフト、南に凍った湖と集落がある盆地を、朝の光の中で滑る。
（2026-11-10 の夜に、本人が参考画像 9 枚と配置の指示を渡した。それまでの「東北にありそうな独立峰・樹氷・夕方の光」から、この配置へ改めた。仕様は `valley-map`。）

雪山を自由に滑るゲーム（Ubisoft の Steep など）と同じジャンルに入るが、どの作品の再現でもない。
名称・地図・画面の見た目・キャラクター・音・素材は持ち込まず、考え方だけを学んで一から作る。

## なぜ作るか

本人の依頼（2026-11-10）は「雪山を滑るゲームを、JavaScript の Web 版で、本物に近い滑る体験として作る」。
2026-10-08 に作った一人称スキーの試作 ALPINE FLOW は、滑走感の入口までは届いたが、
見た目は手続き生成の簡素な表現で止まり、板の向きと進む向きを分けた横滑りも未実装だった（同作の記録より）。
本作はその反省を引き継ぎ、物理と描画の土台から設計し直す。ALPINE FLOW 本体には手を入れない。

## 体験の目標

コアループは次の1文。
**山の上で自分のラインを選び、切って曲がる・削って止める・飛んで回る手ごたえを味わい、駅で一本の記録を見て、1操作で次の一本へ行く。**

手ごたえの定義は「エッジを立てると雪を切って曲がり、板を横へ向けると雪を削って減速する。
その違いが、姿勢・雪煙・音・跡で同時に分かること」。調査 R1 が最優先に挙げた点でもある。

## 利用者

| 利用者 | 欲しいことと理由 | 受け入れ条件 |
|---|---|---|
| 本命：SNSのリンクからスマホやPCで開く人 | 説明を読まずに30秒で滑り出したい。待たされると閉じる | 開いて1操作で滑走が始まり、最初の10秒で曲がれる |
| 本命：スノーボードやスキーの経験者 | 「分かってる」と感じる板の挙動が見たい | 切るターンと横滑りが別物として成立し、斜度と雪質で速度が変わる |
| 救う相手：雪山へ行けない人・ゲーム機を持たない人 | 道具も移動も無しに、雪山の気持ちよさを味わいたい | インストール無し。数年前のスマホでも画質を落として滑れる |
| 本人 | 作品として人に見せられる質にしたい | 写真と並べても雪山に見える画と、5分遊んで単調でない山 |

## UX の5階層

| 階層 | 決めたこと |
|---|---|
| 戦略 | 差別化は「URLだけで動くのに、板の挙動と雪山の光が本物寄り」と「山頂から湖畔の集落まで、1 つの谷を通して滑れる」の2点 |
| 要件 | 入れる：自由滑走、切るターンと横滑り、ジャンプと着地、空中の技（スピン・宙返り・つかみ）、ジャンプ台や崖などの地形の仕掛け、転倒と即再開、山の地図と駅、一本ごとの記録と課題、跡と雪煙、状態に連動した音。スキー（2026-11-11 に足した。道具を選べる。物理は 1 枚の板として解き、値と姿勢で違いを出す）。入れない：対戦と順位表、ウイングスーツ、イベント課金、会員登録 |
| 構造 | 題字 → 滑走 ⇄ 一時停止（再開・戻る・山の地図・設定）→ 駅に着くか止まると一本の記録 → 1操作で次の一本（おすすめ・同じ地点・地図）。どこで止まっても、地図から次の出発地点へ1操作で移れる。迷う分岐は「止まって動けない」「転んだ」の2つで、どちらも1操作で戻れる |
| 骨格 | 滑走中にいちばん大きいのは山の景色。表示は速度と標高だけを左下に置き、案内は下中央に1行で出して消す。タッチは左下に舵、右下にジャンプと制動（44px以上） |
| 表層 | 色は景色から取る（雪の白・影の青・夕日の橙）。強調色は橙の1色だけで、赤緑に意味を持たせない。動きは不透明度と移動だけ。カメラと姿勢はばねで連続に保つ |

この5階層を通して、実装が変わった点は次の5つ。
1. 板の向きと進む向きを最初から分けた物理にする（ALPINE FLOW の向き＝進路モデルを捨てる）。
2. 滑走者を画面中央の下へ置き、進む先を見せるカメラにする（R1：体が前方を隠す不満の回避）。
3. 画面に常に出す数字は速度と標高だけにする。技の名前と点は、着地の直後に案内の1行へ2秒だけ出す（2026-11-10 に本人が技を望んだため、初版の「点を出さない」を改めた。景色を塞がない方針は保つ）。
4. 転倒の理由を1行で返し、1操作で再開できるようにする（R1：衝撃の仕組みが分からない不満の回避）。
5. ポインターロックを使わない視点操作にする（スマホと同じ「ドラッグで見回す」に統一できる）。

## やらないと決めたこと

- 既存作品の山・コース・画面構成・名称・音を再現しない。実在ブランドのロゴや意匠を装備に付けない。
- 実在の山の標高データを使わない（2026-11-10 の決定。権利確認の手間を避け、滑って面白い地形を狙って作る）。
- 当面は手元の git だけで版を残し、GitHub への push・公開をしない（2026-11-10 の決定）。公開は遊べる形になってから決める。
- 公開しない間は SNS 共有・OGP を作らない。公開を決めたら、共有4点セットと OGP を公開の条件に入れる。

## 名称

仮称は「銀嶺 GINREI」。雪をかぶって銀色に光る峰を指す言葉で、雪の山頂を見上げて滑る本作の画に合う。
最初の仮称「雪線 SESSEN」は、同じジャンルのブラウザゲーム「Yuki Line（雪線）」と重なる恐れがあり、2026-11-10 に変えた（調査 R4）。
調査 R1〜R4 の本文に残る「雪線 SESSEN」「Projects/sessen」は当時の呼び名。公開前に、商標（J-PlatPat の第9類・第41類）を本人が確かめる。
