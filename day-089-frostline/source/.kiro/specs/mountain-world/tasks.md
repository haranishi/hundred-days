# Implementation Plan

- [x] 1. 土台：世界の定数と補間の式
- [x] 1.1 世界の定数・版・座標の決まりと、データの検査を用意する
  - 格子と座標の変換、配列の並び、版番号、`world.json` の必須項目を1か所で定める
  - 版や項目が違う `world.json` を渡すと、作り直す命令を含む誤りになることを試験で確かめる
  - _Requirements: 2.3, 7.4_
- [x] 1.2 高さの補間（3次Bスプライン・周期タイル・差分）を純粋関数として作る
  - 高さ・法線・進行方向の法曲率を、配列と定数だけから求める。大きな形・タイル・強さの3つを同じ補間で読む
  - 1次式の再現、合成した高さの傾きが境目で連続、横にも傾いた面での法曲率の値が試験で通る
  - _Requirements: 2.1, 2.2_

- [x] 2. 山を作る生成スクリプト
- [x] 2.1 種つき乱数・雑音・確認用の画像の書き出しを用意する
  - 段ごとに別の乱数の系列、周期つきの雑音、依存なしの PNG 書き出し
  - 同じ種で同じ値になること、書き出した PNG を標準の道具で開けることを確かめる
  - _Requirements: 7.2, 7.3_
- [x] 2.2 火山の基本形と特徴（火口・尾根と沢・棚・寄生火山・台地・練習の斜面）を作る
  - 設計の特徴の一覧を、場所と大きさを指定できる形で重ねる
  - 小さな山の陰影図で、火口・放射状の沢・台地・練習の斜面が見分けられる
  - _Requirements: 1.1, 1.2, 1.4_
- [x] 2.3 浸食（雨粒の流下と安息角のならし）を作る
  - 沢と扇状の堆積ができ、硬い岩の帯が残る。回数と強さは引数で変えられる
  - 浸食の前後で、沢の本数と斜度の分布が変わることを統計で示す
  - _Requirements: 1.2, 1.3_
- [x] 2.4 積雪と雪質・凹凸の強さ・木の密度の地図を作る
  - 風向き・標高・斜度・凹みから雪の深さと質を決め、岩の露出を出す
  - 雪質の割合の和が1、急な面に岩、沢と風下に深い雪があることを試験と画像で確かめる
  - _Requirements: 1.5, 3.1, 3.2, 4.3_
- [x] 2.5 出発地点と区域を作る
  - 候補の座標から条件を満たす雪面を探し、満たせなければ生成を失敗させる。区域の番号と名前を地図に書く
  - 出発地点が6か所以上あり、すべて要件5の条件（谷向き・前方150mに障害なし）を満たすことを試験で確かめる
  - _Requirements: 5.1, 5.2, 5.3, 5.4_
- [x] 2.6 夕方の影を作る
  - 太陽の向きへ高さをたどり、日が当たる度合いを 0〜1 で書く。縁は数十メートルの幅でぼかす
  - 解析的な壁の地形で影の長さが理論値と合い、縁の値がなめらかに変わることを試験で確かめる
  - _Requirements: 6.1, 6.2_
- [x] 2.7 書き出しと統計・短時間の確認用の指定をまとめる
  - 全配列・`world.json`（SHA-256 つき）・画像4種・統計を書き出す。`--quick` は小さな格子で作る
  - 本番の山が5分以内、小さな山が10秒以内。2回作って SHA-256 が一致する
  - _Requirements: 7.1, 7.2, 7.3, 7.5_

- [x] 3. 実行時の問い合わせ
