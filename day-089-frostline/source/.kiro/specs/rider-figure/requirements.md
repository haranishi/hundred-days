# 要件：滑走者の作り直し（rider-figure）

本人の感想（2026-11-10）は「人間があまりにも雑。もうちょっと丁寧に作ってほしい」。
いまの滑走者は、筒と球を関節でつないだ人形で、服のしわも縫い目も無く、色は 1 部品 1 色。近くで見ると作りかけに見える。
ねらいは、近くで見ても「スノーボードの服を着た人」に見えること。写真と見分けがつかない人物までは、この仕様では求めない。

## 1. 形

1.1 体と服は、継ぎ目のないひと続きの面にする。肩・ひじ・ひざ・腰で、球や筒の継ぎ目が見えない。
1.2 服と道具を作り分ける。
  - 上着：腰までの丈・すその広がり・後ろに下ろしたフード・立てた襟・前の合わせ・胸と腕のポケットの線・袖口。
  - ズボン：ゆったりした幅・ひざと足首のたるみ・靴にかぶるすそ。
  - 手：ミトン型の手袋（親指が分かれる）・袖口にかぶる長い口。
  - 頭：つばと通気の溝のあるヘルメット・枠と幅広の帯のあるゴーグル・口もとまで上げた首の覆い。肌は見せない。
  - 背中：小さな背負い袋（肩の帯・胸の留め具）。
  - 足：ひもの段が分かる靴・台座と背板と 2 本の帯のあるビンディング。
  - 板：先と後ろの丸みと反り・横の絞り・金属の縁・上面の独自の柄。
1.3 体つきは大人の 7 頭身前後（身長 1.75 m）。板の上で横を向いた立ち方が自然に見える。
1.4 実在の製品の意匠・ロゴは付けない。色と柄は独自にする。

## 2. 動き

2.1 いまの姿勢の計算（関節の位置と胸・頭の向き）をそのまま受けて動く。ひじ・ひざを深く曲げても、面が折れ目で潰れたり裏返ったりしない。
2.2 立つ・深く切る（両側）・低い姿勢・技の構え・つかみ 3 種・転倒の 8 つの姿勢で、体と服と板がめり込んで見えない。
2.3 速さに応じて、上着のすそとフードがわずかに揺れる（頂点の計算で行い、CPU の負荷を足さない）。
2.4 一人称では、いまと同じく頭と上半身を描かない（足もとと板と前腕は見える）。

## 3. 質感

3.1 布：細かい織り目と、関節まわりのしわが光で分かる。上着・ズボン・手袋・靴で、つやの強さが違う。
3.2 色分け：上着は 2 色の切り替え（橙が基調）。縫い目と前の合わせが線で分かる。
3.3 ゴーグル：空を映す色つきの面。ヘルメット：つやのある硬い面。板：つやのある上面と、白い滑走面。
3.4 影を落とし、自分にも影が落ちる。

## 4. 予算

4.1 三角形は合計 3 万以下。4.2 読み込むデータは 600 kB 以下（圧縮前）。4.3 毎コマの CPU の計算は 0.3 ms 以下（高画質・1440×900 で毎秒 60 コマを保つ）。
4.4 低い画質の段では、織り目としわの計算を省いてよい。

## 5. 作り方の決まり

5.1 形は手続きで作る（Node の道具が、決まった式から頂点・法線・重みを書き出す）。同じ入力なら、1 バイトも違わないデータができる。
5.2 道具は、ブラウザなしで確かめられる絵（正面・横・後ろ・斜めの 4 枚）を書き出す。
5.3 上着・ズボン・ヘルメットの色は、後から変えられる値にする（進み具合のごほうびに使えるように）。

## 6. 変えないこと

6.1 姿勢の計算の出力の形（`pose.joints`・`chestFwd`・`chestUp`・`headFwd`・`board`）。6.2 雪煙・跡・カメラが読んでいる値。
