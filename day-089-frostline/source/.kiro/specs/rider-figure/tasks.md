# タスク：滑走者の作り直し（rider-figure）

担い手は、形を作る道具と骨の計算が Codex（依頼書 I13）、実ブラウザでの組み込みと見た目の採点の段取りが設計役。

## 形を作る道具（`tools/ridergen`）

- [ ] 1. 服と体の形（距離の関数）と、面に起こす処理（要件 1.1〜1.3）
- [ ] 2. 硬い道具：ヘルメット・ゴーグル・靴・ビンディング・板（要件 1.2）
- [ ] 3. 頂点に付ける値：法線・骨の重み・部位の番号・しわの強さ・揺れの強さ（要件 2.1・2.3・3.1）
- [ ] 4. 書き出し（`public/models/rider-v1.bin`・`.json`）と、確認の絵 4 枚（要件 5）
- [ ] 5. 予算と決定性の試験（要件 4.1・4.2・5.1）

## 骨の計算（`src/render/ride/skeleton-math.js`）

- [ ] 6. 関節の位置と向き → 骨ごとの位置と向き。立った姿勢で、何も変形しないこと（要件 2.1）
- [ ] 7. 曲げがほぼ 0 のとき・逆さのときの安定（非数なし・向きが飛ばない）

## 組み込み（`src/render/ride/figure.js`・実ブラウザ）

- [ ] 8. データの読み込み・骨つきの面・硬い道具の固定・一人称の扱い（要件 2.4）

- [ ] 10. すそとフードの揺れ（前のコマの位置も合わせる）（要件 2.3）
- [ ] 11. 8 つの姿勢を 3 方向から撮る・性能を測る（要件 2.2・4.3）
- [ ] 12. 見た目の採点（作者と別の担い手）と直し
