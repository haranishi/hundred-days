# Design: ride-feedback

## Overview
滑走の状態（ride-sim）を読み、滑走者の姿勢・カメラ・雪煙・跡・音にする。描画の場面とカメラは mountain-render の口を通して使う。

- **Goals**: 切る・削る・飛ぶ・着地・転倒の違いが、姿勢・雪煙・跡・音で同時に分かる。見た目の値がどの切り替えでも跳ばない。
- **Non-Goals**: 物理、地形と空、HUD、技の姿勢、雪面をへこませる跡、作り込んだ人物の造形。

## Boundary Commitments
- **This Spec Owns**: `src/render/ride/`、`src/audio/`、`tests/ride/`、`tests/audio/`
- **Out of Boundary**: `src/sim`（読むだけ）、`src/render` のほかの場所、`src/ui`
- **Allowed Dependencies**: `three`、`src/core`（ばね・乱数・画質の段）、mountain-render の差し込み口、ride-sim の状態の形
- **Revalidation Triggers**: 滑走の状態・出来事の形、mountain-render の差し込み口、器の `audio` の形が変わったとき

## 組み立て
```
src/render/ride/index.js      createRideFeedback({ view, world, settings })：系を登録し、音の部品を返す
src/render/ride/springs.js    臨界減衰のばね・角度のばね・2次遅れ（純粋な計算）
src/render/ride/ik.js         2本の骨の IK（純粋な計算）
src/render/ride/pose.js       状態から関節の位置と回転を決める（純粋な計算）
src/render/ride/figure.js     滑走者と板の形（手続きで作る）と、姿勢の反映
src/render/ride/camera-rig.js 三人称と一人称のカメラ（計算は純粋な関数に分ける）
src/render/ride/spray.js      雪煙
src/render/ride/tracks.js     雪面の跡（帯）
src/audio/params.js           状態と出来事から、音の値を決める（純粋な計算）
src/audio/engine.js           WebAudio の組み立てと、値の反映
```
描画の系は、補間した状態（`prev` と `state` を `alpha` で混ぜたもの）を使う。位置と向きは線形と球面で混ぜ、`jumped` のときは混ぜずに作り直す。

## 滑走者の姿勢（`pose.js`）
素材の動きは使わず、状態から毎コマ作る。順番は固定：①板 → ②足 → ③腰 → ④脚（IK）→ ⑤胴と頭 → ⑥腕 → ⑦二次の揺れ → ⑧非数の検査（出たら前コマの姿勢）。
- **板**：位置は状態の `pos`。向きは `fwd`・`up`。長い軸まわりに `edge` だけ傾ける。先端と後端の雪面の高さで前後の傾きを合わせる。
- **足**：板の上の決まった位置（前後 ±0.26 m・開き +15°／−9°）。必ず板に付く。
- **腰**：板の中心から、脚の長さ `leg` の所。傾き（`edge` の 0.9 倍）の内側へ寄せ、つま先側は膝を前へ、かかと側は腰を後ろへ出す。
  進む向きへ 30° ほど開く。横滑りでは山側へ預ける。
- **胴と頭**：脚より起こす（傾きの 6 割を戻す）。しゃがみで前へ曲げる。頭は進む向きと、次に曲がる側を見る。
- **腕**：前の腕は先端の方向、後ろの腕は釣り合いを取る。横の加速度と着地に、ばねで遅れて揺れる。深い傾きでは内側の手を雪面へ近づける。
- **空中**：`crouch` で膝を引きつける。回転は板に体を合わせ、着地の 0.25 秒前から脚を伸ばす。
- **転倒**：速さに応じて体を丸めて転がし、止まったら座り、立ち上がりで通常の姿勢へ 0.4 秒で戻す。
- 駆動する値（傾き・腰の高さ・開き・頭の向き）は、すべて臨界減衰のばねを通す。利き足と逆向きの滑走で左右を入れ替える。

## 滑走者の形（`figure.js`）
身長 1.75 m。胴・腰・上腕・前腕・手・もも・すね・足・首・頭を、丸めた箱とカプセルで作る。ヘルメット・ゴーグル・手袋・靴・板とビンディングを足す。
色は上着が橙、ズボンが濃い灰、板は独自の単純な柄。実在の製品の意匠を写さない。影を落とす。作り込みは snow-look で差し替えられるよう、形と姿勢を分ける。

## カメラ（`camera-rig.js`）
- **三人称**：注視点は、滑走者の腰の上から、進む向きへ速さに応じて 2〜8 m 先。カメラは進む向きの後ろ 5.5〜7.5 m、滑走者より 2.2〜3.0 m 上。
  斜面の傾きを平滑化して下向きの角度に足し、谷の先が見えるようにする。視野は 62°〜78°。
- 進む向きは「目標・変化の速さ・実際の向き」の3段で平滑化する。`s<1` では板の向きを使う。ドラッグの視点は足し算で、1.5 秒触らなければ戻す。
- 着地は、沈み込みと視野のばねへ、等価落下高に応じた初速を与える。揺れは「強さの2乗」を振幅にし、速さ・荒さ・横滑りで足し、設定の倍率を掛ける。
- カメラの高さは、その場の雪面より 1.2 m 以上。滑走者とのあいだに木があれば、高さを上げて避ける。寄せるのは速く、戻すのはゆっくり。
- **一人称**：頭の位置。進む向きを見て、傾きは体の 3 割だけ伝える。視野 88°。頭とヘルメットは描かない。
- `jumped` のときは、ばねを新しい位置で作り直す。

## 雪煙（`spray.js`）
粒は「生まれた位置・初速・生まれた時刻・大きさ・種」だけを持つインスタンス。位置は頂点シェーダーが時刻から計算する（重力・空気の抵抗・風）。
毎コマ CPU が書くのは、新しく生まれた粒だけ。数は 高 3000・中 1200・低 500 の輪の入れ物。
- 量は計測値の `spray` に比例。向きは、切るとき弧の外側と上、横滑りでは進む向きの前と上。初速に滑走者の速度の 3〜6 割を足す。
- 着地・転倒は一度にまとめて出す。空中では出さない。雪質の係数（新雪 1.6・圧雪 1.0・氷 0.3）を掛ける。
- 見た目は柔らかい円（雑音で崩す）。奥行きの差で縁を薄くする。逆光で明るく、日陰で青く。カメラのすぐ前の粒は薄くする。

## 雪面の跡（`tracks.js`）
通った点を 0.25 m ごとに記録し、帯の三角形の列にする（高 4096・中 2048・低 1024 節の輪）。帯の両端の高さは雪面に合わせ、わずかに浮かせる。
- 幅は、切るとき板の幅（0.26 m）、横滑りでは `0.26 + 1.3·|sin(slip)|` m。濃さは荷重と雪の柔らかさ。
- 見た目は、少し暗く滑らかな雪と、両縁の盛り上がりを法線で表す。縁はぼかす。空中では列を切る。
- 雪面を実際にへこませる方式は snow-look で差し替える（mountain-render の `setTrailSource`）。

## 音（`src/audio/`）
`params.js` が、状態と出来事から次の値を決める。`engine.js` はそれを WebAudio へ、時定数つきで反映するだけにする。
| 音 | 作り方 | 何で変えるか |
|---|---|---|
| 風 | 白い雑音を帯域で絞る | 音量は速さの2乗、帯域の中心は速さ。回る速さで左右の差 |
| 滑走 | 低めの雑音 | 速さ × 荷重。新雪は低く柔らかく、氷は高く硬く |
| 切る | 800〜2500Hz の雑音 | エッジの力 × 速さ。氷では 20〜40Hz の震えを掛ける |
| 削る | 300〜4000Hz の広い雑音 | 削る強さ（`skidPower`）。粒の粗い震え |
| 着地・転倒 | 60〜90Hz の短い正弦波と雑音 | 等価落下高。転倒は大きく長く |
| 山の空気 | ごく小さい風 | 常に |
空中は、滑走・切る・削るを 0.05 秒で絞る。音は始めるボタンのあとに開始し、音量と消音は設定に従う。雑音は種つきの乱数で作る。

## Testing Strategy
- **Node**：ばね（跳ばない・行き過ぎない）、IK（届く・届かないときの伸び切り・肘と膝の向き）、姿勢（幅広い状態で非数なし・足が板から離れない・
  切り替えの前後で関節の動きが上限以内）、カメラ（連続・雪面より下に入らない・`jumped` で作り直す）、跡（幅の式・空中で切れる）、
  音の値（速さで風が単調に増える・空中で雪面の音が 0・切ると削るの値が入れ替わる）。
- **実ブラウザ**：起動の検査、固定の場面（切る左右・横滑りの停止・空中・着地・転倒）の撮影、毎コマの計算時間。
