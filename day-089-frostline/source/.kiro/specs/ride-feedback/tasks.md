# Implementation Plan

- [x] 1. 土台：ばねと IK
- [x] 1.1 (P) 連続に保つための計算（ばね・角度のばね・2次遅れ）を作る
  - 値と速さを持ち、目標が跳んでも値が跳ばない。大きな時間刻みでも安定する
  - 行き過ぎない・収束する・時間刻みを変えても結果がほぼ同じであることが試験で通る
  - _Boundary: src/render/ride の springs_
  - _Requirements: 1.8, 2.2, 5.7_
- [x] 1.2 (P) 2本の骨の IK を作る
  - 付け根・先・曲がる向きの目印から、中間の関節の位置を決める。届かないときは伸び切る
  - 届く場合の長さの一致、届かない場合の伸び切り、曲がる向きが目印の側であることが試験で通る
  - _Boundary: src/render/ride の ik_
  - _Requirements: 1.1_

- [x] 2. 滑走者
- [x] 2.1 状態から姿勢を決める計算を作る
  - 板・足・腰・脚・胴と頭・腕・二次の揺れの順で、関節の位置と回転を決める。空中・転倒・立ち上がりを含む
  - 幅広い状態で非数が出ない、足が板から離れない、切り替えの前後で関節の動きが上限以内であることが試験で通る
  - _Requirements: 1.1, 1.2, 1.3, 1.4, 1.5, 1.6, 1.7, 1.8_
- [x] 2.2 滑走者と板の形を作り、姿勢を反映する
  - 手続きで形を作り、影を落とす。補間した状態から毎コマ姿勢を反映する
  - 固定の場面（切る左右・横滑り・空中・転倒）で、足が板に付き、傾きと形が状態に合って見える
  - _Requirements: 1.1, 1.2, 1.3, 1.4, 1.5, 1.6, 1.7_

- [x] 3. カメラ
- [x] 3.1 三人称のカメラを作る
  - 進む向きを平滑化して後ろから追い、先を見せる。速さで視野と距離を変え、着地で沈み、雪面と木を避ける
  - 状態の列を与えた試験で、カメラが連続に動き、雪面より下へ入らない。固定の場面で滑走者が中央より下にいる
  - _Requirements: 2.1, 2.2, 2.3, 2.4, 2.5, 2.8, 2.9_
- [x] 3.2 視点のドラッグと一人称を作る
  - ドラッグで見回し、触らなければ戻る。一人称へ切り替え、地平線の傾きを抑える
  - 切り替えの前後でカメラが跳ばず、一人称で頭が視界を塞がない
  - _Requirements: 2.6, 2.7_

- [x] 4. 雪煙と跡
- [x] 4.1 (P) 雪煙を作る
  - 計測値に応じた量と向きで粒を出し、時刻から GPU で動かす。着地と転倒でまとめて出す。段で数を変える
  - 固定の場面で、切ると削るで量と向きが違い、空中で出ず、滑走者と先を隠し続けない
  - _Boundary: src/render/ride の spray_
  - _Requirements: 3.1, 3.2, 3.3, 3.4, 3.5, 3.6, 6.1_
- [x] 4.2 (P) 雪面の跡を作る
  - 通った点から帯を作り、雪面に沿わせる。切ると削るで幅を変え、空中で切る。段で長さを変える
  - 幅の式と、空中で列が切れることが試験で通る。固定の場面で、跡が離れた所からも見える
  - _Boundary: src/render/ride の tracks_
  - _Requirements: 4.1, 4.2, 4.3, 4.4, 6.1_

- [x] 5. 音
- [x] 5.1 (P) 状態と出来事から音の値を決める計算を作る
  - 風・滑走・切る・削る・着地・山の空気の、音量と帯域を決める
  - 速さで風が単調に増える、空中で雪面の音が 0、切ると削るで値が入れ替わる、雪質で値が変わることが試験で通る
  - _Boundary: src/audio の params_
  - _Requirements: 5.1, 5.2, 5.3, 5.4, 5.5_
- [x] 5.2 WebAudio の組み立てと、値の反映を作る
  - 雑音と正弦波から音を作り、値を時定数つきで反映する。最初の操作のあとに始め、音量と消音に従う
  - 実ブラウザで誤りなく始まり、値の変化で音量がなめらかに変わる（計測値の記録で確かめる。聞こえ方は人が確かめる）
  - _Requirements: 5.6, 5.7_

- [x] 6. まとめと検証
- [x] 6.1 系を登録する入口を作り、固定の場面を用意する
  - 滑走者・カメラ・雪煙・跡を描画へ登録し、音の部品を返す。切る左右・横滑りの停止・空中・着地・転倒の場面を定義する
  - 場面を決まった操作から再現して撮影でき、起動の検査が誤りと警告なしで通る
  - _Requirements: 7.1, 7.2_
- [x] 6.2 速さを測って整える
  - 毎コマの計算時間を測り、段ごとの数を決める
  - 高い段で、演出の毎コマの計算が 2 ms 以内
  - 検証（2026-11-10）：曲がりと制動を混ぜた滑走中で、演出の毎コマの計算は 95% 点 0.2 ms・最大 0.3 ms（高の段・3 地点）
  - _Requirements: 6.1, 6.2_
