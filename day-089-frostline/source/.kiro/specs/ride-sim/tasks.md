# Implementation Plan

- [x] 1. 土台：係数・ベクトル演算・試験用の地形
- [x] 1.1 係数と雪質の表を、出どころつきで1か所に置く
  - `model.md` の全係数と雪質の表を定め、雪質の割合から係数を混ぜる
  - 割合が圧雪100%・新雪100%・氷100%・岩100%のとき、表の値そのものが返ることを試験で確かめる
  - _Requirements: 8.1, 8.2, 8.3_
- [x] 1.2 物を作らないベクトル演算と、解析的な試験用の地形を用意する
  - 平面（任意の斜度と向き）・一定の曲率の丘と谷・波・キッカーを、地形の問い合わせの形で用意する
  - 各地形の高さ・法線・曲がり具合が、解析式と一致することを試験で確かめる
  - _Requirements: 9.1_

- [x] 2. 接地の力学
- [x] 2.1 状態の入れ物・出来事の出し方・脚のばねと荷重を作る
  - 状態と出来事の共通の仕組み（写し・空にする時点）を先に決める。凹みで縮んで荷重が増え、凸で伸びて荷重が減り、支えきれなければ空中へ出る
  - 丘の頂と谷底の荷重（横にも傾いた面を含む）、離雪の境界の速さ、静止時の縮みと減衰比が数値目標と一致する
  - _Requirements: 4.1, 4.2, 4.3, 10.1, 10.2_
- [x] 2.2 斜面での加減速・止まる・動き出すを作る
  - 重力・雪の摩擦・空気の抵抗で速さが決まり、登りと平らで減速し、横向きで留まり、谷か山を向いて止まれば先端を谷へ向けて動き出す
  - 終端速度（20・30・40 度と低い姿勢）が理論値の±2%、摩擦で速度の向きが反転しないこと、速さ 0 と荷重 0 で非数が出ないことが試験で通る
  - _Requirements: 1.1, 1.2, 1.3, 1.4, 1.5_
- [x] 2.3 切るターンを作る
  - 左右で傾いて弧を描き、半径が速さと雪の横力で決まり、切り替えに時間がかかる。左右なしでも斜面を横切り続ける
  - 平らな面の弧の横力と傾き、氷で弧が3倍以上、切り替え 0.3〜0.5 秒、横切りの保持、横力不足の出来事が試験で通る
  - _Requirements: 2.1, 2.2, 2.3, 2.4, 2.5, 8.2_
- [x] 2.4 横滑りと制動を作る
  - 制動を入れると切る状態から削る状態へ移り、板が横を向いて減速する。左右と合わせると小さく回り、離すと板が戻る。山側のエッジだけを使う
  - 時速 60 km からの制動距離 12〜20 m、離して 0.5 秒で復帰、横滑り中に雪の力が速さを増やさないことが試験で通る
  - _Requirements: 3.1, 3.2, 3.3, 3.4, 3.5_
- [x] 2.5 新雪の沈み込みと岩の減速を作る
  - 新雪で沈んで抵抗が増え、遅いほど深く沈む。岩の露出で強く減速する
  - 新雪の支持の数値目標、速さと沈み込みの関係、岩での減速が試験で通る
  - _Requirements: 8.1, 8.3_

- [x] 3. 空中と着地
- [x] 3.1 踏み切りと空中の動きを作る
  - 押してしゃがみ、離して踏み切る。空中は放物線で、仕込みと空中の左右で横に回り、低い姿勢で速く回る
  - 平らな面の踏み切りの高さ 0.2〜0.45 m、放物線の頂点と滞空、しゃがみでの回転の加速が試験で通る
  - _Requirements: 5.1, 5.2, 5.3, 5.4, 5.5_
- [x] 3.2 着地の判定を作る
  - 刻みの中で雪面と最初に交わる時刻を求め、その時点の衝撃と向きのずれから4つに分ける。下り斜面への着地を軽く扱い、逆向きの着地を続けさせる
  - 4分類の境界、斜面への着地の等価落下高、逆向きの着地、着地の出来事の中身、60・120・240Hz での衝撃の差 5% 以内が試験で通る
  - _Requirements: 6.1, 6.2, 6.3, 6.4_

- [x] 4. 転倒・接触・復帰
- [x] 4.1 (P) 転倒と立ち上がり・復帰・安全な地点を作る
  - 理由つきで転び、滑って止まり、立ち上がる。出発地点と安全な地点へ戻せる
  - 転倒から立ち上がりまでの時間、復帰後に止まっていること、安全な地点が安定時だけ更新されることが試験で通る
  - _Boundary: src/sim の crash_
  - _Requirements: 7.1, 7.2, 7.3, 7.4_
- [x] 4.2 (P) 木と岩への接触と、地図の端を作る
  - かすれば向きと速さが変わり、強く当たれば転ぶ。端の近くで止まる
  - 当たる速さの境界の前後で結果が変わること、端で止まって出来事が出ることが試験で通る
  - _Boundary: src/sim の contact_
  - _Requirements: 8.4, 8.5_

- [x] 5. まとめと検証
- [x] 5.1 計測値と控えをそろえ、出来事の網羅を確かめる
  - 全計測値を出し、控えを取って戻せる。設計の出来事がすべて、対応する場面で出ることを確かめる。短い浮きは出来事にしない
  - 控えから戻して続けた結果が、止めずに進めた結果と一致することが試験で通る
  - _Requirements: 9.1, 10.1, 10.2, 10.3_
- [x] 5.2 決定性・刻み・耐久の試験を通す

  - 全試験が通り、1刻みの時間の実測を記録する
  - _Requirements: 9.1, 9.2, 9.3_
