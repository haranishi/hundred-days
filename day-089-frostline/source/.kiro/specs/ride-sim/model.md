# 力学の式と係数：ride-sim

出どころは調査 R2（`docs/research/R2_physics.md`）。「提案値」は実測の裏づけが無く、遊んで調整する値。係数はすべて `src/sim/params.js` に置く。
2026-11-10 I10で空中技・制動を更新。検証は `.agent-harness/runs/impl/I10_progress.md` と `node tests/sim/trick-measure.mjs`。I8では、T12〜T19と検証証拠は `.agent-harness/runs/impl/I8_progress.md`。I8の依頼で旧要件1.5（先端を谷へ）・2.4（無操作で横切り保持）を更新する。T2は浮かない振幅0.05mの既存試験を引き継ぐ。

## 記号
`m=80`・`g=9.81`・空気 `ρ=1.10`。雪面の法線 `n`、接平面の速度 `vt`、速さ `s`、進む向き `t=vt/s`、進む向きの右 `c=t×n`。
板の先端の向き `f`、板の右 `Rb=f×n`、板に沿う速さ `u=vt·f`、横の速さ `w=vt·Rb`。`gn=g·n.y`（法線方向の重力）。
`κ` は進む向きの雪面の法曲率（`terrain.curvatureAlong`・上に凹が正）。

## 摩擦・荷重が無いとき・遅いときの決まり
- **摩擦と抵抗は、必ず実際の速度の逆向きに掛ける**（覚えておいた `t` を使わない）。先に重力などで速度を進め、そのあと速さを
  `max(0, 速さ − 減速×dt)` に縮める。1刻みで 0 を越えないので、向きが反転しない。板に沿う成分へ掛ける摩擦も同じ。
- `N=0` のとき、横力の上限も横滑りの力も 0。横滑りの式は `N` が約分できる形（下の5）で書く。
- **遅いとき（`lowSpeed`）は、切る・削るとは別の更新にする。** 入るのは `s<2.5`、出るのは `s>3.0`（行き来を防ぐ）。制動中は削るの式を使う。
  - 板の向き `f` は進む向きに沿わせず、自分で持つ。左右があれば毎秒 `clamp(steer·2.2·(1−s/3),−1.8,1.8)` rad で回す。左右が無く、留められない（下の7）ときは、近い板端を谷へ `clamp(1.1·誤差,−100°,100°)` /sで回す（誤差を±90°へ折り返す）。
  - 速度は板の軸に沿う成分 `u` と横の成分 `w` に分ける。`u` は板に沿う重力と摩擦で進める。`w` はエッジが止める：
    横の力は `−m·w/dt` を `±λ·N·E(25°)` で切った値（止め切れない分だけ横へずれる）。
  - `t` や `1/s` を使う式（切るの4）は、この更新では使わない。出るとき、`t` を速度の向きから作り直し、`aLat=0` で切るへ渡す。
  - 止まって留まる条件（下の7）を満たせば、速度を 0 にして `mode='rest'` ではなく、接地のまま静止として扱う（操作で動き出せる）。

## 毎刻みの順（接地）
1. 雪面と雪質を読む。`f` を接平面へ落とし直す。
2. **脚と荷重**：進む向きの法曲率 `κ` から、脚が支える加速度 `aN = gn + s²κ`。
   脚は片側のばね `F = max(0, k(ℓrest−ℓ) − c·ℓ̇)`、`ℓ̈ = F/m − aN`。`k=15000`・縮み側 `c=1800`・伸び側 `c=1000`（提案値）。
   `ℓ` は 0.45〜1.00 m。立ち 0.90、しゃがみ 0.55。`ℓrest = ℓtarget + m·gn/k`（どの斜度でも静止時に目標の長さ）。
   下限に当たれば `bottomOut`。上限で `ℓ̇>0`、または上限にいて `aN≤0` なら離雪。上限前でも `F=0` の時間が連続 `unloadTime=0.04s` に達したら自然離雪する。荷重復帰・操作によるしゃがみ短縮・配置・離雪・着地でタイマーを消す。ジャンプ保持/tuck操作で脚を短くする荷重抜けはT10維持のため除外する。自然に脚が短くなるときは除外しない。
   自然離雪には脚の相対伸び速度を上向きの速さとして加算しない。雪面の反力 `N=F`、`load=N/(mg)`。
3. **横の指令**：`E(φ)=0.06+0.94·sin(min(|φ|,60°))^0.8`、横力の上限 `Fmax=λ·N·E(φ)`。
   指令用の定常支持を `N0=m·gn` とし、横力予算 `C=0.86·λ·E(φmax)·N0/m`。`Rsc=8`・`φmax=60°`（低い姿勢は 38°）。
   `gSide=Fg·c/m`、`ωcmd=clamp(s/(Rsc·cos φmax),1.6,1.8)`、`aCmd=steer·min(s·ωcmd,C)`。これはエッジだけの要求。無操作では横重力を相殺せず、谷へ流れる。
   指令を臨界減衰の2次遅れ（`ω=8`、荷重 0.5 未満は 1.3 倍）に通して `aLat` にする。実際の力の上限には瞬間の `N` を使う。
4. **切る**（`mode='carve'`）：エッジが出す力 `Freq = m·aLat`（`Fg` は重力の接平面成分）。
   傾き `φ = atan2(Freq, N0)`（±60°で止める）。`|Freq|>Fmax` なら `Fmax` で切り、1.15 倍の要求、または速さ24m/s超かつ|steer|≥0.9が0.10秒続いたら横滑りへ移して `carveBreak`。
   進む向きの加速度 `at = (Fg + Fair)·t/m − (μN + 0.045|Fedge| + Dplow)/m`、横 `ac = (Fedge + Fg·c)/m`。
   速度は `sEnd=max(0,s+at·dt)`、進行方向を `clamp(ac/s,−1.8,1.8)·dt` だけ接平面内で回す。Euler加算で横力が仕事をするのを防ぐ。板は進行方向へ沿う。
   グリップ破れ後も制動なしで左右を入れる間はこの操舵を続ける。力上限 `Fcap=1.15·Fmax`、滑り角 `β=30°·clamp(Fedge/Fcap,−1,1)·(1−exp(−7·横滑り経過秒))`（移行刻みのFcapは切る上限）。力と滑り角の符号をそろえて切り返しでも山側エッジを使う。
   追加抵抗 `Dscrape=0.60·|Fedge|·|sin β|`、`skidPower=Dscrape·s`、`spray=clamp(skidPower/8000,0,1)`。板は速度方向からβだけ回し、yawRateにβの変化も含める。既に削っている間はcarveBreakを再発行しない。
5. **削る**（`mode='skid'`）：切る状態で制動が 0.05 を超えたら、ここへ移る。移るとき、板の回転の速さは切るときの `yawRate` を引き継ぎ、位置と速度は変えない。
   横滑りの目標 `βcmd = √brake·75°·side`。`side` は左右の入力の符号、無ければ直前の側（初期はかかと側）。
   板の回転は PD（`ωn=7`・`ζ=0.9`、荷重が抜けるほど速い）。雪の横力は板の右方向に
   `Fside = −sign(w)·Fdyn·tanh(10·βe/(λ·E(φs)))`、`Fdyn=(0.44+0.16·ice)·λ·N·E(φs)`、`φs=20°+25°·brake`、`βe=atan2(|w|, max(|u|,0.5))`。
   （氷の動摩擦係数は旧0.6を保ち、圧雪側を0.44へ下げる。`N=0`でも定義できる。）`s<1` では `Fside = −Fdyn·tanh(w/0.5)`。
   低速補正が有効な制動中s≤0.25では板のPDを止め、`m|g接線|≤Fdyn`なら速度も0に留める。板に沿う摩擦 `−μN·sign(u)`。エッジは必ず `−sign(w)` の側（山側）を使う。
   制動が 0.05 未満で `|β|<4°` が 0.10 秒続いたら切るへ戻す。そのとき速度の向きを動かさない。
6. 位置を進め、高さを雪面へ合わせる。新しい法線へ、`vt` と `f` を大きさを保って回す（接平面の乗り換え）。
7. **止まる・動き出す**：`s<0.25` で、板に沿う重力が `0.10N` 未満、横の重力が `λN·E(25°)` 未満なら速度を 0 にして留める。
   留められないとき（板が谷か山を向いている）は、上の「遅いとき」の更新で動き出す。板の軸の近い端が谷へ回り、後ろ向きのまま再開してもよい。低速で制動を離したときはskidのPD回転を止め、この板軸の更新へ渡す。
   **蹴り進み**：接地・ジャンプなし・制動が厳密に0でtuck>0なら、抵抗計算後に `min(4·tuck·dt,max(0,3.2−s))` m/sを板の先端方向へ足す。tuck中は静止保持を解除。蹴りだけでは3.2m/sを超えない。
8. 木と岩・地図の端・安全な地点・出来事と計測値。安全地点はcarve・速さ4m/s以上・有効岩露出0・荷重0.5超・滑り角10°未満などの安定条件が3秒続いたときだけ更新。

## 抵抗
- 雪の摩擦 `μN`、切るときの追加 `0.045·|Fedge|`（提案値）、空気 `Fair = −½ρ·CdA·|v|v`。`CdA` は立ち 0.50、低い姿勢 0.34。
- 新雪の沈み込み `z`：`N = A[Kz·z + ½ρs·CL·s²·min(z/0.10,1)]` を毎刻み解く（`A=0.40`・`ρs=150`・`CL=0.15`）。`z` は雪の深さと 0.25 m で止める。
  押しのけの抵抗 `Dplow = q·z²·tanh(s/0.5)`。横滑り中は `(1+2|sin β|)` 倍。

## 踏み切りと空中（I10・ride-tricks要件1〜6）
- ジャンプを押す間はしゃがむ（時定数0.10秒）。離すと `q=clamp((保持秒−0.12)/(0.8−0.12),0,1)`、`d=crouch·(0.70+0.30q)` を求める。保持0.12秒以上で脚を毎秒`3.8·d`mで伸ばし、伸び切りで法線速度へ加算する。15°の最短/最大滞空は0.4403/0.8219秒。
- 空中は `v̇=g+Fair/m`。重心に回転による力を足さない。基準姿勢の上は雪面法線へ毎秒3radで寄せ、前はスピンで回す。内部記憶は数値6項目で持つ。
- 仕込みは離雪時yaw（±2.5rad/s）＋`steer·6·crouch`、上限430°/s。仕込み初速を離雪時に記憶するが、全回転の角度積分は離雪後0.12秒から（要件1.4を優先）。ゲート中も内部の速度応答を進め、最初の入力から0.15秒で90%へ届かせる。
- スピン許可は空中jump、または仕込みと同じ向きの舵を継続した間。後者は一度切ると再許可しない。目標は`steer·430°/s`（jump）／`steer·300°/s`（仕込み継続）。宙返り目標はjump時だけ`(tuck−brake)·400°/s`。
- 回転速度は `r1=target+(r0−target)exp(−dt/τ)`、角度差は `target·dt+(r0−target)τ(1−exp(−dt/τ))`。τは入力時0.05秒、解除時0.08秒。衝突探索でもこの式で予測し、時刻確定後だけ記憶を更新する。
- 解除時はスピンを進行方向の近い順/逆軸へ、宙返りを360°の近い倍数へ、誤差45°以内なら最大240°/sで補助。自然離雪で未操作の飛びは従来どおり近い板軸へ毎秒3radで沿わせる。
- 実姿勢は基準上U・前Fから`up=U cos(flip)+F sin(flip)`、`fwd=F cos(flip)−U sin(flip)`、`right=fwd×up`。板位置は`com−up·leg`。脚はpopで0.80mへ、自然離雪では離雪時の長さ以上を保つ。
- 空中jump連続0.3秒でつかみ成立。開始時の舵で中立1/左2/右3、未成立0。`air.grabTime`は最長の連続構え秒、成立した種類と時間は解除後も着地まで保持。crouchは従来のmax(tuck,jump)へ寄る。
- 状態airへflip（累計rad）、grab（整数）、grabTime（秒）を追加。landへspin/flip（累計rad）、grab/grabTime、air（秒）、drop（頂点COMから着地COMまでの世界鉛直m）、pop、switchIn/Outを記録。旧保存の欠損値は0/false。空中jumpは接地後いったん離し、押し直すまで次の構えを禁止。

## 着地と転倒
- **着地の時刻**：空中の1刻みの動きを、進む距離 0.25 m ごとの小区間に分け（最低1つ）、板の底と体の先行接触の両方を調べる。体はCOM位置での法線距離`(com.y−h)·n.y−0.45`、板は`pos.y−h`。先頭の接触を採用する。
  初めて雪面より下になった小区間の中で、交わる時刻を二分法（8回）で求める。小区間に分けるのは、薄い隆起を飛び越えて見逃さないため。
  その時刻まで放物線で進めた状態で判定し、刻みの残りの時間は、決まった状態（接地か転倒）の更新で進める。刻みの終点では判定しない。
- 法線方向の速さ `vn = max(0, −v·n)`、等価落下高 `EFH = vn²/(2g)`。
- 板の軸と進む向きの角度を 0〜180° で測り、90° を超えていれば逆向きの着地。ずれ `δ` は、それを 0〜90° へ折り返した値。
- `EFH>1.5`（しゃがみ 0.25〜0.85 で構えていれば 1.8）→ 転倒 `landing-hard`。`δ>55°` かつ `s>6` → 転倒 `landing-sideways`。
- 残り角`|wrap(flip)|>50°`または体の先行接触は`landing-inverted`。残り角>20°、`δ>15°` か `EFH>1.0` → ぐらつく（0.6 秒のあいだ左右の効きを半分、速さを 0.9 倍。`δ>15°` は横滑りから始める）。
- `EFH>0.85` → 重い（I10で0.5から更新。自力最大popのEFH0.8075mをきれいにする）。それ以外はきれい。着地後は脚の速さを `ℓ̇ = −vn`（縮む向き）として、脚のばねに吸収させる。
- 転倒中は `μ=min(2.2,0.45+1.2·転倒経過秒)` で滑り、`s<0.5` が0.3秒続けば1.2秒後に立ち上がる。向きは谷側。
- 自然着地では操舵指令の追従状態を維持し、popの着地ではリセットする。短い浮きで毎回旋回を0からやり直さない。
- 木と岩：滑走者の半径 0.35 m。法線方向 6 m/s 超（岩は 5）で転倒、未満は反発 0.2 で向きと速さを変える。
- 地図の端から 60 m 以内は強い抵抗で止め、`bounds` を出す。

## 復帰（T17/T18）
- safe/dropとも復帰直後の速さは0。斜度5°以上は谷向き、未満は記録した向き。記録そのものは書き換えない。
- 前方12m・左右2mの通路に障害物の半径＋人の半径0.35mを足して確認。横へ最大6m動かし、地図内の候補から最も近い空いた位置へ置く。空かなければ、候補の中で最小空き幅が最大になる位置を選ぶ。

## 逆向きの滑走
`u<0` を逆向きとして扱う。切るときの板の向きは `f=−t`。左右の操作は常に画面の左右（進む向き基準）で、利き足や逆向きで反転させない。
