# Implementation Plan

- [x] 1. 土台：時間・設定・画質の段
- [x] 1.1 固定刻みの時間と手動送りを作る
  - 実時間では上限つきで刻みを進め、手動送りでは指示された秒数だけ進める。隠れたら止める
  - 仮の時計を使った試験で、刻みの回数・上限・手動送りの決定性・復帰時に飛ばないことが通る
  - _Requirements: 2.1, 2.2, 2.3, 2.4_
- [x] 1.2 (P) 設定の保存と画質の段の選び方を作る
  - 設定を端末に保存し、保存できなくても動く。段は自動で選び、URL の指定を優先する
  - 保存の失敗・壊れた保存値・URL の優先を試験で確かめる
  - _Boundary: src/core の settings・quality_
  - _Requirements: 5.2, 5.3, 5.4_

- [x] 2. 入力
- [x] 2.1 (P) キーボードとゲームパッドを、同じ操作の値にまとめる
  - 左右のなめらかな立ち上がり、不感帯、単発の操作（一時停止・復帰・視点）の出来事
  - 仮の入力で、2装置が同じ値と出来事を出すことが試験で通る
  - _Boundary: src/input_
  - _Requirements: 3.1, 3.2, 3.5, 3.6_
- [x] 2.2 タッチの操作部品を作る
  - 左下の舵、右下のジャンプと制動、上の一時停止と視点。左右の指を同時に受け付ける
  - 指を置いた位置が舵の中心になり、2本目の指のジャンプが効くことを、仮のポインター入力の試験で確かめる
  - _Requirements: 3.1, 3.3, 3.4, 3.5_

- [x] 3. 画面の部品
- [x] 3.1 題字・読み込み・失敗の表示を作る
  - 作品名、進み具合、始めるボタン、入力装置ごとの操作の早見、失敗時の案内
  - 始めるボタンが読み込みの完了まで押せず、失敗時に日本語の案内が出ることを確かめる
  - _Requirements: 1.1, 1.2, 1.3_
- [x] 3.2 HUD と案内・転倒の表示を作る
  - 速さと標高、操作の案内の1行、転倒の理由と復帰の操作、止まったときの案内
  - 表示の中身を決める関数に滑走の状態と出来事を与えると、仕様どおりの文言と表示・非表示が返ることを Node の試験で確かめる
  - _Requirements: 1.4, 4.1, 4.2, 4.3, 4.4_
- [x] 3.3 一時停止と設定の画面を作る
  - つづける・直前へ・出発地点へ・設定。設定の5項目を変えられ、すぐ反映される
  - キーボードだけ・指だけの両方で、全項目へ届いて戻れることを確かめる
  - _Requirements: 5.1, 5.2, 5.3_
- [x] 3.4 画面の大きさと向きへの対応を仕上げる
  - 幅 390・768・1440 と横向きで、部品が画面内に収まり、重ならない。動きを減らす設定に従う
  - 3幅と横向きの配置の決まり（大きさ・余白・安全領域）が CSS にあり、部品に検査用の目印（data 属性）が付いている。実測は 5.2 の道具で行う
  - _Requirements: 3.4, 6.1, 6.2, 6.3_

- [x] 4. 開発用の同梱物と器の本体
- [x] 4.1 仮の滑走と、上から見た確認用の表示を作る
  - 速さと向きだけを持つ仮の滑走（本物と同じ形の状態・出来事と、`createState`・`copyState` を持つ）と、位置・向き・速さを描く 2D の表示
  - 仮の滑走に操作を与えて進めると、状態と出来事が決めた形で出ることを試験で確かめる
  - _Requirements: 4.1, 7.3_
- [x] 4.2 部品をつなぐ器と、試験用の窓口を作る
  - 物理・世界・描画・音を差し込んで動かす。前後2刻みの状態と、1回の画面更新ぶんの出来事を持って描画へ渡す。開発用の指定があるときだけ窓口を置く
  - 仮の滑走を差し込み、手動送りで同じ操作の列から同じ状態になること、複数の刻みの出来事が順に全部届くこと、復帰後に前後がそろうことが試験で通る
  - _Requirements: 1.2, 2.1, 7.1, 7.2, 7.3_
- [x] 4.3 器だけのページを作る
  - 3D の描画が無くても、題字から滑走・一時停止・復帰まで通せる入口
  - 入口から読む全ファイルの import が解決でき、開発サーバーで開くと題字から滑走まで進める（実ブラウザの確認は依頼元）
  - _Requirements: 1.1, 1.2_

- [x] 5. 検査と撮影の道具
- [x] 5.1 (P) 起動の検査と固定撮影の道具を作る
  - 3つの方式で開けて、誤り・警告・例外が1件でもあれば失敗。場面の定義から3幅の画像を保存する
  - 器だけのページに対して実行でき、失敗を作ると終了コードが 1 になる
  - _Boundary: tools/shots の boot-check・capture_
  - _Requirements: 8.1, 8.2, 8.4_
- [x] 5.2 (P) 指の操作の検査の道具を作る
  - 左右の指の同時操作を再現し、操作の値と、部品の位置・大きさ・重なりを確かめる
  - 器だけのページに対して実行でき、部品が小さい・重なる状態を作ると失敗する。3幅と横向きの矩形の検査を含む
  - _Boundary: tools/shots の touch-check_
  - _Requirements: 3.3, 3.4, 8.3_
