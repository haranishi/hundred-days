# Rider v1：スキーとスノーボード

`npm run ridergen` で人物モデルと確認画像を生成する。
既定の保存先は `.agent-harness/runs/ridergen/ski/`。
`round-38/` にスキーの11姿勢と4方向の画像が入り、`all-views-1〜3.png` で一覧できる。
各列は後方6°・後方14°・横・正面。後方は距離3mで、ゲームの撮影条件に合わせた。
ブラウザ起動・依存追加・Pythonは不要。番号は画像の接頭辞で、過去のソースを復元する指定ではない。

## I18bの確認と制約

- 実画面では `?gear=ski` でスキーを強制表示できる。物理の選択値は変えない。
- 道具は同じ20本の骨で動かす。スキーの足とストックの向きだけを専用の基準で解く。
- 追加は2,304三角形。合計34,698三角形・851,060 bytesで、仕様の36,000三角形・900 kB以内。
- 読み込み側の旧34,000三角形制限を36,000へ変更。容量制限860,000 bytesは維持した。
- 旧モデルの全頂点属性と面の並びは、SHA256で一致を確認する。基準値は更新しない。
- CPU画像には実際の地形・雪煙・一人称の見え方は含まれない。実画面とFPSは依頼元で確認する。
- 4回の画像修正と最終確認の記録は `.agent-harness/runs/impl/I18b_progress.md`。

## I13fから引き継いだ変更

- 胴と両袖を合成した距離場から、一体の閉じた面を生成する。袖付けの輪と別部品の端を廃止。
- 胸・鎖骨・上腕を混ぜ、極小辺の縮約と関節の動きに合わせた対角線の選択で通常姿勢の面反転を防ぐ。
- 股/ひざ/足首の折りとAOを強調し、ズボンの色は上下で統一する。
- 背負い袋を低く薄くし、肩ひもを下まで延ばす。
- pose.jsでミトンを脚筒・靴箱から逃がす。ひざを回るつかみ軌道、上半身の山側への傾きを追加。

## 確認

- `node tools/ridergen/compare.mjs 34`：指定ゲーム画像10枚との比較を `ridergen/I13f/` へ出す。
- `node tools/ridergen/validate.mjs`：寸法・容量・手の隙間・面反転・袋の上の端を記録する。
- `node tools/ridergen/update-fixtures.mjs`：脚/腰の固定を確認し、許可された上半身関節だけ基準値を更新する。
- 試験：`NODE_OPTIONS=--max-old-space-size=1536 timeout 300 npx vitest run tests/ridergen tests/ride`。

CPUの確認絵はゲームと同じ方位・距離・仰角を使うが、姿勢はsolvePoseの代表値。
保存されたゲームの操作列・地形・照明を再現した画像ではない。実ゲームの再撮影はしていない。

## 残件

通常の代表9姿勢は面反転0。ただし前へ腕を上げる人工姿勢249面、真上396面が反転する。
一体の面にはなったが、極端な腕上げの折れ防止は未達。横へ上げる人工姿勢は反転0。
袋に対するヘルメットの投影上端の露出は33.59%。低い後ろ視点では上着による頭の隠れが残る。
中距離のズボンは足首の陰が読める一方、ひざ裏・股は暗い照明で弱い。
数値と画像は `.agent-harness/runs/ridergen/I13f/`、周回記録は `runs/impl/I13f_progress.md`。
