# Day089「FROSTLINE」の宣伝動画

30秒の縦型動画（1080×1920・30fps）を作る道具。画面はすべて実際のゲームを1コマずつ動かして撮ったもので、後から重ねたのは字幕・押した位置の輪・白い閃光・「あるある」の札・終わりのカードだけ。
流れは機能の一覧ではなく、見た人が滑りたくなる順にした。問いかけ（大ジャンプ台から飛ぶ）→ あるある（雪山は遠い）→ 題字から押してすぐ滑り出す（音のドロップ）→ 切って曲がる・削ってブレーキ → 台で回る（スロー）→ スキー・地図・景色 → 無料・ログイン不要。
絵コンテは `timeline.mjs` の1つの表で、映像（`render-promo.mjs`）とBGM（`promo-audio.mjs`・2案）が同じ表を読む。

## 作り直しは4行、全部で約6分

要るもの: 組み立て済みのゲームを手元で配る配信（ゲームのリポジトリなら `npm run build` のあと `npx vite preview --port 5185`、100日チャレンジなら `day-089-frostline/` を静的に配る）、Playwright（同じリポジトリの `node_modules` から読む。無ければ `--app-dir` で入れた場所を渡す）、ffmpeg / ffprobe、手元の Zen Kaku Gothic New の Bold と Black（既定は `~/Library/Fonts/`、別の場所は `PROMO_FONT`・`PROMO_FONT_BLACK`）。

```sh
node tools/promo/promo-audio.mjs --variant a --out-dir <書き出し先>
node tools/promo/promo-audio.mjs --variant b --out-dir <書き出し先>
node tools/promo/verify-audio.mjs --out-dir <書き出し先>
node tools/promo/render-promo.mjs --url http://127.0.0.1:5185/ --frames-dir <コマの置き場> --out-dir <書き出し先> --mux a,b --clean
```

- 書き出し: `Day089_frostline_promo_{a,b,silent}.mp4`・`first-frame.png`・`contact-sheet.jpg`（1秒ごと）・`cut-check.jpg`（各カットの前後2コマ）・`capture-report.json`・`bgm_{a,b}.{wav,mp3}`・`audio-report.json`・`spectrogram-{a,b}.png`。
- `--only hook,jump` で一部の場面だけ撮り直せる（`overlay` は字幕と札）。`--compose-only` は重ねと書き出しだけ。コマはJPEGで約0.25GB、`--clean` が合成のあとに消す。
- 時間の目安（2026-11-11）: 撮影2.7分、重ね1分、合成0.5分、BGMは1案7秒、音の検査1分。ブラウザは常に1つ。

## 撮影は、ゲーム自身の時計と物理の刻みに合わせる

- **ゲーム自身の時計で1コマずつ進める。** `?debug=1` で開き、ゲームの `setManual`・`teleport`・`setInput`・`advance` だけを使う。物理や座標は書き換えない。進めたあと描画を2回待ってから撮るので、画面なしのブラウザの速さに左右されない。
- **操作は物理の刻み（1/120秒）の上でだけ替える。** 1コマの途中で操作が替わるときは、その刻みで区切って渡す。こうするとジャンプをスローで撮っても、物理は普通の速さで遊んだときと同じになる。台の場面は撮る前に物理だけで1刻みずつ滑らせ、「テール 360」がきれいに着地することと、踏み切り（15.0秒）・着地（18.13秒）のコマを確かめてから撮る。
- **撮り始めまでも1/30秒ずつ遊ぶ。** 手前をまとめて1回で進めると、カメラが大きな1コマの位置に置かれ、普通に遊んだときと違う絵から始まった。
- **画面のボタン（視点・地図・一時停止）は隠す。** ゲームの一覧用デモ（`tools/shots/demo-capture.mjs`）と同じ扱い。速さの表示と技の名前はゲームのまま残す。
- **画質の段はゲームが選ぶ high。** CSS 540×960・DPR 2（指のない画面）で開くとゲームは high を選ぶ。指で操作する端末では既定が mid に下がるので、スマホの既定より上の段で撮っている。
- **手元の住所は映らない。** 配信の宛先以外の要求は送る前に止めて数え、各場面の最初・最後・押したコマで画面の文字と入力欄に `127.0.0.1`・`localhost` が無いことを確かめる。2026-11-11の撮影では要求113件がすべて手元の配信で、止めた要求は0件。書体も手元のファイルで、取得の通信はしていない。
- **押す操作は本物。** 「滑りはじめる」・地図の「山頂」・景色の「次へ」は、マウスを下ろしてから離して押す。輪は下ろしたコマから出し、画面が替わる「滑りはじめる」は押したコマで消す。
- **字幕は投稿アプリの文字に隠れない帯に置く**（上8%と下20%の外）。題字の画面は FROSTLINE の下へ、地図は上半分を地図が占めるので名前の一覧の上へ下げ、暗い板を敷いた。切り替えのコマで前の字幕を薄く残す方法（Day088）は、字幕の行数や位置が違うと二重に見えたのでやめた。

## 字幕は、その秒の画面で起きていることだけ

字幕には、その時の画面で起きていることか、ゲームの機能の事実だけを書く。誇張（本物と同じ・どこより速い）は書かない。

| 秒 | 字幕 | 画面で確かめること |
|---|---|---|
| 0–2.5 | 今すぐ、雪山を／滑りたくない？ | 1コマ目は大ジャンプ台の縁を時速52kmで離れるところ。0.2秒でカメラが縁を越え、板をつかんで森と湖の上を飛ぶ。着地の前で切る（0.88倍） |
| 2.5–5.0 | でも雪山は遠いし、／滑れる時間も短い。 | ゲームは映さない。ぼかした山の絵の上に「遠い…」など6つの札が半拍ごとに出る |
| 5.0–7.5 | ブラウザなら、／押してすぐ滑れる。 | 5.0秒に題字の画面。5.625秒に「滑りはじめる」を押し、そのコマから森の道を滑り出す |
| 7.5–10.0 | エッジを立てて、／雪を切って曲がる。 | 東の尾根で左右に切って曲がる。時速48→71km |
| 10.0–12.5 | 板を横に向けて、／雪を削ってブレーキ。 | 10.0秒から制動。板が横を向き、雪煙を上げて時速71→19km |
| 12.5–18.1 | ジャンプ台で、／回って、板をつかむ。 | パークの小さい台。15.0秒に踏み切り、テールをつかんで1回転。空中はスロー（最も遅い所で0.48倍） |
| 18.1–20.0 | テール 360。／技の名前と点が出る。 | 18.13秒にきれいに着地し、下に「テール 360　＋1,146 点」が出る |
| 20.0–22.5 | スキーも選べる。 | スキーで谷のゲレンデを切って曲がる |
| 22.5–25.0 | 一辺4km・標高差約1,600m。／地図で出発地点を選べる。 | 山の地図。23.125秒に「10 山頂」を押し、詳細が山頂に替わる |
| 25.0–27.5 | 氷河も、湖も。／景色を見る視点は9つ。 | 景色を見る「東の斜面から（5／9）」。26.25秒の「次へ」で「南の岸から（6／9）」 |
| 27.5–30.0 | （終わりのカード） | FROSTLINE・ブラウザで、雪山を滑る。・無料／ログイン不要／ブラウザですぐ／スマホは指で操作・rairakku.com/100days/day-089-frostline/・はじめに山のデータ（約36MB）を読み込みます |

「一辺4km・標高差約1,600m」は、山のデータの値（一辺 4,096 m・標高 1,180〜2,792 m）。最初は計画の値の 1,500m と書いていたが、生成した山と食い違っていたので直した。

## 落とし穴：急斜面のブレーキは1小節では止まりきらない

- 東の尾根は急で、時速70kmから制動をかけると止まるまで約3秒かかり、1小節（2.5秒）に収まらない。だから字幕は「止まる」でなく「ブレーキ」にした。止まるところまで見せるなら、谷の入口（時速50kmから約2秒で止まる）に替える。
- 大ジャンプ台の着地はゲーム時間4.567秒。フックの開始や速さ（`rate`）を変えたら、最後のコマが着地より前かを道具が検査する。
- 絵コンテの秒を変えたらBGMも作り直す。ドロップ・着地・押した音はこの表の秒を読んでいる。

## BGMは2案。数値の検査は全項目合格、耳では未確認

96BPM・12小節でちょうど30秒。どちらも計算だけで合成する（録音・サンプル・追加パッケージなし）。同じ入力からは1バイトも違わない同じファイルになる。
A「雪原エレクトロ」はニ長調。のこぎり波のパッド、16分のFMアルペジオ、キックに合わせて沈むベース、クラップ、リード。B「インディ・ギター」はト長調。撥弦のギター（Karplus-Strong）を8分で刻み、指弾きふうのベース、ロックのドラム、鉄琴。和音進行と6音の旋律は自作。
展開は絵コンテに合わせた。フックは軽い拍、あるあるは拍を抜いて上がる音、題字の5.0秒でドロップ、ブレーキの10.0秒にシンバル、踏み切りまでスネアを詰め、空中はドラムを止めて上がっていく風の音、18.125秒の着地で一番大きな打撃、27.5秒から終止和音、最後の1.6秒で消える。押した3か所には小さな音を入れた。

検査（`verify-audio.mjs`）は −16 LUFS±1、真のピーク −1.5dBTP以下、クリップ0、0.5秒ごとの音量が −40dBFS を下回らないこと、ドロップと着地で3dB以上上がること、その位置が絵コンテから1コマ以内、低域（120Hz以下）が全体より −9〜−6dB、高域（8kHz以上）が −43〜−38dBFS、作り直して同じバイト列になること。
2026-11-11の結果は、A −16.04 LUFS・−1.94dBTP・低域 −7.06dB・高域 −38.29dBFS、B −16.11 LUFS・−2.06dBTP・低域 −6.26dB・高域 −38.07dBFS で、全項目が合格した。数値とスペクトログラムで確かめただけで、耳では聴いていない。
