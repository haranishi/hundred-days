# Day056 — 夕暮れ怪獣ラッシュ

紅竜・雷翼・溶背の3体から選び、夕暮れの架空の湾岸都市を3分間壊す3Dアクション。

[公開ページ](https://hundred-days.pages.dev/day-056-dragon-rush/)

WebGL2対応ブラウザが必要です。PCはキーボードとマウス、スマホは横向きのタッチ操作に対応。
スマホは軽量画質固定です。端末によって読み込みや動作が重くなる場合があります。
無料・登録不要。強い光と画面の揺れがあります。

## 操作

- スマホ：左の丸で移動、右の面をなぞって見回す。主砲は長押し、ほかの技はボタンで操作。
- 縦向き・別アプリへの切り替えは一時停止。横向きに戻して「再開」を押す。
- WASD：移動。マウス：見回す。
- 左クリック長押し：主砲。右クリック：爪／角。
- Q：尾。E：大技。Space：飛ぶ／跳ぶ。
- Shift：急降下／突進。Esc：一時停止、画質・音量の調整。

3体は壊し方が異なります。紅竜は炎、雷翼は連鎖雷、溶背は溶岩・地割れ・突進。
自己ベストと設定はこのブラウザのlocalStorageに保存します。
ゲームの操作記録を外部へ送信する機能はありません。

## ソースと配信

`game/` は同梱素材とViteの配信ビルド、`source/` はそのTypeScriptと生成ツールです。
公開入口では開始ボタンを押すまでWebGLと音を読み込みません。
共有はX・LINE・端末の共有シート・リンクコピーに対応します。
OGPとcanonicalは共通ビルドが生成します。

```sh
cd day-056-dragon-rush/source
npm ci
npm test
npm run build
npm run dev
```

元モデルと合成音は`../game/assets/`にあります。`public`はその配信ディレクトリへのリンクです。
生成ツールはBlenderとffmpegを別途必要とします。
ルートの`npm run build`は再生成せず、確認済みの配信ビルドをコピーします。
