# Day 56 プロモ動画

実ゲームの自動操作を録画し、32秒の縦動画と18秒の横デモに編集する。
ゲームは変えない。
スコア・怒り・破壊・カメラを録画のために書き換えることはせず、
通常のキー操作と同じ入力経路を通る自動操作で3体を動かす。

## 編集の5要素

- 用途：X、Reels、Shorts等に使える紹介素材。SNSへの自動投稿はしない。
- 尺：縦1080×1920・32秒、横1280×720・18秒。どちらも30fps。
- トーン：夕暮れの街を壊す爽快感。実画面を中心にテンポよく見せる。
- 対象：PCのキーボードとマウスで遊ぶブラウザゲームが好きな人。
- 完成像：先頭から動く実ゲーム映像、短い字幕、ゲーム内の独自合成BGM。

## 採用カット

| 秒 | 実ゲーム素材の秒 | 内容・字幕 |
|---|---|---|
| 0–3 | 紅竜10–13 | 今日は、街を壊す側。／怪獣になって大暴れ |
| 3–8 | 紅竜4–9 | 紅竜は、炎と飛行。 |
| 8–15 | 雷翼0–7 | 雷翼は、雷を連ねる。 |
| 15–24 | 溶背4–13 | 溶背は、溶岩と地割れ。 |
| 24–29 | 紅竜6–11 | 3体から選んで大暴れ。／PC用の3D怪獣ゲーム |
| 29–32 | 雷翼9–12 | PCのブラウザで遊べます／キーボード＋マウスで操作 |

素材の起点はゲーム内時刻で紅竜5秒、雷翼4.2秒、溶背38秒。
ヒットストップがあるため素材の秒とゲーム内時計は完全には一致しない。
映像は自動操作・コマ送り収録。人のプレイ実績・実時間の性能証明ではない。

## 音と画角

音声はナレーションなし。ゲームの手続き合成BGMを紹介用に再編集する。
第三者の音源やサンプルは使わず、生録りの同期効果音とは表記しない。
OGGの前後0.1秒の糊しろを外し、3層を混合。末尾は1.2秒で消す。
ラウドネスは書き出した音を測り、最終AACを約−14LUFSへ合わせる。
縦画面の中央にゲーム映像、上下に字幕。上下10%には重要な文字を置かない。
字幕は1行16字以内・2行まで。文字はOSのヒラギノで焼き込み、フォントは配布しない。

## 再現

Node、Playwright Chromium、ffmpeg、ffprobe、日本語フォントが必要。
ゲームをローカルで起動してから、リポジトリのルートで実行する。

```sh
GAME_URL=http://127.0.0.1:5301/ node day-056-dragon-rush/tools/promo/record-game.mjs
node day-056-dragon-rush/tools/promo/render-promo.mjs
```

別のPlaywright依存を使う場合は`PLAYWRIGHT_ROOT`、音源の場所は`AUDIO_ROOT`、
日本語フォントは`PROMO_FONT`で指定できる。`REBUILD_RAW=1`で素材MP4を再生成する。
修正版は両スクリプトに同じ`PROMO_OUTPUT_DIR`を指定し、原本とは別の保存先へ出す。
原本のゲームと音源は変更しない。生成物はGit対象外で、`cache/`に中間素材を残す。
録画のGPU・エラー・時刻・技のイベントは各怪獣の`cache/*/record.json`に保存する。

## 検品と引き渡し

`promo-probe.json`で尺・fps・解像度・H.264/yuv420p/AACを確認する。
`promo-loudness.json`の`input_i`と`input_tp`が完成MP4の測定値。
`promo-first-frame.png`と時刻付き`preview-contact.jpg`で文字と画角を目視する。
`demo-first-frame.png`は横デモの最初のコマ。
最終的な間・テンポ・音の好みはユーザーによる再生確認が残る。
成果物の保存先・実測結果・編集ログは作業を取りまとめる担当が記録する。
