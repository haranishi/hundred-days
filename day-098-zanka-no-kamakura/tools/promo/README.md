# Day098「残火の鎌倉 — 隠れ谷の灯」宣伝動画ツール

縦型30秒（1080×1920・30fps・H.264 `yuv420p` `bt709`・AAC 192kbps）の宣伝動画（BGM A案・B案・無音）と、100日チャレンジ一覧カード用の `demo.mp4`（540×960・16秒・30fps・無音）を実アプリの3D描画から1コマずつ決定的に生成する道具です。

## 再生成コマンド

```sh
OUT=/tmp/day98-promo-out
FRAMES=/tmp/day98-promo-frames
SITE=../kamakura-no-zanka/.pages-dist

node day-098-zanka-no-kamakura/tools/promo/promo-audio.mjs --out-dir "$OUT"
node day-098-zanka-no-kamakura/tools/promo/verify-audio.mjs --out-dir "$OUT"
node day-098-zanka-no-kamakura/tools/promo/render-promo.mjs --site-dir "$SITE" --frames-dir "$FRAMES" --out-dir "$OUT"
```

## BGM と権利

- BGM は `promo-audio.mjs` による純 JavaScript 合成（D の陰旋法／都節音階 `D・Eb・G・A・Bb`・90 BPM、外部音源・サンプル不使用）。
  - A案「残火の静寂」：低音ドローン＋箏/三味線の撥弦（Karplus-Strong）＋遠太鼓＋刀戟アクセント
  - B案「隠れ谷の陣太鼓」：半拍刻みの太鼓・締め太鼓＋拍子木＋撥弦＋剣戟・とどめの大太鼓
- 映像はすべて『残火の鎌倉 — 隠れ谷の灯』公開用ビルドの実描画。字幕書体は macOS 付属の「ヒラギノ明朝 ProN」を映像へ焼き込み（フォントファイル非配布）。
