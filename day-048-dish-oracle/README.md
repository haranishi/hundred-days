# Day 048：いま食べたいもの、当てます

占い師の質問に「はい・たぶんそう・わからない・たぶん違う・いいえ」で答えると、水晶玉があなたの心にある料理を当てる。
料理を思い浮かべていれば心を読む遊びに、まだ決めていなければ「いま食べたいもの」を1つに決める道具になる。

## 遊び方

1. 料理をひとつ思い浮かべる（決まっていなければ、いまの気分のままでよい）。
2. 「それは、温かい料理ですか？」のような質問に答える。押し間違えたら「ひとつ戻る」。
3. 水晶玉が推測したら「当たり！」か「ちがう」。当たると、決め手になった答えが出る。
4. 推測3回・質問25問で当たらなければ、正解を教える。一覧に無い料理でも教えられる。

キーボードでは、始めの画面を Enter（または 1）で始め、1〜5 で答え、Backspace で戻る。推測には Y（当たり）／N（ちがう）。結果の画面では Enter でもう一度占う。

## しくみ

- 料理154品それぞれに、76の質問へ「はい」と答える見込みを持たせている（`lib/dishes.js`・`lib/questions.js`）。
  値は日本の一般的な食卓を想定した作者の目安で、統計ではない。
- 答えのたびに見込みを掛け合わせて、各料理の確からしさを更新する（`lib/oracle.js`）。答えが1回食い違っても正解が消えないよう下駄をはかせてある。
- 次の質問は、答えを聞いたときに候補が最も絞れるものを選ぶ。名前・色・形・地方の質問は、まだ料理を決めていない人に答えにくいので8問目まで出さない。
- 10問を過ぎると、推測に踏み切る基準を少しずつ下げる。気分が2〜3品のあいだで揺れている人にも、20問以内に1つ出すため。
- 「はい」「いいえ」とはっきり答えたことと食い違う料理は推測しない（確率が低い推測は1つでも食い違えば出さない）。推測できる料理が残らなければ、25問を待たずに「参りました」と言う。当てずっぽうに出したり、読み0%のまま聞き続けたりするより、潔く降参するほうが納得できるため。
- 「たぶん」「わからない」が多い人は料理を決めずに気分で答えていることが多いので、少し早めに「提案」として推測する。
- 水晶玉のまわりの「読みの輪」は、推測してよい料理のうち最有力の確からしさ。推測の瞬間にだけ100%になる。答えるたびに上下の差分（+14%／−9%）を出し、1問ごとの読みを小さな折れ線で残すので、どの答えで遠のいたかが分かる。
- 水晶玉の中の絵はその料理で、読みが高いほどぼかしが弱まる。当てた瞬間は、絵が玉から大きく浮かび上がる。

## 端末の中で賢くなる

当たった料理と教わった料理について、各質問への答え方を端末の `localStorage`（`day048.oracle.memory.v1`）に覚え、次の占いで元の見込みに混ぜる。
覚えるのは料理名と答え方だけで、外部には送らない。一覧に無い料理は30品まで。画面の「覚えたことを忘れさせる」で全部消せる。
保存が使えない端末でも遊べる（覚えないだけ）。
ほかに端末に残すのは、直前の占いの出だしの質問（`day048.oracle.openers.v1`・同じ出だしを避けるため）と、読みの輪の説明を出したかどうか（`day048.oracle.ringhint.v1`）。途中で再読み込みしても続きから遊べるよう、進行中の占いはそのタブの `sessionStorage`（`day048.oracle.session.v1`）に置く。

## 構成・開発

- `lib/oracle.js`：推理（確率の更新・質問の選び方・推測の判断・決め手）。画面から独立した純粋関数。
- `lib/memory.js`：端末の記憶の検証・保存・料理名の検索。
- `lib/dishes.js`・`lib/questions.js`：料理と質問のデータ。
- `app.js`・`app.css`・`index.html`：画面。占い師と水晶玉はSVGで描いている。

リポジトリのルートで `npm run shared:sync`、`npm run build` を実行し、`node scripts/serve-dist.mjs` で確認する（ESモジュールのためHTTP経由で開く）。

## テスト

- `node --test day-048-dish-oracle/tests/`：データの整合、推理、記憶、全154品の当てシミュレーション。
  正直に答える人は全品を平均12問以内で当て、明らかな事実はめったに間違えない人も9割以上を当てる。一覧に無い料理のとき、答えと食い違う料理を推測しないことも確かめている。
- `npx playwright test tests/e2e/day-048.spec.mjs`：開始から当たりまで、戻る、キーボード、教える、保存できない端末、忘れさせる、画面幅。

## 権利・注意

質問で当てる遊び方そのものは昔からあるもので、特定の作品の名前・キャラクター・絵は使っていない。
料理の絵（`assets/dishes/`・154品と「覆いをかけた皿」）は、このアプリのためにAIの画像生成で作った。9品ずつ3×3のタイルで生成し、区切り線を画素から探して1品ずつに切り分け、320pxのWebPにしている。絵が読めないときは各OSの絵文字に戻す。
料理データ・質問文・占い師の絵（SVG）はこのリポジトリ独自のもの。
