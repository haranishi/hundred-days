# いま食べたいもの、当てます

占い師の質問に5段階で答えると、水晶玉があなたの心にある料理を当てる。
料理を思い浮かべた人には「心を読まれる」遊びとして、まだ決めていない人には「いま食べたいもの」を1つに決める道具として働く。

## ユーザーストーリー

1. 料理を思い浮かべた人として、20問くらいまでに当てられて驚きたい
2. 晩ごはんが決まらない人として、気分のまま答えて、食べたいものを1つに決めてほしい
3. 答えを押し間違えた人として、最初からやり直さずに1問だけ戻したい
4. 当てられた人として、どの答えが決め手だったかを知り、結果を送りたい
5. 当てられなかった人として、正解を教え、次はこの端末で当ててほしい。一覧に無い料理でも教えたい

## UXの5階層

| 層 | 決めたこと | 画面への反映 |
| --- | --- | --- |
| 戦略 | 心を読む遊びと、決めきれない夕食の手助けを同じ質問で | 質問は「それは、〜ですか？」の1通り。料理を決めていても、気分で答えても通じる |
| 要件 | 答える・戻る・推測に答える・教える | 5段階の答え、ひとつ戻る、当たり／ちがう、一覧から探す／新しく教える |
| 構造 | 質問 → 推測 → 結果。外れたら質問に戻る | 推測は3回、質問は25問まで。使い切ったら「参りました」で教わる |
| 骨格 | 舞台（占い師と水晶玉）の下に質問と答え | スマホは答えを縦に5つ。舞台は質問中だけ低くして、質問と答えを1画面に |
| 表層 | 夜の占いの館 | 藍と金、明朝の見出し。霧の回る水晶玉に最有力候補の3Dの絵がぼやけて映り、まわりの読みの輪が満ちていく。上下の差分と読みの軌跡で、近づいたか遠のいたかを見せる |

## 推理

- 料理ごとに「その質問に『はい』と答える確率」を持つ（`lib/dishes.js`・154品×76問）。
- 答え（はい1・たぶんそう0.75・わからない＝使わない・たぶん違う0.25・いいえ0）ごとに尤度を掛けて事後確率を出す。
  尤度には下駄（0.08）があり、答えが1回食い違っても正解が消えない。
- 次の質問は期待情報量が最大のもの。最初の3問は、情報量が最大の6割以上ある上位6問からくじで選び、直前の占いの出だしは避ける。
  名前・色・形・地方の質問は8問目まで出さない。それらに「わからない」と答えた人には、以後も後回しにする。
- 最有力の確率が基準を超えたら推測する。基準は10問目まで0.85、以降1問ごとに0.05下げ、下限0.4。外した直後は最低1問聞いてから次を推測する。
- はっきりした答え（はい・いいえ）と2つ以上食い違う料理は推測しない（確率0.95以上は例外）。確率0.85未満の推測は、食い違いが0の料理に限る。
- 推測できる見込みの料理が残らなければ、25問を待たずに「参りました」（食い違いは答えるほど増える一方なので、聞き続けても読みは0%のまま）。
- 「たぶん」「わからない」が半分以上の人には、10問目から基準を0.15下げ、提案として推測する。教わった料理は事前の重みを3倍にし、ほぼ同点なら先に出す。
- 読みの輪＝推測してよい料理のうち最有力の確率÷その問数の基準（上限0.99）。推測の画面でだけ100%。
- 状態は「答えの列」と「外れた推測の列」だけ。事後確率は毎回その列から計算し直す。

### 合格ライン（単体テストで固定）

- 正直に答える人：全料理を100%、平均12問以内で当てる。
- 明らかな事実はめったに間違えない人（事実3%・判断が割れる質問15%を逆に答える）：90%以上。
- 何でも1割逆に答える人（負荷試験）：60%以上。食い違う料理を推測しない決まりと早めの降参と引き換えに下がる（決まりの前95%→63%）。一覧に無い料理で読み0%のまま聞き続ける不満を優先した。
- 一覧に無い料理を思い浮かべた人：はっきりした答えと食い違う料理を推測しない（2つ以上は0回、確率0.85未満なら1つでも0回）。降参までの平均は20問以内。
- 2品のあいだで気分が揺れる人：最初の推測の中央値が20問以内で、推測はどちらかの料理。3割以上は「提案」として出る。
- 教えた料理は、同じ答え方の次の占いで最初に推測される。

## 端末に覚えること

- 当たった料理・教わった料理について、各質問への答えの合計と回数を `localStorage` の1か所（`day048.oracle.memory.v1`）に保存する。
- 次の占いでは、元の確率にこの答え方を混ぜる（元の確率を2回分の答えとみなす）。一覧に無い料理は名前ごと覚える（30品まで）。
- 覚えるのは料理名と答え方だけ。外部へは送らない。保存が使えない端末でも遊べる。壊れた記録は捨ててやり直す。
- 「覚えたことを忘れさせる」で、確認のうえ全部消す。

## 共有

- 共通の共有欄（アプリの紹介）とは別に、結果の行を置く。Xの投稿画面と、結果文＋URLのコピー。
- 結果文は料理名と問数を含む。共有するのは結果の文とアプリのURLだけで、答えの中身は送らない。
