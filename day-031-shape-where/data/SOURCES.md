# 同梱データの出どころ

`prefectures.json`（47都道府県）と `towns/NN.json`（県ごとの市区町村）は、下の元データを変換して作った。クイズは通信なしでこの2つだけを読む。

- **元データ**: 国土数値情報「行政区域データ」2025年版（N03-20250101）／国土交通省
  <https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-N03-2025.html>
- **取得日**: 2026-09-07（都道府県別 zip 47本）
- **ライセンス**: CC BY 4.0。原典は国土地理院「数値地図（国土基本情報）」
- **画面に出す出典**: 「国土数値情報（行政区域データ）」（国土交通省）（上記URL）を加工して作成

## 加工したこと

- 政令指定都市の区は市にまとめた（横浜市の18区→横浜市1件）。東京23区は区のまま。合計1,741件
- 所属未定地（コードが `NN000`）と北方領土の6村（`01695`〜`01700`）は載せていない
- 輪郭は mapshaper 0.7.59 で融合し、市区町村は100m・都道府県は300mまで単純化した
- 本体から遠く離れた小さな島は落とした（規則は `lib/geo.js` の `keepMainParts`）
- 旧市町村の境界に沿って残る糸のような穴（スリバー）は落とした。湖や飛び地の穴は残る（同 `dropSliverHoles`）
- **緯度経度と縮尺は残していない。** どの形も長い辺が1000になるよう拡大縮小して整数に丸めてあるので、位置や面積は読み取れない（地図としては使えない）。原典が測量成果であるための措置
- `rings` は外側も穴も同じ並びに入れ、閉じていない（描く側が `Z` で閉じる・`fill-rule="evenodd"`）
- `pos` は県の枠（0〜1000）で測った町の中心と長い辺
- 県の輪郭から落とした離島にある町34件（奄美群島・伊豆諸島・先島諸島など）には `"far": true` が付く。`pos` は枠の縁に寄せた値なので位置としては正しくない。枠に収まる町に `far` は書かない

## 作り直す

`node tools/fetch-n03.mjs` で元データを集め、`node tools/build-data.mjs` で書き出す。`--date YYYY-MM-DD` で `generatedAt` を固定できる。同じ入力からは同じ出力になる。
